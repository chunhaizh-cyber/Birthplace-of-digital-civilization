## 1. 口径

`获取特征值` 是自我通过双目相机取得外部可观察特征值的使用类内部本能方法。

它不是：

```text
1. 读取世界树中已经存在的特征快照。
2. 双目相机内部的采集、校正、视差、深度、滤波、分割步骤。
3. 控制面板相机画面的人工观察入口。
4. 可在未实现动作入口时进入普通候选集的占位方法。
```

读取已有特征快照只能是普通工具函数或诊断读取；只有一次真实观测动作产生新的观察事实、输出结果场景或世界模型刷新时，才符合 `获取特征值` 本能方法口径。

## 2. 方法契约

必需输入：

```text
目标外设：
    双目相机或可被解析为双目相机的外设存在。

目标宿主：
    需要被观测的对象、场景、自我内部世界模型或观察场景。

目标特征类型：
    本轮要获取的具体特征类型。
```

可选输入：

```text
观察场景
来源需求
任务信息节点
观察限制包
目标状态
允许置信度下限
```

前置条件：

```text
1. 目标外设可用。
2. 双目相机运行状态正常或降级可用。
3. 目标宿主可被当前观察场景绑定或识别。
4. 目标特征类型属于双目相机可观察特征集合。
5. 本轮调用权限允许使用该外设。
```

动作入口：

```text
自我层只调用双目相机适配器提供的不透明观察入口。
D455 的采集、校正、匹配、滤波、轮廓提取等内部步骤不暴露为自我层方法。
```

输出结果：

```text
输出结果场景：
    目标外设
    目标宿主
    目标特征类型
    特征值
    观察结果状态
    方法运行结果状态
    失败原因或缺口原因

本轮运行虚拟存在：
    输入参数场景
    输出结果场景
    目标外设
    目标宿主
    目标特征类型
    动作动态
```

## 3. 可观察特征范围

第一阶段只承接双目相机能够直接或通过外设适配器稳定输出的空间与可见性特征：

```text
距离
相对位置
尺寸
方位
高度
可见性
在场状态
候选存在集合
当前观察场景
```

不在该集合内的目标特征不能由本方法猜测、推断或从旧世界树快照读取后伪装成观测结果。

## 4. 动作动态边界

`获取特征值` 的方法动作动态只表示：

```text
自我通过双目相机执行了一次观测动作；
本轮输入是什么；
本轮输出了哪些观察事实；
自我内部世界或观察场景获得了哪些刷新结果。
```

不得表示：

```text
自我改变了被观测对象的物理状态；
外部对象自身发生的独立变化由自我方法造成；
需求已经满足。
```

需求满足只能由后续比较、回写和结算链判断。外部对象状态变化只能作为观察动态、外部事件动态或观察结果事实进入世界模型。

## 5. 当前未实现缺口

当前尚缺：

```text
1. 自我层可复用的双目相机外设存在和适配器持有位置。
2. 获取特征值的本能方法枚举、默认方法种子、运行时注册和专属规格。
3. 输入条件包到目标外设、目标宿主、目标特征类型的参数绑定。
4. 目标宿主到 D455 轮廓 / 空间观测结果的绑定规则。
5. 距离、相对位置、尺寸、方位、高度、可见性、在场状态到特征值的转换规则。
6. 输出结果场景、观察事实和方法动作动态落账。
7. 无硬件、目标不可见、特征不可观察、采样失败时的缺口输出。
```

因此，当前不得把 `获取特征值` 加入默认可执行本能方法表或普通候选方法集；只能把它作为待实现的使用类外设本能方法继续推进。

## 6. 落地顺序

```text
1. 先整理双目相机外设存在与可观察特征口径。
2. 再补自我层双目相机适配器入口。
3. 然后实现 获取特征值 的明确输入、前置条件、输出和动作动态落账。
4. 最后登记默认本能方法、专属规格和多条结果能力。
```

若没有真实 D455、真实目标对象或真实观测需求，只能记录等待真实样本，不得使用模拟样本或伪造动作动态验收。
