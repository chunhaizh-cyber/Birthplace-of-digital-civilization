# 鱼巢工程模块索引

本文件对应书稿《人工智能之数字生命：从会回答的机器到会生存的系统》附录 B 的仓库版模块索引。它是阅读指南，不是源码清单，也不是实现完成证明。

固定引用版本：

```text
tag: v0.1-book-rc2
对应书稿: 2026-05-28 发布候选稿
branch: main 仍是 active development
```

## 阅读边界

本索引只做三件事：

```text
第一，标明章节概念在鱼巢这个工程原型中的对应位置；
第二，标明这些对应位置能够提供什么工程证据；
第三，标明这些证据不能推出什么结论。
```

鱼巢工程模块只能说明一组实现样本，不能反过来定义数字生命判据。七层判据的来源是一般行动系统的结构要求：持续存在、结构化感知、可行动场景、需求归属、方法能力、反馈记忆和边界约束。

## 章节到工程模块的对应关系

| 理论层 | 主要章节 | 鱼巢模块或结构 | 可提供的工程证据 | 不可推断结论 |
| --- | --- | --- | --- | --- |
| 存在层 | 第三章 | `世界树类.*`, `存在类.*`, 主键、状态记录、存档与重载材料 | 系统可以把对象作为持续节点保存、追踪和恢复 | 不能推出系统已经拥有成熟自我 |
| 感知层 | 第六章 | `特征类.*`, `状态类.*`, `动态类.*`, `二次特征类.*`, 通用函数 | 输入可以被转化为可比较、可存储、可复用的特征材料 | 不能推出系统已经理解世界本身 |
| 场景层 | 第七章 | `场景类.*`, 父子场景、坐标、包围盒、局部变换、空间匹配 | 对象可以被放入处境、关系和空间组织中 | 不能推出系统已经具备完整身体经验 |
| 需求层 | 第四章 | `需求类.*`, `需求主信息类.h`, 需求树、当前状态、目标状态、满足条件 | 状态差可以被整理成需求候选和需求节点 | 不能推出需求已经能够稳定自生长 |
| 方法层 | 第五章 | `方法类.*`, `方法虚拟存在服务类.*`, `本能方法类.*`, 方法树 | 行动能力可以被条件、对象、效果和边界约束 | 不能推出方法学习链已经闭合 |
| 任务层 | 第十章 | `任务类.*`, `任务模块.筹办.ixx`, `任务模块.执行.ixx`, `任务模块.管理工作线程.ixx` | 需求可以被转译为过程，并通过方法执行取得结果材料 | 不能把任务完成直接等同于需求满足 |
| 记忆层 | 第八章 | 世界链、特征链、语言链、需求链、任务链、方法链、动作动态、回写材料 | 场景、需求、方法、结果和边界材料可以被保存并再次参与判断 | 不能把保存数据直接等同于经验成熟 |
| 语言层 | 第九章 | `语素类.*`, `语言类*.cpp`, 语素链、语言链、表达材料、意图材料 | 人类表达可以转化为需求、场景和方法之间的接口材料 | 不能把流畅表达等同于生命结构成立 |
| 责任链 | 第十二章 | `动态类.*`, `因果类.*`, 动作动态、回执、权限记录、确认记录、因果账本 | 行为过程可以留下追踪材料，供复盘和责任分析使用 | 不能替代法律责任判断 |
| 边界与价值 | 第十一章、第十三章 | 权限、阈值、追踪材料、确认节点、边界行为 | 系统可以在行动前、中、后引入允许、暂缓、确认和停止承接 | 不能推出价值冲突已经被完全解决 |
| 休眠、复制与继承 | 第十四章 | 存档、重载、状态复制、实例分叉、继承边界 | 数字存在可以讨论暂停、恢复、复制和继承的工程条件 | 不能把备份恢复简单等同于同一生命延续 |
| 可观测性 | 全书工程材料 | `控制面板类.*`, `控制面板WebView2.*`, `日志模块.ixx`, `说明书/项目说明.md` | 运行状态、快照、日志和 HTML 面板可用于检查工程路径 | 不能把显示面板或摘要当作阶段完成证书 |

这张表的关键不在于证明鱼巢已经抵达终点，而在于说明：本书讨论的存在、感知、场景、需求、方法、任务、反馈、记忆和边界，都不是孤立修辞，而是可以被工程拆解、观察和验证的结构。

## 随书代码边界

完整源码不直接进入书稿正文。外部仓库以版本号、提交哈希、许可证和章节索引的方式提供工程材料，而不是把未整理源码整体印入书中。

看见代码，不等于数字生命已经完成。代码只能提供工程证据和结构骨架，不能直接推出完整自我、稳定需求生长、成熟方法学习、完整因果理解、完整治理能力或现象意识。
