# 文档总索引

## 0. 定位

本文件只做入口导航和权力关系说明，不承载复杂论证，不替代规范、详细设计、计划或实施记录。

权威等级：入口导航。若本文件与 `规范/规范目录.md` 或具体上级规范冲突，以规范为准。

## 1. 文档权力关系

| 层级 | 主要入口 | 作用 | 不能做 |
| --- | --- | --- | --- |
| 入口层 | `README.md`、`AGENTS.md`、`说明书/项目说明.md`、`docs/book-mapping.md`、本文件 | 告诉人和 Codex 从哪里读、当前边界是什么 | 不定义新系统规则 |
| 权威规则层 | `规范/规范目录.md`、`规范/*.md` | 判断能不能这样做 | 不记录临时执行流水 |
| 设计解释层 | `详细设计/*.md` | 解释如何实现规范 | 不覆盖规范 |
| 流程图层 | `流程图/*.md`、`流程图/*.html` | 把规则和代码路径视觉化 | 不作为权威规则来源 |
| 执行层 | `计划/计划索引.md`、`计划/*.md` | 决定本轮做哪一段 | 不改变系统口径 |
| 证据层 | `实施记录/*.md` | 记录实际做了什么、跑了什么、结果是什么 | 不反向定义规则 |
| 图谱层 | `docs/工程图谱/*.md` | 把概念、规范、代码、证据入口短索引化 | 不替代规范和计划 |
| 对外说明层 | `README.md`、`说明书/*.md`、`docs/book-mapping.md` | 给人读的项目说明和书稿映射 | 不塞入临时 TODO 或旧口径 |

## 2. 默认阅读顺序

初次了解项目：

```text
README.md
-> 说明书/项目说明.md
-> docs/book-mapping.md
-> 本文件
```

执行计划或修改代码：

```text
AGENTS.md
-> docs/00_文档总索引.md
-> 规范/禁止性规范20260611.md
-> 规范/规范目录.md
-> 计划/计划索引.md
-> docs/工程图谱/00_图谱总索引.md
-> 当前主题对应图谱
```

按主题优先查：

```text
需求 / 任务 / 方法闭环：docs/工程图谱/01_任务需求方法闭环图谱.md
外设 / 观察 / 事实提交：docs/工程图谱/02_外设观察事实图谱.md
安全 / 服务 / 结算：docs/工程图谱/03_安全服务结算图谱.md
Codex 改代码前自检：docs/工程图谱/04_Codex改代码前检查清单.md
```

## 3. 统一流转规则

正式流转只允许沿这条链推进：

```text
问题 / 新口径
-> 规范变更
-> 详细设计解释
-> 计划拆分
-> 代码实施
-> 实施记录
-> 回归验证
-> 更新索引
-> 完成 / 归档
```

禁止反向覆盖：

```text
实施记录直接改规则
流程图直接改规则
计划直接改规则
详细设计覆盖规范
旧说明书覆盖新规范
图谱替代规范或计划
```
