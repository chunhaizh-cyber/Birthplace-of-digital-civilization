# 规则原子索引

## 0. 定位

规则原子是 Codex 改代码前的高风险规则路标，用于快速定位来源规范、适用范围、代码入口和验证状态。

权威等级：规则导航层。规则原子不覆盖来源规范；若规则原子与来源规范冲突，以 `规范/规范目录.md` 和来源规范为准。

## 1. 使用规则

```text
1. 修改代码前，按任务主题先查本文件。
2. 命中 RULE 后，必须回读来源规范。
3. 相关测试为“人工审查”时，不得宣称自动回归已覆盖。
4. 发现规则原子过时，应先按来源规范修正规则原子，再继续代码修改。
```
