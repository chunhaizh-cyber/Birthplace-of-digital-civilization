# 工程图谱总索引

## 0. 定位

工程图谱是 Codex 和维护者改代码前的短索引层，用来把概念、规范、代码、验证证据和禁止事项放在同一张导航表里。

权威等级：图谱索引。图谱不覆盖规范，不改变计划，不替代实施记录。

## 2. 使用规则

```text
1. 先用本索引定位主题图谱。
2. 再读图谱列出的上级规范、当前计划和相关代码。
3. 图谱只帮助定位，不把图谱文字当作机器逻辑或权威规则。
4. 发现图谱与规范冲突时，先按规范执行，再修正图谱。
5. 发现图谱与代码现状不一致时，先核对计划和实施记录；只有确认代码已正式变化后再更新图谱。
6. 规则原子命中后必须回读来源规范；规则原子不是规范正文。
```
