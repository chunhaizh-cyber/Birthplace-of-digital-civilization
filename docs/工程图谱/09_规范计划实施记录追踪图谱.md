# 规范到计划 / 实施记录追踪图谱

## 0. 定位

权威等级：工程图谱。用于把规范、规则原子、计划、实施记录、代码和验证方式串起来。

详细追踪表见 `docs/规范治理/规范变更追踪表.md`。

## 1. 追踪链

```text
规范编号
-> 规则原子
-> 当前计划或待补计划
-> 实施记录 / 断点清单
-> 代码入口
-> 验证方式
-> 状态
```

## 3. 使用规则

```text
1. 新增规则原子后，补本图谱和规范变更追踪表。
2. 执行计划闭合后，补实施记录和验证方式。
3. 没有验证方式时，状态只能写“待补证据”或“人工审查”。
```
