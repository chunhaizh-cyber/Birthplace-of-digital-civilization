# 规范到测试映射

## 0. 定位

权威等级：工程图谱。用于登记规范验证方式，不新增旧式 `--*-check` 回归命令。

当前 `计划/计划索引.md` 明确禁止新增或依赖模拟测试、夹具测试、伪造样本、伪造入口、伪造动作动态或 `--*-check` 回归命令，因此本图谱只记录验证类型和待绑定真实证据。

## 2. 验证声明规则

```text
1. 构建通过只能说明编译链接通过。
2. 文档治理检查通过只能说明规范治理硬错误为 0。
3. 人工审查必须保留代码锚点或文档锚点。
4. 真实运行必须说明命令、样本、关键日志和退出码。
5. 任何验证不得提前宣称自我苏醒完成或初步成熟完成。
```
