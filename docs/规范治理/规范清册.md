## 2. 治理原则

```text
1. 清册先点名，不在同一切片搬迁规范文件。
2. 已进入规范目录的文件，目录编号先作为当前索引编号。
3. 缺文件头编号不等于规范失效，但应进入后续规范头补齐切片。
4. 标题偏详细设计、总结、说明的文件，必须补权威等级，避免被误当最高规则来源。
5. 规则原子只抽取高风险强制口径，不把全部规范正文机械拆碎。
6. 自动检查脚本第一版以告警为主，避免历史规范头不统一直接阻断开发。
```
