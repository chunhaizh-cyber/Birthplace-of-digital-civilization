## 2. 使用规则

```text
1. 规范发生实质修改后，先更新规则原子和本表。
2. 代码实现完成后，补对应计划、实施记录和代码入口。
3. 验证完成后，补真实命令、日志锚点或人工审查记录。
4. 不把本表当作计划索引；当前执行顺序仍以 计划/计划索引.md 为准。
```
