# 20260701 子规范修订迁移总账

## 0. 定位

本文件是 `规范/旧规范/` 到当前正式 `规范/` 目录的迁移控制总账，不是正式规范，不覆盖 `规范/规范目录.md`。

当前原则：

```text
1. 子规范需要修订后迁入当前规范目录。
2. 不强行压缩文件数量；只有重复、同义或可合并的内容才合并。
3. 旧规范不得原样迁回，必须按当前根规范、0050 总纲和冲突处理记录修订。
4. 详细设计、总结、说明、历史验收材料不伪装成规范，转入 docs/ 或详细设计/。
5. 迁回后的子规范必须进入 规范/规范目录.md，否则不算正式权威。
```

## 1. 迁移结果类型

| 结果 | 含义 |
| --- | --- |
| 修订迁回 | 保留独立子规范价值，按当前根规范改写后进入 `规范/` 和 `规范/规范目录.md` |
| 合并迁回 | 与其他旧规范重复或同义，合并成一个新子规范后迁回 |
| 转docs/详细设计 | 内容主要是实现说明、能力总结、详细设计或治理说明，不作为正式规范迁回 |
| 已吸收不迁回 | 关键口径已进入根规范、0050 总纲或冲突处理记录，旧文件只保留历史 |
