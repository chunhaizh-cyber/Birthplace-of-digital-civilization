本文件用于把 060 段散落规范的工作边界放到一个 docs 入口中，不替代正式规范。

## 1. 总口径

```text
因果账本由动作动态链表达；
因果信息服务解释、预测、反推、需求投影、执行审查、执行验收、稳定度更新和结算证据；
学习需求必须来自明确缺口；
探索和练习不得绕过需求、任务、方法和事实提交边界。
```
