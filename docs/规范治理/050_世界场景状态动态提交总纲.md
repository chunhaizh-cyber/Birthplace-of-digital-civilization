# 050 世界 / 场景 / 状态 / 动态提交总纲

## 0. 定位

权威等级：治理总纲。当前正式 050 一级入口仍以 `规范/规范目录.md` 中的 `050 自我所在场景认知工作区规范20260525.md` 为准。

本文件只把世界、场景、状态和动态提交的跨文件口径收拢到 docs，便于 Codex 定位。

## 1. 总口径

```text
世界树承载真实事实；
场景组织存在、关系、范围和局部事实；
状态表达当前值或阶段结果；
动态表达事实变化过程；
输出结果场景承载方法运行结果材料，不承载任务状态回执。
```
