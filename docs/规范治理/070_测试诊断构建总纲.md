# 070 测试 / 诊断 / 构建总纲

## 0. 定位

权威等级：治理总纲。当前正式 070 一级入口以 `规范/远程执行通道与断点续跑规范20260524.md`、`AGENTS.md` 和 `计划/计划索引.md` 为准。

本文件用于统一构建、真实运行、日志、诊断、验证和阶段声明边界。

## 1. 总口径

```text
构建通过只证明当前代码能通过指定配置编译；
日志和控制面板只提供证据材料，不自动证明阶段完成；
真实运行业务验证必须先写预测，再走真实路径，最后用日志、状态快照、动作动态和错误日志核对；
不得用 remote compact / stream disconnected / websocket / network error 作为项目实现失败证据。
```

## 2. 验证类型

| 验证类型 | 能证明 | 不能证明 | 证据形式 |
| --- | --- | --- | --- |
| Debug x64 构建 | 编译和链接通过 | 业务闭环完成、自我苏醒完成 | msbuild 退出码、关键错误 |
| 真实运行 | 指定路径在当前样本下运行 | 通用成熟或全部场景完成 | 运行命令、日志、状态快照 |
| 日志核对 | 某路径发生或未发生 | 没有日志就一定没有事实 | 关键日志行、错误日志 |
| 状态快照 | 当前结构状态 | 历史因果完整性 | 节点、状态、特征、账本快照 |
| 动作动态 / 因果证据 | 行为和归因材料 | 单独替代需求满足 | 动态链、因果类读取结果 |
| 人工审查 | 尚无自动化时的风险判断 | 自动回归覆盖 | 审查记录、代码锚点 |

## 3. 当前限制

`计划/计划索引.md` 当前明确禁止新增或依赖模拟测试、夹具测试、伪造样本、伪造入口、伪造动作动态或 `--*-check` 回归命令。因此本总纲不新增旧式 check 命令，只登记验证方式和待绑定真实命令。

## 4. 后续正式化缺口

```text
1. 将规范到测试映射里的“人工审查”逐步替换为真实运行命令或日志锚点。
2. 为文档治理脚本建立 CI 或手动执行入口。
3. 为阶段声明建立负面清单：哪些证据不能证明自我苏醒 / 初步成熟。
```
