# Codex 执行规范

## 0. 定位

权威等级：执行治理规则。`AGENTS.md` 是项目级执行入口，本文件用于把 Codex 执行规范展开成可复查清单。

## 1. 修改代码前

```text
1. 读取 AGENTS.md。
2. 读取 docs/00_文档总索引.md。
3. 读取 规范/禁止性规范20260611.md。
4. 读取 规范/规范目录.md。
5. 读取 计划/计划索引.md。
6. 查询 docs/工程图谱/05_规则原子索引.md。
7. 查询当前主题对应工程图谱。
8. 回读命中的来源规范。
9. 明确本轮涉及哪些 RULE 和哪些文件。
```

## 2. 修改代码时

```text
1. 只改当前闭合切片需要的文件。
2. 不混入用户已有未提交改动。
3. 不用计划、实施记录、流程图或显示摘要覆盖规范。
4. 涉及因果、世界树、语素、需求、任务、方法等领域操作时，优先调用对应类功能函数。
5. 缺少功能函数时，按“缺哪个类补哪个类第一优先”生成或修订对应逻辑纠偏计划。
```

## 3. 修改后

```text
1. 说明遵守了哪些 RULE。
2. 说明是否新增或修改规则原子。
3. 说明是否需要更新工程图谱、规范清册或追踪表。
4. 运行相关构建、真实运行或文档治理检查。
5. 文档小改未构建时，明确说明未运行 C++ 构建。
6. 每个闭合切片按 AGENTS.md Git 规则提交。
```

## 4. 禁止

```text
未读来源规范就按规则原子改核心代码。
把草案 / 待修订 / 历史参考当正式规范。
把构建通过说成业务闭环通过。
把日志或控制面板显示当机器判断事实。
为了通过验证吞掉弹窗、降级错误或屏蔽根因。
```
