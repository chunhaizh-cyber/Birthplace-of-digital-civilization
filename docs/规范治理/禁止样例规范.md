# 禁止样例规范

## 0. 定位

权威等级：禁止样例清单。它把高风险反例集中给 Codex 检索，不替代来源规范。

## 1. 禁止样例

| 编号 | 禁止样例 | 来源规则 |
| --- | --- | --- |
| BAD-001 | 任务完成后直接结算安全值或服务值 | RULE-TASK-005、RULE-SETTLE-001 |
| BAD-002 | 用安全值 / 服务值已经变化证明结算前证据成立 | RULE-SETTLE-002 |
| BAD-003 | 读取函数隐式创建根节点或业务结构 | RULE-FACT-001、RULE-STRUCT-001 |
| BAD-004 | 诊断快照或控制面板刷新补写业务状态 | RULE-STRUCT-002、RULE-FACT-001 |
| BAD-005 | 任务筹办 / 任务执行重新注册为本能方法 | RULE-TASK-001 |
| BAD-006 | 任务筹办自身进入方法候选集 | RULE-TASK-002 |
| BAD-007 | 外设像素簇直接当已确认存在 | RULE-FACT-003 |
| BAD-008 | 首次扫描直接写“发现存在” | RULE-FACT-004 |
| BAD-009 | 外设线程直接写需求树、世界树真值或价值结算 | RULE-FACT-002 |
| BAD-010 | 构建通过后宣称自我苏醒或初步成熟 | RULE-RUN-001 |
| BAD-011 | 线程状态进入自我治理邮箱并生成动作动态 | RULE-THREAD-004 |
| BAD-012 | `I64_MAX` 作为未知或默认满分进入真实结算 | RULE-SETTLE-004 |
| BAD-013 | 被动动作学习成可执行主动方法 | RULE-ACTION-004 |
| BAD-014 | 外部变化伪装成自我方法动作动态 | RULE-ACTION-002 |
| BAD-015 | 只返回错误码，让上层猜测缺口和失败原因 | RULE-ACTION-005 |

## 2. 使用规则

```text
1. 看到相似代码路径时，先回读对应 RULE 和来源规范。
2. 禁止样例只用于快速拦截，不替代代码和日志证据。
3. 若发现新反例，先补规则原子，再补本清单。
```
