# 事实来源与写入权限总规范

## 0. 定位

权威等级：治理总纲，待按 `规范/规范目录.md` 裁决是否拆入正式规范。

本文件用于统一事实来源、写入权限、只读读取和显式确保边界。它不覆盖 `规范/禁止性规范20260611.md`、`规范/自我线程与任务管理线程权责边界规范20260512.md` 或各领域正式规范。

## 1. 总原则

```text
事实必须能回答：
谁产生；
谁有权写；
谁只能读；
谁负责验证；
写入后由哪个项目结构承载。
```

## 2. 事实来源分层

| 事实类型 | 合法来源 | 写入方 | 只读方 | 验证方式 |
| --- | --- | --- | --- | --- |
| 现实外部事实 | 外设观察、传感器、外设线程报告 | 外设提交链、任务承接后的正式提交入口 | 自我线程、任务管理、控制面板 | 外设报告句柄、输出结果场景、场景/存在/特征事实 |
| 内部治理事实 | 需求、任务、方法、结算等生命周期结果 | 对应领域类或任务管理提交入口 | 控制面板、日志、诊断工具 | 任务状态、需求状态、方法状态、动作动态 |
| 诊断事实 | 日志、快照、控制面板只读投影 | 诊断模块或显示层 | 人和 Codex | 不作为机器判断；只辅助定位 |
| 初始化事实 | 显式初始化或显式确保入口 | 对应领域类 | 后续正式流程 | 初始化日志、节点存在性、结构闭合证据 |
| 安全 / 服务账务事实 | 任务完成后的价值反馈链 | 结算方法和对应提交入口 | 自我线程、控制面板、日志 | 实际结果状态、完成度、权重账本、因果证据 |

## 3. 只读与确保边界

```text
只读读取：
    不创建节点；
    不补默认值；
    不写状态；
    不触发派生需求；
    不改变动作动态或因果账本。

显式确保：
    函数名、调用点和日志必须体现“确保 / 初始化 / 创建”语义；
    必须说明写入方、写入结构和后续读取方；
    不得藏在 getter、诊断读取或显示层刷新里。
```

## 4. 禁止样例

```text
诊断读取隐式创建根节点。
控制面板刷新补写业务状态。
外设线程直接写需求树或安全 / 服务值。
自我线程直接写任务状态。
任务筹办直接生成需求节点。
日志摘要作为机器判断事实。
```
