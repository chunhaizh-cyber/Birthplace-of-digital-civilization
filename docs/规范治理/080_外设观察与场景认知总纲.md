# 080 外设观察与场景认知总纲

## 0. 定位

权威等级：治理总纲。当前外设观察相关正式规范分布在 040、050 段，本文件只做跨主题总入口。

## 1. 总口径

```text
外设线程负责看、动、报；
外设报告是材料，不是自我内部事实最终裁决；
像素簇是候选材料，不是已确认存在；
识别只返回已有存在指针或空指针；
扫描维护当前状态和可比变化；
跟踪返回新坐标或空信息；
观察失败或质量不足应成为结构化缺口，而不是显示层文本。
```
