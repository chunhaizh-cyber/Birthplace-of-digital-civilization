```text
观察
识别
跟踪
```

## 1. 总体定位

D455 / RGB-D 外设只负责稳定供料。外设侧 L0-L3 产出原始帧、深度与掩码稳定材料、跨帧关联材料和稳定观察子集；自我侧 L4 才负责观察、识别、跟踪、扫描。

当前阶段对自我内部治理真正主动需要的是扫描：

```text
安全 / 服务增加根需求
    -> 内部治理判断需要当前状态或任务结果验证
    -> 生成扫描需求
    -> 任务创建 / 任务筹办 / 方法选择
    -> 外设供料
    -> 扫描读取自我内部场景指针和外设当前数据集
    -> 扫描比较内部场景基准和外设当前数据集
    -> 扫描语义输出状态信息或空信息
    -> 比较缺口写入输出结果场景作为结构化需求来源
    -> 状态信息接回需求、任务、方法、学习虚拟存在特征变化链
```

观察、识别、跟踪不是扫描的直接子函数。四者只能通过下列链路间接衔接：

```text
方法结果 / 结构化缺口
    -> 需求生成
    -> 任务创建
    -> 任务筹办
    -> 方法选择
```

## 2. 共同硬规则

四个方法都必须形成本能方法内部闭环，至少写清：

```text
输入参数场景
输出结果场景
目标宿主
目标特征类型
当前状态 / 目标状态 / 实际结果状态
方法执行情况
失败原因、缺口类型或异常类型
动作动态或错误日志证据
后续承接入口
```

四个方法都不得只返回错误码、失败文本或原因摘要。过程证据只能写入运行存在或输出结果场景；不得把过程证据长期挂到世界树存在主特征集合中。

按 `本能函数实现规范20260430.md`，四个本能函数的 C++ 返回值均为本轮运行虚拟存在指针。本文中的“语义输出”不是函数裸返回值，而是写入输出结果场景、运行存在或后续提交链可消费的功能结果事实。

世界树中已确认存在的长期观察特征类型只允许保存：

```text
空间位置
空间尺寸
轮廓
彩图
深度图
轮廓极值
```

下列内容不得作为已确认存在的长期特征保存：

```text
外设内部候选编号
帧内编号
报告编号
任务编号
同一性评分
匹配评分
候选数量
硬冲突数量
质量诊断摘要
补观察建议
调试文本
```

这些数据可以作为本轮运行存在、输出结果场景、外设材料页或日志证据使用，用完即丢，或仅保留为可回查证据引用。

## 3. 方法关系

### 3.1 扫描驱动关系

扫描执行中遇到缺口时，不直接调用其它方法，也不直接决定“观察 / 识别 / 跟踪”。扫描只记录结构化需求来源；需求生成后进入任务创建、任务筹办和方法选择。

```text
对应关系缺口
    -> 目标宿主：当前材料 / 候选存在
    -> 目标特征：当前材料对应已有存在状态
    -> 目标状态：已确定

空间坐标缺口
    -> 目标宿主：目标存在
    -> 目标特征：当前空间坐标
    -> 目标状态：已取得

当前特征值缺口
    -> 目标宿主：目标存在 / 目标特征
    -> 目标特征：当前特征值可比较状态
    -> 目标状态：已取得 / 可比较

材料质量缺口
    -> 目标宿主：外设当前数据集
    -> 目标特征：材料质量
    -> 目标状态：可比较

状态变化
    -> 目标宿主：发生变化的存在或场景范围
    -> 目标特征：状态变化记录状态
    -> 目标状态：已记录并进入内部治理判断
```

### 3.2 结果回流关系

```text
观察完成
    -> 已确认存在的允许特征值集合得到补充
    -> 扫描可使用更完整的当前特征

识别返回存在指针
    -> 任务链可选择扫描该存在

识别返回空指针
    -> 任务链可生成观察补完、存在创建或其它后续需求

跟踪返回新空间坐标
    -> 任务链可让扫描或观察继续锁定同一存在

跟踪返回空信息
    -> 任务链记录跟丢，并按需求重新识别或补观察

扫描语义输出状态信息
    -> 接入内部治理被动因果链

扫描语义输出空信息
    -> 表示本轮没有可提交状态变化或当前材料不足
```

## 4. 观察方法规格

### 4.1 方法名

规格语义名：

```text
自我_观察存在特征
```

当前已有实现名：

```text
自我_观察单个空间候选并组合存在假设
```

当前已有实现名带有历史语义。按本规格理解时，它只能收束为“锁定同一个存在并补充允许特征值集合”，不得继续把“组合存在假设”当作观察方法的当前语义。

### 4.2 目标

观察的目标是：

```text
在锁定同一个已知存在的前提下，
补充该存在当前可观察到的特征值集合，
直到本轮可观察特征类型不再出现新特征值。
```

观察不是识别，不回答“有没有见过”。观察不是跟踪，不负责在空间位置变化后找回目标。观察不是扫描，不输出状态变化。

### 4.3 输入

输入参数场景必须提供：

```text
目标存在指针 / 目标存在引用
当前观察材料集 / 外设观察报告引用
观察范围 / ROI / 掩码 / AABB / 点集
当前空间位置
当前空间尺寸
当前轮廓
彩图材料引用
深度图材料引用
轮廓极值材料
材料质量状态
允许补充的特征类型集合
观察窗口 / TTL / generation
```

允许补充的特征类型集合只能包含：

```text
空间位置
空间尺寸
轮廓
彩图
深度图
轮廓极值
```

子轮廓可以作为自我内部细化线程从彩图和深度图中提取的过程材料；当前不得作为已确认存在根层长期特征类型直接追加。若需要长期表达，应进入内部世界子存在、轮廓细化结果或轮廓极值等合法承载面。

### 4.4 判定逻辑

观察先用空间位置锁定目标：

```text
空间位置一致
    -> 使用空间尺寸和轮廓确认仍是同一个存在

空间位置不一致
    -> 不继续观察
    -> 输出需跟踪缺口
```

确认同一存在后，逐项比较允许特征类型：

```text
已存在相同特征值
    -> 不重复写入

出现新的合法特征值
    -> 添加到目标存在的特征值集合

特征材料质量不足
    -> 输出补观察缺口

特征类型不在允许集合
    -> 不写入存在
```

### 4.5 输出

观察的输出结果场景必须包含：

```text
目标存在指针 / 目标存在引用
观察状态 = 进行中 / 已完成 / 需跟踪 / 需补观察 / 需识别 / 材料不足
本轮新增特征值数量
本轮新增特征类型集合
本轮未新增特征类型集合
材料质量状态
动作动态引用
后续承接入口
```

观察完成条件：

```text
当前观察材料中所有允许特征类型均已检查；
同一存在仍被锁定；
没有新的合法特征值可追加；
没有未解释质量缺口。
```

语义输出：

```text
观察状态信息
```

持久写入：

```text
仅允许向目标存在追加：
空间位置 / 空间尺寸 / 轮廓 / 彩图 / 深度图 / 轮廓极值
```

## 5. 识别方法规格

### 5.1 方法名

```text
自我_识别外设观察材料
```

当前本能方法 ID：

```text
6145
```

### 5.2 目标

识别只回答：

```text
当前获取到的存在材料有没有见过。
```

输出只有两类：

```text
已有存在指针
空指针
```

已有存在可以是具体存在，也可以是抽象存在。

### 5.3 输入

输入参数场景必须提供：

```text
当前存在材料 / 外设观察材料引用
当前观察范围
识别范围
自我所在场景指针
世界树根指针
轮廓
空间尺寸
子轮廓材料，若已有
彩图 / 深度图材料，若需要辅助
空间位置上下文
材料质量状态
匹配阈值 / 硬冲突阈值
```

识别不得以外设内部候选编号、帧内编号、报告编号、任务编号或固定 ID 作为“见过”的依据。

### 5.4 查找顺序

识别必须先查自我所在场景，再查世界树：

```text
当前材料
    -> 自我所在场景已有存在
    -> 世界树根部
    -> 由粗到细向下查找
```

候选召回推荐顺序：

```text
1. 轮廓
2. 空间尺寸 / AABB 尺寸
3. 子轮廓
4. 掩码重合
5. 深度摘要 / 颜色特征
6. 可观测物理标记，若存在
7. 空间位置上下文 / 局部三维模型
```

空间位置不是识别主准则，只能作为范围上下文、反证检查或后续跟踪入口。

### 5.5 判定逻辑

```text
候选数量 = 0
    -> 输出空指针

候选数量 = 1 且无硬冲突
    -> 输出已有存在指针

候选数量 > 1
    -> 继续使用轮廓、尺寸、子轮廓等更细特征收敛

唯一候选存在硬冲突
    -> 输出空指针
```

最低反证检查：

```text
轮廓是否严重失配
空间尺寸是否严重失配
子轮廓是否严重失配
掩码重合率是否低于硬阈值
关键类别特征是否互斥
一个材料是否强匹配多个存在
一个存在是否被多个互斥材料强匹配
```

### 5.6 输出

语义输出：

```text
存在指针 | 空指针
```

输出结果场景可记录过程证据：

```text
候选数量
唯一性状态
硬冲突状态
证据不足原因
补观察建议
动作动态引用
```

这些过程证据不是识别语义输出，不得写入目标存在的一阶特征集合。

识别不得：

```text
创建新存在
补写空间位置
补写空间尺寸
补写轮廓
补写彩图
补写深度图
输出当前状态
输出状态变化
```

## 6. 跟踪方法规格

### 6.1 方法名

```text
自我_跟踪指定存在
```

当前本能方法 ID：

```text
6147
```

### 6.2 目标

跟踪只回答：

```text
同一个存在现在在哪里。
```

输出只有两类：

```text
新空间坐标
空信息
```

空信息表示跟丢或当前材料不足以唯一找回。

### 6.3 输入

输入参数场景必须提供：

```text
目标存在指针 / 目标存在引用
上一空间位置
当前观察材料集 / 外设跟踪报告引用
当前场景指针
空间尺寸
轮廓
轮廓极值
ROI / 掩码 / 点集
搜索范围 / TTL / generation
材料质量状态
唯一凭证阈值
```

外设内部跟踪 ID、候选编号、帧内编号只能用于回查材料，不得作为自我世界存在对应关键。

### 6.4 判定逻辑

```text
空间位置一致
    -> 使用空间尺寸和轮廓确认仍是同一个存在
    -> 输出当前空间坐标

空间位置不一致
    -> 在当前场景中用空间尺寸、轮廓、轮廓极值等唯一凭证查找
    -> 找到唯一匹配则输出新空间坐标
    -> 找不到或多重冲突则输出空信息
```

跟踪不得把找到的材料直接写成新存在，也不得补写长期特征集合。跟踪只产坐标或空信息；坐标入树或后续观察/扫描由提交入口和任务链承接。

### 6.5 输出

语义输出：

```text
新空间坐标 | 空信息
```

输出结果场景可记录：

```text
目标存在指针 / 目标存在引用
上一空间位置
新空间坐标或空信息
跟踪状态 = 已定位 / 跟丢 / 多重冲突 / 材料不足
唯一凭证特征类型集合
冲突 / 证据不足原因
动作动态引用
后续承接入口
```

## 7. 扫描方法规格

### 7.1 方法名

```text
自我_扫描已识别区域
```

当前本能方法 ID：

```text
6146
```

### 7.2 目标

扫描是当前场景事实可用性维护主方法。它负责：

```text
读取已确认存在
生成本轮扫描关注集合
读取已合法进入系统的外设当前数据集
用已合法外设数据项更新该存在的当前状态值
比较当前特征值与基准
语义输出状态信息、信息缺口或空信息
```

扫描不是识别，不确认新存在。扫描不是观察，不从原始外设材料生产新的观察特征值，也不向长期特征值集合追加新特征类型。扫描不是跟踪，不负责在目标消失后找回空间位置。

### 7.3 输入

输入参数场景必须提供：

```text
自我内部场景指针
自我内部场景基准 / 上一轮扫描基准，若存在
外设当前获取的数据集 / 外设扫描报告引用
内部场景中的已确认存在指针 / 已确认存在集合
外设当前候选材料 / 当前特征值材料
存在对应关系 / 对应状态
当前观察材料范围 / 数据集范围
当前扫描范围 / ROI / 外设视野
来源需求 / 来源任务的目标范围
当前状态基准，若存在
目标特征类型集合
比较规则：空间位置、空间尺寸、轮廓、当前特征值、材料质量
材料质量状态
处理频率规则 / 扫描优先级规则
状态变化阈值
TTL / generation
```

可扫描的特征类型应优先限定为：

```text
空间位置
空间尺寸
轮廓
彩图
深度图
轮廓极值
```

### 7.4 判定逻辑

```text
内部场景指针不可读或外设当前数据集不可读
    -> 记录输入缺口或材料质量缺口需求来源
    -> 语义输出空信息
```

扫描正式核对外设数据前，必须先生成本轮扫描关注集合：

```text
当前场景存在集合
    -> 按当前扫描范围 / ROI / 外设视野筛选
    -> 按空间位置或预测投影判断是否应被当前外设覆盖
    -> 按低频维护规则排除本轮不维护的静止 / 环境存在
    -> 按跟踪接管状态排除已被目标跟踪任务接管的存在
    -> 按扫描优先级筛出本轮需要维护的存在
```

筛选结果只写入扫描方法运行虚拟存在，不直接写入存在长期状态：

```text
本轮应覆盖存在集合
本轮可忽略存在集合
本轮需补条件存在集合
```

其中：

```text
本轮应覆盖存在集合：
    本轮理论上应被当前外设覆盖或维护。

本轮可忽略存在集合：
    范围外 / 视野外 / 低频跳过 / 跟踪排除 / 优先级不足。
    不参与消失、遮蔽或异常未覆盖判断。

本轮需补条件存在集合：
    缺空间位置 / 缺基准 / 缺值域 / 预测位置不可靠 / 材料不可回查。
    记录信息缺口，不进入普通扫描比较。
```

外设数据项处理完成后，未覆盖解释的输入必须是：

```text
本轮异常未覆盖存在集合
    = 本轮应覆盖存在集合 - 本轮外设覆盖存在集合
```

不得使用：

```text
当前场景所有存在 - 本轮外设覆盖存在集合
```

作为未覆盖解释输入。

```text

没有已确认存在或对应关系未确定
    -> 记录对应关系缺口需求来源
    -> 语义输出空信息

空间位置不一致，且不能用空间尺寸、轮廓等唯一凭证重新对应
    -> 记录坐标缺口需求来源
    -> 语义输出空信息

存在对应已确定，但缺当前可比较特征值
    -> 记录当前特征值缺口需求来源
    -> 语义输出空信息

材料质量不足以比较
    -> 记录材料质量缺口需求来源
    -> 语义输出空信息

首次扫描 / 无可比历史
    -> 用已合法外设数据项更新当前状态值
    -> 建立当前状态基准
    -> 语义输出状态信息或空信息
    -> 不生成发现语义
    -> 不生成变化动态

后续扫描 / 有可比历史
    -> 比较内部场景基准与外设当前数据集中的当前特征值
    -> 无变化则语义输出空信息
    -> 有变化则语义输出状态信息
    -> 将状态变化记录为内部治理可接入的事实
```

扫描发现未知区域时，只能输出：

```text
未稳定对应特征
对应关系缺口需求来源
```

不得由扫描直接创建新存在。

### 7.5 输出

语义输出：

```text
状态信息 | 信息缺口 | 空信息
```

输出结果场景可记录：

```text
目标存在指针 / 目标存在引用

```

扫描可更新：

```text
已确认存在的当前状态值 / 当前特征值
当前状态基准
下一轮扫描基准引用
```

扫描不得：

```text
把首次扫描写成发现存在
把首次扫描写成发现特征
把无可比历史写成变化动态
把未知区域直接确认为新存在
把过程评分写入存在长期特征集合
```

扫描写入当前状态值必须满足：

```text
当前值来自已合法外设数据项；
当前值属于空间位置 / 空间尺寸 / 轮廓 / 彩图 / 深度图 / 轮廓极值等允许特征类型；
若材料只是原始外设材料或尚未合法观察成特征值，扫描不得写入该存在，只能记录信息完备性缺口。
```

### 7.6 方法运行虚拟存在

本轮扫描上下文的权威语义承载面是：

```text
扫描方法运行虚拟存在
```

它是一次方法运行的临时虚拟存在，不是现实场景存在，也不是新的权威上下文树。代码执行层可以使用局部 C++ 结构或缓存加速访问，但该结构只是运行存在特征的视图。

扫描方法运行虚拟存在至少承载：

```text
运行ID / 来源需求ID / 来源任务ID / 当前场景引用 / 运行状态
```

### 7.7 可编程判断闸门

下列判断不得用自然语言裸判断，必须落成函数、枚举状态、量化指标和证据引用：

```text
判断空间位置一致
判断空间尺寸和轮廓一致
判断唯一找回
判断当前特征值是否发生可记录变化
判断预测空间坐标是否在当前视野外
判断遮蔽 / 覆盖证据是否成立
判断子层特征证据是否足够
判断消失条件是否成立
判断本轮扫描关注集合归属
```

每个判断至少输出：

```text
判断状态
量化指标
证据引用
缺口原因
```

## 9. 实现落地注意

1. 当前代码中 `自我_识别外设观察材料`、`自我_扫描已识别区域`、`自我_跟踪指定存在` 已有本能 ID 和执行入口；规格修订后，旧实现中“首次发现提交入口”等命名需要后续按当前状态基准口径复核。
2. 当前代码中观察方法仍使用历史名 `自我_观察单个空间候选并组合存在假设`；后续若保留该 ID，必须收束语义，不得继续把“存在假设”作为观察的正式输出。
3. 任何旧日志、旧断点或旧计划中出现“扫描发现存在 / 首次发现事实”时，应解释为历史证据，不得作为当前新规格的验收标准。
4. 本说明书只定义方法规格，不宣称 D455 自然业务样本完整通过，也不宣称识别 / 扫描 / 跟踪边界已经全部动态闭合。
