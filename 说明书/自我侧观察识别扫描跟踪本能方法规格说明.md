# 自我侧观察识别扫描跟踪本能方法规格说明

状态：2026-06-15 规格说明稿。

本文说明自我侧四个感知相关本能方法的规格口径：

```text
观察
识别
跟踪
扫描
```

## 1. 总体定位

D455 / RGB-D 外设只负责稳定供料。外设侧 L0-L3 产出原始帧、深度与掩码稳定材料、跨帧关联材料和稳定观察子集；自我侧 L4 才负责观察、识别、跟踪、扫描。

当前阶段对自我内部治理真正主动需要的是扫描：

```text
安全 / 服务增加根需求
    -> 内部治理判断需要当前状态或任务结果验证
    -> 生成扫描需求
    -> 外设供料
    -> 扫描产出状态信息或空信息
    -> 状态信息接回需求、任务、方法、学习虚拟存在特征变化链
```

观察、识别、跟踪不是扫描的直接子函数。四者只能通过下列链路间接衔接：

```text
方法结果 / 结构化缺口
    -> 需求生成
    -> 任务创建
    -> 任务筹办
    -> 方法选择
```

## 2. 共同硬规则

四个方法都必须形成本能方法内部闭环，至少写清：

```text
输入参数场景
输出结果场景
目标宿主
目标特征类型
当前状态 / 目标状态 / 实际结果状态
方法执行情况
失败原因、缺口类型或异常类型
动作动态或错误日志证据
后续承接入口
```

四个方法都不得只返回错误码、失败文本或原因摘要。过程证据只能写入运行存在或输出结果场景；不得把过程证据长期挂到世界树存在主特征集合中。

世界树中已确认存在的长期观察特征类型只允许保存：

```text
空间位置
空间尺寸
轮廓
彩图
深度图
轮廓极值
```

下列内容不得作为已确认存在的长期特征保存：

```text
外设内部候选编号
帧内编号
报告编号
任务编号
同一性评分
匹配评分
候选数量
硬冲突数量
质量诊断摘要
补观察建议
调试文本
```

这些数据可以作为本轮运行存在、输出结果场景、外设材料页或日志证据使用，用完即丢，或仅保留为可回查证据引用。

## 3. 方法关系

### 3.1 扫描驱动关系

扫描执行中遇到缺口时，不直接调用其它方法：

```text
扫描缺少可用特征
    -> 输出观察缺口
    -> 生成观察需求

扫描遇到未知材料
    -> 输出识别缺口
    -> 生成识别需求

扫描找不到已确认存在当前位置
    -> 输出跟踪缺口
    -> 生成跟踪需求
```

### 3.2 结果回流关系

```text
观察完成
    -> 已确认存在的允许特征值集合得到补充
    -> 扫描可使用更完整的当前特征

识别返回存在指针
    -> 任务链可选择扫描该存在

识别返回空指针
    -> 任务链可生成观察补完、存在创建或其它后续需求

跟踪返回新空间坐标
    -> 任务链可让扫描或观察继续锁定同一存在

跟踪返回空信息
    -> 任务链记录跟丢，并按需求重新识别或补观察

扫描返回状态信息
    -> 接入内部治理被动因果链

扫描返回空信息
    -> 表示本轮没有可提交状态变化或当前材料不足
```

## 4. 观察方法规格

### 4.1 方法名

规格语义名：

```text
自我_观察存在特征
```

当前已有实现名：

```text
自我_观察单个空间候选并组合存在假设
```

当前已有实现名带有历史语义。按本规格理解时，它只能收束为“锁定同一个存在并补充允许特征值集合”，不得继续把“组合存在假设”当作观察方法的当前语义。

### 4.2 目标

观察的目标是：

```text
在锁定同一个已知存在的前提下，
补充该存在当前可观察到的特征值集合，
直到本轮可观察特征类型不再出现新特征值。
```

观察不是识别，不回答“有没有见过”。观察不是跟踪，不负责在空间位置变化后找回目标。观察不是扫描，不输出状态变化。

### 4.3 输入

输入参数场景必须提供：

```text
目标存在指针 / 目标存在引用
当前观察材料集 / 外设观察报告引用
观察范围 / ROI / 掩码 / AABB / 点集
当前空间位置
当前空间尺寸
当前轮廓
彩图材料引用
深度图材料引用
轮廓极值材料
材料质量状态
允许补充的特征类型集合
观察窗口 / TTL / generation
```

允许补充的特征类型集合只能包含：

```text
空间位置
空间尺寸
轮廓
彩图
深度图
轮廓极值
```

子轮廓可以作为自我内部细化线程从彩图和深度图中提取的过程材料；当前不得作为已确认存在根层长期特征类型直接追加。若需要长期表达，应进入内部世界子存在、轮廓细化结果或轮廓极值等合法承载面。

### 4.4 判定逻辑

观察先用空间位置锁定目标：

```text
空间位置一致
    -> 使用空间尺寸和轮廓确认仍是同一个存在

空间位置不一致
    -> 不继续观察
    -> 输出需跟踪缺口
```

确认同一存在后，逐项比较允许特征类型：

```text
已存在相同特征值
    -> 不重复写入

出现新的合法特征值
    -> 添加到目标存在的特征值集合

特征材料质量不足
    -> 输出补观察缺口

特征类型不在允许集合
    -> 不写入存在
```

### 4.5 输出

观察的输出结果场景必须包含：

```text
目标存在指针 / 目标存在引用
观察状态 = 进行中 / 已完成 / 需跟踪 / 需补观察 / 需识别 / 材料不足
本轮新增特征值数量
本轮新增特征类型集合
本轮未新增特征类型集合
材料质量状态
动作动态引用
后续承接入口
```

观察完成条件：

```text
当前观察材料中所有允许特征类型均已检查；
同一存在仍被锁定；
没有新的合法特征值可追加；
没有未解释质量缺口。
```

语义输出：

```text
观察状态信息
```

持久写入：

```text
仅允许向目标存在追加：
空间位置 / 空间尺寸 / 轮廓 / 彩图 / 深度图 / 轮廓极值
```

## 5. 识别方法规格

### 5.1 方法名

```text
自我_识别外设观察材料
```

当前本能方法 ID：

```text
6145
```

### 5.2 目标

识别只回答：

```text
当前获取到的存在材料有没有见过。
```

输出只有两类：

```text
已有存在指针
空指针
```

已有存在可以是具体存在，也可以是抽象存在。

### 5.3 输入

输入参数场景必须提供：

```text
当前存在材料 / 外设观察材料引用
当前观察范围
识别范围
自我所在场景指针
世界树根指针
轮廓
空间尺寸
子轮廓材料，若已有
彩图 / 深度图材料，若需要辅助
空间位置上下文
材料质量状态
匹配阈值 / 硬冲突阈值
```

识别不得以外设内部候选编号、帧内编号、报告编号、任务编号或固定 ID 作为“见过”的依据。

### 5.4 查找顺序

识别必须先查自我所在场景，再查世界树：

```text
当前材料
    -> 自我所在场景已有存在
    -> 世界树根部
    -> 由粗到细向下查找
```

候选召回推荐顺序：

```text
1. 轮廓
2. 空间尺寸 / AABB 尺寸
3. 子轮廓
4. 掩码重合
5. 深度摘要 / 颜色特征
6. 可观测物理标记，若存在
7. 空间位置上下文 / 局部三维模型
```

空间位置不是识别主准则，只能作为范围上下文、反证检查或后续跟踪入口。

### 5.5 判定逻辑

```text
候选数量 = 0
    -> 输出空指针

候选数量 = 1 且无硬冲突
    -> 输出已有存在指针

候选数量 > 1
    -> 继续使用轮廓、尺寸、子轮廓等更细特征收敛

唯一候选存在硬冲突
    -> 输出空指针
```

最低反证检查：

```text
轮廓是否严重失配
空间尺寸是否严重失配
子轮廓是否严重失配
掩码重合率是否低于硬阈值
关键类别特征是否互斥
一个材料是否强匹配多个存在
一个存在是否被多个互斥材料强匹配
```

### 5.6 输出

语义输出：

```text
存在指针 | 空指针
```

输出结果场景可记录过程证据：

```text
候选数量
唯一性状态
硬冲突状态
证据不足原因
补观察建议
动作动态引用
```

这些过程证据不是识别语义输出，不得写入目标存在的一阶特征集合。

识别不得：

```text
创建新存在
补写空间位置
补写空间尺寸
补写轮廓
补写彩图
补写深度图
输出当前状态
输出状态变化
```

## 6. 跟踪方法规格

### 6.1 方法名

```text
自我_跟踪指定存在
```

当前本能方法 ID：

```text
6147
```

### 6.2 目标

跟踪只回答：

```text
同一个存在现在在哪里。
```

输出只有两类：

```text
新空间坐标
空信息
```

空信息表示跟丢或当前材料不足以唯一找回。

### 6.3 输入

输入参数场景必须提供：

```text
目标存在指针 / 目标存在引用
上一空间位置
当前观察材料集 / 外设跟踪报告引用
当前场景指针
空间尺寸
轮廓
轮廓极值
ROI / 掩码 / 点集
搜索范围 / TTL / generation
材料质量状态
唯一凭证阈值
```

外设内部跟踪 ID、候选编号、帧内编号只能用于回查材料，不得作为自我世界存在对应关键。

### 6.4 判定逻辑

```text
空间位置一致
    -> 使用空间尺寸和轮廓确认仍是同一个存在
    -> 输出当前空间坐标

空间位置不一致
    -> 在当前场景中用空间尺寸、轮廓、轮廓极值等唯一凭证查找
    -> 找到唯一匹配则输出新空间坐标
    -> 找不到或多重冲突则输出空信息
```

跟踪不得把找到的材料直接写成新存在，也不得补写长期特征集合。跟踪只产坐标或空信息；坐标入树或后续观察/扫描由提交入口和任务链承接。

### 6.5 输出

语义输出：

```text
新空间坐标 | 空信息
```

输出结果场景可记录：

```text
目标存在指针 / 目标存在引用
上一空间位置
新空间坐标或空信息
跟踪状态 = 已定位 / 跟丢 / 多重冲突 / 材料不足
唯一凭证特征类型集合
冲突 / 证据不足原因
动作动态引用
后续承接入口
```

## 7. 扫描方法规格

### 7.1 方法名

```text
自我_扫描已识别区域
```

当前本能方法 ID：

```text
6146
```

### 7.2 目标

扫描是当前阶段外界状态生产主方法。它负责：

```text
读取已确认存在
读取当前观察材料
更新该存在的当前特征值
比较当前特征值与基准
输出状态信息或空信息
```

扫描不是识别，不确认新存在。扫描不是观察，不向长期特征值集合追加新特征类型。扫描不是跟踪，不负责在目标消失后找回空间位置。

### 7.3 输入

输入参数场景必须提供：

```text
已确认存在指针 / 已确认存在集合
当前观察材料集 / 外设扫描报告引用
扫描范围
当前特征值材料
上一轮扫描基准，若存在
当前状态基准，若存在
目标特征类型集合
材料质量状态
状态变化阈值
TTL / generation
```

可扫描的特征类型应优先限定为：

```text
空间位置
空间尺寸
轮廓
彩图
深度图
轮廓极值
```

### 7.4 判定逻辑

```text
没有已确认存在
    -> 输出空信息或识别缺口

存在已确认但缺当前材料
    -> 输出观察缺口

存在空间位置无法锁定
    -> 输出跟踪缺口

首次扫描 / 无可比历史
    -> 更新当前特征值
    -> 建立当前状态基准
    -> 输出状态信息或空信息
    -> 不生成发现语义
    -> 不生成变化动态

后续扫描 / 有可比历史
    -> 比较当前特征值与基准
    -> 无变化则输出空信息
    -> 有变化则输出状态信息
```

扫描发现未知区域时，只能输出：

```text
未稳定对应特征
需重识别区域
```

不得由扫描直接创建新存在。

### 7.5 输出

语义输出：

```text
状态信息 | 空信息
```

输出结果场景可记录：

```text
目标存在指针 / 目标存在引用
扫描范围
当前特征值
当前状态基准
状态信息或空信息
特征值变化事实候选
材料质量状态
需观察 / 需识别 / 需跟踪缺口
动作动态引用
后续承接入口
```

扫描可更新：

```text
已确认存在的当前特征值
当前状态基准
下一轮扫描基准引用
```

扫描不得：

```text
把首次扫描写成发现存在
把首次扫描写成发现特征
把无可比历史写成变化动态
把未知区域直接确认为新存在
把过程评分写入存在长期特征集合
```

## 8. 四方法输入输出总表

| 方法 | 输入核心 | 语义输出 | 可持久写入 | 不得做 |
| --- | --- | --- | --- | --- |
| 观察 | 目标存在、当前观察材料、空间位置、尺寸、轮廓、彩图、深度图、轮廓极值 | 观察状态信息 | 仅允许的六类长期特征值 | 不识别、不跟踪、不输出状态变化 |
| 识别 | 当前存在材料、识别范围、当前场景、世界树、轮廓、尺寸、子轮廓 | 已有存在指针或空指针 | 无 | 不创建存在、不补写一阶特征、不输出状态 |
| 跟踪 | 目标存在、上一空间位置、当前材料、尺寸、轮廓、唯一凭证 | 新空间坐标或空信息 | 无，坐标入树由提交链承接 | 不创建存在、不补特征、不做全场扫描 |
| 扫描 | 已确认存在、当前材料、当前特征、基准、目标特征类型 | 状态信息或空信息 | 当前特征值、当前状态基准、下一轮扫描基准引用 | 不发现存在、不追加长期特征、不直接调用其它方法 |

## 9. 实现落地注意

1. 当前代码中 `自我_识别外设观察材料`、`自我_扫描已识别区域`、`自我_跟踪指定存在` 已有本能 ID 和执行入口；规格修订后，旧实现中“首次发现提交入口”等命名需要后续按当前状态基准口径复核。
2. 当前代码中观察方法仍使用历史名 `自我_观察单个空间候选并组合存在假设`；后续若保留该 ID，必须收束语义，不得继续把“存在假设”作为观察的正式输出。
3. 任何旧日志、旧断点或旧计划中出现“扫描发现存在 / 首次发现事实”时，应解释为历史证据，不得作为当前新规格的验收标准。
4. 本说明书只定义方法规格，不宣称 D455 自然业务样本完整通过，也不宣称识别 / 扫描 / 跟踪边界已经全部动态闭合。
