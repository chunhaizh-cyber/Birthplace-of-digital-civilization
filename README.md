# 鱼巢工程原型仓库

> **边界声明**
>
> 鱼巢是《人工智能之数字生命》一书使用的研究性 C++ 工程原型，用于展示存在、特征、场景、需求、任务、方法、动作动态、记忆与边界等结构如何进入工程材料。
>
> 它不是数字生命已经诞生的证明。
> 它不是通用 AI 产品。
> 它不是生产环境机器人控制系统。
> 它不是完整自我意识、现象意识或人工生命已经实现的证明。

## 这是什么

鱼巢是一个以“世界树 + 自我线程 + 需求 / 任务 / 方法 + 状态 / 动态 / 因果 + 自然语言显示”为核心的 C++ 实验工程。当前仓库适合作为：

- 鱼巢工程原型仓库
- 随书工程材料仓库
- 研究性 C++ 原型仓库

仓库代码提供工程材料、结构骨架和持续开发中的运行链路，不提供“数字生命已完成”的结论。

这与书稿中的定位一致：鱼巢是贯穿案例和工程样本，不是理论主角；它帮助把抽象概念放回可观察、可拆解、可验证的工程结构中。

## 不是什么

请不要把本仓库解读为：

- 数字生命已实现仓库
- 鱼巢正式产品仓库
- 数字文明诞生地证明仓库
- 可直接用于真实机器人或生产系统的控制软件

生命判据必须先由通用定义给出，再映射到鱼巢的工程证据。工程证据不能越界推断为最终生命结论。

## 固定书稿版本

建议书稿、引用和外部评审优先指向固定版本，而不是跟随 `main` 分支漂移：

```text
推荐版本：v0.1-book-rc2
对应书稿：《人工智能之数字生命：从会回答的机器到会生存的系统》2026-05-28 发布候选稿
```

`main` 分支仍是开发现场，可能持续移动、重排和修订。

## 构建

推荐环境：

- Windows 10/11
- Visual Studio 2022 或兼容 MSBuild 环境
- C++20
- x64

构建命令：

```powershell
msbuild .\鱼巢.vcxproj /p:Configuration=Debug /p:Platform=x64 /p:LinkIncremental=false /m
```

## 当前边界

当前工程仍是可运行原型与工程现场。它可以用于阅读结构、检查模块边界、跟踪运行链路和复现实验性工程材料；它不应被作为阶段完成、生命出现、自我苏醒完成或初步成熟完成的单独证据。
