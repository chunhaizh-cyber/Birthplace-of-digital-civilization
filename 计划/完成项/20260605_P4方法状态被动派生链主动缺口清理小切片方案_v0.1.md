# P4 方法状态被动派生链主动缺口清理小切片方案 v0.1

## 目标

把学习本能中的 `方法状态` 主动派生缺口收敛为量化底账缺口，并给方法状态提交动态补被动证据日志。

本切片只处理可闭合范围：

```text
自我_练习：
    缺条件节点 -> 方法条件节点数量 当前值 -> 1
    缺条件结果对 -> 方法条件结果对数量 当前值 -> 1
    好用目标未达 -> 方法最近连续成功次数 当前值 -> 4

自我_提交方法状态变化：
    仍只作为方法域提交 / 审计入口；
    方法状态动态必须保持 被动动作 语义；
    增加日志锚点，便于 P5 真实日志验证。
```

## 实施切点

1. 在自我动作模块补 `方法条件节点数量` 特征入口，用现有 `方法真实条件节点数量()` 作为读数。
2. 将 `自我_练习` 中两处 `写入目标方法状态派生需求` 改为量化底账派生：

```text
缺真实条件节点：
    方法条件节点数量 当前值 -> 1

缺真实条件结果对：
    方法条件结果对数量 当前值 -> 1
```

3. 删除 `好用目标未达-方法状态未达` 的主动派生需求，只保留已存在的 `方法最近连续成功次数 当前值 -> 4`。
4. 在方法域 I64 提交动作中，针对 `方法状态` 提交增加日志锚点：

```text
方法域提交/方法状态被动派生动态
    特征=方法状态
    动作语义=被动动作
    动态=...
```

## 暂不处理

```text
结果符合次数 / 结果不符合次数 的“同一条件”宿主：
    当前仍是方法虚拟存在整体计数；P5 前需要单独小切片或真实日志验证决定是否迁移到条件节点宿主。

新结果分支数量：
    当前没有独立特征入口和读写桥，本切片不临时虚构。

方法状态被动因果模板：
    本切片只清理主动缺口和补动态锚点；模板落账需要确认遗传模板加载边界后另切。
```
