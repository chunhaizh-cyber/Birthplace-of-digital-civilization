## 执行切片

### P1 自我初始场景坐标锚点

目标：

```text
在 世界树类::取或创建自我存在 中，若自我存在尚无 存在_场景绝对坐标，
用 自我初始场景 的原点作为自我存在初始场景绝对坐标锚点。
```

边界：

```text
只写自我存在自身的 存在_场景绝对坐标。
不批量改写其他存在。
不写安全值、风险值或当前场景特征值明确状态。
不把 D455 像素簇、ROI 或普通场景坐标替代为自我边界。
姿态仍不硬写，保持待真实来源。
```

验收：

```text
世界树.取或创建自我存在 后，世界树.读取存在场景绝对坐标(世界树.自我指针) 可读。
自我边界方法可由该坐标同步 自我_场景绝对坐标明确状态。
Debug x64 构建通过。
```

### P2 真实 D455 可用性验证

目标：

```text
在相机外设正常工作的条件下，先用保留的真实相机命令验证硬件可用和单帧采集；
后续正式业务链只走自我线程、任务管理等待项、外设观察报告、提交入口和日志证据。
```

预测：

```text
.\x64\Debug\鱼巢.exe --d455-capture-once
应出现命令行相机控制日志；
应包含 D455 打开、采集一帧、释放结果；
退出码应为 0。
```

禁止：

```text
不恢复 --peripheral-autonomous-observe 等已删除硬串业务链入口。
不把单帧采集等同于观察事实承接完成。
不宣称当前场景存在集合明确、风险明确或安全值增加。
```
