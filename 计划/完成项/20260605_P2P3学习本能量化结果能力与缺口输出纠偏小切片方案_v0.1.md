# P2/P3 学习本能量化结果能力与缺口输出纠偏小切片方案 v0.1

## 目标

把三个学习相关本能方法的可达结果和失败缺口改成可被任务筹办统一查找的量化目标。

```text
自我_定向学习：
    承接 方法动作数量 >= 1 / 方法可执行入口数量 >= 1；
    成功必须以真实数量读数闭合，候选动作不能冒充真实动作。

自我_尝试学习：
    声明并输出 方法条件结果对数量 >= 1。

自我_练习：
    声明并输出 方法最近连续成功次数 >= 4。
```

旧的 `方法动作状态`、`方法条件结果配对状态`、`方法状态` 输出只作为兼容证据保留，不作为新增学习缺口的主要目标。

## 实施切点

1. 在自我动作模块补齐 `方法动作数量`、`方法条件结果对数量` 特征入口和本能侧数量读取桥。
2. 在 `确认定向学习规格` 中加入 `方法动作数量`、`方法可执行入口数量` 结果表和可尝试承接能力。
3. 在 `确认尝试学习规格` 中加入 `方法条件结果对数量` 结果表和结果能力。
4. 在 `确认练习规格` 中加入 `方法最近连续成功次数` 结果表和结果能力。
5. 修改 `自我_定向学习` 和 `自我_尝试学习` 失败派生需求，优先输出数量特征；保留旧状态字段作为兼容运行证据。
6. `自我_练习` 已能写出连续成功次数缺口，本切片补结果能力声明和结果表，不在这里新增同条件命中宿主或新结果分支宿主。

## 暂不处理

```text
结果符合次数 / 结果不符合次数：
    现有写入发生在方法运行账更新路径，尚未形成“同一条件命中超过 3 次且无新结果对”的任务目标宿主。

新结果分支数量：
    当前缺少明确特征入口、宿主和写入桥。

方法状态被动派生：
    放入 P4，按方法状态由量化特征被动派生，不在学习本能中主动反推。
```
