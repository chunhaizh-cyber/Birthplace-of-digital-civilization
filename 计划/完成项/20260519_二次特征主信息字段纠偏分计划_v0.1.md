# 二次特征主信息字段纠偏分计划 v0.1

更新时间：2026-05-19

对应主信息：`二次特征主信息类`

## 审查结论

二次特征是关系、差值、判断的特征化结果。当前字段较多，但大多数可保留；需要重点收口解释性缓存和粒度字段。

## 字段分级

```text
关系本体：
    主体 / 客体 / 左对象 / 右对象
    标量值
    比较左值 / 比较右值
    允许方向
    差值
    方向区间
    标量区间

结构 / 索引：
    形态
    种类
    域
    粒度
    基准类型
    时间归一方式
    值形态
    度量签名_链键
    概念名称
    概念模板
    所属场景
    规则版本

待降权：
    是否满足
    区间层级
    离散语义键
```

## 纠偏动作

```text
P1. 标注 是否满足 为 标量值 / 标量区间 / 允许方向 命中缓存。
P2. 区间层级 后续用父子刻度链替代；当前不再新增依赖。
P3. 离散语义键 只作索引 / 显示 / 外部映射，不作底层判断。
P4. 二次特征匹配统一走比较量、值域、允许方向和方向区间。
```
