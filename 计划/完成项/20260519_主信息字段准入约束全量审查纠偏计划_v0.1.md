## 0. 总口径

本计划只处理“主信息类字段是否符合底层逻辑”的结构纠偏，不直接扩大内部循环功能。

准入判断顺序固定为：

```text
1. 它是不是对象、状态、任务、需求、方法或世界的可比较属性？
   是：优先建模为特征。

2. 它是不是两个对象、两个特征、当前值与目标值、初始值与结果值之间的关系？
   是：优先建模为二次特征。

3. 它是不是动作造成变化的来源？
   是：必须绑定方法动作或外部观察动态。

4. 它是不是变化、满足、结算、学习、方法状态之间的来源链？
   是：优先进入因果追踪 / 动作动态引用链。

5. 它是否只是缓存、索引、去重、审计、显示或迁移兼容？
   是：可以保留为普通字段，但必须标注非权威，不得作为业务事实来源。
```

凡是可以由特征、二次特征、方法动作、因果追踪推导的内容，不新增平行字段，不保留为权威字段。

### P6. 二次特征 / 因果缓存字段标注与替代

目标：

```text
二次特征和因果主信息只保留事实结构和基础统计，解释结果作为运行时推导。
```

动作：

```text
1. 标注 二次特征::是否满足 为缓存。
2. 标注 因果::已验证 为确认标记，不替代次数和证据链。
3. 规划 区间层级 -> 父子刻度链 的替代。
4. 限制 离散语义键 只用于索引 / 显示 / 外部映射。
```

验收：

```powershell
rg -n "是否满足|已验证|区间层级|离散语义键" -S 基础信息主信息类.h 因果类.cpp 二次特征类.cpp
```

通过条件：

```text
底层判断以比较量、值域、允许方向、次数和证据链为准。
解释字段不作为权威事实。
```
