# 短语主信息字段纠偏分计划 v0.1

更新时间：2026-05-19

对应主信息：`短语主信息类`

## 审查结论

`短语主信息类` 是语言组合结构，不应保存治理业务语义字段。

## 纠偏动作

```text
P1. 检查短语字段是否只表达语言组合结构。
P2. 若短语用于生成需求或方法候选，只能作为输入文本 / 语义来源，不作为权威事实。
P3. 不新增任务状态、需求满足、方法结果方向等字段。
```

## 验收

```powershell
rg -n "短语主信息类" -S 语素主信息类.h 语素类.cpp
```

通过条件：

```text
短语主信息不承载可由特征、二次特征或因果链表达的业务事实。
```
