## 4. 实施步骤

```text
S1d-4p-1：
    在 `二次特征应用模块.ixx` 的分步结果生成路径增加低频内部采样。

S1d-4p-2：
    拆分记录：
        分步模板构造；
        分步签名查找 / 创建；
        分步主信息读取；
        分步语义绑定；
        分步来源 / 主体绑定；
        分步值写入；
        分步差值写入。

S1d-4p-3：
    采样锚点：`动态二次特征分步结果/内部阶段耗时`。
    采样规则：
        继承 S1d-4o 的慢调用阈值；
        总耗时低于 100000us 不输出；
        慢调用前 3 次输出；
        之后每 10 次输出；
        总耗时不低于 500000us 输出。

S1d-4p-4：
    构建 Debug x64，真实运行 `--self-check-log --self-check-log-wait-ms=10000`。

S1d-4p-5：
    汇总最新线程的 `动态二次特征分步结果/内部阶段耗时`，决定下一步是否进入局部签名索引快路径或写入路径瘦身。
```

## 5. 验证预测

```text
构建：
    Debug x64 构建通过。

真实运行：
    退出码=0。
    日志出现 `动态二次特征分步结果/内部阶段耗时`。

    不出现旧路径锚点 `准备本能调用`、`执行本能方法`、`任务域本能输入包`。

性能判断：
    如果 `分步签名查找 / 创建` 为主耗时，下一步优先做场景内二次特征签名局部索引快路径。
    如果 `分步来源 / 主体绑定` 或 `分步值写入` 为主耗时，下一步优先减少重复刷新度量签名和重复概念模板刷新。
    如果 `分步差值写入` 为主耗时，下一步优先收束变化量 / 方向节点的重复差值写入。
```
