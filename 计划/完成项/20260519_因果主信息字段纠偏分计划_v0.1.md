## 审查结论

因果主信息已基本符合“只存事实骨架和基础次数”的口径。重点是防止重新加入作用类型、确定性、成功率等派生字段。

## 字段口径

```text
可保留：
    形态
    适用锚点类型
    适用层级
    条件比较模板
    因比较模板
    因方法模板
    因动作名称 / 因动作语义键
    果比较模板
    主果比较模板
    来源类型
    证据动态样本
    观察次数 / 条件命中次数 / 因出现次数 / 果出现次数 / 成立次数 / 失败次数
    最近命中时间 / 最近失败时间

待降权：
    已验证
```

## 纠偏动作

```text
P1. 禁止新增 因果作用类型 / 因果确定性 / 成功率 / 失败样本列表 / 时间窗口 字段。
P2. 已验证 只作为确认标记，不替代次数和证据链。
P3. 稳定度运行时由 成立次数 - 失败次数 计算。
P4. 果侧作用解释由主果比较模板的二次特征比较结果推导。
```
