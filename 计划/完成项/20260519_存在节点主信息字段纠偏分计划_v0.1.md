对应主信息：`存在节点主信息类`

## 审查结论

`存在节点主信息类` 中的根链、内部对象引用可保留；位置历史和观测计数字段属于存在特征或二次特征，应降权为观测缓存。

## 字段分级

```text
结构字段：
    内部信息根
    需求根
    任务根
    方法根
    特征根 / 状态根 / 动态根等根链引用

待降权缓存：
    有位置历史
    上次观测位置_mm
    最近观测位置_mm
    最近位移_mm
    连续静止帧
    连续未命中帧
```

## 纠偏动作

```text
P1. 将位置历史字段标注为观测缓存。
P2. 最近观测位置迁移方向：存在特征。
P3. 上次 / 最近位置差、最近位移迁移方向：二次特征。
P4. 连续静止、连续未命中迁移方向：统计特征或二次特征。
P5. 治理逻辑不得只凭存在主信息位置缓存作任务或需求判断。
```

## 验收

```powershell
rg -n "有位置历史|上次观测位置_mm|最近观测位置_mm|最近位移_mm|连续静止帧|连续未命中帧" -S .
```

通过条件：

```text
位置历史字段只作为观测缓存；权威判断改由特征 / 二次特征 / 动态证据提供。
```
