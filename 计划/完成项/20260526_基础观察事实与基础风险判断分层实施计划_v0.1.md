## 1. 定案目标

把安全观察派生链拆成两阶段：

```text
第一阶段：
    当前观察帧.基础观察事实可用状态 等于 可用

第二阶段：
    自我所在场景.基础风险判断状态 等于 已明确
```

第一阶段只证明自我拥有一份可用的当前观察事实；不得宣称基础风险已明确、基础风险值已计算或场景安全。

2026-05-29 口径覆盖：

```text
“基础风险判断”在本计划中只作为兼容名称，实际含义收束为当前场景安全影响因果评估证据是否足够。
不定义安全因素表，不写死危险对象、危险场景或固定风险公式。
未知场景只表示安全影响关系低置信 / 不可判定，不等于危险。
```

2026-05-31 口径覆盖：

```text
历史直接伤害会先生成 / 更新负向安全因果信息。
当前风险判断以负向安全因果信息为运行时判据，不另建一套历史伤害直查路径。
没有负向因果信息时，当前风险判断默认安全，需求树和任务推进不因未知阻塞。
默认安全不等于永久安全事实，不等于关闭被动更新入口，不等于直接结算自我安全值。
```

## 2. 边界

```text
1. 基础观察事实可用不是基础风险已明确。
2. 基础风险已明确不是风险可接受。
3. 像素级 100% 只表示可寻址、可回查、无遗漏、无重复。
4. 场景存在集合等基础输入缺失时，基础风险判断只能是 条件不足；基础输入可用但未读取到负向因果信息时，当前风险判断默认安全。
5. 任务筹办第一阶段不得直接派生 基础风险判断状态 == 已明确。
6. 仍然使用 大于 / 小于 / 等于 三比较格式，不恢复语义词方向。
7. 不新增模拟样本、伪造入口或伪造动作动态。
8. 已建立 / 已取得 / 已覆盖 / 已完成 / 已完备 / 新鲜 / 可用 / 已明确 等枚举型实例特征值不能手工赋值，必须由合法生产者写入，并能追溯输入证据、判定标准、输出宿主、输出特征和动作动态 / 来源动态 / 规则证据；枚举值域初始化本身不需要通过本能方法获取。
9. 观察帧存在已建立只表示帧容器成立；像素覆盖、像素特征值承接、新鲜度、质量可用和基础观察事实可用必须分层落账。
```
