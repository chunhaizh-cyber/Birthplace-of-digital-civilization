对应主信息：`特征节点主信息类`

## 审查结论

`特征节点主信息类` 是一次特征本体，但当前包含若干稳态、命中和区间缓存字段。缓存可以短期存在，但不得成为治理权威事实。

## 字段分级

```text
本体字段：
    特征类型
    当前值
    区间 / 值域兼容字段

缓存 / 索引：
    当前命中抽象特征
    当前稳态索引
    近帧候选抽象特征
    近帧候选开始时间
    近帧候选累计时间
    局部区间覆盖
    稳态列表
    连续测量误差区间
```

## 纠偏动作

```text
P1. 标注命中、稳态、近帧字段为缓存。
P2. 新逻辑不得以缓存字段作为需求满足、任务完成、结算判断的唯一依据。
P3. 区间表达逐步与抽象特征值域口径对齐。
P4. 稳态和误差后续由特征 / 二次特征 / 因果证据反查。
```

## 验收

```powershell
rg -n "当前命中抽象特征|当前稳态索引|近帧候选|局部区间覆盖|稳态列表|连续测量误差区间" -S .
```

通过条件：

```text
这些字段只作为缓存 / 显示 / 索引，不作为业务事实权威。
```
