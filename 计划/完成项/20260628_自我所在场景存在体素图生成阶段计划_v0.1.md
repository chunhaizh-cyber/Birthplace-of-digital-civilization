# 20260628 自我所在场景存在体素图生成阶段计划 v0.1

## 定位

阶段目标：

```text
自我所在场景中能够生成存在的体素图。
```

本计划只推进当前场景中已确认存在的体素图生成与验证链路，不宣称视觉系统完成、D455 自然业务闭合、自我苏醒完成或初步成熟完成。

核心边界：

```text
1. 场景体素服务只能只读生成运行期快照，不写世界树事实、需求满足、价值结算或方法动作动态。
2. 存在体素图必须来自已确认存在的三维体素特征和值池 VecU 句柄。
3. 场景体素快照可以作为工程守卫证据，不能作为世界树事实成立或视觉业务闭合证据。
4. 如果当前场景没有合法体素来源，必须继续追根因到来源缺口，不能伪造体素样本。
```

## 自查根因协议

执行本计划时，Codex 不得因为第一轮缺数据、缺入口或自然样本未命中就停止。必须按以下顺序自行查找根因和实现方案：

```text
1. 固定当前目标：
   当前只解决“自我所在场景存在体素图可生成”，不扩展到视觉业务闭合。

2. 固定证据：
   先记录命令、退出码、DB 查询结果、快照统计、日志辅助锚点。

3. 查规范：
   先查 050007 和 RULE-VISION-PRIOR，再查自我所在场景、当前场景明确性、事实来源和写权规则。

4. 查现有代码：
   优先复用 场景体素模块、场景类、存在类、特征类、世界树 SQL 投影、数据库 ADO 模块。

5. 定位缺口所属类：
   缺场景枚举走场景类；
   缺存在坐标走存在类；
   缺三维体素特征值读写走特征类；
   缺 SQL 投影或 DB 回查走世界树 / 数据库 ADO；
   缺快照生成或查询走场景体素模块。

6. 最多生成 3 个最小方案并选择最小闭合方案：
   只读核查优先；
   复用已有函数优先；
   当前类最小缺口补齐其次；
   只有跨类封装确实缺失时才切到对应类逻辑纠偏计划。

7. 确实无解才停止交互：
   只有权威规范冲突、真实硬件 / SQL 环境不可得、必须用户确认事实来源、或继续会伪造业务证据时，才输出阻塞回执并请求确认。
```

## 证据规则

本计划采用数据库优先验证：

```text
1. 运行生成的信息如果已进入数据库投影，优先用数据库数据判断是否符合预期。
2. 日志只作为辅助证据，用于定位命令路径、退出码、错误原因和快照统计。
3. 构建通过只能证明工程守卫，不证明体素图业务可用。
4. 快照可生成只能证明运行期心像缓存生成，不证明世界树事实新增。
```

最低证据等级：

```text
P0：E1/E2，静态结构 + 已有命令事实梳理。
P1：E2/E3，构建 + 真实命令运行。
P2：E3/DB，真实命令运行后用 DB 投影核对当前场景、存在、特征和值承载。
P3：E3/DB，快照统计和 DB 来源事实互相一致。
```

## 分步实施

### P0 当前根因扫描与计划接入

目标：

```text
确认现有场景体素服务、三维体素特征读写、SQL 投影和命令入口的真实状态；
把本计划登记为计划索引当前可执行项；
写入断点清单。
```

预测：

```text
现有 --scene-voxel-maintenance-smoke 能同步快照，但未传入三维体素特征类型，无法证明存在体素图已生成。
```

验收：

```text
计划文件存在；
计划索引指向本计划 P0/P1；
断点清单记录当前根因假设和下一步验证命令。
```

### P1 体素图生成入口最小补齐

目标：

```text
让场景体素同步参数绑定正式“三维体素模型”特征类型；
运行命令能输出快照统计中的枚举存在数量、有坐标存在数量、有体素存在数量、入选存在数量和缺口数量。
```

实现原则：

```text
优先修改既有 --scene-voxel-maintenance-smoke 或新增同类工程守卫命令；
不得新增业务结构体；
不得伪造外设样本；
不得把缺口强行改成成功。
```

如果当前场景存在没有体素特征：

```text
命令必须输出缺口统计；
继续自动追根因到“合法体素来源缺失”，不得停止在缺口结果。
```

### P2 DB 优先验证查询

目标：

```text
运行后刷新或读取 SQL 投影；
用 DB 查询当前世界树节点 / 关系核对：
    自我现实场景存在；
    场景直接子存在存在；
    子存在坐标特征存在；
    三维体素特征类型和体素特征节点存在或缺口原因明确。
```

验收：

```text
实施记录中必须写 DB 查询 SQL、关键返回行数和判断；
若 SQL Server 不可用，降级为环境条件阻塞，日志只作辅助，不能宣称 DB 验证通过。
```

### P3 存在体素图可生成闭合

目标：

```text
至少一个当前场景已确认存在具备坐标和三维体素 VecU 句柄；
场景体素快照中入选存在数量 >= 1；
DB 来源事实与运行快照统计一致。
```

若没有合法体素来源：

```text
转入 P3a 合法体素来源补齐切片；
先查自我身体 / 自我边界 / 外设观察 / 合法提交入口是否已有体素生成路径；
不能新增伪体素或夹具体素。
```
