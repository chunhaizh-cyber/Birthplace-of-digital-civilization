# 20260629 日志输出预处理分级控制计划 v0.1

## 1. 目标

```text
把运行日志、预测日志、逻辑错误排查日志、调试日志、控制台输出、UI 提示和调试器输出全部纳入预处理控制。
总开关 鱼巢_开关_启用所有输出=0 时，本次运行不得新增或增长日志文件。
日志只允许作为人工诊断输出，不得承载正式机器逻辑、业务状态、需求 / 任务 / 方法 / 因果闭环判断。
```

## 3. 细分开关

```text
总开关：
    鱼巢_开关_启用所有输出

分类开关：
    鱼巢_开关_启用运行日志输出
    鱼巢_开关_启用登记管理日志输出
    鱼巢_开关_启用预测日志输出
    鱼巢_开关_启用逻辑错误日志输出
    鱼巢_开关_启用逻辑错误排查日志输出
    鱼巢_开关_启用调试日志输出
    鱼巢_开关_启用控制台输出
    鱼巢_开关_启用调试器输出
    鱼巢_开关_启用UI直接提示输出
    鱼巢_开关_启用项目弹窗错误

默认关系：
    所有分类开关默认继承总开关或上级分类开关。
    自检日志入口默认继承调试日志输出。
    动作验证报告诊断日志默认继承预测日志输出。
    扫描上游契约诊断默认继承逻辑错误排查日志输出。
```

## 4. 验收标准

```text
1. 默认 Debug x64 构建通过。
2. 鱼巢_开关_启用所有输出=0 的 Debug x64 Rebuild 通过。
3. 全关构建产物运行短入口后，./日志 目录无新增日志文件，既有日志文件大小不增长。
4. 低级错误保护仍终止程序，但其调试器、文件和弹窗输出均受对应输出开关控制。
5. 关闭输出不改变项目结构事实写入、逻辑错误检测和错误终止语义。
```
