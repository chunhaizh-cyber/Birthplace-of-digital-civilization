## 1. 只读复核结论

```text
当前不是单个字段越界，而是工作结果包和上行消息同时承担两类职责：
    1. 线程调度 / 状态检查所需的轻量结果。
    2. 任务虚拟存在写回、输出结果场景回查和派生需求构造所需的事实指针。

需要先拆职责，再删除旧指针字段。
```

关键命中：

```text
任务模块.管理线程协议.ixx:
    结构_任务工作结果 仍携带 任务信息节点、任务虚拟存在、来源需求、方法运行结果、方法执行数据、任务筹办情况、任务执行情况。
    结构_任务筹办情况 携带 方法运行结果 / 结果场景。
    结构_任务执行情况 携带 方法运行结果 / 输出结果场景。

任务模块.工作线程消息协议.ixx:
    结构_任务管理派生需求消息 携带 方法虚拟存在指针、来源因果指针、来源动态指针、来源方法指针、父需求指针、需求特征类型指针、需求目标主体指针、需求当前状态指针、需求目标状态指针。
    结构_任务管理结果状态消息 携带 方法虚拟存在指针，并保留服务对象状态变化集 / 关键中间状态变化集。
    结构_任务管理观察事实承接请求 当前主要是 ID / 文本 / 时间 / 数量字段，优先级低于前两类。

任务模块.管理界面线程.impl.cpp:
    私有_同步工作回执方法到任务壳 从 工作结果 中读取 方法运行结果 / 输出结果场景，并在界面线程写 当前方法运行存在 / 最近运行虚拟存在 / 输出结果场景。
    私有_应用工作结果到任务壳 先普通整理回执到任务壳，再通过 提交任务状态变化 推进任务状态。

任务模块.管理工作线程.ixx:
    工作线程执行后把 方法运行结果、方法执行数据、任务筹办情况、任务执行情况 填入 结构_任务工作结果，供界面线程继续处理。
```

## 2. 目标边界

```text
可跨线程保留：
    请求ID、工作项ID、任务主键、来源需求主键、状态分类、结果分类、完成度、错误码、幂等键、批次ID、事件ID、写回完成标志、需要状态检查标志、需要下一轮标志、等待 / 重筹办 / 收束控制标志。

不得继续作为跨线程正式字段：
    存在节点指针、特征节点指针、状态节点指针、动态节点指针、方法节点指针、场景节点指针、二次证据结构、输出结果场景指针、方法运行存在指针、真实事实变化明细。

过渡期允许：
    旧结构作为本地兼容承载保留一小段，但新增轻量字段必须先成为界面线程决策依据。
    每次删除旧指针字段前必须确认所有消费者已经改用主键 / 事件ID / 写回标志。
```
