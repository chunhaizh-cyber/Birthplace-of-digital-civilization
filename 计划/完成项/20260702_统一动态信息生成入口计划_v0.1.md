日期：2026-07-02

状态：需求契约、需求树和当前绑定方法已确认；S0-S7 代码 / 静态门禁已完成，S8 已取得被动动作和主动动作真实运行证据；结算动作真实路径待自然条件命中。

## 0. 承接的根需求

统一动态信息生成入口。主动动作动态、被动动作动态必须通过同一个动作动态生成入口创建，并固定动作动态主信息必填字段、主动 / 被动判定规则和空字段逻辑错误检查。

## 1. 需求契约摘要

```text
1. 动作动态必须固定填写：
   动态主体、动态特征、初始状态、结果状态、来源输入场景、来源输出场景。
2. 缺任一必填项就是逻辑错误，不创建动作动态。
3. 主动动作：
   来源动作非空，必须是有效方法头，必须校验动作句柄。
4. 被动动作：
   来源动作必须为空，来源动作名固定为“被动动作”，不读取方法头、动作句柄或本能 ID。
5. 来源执行成功、来源错误码退出动作动态主信息口径；控制面板先不显示。
6. 动态路径签名暂时保留，继续服务动态聚合和二次特征匹配。
7. 空字段检查和相关错误日志由预编译控制诊断输出，但关闭输出不得改变错误检测、不创建动态和终止语义。
```

### 8.1 字段填写契约

| 字段 | 主动动作填写规则 | 被动动作填写规则 | 检查方式 |
| --- | --- | --- | --- |
| 动态主体 | 必填。填写被方法运行改变或记录运行事实的存在 / 治理虚拟存在 / 方法执行实例存在 | 必填。填写被提交事实所在的任务虚拟存在、方法虚拟存在、需求虚拟存在、记录宿主或结算宿主 | 统一入口空字段检查；空则逻辑错误，不创建动态 |
| 动态特征 | 必填。必须与初始状态、结果状态的状态特征一致 | 必填。必须与初始状态、结果状态的状态特征一致 | 统一入口一致性检查；不一致则逻辑错误 |
| 初始状态 | 必填。由调用方在进入统一入口前构造；无目标值变化时必须改用运行存在 / 提交记录等可记录事实状态 | 必填。由提交链在进入统一入口前构造；不能因“被动”而留空 | 统一入口空字段检查；空则逻辑错误 |
| 结果状态 | 必填。由调用方在进入统一入口前构造；失败、缺口、等待应落为输出场景或运行存在特征事实 | 必填。由提交链在进入统一入口前构造；失败或拒绝也要落为正式结果事实 | 统一入口空字段检查；空则逻辑错误 |
| 来源动作 | 必填且必须是有效方法头；必须有可执行动作句柄 | 必须为空；非空即判为逻辑错误 | 先判动作类型；被动不读取方法头和动作句柄 |
| 来源动作名 | 主动可由来源方法动作名推导；显式传入时只能作为动作语义入口，不替代方法头 | 必填为 `被动动作`；它是空占位动作，不可主动调用 | 被动动作名 + 空来源动作共同定义被动；非被动缺方法则逻辑错误 |
| 来源输入场景 | 必填；没有实际输入内容时传正式空输入场景 | 必填；没有实际输入内容时传正式空输入场景 | 统一入口空字段检查 |
| 来源输出场景 | 必填；方法结果、失败、缺口、等待必须落到输出场景或运行存在特征事实 | 必填；提交结果、拒绝、幂等结果必须落到输出场景或记录宿主事实 | 统一入口空字段检查 |
| 来源低层动态 | 可选；若有同源状态迁移、D0/D1、满足证据或上游动作动态，创建后追加 | 可选；用于承接上游主动动作、状态迁移或提交资格证据 | 后续因果 / 二次特征读取，不能用自由文本替代 |
| 动态路径签名 | 统一入口按现有动态路径签名逻辑生成并保留 | 同主动 | 静态检查保留字段；动态聚合和二次特征继续读取 |
| 来源执行成功 | 不作为动作动态主口径；后续停止由统一入口写入，控制面板先不显示 | 同主动 | 不作为机器判断；SQL 兼容字段本轮不作为显示字段 |
| 来源错误码 | 不作为动作动态主口径；错误、失败、缺口必须特征化 | 同主动 | 不作为机器判断；SQL 兼容字段本轮不作为显示字段 |

