# P4b1 同条件统计宿主与新结果分支最小落账方案 v0.1

## 目标

在不改 `data/initial_causal_templates.tsv` 结构、不进入自我线程已有脏改区的前提下，先完成 P4b 中可以闭合的两项：

```text
1. 结果符合 / 不符合次数不再写到方法虚拟存在整体，而是写到同一条件对应的条件场景。
2. 新结果分支数量独立成特征，并在同一条件下出现非等价新结果分支时累加。
```

## 依据

```text
规范/方法规范20260425.md：
    结果节点必须挂在具体条件节点下；
    同一个结果出现在不同条件下，不能因为结果相同就把统计混在一起。

用户口径：
    练习要求是同一个条件被命中过 3 次以上，且没有生成新的结果对。
```

## 实施范围

```text
允许修改：
    自我动作实现模块.ixx
    计划/计划索引.md
    本方案
    对应实施记录

禁止修改：
    data/initial_causal_templates.tsv
    自我线程模块.impl.cpp
```

## 实施要点

```text
1. 条件节点本身不是世界树基础信息节点，不能直接写特征；
2. 条件节点引用的条件场景是基础信息节点，并且由方法虚拟存在下创建、绑定到该目标方法；
3. 因此同一条件统计宿主采用：条件节点 -> 条件场景；
4. 条件场景写入：
       样本次数
       最近样本时间
       结果符合次数
       结果不符合次数
       新结果分支数量
5. 方法虚拟存在继续保留方法级样本总数 / 最近样本时间，作为聚合摘要；
6. 练习好用闸门改为：
       目标方法最近连续成功次数 >= 4；
       同条件样本次数 >= 4；
       同条件新结果分支数量 == 0。
```

## 验收

```text
1. Debug x64 构建通过；
2. 日志中可看到练习读取同条件样本次数和新结果分支数量；
3. 当同条件样本不足或出现新结果分支时，不生成“把新结果分支数量降为 0”的伪需求；
4. P4b 剩余问题继续停在方法状态被动模板接入入口，而不是同条件统计宿主。
```

## 剩余堵点

```text
当前 TSV 应用入口仍只服务安全风险树：
    宿主只识别 target / scene / world；
    比较值固定使用 安全因果风险树明确状态_未明确 -> 已明确；
    不能表达 方法动作数量 > 0 / 方法条件结果对数量 > 0 / 同条件样本次数 >= 4 这类数量底账已满足条件。

因此方法状态被动模板接入仍需后续 P4b2：
    先定义“数量底账已满足”的二次特征或等价布尔特征生成路径；
    再新增方法状态被动因果种子应用入口。
```
