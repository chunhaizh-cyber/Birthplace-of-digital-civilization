## 审查结论

`抽象特征主信息类` 已进入 v0.2 结构，但仍有旧字段需要迁移。

## 字段分级

```text
权威字段：
    名称
    类型
    形态
    值域

可保留粗溯源：
    来源实例特征

待迁移 / 删除：
    区间
    组合规则
```

## 纠偏动作

```text
P1. 禁止新增 区间 和 组合规则 写入点。
P2. 将旧 区间 读取适配到 特征值域。
P3. 删除或隔离 组合规则。
P4. 复合抽象特征只按直接子抽象特征组成结构匹配。
P5. 校验复合抽象特征直接子节点只能是抽象特征，且每个直接子特征必须有名称。
```

## 执行记录

### 2026-05-19 首轮完成

实现：

```text
1. 抽象特征创建入口会规范化旧字段：
   - 缺名称时用类型补名称；
   - 缺类型时用名称补类型；
   - 旧 区间 会迁移成 I64值域项。

2. 叶子抽象特征的区间读取已优先走 特征值域。
   旧 区间 仅作为兼容回退路径。

3. 常用抽象特征初始化不再写入 组合规则。
   特征值差值不等于零 已改为明确 I64 值域：
       [I64_MIN, -1] ∪ [1, I64_MAX]

4. 复合抽象特征校验收口为具名子特征组成结构：
   - 直接子节点必须是抽象特征；
   - 直接子特征必须有名称；
   - 同一父复合抽象特征下直接子特征名称不得重复。

5. 旧 组合规则 不再参与抽象特征求值。
   控制面板仅以 弃用组合规则数量 形式显示存量诊断信息。
```
