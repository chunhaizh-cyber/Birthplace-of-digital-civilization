对应主信息：`需求主信息类`

## 审查结论

需求主信息应表达目标宿主、目标特征、目标状态和治理关系。当前派生归因平铺字段需要收口，权重和结算字段需要明确非安全值本体。

## 字段分级

```text
目标本体：
    需求主体
    需求场景
    被需求存在
    被需求当前状态
    需求状态
    满足关系
    目标特征类型缓存

治理关系：
    对应任务
    任务列表
    需求有效截止
    是否阻塞父任务执行

活动 / 账本摘要：
    安全权重
    服务权重
    累计安全结算
    累计服务结算
    最近结算任务主键
    最近结算时间

待迁移平铺字段：
    派生来源方法主键
    派生需求类型抽象特征指针 / 值
    派生方法需求位抽象特征指针 / 值
    派生本能能力缺口类型抽象特征指针 / 值
```

## 纠偏动作

```text
P1. 固定 安全权重 / 服务权重 为活动权重或预算，不是安全值 / 服务值。
P2. 结算摘要字段只由正式 D2 结算动作动态更新。
P3. 派生平铺字段迁移到来源回执、动作动态、缺口二次特征、因果证据链。
P4. 控制面板优先展示来源链推导结果，旧字段只作兼容。
```

## 验收

```powershell
rg -n "安全权重|服务权重|累计安全结算|累计服务结算|派生来源方法主键|派生需求类型|派生方法需求位|派生本能能力缺口" -S .
```

通过条件：

```text
需求目标字段仍保持清晰；派生归因不再以平铺字段作为唯一权威来源。
```
