# 指代节点主信息字段纠偏分计划 v0.1

更新时间：2026-05-19

对应主信息：`指代节点主信息类`

## 审查结论

`指代节点主信息类` 负责指代关系和引用入口，不应扩展为业务事实容器。

## 字段口径

```text
可保留：
    指代对象
    指代类型
    引用入口
    路由或解析辅助字段

不得新增：
    业务语义枚举
    满足判断
    安全 / 服务结算字段
```

## 纠偏动作

```text
P1. 检查指代字段是否只用于引用解析。
P2. 若指代关系本身需要被判断，生成二次特征，不扩写指代主信息。
P3. 若指代变化需要追溯，使用动态 / 因果证据链。
```

## 验收

```powershell
rg -n "指代节点主信息类|指代" -S 基础信息主信息类.h 基础信息类.cpp
```

通过条件：

```text
指代节点不承载可由特征、二次特征或因果链表达的业务事实字段。
```
