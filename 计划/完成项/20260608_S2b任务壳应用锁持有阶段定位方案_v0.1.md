## 2. 目标

```text
先定位 `完成归并应用任务壳` 的锁内耗时构成。
确认耗时来自快照重写、工作结果应用、状态提交回执同步、worker 派发、日志输出、队列操作还是重复检查。
只在证据明确后做最小瘦身，优先减少锁内工作和重复工作，不改变任务状态动作动态账。
```

## 3. 边界

```text
任务状态变化仍必须通过 `提交任务状态变化` 动作入口。
不得裸写任务状态，不得跳过任务状态动作动态。
不得把任务筹办 / 任务执行恢复为本能方法。
不得把等待、未满足、D455 条件不足写成完成 / 满足。
不得为了降低锁耗时改变任务壳、状态值、动作动态、worker 派发之间的顺序一致性。
```

## 5. 执行步骤

```text
1. 在 `完成归并应用任务壳` 锁内增加阶段耗时采样：
       任务壳快照 / 字段归并
       工作结果应用
       状态提交回执同步
       worker 派发检查
       日志输出
       队列或集合操作

2. 真实运行一次，先只定位不改语义。

3. 若主耗时为重复快照或字段归并：
       仅对无变化字段跳过重复写入，保留必要状态版本和动作动态引用。

4. 若主耗时为 worker 派发检查或队列操作：
       优先缩短锁内检查范围，禁止 worker 先执行后补账。

5. 若主耗时为状态提交回执同步：
       回到任务状态提交链局部定位，不绕开 `提交任务状态变化`。

6. 若主耗时为日志输出：
       登记 S3 后续，不在本切片混改日志策略。
```
