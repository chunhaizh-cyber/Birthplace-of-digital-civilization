# 基础信息类逻辑纠偏计划 v0.1

日期：2026-06-20

状态：由存在类 1.3 非存在主信息操作审查触发；当前只执行第一优先缺口，闭合后返回存在类 1.3。

## 0. 目标

把基础信息节点主信息生命周期操作收束到 `基础信息类`，避免存在类直接删除任意节点的 `主信息` 指针。

## 1. 第一优先缺口：递归释放节点主信息

触发点：

```text
存在类::删除存在 当前先调用 私有_递归释放基础信息主信息：
    delete 节点->主信息;
    节点->主信息 = nullptr;

该操作属于基础信息节点生命周期，不属于存在类业务职责。
```

建议函数：

```cpp
void 释放节点主信息递归(节点类* 节点) noexcept;
```

执行边界：

```text
1. 函数归属 基础信息类.h/.cpp。
2. 只释放指定节点及其子链节点上的主信息指针，不删除节点本身。
3. 节点摘链仍由 基础信息类::删除节点 / 双向链表模板负责。
4. 存在类::删除存在 只调用基础信息类生命周期函数，不再直接 delete 节点->主信息。
5. 闭合后返回 计划/20260620_存在类逻辑纠偏计划_v0.1.md 的 1.3。
```

验收命令：

```powershell
rg -n "释放节点主信息递归|delete 节点->主信息|节点->主信息 = nullptr|私有_递归释放基础信息主信息" 基础信息类.h 基础信息类.cpp 存在类.cpp
python .\tools\生成函数功能说明文档.py
msbuild .\鱼巢.vcxproj /p:Configuration=Debug /p:Platform=x64 /p:LinkIncremental=false /m
```

执行状态：

## 2. 跨类缺口转向规则

```text
1. 后续任意类缺少当前切片所需功能函数时，不在调用方临时拼字段、解释其它类主信息或新增平行结构体。
2. 若对应类已有逻辑纠偏计划，则把当前缺口加入该计划，并放到第一优先位置。
3. 若对应类没有逻辑纠偏计划，则生成 `计划/YYYYMMDD_<类名>逻辑纠偏计划_v0.1.md`，并把当前缺口作为第一优先切片。
4. 新生成或被修改的逻辑纠偏计划必须包含本“跨类缺口转向规则”。
5. 更新 `计划/计划索引.md`：把新生成或新修改的计划临时提升为第一优先计划；原计划和原切片记录为返回点。
6. 只执行新计划的第一优先缺口切片，不顺带推进新计划后续候选项。
7. 第一优先缺口闭合后，立即停止该新计划，更新计划索引返回原计划和原切片。
8. 若第一优先缺口切片不能闭合，保留该计划为当前阻塞，不回到原计划继续补丁化绕过。
```
