对应主信息：`动态节点主信息类`

## 审查结论

动态节点应记录“某主体某特征从初始状态到结果状态，并追踪来源”。`业务语义类型` 属于可推导业务标签，不应作为权威字段。

## 字段分级

```text
动态本体：
    初始状态
    结果状态
    动态主体
    动态特征
    时间

来源审计：
    来源类型
    来源动作
    来源动作相位
    来源输入场景
    来源输出场景
    动态路径签名

非权威快照 / 待收口：
    业务语义类型
    来源动作名
    来源执行成功
    来源错误码

聚合审计：
    动态层级
    聚合方式
    来源低层动态
```

## 纠偏动作

```text
P1. 整理 推导动态业务语义(...)。
P2. 因果边类型、二次特征聚合、面板展示改读推导结果。
P3. 停止把 业务语义类型 作为治理判断权威字段。
P4. 来源类型只表示来源机制，不表示业务语义。
P5. 来源动作名、来源执行成功、来源错误码降级为非权威快照。
```

## 验收

```powershell
rg -n "业务语义类型|枚举_动态业务语义类型|来源动作名|来源执行成功|来源错误码" -S .
```

通过条件：

```text
核心治理逻辑以 来源动作 + 动态特征 + 状态比较 + 二次特征 / 因果证据推导动态语义。
```
