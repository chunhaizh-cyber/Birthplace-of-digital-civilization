# 子句主信息字段纠偏分计划 v0.1

更新时间：2026-05-19

对应主信息：`子句主信息类`

## 审查结论

`子句主信息类` 是语言结构最小分段之一。它可作为解析来源，不作为业务事实权威。

## 纠偏动作

```text
P1. 确认字段只表达子句结构。
P2. 由子句产生的需求候选、方法候选或因果候选必须通过正式入口生成。
P3. 不新增任务状态、需求满足、方法状态字段。
```

## 验收

```powershell
rg -n "子句主信息类" -S 语言主信息类.h
```

通过条件：

```text
子句主信息只作为文本解析来源。
```
