# S1d-4k 状态创建后处理内部阶段定位方案 v0.1

日期：2026-06-08

## 1. 目标

```text
承接 S1d-4j。

S1d-4j 已定位：
    `输出任务状态提交动作动态` 内部主耗时集中在新状态节点创建；
    最新线程 T13928 动作动态创建内部采样 19 条；
    最慢阶段分布为 `新状态节点=19`；
    `新状态节点` 平均约 408635us，最大 538594us。

本切片只拆 `状态类::创建状态` 内部阶段：
    添加子节点；
    读取场景主信息；
    追加状态索引；
    状态记录后刷新动态；
    状态写入后整理。
```

```text

不删除状态索引追加。

不新增模拟入口、夹具、伪造样本或 `--*-check` 回归入口。
```

## 4. 实施步骤

```text
S1d-4k-1：
    在 `状态类::创建状态` 中增加低频阶段采样。

S1d-4k-2：
    采样锚点：`状态创建/内部阶段耗时`。
    采样规则：
        总耗时低于 100000us 不输出；
        慢调用前 3 次输出；
        之后每 10 次输出；
        总耗时不低于 500000us 输出。

S1d-4k-3：
    构建 Debug x64，真实运行 `--self-check-log --self-check-log-wait-ms=10000`。

S1d-4k-4：
    用日志确认状态创建内部主耗时。
```

## 5. 验证预测

```text
构建：
    Debug x64 构建通过。

真实运行：
    退出码=0。
    日志出现少量 `状态创建/内部阶段耗时`。
    日志保留 `任务状态动作动态=<动态主键>`。
    不出现 `任务状态被动提交/逻辑错误`。
    不出现 `任务状态动作动态逻辑错误`。

性能判断：
    如果主耗时是 `状态记录后刷新动态` 或 `状态写入后整理`，
    只能登记为规范边界堵点：
        当前规范要求状态写入后自动生成状态动态和整理旧状态；
        未有任务状态动作动态边界状态专用安全入口；
        不能直接删除世界层统一后处理。
```

## 6. 阻塞条件

```text
如果诊断定位到世界层统一后处理，而没有规范允许的任务状态动作动态专用入口，停止在证据和方案。
如果真实日志出现任务状态动作动态缺失，停止并修正动作动态账。
```

## 7. 落地结果

```text
已落实：
    `状态类::创建状态` 增加低频内部阶段采样；
    输出锚点为 `状态创建/内部阶段耗时`；
    采样不改变状态节点创建、状态动态刷新或状态写入后整理语义。

验证：
    Debug x64 构建通过；
    `.\x64\Debug\鱼巢.exe --self-check-log --self-check-log-wait-ms=10000` 退出码 0；
    日志/鱼巢_run_20260608.低值g 出现状态创建内部阶段采样；
    日志保留 `任务状态动作动态=<动态主键>`；
    未检出 `任务状态被动提交/逻辑错误`、`任务状态动作动态逻辑错误`。

定位结论：
    最新线程 T24008 状态创建内部采样 33 条；
    最慢阶段分布：`状态动态刷新=33`；
    最新线程平均总耗时约 849400us；
    `状态动态刷新` 平均约 849007us，最大 2081942us；
    `状态写入后整理` 平均约 207us；
    全部 54 条状态创建慢样本最慢阶段均为 `状态动态刷新`。

下一步：
    转入 S1d-4l，优化 `动态类` 内状态 / 动态索引引用解析。
    代码复核显示 `动态类::私有_解析状态引用` 当前先走主键查找，
    而场景状态索引里的引用通常已有有效指针；
    可改为指针有效且主键匹配时直接使用指针，主键查找作为兜底。
```
