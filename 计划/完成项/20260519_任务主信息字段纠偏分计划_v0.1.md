对应主信息：`任务主信息类`

## 审查结论

任务主信息是需求过程承接壳，不应保存任务状态权威事实。任务状态仍由任务虚拟存在和任务管理生命周期提交链维护。

## 字段口径

```text
可保留：
    名称
    类型
    创建时间
    修改时间
    对应需求
    任务虚拟存在
    场景
    目标状态

待降权：
    结果状态信息
```

## 纠偏动作

```text
P1. 标注 结果状态信息 为结果摘要 / 兼容字段。
P2. 任务完成判断必须以任务目标和实际结果状态比较为准。
P3. 不向任务主信息类恢复任务状态裸字段。
P4. 不恢复 自我_任务筹办 / 自我_任务执行 为本能方法。
```

