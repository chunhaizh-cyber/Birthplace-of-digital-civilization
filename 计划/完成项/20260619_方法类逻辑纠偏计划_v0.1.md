# 方法类逻辑纠偏计划 v0.1

日期：2026-06-19

状态：旧第一优先缺口已闭合；2026-06-20 方法引用解析成员函数已闭合；因果类 P7 可调用的基于基础信息方法解析函数已闭合，已停止本计划并返回协调计划 P7。

## 0. 目标

围绕 `方法类.h/.cpp` 补齐方法能力读取和判断函数，避免需求类、任务筹办或其它调用方直接解释方法主信息字段。

当前触发缺口：

```text
需求类计划 4.5 需要判断“方法首节点是否能生产目标特征类型”。
当前只有 需求类.cpp::私有_方法首节点生产目标特征 私有实现。
方法类缺少公开功能函数，导致需求类若要迁移因果来源生产者分级，仍必须解释方法结果能力。
```

## 1. 第一优先缺口

建议函数：

```cpp
static bool 方法首节点生产目标特征(
    const 方法节点类* 方法,
    const 语素入口节点类* 目标特征类型) noexcept;
```

实现边界：

```text
1. 函数归属 方法类.h/.cpp。
2. 不修改需求类业务逻辑。
3. 不新增结构体，不新增方法主信息字段。
4. 只读取方法首节点能力结果包，判断结果项是否明确生产目标特征类型。
5. 关系目标特征类型由参数决定的结果项不能被当作确定生产目标特征。
6. 根写入原语不能被当作专用目标生产方法。
```

## 1.1 新增第一优先缺口：方法引用解析

当前新增缺口：

```text
因果类外部数据读取检查发现，因果类.cpp 内仍存在私有方法引用解析逻辑：
    通过 基础信息->查找主键 解析方法主键
    再将基础信息节点解释为 方法节点类

方法引用解析应归属 方法类，因果类不应直接操作方法节点查找和类型解释。
```

建议函数：

```cpp
方法节点类* 按主键解析方法节点(const std::string& 主键) const noexcept;
const 方法节点类* 按主键解析方法节点(const std::string& 主键) const noexcept;
```

实现边界：

```text
1. 函数归属 方法类.h/.cpp。
2. 只读解析，不隐式创建方法节点。
3. 不新增方法主信息字段，不新增方法引用结构体。
4. 因果类回迁时只调用方法类解析函数，不再直接 `基础信息->查找主键 + dynamic_cast/reinterpret_cast`。
```

## 2. 跨类缺口转向规则

执行本计划时，如果发现当前切片必须依赖其它类新增或补齐功能函数，按以下规则处理：

```text
1. 不在方法类或调用方临时拼字段、解释其它类主信息或新增平行结构体。
2. 若对应类已有逻辑纠偏计划，则把当前缺口加入该计划，并放到第一优先位置。
3. 若对应类没有逻辑纠偏计划，则生成 `计划/YYYYMMDD_<类名>逻辑纠偏计划_v0.1.md`，并把当前缺口作为第一优先切片。
4. 新生成或被修改的逻辑纠偏计划必须包含本“跨类缺口转向规则”。
5. 更新 `计划/计划索引.md`：把新生成或新修改的计划临时提升为第一优先计划；原计划记录为返回点。
6. 执行新计划的第一优先缺口切片。第一优先完成后立即停止该计划，更新计划索引返回原计划和原切片。
7. 若第一优先缺口切片不能闭合，保留该计划为当前阻塞，不回到原计划继续补丁化绕过。
```
