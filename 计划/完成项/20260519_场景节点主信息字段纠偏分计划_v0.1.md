# 场景节点主信息字段纠偏分计划 v0.1

更新时间：2026-05-19

对应主信息：`场景节点主信息类`

## 审查结论

`场景节点主信息类` 主要承载状态、动态、关系、因果实例索引。它是事实集合容器，不应新增业务语义判断字段。

## 字段口径

```text
可保留：
    世界类型
    状态索引
    动态索引
    关系索引
    实例因果索引
    来源 / 时间 / 场景归属

不得新增：
    任务完成判断
    需求满足判断
    安全 / 服务结算判断
```

## 纠偏动作

```text
P1. 确认场景节点只保存事实索引。
P2. 业务判断通过场景内状态、动态、二次特征和因果实例推导。
P3. 输出结果场景不得承载任务状态回执。
```

## 验收

```powershell
rg -n "场景节点主信息类|状态索引|动态索引|关系索引|实例因果索引" -S 基础信息主信息类.h 基础信息类.cpp
```

通过条件：

```text
场景字段不直接表达任务状态、需求满足或结算结论。
```
