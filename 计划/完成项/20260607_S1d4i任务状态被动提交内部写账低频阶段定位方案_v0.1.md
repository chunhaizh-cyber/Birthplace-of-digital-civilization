# S1d-4i 任务状态被动提交内部写账低频阶段定位方案 v0.1

日期：2026-06-08

## 1. 目标

```text
承接 S1d-4h。

S1d-4h 已证明：
    重复来源规格确认可以走方法首节点缓存快路径；
    `准备被动提交` 首轮后多为 1-3us；
    当前主耗时仍集中在 `执行被动提交` 内部写账。

本切片只做低频内部阶段定位：
    不删除状态节点；
    不删除任务状态动作动态；
    不删除任务虚拟存在上的 `任务状态动作动态` / `动作动态` 回写；
    不恢复完整本能函数执行壳；
    不改变任务状态裁决、完成态目标检查、worker 派发顺序。
```

## 4. 实施步骤

```text
S1d-4i-1：
    在 `提交任务状态被动动作` 内增加阶段计时变量。

S1d-4i-2：
    只在慢调用采样时输出 `任务状态被动提交/内部阶段耗时`：
        总耗时低于 100000us 不输出；
        慢调用前 3 次输出；
        之后每 10 次输出；
        总耗时不低于 500000us 输出。

S1d-4i-3：
    阶段只记录：
        前置判定；
        来源规格确认；
        任务虚拟存在；
        完成推进特征；
        完成目标检查；
        状态阶段写入；
        动作动态创建；
        动态特征回写。

S1d-4i-4：
    构建 Debug x64，真实运行 `--self-check-log --self-check-log-wait-ms=10000`，
    用日志确认内部阶段采样存在且动作动态正向 / 负向边界未破坏。
```

## 5. 验证预测

```text
构建：
    Debug x64 构建通过。

真实运行：
    退出码=0。
    日志保留 `任务状态动作动态=<动态主键>`。
    日志出现少量 `任务状态被动提交/内部阶段耗时`。
    不出现 `任务状态被动提交/逻辑错误`。
    不出现 `任务状态动作动态逻辑错误`。
    不出现 `准备本能调用`、`执行本能方法`、`任务域本能输入包`。

性能判断：
    如果内部阶段日志显示动作动态创建或状态节点创建占主耗时，
    下一轮只评估账本创建内部是否有重复取任务存在、重复特征创建或可缓存词/特征。

    如果内部阶段日志显示动态特征回写占主耗时，
    下一轮只评估两次任务虚拟存在指针特征写入是否可合并为既有批量接口；
    没有现成安全接口则不硬改。
```

## 6. 阻塞条件

```text
如果新增采样导致构建失败且原因不是局部可修复语法 / include 问题，停止。
如果真实日志出现任务状态动作动态缺失，停止并修正动作动态账。
如果内部阶段仍不能定位主耗时，先扩大低频阶段粒度，不直接删除核心写账。
```

    采样不改变任务状态写入、动作动态创建和动态引用回写路径。

    Debug x64 构建通过；

    日志保留 `任务状态动作动态=<动态主键>`；
    未检出 `任务状态被动提交/逻辑错误`、`任务状态动作动态逻辑错误`、
    `准备本能调用`、`执行本能方法`、`任务域本能输入包`。
