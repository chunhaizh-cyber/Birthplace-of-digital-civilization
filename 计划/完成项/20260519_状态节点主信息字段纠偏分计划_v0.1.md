# 状态节点主信息字段纠偏分计划 v0.1

更新时间：2026-05-19

对应主信息：`状态节点主信息类`

## 审查结论

状态节点应保存某一特征在某一时刻或语境下的值。`是否变化` 可由动态的初始状态和结果状态比较推出，不应作为权威字段。

## 字段分级

```text
本体字段：
    状态值
    所属特征 / 主体 / 时间等状态事实字段

待降权字段：
    是否变化
```

## 纠偏动作

```text
P1. 标注 是否变化 为创建提示 / 显示缓存。
P2. 状态变化判断统一从动态节点或二次特征比较结果读取。
P3. 清理把 是否变化 作为业务事实的判断点。
```

## 验收

```powershell
rg -n "是否变化" -S 状态类.cpp 状态类.h 基础信息主信息类.h 自我类.cpp 自我线程模块.impl.cpp 控制面板类.cpp
```

通过条件：

```text
任务完成、需求满足、安全 / 服务结算均不以 状态节点::是否变化 为唯一依据。
```
