## 2. 目标结构

目标顺序：

```text
WT11 -> WT12 -> VX0 -> WT13 -> WT14 -> WT15
UP5 -> CL0 -> VC0 -> CL1
CL1 -> 普通价值 / 内部治理 / 证据特殊 / 仅闭账
普通价值 -> SET0/SET1/SET2/VAL0/VAL1/VAL2/VAL3/VAL5/ACTION
内部治理 -> GOV0/GOV1/GOV2
证据特殊 -> EVD0/EVD1
仅闭账 -> CLOSE0/CLOSE1
```

第一阶段不追求一次性实现全图。先保证：

```text
执行报告态 E != 实际回读态 R；
动作验证报告 V 可以被任务执行、结果消息、结算域分类和价值闸门读取；
结算域分类在来源需求普通满足反馈之前发生；
内部治理任务和证据任务不进入核心价值结算。
```
