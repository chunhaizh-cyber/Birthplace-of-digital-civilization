## 1. 目标

把观察质量诊断事实转成通用父需求裁决：

```text
父需求需要深度 / 空间坐标 -> 质量不足可能成为硬阻塞或软阻塞。
父需求只需要颜色 / 像素回查 -> 质量不足只作为旁路补救或失败归因。
父需求允许降级继续 -> 继续执行可用分支，同时派生高优先级质量提升需求。
父需求不允许降级继续 -> 等待质量提升子需求。
```

该裁决由父需求筹办 / 重筹办完成，不由 S1、不由子任务、不由任务执行决定。

## 2. 输入事实

任务筹办读取通用事实，不读取具体方法名：

```text
父需求.所需观察特征集合
父需求.降级继续允许状态
父需求.当前步骤硬前置特征集合

当前观察帧.基础像素事实可用状态
当前观察帧.颜色观察质量状态
当前观察帧.深度观察质量状态
当前观察帧.空间坐标观察质量状态
当前观察帧.空间类后续处理适用状态
当前观察帧.风险判断适用状态
当前观察帧.存在确认适用状态
当前观察帧.质量缺口状态
当前观察帧.质量缺口原因集合

世界树中已有观察质量改善因果路径
世界树中观察质量改善未知路径缺口
```

## 3. 父需求继续策略

```text
父需求.继续策略 == 等待子需求
父需求.继续策略 == 降级继续
父需求.继续策略 == 并行补救
```

裁决规则：

```text
硬阻塞：
    父需求必须依赖深度 / 空间坐标；
    当前深度观察质量状态 == 不足 或 空间坐标观察质量状态 == 不足；
    父需求.降级继续允许状态 == 否；
    -> 父需求.继续策略 == 等待子需求。

软阻塞：
    父需求依赖深度 / 空间坐标，但允许低置信或局部降级；
    -> 父需求.继续策略 == 降级继续。

旁路补救：
    父需求不依赖深度 / 空间坐标；
    当前帧仍可满足颜色 / 像素 / 二维复现类目标；
    -> 父需求.继续策略 == 并行补救。
```

父需求继续策略是父任务筹办结果，不是子任务属性。

## 4. 派生需求目标

质量提升需求不得指向旧观察帧：

```text
禁止：
    当前观察帧.深度有效率 大于 最低深度有效率
    当前观察帧.空间坐标有效率 大于 最低空间坐标有效率
```

应指向新材料：

```text
新观察材料.深度有效率 大于 最低深度有效率
新观察材料.空间坐标有效率 大于 最低空间坐标有效率
```

或按实际因果路径细化为：

```text
后续观察帧.深度有效率 大于 最低深度有效率
后续观察帧.空间坐标有效率 大于 最低空间坐标有效率

融合观察帧.深度有效率 大于 最低深度有效率
融合观察帧.空间坐标有效率 大于 最低空间坐标有效率

目标区域观察材料.深度有效率 大于 最低深度有效率
目标区域观察材料.空间坐标有效率 大于 最低空间坐标有效率
```

## 5. 已知路径和未知路径

```text
已有观察质量改善因果路径：
    生成对应派生需求消息；
    生成类型 = 条件补齐 / 促成；
    优先级 = 高；
    来源因果 = 观察质量不足影响父需求所需特征。

没有已有改善因果路径：
    生成观察质量改善路径学习需求；
    目标可为 观察质量改善路径验证状态 等于 已验证；
    学习对象是如何获得更好观察材料，不是修正旧帧。
```

