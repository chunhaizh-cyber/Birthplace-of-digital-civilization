## 1. 目标

```text
校验当前观察帧的基础观察事实是否完备；
写入 当前观察帧.观察事实完备状态 等于 已完备。
```

观察事实完备只包含像素覆盖、像素特征值承接、坐标回查和帧内编号回查等事实承接条件；不包含质量可用、新鲜度或基础风险判断。

## 2. 输入与输出

输入：

```text
当前观察帧
像素覆盖状态
像素特征值承接状态
坐标回查可用状态
帧内编号回查可用状态
前置动作动态列表
```

输出：

```text
观察事实完备状态 = 已完备 / 条件不足 / 待补齐
完备性失败条件数量
完备性失败原因摘要
动作动态 / 来源动态证据
```

```text
本能方法类.h

```

`本能方法类.*` 只允许登记 `自我_校验观察事实完备性` 一个方法。

## 4. 禁止越界

```text
不得把质量可用或新鲜度混入观察事实完备；
不得把观察事实完备写成基础观察事实可用；
不得写 基础风险判断状态；
不得通过任务管理线程直接写需求树。
```

## 5. 实施步骤

```text
C1 先检查是否已有等价方法头和动作入口；没有则只登记本方法。
C2 读取像素覆盖、像素特征值承接、坐标回查和帧内编号回查状态。
C3 逐项记录缺失条件和来源动作动态。
C4 当且仅当前置全部成立时写 观察事实完备状态=已完备。
C5 日志输出失败条件数量和具体缺口。
```

## 6. 验收

```text
Debug x64 构建通过；
真实日志中 自我_校验观察事实完备性 有动作动态；
缺像素覆盖、特征承接或回查能力时不能写 已完备；
观察事实完备状态不包含质量、新鲜度或风险结论；
最新运行段没有 基础风险判断状态=已明确。
```
