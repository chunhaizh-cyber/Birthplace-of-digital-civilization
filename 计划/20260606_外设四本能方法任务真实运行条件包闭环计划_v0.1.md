# 20260606_外设四本能方法任务真实运行条件包闭环计划_v0.1

## 1. 目标

让四个自我外设本能方法不只注册和被候选召回，而是能够通过统一任务生命周期真实运行：

```text
需求目标
    -> 任务创建
    -> 任务筹办选择当前方法
    -> 缺外设材料时生成等待项
    -> 外设线程产出报告 / 材料
    -> 任务管理承接并装配方法条件包
    -> 任务重入执行当前方法
    -> 方法写正式结果和方法动作动态
    -> 提交入口按来源动作动态入账
```

四个目标方法：

```text
6127 自我_验证外设观察像素簇候选
6145 自我_识别外设观察材料
6146 自我_扫描已识别区域
6147 自我_跟踪指定存在
```

## 2. 当前问题

最新真实日志和代码对账显示，当前不是“外设完全不能供料”，而是“外设材料没有闭合成任务可消费的条件包”。

具体堵点：

```text
1. 6127 / 6145 的形式参数闭合不等于语义条件满足。
   日志里 required=0 / missing=0，但方法执行仍因缺 D455 逐簇识别报告或稳定复现状态失败。

2. 外设线程能生成逐簇识别报告、扫描变化报告、跟踪报告，
   但报告匹配等待项、承接请求、条件事实写回、任务重入执行没有稳定贯通。

3. 任务派发会被派生需求邮箱待落账暂停，
   外设报告承接不能依赖普通任务派发后才偶然发生。

4. 扫描和跟踪不是裸外设报告可直接启动。
   扫描必须已有稳定对应存在 / 基准 / 目标区域；
   跟踪必须已有目标存在 / 目标种子 / 观察窗口 / 跟踪基准。

5. 外设内部材料字段已经被禁止入普通需求树。
   后续不能再把像素坐标、ROI、目标簇、材料句柄、方法动作数量等内部字段派生为子需求。
```

## 3. 边界

必须遵守：

```text
外设线程只负责看、动、报。
外设报告只作为材料、回查索引和条件来源。
任务管理负责等待项、报告匹配、承接请求和任务重入。
自我方法负责把材料转换为正式存在、特征、二次特征、状态动态。
提交入口负责正式入账和来源动作动态串接。
```

禁止：

```text
外设线程直接写需求树；
外设线程直接写世界树真值；
外设报告直接满足安全 / 服务 / 需求完成；
恢复任务筹办 / 任务执行为本能方法；
新增模拟测试、伪造样本、伪造入口或 --*-check 回归命令；
把内部材料字段重新放回需求树。
```

## 4. 条件包定义

这里的条件包不是新主结构。它是任务管理承接外设报告后，对既有方法输入场景、宿主事实、输出结果场景、回查材料索引的最小装配结果。

### 4.1 6127 观察验证条件包

来源：

```text
D455 逐簇识别报告
D455 短期观察材料页
原始帧 / 深度帧 / 空间候选 / 像素归属账本 / 簇材料回查句柄
```

装配后应能支持：

```text
外设观察材料可回查状态
外设像素簇候选验证状态
外设观察像素簇候选已验证状态
当前观察范围有效可观测单位计数事实
```

### 4.2 6145 识别条件包

来源：

```text
已验证的逐簇识别报告
观察稳定复现状态
观察完成状态
可复验状态
跨帧同一性证据
外设观察存在候选确认方案
```

装配后应能支持：

```text
外设观察存在_自我存在同一性状态
外设观察存在自我归属状态
归属目标
扫描可启动状态
当前观察范围可观测单位存在对应事实
```

### 4.3 6146 扫描条件包

来源：

```text
已归属存在
当前观察材料集
上一轮 / 基准观察材料集
目标区域或稳定对应存在范围
D455 扫描变化报告
```

装配后应能支持：

```text
首次扫描发现存在 / 发现特征事实
已归属存在当前特征_基准特征差异状态
已识别区域扫描入账状态
存在特征变化动态
无变化时只续写基准和稳定计数，不提交变化动态
```

### 4.4 6147 跟踪条件包

来源：

```text
已确认目标存在
目标种子
目标观察窗口
跟踪基准特征
预测区间
D455 跟踪报告
```

装配后应能支持：

```text
目标存在跟踪状态
跟踪预测区间状态
跟踪区间迁移状态
目标存在丢失状态
目标存在重捕获状态
目标存在区间迁移动态
```

## 5. 实施切片

### P9a：报告承接与条件包装配对账

目标：

```text
确认等待项匹配、报告读取、承接请求、任务重入和方法输入写回的真实代码路径。
```

检查点：

```text
1. 对账 任务管理等待项集合、按等待项匹配外设观察报告、任务管理外设消息承接_处理一次。
2. 对账 自我线程派生需求邮箱待落账时，外设报告承接是否仍有机会运行。
3. 对账 6127 / 6145 / 6146 / 6147 方法体实际读取的条件事实与当前等待项输出是否一致。
4. 写实施记录，列出缺哪一个写点，而不是泛称“条件不足”。
```

验收：

```text
得到四方法条件包字段对照表；
确认最小代码接入点；
未修改业务代码可不构建；
不得生成新的材料字段子需求。
```

### P9b：外设报告承接先行与任务重入

目标：

```text
让外设报告承接不被普通任务派发暂停长期饿死。
```

修改方向：

```text
1. 在任务派发暂停前，允许外设等待项巡检和报告承接先执行一个安全步。
2. 承接只处理已存在等待项和外设报告，不直接创建需求树子节点。
3. 承接完成后给对应任务留下可重入执行的回执或条件事实。
4. 日志必须区分“报告已承接”和“任务已执行方法”。
```

验收：

```text
真实日志出现：
    外设等待项命中；
    D455 报告匹配；
    观察事实承接请求生成；
    对应任务重入筹办 / 执行。
```

### P9c：6127 观察验证真实运行

目标：

```text
让 自我_验证外设观察像素簇候选 通过任务真实拿到逐簇识别报告并执行。
```

修改方向：

```text
1. 当前方法为 6127 且缺逐簇识别报告时，任务管理生成观察验证等待项。
2. D455 逐簇识别报告匹配等待项后，承接为 6127 写入报告 ID 和材料回查条件。
3. 6127 执行后写外设观察材料可回查状态、外设像素簇候选验证状态和方法动作动态。
```

验收：

```text
真实日志能看到：
    当前本能ID=6127；
    缺少D455逐簇识别报告 不再是最终停点；
    外设像素簇候选验证状态 或 外设观察材料可回查状态 被写入；
    不出现像素坐标 / ROI / 材料句柄入普通需求树。
```

### P9d：6145 识别真实运行

目标：

```text
让 自我_识别外设观察材料 在观察验证和稳定复现事实具备后通过任务执行。
```

修改方向：

```text
1. 将 6127 输出的候选验证结果接到 6145 的前置条件。
2. 将稳定复现、观察完成、可复验状态写到 6145 能读取的宿主或输入场景。
3. 6145 成功后写同一性状态、归属状态、归属目标和扫描可启动状态。
4. 观察未达标时只派生正式观察状态缺口，不派生外设内部材料字段。
```

验收：

```text
真实日志能看到：
    当前本能ID=6145；
    识别条件不足:外设观察存在未稳定复现或不可复验 不再是最终停点；
    外设观察存在自我归属状态=已归属 或 证据不足 / 冲突 的正式结果；
    来源动作动态能串接到后续提交入口。
```

### P9e：6146 扫描真实运行

目标：

```text
让 自我_扫描已识别区域 只在已有稳定对应存在后通过任务执行。
```

修改方向：

```text
1. 识别写出已归属和扫描可启动状态后，任务筹办能生成扫描等待项。
2. 等待项必须携带稳定对应存在范围、目标区域或可回查基准，不允许裸扫描。
3. D455 扫描变化报告匹配后，承接为 6146 写当前 / 历史观察材料和基准事实。
4. 首次扫描只写发现存在或发现特征事实；无变化不提交变化动态；有变化才生成状态信息。
```

验收：

```text
真实日志能看到：
    当前本能ID=6146；
    扫描等待项有明确目标区域或稳定对应存在；
    首次扫描不被误判为变化；
    无变化时不写存在特征变化动态；
    有变化时写正式状态信息和来源动作动态。
```

### P9f：6147 跟踪真实运行

目标：

```text
让 自我_跟踪指定存在 只在已有目标存在、目标种子、窗口和基准后通过任务执行。
```

修改方向：

```text
1. 从识别 / 扫描结果中形成合法跟踪目标种子。
2. 跟踪等待项必须携带目标存在、观察窗口和基准条件。
3. D455 跟踪报告匹配后，承接为 6147 写跟踪报告、目标窗口、预测区间和基准事实。
4. 缺目标 / 缺窗口 / 缺基准时，只派生正式目标特征缺口。
```

验收：

```text
真实日志能看到：
    当前本能ID=6147；
    跟踪等待项有目标种子；
    目标存在跟踪状态、预测区间状态、丢失 / 重捕获 / 区间迁移状态至少一种正式结果；
    跟踪不替代全场扫描或全场明确。
```

## 7. 暂停条件

出现以下情况必须暂停并回到计划修订：

```text
1. 条件包必须新增主信息结构才能表达，且无法由既有特征 / 场景 / 回查索引表达。
2. 外设线程必须直接写需求树或世界树真值才能推进。
3. 扫描或跟踪没有目标存在 / 基准 / 种子，却被实现成裸运行。
4. 方法动作动态无法绑定到四个自我方法或提交入口。
5. 真实运行只能靠模拟样本、伪造入口或 --*-check 才能通过。
```
