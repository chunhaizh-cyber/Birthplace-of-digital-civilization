# 20260618 项目功能函数去重与无效代码清理计划 v0.1

## 0. 目标

按既有函数清单和项目规范，审计项目中的重复定义函数、无调用函数、无效壳函数和旧兼容代码，逐步删除或改为调用唯一正式函数。

本计划不以函数名相同作为删除依据；只有在调用证据、语义等价证据、项目结构闭环证据和构建验证均闭合后，才允许进入删除切片。

```text

```

关键约束：

```text
1. 规范优先于计划；计划优先于临时推断。
2. 新建、删除或改名函数后必须重新运行 tools/生成函数功能说明文档.py。
3. 全局共享函数类.ixx 只放不依赖项目自定义数据类型头文件的通用函数。
4. 涉及语素、基础信息、主信息类等自定义类型的共享函数必须放回对应功能类或对应头文件。
5. 禁止保留兼容旧路径、旧入口、旧字段双写和 fallback。
6. 禁止用文本、日志、注释、临时 JSON 或错误码冒充项目结构闭环。
7. 弹窗 / 逻辑错误路径不得通过删除日志、吞错或降级返回来规避。
```
