## 硬边界

```text
1. 候选不能直接变成存在。
2. 外设线程只供料，不直接写世界树真值。
3. 自我应先产生扫描需求；扫描比较过程中的对应关系、材料质量、当前特征值等缺口只能作为结构化需求来源。
4. 观察 / 识别需求应由扫描缺口经需求树和任务筹办派生，不得把观察需求当根起点。
5. 观察仍是候选变为自我所在场景存在的事实闸门。
6. 候选入账必须经过需求任务链、任务管理等待项、观察事实承接、候选验证、候选确认和提交_确认观察存在事实。
7. 不得用 --d455-capture-once 的材料包证据卡冒充场景存在入账。
8. 不得把历史日志中曾经入账成功冒充当前数据库最新快照。
9. 外设观察事实承接完成后，不得反向直接确保 6146 / 6147 任务主体。
10. 稳定观察子集不得反向直接生成“稳定子集全量扫描等待项”或扫描入账派生需求。
11. 执行链条必须由任务筹办查询因果关系建立；扫描缺口后续是否派生观察、识别、跟踪或再扫描，只能由需求树、任务筹办和方法选择决定。
12. 中间层不能省略。观察、识别、扫描、跟踪只能消费中间层 / 外设侧已经提交到队列、报告、材料页或合法数据集中的结果；不得由自我本能方法在执行体内直接调用中间层函数来现场造材料。
13. 如果观察或扫描缺少中间层数据，应生成结构化缺口、等待项、订阅项或任务输入缺口，由任务管理和外设 / 中间层队列后续补齐；不得用“被动动作”把中间层函数直连进观察或扫描本能函数内部。
14. 中间层内部 L0-L3 数据生产链允许用被动动作自动串联；该链路只负责把原始帧推进为稳定观察子集、报告队列、材料页和稳定缓存，不走普通需求 / 任务 / 方法筹办，也不生成自我可主动调用方法。
15. 中间层可提供跨帧信息作为识别证据；但观察函数一次次运行，不应靠传入“上次观察存在”来续接对象，否则会滑到跟踪。观察应通过识别把本次观察材料关联到场景中的存在。
16. 识别需要双入口：`6145 自我_识别外设观察材料` 保留为主动本能方法；观察每次运行必需的识别不能再走主动任务筹办，必须由观察内部的被动识别治理闭环完成，返回值只能是已有存在指针或空指针。
17. 观察发现并经自我验证链确认的存在只能写在自我所在场景子链上；观察帧、输出结果场景、集合引用或统计摘要只能保存来源证据和索引，不能替代场景存在节点。
```

## 中间层取数口径纠偏

```text
废止口径：
    6085 观察函数发现缺少当前观察特征帧 / 空间候选账本时，
    在函数内部直接调用中间层被动动作函数补齐材料。

原因：
    中间层是数据生产和稳定化层，不是观察 / 扫描本能函数内部的同步子过程。
    观察、识别、扫描、跟踪需要从中间层已经提交的数据队列、报告队列、材料页或合法外设当前数据集中取数。

当前硬口径：
    缺中间层数据 = 任务输入 / 等待项 / 队列供料缺口；
    不等于观察或扫描函数可以直接调用中间层函数。

补充硬口径：
    中间层内部可以走被动动作自动链：
        原始帧 -> 稳定化 -> 跨帧关联 -> 稳定观察子集 -> 报告队列 / 材料页 / 稳定缓存

    该被动动作链不经自我需求树、任务筹办和方法选择；
    也不把 `被动动作` 暴露为普通候选方法。

    自我侧观察 / 识别 / 扫描 / 跟踪只消费该链已经提交的结果，
    不能在本能函数执行体内同步调用中间层函数补料。

代码处理：
    已撤销 6085 内部触发 `被动动作_取得当前观察特征帧` 的路径；
    已恢复空间候选提取链对中间层状态和外设运行状态的筹办前置要求。

后续下钻：
    1. 查中间层 L0-L3 内部数据生成链是否已经自然串到报告队列 / 材料页；
    2. 查该内部链是否有被动动作动态证据或可补的被动动作动态出口；
    3. 查任务管理是否按因果筹办结果创建正确等待项；
    4. 查 D455 / 中间层报告是否被等待项消费；
    5. 查 6085 / 6146 / 6150 是否只从已提交队列和任务输入中取数。
```

## 内部治理记录计数口径

```text
识别、观察、扫描、跟踪都属于内部治理方法。
它们可以涉及现实世界材料，但治理动作结果必须记录在自我内部世界中。

内部治理记录不能只写“运行一次”，必须写结构化结果摘要：
    扫描：
        扫描治理输出状态
        外设数据项总数
        信息缺口数量
        已写入特征数量
        已写入状态动态数量
        扫描状态改变信息数量
        扫描状态变化动作动态数量
        覆盖冲突数量
        视觉观察候选数量
        视觉信息缺口数量

    观察：
        被动识别同一性状态
        被动识别归属状态
        候选确认新建 / 合并 / 冲突 / 证据不足 / 可提交数量
        观察实际新建存在数量
        观察实际更新已有存在数量
        观察实际写入特征数量
        观察治理处理项数量
        观察治理写入失败数量

记录位置：
    自我内部世界 -> 扫描内部治理记录 / 观察内部治理记录。

动作动态：
    内部治理记录生成被动动作动态；
    被动动作动态引用本轮主动方法动作动态作为来源低层动态；
    被动动作不得进入普通主动方法候选或学习为主动方法。

扫描状态改变信息数量：
    由已写入状态动态数量 + 未覆盖状态信息数量得到；
    用于记录本轮扫描发现的状态改变 / 异常状态线索条数，
    首次建立基准不计入变化。
```
