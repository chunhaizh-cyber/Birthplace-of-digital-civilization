```text
父计划：计划/20260526_基础观察事实与基础风险判断分层实施计划_v0.1.md
```

## 1. 目标

```text
从当前观察特征帧建立当前观察帧存在；
写入 自我所在场景.当前观察帧存在状态 等于 已建立；
优先补入 当前观察帧.观察帧容器状态 等于 已建立。
```

该方法只证明观察帧容器成立，不证明像素覆盖、像素特征值承接、观察事实完备、质量可用、新鲜或基础风险已明确。

## 2. 输入与输出

输入：

```text
双目相机_取得当前观察特征帧 的动作动态
当前观察特征帧
自我所在场景
来源外设
帧宽度 / 帧高度 / 彩色帧号 / 深度帧号
预期像素数量
```

输出：

```text
当前观察帧存在
当前观察帧.观察帧容器状态 = 已建立 / 条件不足
自我所在场景.当前观察帧存在状态 = 已建立 / 条件不足
创建动作动态状态 = 已记录
```

## 4. 禁止越界

```text
不得把 当前观察帧存在状态 已建立 当成 像素覆盖 已覆盖；
不得把 当前观察帧存在状态 已建立 当成 观察事实完备 已完备；
不得写 基础观察事实可用状态；
不得写 基础风险判断状态。
```

## 5. 实施步骤

```text
F1 复核方法登记、派发和当前观察特征帧输入读取。
F2 建立或定位当前观察帧存在，写入来源外设、帧宽、高、帧号、预期像素数量。
F3 写入观察帧容器状态和当前观察帧存在状态，并绑定创建动作动态。
F4 缺帧宽、高、帧号、来源外设或动作动态时返回条件不足，不写 已建立。
F5 控制面板只展示容器状态，不把它折叠成基础事实可用。
```
