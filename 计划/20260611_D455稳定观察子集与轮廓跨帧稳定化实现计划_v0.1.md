# D455 稳定观察子集与轮廓跨帧稳定化实现计划 v0.1

更新时间：2026-06-12

## 1. 目标

解决真实 D455 静止画面下逐簇识别候选 / 轮廓集合跨帧波动的问题，使任务管理和自我提交入口优先消费“稳定观察子集”，而不是把每帧原始逐簇候选直接当成可进入正式识别 / 扫描 / 跟踪的材料。

本计划不追求让相机原始每帧轮廓完全一致。工程目标是：

```text
外设线程持续供给原始观察材料；
外设线程内部维护跨帧候选轨迹；
队列中区分原始材料报告与稳定子集报告；
任务管理只把稳定子集报告推进到观察事实承接 / 提交入口；
原始材料仍可回查、可诊断、可过期清理，但不直接成为正式认知事实。
```

总体架构按五层收束：

```text
L0 原始帧层：
    RGB / Depth / IR / aligned depth。

L1 深度与掩码稳定化层：
    RealSense 后处理、形态学处理、孔洞填充、面积阈值、轮廓简化。

L2 跨帧关联层：
    外设观察轨迹、中心 / 面积 / 深度 / 轮廓 / 掩码关联、预测和匹配。

L3 稳定观察子集层：
    连续命中、连续丢失宽限、误差方差稳定、特征值域初步形成。

L4 自我认知承接层：
    观察写新特征，识别定唯一，扫描比较变化，跟踪判断动态连续性。
```

其中 L0-L3 属于 D455 外设侧，L4 属于自我侧。RealSense / OpenCV / 跟踪 / SLAM / TSDF / VOS 只能作为外设内部稳定化和供料技术，不作为自我识别世界存在的直接入口。

## 4. 问题定义

真实日志已显示连续 D455 报告中：

```text
簇数量在 14 / 15 / 16 / 18 等值间波动；
跨帧稳定簇、丢失簇、新建簇数量持续变化；
报告质量为优质不等于候选轮廓集合稳定。
```

因此当前堵点不是“没有真实 D455 报告”，而是：

```text
报告生产已经恢复；
但原始逐簇报告仍带有相机分割抖动；
质量门没有把跨帧稳定性作为正式承接前置；
6150 / 扫描 / 跟踪仍可能拿到未稳定的原始候选集合。
```

正式修订后，质量判断必须拆成：

```text
单帧材料质量等级 == 优质
跨帧稳定质量等级 == 优质
外设观察存在提交状态 == 可提交
```

原始簇只能证明单帧分割结果；候选簇只能证明单帧质量门已过；稳定外设观察存在才证明跨帧关联和值域初步稳定；可提交观察材料才允许进入任务管理承接和自我侧正式链。

## 5. 硬边界

```text
1. 外设线程只供材料、轨迹摘要、稳定子集报告，不直接写世界树真值。
2. 稳定子集报告仍是外设观察材料，不是已确认观察存在。
3. 任务管理只负责匹配等待项、质量门控和生成承接请求，不直接结算需求满足。
4. 提交入口仍是正式入账边界。
5. 原始逐帧材料允许入队、可回查、可诊断，但不得作为 当前场景特征值明确状态 或 需求满足 的直接证据。
6. 不新增模拟样本、夹具入口、伪造报告或伪动作动态。
7. 不把采集、滤波、分割、跟踪、稳定化登记成新的自我层本能方法。
8. 不把任务筹办 / 任务执行恢复为本能方法。
```

## 6. 特征调整准入

允许为适配稳定观察子集口径，适当调整、增加或停用现有存在特征，但只限于表达机器判断必需的事实，不增加说明性摘要字段。

准入顺序：

```text
1. 优先复用已有特征：
    外设观察报告ID；
    外设观察像素簇ID；
    外设跨帧簇ID；
    跨帧匹配状态；
    跨帧连续命中次数；
    跨帧复现离散度；
    映射稳定性状态；
    稳定对应存在数量；
    扫描可启动状态。

2. 若现有特征无法表达 L0 / L1 口径，可新增最小特征：
    观察材料层级；
    稳定观察子集状态；
    稳定观察子集来源原始报告ID；
    稳定观察子集来源外设帧ID；
    稳定观察子集簇数量；
    轨迹稳定状态；
    轨迹丢失宽限状态。

3. 若现有特征把 原始材料可用 与 稳定可承接 混成一个机器判断含义，应停用该机器判断用途，或拆成明确的 L0 材料可回查状态 与 L1 稳定可承接状态。
```

禁止：

```text
1. 不在 特征值主信息类 中新增坐标 / 轮廓专用存储类型。
2. 不把报告、材料页、帧或队列项写成世界真值主体。
3. 不新增“原因摘要 / 说明文本 / 口径说明”作为机器判断字段。
4. 不用新旧字段双写做兼容过渡；当前机器判断只能指向唯一正式特征。
5. 不把 L0 原始材料状态当作 当前场景特征值明确状态、需求满足、安全值或服务值证据。
```

特征落点：

```text
外设观察存在 / 观察材料集：
    可记录 L0 原始材料可回查状态、来源报告ID、来源外设帧ID、跨帧簇ID和材料层级。

稳定观察子集项：
    可记录 L1 稳定观察子集状态、轨迹稳定状态、连续命中、复现离散度、丢失宽限状态和来源 L0 报告ID。

当前观察范围可观测单位存在对应事实：
    只记录稳定对应数量、未稳定数量、冲突数量、映射稳定性状态和扫描可启动状态。
```

### P5 扫描 / 跟踪消费稳定子集

目标：

```text

扫描基准不得使用未稳定 L0 原始簇集合；
```

扫描输入收束为：

```text

上一轮基准

```

```text

当前轨迹预测
目标窗口
特征值域
预测区间
```

跟踪不写新一阶特征值。低置信候选只用于重捕获和轨迹恢复，不能直接写成跟踪成功事实。

验收：
