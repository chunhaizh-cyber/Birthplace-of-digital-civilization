## 1. 背景

最新真实运行日志显示，当前主需求反复落在：

```text
E = 当前交互者明确状态
```

现有链路表现为：

```text
当前交互者明确状态
-> 生成任务
-> 任务筹办无既有候选方法
-> 创建占位方法头
-> 派生泛化学习信息补齐需求
-> 学习信息补齐任务无承接方法
-> 禁止递归派生同类学习缺口
-> 等待
```

这暴露的问题不是需求树不能生长，也不是任务不能生成，而是无路径 / 无方法时过早进入占位方法头和复杂学习缺口，导致主线被学习链反向拖住。

## 2. 当前口径

```text
1. 当前交互者明确状态不优先用本能方法实现。
2. 当前交互者属于服务上下文 / 观察事实 / 会话事实；已有事实则满足，没有事实则等待。
3. 当前阶段不要把无方法问题扩展成复杂学习系统。
4. 任务筹办主线应为：查路径 -> 查方法 -> 无路径且无方法则挂起。
5. 挂起后调度继续处理其他任务，不让单个无方法需求长期占住主动推进。
6. 只有已经存在明确路径或明确方法，并暴露具体缺口时，才讨论后续补齐；复杂学习方法后置。
```

## 3. 规范同步前置

当前以下规范仍保留旧口径：

```text
规范/任务筹办按方法能力查找到就绪因果链规范20260513.md
    无既有候选方法路径中仍要求创建面向目标特征的占位方法头。

规范/任务筹办父方法与协作子方法链规范20260513.md
    普通可任务化叶子任务仍写有新建目标方法头后待重筹办口径。
```

因此代码执行前必须先完成规范口径同步：

```text
无路径 / 无候选方法不是失败；
也不自动创建占位方法头；
第一版只返回明确挂起回执：
    路径未找到；
    方法未找到；
    等待事实 / 外部输入 / 后续学习机制；
    调度可继续其他任务。
```

若暂不修订规范，则不得推进代码实现，只能停在本计划。

## 4. 实施切片

### P0 规范口径同步（已完成）

目标：

```text
把“无候选即创建占位方法头”的旧口径改为“无路径 / 无方法则挂起”。
明确当前交互者明确状态不登记专用本能方法，不通过占位方法头伪装成已有方法。
```

验收：

```text
相关规范不再要求普通任务在无候选时创建占位方法头；
任务筹办仍必须先完整查路径、查方法；
任务筹办 / 任务执行仍不是本能方法。
```

### P1 当前交互者明确状态事实路径收口

目标：

```text
确认当前交互者明确状态的事实来源顺序：
    当前服务上下文；
    当前会话 / 控制面板交互上下文；
    已提交观察事实或外部输入事实。
```

规则：

```text
已有当前交互者事实：
    回写需求满足。

无当前交互者事实：
    任务挂起，缺口为“当前交互者事实缺失”或“无可用确认路径”。
```

禁止：

```text
不新增 当前交互者明确 本能方法；
不创建占位方法头；
不派生泛化学习信息补齐需求；
不伪造交互者事实。
```

### P2 任务筹办无路径 / 无方法挂起

目标：

```text
任务筹办对普通可任务化目标按顺序处理：
    1. 查既有因果 / 方法路径；
    2. 查既有候选方法；
    3. 无路径且无方法时形成挂起回执。
```

挂起回执至少包含：

```text
来源需求；
任务；
目标宿主；
目标特征；
当前状态；
目标状态；
路径查找结果；
候选方法数量；
挂起原因。
```

验收：

```text
无候选时不出现“按需求目标创建占位方法头”；
不新增泛化学习信息补齐子需求；
父任务进入等待 / 挂起状态；
调度继续推进其他可执行任务。
```

### P3 学习逻辑降级为等待边界

目标：

```text
当前阶段学习逻辑只承认最小边界：
    有目标方法头 -> 查既有路径；
    无路径 -> 查既有方法；
    无方法 -> 挂起。
```

后置内容：

```text
如何学习新动作入口；
如何生成条件结果对；
如何设计探索参数；
如何形成新方法。
```

这些不作为本计划执行目标。

### P4 调度与日志可观测性

目标：

```text
让日志能明确回答：
    当前任务是否因无路径 / 无方法挂起；
    是否错误创建了占位方法头；
    是否错误派生了泛化学习需求；
    调度是否继续推进其他任务。
```

验收：

```text
E 需求无事实来源时显示挂起；
其他可执行任务仍能筹办 / 执行 / 回写；
摘要和控制面板只作为只读诊断，不作为业务验收来源。
```
