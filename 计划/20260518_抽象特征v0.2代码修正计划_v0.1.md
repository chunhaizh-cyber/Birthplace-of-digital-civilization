## 1. 总目标

把当前代码中的抽象特征实现，从旧的：

```text
抽象特征 = 类型 + I64 区间 + 组合规则 + 命中统计
```

修正为规范 v0.2 的：

```text
叶子抽象特征 = 名称 + 类型 + 明确值域 + 粗粒度来源
复合抽象特征 = 名称 + 类型 + 子特征结构 + 粗粒度来源
```

其中：

```text
复合抽象特征只表达组成结构；
复合抽象特征的直接子节点只能是组成子特征；
关系、比较、推导、状态判断，全部由二次特征或外部匹配 / 因果逻辑表达。
```

## 2. 当前代码偏差

### D1. 抽象特征主信息仍以 I64 区间为核心值域

当前位置：

```text
基础信息主信息类.h
抽象特征主信息类::区间
```

偏差：

```text
规范要求叶子抽象特征使用 特征值域；
值域可以是空值、空集合、I64 值域项集、VecU 句柄值域、指针句柄抽象目标值域。
当前只能表达 std::optional<I64区间>。
```

### D2. 抽象特征缺少显式叶子 / 复合形态

当前位置：

```text
基础信息主信息类.h
抽象特征主信息类
```

偏差：

```text
规范要求显式字段：
    枚举_抽象特征形态::叶子
    枚举_抽象特征形态::复合

不能靠“有没有子节点”推断形态。
```

### D3. 组合规则仍存放在抽象特征主信息中

当前位置：

```text
抽象特征主信息类::组合规则
特征类.cpp::求值组合抽象特征
特征类.cpp::初始化常用抽象特征
```

偏差：

```text
规范明确：
    复合抽象特征不是规则集合；
    不做任意命中、至少 N 个、按权重匹配；
    复合抽象特征只做命名结构组成匹配。

当前代码中的 组合规则 / 全部命中 / 任一命中 / 最少命中数
应迁出抽象特征本体，后续转入二次特征、条件模板或外部策略。
```

### D4. 命中统计 / 升格时间仍作为抽象特征本体字段使用

当前位置：

```text
特征类.cpp::解析实例特征命中抽象特征
特征类.cpp::升格当前稳态为抽象区间
```

偏差：

```text
规范要求：
    来源实例特征可以作为粗溯源保留；
    重叠命中次数、最近命中时间、升格时间不属于抽象特征本体；
    细粒度统计、升格记录应进入归纳器、统计表或因果 / 动态系统。
```

当前主信息类里相关字段已被注释，但调用点仍写入：

```text
重叠命中次数
最近重叠命中时间
升格时间
```

这说明代码和头文件状态已经不一致，需要统一处理。

### D5. 匹配逻辑仍是“类型 + 区间”口径

当前位置：

```text
特征类.cpp::枚举命中抽象状态
特征类.cpp::解析实例特征命中抽象特征
```

偏差：

```text
规范要求：
    叶子匹配 = 名称一致 + 类型一致 + 实例值命中值域 + 比较策略确认合法；
    复合匹配 = 名称一致 + 类型一致 + 所有声明子特征按名称递归匹配。

当前代码未按名称槽位匹配，也未按 特征值域 匹配。
```

### D6. 指针句柄值域尚未表达“抽象目标匹配”

偏差：

```text
规范要求 指针句柄值域 表达：
    当前指针句柄指向的具体目标
    必须匹配某个允许目标抽象。

不得把指针句柄值域理解为裸地址集合。
```

当前代码尚无对应 `指针句柄值域::允许目标抽象` 与匹配器。

### D7. 世界树包装接口仍暴露旧抽象特征能力

当前位置：

```text
世界树类.h / 世界树类.cpp
取或创建抽象特征_按类型
升格实例稳态为抽象区间
求值组合抽象特征
```

偏差：

```text
这些接口仍把抽象特征理解为按类型 / 区间 / 组合规则管理。
需要迁移为叶子 / 复合创建、结构校验和值域匹配接口。
```

## 3. 不改动边界

本计划不处理：

```text
1. 二次特征的 方向区间 / 差值 字段。
   这两个字段按最新口径保留：
       方向区间 = 三大比较方向内部的量域细分；
       差值 = 多次特征和距离 / 余量类关系的材料。

2. 三态比较协议本身。
   三态比较协议不是数据结构，不进入抽象特征主信息类。

3. 状态转换因果树与目标投影结算链。
   该部分继续由 060005 相关计划推进。
```

## 4. 修正步骤

### P0. 编译现状确认

执行：

```powershell
msbuild .\鱼巢.vcxproj /p:Configuration=Debug /p:Platform=x64 /p:LinkIncremental=false /m
```

目标：

```text
确认当前基线是否可编译。
若当前已不可编译，先记录错误，不进入字段迁移。
```

### P1. 引入抽象特征值域类型

在主信息或特征值相关公共头文件中新增：

```cpp
enum class 枚举_抽象特征形态 : std::uint8_t {
    叶子,
    复合
};

struct 空值值域 {};
struct 空集合值域 {};

using I64值域项 = std::variant<I64, I64区间>;

struct I64值域 {
    std::vector<I64值域项> 项集{};
};

struct VecU句柄值域 {
    std::vector<VecU句柄> 允许句柄{};
};

struct 指针句柄值域 {
    std::vector<可解析引用<基础信息节点类>> 允许目标抽象{};
};

using 特征值域 = std::variant<
    空值值域,
    空集合值域,
    I64值域,
    VecU句柄值域,
    指针句柄值域
>;
```

说明：

```text
第一版可复用当前工程已有 I64区间 类型，避免同时改动全局区间表示。
若后续必须使用 optional 上下界版 I64区间，应单独开“区间类型迁移计划”。
```

### P2. 修订抽象特征主信息类

目标结构：

```cpp
class 抽象特征主信息类 : public 基础信息基类 {
public:
    词性节点类* 名称 = nullptr;
    词性节点类* 类型 = nullptr;

    枚举_抽象特征形态 形态 = 枚举_抽象特征形态::叶子;

    std::optional<特征值域> 值域{};

    std::vector<可解析引用<基础信息节点类>> 来源实例特征{};

    bool 是叶子特征() const noexcept;
    bool 是复合特征() const noexcept;
    bool 校验结构() const noexcept;
    const 特征值域* 取值域() const noexcept;
    void 设为叶子特征(特征值域 新值域);
    void 设为复合特征();
};
```

处理：

```text
1. 删除或废弃 抽象特征主信息类::区间。
2. 删除或废弃 抽象特征主信息类::组合规则。
3. 保留 来源实例特征 作为粗溯源。
4. 不恢复 重叠命中次数 / 最近重叠命中时间 / 升格时间。
```

### P3. 新增叶子 / 复合创建接口

新增接口：

```cpp
抽象特征节点类* 创建叶子抽象特征(
    基础信息节点类* 父,
    const 语素入口节点类* 名称,
    const 语素入口节点类* 类型,
    特征值域 值域);

抽象特征节点类* 创建复合抽象特征(
    基础信息节点类* 父,
    const 语素入口节点类* 名称,
    const 语素入口节点类* 类型);
```

旧接口处理：

```text
创建抽象特征_按类型
取或创建子抽象特征_按类型
```

第一步可改成兼容包装，但必须明确：

```text
按类型创建不再足以表达复合槽位；
新代码必须使用 名称 + 类型 + 形态。
```

### P4. 增加抽象特征子链校验

实现：

```cpp
bool 校验抽象特征子链(const 基础信息节点类* 节点);
```

规则：

```text
1. 只有复合抽象特征允许把直接子节点解释为组成子特征。
2. 复合抽象特征的直接子节点必须全是抽象特征。
3. 直接子特征必须有名称和类型。
4. 同一父复合特征下，子特征名称默认唯一。
5. 注释、来源、因果、调试、统计、缓存，不允许作为复合抽象特征直接子节点。
```

### P5. 实现叶子抽象特征匹配

新增或替换：

```cpp
bool 匹配叶子抽象特征(
    const 抽象特征主信息类& 抽象,
    const 特征节点主信息类& 实例,
    const 特征比较策略& 比较策略);
```

规则：

```text
1. 名称一致。
2. 类型一致。
3. 抽象为叶子，且有值域。
4. 实例有当前值。
5. 比较策略确认值域和值类型合法。
6. 实例当前值命中值域。
```

其中：

```text
指针句柄值域不得按裸地址匹配；
必须解析当前指针目标，再判断该目标是否匹配允许目标抽象。
```

### P6. 实现复合抽象特征匹配

新增或替换：

```cpp
bool 匹配复合抽象特征(
    const 抽象特征节点类& 抽象节点,
    const 特征节点类& 实例节点,
    const 特征比较策略& 比较策略);
```

规则：

```text
1. 抽象为复合，且无值域。
2. 名称一致。
3. 类型一致。
4. 对每个直接子抽象特征：
       按子特征名称在实例复合特征中查找对应子特征；
       找不到则失败；
       找到后递归匹配。
5. 不支持任意命中 / 至少 N 个 / 权重匹配。
```

### P7. 迁移旧区间命中链路

目标替换：

```text
枚举命中抽象状态
解析实例特征命中抽象特征
升格当前稳态为抽象区间
合并抽象区间
设置实例特征局部区间覆盖
清除实例特征局部区间覆盖
```

迁移方向：

```text
1. 将“抽象区间”改为“叶子抽象特征的 I64值域项”。
2. 将“命中区间”改为“实例值命中特征值域”。
3. 将“升格区间”改为“由实例稳态生成叶子抽象特征值域项”。
4. 停止写抽象特征本体统计字段。
```

### P8. 迁出组合规则逻辑

当前旧逻辑：

```text
特征值差值.不等于零.任一命中
任务是否可执行.全部命中(...)
求值组合抽象特征
```

处理口径：

```text
1. 不再把这些作为抽象特征主信息的组合规则。
2. 属于关系 / 比较 / 推导的部分，迁往二次特征或条件模板。
3. 若短期没有替代实现，不做静默兜底；
   保留旧函数时必须标记为过渡路径，并记录日志或返回不可用。
```

### P9. 更新世界树包装接口

```text
世界树类::取或创建抽象特征_按类型
世界树类::升格实例稳态为抽象区间
世界树类::求值组合抽象特征
```

目标：

```text
1. 新增叶子 / 复合抽象特征包装接口。
2. 旧接口转为兼容层或删除。
3. 不再让世界树接口暴露“组合抽象特征”作为当前口径。
```

## 5. 暂停条件

```text
S1:
如果迁移 I64区间 需要同时改变二次特征、稳态、场景、动态等全局区间表示，
暂停本计划，先拆出“区间值域类型迁移计划”。

S2:
如果当前运行链路仍依赖 组合规则 生成任务可执行判断或关键回归结果，
不得直接删除组合规则。
先确认对应逻辑应迁往二次特征、任务筹办条件判断还是外部策略。

S3:
如果 指针句柄值域 需要抽象存在 / 抽象特征匹配器，但当前代码没有目标匹配入口，
不得退化成裸地址比较。
应先只落结构和日志，暂停正式匹配。

S4:
如果新叶子 / 复合接口与 004 三态比较底层规范或 011001 抽象特征规范冲突，
暂停并修订规范，不继续改代码。
```

## 6. 验收标准

```text
1. 抽象特征主信息类不再以 std::optional<I64区间> 作为唯一值域。
2. 抽象特征主信息类具有明确叶子 / 复合形态。
3. 叶子抽象特征必须有明确 特征值域。
4. 复合抽象特征必须无值域，直接子节点只表示组成子特征。
5. 同一父复合抽象特征下，直接子特征名称默认唯一。
6. 组合规则不再属于抽象特征本体。
7. 重叠命中次数、最近命中时间、升格时间不再写入抽象特征主信息。
8. 叶子匹配按 名称 + 类型 + 值域。
9. 复合匹配按 命名子特征结构递归。
10. 指针句柄值域按抽象目标匹配，不按裸地址集合解释。
11. Debug x64 构建通过。
12. 相关需求树 / 方法候选回归不因抽象特征迁移出现静默兜底。
```
