# 20260605_P1c自我线程学习任务去重键扩展小切片方案_v0.1

## 1. 目标

```text
扩展自我线程学习任务去重键，避免同一目标方法上的不同量化学习缺口互相吞并。

本切片只处理：
    自我线程提交任务发起请求前的同方法活跃学习任务过滤；
    去重键从“派生来源方法”扩展为：
        派生来源方法
        目标主体
        目标特征类型
        满足关系
        目标状态值 / 目标状态主键

本切片不处理：
    任务管理工作线程消息结构；
    三个学习本能结果能力声明；
    方法状态被动因果模板；
    同一条件统计宿主；
    真实日志验证剧本。
```

## 5. 实施步骤

```text
1. 在自我线程同方法学习任务过滤处新增学习缺口去重签名。

2. 签名字段：
       派生来源方法主键；
       目标主体主键；
       目标特征类型主键；
       满足关系；
       目标状态值，若无法读取 I64 值则使用目标状态主键。

3. 只有当前需求和候选需求签名完整且完全一致时，才复用既有活跃学习任务。

4. 如果签名不完整，则不再退回“只按来源方法”粗过滤；
   该需求继续任务化，由后续入树校验、任务筹办和任务管理回执处理。

5. 日志增加当前签名，方便 P5 真实日志验证。
```

## 6. 预测结果

```text
P1c 完成后：
    同一目标方法的 方法动作数量 > 0 与 方法条件结果对数量 > 0
    不会因为来源方法相同而互相吞并；

    同一目标方法的 方法最近连续成功次数 >= 4、
    结果符合次数 >= 4、结果不符合次数 = 0
    在目标特征 / 目标值 / 满足关系不同的情况下也不会互相吞并；

    完全相同量化缺口仍会复用已有活跃学习任务，避免重复任务化。

P1c 完成后仍不会宣称学习闭环完成：
    学习本能结果能力尚未声明量化目标；
    方法状态被动派生链尚未补齐；
    真实日志验证尚未执行。
```
