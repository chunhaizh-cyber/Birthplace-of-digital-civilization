
## 1. 目标

```text
把当前观察特征帧中的颜色、深度有效性、深度值和空间坐标等特征承接到像素观察存在；
写入 当前观察帧.像素特征值承接状态 等于 已完成。
```

该方法不建立像素索引，不判断质量，不判断新鲜度，不直接写基础观察事实可用状态。

## 2. 输入与输出

输入：

```text
自我_建立像素观察事实索引 的动作动态
当前观察帧
像素观察存在集合
颜色数据
深度有效性数据
深度值数据
空间坐标数据，若本阶段要求空间坐标
```

输出：

```text
每个像素观察存在的颜色R/G/B值状态
每个像素观察存在的深度有效性值状态
必要时的深度值状态
必要时的空间坐标值状态
像素特征值承接状态 = 已完成 / 条件不足 / 待补齐
动作动态 / 来源动态证据
失败条件数量和摘要
```

## 4. 禁止越界

```text
不得用像素索引存在替代像素特征值承接；
不得在空间坐标条件不足时写 已完成；
不得写 质量可用状态；
不得写 基础观察事实可用状态；
不得写 基础风险判断状态。
```

## 5. 实施步骤

```text
V1 先检查是否已有等价方法头和动作入口；没有则只登记本方法。
V2 从当前观察帧和像素索引读取像素观察存在集合。
V3 按像素逐项承接颜色、深度有效性、深度值和空间坐标。
V4 汇总缺失、无效和空间坐标条件不足数量。
V5 当且仅当本阶段要求的特征全部承接时写 像素特征值承接状态=已完成。
```

## 6. 验收

```text
Debug x64 构建通过；
真实日志中 自我_承接像素特征值 有动作动态；
日志能列出承接项、缺失项和失败条件数量；
缺任一必须承接项时不能写 已完成；
最新运行段没有 基础风险判断状态=已明确。
```
