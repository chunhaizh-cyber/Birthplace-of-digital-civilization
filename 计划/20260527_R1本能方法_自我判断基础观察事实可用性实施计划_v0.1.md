## 1. 目标

```text
综合第一阶段前置状态，判断当前观察帧基础观察事实是否可用；
写入 当前观察帧.基础观察事实可用状态 等于 可用 / 条件不足 / 不可用。
```

该方法是第一阶段收束方法。它只证明“当前观察事实可用”，不得推出“基础风险判断已明确”。

## 2. 输入与输出

输入：

```text
自我所在场景.当前观察特征帧取得状态
当前观察帧.观察帧容器状态 / 自我所在场景.当前观察帧存在状态
双目相机.可用状态
双目相机.运行可用性值
当前观察帧.像素覆盖状态
当前观察帧.像素特征值承接状态
当前观察帧.观察事实完备状态
当前观察帧.质量可用状态
当前观察帧.观察年龄
当前观察帧.观察新鲜度状态
当前观察帧.新鲜度失败原因
自我所在场景.当前观察新鲜度状态，兼容摘要
前置动作动态列表
```

输出：

```text
基础观察事实可用状态 = 可用 / 条件不足 / 不可用
基础观察事实失败条件数量
基础观察事实失败条件摘要
当前观察帧.观察年龄
当前观察帧.观察新鲜度状态 == 新鲜 / 过期 / 条件不足
动作动态 / 来源动态证据
```

```text
不得把基础观察事实可用推出基础风险判断状态已明确；
不得写基础风险值、风险等级、安全值或服务值；
不得绕过枚举型实例特征值生产者校验；
不得让任务管理线程直接写需求树。
```

## 5. 实施步骤

```text
B1 先检查是否已有等价方法头和动作入口；没有则只登记本方法。
B2 读取全部第一阶段前置状态、时间证据、失效证据和来源动作动态。
B3 内部计算当前观察帧观察年龄和观察新鲜度状态；不得调用或登记独立的 自我_判断当前观察帧新鲜度 方法。
B4 逐项计算失败条件数量与原因。
B5 当且仅当前置全部成立且当前观察帧.观察新鲜度状态 == 新鲜 时写 基础观察事实可用状态=可用。
B6 输出日志和控制面板摘要，明确基础风险仍未判断。
```

