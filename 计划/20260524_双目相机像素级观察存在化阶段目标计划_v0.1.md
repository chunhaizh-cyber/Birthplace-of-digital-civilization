## 1. 阶段目标

### 1.1 像素级观察特征可回查

```text
当前画面中所有像素都应该有对应的观察特征记录，
记录到自我所在的场景中，
并且可以被 100% 在此识别。
```

本阶段的“100% 识别”只表示帧内可寻址、可回查、无遗漏、无重复，不表示已经理解每个像素对应的稳定真实世界对象。

```text
100% 覆盖：
    对于观察帧中每一个像素坐标 (x, y)，都存在一个像素观察存在或像素特征索引项。

100% 回查：
    给定 观察帧编号 + 像素坐标 或 观察帧编号 + 帧内像素编号，
    必须能唯一定位回同一个像素观察存在或像素特征索引项。

不宣称：
    不宣称像素已经被归并为稳定外部对象；
    不宣称跨帧身份已经稳定；
    不宣称语义识别、物体分类或目标可见性已经闭合。
```

### 1.2 空间主导存在确认

本计划的存在确认原则改为：

```text
存在确认主依据 = 空间坐标连续性 + 范围坐标稳定性
轮廓 = 注意力入口 / 投影边界 / 辅助校验
颜色 = 辅助校验
```

核心流程：

```text
相机提供当前帧像素级观察特征；
自我先按空间坐标和范围坐标组合空间候选；
再用轮廓辅助确定投影边界；
最后通过空间一致性、范围稳定性、投影覆盖和轮廓吻合确认一个观察存在。
```

不再使用：

```text
轮廓 -> 存在
```

改为：

```text
空间坐标簇 / 范围坐标 -> 存在候选
轮廓 -> 边界辅助
覆盖原帧 -> 验证归属
```

### 1.3 控制面板复现场景信息

第二个阶段目标：

```text
复现场景信息，
将自我所在场景中识别到的特征信息在控制面板中画出来。
```

这里的“画出来”必须以自我所在场景中的已识别特征信息为数据源，不以控制面板直接读取的相机原始画面作为真值来源。

```text
输入来源：
    自我所在场景
    当前观察帧存在
    当前帧像素特征索引 / 像素观察存在
    空间候选
    存在假设
    已验证观察存在
    投影覆盖掩码
    已识别的颜色、深度、空间坐标、范围坐标、距离、尺寸、方位、编号、验证状态

输出位置：
    控制面板场景复现画布

边界：
    控制面板只负责观察和复现；
    控制面板不得反向写入世界树真值；
    控制面板显示成功不等于业务链路验收通过；
    控制面板不能替代日志、状态快照、动作动态和错误日志作为验收依据。
```

## 3. 核心定义

### 3.1 观察帧存在

观察帧存在是一次双目相机采集结果在自我所在场景中的承载节点。

```text
观察帧存在
    来源 = 观察生成
    所属上下文 = 自我所在场景
    来源外设 = 双目相机
    深度帧号
    彩色帧号
    帧宽度
    帧高度
    像素特征数量
    预期像素数量
    像素覆盖状态
    帧解释状态
```

### 3.2 当前帧像素特征索引

当前帧像素特征索引是按帧内像素编号建立的只属当前观察帧的可回查表。

```text
当前帧像素特征索引项
    所属上下文 = 当前观察帧存在
    观察帧编号
    帧内像素编号
    像素坐标X
    像素坐标Y
    颜色R
    颜色G
    颜色B
    深度值
    深度有效性
    空间坐标X
    空间坐标Y
    空间坐标Z
```

P2 可以先建立当前帧像素特征索引，不急于把每个像素都确认为稳定外部对象。

### 3.3 像素观察存在

像素观察存在不是稳定外部对象，只是当前观察帧内的最小观察事实单位。

```text
像素观察存在
    所属上下文 = 当前观察帧存在
    来源 = 观察生成
    来源外设 = 双目相机
    观察帧编号
    帧内像素编号
    像素坐标X
    像素坐标Y
    指向当前帧像素特征索引项
```

像素观察存在可以后续被空间候选、存在假设、已验证观察存在和跨帧跟踪对象引用或归并，但本阶段不把它直接等同于真实世界对象。

### 3.4 帧内像素编号

```text
帧内像素编号 = y * 帧宽度 + x
值域：
    0 <= 帧内像素编号 < 帧宽度 * 帧高度
```

帧内像素编号只在同一个观察帧内有效。

### 3.5 空间候选

空间候选是自我按像素空间坐标、深度和空间邻近关系组合出的待观察空间块。

```text
空间候选
    来源观察帧
    候选编号
    像素索引集合 / 掩码引用
    空间点数量
    有效点比例
    中心空间坐标
    范围坐标AABB
    平均深度
    最近深度
    最远深度
    空间连续性评分
    范围稳定性评分
    相对独立状态
    初始状态 = 待观察
```

### 3.6 范围坐标

范围坐标表示空间坐标集合在参考坐标系中的占据范围。

第一阶段只做 AABB：

```text
范围坐标AABB
    最小X
    最大X
    最小Y
    最大Y
    最小Z
    最大Z
```

OBB 只作为后续扩展：

```text
范围坐标OBB
    中心点
    主方向1
    主方向2
    主方向3
    半长1
    半长2
    半长3
```

第一阶段选择 AABB 的原因：

```text
输入简单；
结果容易落账；
OpenGL 容易绘制；
筹办容易按距离、尺寸、范围命中特征；
真实 D455 验证时更容易判断。
```

### 3.7 存在假设和已验证观察存在

```text
存在假设
    来源观察帧
    来源空间候选
    中心空间坐标
    范围坐标AABB
    候选像素掩码
    投影轮廓
    距离
    尺寸
    方位
    有效点比例
    空间连续性评分

    轮廓支持评分
    验证状态 = 待验证

已验证观察存在
    来源观察帧
    来源存在假设
    中心空间坐标
    范围坐标AABB
    距离
    尺寸
    方位
    像素归属掩码

    轮廓吻合率
    验证状态
```

## 4. 值域约束

```text
帧宽度：
    I64，> 0

帧高度：
    I64，> 0

像素坐标X：
    I64，0 <= X < 帧宽度

像素坐标Y：
    I64，0 <= Y < 帧高度

帧内像素编号：
    I64，0 <= 编号 < 帧宽度 * 帧高度

颜色R / 颜色G / 颜色B：
    I64，0 <= 值 <= 255

深度有效性：
    I64，0 或 1

深度值：
    I64，毫米口径，深度有效性=1 时 > 0；深度有效性=0 时不得用 I64_MAX 表示真实值

空间坐标X / Y / Z：
    I64 或后续定点数值口径；必须明确单位，不得用未声明比例

范围坐标AABB：
    与空间坐标使用同一单位；
    最小X <= 最大X；
    最小Y <= 最大Y；
    最小Z <= 最大Z；
    任一坐标不得用 I64_MAX 表示真实值

有效点比例 / 深度一致率 / 范围内点比例 / 投影覆盖率 / 轮廓吻合率：
    I64，0 <= 值 <= 10000，表示 0.00% 到 100.00%

空间连续性评分 / 范围稳定性评分 / 轮廓支持评分：
    I64，0 <= 值 <= 10000

像素覆盖状态：
    I64，1 表示 像素特征数量 == 帧宽度 * 帧高度
```

## 5. 存在确认原则

### 5.1 证据排序

```text
一级证据：空间坐标连续性
二级证据：范围坐标稳定性
三级证据：深度一致性
四级证据：投影覆盖一致性
五级证据：轮廓吻合度
六级证据：颜色 / 纹理一致性
```

对应含义：

```text
空间坐标连续性：
    一组像素的 X/Y/Z 在三维空间中是否相邻、连贯、没有明显断裂。

范围坐标稳定性：
    该候选的 AABB / OBB 是否合理，是否与周围候选明显分离。

深度一致性：
    候选内部深度是否连续，边界处是否有深度突变。

投影覆盖一致性：
    将该空间候选投影回原帧，是否能覆盖对应观察区域。

轮廓吻合度：
    投影边界与图像轮廓是否大体吻合。

颜色 / 纹理一致性：
    只作为辅助，不作为确认主依据。
```

### 5.2 轮廓定位

```text
轮廓是辅助特征，不是存在确认主证据。
轮廓可以触发观察，但不能单独确认存在。
轮廓与空间坐标冲突时，以空间坐标和范围坐标为主。
空间坐标否定轮廓；轮廓不能单独肯定存在。
```

轮廓承担四个辅助任务：

```text
1. 注意力入口：
    帮助从图像上找到值得观察的区域。

2. 投影边界辅助：
    帮助修正空间候选在二维画面上的边界。

3. 拆分提示：
    一个空间范围内若存在多个明显轮廓，可提示拆分。

4. OpenGL 显示辅助：
    用于画出候选边界、当前观察对象边界、已验证对象边界。
```

### 5.3 硬规则

已验证观察存在：

```text
空间连续性评分 >= 阈值
范围内点比例 >= 阈值
深度一致率 >= 阈值
有效点比例 >= 阈值
与已确认存在冲突率 <= 阈值
范围尺寸在合理值域内
```

轮廓条件：

```text
轮廓吻合率低时，不直接否定；
只要空间证据强，可以标记为：
    已验证_轮廓待修正
```

待拆分：

```text
空间候选内部出现两个或更多稳定子范围
或范围坐标过大且内部深度断裂明显
或一个轮廓包住多个空间簇
```

待合并：

```text
多个空间候选范围相邻
深度连续
投影边界接近
中间缺口可由遮挡或深度空洞解释
```

已否定：

```text
空间坐标稀疏
深度无效比例过高
范围坐标不稳定
投影回原帧后大面积无法解释
与已确认存在高冲突且无法形成遮挡关系
```

## 6. 方法粒度调整

当前 `双目相机_刷新当前观察场景` 粒度偏大，后续应迁出本能最小动作层或降为组合 / 归并动作。

### 6.1 双目相机使用类本能方法

双目相机只输出当前帧像素级观察特征，不直接确认稳定外部对象。

```text
双目相机_取得当前观察帧
    输出：观察帧存在、帧宽度、帧高度、深度帧号、彩色帧号。

双目相机_建立当前帧像素特征索引
    输入：观察帧存在。
    输出：当前帧像素特征索引、像素特征数量、像素覆盖状态。

双目相机_按帧内像素编号识别像素特征
    输入：观察帧存在、帧内像素编号。
    输出：当前帧像素特征索引项。

双目相机_按像素坐标识别像素特征
    输入：观察帧存在、像素坐标X、像素坐标Y。
    输出：当前帧像素特征索引项。

双目相机_获取像素颜色
    输入：当前帧像素特征索引项 或 像素观察存在。
    输出：颜色R / 颜色G / 颜色B。

双目相机_获取像素深度
    输入：当前帧像素特征索引项 或 像素观察存在。
    输出：深度有效性、深度值。

双目相机_获取像素空间坐标
    输入：当前帧像素特征索引项 或 像素观察存在。
    输出：空间坐标X / Y / Z。
```

### 6.2 自我空间组合方法

```text
自我_提取空间候选
```

```text
自我_获取观察存在投影轮廓
自我_跟踪观察存在
```

## 7. 场景挂载规则

为避免直接污染自我所在场景根层，观察事实按观察帧隔离挂载：

```text
自我所在场景
    -> 当前观察帧存在
        -> 当前帧像素特征索引
        -> 像素观察存在[0]
        -> 像素观察存在[1]
        -> ...
        -> 像素观察存在[宽度 * 高度 - 1]
        -> 空间候选集合
        -> 空间候选观察队列
        -> 存在假设集合
        -> 已验证观察存在集合
        -> 像素归属图
        -> 未解释区域图
```

这样所有像素和组合结果仍记录在自我所在场景范围内，但可以通过观察帧存在隔离本轮画面。

## 8. 存在确认流程

### P1 双目相机取得当前观察特征帧

相机只输出当前帧特征：

```text
颜色
深度
深度有效性
空间坐标X/Y/Z
像素坐标X/Y
帧内像素编号
```

### P2 建立当前帧像素特征索引

每个像素可回查：

```text
像素坐标
帧内编号
颜色
深度
空间坐标
深度有效性
```

继续保留：

```text
每个像素坐标和帧内像素编号都能唯一回查；
不能把 I64_MAX 当作真实深度或坐标值。
```

### P3 自我提取空间候选

输入：

```text
当前观察特征帧
像素空间坐标X/Y/Z
深度有效性
深度值
像素坐标
```

处理：

```text
1. 排除深度无效像素。
2. 将有效像素映射到相机坐标系或宿主坐标系。
3. 按空间邻近关系聚类。
4. 按深度断裂、空间距离断裂、法向突变切分。
5. 生成空间候选集合。
```

输出：

```text
空间候选集合
中心空间坐标
范围坐标AABB
空间连续性评分
范围稳定性评分
```

### P4 自我判断空间候选相对独立性

主看：

```text
空间连续性
范围坐标闭合程度
与周围空间候选的分离度
深度边界差异
有效点比例
范围尺寸是否合理
```

判断结果：

```text
空间候选.相对独立状态 =
    相对独立
    不独立
    待拆分
    待合并
    不确定
```

轮廓只作为辅助：

```text
如果空间连续但图像轮廓极乱：
    不直接否定，只降低轮廓支持分。

如果轮廓清楚但空间坐标不连续：
    不直接确认，应拆分或标记为二维轮廓假象。

如果空间候选跨越明显轮廓边界：
    进入待拆分。
```

### P5 自我生成空间候选观察队列

排序指标：

```text
候选空间范围大小
候选中心到画面中心距离
候选中心到自我距离
空间连续性评分
范围稳定性评分
有效点比例
任务相关性
与已确认存在的重叠程度
```

默认优先级：

```text
优先级 =
    空间连续性评分 * 0.30
  + 范围稳定性评分 * 0.25
  + 中心接近评分 * 0.20
  + 有效点比例评分 * 0.15
  + 范围大小评分 * 0.10
  - 已确认区域重叠惩罚
  - 背景疑似惩罚
```

不同任务可以换权重：

```text
抓取任务：
    中心接近 + 距离近 + 尺寸适中 优先。

避障任务：
    距离近 + 范围大 + 位于前进方向 优先。

场景建图：
    范围大 + 空间稳定 + 覆盖主要区域 优先。

找目标：
```

### P7 自我用空间范围投影覆盖原帧验证像素归属

覆盖验证使用：

```text
空间范围投影 + 深度一致性 + 轮廓辅助
```

流程：

```text
1. 将存在假设的空间点集或范围坐标投影回当前帧。
2. 生成投影覆盖掩码。
3. 生成预测深度图 / 范围深度区间。
4. 与原帧每个像素的深度和空间坐标比较。
5. 再用轮廓检查投影边界是否合理。
6. 输出归属图和残差图。
```

像素判定：

```text
若像素落在空间候选投影内
且像素空间坐标在候选范围坐标内
且深度残差小于阈值：
    归属成立

若像素落在轮廓内
但空间坐标不在候选范围内：
    不确认归属，标记为轮廓支持但空间冲突

若像素空间坐标在候选范围内
但轮廓边界不吻合：
    可暂时确认空间归属，标记为轮廓边界待修正

若多个候选争夺同一像素：
    用空间深度前后关系和范围重叠规则判断遮挡
```

输出：

```text
像素归属验证结果
空间覆盖像素数
空间匹配像素数
空间冲突像素数
轮廓支持像素数
轮廓冲突像素数
深度一致率
范围内点比例
投影覆盖率
轮廓吻合率
遮挡像素数
未解释像素数
验证状态
```

## 10. 验收口径

验收必须使用真实 D455 画面或真实运行日志，不能用模拟样本。

```text

    若观察帧宽度 = W，高度 = H，

必查：
    观察帧存在已挂到自我所在场景；
    像素特征索引项数量 == W * H；
    每个像素坐标 (x, y) 都能回查到唯一像素特征索引项；
    每个帧内像素编号都能回查到唯一像素特征索引项；
```

## 11. 风险

```text
风险 1：节点数量爆炸。
处理：第一轮只承接单帧；后续再设计分块、分页或懒展开，但不得破坏每个像素可唯一回查的目标。

风险 2：把像素观察存在误当成稳定外部对象。
处理：像素观察存在只在观察帧内有效；跨帧跟踪与对象归并另立目标。

风险 3：把 D455 内部采集、对齐、滤波步骤登记为自我本能方法。
处理：自我本能方法只看到观察帧、像素特征和可认知特征输出；空间组合属于自我观察链。

风险 4：缺真实硬件时误宣称通过。
处理：缺真实 D455 或真实画面只记录等待验证。

风险 5：控制面板直接显示相机帧，被误当成自我识别结果。
处理：场景复现画布必须读取自我所在场景中的观察帧、像素特征、空间候选、存在假设或已验证观察存在；相机预览只作为辅助观察面。

风险 6：轮廓被误当成存在确认主证据。
处理：轮廓只作为注意力入口、投影边界辅助、拆分/合并提示和显示辅助；空间坐标和范围坐标冲突时以空间证据为主。

风险 7：范围坐标单位不清。
处理：范围坐标必须与空间坐标使用同一参考坐标系和单位，未声明单位不得进入真实验证结论。
```
