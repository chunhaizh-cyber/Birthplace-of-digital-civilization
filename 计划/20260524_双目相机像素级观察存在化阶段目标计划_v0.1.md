# 双目相机像素级观察存在化阶段目标计划 v0.1

日期：2026-05-24

状态：目标设定，待详细设计与小切片实现。

## 1. 阶段目标

### 1.1 像素级观察存在化

```text
当前画面中所有像素都应该有对应的存在，
记录到自我所在的场景中，
并且可以被 100% 在此识别。
```

本阶段的“100% 识别”只表示帧内可寻址、可回查、无遗漏、无重复，不表示已经理解每个像素对应的稳定真实世界对象。

```text
100% 覆盖：
    对于观察帧中每一个像素坐标 (x, y)，都存在一个像素观察存在。

100% 回查：
    给定 观察帧编号 + 像素坐标 或 观察帧编号 + 帧内像素编号，
    必须能唯一定位回同一个像素观察存在。

不宣称：
    不宣称像素已经被归并为稳定外部对象；
    不宣称跨帧身份已经稳定；
    不宣称语义识别、物体分类或目标可见性已经闭合。
```

### 1.2 控制面板复现场景信息

第二个阶段目标：

```text
复现场景信息，
将自我所在场景中识别到的特征信息在控制面板中画出来。
```

这里的“画出来”必须以自我所在场景中的已识别特征信息为数据源，不以控制面板直接读取的相机原始画面作为真值来源。

```text
输入来源：
    自我所在场景
    当前观察帧存在
    像素观察存在
    候选存在 / 轮廓 / 跟踪存在
    已识别的颜色、深度、坐标、距离、轮廓、编号、置信或状态特征

输出位置：
    控制面板场景复现画布

边界：
    控制面板只负责观察和复现；
    控制面板不得反向写入世界树真值；
    控制面板显示成功不等于业务链路验收通过；
    控制面板不能替代日志、状态快照、动作动态和错误日志作为验收依据。
```

## 3. 核心定义

### 3.1 观察帧存在

观察帧存在是一次双目相机采集结果在自我所在场景中的承载节点。

```text
观察帧存在
    来源 = 观察生成
    所属上下文 = 自我所在场景
    来源外设 = 双目相机
    深度帧号
    彩色帧号
    帧宽度
    帧高度
    像素存在数量
    预期像素数量
    像素覆盖状态
```

### 3.2 像素观察存在

像素观察存在不是稳定外部对象，只是当前观察帧内的最小观察事实单位。

```text
像素观察存在
    所属上下文 = 当前观察帧存在
    来源 = 观察生成
    来源外设 = 双目相机
    观察帧编号
    帧内像素编号
    像素坐标X
    像素坐标Y
    颜色R
    颜色G
    颜色B
    深度值
    深度有效性
    空间坐标X
    空间坐标Y
    空间坐标Z
```

像素观察存在可以后续被轮廓、候选存在、跨帧跟踪对象引用或归并，但本阶段不把它直接等同于真实世界对象。

### 3.3 帧内像素编号

```text
帧内像素编号 = y * 帧宽度 + x
值域：
    0 <= 帧内像素编号 < 帧宽度 * 帧高度
```

帧内像素编号只在同一个观察帧内有效。

## 4. 值域约束

```text
帧宽度：
    I64，> 0

帧高度：
    I64，> 0

像素坐标X：
    I64，0 <= X < 帧宽度

像素坐标Y：
    I64，0 <= Y < 帧高度

帧内像素编号：
    I64，0 <= 编号 < 帧宽度 * 帧高度

颜色R / 颜色G / 颜色B：
    I64，0 <= 值 <= 255

深度有效性：
    I64，0 或 1

深度值：
    I64，毫米口径，深度有效性=1 时 > 0；深度有效性=0 时不得用 I64_MAX 表示真实值

空间坐标X / Y / Z：
    I64 或后续定点数值口径；必须明确单位，不得用未声明比例

像素覆盖状态：
    I64，1 表示 像素存在数量 == 帧宽度 * 帧高度
```

## 5. 本能方法粒度调整

当前 `双目相机_刷新当前观察场景` 粒度偏大，后续应迁出本能最小动作层或降为组合 / 归并动作。

本阶段优先设计以下更小的使用类本能方法：

```text
双目相机_取得当前观察帧
    输出：观察帧存在、帧宽度、帧高度、深度帧号、彩色帧号。

双目相机_建立像素观察存在集合
    输入：观察帧存在。
    输出：像素观察存在集合、像素存在数量、像素覆盖状态。

双目相机_按帧内像素编号识别像素存在
    输入：观察帧存在、帧内像素编号。
    输出：像素观察存在。

双目相机_按像素坐标识别像素存在
    输入：观察帧存在、像素坐标X、像素坐标Y。
    输出：像素观察存在。

双目相机_获取像素颜色
    输入：像素观察存在。
    输出：颜色R / 颜色G / 颜色B。

双目相机_获取像素深度
    输入：像素观察存在。
    输出：深度有效性、深度值。

双目相机_获取像素空间坐标
    输入：像素观察存在。
    输出：空间坐标X / Y / Z。
```

后续存在级方法再建立在像素级事实之上：

```text
双目相机_发现候选存在
双目相机_获取存在距离
双目相机_获取存在坐标
双目相机_获取存在颜色
双目相机_获取存在轮廓
双目相机_跟踪观察存在
```

## 6. 场景挂载规则

为避免直接污染自我所在场景根层，像素观察存在按两级挂载：

```text
自我所在场景
    -> 当前观察帧存在
        -> 像素观察存在[0]
        -> 像素观察存在[1]
        -> ...
        -> 像素观察存在[宽度 * 高度 - 1]
```

这样所有像素仍记录在自我所在场景范围内，但可以通过观察帧存在隔离本轮画面。

## 7. 验收口径

验收必须使用真实 D455 画面或真实运行日志，不能用模拟样本。

```text
预测：
    若观察帧宽度 = W，高度 = H，
    则当前观察帧存在下应生成 W * H 个像素观察存在。

必查：
    观察帧存在已挂到自我所在场景；
    像素观察存在数量 == W * H；
    每个像素坐标 (x, y) 都能回查到唯一像素观察存在；
    每个帧内像素编号都能回查到唯一像素观察存在；
    回查得到的像素观察存在反写同一观察帧编号和坐标；
    无 I64_MAX 进入真实深度值或坐标值；
    方法动作动态绑定具体双目相机使用类方法。

结论：
    只能宣称“当前帧像素观察存在 100% 覆盖 / 回查通过”；
    不宣称跨帧对象身份稳定；
    不宣称目标可见性 / 在场状态已闭合；
    不宣称语义识别完成。
```

## 8. 控制面板复现目标

现有控制面板已有 D455 相机画面和轮廓图画面；本目标不等同于相机预览。

控制面板复现场景信息必须从自我所在场景中的识别结果生成：

```text
场景复现画布：
    以观察帧尺寸建立画布坐标系。

像素层：
    按像素观察存在绘制颜色 / 深度 / 有效性。

特征层：
    绘制像素坐标、空间坐标、距离、颜色、深度等可认知特征。

候选存在层：
    绘制候选存在编号、轮廓、中心点、外接框、距离摘要。

跟踪层：
    绘制跨帧跟踪编号、当前帧帧内编号、跟踪状态。

诊断层：
    显示覆盖率、回查率、缺失像素数、重复映射数、最近动作动态和失败原因。
```

第一轮最小显示：

```text
1. 当前观察帧尺寸。
2. 像素覆盖率：像素存在数量 / 预期像素数量。
3. 按像素观察存在绘制一张复现画面。
4. 鼠标指向像素时，显示帧内像素编号、坐标、颜色、深度有效性、深度值。
5. 若已有候选存在或轮廓，叠加候选编号和轮廓边界。
```

验收口径：

```text
预测：
    若自我所在场景中存在当前观察帧和像素观察存在集合，
    控制面板应能从该场景快照复现画面。

必查：
    控制面板数据来自自我所在场景快照；
    画布尺寸等于观察帧宽高；
    绘制像素数等于像素观察存在数量；
    鼠标命中的像素能回查到对应像素观察存在；
    显示的颜色 / 深度 / 坐标来自像素观察存在特征；
    候选存在或轮廓叠加来自场景中已识别特征；
    控制面板不回写世界树。

禁止宣称：
    不用控制面板画面代替真实业务验收；
    不把原始相机预览误称为自我已识别场景；
    不把显示层推导写成世界树真值。
```

## 9. 风险

```text
风险 1：节点数量爆炸。
处理：第一轮只承接单帧；后续再设计分块、分页或懒展开，但不得破坏每个像素可唯一回查的目标。

风险 2：把像素观察存在误当成稳定外部对象。
处理：像素观察存在只在观察帧内有效；跨帧跟踪与对象归并另立目标。

风险 3：把 D455 内部采集、对齐、滤波步骤登记为自我本能方法。
处理：自我本能方法只看到观察帧、像素观察存在和可认知特征输出。

风险 4：缺真实硬件时误宣称通过。
处理：缺真实 D455 或真实画面只记录等待验证。

风险 5：控制面板直接显示相机帧，被误当成自我识别结果。
处理：场景复现画布必须读取自我所在场景中的观察帧 / 像素观察存在 / 候选存在特征；相机预览只作为辅助观察面。
```
