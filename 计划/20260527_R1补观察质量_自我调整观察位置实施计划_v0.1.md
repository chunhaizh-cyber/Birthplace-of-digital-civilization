## 1. 输入

```text
当前观察位置
允许移动范围

质量失败原因
深度有效率
空间坐标有效率
远距 / 无效深度区域摘要
```

## 2. 输出

```text
观察位置调整结果
新观察位置
重采样观察特征帧
调整前后质量指标对比
动作动态 / 来源动态证据
```

## 3. 转换逻辑

```text
若目标过远或整帧远背景过多：
    生成移动到更稳定观察距离的候选位置。

若移动接口存在：
    移动后重采样并比较质量。

若移动接口不存在：
    占位执行输出外部协助 / 条件不足需求，不伪装为可执行成功。
```

## 4. 禁止越界

```text
不得把人类手动挪动相机伪装成自我方法动作动态。
不得在没有位移接口时写 已调整。
不得直接写质量可用或基础风险已明确。
```
