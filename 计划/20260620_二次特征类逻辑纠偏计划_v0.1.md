执行本计划时，如果发现当前切片必须依赖其它类新增或补齐功能函数，按以下规则处理：

```text
1. 后续任意类缺少当前切片所需功能函数时，不在二次特征类或调用方临时拼字段、解释其它类主信息或新增平行结构体。
2. 若对应类已有逻辑纠偏计划，则把当前缺口加入该计划，并放到第一优先位置。
3. 若对应类没有逻辑纠偏计划，则生成 `计划/YYYYMMDD_<类名>逻辑纠偏计划_v0.1.md`，并把当前缺口作为第一优先切片。
4. 新生成或被修改的逻辑纠偏计划必须包含本“跨类缺口转向规则”，保证后续继续发现缺口时仍按同一调度口径处理。
5. 更新 `计划/计划索引.md`：把新生成或新修改的计划临时提升为第一优先计划；原计划和原切片记录为返回点。

7. 第一优先缺口闭合后，立即停止该新计划，更新计划索引返回原计划和原切片。
```

## 7. 补充总口径：二次特征信息操作统一入口

当前新口径：

```text
所有关于二次特征信息的读取、创建、写入、模板匹配、来源绑定、主体客体绑定、值写入、方向 / 差值 / 区间判断、概念模板归并、场景二次特征目录消费，都必须调用 二次特征类 中的功能函数。
```

目标：

```text
1. 外部调用方不得直接读取 / 修改 二次特征主信息类 字段。
2. 外部调用方不得直接 new 二次特征主信息类 后自行拼装业务语义，除非该路径已明确归属二次特征生成模块并通过二次特征类统一创建 / 写入。
3. 外部调用方不得直接 dynamic_cast<二次特征主信息类> 后解释 形态 / 域 / 粒度 / 基准类型 / 来源 / 主体 / 客体 / 差值 / 标量区间 / 值形态 / 概念名称。
4. 外部调用方不得直接遍历基础信息树查找二次特征节点；世界树结构操作归 世界树类，二次特征语义筛选归 二次特征类。
5. 二次特征类不得吞并状态类、动态类、场景类、特征类、语素类、世界树类的职责；缺哪个类函数就转入哪个类计划第一优先。
6. 二次特征是比较关系的特征化，不是日志、显示文本、普通状态字段或任意多特征高阶推导容器。
```

## 7.1 二次特征信息操作范围

纳入本计划的二次特征操作：

```text
1. 二次特征节点按主键解析、按引用解析、按模板查找。
2. 二次特征主信息只读读取：形态、域、粒度、基准类型、值形态、来源类型、方向区间、差值、标量值、标量区间、概念名称。
3. 二次特征来源读取和写入：来源起始状态、来源结果状态、来源动态、来源场景、来源动态层级、来源动态路径签名、来源时间段。
4. 二次特征主体 / 客体 / 左右对象读取和写入。
5. 二次特征差值、标量值、离散值、方向区间、置信度和满足判断写入。
6. 二次特征概念树根、度量链根、概念小区间、概念模板归并和概念名称反查。
7. 场景二次特征目录消费时的二次特征语义筛选。
8. 方法条件 / 方法结果 / 需求目标 / 因果条件 / 因果结果中引用的二次特征模板匹配。
```

不纳入本计划的操作：

```text
1. 基础信息世界树节点挂接、根访问、父子链枚举和跨类型节点解析，归 世界树类。
2. 场景事实目录增删、场景二次特征索引快照和场景归属维护，归 场景类。
3. 状态主信息、状态值、状态时间和状态主体读取，归 状态类。
4. 动态主信息、动态聚合、动态来源链、动态路径签名和动态所属场景读取，归 动态类。
5. 特征值读取、写入、差异度和抽象特征匹配，归 特征类。
6. 语素入口同一性、概念名称词面读取、信息入口类型读取，归 语素类。
7. 自然语言表达和显示层文本生成，归 语言类 / 控制面板显示层；显示层必须调用二次特征类结构化读取函数，不直接解释主信息字段。
```

```text
    世界树类 / 基础信息类 / 任务模块 / 方法类 / 状态类 / 控制面板 / 语言类 / 自我线程 / 外设动作实现中仍有直接读取、创建或解释 二次特征主信息类 的路径；
    二次特征应用模块内部仍有直接拼装二次特征模板和写主信息字段的路径，需要判断哪些属于二次特征模块内部可保留，哪些应补二次特征类函数；
```

```text
1. 默认不新增二次特征长期结构体；新增结构体前必须先证明现有节点 / 引用 / 输出参数无法表达，并先把结构缺口登记到本计划第一优先。
2. 只读视图若只服务显示层或短期回迁，应优先使用输出参数、局部判定表或临时显示层代码，不新增长期主信息结构。
3. 新增函数必须先扫描 说明书/函数功能说明文档.md，已有同功能函数则复用或改名收口。
4. 新增、删除或改名函数后必须运行 tools/生成函数功能说明文档.py。
5. 二次特征类函数不得直接用语素词面字符串作为机器判断；概念名称同一性调用 语素类 函数。
6. 二次特征类函数不得直接解释动态聚合字段、状态时间和值、场景索引或世界树父子链；缺口转入对应类计划。
```

## 8.2 与其它计划的协同

```text
1. 世界树类：
    二次特征节点挂接、父子链枚举、基础信息树按主键解析归 世界树类；
    二次特征语义读取和写入归 二次特征类。

2. 语素类：
    概念名称、语素入口同一性、词面安全读取归 语素类；
    二次特征类不得保留局部 语素入口主键相等 helper。

3. 场景类：
    场景二次特征索引维护归 场景类；
    读取索引后对二次特征语义筛选归 二次特征类。

4. 状态类 / 动态类 / 特征类：
    二次特征可以引用状态、动态和特征结果，但读取这些节点的主信息必须调用对应类函数。

5. 语言类 / 控制面板：
    显示层只消费二次特征类提供的结构化读取结果；
    不用显示文本反向参与机器判断。
```
