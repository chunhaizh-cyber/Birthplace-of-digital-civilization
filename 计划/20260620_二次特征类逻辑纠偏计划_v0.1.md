状态：第一优先只读缺口已闭合；2026-06-20 因果类 P7 发现的二次特征标量区间写回缺口已闭合，已停止本计划并返回协调计划 P7；2026-06-20 新增二次特征聚合链直接读取动态主信息字段纠偏缺口，调用方目标已登记，第一优先转入 动态类逻辑纠偏计划 P8 补齐动态类功能函数。

## 0. 目标

补齐二次特征类只读功能函数，让因果类不再直接解释 `二次特征主信息类` 的状态迁移来源和值域字段。

当前触发缺口：

```text
因果类.cpp 直接读取：
    二次特征主信息类::形态
    二次特征主信息类::来源动态
    二次特征主信息类::来源起始状态
    二次特征主信息类::来源结果状态
    二次特征主信息类::标量区间
    二次特征主信息类::差值
    二次特征主信息类::标量值
    二次特征主信息类::值形态
```

## 1. 第一优先缺口

建议函数：

```cpp
二次特征节点类* 按主键解析二次特征节点(const std::string& 主键) const noexcept;

bool 读取状态迁移来源(
    const 二次特征节点类* 二次特征,
    状态节点类*& 来源起始状态,
    状态节点类*& 来源结果状态,
    动态节点类*& 来源动态) const noexcept;

bool 是状态迁移二次特征(const 二次特征节点类* 二次特征) const noexcept;

bool 读取可融合标量区间(
    const 二次特征节点类* 二次特征,
    I64区间& 输出区间) const noexcept;

bool 二次特征模板匹配(
    const 二次特征节点类* 二次特征,
    const 二次特征节点类* 模板) const noexcept;
```

实现边界：

```text
1. 函数归属 二次特征类.h/.cpp。
2. 不新增二次特征主信息字段。
3. 不改变二次特征生成或写入流程。
4. 读取状态迁移来源只返回结构节点，不把自然语言说明或日志文本作为判断依据。
```

## 1.2 新增第一优先缺口：同向状态迁移标量区间融合写回

触发点：

```text
因果类 P7 回迁发现 因果类.cpp::私有_融合主果状态迁移区间_因果 会直接写 二次特征主信息类::标量区间。
该写回属于二次特征类数据更新，不应留在因果类中。
```

建议函数：

```cpp
bool 融合同向状态迁移可融合标量区间(
    二次特征节点类* 目标二次特征,
    const std::vector<二次特征节点类*>& 候选集合) const noexcept;
```

实现边界：

```text
1. 函数归属 二次特征类.h/.cpp。
2. 只合并与目标二次特征同向的候选状态迁移可融合标量区间。
3. 不创建新二次特征节点，不解释因果主信息，不操作因果类数据。
4. 第一优先闭合后停止本计划，返回 因果类外部数据读取纠偏协调计划 P7。
```

## 1.3 新增缺口：二次特征聚合链改为调用动态类聚合功能函数

触发点：

```text
二次特征聚合逻辑审查发现 二次特征应用模块.ixx 直接读取并解释：
    动态节点主信息类::动态层级
    动态节点主信息类::聚合方式
    动态节点主信息类::动态路径签名
    动态节点主信息类::来源低层动态

这些字段属于动态类的聚合来源链和路径身份信息。
二次特征模块可以使用动态聚合结果生成二次特征，但不应长期直接解释动态主信息字段。
```

纠偏目标：

```text
1. 二次特征模块后续读取动态聚合信息、判断原子相邻、读取来源低层动态、读取或计算路径签名时，统一调用动态类功能函数。
2. 二次特征模块只保留二次特征生成、比较、写入和查询职责。
3. 不删除当前 枚举_动态聚合方式 / 动态层级 / 聚合方式 / 来源低层动态 / 动态路径签名，因为它们仍是当前聚合链真实使用的结构字段。
4. 不新增二次特征主信息字段，不新增解释性摘要字段，不用字符串或日志文本承载聚合身份。
```

转向处理：

```text
1. 当前缺口的第一阻塞是动态类缺少聚合信息读取 / 来源链读取 / 路径签名功能函数。
2. 已将该缺口加入 计划/20260620_动态类逻辑纠偏计划_v0.1.md P8，并按跨类缺口转向规则临时提升为第一优先。
3. 动态类 P8 第一优先闭合后，再返回本计划执行二次特征应用模块调用点回迁。
4. 本计划当前只登记调用方整改目标，不执行源码修改。
```

## 2. 跨类缺口转向规则

执行本计划时，如果发现当前切片必须依赖其它类新增或补齐功能函数，按以下规则处理：

```text
1. 后续任意类缺少当前切片所需功能函数时，不在二次特征类或调用方临时拼字段、解释其它类主信息或新增平行结构体。
2. 若对应类已有逻辑纠偏计划，则把当前缺口加入该计划，并放到第一优先位置。
3. 若对应类没有逻辑纠偏计划，则生成 `计划/YYYYMMDD_<类名>逻辑纠偏计划_v0.1.md`，并把当前缺口作为第一优先切片。
4. 新生成或被修改的逻辑纠偏计划必须包含本“跨类缺口转向规则”，保证后续继续发现缺口时仍按同一调度口径处理。
5. 更新 `计划/计划索引.md`：把新生成或新修改的计划临时提升为第一优先计划；原计划和原切片记录为返回点。
6. 只执行新计划的第一优先缺口切片，不顺带推进新计划后续候选项。
7. 第一优先缺口闭合后，立即停止该新计划，更新计划索引返回原计划和原切片。
8. 若第一优先缺口切片不能闭合，保留该计划为当前阻塞，不回到原计划继续补丁化绕过。
```
