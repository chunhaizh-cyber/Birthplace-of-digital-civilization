# 语素类逻辑纠偏计划 v0.1

日期：2026-06-20

状态：已登记；未修改当前计划索引主动队列。当前口径为：所有关于语素信息的操作都必须调用 `语素类` 中的功能函数。

## 0. 目标

按当前项目结构闭环口径，纠偏语素信息操作入口：

```text
1. 语素树、词节点、语素入口节点、人类词性入口、信息入口类型入口、语素到基础信息桥接，统一由 语素类 功能函数承接。
2. 外部调用方不得直接读取 / 修改 词主信息类、语素入口主信息类、短语主信息类、语素语言记录主信息类 等语素主信息字段。
3. 外部调用方不得直接遍历 语素节点类 的 父 / 子 / 下 链，或直接使用 语素集.根指针 完成语素信息判断。
4. 外部调用方不得重复实现 语素入口同一、语素入口主键相等、语素入口日志文本、词面读取、信息入口定义读取等 helper。
5. 语素类 只负责语言入口索引和语素到基础信息的桥接，不承载真实世界事实、需求事实、任务事实、方法事实或治理状态。
6. 只读读取和显式确保必须分离；查找语素入口不得隐式创建，确保入口 / 确保基础信息桥接必须走显式函数。
```

本计划不新增兼容层，不保留旧直接访问路径和新 `语素类` 函数双轨。

## 0.1 语素信息操作范围

纳入本计划的语素信息操作：

```text
1. 词节点创建、查找、枚举和词面读取。
2. 人类词性入口创建、查找、读取和候选推断。
3. 信息入口类型入口创建、查找、读取和默认路由定义读取。
4. 语素入口到基础信息模板 / 概念节点的桥接查找、确保、绑定和只读读取。
5. 语素入口同一性判断、主键读取、诊断文本读取、安全词面读取。
6. 语素树根、词节点子入口枚举、入口所属词判断、入口所属词面读取。
7. 语素 SQL 投影、控制面板语素信息只读快照、显示层语素诊断信息生成。
```

暂不纳入本计划的非语素操作：

```text
1. 基础信息节点真实语义对象的创建、删除、特征写入和世界树挂接。
2. 语言类的文章 / 段落 / 自然句 / 子句组织树维护。
3. 需求、任务、方法、场景、状态、动态、因果等领域主信息逻辑。
4. 仅作为指针句柄值传递的语素入口指针本身；但指针解析、校验、显示和同一性判断必须由 语素类 函数承接。
```

边界说明：

```text
1. 语素层是语言入口索引；基础信息层才保存真实语义对象。
2. 文本词面只允许作为入口种子、显示、日志和诊断文本；系统逻辑不得用词面字符串比较替代语素入口节点同一性判断。
3. 语素入口的信息入口类型只决定默认主信息类型、存储树和上下文约束，不得当作需求 / 任务 / 方法状态事实。
4. 语素类可以调用 基础信息类 的桥接函数完成模板查找 / 创建；调用方不得绕过语素类直接改语素主信息桥接字段。
```

```text
P2.1 先回迁重复同一性 helper：
    二次特征类、二次特征应用模块、任务类、方法类、自我类、需求类、自我线程、任务模块、自我动作实现等局部 语素入口主键相等 / 相同 函数；
    统一调用 语素类 同一性函数。

P2.2 再回迁全局信息入口 helper：
    基础信息类、控制面板类 等外部调用 语素_取信息入口... 的路径改为 语素类 函数；
    若 语素主信息类 构造函数仍需内部默认值，可保留最小内部实现，外部不直接调用。

P2.3 再回迁语素主信息字段直读：
    基础信息类.cpp、控制面板类.cpp 等 dynamic_cast<语素入口主信息类> 的路径改为 语素类 读取函数或诊断快照函数。

P2.4 再回迁两段式词入口查找：
    获取词节点指针 / 查找词节点 + 查找信息入口节点 组合改为 语素类::查找信息入口节点(词值, 信息入口类型)。

P2.5 再回迁语素树根和节点链直接访问：
    语素集.根指针、语素节点父 / 子 / 下 链访问改为 语素类 枚举 / 归属 / 校验函数。

P2.6 最后回迁显示层直接获取词：
    SQL 投影、控制面板、日志、语言层统一调用 语素类 安全显示 / 诊断函数；
    显示文本不得参与机器判断。
```

禁止方式：

```text
1. 不在调用方新增新的语素 helper 替代 语素类。
2. 不保留 旧局部 helper + 新语素类函数 双轨。
3. 不用词面字符串比较替代语素入口同一性判断。
4. 不通过查找函数隐式创建语素入口或基础信息桥接。
5. 不把信息入口类型当成需求、任务、方法或治理状态事实。
```

## 1.3 与其它类逻辑纠偏计划的关系

```text
1. 语素类计划负责：语素入口、词面、人类词性、信息入口类型、语素到基础信息桥接、语素入口同一性和语素树只读枚举。
2. 基础信息类计划负责：基础信息节点真实语义模板创建、查找和基础信息树维护；但其语素入口读取必须调用 语素类。
3. 世界树类计划负责：基础信息世界树结构操作；若语素入口桥接需要挂接世界树节点，缺口转入世界树类计划。
4. 语言类计划负责：语言文章 / 句子表达和展示；若需要词面或入口诊断，调用 语素类，不直接读语素主信息。
5. 其它领域类若缺语素入口读取、同一性或桥接函数，先补 语素类；若缺的是本领域主信息读取，则转入对应类计划。
```

当前联动点：

```text
1. 前序已确认 语素入口同一 应归属语素类，不应放在全局共享函数类。
2. 当前场景类主动队列中已有“语素场景索引回迁”实施记录；后续若再发现语素入口读取缺口，应转入本计划第一优先，而不是在场景类中新增局部语素 helper。
3. 本计划当前只登记，不主动改变 计划/计划索引.md 的当前执行队列。
```

## 1.4 自动闭环规则

沿用当前计划索引规则，并补充语素专门归属：

```text
1. 执行任一类逻辑纠偏计划时，若发现直接语素信息操作缺口，优先判断是否属于 语素类。
2. 属于 语素类 的缺口，添加到本计划第一优先位置。
3. 若该缺口阻塞当前切片，更新 计划/计划索引.md，将本计划临时提升为第一优先，并写清原计划返回点。
4. 本计划只执行阻塞缺口所需的最小闭合切片，不顺带清理全部调用点。
5. 第一优先缺口闭合后，停止本计划，更新索引返回原计划。
6. 若缺的是基础信息、世界树、语言或其它领域主信息功能函数，不在语素类中临时解释字段；转入对应类逻辑纠偏计划。
```
