## 1. 输入

```text
当前质量失败原因
重采样次数上限
采样间隔

```

## 2. 输出

```text
多帧观察组
最佳观察帧编号
最佳帧质量指标
重采样择优状态 = 已择优 / 无改善 / 条件不足
动作动态 / 来源动态证据
```

## 3. 转换逻辑

```text
连续采集 N 帧。
每帧计算：
    深度有效率
    空间坐标有效率
    帧质量评分
    未解释区域比例
选择满足阈值且评分最高的帧。
若无帧满足阈值，记录无改善并保留最佳候选，不写质量可用。
```

```text
不得用多帧平均值覆盖单帧原始深度事实。
不得伪造重采样帧。
不得并发运行多个 鱼巢.exe。
不得跳过预测文件。
```
