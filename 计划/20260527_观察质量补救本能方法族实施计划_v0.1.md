## 1. 方法族边界

```text
质量不足不是基础风险已明确。
当前帧是已经发生的观察事实；旧帧不能被洗白成可用。
补观察质量方法族只服务于让后续新观察帧、派生观察帧、目标区域观察材料或替代观察材料更可能改善用途相关质量指标。
补全 / 融合 / ROI 可产生低置信或局部质量候选，但不得覆盖原始深度事实。
没有硬件执行接口的姿态 / 位置调整可以登记占位本能方法；执行时必须返回条件不足 / 待实现，不得伪装为可执行成功。
占位方法不得自动插入当前自然观察链，不得把补观察缺口状态解释成 质量可用 或 基础风险已明确。
S1 已正式实现后可作为质量评估后的诊断方法进入自然观察链；S2-S7 不得在未实现前自动插入自然观察链。
任务筹办 / 任务执行仍不是本能方法。
6118 名称中的“并派生补观察需求”只作为已登记名称保留；正式实现不得在 S1 内部直接派生需求入树。
S1 只写用途相关质量事实、诊断摘要和观察质量改善线索；解决办法必须由通用父需求筹办 / 重筹办依据父需求所需特征和世界树因果信息生成。
有已知因果路径时，任务筹办生成对应派生子需求消息；没有已知因果路径时，任务筹办生成寻找 / 验证 / 学习观察质量路径的学习型子需求消息。
父需求是否等待、降级继续或并行补救，由父需求筹办根据硬阻塞 / 软阻塞 / 旁路补救关系裁决，不由 S1 或子任务决定。
只有派生后的叶子任务才按方法结果能力填充候选集并选择当前方法。
派生需求目标只能使用 大于 / 小于 / 等于，改善 / 建立 / 确认 / 刷新 只能出现在方法语义、生成类型或派生原因中。
外设内部采集、对齐、曝光、滤波、视差变换和孔洞处理属于双目相机适配器私有流程，不逐项登记为自我本能方法。
```

## 4. 验收口径

```text
每个方法必须先写预测，再走真实运行路径。
每个方法必须有动作动态、输出宿主、输出特征和来源证据。
占位方法只能产出失败回执、补观察缺口状态、失败原因和动作动态；不得作为质量改善验收证据。
S1 正式实现只能产出用途相关质量事实、诊断摘要、观察质量改善线索和动作动态；不得直接写需求树。
真实低阈值日志证明当前帧没有因深度 / 空间坐标不足被整体作废的复验已移入待完成项，不作为当前主动队列阻塞。
任务筹办验收必须证明读取的是通用事实和父需求所需特征，不是 S1 方法名。
父需求是否等待、降级继续或并行补救，必须由父需求筹办 / 重筹办裁决；不得由子任务字段决定。
真实日志可证明后续新观察帧 / 派生观察帧 / 目标区域观察材料改善或未改善质量指标。
不得新增 --*-check 业务回归入口。
不得用模拟帧、夹具帧或伪造动作动态证明质量提升。
不得把 质量可用 / 降级可用 解释为 基础风险判断状态=已明确。
```
