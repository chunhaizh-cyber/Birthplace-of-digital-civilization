# S1d-5g 按动态创建因果信息内部定位方案 v0.1

日期：2026-06-08

## 1. 目标

```text
承接 S1d-5f。

S1d-5f 已闭合：
    `同类事件段聚合` 平均约 34013us，较 S1d-5e 的约 163712us 明显下降。

最新高层证据：
    `创建动态/内部阶段耗时` 最慢阶段转回 `动态二次特征`；
    `动态二次特征命中回写因果实例/内部阶段耗时` 42 条；
    `按动态创建因果信息` 平均约 21613us；
    `命中模板证据动态追加` 平均约 18111us。

当前判断：
    `按动态创建因果信息` 需要沉淀当前动态自身的状态变化 / 动作致变因果信息；
    不能为了提速跳过因果账本；
    但其内部可能慢在模板签名计算 / 模板查找 / 证据实例创建 / 证据实例追加 / 主结果桥接。

本切片目标：
    为 `因果类::按动态补全两层因果` 增加低频内部阶段耗时采样；
    定位主慢点是否已经满足 S7 因果模板索引恢复条件；
    不改变因果模板、因果实例、证据动态、证据实例或主结果桥接语义。
```
