# 需求类头文件结构体清理与目标逻辑纠偏计划 v0.1

生成时间：2026-06-19

状态：4.5 第一优先依赖函数已闭合；4.6 安全 / 服务方向只读函数缺口已闭合，已停止本计划并返回因果类外部数据读取纠偏协调计划 P6。

## 0. 目标

围绕 `需求类.h/.cpp` 做一次结构和逻辑收束：

1. 尽量删除头文件中的临时结构体，用明确功能函数替代结构体传参、结构体返回和外部字段解释。
2. 纠偏现有需求目标逻辑：需求不是“一步满足”，而是围绕同一目标特征值逐步推进；推进方向必须与需求方向一致。
3. `需求类` 过程中不得直接操作其它类型数据的增删改查；必须调用对应功能实现类函数。若缺少所需功能函数，当前切片暂停并提出缺口函数。

## 1. 权威口径

需求的原子目标：

```text
目标宿主 / 被需求存在
目标特征类型
当前状态 / 当前特征值
目标状态 / 目标特征值
```

需求方向：

```text
需求方向 = 比较(目标特征目标值, 当前特征当前值) 的符号方向
```

过程推进：

```text
推进方向 = 比较(新当前值, 旧当前值) 的符号方向
推进方向必须与需求方向一致
```

满足判断：

```text
满足判断 = 比较(新当前值, 目标值) 后由满足关系 / 接受掩码判断是否已达成
```

关键边界：

```text
满足关系不是需求方向。
方向不能由字段名、文本、日志或过程语义推断。
目标特征类型权威来源是状态节点的状态特征；目标特征类型缓存只能作为可重算缓存或校验对象。
目标值权威来源是目标状态节点的状态值；不得在需求类结构体里另造目标值仓库。
```

## 2. 项目结构映射表

| 业务概念 | 项目承载结构 | 值类型 | 写入方 | 读取方 | 验证方式 |
| --- | --- | --- | --- | --- | --- |
| 目标宿主 | `需求主信息类::被需求存在` 或状态节点主体 | `存在节点类* / 主键` | 需求入树函数 / 状态类函数 | 需求类目标读取函数 / 任务筹办 | 状态主体与需求目标宿主一致 |
| 目标特征类型 | 目标状态或当前状态的状态特征类型 | `语素入口节点类*` | 状态类 / 特征类 | 需求类目标读取函数 | 当前状态和目标状态特征类型一致 |
| 当前值 | `被需求当前状态` 的状态值 | `特征值` | 状态类 | 需求类方向函数 / 任务筹办 | 通过状态类读取，不直接取字段 |
| 目标值 | `需求状态` 的状态值 | `特征值` | 状态类 | 需求类方向函数 / 任务筹办 | 通过状态类读取，不直接取字段 |
| 需求方向 | 当前值与目标值比较结果 | 三态比较符号 / 二次特征 | 特征类比较函数 | 需求类推进校验函数 | 与推进方向同向 |
| 推进方向 | 旧当前值与新当前值比较结果 | 三态比较符号 / 二次特征 | 特征类比较函数 | 需求类推进校验函数 | 命中需求方向 |
| 满足判断 | 新当前值与目标值比较结果 + 接受掩码 | `枚举_三向关系` + `三向关系掩码` | 特征类比较函数 | 需求类满足判断函数 | `三向关系被接受` |
| 入树/更新动作 | 需求类功能函数 | 函数调用 | 自我线程 / 任务治理入口 | 需求类 | 不绕过需求类写树 |

## 3. 当前头文件结构体清单和处理原则

当前 `需求类.h` 中需要逐项清理的结构体：

```text
结构_枚举目标校验结果
结构_需求树更新指令
结构_子需求平分权重
结构_需求目标视图项
结构_需求方向签名
结构_任务初始化上下文
结构_需求目标语义视图
结构_需求获取途径语义视图
结构_逻辑组织需求更新输入
结构_需求目标键
```

处理原则：

1. 只读语义视图优先拆为查询函数，不再返回结构体。
2. 私有临时结构体优先内联到函数局部变量或拆成多个小函数。
3. 入树/更新类结构体优先拆成 `新增需求 / 更新需求 / 满足需求 / 删除需求` 功能函数。
4. 涉及消息协议的结构体不能在同一切片直接删除；必须先列出协议调用方和规范冲突点，再执行迁移。
5. 如果删除结构体会导致新增平行结构体，停止；应改为功能函数或现有项目节点/状态/特征承载。

## 4. 必须暂停并提出的功能函数缺口

实现过程中只要命中以下任一情况，暂停当前代码改动，写入缺口清单，不得直接访问其它类型主信息字段或临时补函数绕过：

### 4.1 状态类函数缺口

如果 `需求类` 需要读取状态值、状态主体、状态特征或解析状态主键，但 `状态类` 没有公开函数，应暂停并提出：

```cpp
状态节点类* 状态类::按主键解析状态节点(const std::string& 主键) noexcept;
const 状态节点主信息类* 状态类::读取状态主信息(const 状态节点类* 状态) noexcept;
bool 状态类::读取状态值(const 状态节点类* 状态, 特征值* 输出) noexcept;
基础信息节点类* 状态类::读取状态主体(const 状态节点类* 状态) noexcept;
const 语素入口节点类* 状态类::读取状态特征类型(const 状态节点类* 状态) noexcept;
```

### 4.2 特征类函数缺口

如果 `需求类` 需要比较状态值、计算方向、校验特征类型一致或判断推进方向，但 `特征类` 没有公开函数，应暂停并提出：

```cpp
结构_特征比较结果 特征类::比较状态(const 状态节点类* 左, const 状态节点类* 右) noexcept;
结构_特征比较结果 特征类::比较状态值(
    const 语素入口节点类* 特征类型,
    const 特征值& 左值,
    const 特征值& 右值) noexcept;
bool 特征类::状态特征类型一致(const 状态节点类* 左, const 状态节点类* 右) noexcept;
```

### 4.3 基础信息 / 存在 / 场景函数缺口

如果 `需求类` 需要按主键解析存在、场景或基础信息节点，但对应类没有公开解析函数，应暂停并提出，不得直接 `世界树.基础信息().查找主键 + dynamic_cast` 后继续写逻辑。

### 4.4 需求类自身函数缺口

如果调用方需要判断目标、方向、推进或满足，但 `需求类` 没有明确函数，应先补需求类功能函数，不得让调用方继续解释 `需求主信息类` 字段：

```cpp
const 语素入口节点类* 需求类::读取需求目标特征类型(const 节点类* 需求) noexcept;
bool 需求类::读取需求当前状态(const 节点类* 需求, 可解析引用<状态节点类>* 输出) noexcept;
bool 需求类::读取需求目标状态(const 节点类* 需求, 可解析引用<状态节点类>* 输出) noexcept;
枚举_需求方向比较结果 需求类::计算需求方向(const 节点类* 需求) noexcept;
bool 需求类::状态变化推进需求方向(
    const 节点类* 需求,
    const 状态节点类* 旧当前状态,
    const 状态节点类* 新当前状态) noexcept;
bool 需求类::判断需求已满足(const 节点类* 需求) noexcept;
bool 需求类::需求目标同一或重叠(const 节点类* 左, const 节点类* 右) noexcept;
```

### 4.7 跨类缺口转向规则

```text

4. 新生成或被修改的逻辑纠偏计划必须包含本“跨类缺口转向规则”，保证后续继续发现缺口时仍按同一调度口径处理。

8. 若第一优先缺口切片不能闭合，保留该计划为当前阻塞，不回到原计划继续补丁化绕过。
```

### P2 纠偏目标键和去重逻辑

当前疑点：

```text
生成需求目标键_已加锁 当前把 满足关系 作为 方向掩码；
需求目标重叠_已加锁 当前以 方向掩码重叠作为目标重叠条件之一；
这会把最终满足条件和需求推进方向混在一起。
```

目标：

```text
目标键改为 目标宿主 + 目标特征类型 + 目标值。
方向只作为过程推进判断，不作为目标身份权威字段。
```

动作：

```text
删除或私有化 结构_需求目标键。
把 查找直接子需求_按目标重叠_已加锁 改为调用 需求目标同一或重叠 函数。
目标值读取必须来自目标状态节点，不得来自字符串主键、日志或缓存字段。
```

暂停条件：

```text
如果不能通过状态类读取目标值，暂停提出 状态类::读取状态值。
如果不能通过特征类比较目标值同一性，暂停提出 特征类::比较状态值 或 状态目标值同一函数。
```
