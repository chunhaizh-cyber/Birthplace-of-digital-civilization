规范中的 `自我_建立像素观察存在集合` 在第一版由本方法承接。若后续要把它拆成新方法，必须另立独立计划，不在本计划中同义双写。

## 1. 目标

```text
为当前观察帧建立像素观察事实索引；
写入 当前观察帧.像素覆盖状态 等于 已覆盖；
写入 坐标回查可用状态 / 帧内编号回查可用状态 等于 可用。
```

该方法只证明像素观察存在覆盖和索引可回查，不证明每个像素特征值都已承接，也不证明质量可用或风险已明确。

## 2. 输入与输出

输入：

```text
自我_建立观察帧存在 的动作动态
当前观察帧存在
帧宽度
帧高度
预期像素数量
当前观察特征帧中的像素源数据
```

输出：

```text
像素观察存在数量
缺失像素数量
重复映射数量
坐标回查可用状态 = 可用 / 不可用
帧内编号回查可用状态 = 可用 / 不可用
像素覆盖状态 = 已覆盖 / 条件不足
动作动态 / 来源动态证据
```

## 4. 禁止越界

```text
不得把像素覆盖已覆盖写成像素特征值承接已完成；
不得把 100% 像素回查解释为完整视觉分割；
不得写 基础观察事实可用状态；
不得写 基础风险判断状态。
```

## 5. 实施步骤

```text
P1 复核像素索引方法登记、派发和当前观察帧输入读取。
P2 依据帧宽、高和预期像素数量建立像素观察事实索引。
P3 统计像素观察存在数量、缺失像素数量和重复映射数量。
P4 当且仅当数量等于预期且缺失/重复为 0 时写 像素覆盖状态=已覆盖。
P5 写入坐标回查和帧内编号回查状态，并输出动作动态证据。
```

