# S1d-4b 本能动作管理器外层阶段拆分方案 v0.1

日期：2026-06-07

## 1. 目标

```text
继续拆 自我_提交任务状态变化 的执行本能方法耗时。
本切片只在本能动作管理器外层拆阶段，不改变本能动作函数签名、返回结构和任务状态提交语义。
```

## 2. 边界

```text
1. 本能动作管理类只登记、查询、检查和调用，不推进任务、不创建需求、不解释执行结果。
2. 不新增混合返回结构，不修改 本能动作函数 形态。
3. 不在 自我_提交任务状态变化 本能方法内部新增耗时日志。
4. 不跳过 提交任务状态变化 本能方法、任务状态动作动态、运行虚拟存在或输出结果场景。
5. 只对 自我_提交任务状态变化 的慢调用输出外层阶段耗时。
```

## 3. 最小实现

```text
在 本能动作管理类::执行功能函数 外层增加阶段计时：
    检查是否可调用；
    查询已注册动作；
    动作函数调用；
    运行码写回；
    总耗时与最慢阶段。

日志锚点：
    本能动作管理/执行功能函数/阶段耗时

触发规则：
    仅 本能ID=自我_提交任务状态变化；
    总耗时或任一阶段超过 10000us。
```

## 4. 验证预测

```text
构建：
    Debug x64 应通过。

真实运行：
    .\x64\Debug\鱼巢.exe --self-check-log --self-check-log-wait-ms=10000 应退出码 0。

日志：
    应出现 本能动作管理/执行功能函数/阶段耗时。
    若 动作函数调用 仍是最慢阶段，下一刀继续定位统一方法环境或状态提交本体。
    若 检查是否可调用 或 运行码写回 成为主耗时，则先治理对应外层桥。

负向核对：
    不应出现 状态提交确认失败、状态版本错配、后台worker工作项进入死信、拒绝归并完成项。
```

## 5. 执行结果 2026-06-07

```text
已实现：
    本能动作管理类::执行功能函数 对 自我_提交任务状态变化 慢调用输出外层阶段耗时。

构建：
    msbuild .\鱼巢.vcxproj /p:Configuration=Debug /p:Platform=x64 /p:LinkIncremental=false /m
    退出码=0，警告=既有 LNK4075。

真实运行：
    .\x64\Debug\鱼巢.exe --self-check-log --self-check-log-wait-ms=10000
    退出码=0。

日志证据：
    20:10 窗口 本能动作管理/执行功能函数/阶段耗时 33 条；
    平均总耗时约 279475us，最大 494529us；
    动作函数调用平均约 275322us，最大 491107us；
    检查是否可调用平均约 3235us，最大 24875us；
    运行码写回平均约 208us，最大 396us。

负向核对：
    20:09-20:11 窗口未检索到 状态提交确认失败；
    未检索到 状态版本错配、后台worker工作项进入死信、拒绝归并完成项。

结论：
    本能动作管理器外层桥不是主耗时；
    慢点进入动作函数内部；
    下一刀应定位统一本能方法环境 helper 的 同步方法节点到虚拟存在 / 本轮运行虚拟存在 / 确认规格 / 条件节点解析 / 二次同步，
    仍不在具体 自我_提交任务状态变化 函数体内新增耗时日志。
```
