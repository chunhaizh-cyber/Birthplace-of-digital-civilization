# P3c 任务目标升级提交契约小方案 v0.1

日期：2026-06-09

状态：已落地；真实运行未自然命中新强目标升级样本，待后续自然样本复核。

## 1. 依据

```text
P3b 已闭合：已有任务目标覆盖新需求目标时复用，不再新建并行任务。
剩余缺口：新需求目标强于已有任务目标时，当前只记录 `同目标任务目标升级待契约`。

代码证据：
    任务目标状态只在任务创建 / 运行壳准备时写入。
    现有 重筹办任务 治理请求会调用 私有_绑定任务需求关系 和 私有_准备任务运行壳；
    若直接把强目标新需求作为来源需求提交，会改写既有任务的来源需求，破坏多需求共享边界。
```

## 2. 目标

```text
在任务管理界面线程内部建立同目标任务目标升级契约：
    不改写既有任务的 对应需求 / 来源需求。
    只把新强需求绑定到既有任务。
    将任务目标状态升级为新强需求目标状态。
    同步任务虚拟存在中的任务目标状态 / 任务目标 / 任务完成条件目标状态。
    通过 提交任务状态推进请求 把可重筹办任务推进到 待重筹办 / 筹办。

只处理非执行中的活动任务：
    未启动 / 筹办中 / 待重筹办 / 等待中 / 挂起 / 无法执行 / 就绪 / 排队中。

不处理：
    执行中 / 运行中 的目标抢占。
    完成 / 已结算任务的结果证据复用。
    多需求共享任务完成后的结果扇出。
```

## 3. 禁止范围

```text
不得优化相机外设四个方法。
不得修改 结构_任务工作结果。
不得裸写任务状态；目标升级后的状态变化必须走 提交任务状态推进请求。
不得绕过 提交任务状态变化。
不得把任务筹办 / 任务执行恢复成本能方法。
不得新增 mock、fixture、伪入口、伪动作动态或 `--*-check` 回归入口。
```

## 4. 验收

```text
Debug x64 构建通过。
真实运行 self-check-log 退出码 0。
若自然命中新强目标：
    日志出现 `同目标任务目标升级提交`。
    不创建并行任务。
    新需求绑定到既有任务。
    状态变化经 `任务状态动作动态=<动态主键>` 留证。
若未自然命中新强目标：
    记录未自然命中，不新增模拟样本。
日志不出现任务状态裸写、任务状态逻辑错误、旧完整本能调用锚点或 [FTL]。
```
