## 1. 总口径

```text
世界状态转换因果树：
    挂在世界树根链。
    存储所有状态转换、动作动态、因果模板、因果实例和状态变化线索。

目标投影树：
    从世界状态转换因果树中按目标维度生成的只读视图。
```

目标维度第一版包括：

```text
安全
服务
学习
方法维护
自维护
其他后续目标
```

安全目标投影树回答：

```text
哪些状态转换可映射到安全目标改善；
该转换对应哪些安全权重类型；
在安全投影下属于第几层结算贡献；
需要哪些证据；
是否有副作用或竞争原因。
```

## 2. 本体与投影边界

### 2.1 因果树本体

因果树本体存储最小语义：

```text
状态 S_before
    + 动作 A / 动态 D
        -> 状态 S_after
            + 证据 E
            + 条件 C
            + 置信度 / 稳定度
            + 副作用
            + 来源引用
```

它不得被安全值、服务值或某个账本字段窄化为唯一根。

### 2.2 目标投影树

目标投影树只读，不新增权威因果节点。

```text
安全目标投影树：
    查询所有最终可映射到安全目标的状态转换路径。

服务目标投影树：
    查询所有最终可映射到服务目标的状态转换路径。

学习 / 方法 / 自维护投影树：
    查询所有最终可映射到对应目标维度的状态转换路径。
```

### 2.3 安全目标投影与安全账务投影

必须区分：

```text
安全目标改善路径：
    事实状态转换投影。
    说明世界、任务、方法或观测目标特征如何改善安全。

安全值变化路径：
    账务状态转换投影。
    说明结算方法如何把已验收贡献写入安全值。
```

示例：

```text
事实路径：
    降低负载动作
        -> 温度下降
            -> 宕机风险下降
                -> 安全目标改善

账务路径：
    叶子任务业务动作 D0
        -> 需求满足登记 D1
            -> 结算叶子任务价值 D2
                -> 安全值账本增加
```

D2 是账务因果边，不是物理安全因果边。

## 4. 叶子任务业务动作前置预判

叶子任务业务动作 D0 生成 / 执行前，必须先执行：

```text
叶子任务因果投影预判。
```

它查询：

```text
1. 叶子任务目标宿主。
2. 叶子任务目标特征类型。
3. 该目标特征类型可映射到哪些权重类型。
4. 在每个权重类型下属于第几层结算贡献。
5. 预计会造成什么状态转换。
6. 需要哪些 before / target / actual 证据。
7. 是否存在副作用或竞争原因。
```

预判输出结构建议：

```text
结构_叶子任务因果投影预判：
    来源叶子任务
    来源需求
    目标宿主
    目标特征类型
    候选权重类型集
    每个权重类型对应：
        目标投影路径
        结算贡献层级
        层级比例分子
        因果距离层级
        证据要求
        副作用检查项
        是否允许形成 D0
        是否允许后续结算
```

该预判不是结算，不写安全值、不写服务值、不写任务状态、不写需求树、不生成动作动态。

## 5. D0 / D1 / D2 分工

```text
D0：叶子任务业务动作动态
    记录事实状态转换。
    绑定目标特征类型、权重类型候选、层级候选、预期状态转换、证据要求和因果路径引用。

D1：需求满足动作动态
    记录治理满足。
    只登记目标是否满足，不负责账务入账。

D2：结算叶子任务价值动作动态
    记录账务入账。
    读取 D0 / D1 / 实际结果 / 因果投影，最终决定是否入安全值、服务值或其他价值账。
```

禁止：

```text
D0 直接涨安全值；
D2 反过来证明 D0 有效；
账务因果边伪装成物理因果边。
```

## 7. 生成算法

### P1. 读取世界树根链状态转换信息

读取：

```text
状态节点
动态节点
状态变化线索
完整因果模板
因果实例
来源输入场景
来源输出结果场景
```

### P2. 建立状态转换路径

按：

```text
S_before + A / D -> S_after
```

生成只读路径，并标记边类型：

```text
物理因果
观测因果
治理因果
账务因果
引用关系
```

### P3. 按目标维度生成投影

对每条状态转换路径，判断其是否可映射到：

```text
安全目标
服务目标
学习目标
方法维护目标
自维护目标
```

### P4. 判定权重类型与结算贡献层级

同一目标特征类型可在不同投影下拥有不同层级。

示例：

```text
方法稳定度提高：
    学习投影：可能是一层或二层学习收益。
    安全投影：通常是第三层安全支撑。
    服务投影：也可能是第三层服务支撑。
```

### P5. 输出叶子任务预判

输出：

```text
目标特征类型
候选权重类型
目标投影路径
结算贡献层级
因果距离层级
证据要求
副作用检查项
是否允许形成 D0
是否允许进入结算候选
缺失证据
```

## 8. 回归命令建议

新增：

```text
--state-transition-causal-projection-check
```

第一版断言：

```text
1. 能从世界树根链生成状态转换因果投影。
2. 投影节点能追溯到世界树状态 / 动态 / 因果模板 / 因果实例。
3. 安全目标投影不是因果本体。
4. 安全值账务变化被识别为账务因果边，而非物理安全因果边。
5. 叶子任务目标特征可查询候选权重类型。
6. 叶子任务目标特征可查询安全 / 服务 / 学习等投影下的结算贡献层级。
7. 同一特征在不同目标投影下允许不同层级。
8. 未处理副作用会让路径降级为候选或禁止结算。
9. 缺少 before / target / actual 证据时，不允许进入正式结算。
```

兼容别名：

```text
--safety-causal-tree-check
```

该命令后续应改为调用状态转换因果投影检查中的安全目标投影子项。

## 10. 停止条件

```text
1. 若生成投影需要直接写需求树，暂停。
2. 若生成投影需要直接写安全值 / 服务值，暂停。
3. 若生成投影需要生成动作动态，暂停。
4. 若无法从现有因果模板 / 动作动态 / 父链获得任一证据，暂停并补日志。
5. 若需要新增基础信息结构，先确认，不直接实现。
6. 若实现又把安全值账务变化当成因果总根，暂停。
```

## 11. 最终口径

```text
因果树本体存储所有状态转换信息，挂在世界树根链上。

安全目标投影、服务目标投影、学习收益投影、自维护投影等，
不是独立权威树，而是从世界状态转换因果树中按目标维度生成的只读投影。

安全值变化状态只是账务状态转换投影之一；
它不能作为事实安全改善的因果根。

叶子任务业务动作生成前，必须先查询状态转换因果树，
取得该叶子任务目标特征类型对应的权重类型候选、
目标投影路径、结算贡献层级和证据要求。

叶子任务业务动作 D0 只记录事实状态转换；
需求满足动作 D1 只记录治理满足；
结算动作 D2 只记录账务入账。
```

一句话：

```text
先用全局状态转换因果树判断“这个叶子任务改了什么、属于哪类权重、在该权重下是第几层”；再执行业务动作；最后才按实际状态转换和需求满足证据结算。
```
