## 1. 输入

```text
当前外设姿态
允许旋转范围
质量失败原因
深度空洞区域
目标 ROI 或主候选方向
```

## 2. 输出

```text
外设观察姿态调整结果
新姿态
重采样观察特征帧
调整前后质量指标对比
动作动态 / 来源动态证据
```

## 3. 转换逻辑

```text
在允许范围内选择若干候选姿态。
逐姿态重采样并评估质量。
选择质量最高且满足阈值的姿态。
若没有可控姿态接口，占位执行输出条件不足，不伪装成功。
```

## 4. 禁止越界

```text
不得在没有硬件姿态接口时把占位方法标记为可执行成功。
不得把人类手动转动相机伪装成自我方法动作动态。
不得让姿态调整直接写基础观察事实可用。
```
