```text
P14 多候选观察存在落账与全帧像素归属
```

它补充的是观察质量和认知补偿线，防止后续把“轮廓不准 / 深度不完整”误写成“相机识别不准”。

## 1. 目标

分清两种提升：

```text
Q 线提升 1：相机输出观察特征质量
    输出 RGB、深度、深度有效性、XYZ、对齐状态和质量摘要。

Q 线提升 2：自我对不完整特征的认知补偿
    用空间坐标、深度、彩图、轮廓、历史帧和质量诊断共同验证，
    对缺失区域生成补观察、融合、多帧或内部细分需求。
```

最终目标：

```text
自我能知道哪些是可靠观察、哪些是滤波观察、哪些是补全猜测、哪些是未解释区域、哪些轮廓有空间支持、哪些轮廓只是颜色幻象。
```

## 2. 当前边界

已成立口径：

```text
相机只提供观察特征；
自我确认存在；
顶层存在确认以空间坐标连续性和范围坐标稳定性为主；
轮廓只作注意力入口、投影边界、拆分合并提示和显示辅助；
像素观察存在只是当前帧最小观察事实单位。
```

不得宣称：

```text
相机发现存在
相机直接识别对象更准
补全深度是真实深度
彩图轮廓就是对象边界
跨帧身份稳定
语义识别完成
目标可见性 / 在场状态闭合
```

## 3. 实施切片

### Q1 完整观察特征帧 DTO

目标：

```text
将适配器结果从 帧宽高 + 帧号 + 轮廓数量 升级为 RGB-D + XYZ 观察特征帧。
```

输出：

```text
颜色RGB
原始深度毫米
滤波深度毫米，可空
补全深度毫米，可空
深度有效性 mask
空间坐标毫米XYZ
彩色深度已对齐
对齐目标
深度有效率
空间坐标有效率
帧质量评分
```

验收：

```text
真实 D455 单帧输出 W * H 的 RGB、深度、有效性和 XYZ 结构。
无效深度不得写入 I64_MAX 作为真实值。
自我方法消费已落账观察特征帧，不重复采集。
```

### Q2 观察帧质量诊断摘要

目标：

```text
为每个观察帧落账质量摘要，先分类问题再调算法。
```

输出：

```text
深度有效率
深度空洞数量
深度空洞区域集合
彩色深度对齐状态
轮廓闭合率
轮廓断裂数量
空间点有效率
边界深度稳定率
候选存在验证通过率
未解释区域比例
```

验收：

```text
质量摘要可追溯到像素观察事实、深度有效性 mask、空间候选、轮廓集合和未解释区域。
质量摘要只作诊断和条件缺口，不替代权威事实集合。
```

### Q3 RealSense 后处理链

目标：

```text
在双目相机适配器内部增加可配置深度后处理链。
```

链路：

```text
原始深度
    -> 深度范围裁剪
    -> Decimation
    -> Depth to Disparity
    -> Spatial filter
    -> Temporal filter
    -> Disparity to Depth
    -> Hole filling，可选
    -> 深度有效性 mask
    -> XYZ 空间坐标
```

验收：

```text
后处理步骤不登记为自我本能方法。
原始深度、滤波深度、补全深度可同时保留。
孔洞填充只生成补全候选，不覆盖原始事实。
```

### Q4 深度三套口径落账

目标：

```text
建立 原始深度 / 滤波深度 / 补全深度 的事实和置信边界。
```

处理：

```text
像素观察存在.原始深度
像素观察存在.滤波深度
像素观察存在.补全深度
像素观察存在.深度来源
像素观察存在.深度稳定性
像素观察存在.深度邻域一致性
```

验收：

```text
存在确认优先级为 原始有效深度 > 滤波深度 > 补全深度。
由补全深度支撑的候选必须标记低置信或待验证。
```

### Q5 轮廓分层和置信度

目标：

```text
将单一轮廓升级为彩图轮廓、深度轮廓、空间候选投影轮廓和融合轮廓。
```

输出：

```text
轮廓.来源类型
轮廓.闭合度
轮廓.深度支持率
轮廓.颜色支持率
轮廓.空间支持率
轮廓.是否跨越深度断裂
轮廓.是否穿过深度无效区域
轮廓.是否依赖补全深度
轮廓.置信度
```

验收：

```text
顶层存在确认仍以空间候选为主，轮廓只修边和辅助验证。
内部世界细分中可提高彩图轮廓和深度轮廓权重。
```

### Q6 静态多帧深度融合

目标：

```text
在相机不移动、目标场景静止时，用连续 N 帧补偿单帧深度空洞和噪声。
```

输出：

```text
观察帧组.融合深度图
观察帧组.融合深度有效性
观察帧组.深度稳定性图
观察帧组.每像素深度方差
观察帧组.融合依据帧集合
```

推荐：

```text
N = 3 到 7 帧
中位数优先
保留每像素方差
方差过大标记为不稳定
```

验收：

```text
融合结果不覆盖单帧事实。
边界跳变区域不得作为强存在确认依据。
```

### Q7 未解释区域补观察需求

目标：

```text
把深度空洞、轮廓断裂、对齐缺失、有效点不足等质量问题变成结构化缺口。
```

输出：

```text

候选存在.缺失原因
候选存在.未解释区域
候选存在.待补观察区域
候选存在.补全候选
候选存在.低置信轮廓
```

可派生需求：

```text
重新取得观察特征帧
调整双目相机工作模式
缩小 ROI 重新观察
融合稳定观察帧深度
对目标存在进行内部世界细分
对未解释区域继续观察
```

验收：

```text
缺口进入任务筹办可读取的事实或回执。
不得把补全猜测落成已确认存在。
```
