## 1. 计划目标

把当前观察材料质量判定入口逐步整理为符合 1175 的“观察材料质量收束入口”：

```
1. 用 I64 六态质量收束状态表达判断型枚举。
2. 保留现有兼容等级和能力等级，但不让普通布尔值 成为唯一机器判断来源。
3. 将质量状态、承接能力等级、缺口集合和可回查证据组合成上层读取契约。
4. 让观察 / 识别 / 扫描 / 跟踪 / 存在体素融合前置检查读取质量收束结果。
5. 不让 D455 采集线程、日志、控制面板或错误码直接写材料质量状态。
```

本计划的第一轮代码执行必须从 S0 只读扫描开始。S0 只确认真实入口、字段类型、函数位置、调用路径和验证入口；S0 不能修改代码。

## 3. 设计条款清单

### 3.1 必须实现

```
M1. 提供 I64 六态质量收束状态：
    0 未评估
    1 可用
    2 低质量
    3 不可用
    4 部分可用
    5 需复验

M2. 质量状态必须由证据特征族收束：
    来源与可回查
    时间与新鲜度
    深度有效性
    彩色 / 红外 / 对齐
    坐标基准
   感兴趣区域 / 掩码 / 候选完整性
    任务与目标约束
    跨帧稳定
    先验冲突预留

M3. 兼容质量等级 `未定义 / 不合格 / 可用 / 优质` 不得等同于规范质量状态。

M4. `优质` 只表示可用状态下的高等级证据强度，不是第七个质量状态。

M5. 质量缺口必须能回查输入证据。

M6. 可回查判断不能只读句柄非空；必须纳入材料页解析状态、存活时限、来源链和材料页生命周期。

M7. 上层入口读取质量状态、能力等级和缺口集合，不得只读 `可进入识别方法` 等 布尔值 作为唯一门。

M8. 目标观察约束中的可强匹配 / 可降级匹配等 布尔值 在本计划中只标为兼容债务，不扩张。
```

### 3.2 禁止实现

```
F1. 不得新增结构体承载质量收束结果。
F2. 不得新增普通布尔值 字段表达可用、可交付、可识别、可扫描、可跟踪。
F3. 不得把日志文本中的“可用”作为机器判断。
F4. 不得把帧质量评分单独当成材料质量状态。
F5. 不得把句柄非空等同于材料可回查。
F6. 不得把 L0 原始材料直接作为 L1 稳定材料。
F7. 不得把材料质量可用解释成稳定存在确认。
F8. 不得让外设线程直接写世界树事实或需求满足状态。
F9. 不得在未接入场景体素快照前硬编码先验冲突。
F10. 不得因质量不足静默丢弃；必须输出缺口、等待、复验或诊断材料。
F11. 不得从工程性能测量材料收束观察材料质量状态。
```
