# 状态类逻辑纠偏计划 v0.1

日期：2026-06-20

状态：由因果类外部数据读取纠偏触发；当前等待动态类第一优先闭合后执行。

## 0. 目标

补齐状态类只读功能函数，让因果类不再直接解释 `状态节点主信息类` 字段。

当前触发缺口：

```text
因果类.cpp 直接读取：
    状态节点主信息类::状态主体
    状态节点主信息类::状态特征
```

## 1. 第一优先缺口

建议函数：

```cpp
状态节点类* 按主键解析状态节点(const std::string& 主键) const noexcept;

bool 读取状态主体与特征(
    const 状态节点类* 状态,
    基础信息节点类*& 状态主体,
    特征节点类*& 状态特征) const noexcept;

特征节点类* 读取状态特征(const 状态节点类* 状态) const noexcept;
基础信息节点类* 读取状态主体(const 状态节点类* 状态) const noexcept;
```

实现边界：

```text
1. 函数归属 状态类.h/.cpp。
2. 不新增状态主信息字段。
3. 不创建状态，不改状态值，只读解析。
4. 主键解析不允许隐式创建节点。
```

## 2. 跨类缺口转向规则

执行本计划时，如果发现当前切片必须依赖其它类新增或补齐功能函数，按以下规则处理：

```text
1. 后续任意类缺少当前切片所需功能函数时，不在状态类或调用方临时拼字段、解释其它类主信息或新增平行结构体。
2. 若对应类已有逻辑纠偏计划，则把当前缺口加入该计划，并放到第一优先位置。
3. 若对应类没有逻辑纠偏计划，则生成 `计划/YYYYMMDD_<类名>逻辑纠偏计划_v0.1.md`，并把当前缺口作为第一优先切片。
4. 新生成或被修改的逻辑纠偏计划必须包含本“跨类缺口转向规则”，保证后续继续发现缺口时仍按同一调度口径处理。
5. 更新 `计划/计划索引.md`：把新生成或新修改的计划临时提升为第一优先计划；原计划和原切片记录为返回点。
6. 只执行新计划的第一优先缺口切片，不顺带推进新计划后续候选项。
7. 第一优先缺口闭合后，立即停止该新计划，更新计划索引返回原计划和原切片。
8. 若第一优先缺口切片不能闭合，保留该计划为当前阻塞，不回到原计划继续补丁化绕过。
```
