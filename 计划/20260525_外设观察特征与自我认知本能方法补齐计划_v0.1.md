# 20260525_外设观察特征与自我认知本能方法补齐计划 v0.1

## 0. 依据

本计划是 `20260524_双目相机像素级观察存在化阶段目标计划_v0.1.md` 的实现子计划，依据以下规范收束外设方法和自我方法边界：

```text
规范/外设观察特征与自我场景认知本能方法分层规范20260525.md
规范/本能函数实现规范20260430.md
规范/方法动作动态硬规则规范20260512.md
规范/任务筹办按方法能力查找到就绪因果链规范20260513.md
```

上位口径：

```text
外设本能方法只负责控制外设、检查外设、取得当前观察特征帧。
自我本能方法负责把观察特征组织成观察帧存在、像素观察事实、空间候选、已确认观察存在、内部世界、变化事件和复现快照。
任务筹办仍按方法结果能力命中目标填充候选，不把控制 / 检查 / 使用 / 自我认知分类硬编码成分派规则。
```

## 1. 当前代码梳理

已存在外设相关入口：

```text
双目相机_使达到可用状态
双目相机_释放
双目相机_检查运行状态
双目相机_刷新当前观察场景
双目相机_发现候选存在
双目相机_取得当前观察帧
双目相机_建立当前帧像素特征索引
```

其中 `刷新当前观察场景`、`发现候选存在`、`建立当前帧像素特征索引` 按新规范只能作为兼容入口或自我认知链迁移入口，不再作为相机直接理解存在的因果证明。

已存在自我认知相关入口：

```text
自我_提取空间候选
自我_判断空间候选相对独立性
自我_生成空间候选观察队列
自我_观察单个空间候选并组合存在假设
自我_用空间范围投影覆盖原帧验证像素归属
自我_确认观察存在并更新帧解释状态
```

这些入口已经能支撑摘要级空间候选和观察存在确认，但内部世界递归、变化发现、场景识别快照和 OpenGL 复现数据仍未作为完整本能方法闭合。
