# 特征类 VecI 解释视图完善计划 v0.1

日期：2026-06-10

## 1. 目标

```text
在不改 `特征值主信息类` 结构、不把坐标集合拆入特征子链的前提下，
完善特征类对有符号坐标集合的表达、读取、校验和比较能力。

核心路线：
    底层权威容器仍为 `特征值主信息类::VecIU64`；
    `VecI64` 只作为坐标类特征的解释视图；
    有符号坐标通过确定性 ZigZag 编码写入 VecIU64；
    平面轮廓 / 空间极值轮廓由特征类型解释 VecIU64 的坐标维度和语义；
    识别 / 扫描 / 跟踪只通过专用比较函数生成二次特征，不覆盖 `特征值主信息类::比较`。
```

```text

        using VecIU64 = std::vector<std::uint64_t>;

        取VecU只读指针(VecU句柄);
```

```text
现状缺口：
    1. 没有统一 I64 <-> U64 ZigZag 编码 / 解码工具。
    2. 没有 VecI64 -> VecIU64 / VecIU64 -> VecI64 的统一包装入口。
    3. 写入 / 读取 VecI64 坐标类特征时，调用处容易绕过解释规则。
    4. 平面轮廓和空间极值轮廓缺统一格式校验函数。
    5. 轮廓相似、扫描变化、跟踪连续性缺特征类型专用比较入口。
    6. 当前规范已有“平面轮廓 VecIU64”口径，但 “可能为负坐标必须沿用 I64 到 VecIU64 编码” 的具体编码规则还需要落到代码和计划验收中。
```

## 4. 硬边界

必须遵守：

```text
1. 不修改 `特征值主信息类` 字段。
2. 不新增 `特征值主信息类::VecI64`。
3. 不在 `特征值主信息类` 中增加“编码类型”或“业务类型”字段。
4. 不把平面轮廓、空间极值轮廓、掩码、局部图这类整体值拆成特征子链。
5. `VecI64` 是解释视图，不是新的底层存储河道。
6. `特征值主信息类::比较` 只保留去重、排序、绝对相同用途。
7. 轮廓相似、扫描变化、跟踪连续性必须由特征类型专用比较函数生成二次特征。
8. 观察是合法写入新一阶平面轮廓的路径；识别 / 扫描 / 跟踪只读轮廓并生成二次特征、状态动态或缺口。
9. 任何真实行为验收不得使用模拟样本、夹具、伪造入口、伪造动作动态或 `--*-check` 回归命令。
```

允许例外：

```text
只有当某个点本身需要成为可独立认知的存在、子存在、操作目标或需求目标时，才另行制定子链 / 子存在计划。
当前平面轮廓、空间极值轮廓、掩码、局部图不进入该例外。
```

### P3：特征类型解释规则

目标：

```text
由特征类型决定 VecIU64 的解释方式，不由值节点决定。
```

规则：

```text
平面轮廓:
    VecIU64_ZigZag_I64_二维坐标链
    每 2 个 I64 为一个二维坐标
    第一个二维坐标为轮廓中心
    后续二维坐标为边界点
    后续点按轮廓遍历顺序解释

空间极值轮廓:
    VecIU64_ZigZag_I64_三维坐标链
    每 3 个 I64 为一个三维坐标
    第一个三维坐标为空间中心
    后续三维坐标为空间极值点 / 边界点
    后续点按采集顺序解释
```

执行：

```text
1. 优先复用现有语素词入口。
2. 若调用处需要统一引用，再在 `自我类.特征定义` 中补最小特征类型 helper。
3. 不新增 `枚举_特征值编码类型` 到 `特征值主信息类`。
```

验收：

```text
能从特征类型判断轮廓维度和解释规则。
同一个 VecIU64 仍允许被不同特征类型按不同规则解释；值节点本身不携带业务解释。
```

### P4：格式校验函数

目标：

```text
把轮廓格式错误尽早报出，不让错误 VecIU64 静默进入识别 / 扫描 / 跟踪。
```

建议接口：

```cpp
bool 校验平面轮廓VecI64(const VecI64& 值) noexcept;
bool 校验空间极值轮廓VecI64(const VecI64& 值) noexcept;
bool 校验坐标类VecI64_按特征类型(const 语素入口节点类* 特征类型, const VecI64& 值) noexcept;
```

校验规则：

```text
平面轮廓:
    size >= 2
    size % 2 == 0

空间极值轮廓:
    size >= 3
    size % 3 == 0
```

验收：

```text
非法长度必须返回失败并记录明确错误或缺口。
不得通过截断、补 0、静默忽略尾值来兜底。
```

### P5：轮廓专用比较函数

目标：

```text
新增平面轮廓 / 空间极值轮廓的专用比较入口，输出可入账的二次特征材料。
```

首版建议：

```text
平面轮廓比较：
    中心偏差
    点数量差异
    轮廓点平均误差
    轮廓点最大误差
    综合轮廓匹配评分 Q10000

空间极值轮廓比较：
    空间中心误差
    极值点数量差异
    极值点平均误差
    极值点最大误差
    空间轮廓匹配评分 Q10000
```

边界：

```text
首版可只比较同维度、同点数或明确可对齐的点链。
点数不等时先输出点数量差异和不可直接匹配结论，不做自动重采样。
掩码重合率、子轮廓匹配和复杂对齐可作为后续切片，不混入首版。
```

验收：

```text
`特征值主信息类::比较` 不变。
轮廓比较结果通过二次特征 / 状态动态 / 缺口路径表达。
比较函数能区分：
    不可比较；
    格式非法；
    点数量不一致；
    中心偏差；
    平均误差；
    最大误差；
    匹配评分。
```

### P7：识别 / 扫描 / 跟踪读取和比较接入

目标：

```text
识别、扫描、跟踪读取轮廓时解码为 VecI64，并使用 P5 专用比较生成二次特征。
```

执行：

```text
识别：
    读取外设观察存在.平面轮廓 和候选自我存在 / 已有存在的平面轮廓；
    生成平面轮廓匹配评分、平均误差、最大误差和唯一性 / 冲突材料；
    不直接写新的世界存在一阶轮廓。

扫描：
    有可比历史时读取当前 / 基准平面轮廓；
    生成轮廓差异值、变化候选状态、值域冲突或无变化结论；
    首次扫描仍只生成发现存在 / 发现特征事实，不伪造成变化动态。

跟踪：
    读取目标当前轮廓和上一轮 / 基准轮廓；
    用中心偏差和轮廓匹配评分生成连续性、丢失、重捕获候选材料；
    不把跟踪结果当成全场扫描或全场明确。
```

验收：

```text
识别 / 扫描 / 跟踪没有裸用 VecIU64 字典序比较判断相似。
二次特征结果可在日志或状态快照中追到来源特征、来源场景和来源动态。
```
