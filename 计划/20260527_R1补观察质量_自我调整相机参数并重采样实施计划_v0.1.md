## 1. 输入

```text
当前 D455 配置
质量失败原因摘要
深度有效率
空间坐标有效率
帧质量评分
补观察缺失原因
允许调整参数范围
```

## 2. 输出

```text
相机参数调整动作动态
新参数配置摘要
重采样观察特征帧
重采样前后质量指标对比
参数调整结果状态 = 已调整 / 条件不足 / 无改善
```

## 3. 转换逻辑

```text
深度有效率不足：
    优先尝试深度发射器、激光功率、深度 preset / 曝光 / 增益等硬件支持参数。

彩色 / 深度对齐或轮廓证据不足：
    仅调整对应传感器参数或滤波参数，不改写原始深度事实。

每次参数调整后必须重采样并比较：
    深度有效率
    空间坐标有效率
    帧质量评分
    深度空洞数量
```

## 4. 禁止越界

```text
不得把参数修改本身解释为质量可用。
不得用补全深度覆盖原始深度。
不得把硬件不支持的参数当作已调整。
不得新增模拟帧验证。
```
