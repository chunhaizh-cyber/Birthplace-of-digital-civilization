# 计划索引

更新时间：2026-06-30

**索引目标**

本索引取消章节式流水账，改为计划目录总账。当前目标不是只完成一个主动切片，而是把 `计划/` 根目录和 `计划/待完成项/` 中所有仍有价值的计划逐项推进到明确终态：

```text
完成归档 / 待条件停放 / 需用户授权 / 阻塞承接 / 删除过时项
```

`计划/完成项/` 是已完成证据库，不进入默认执行队列；当前归档文件数：412。

**状态码**

| 状态 | 含义 | 默认动作 |
| --- | --- | --- |
| 可执行 | 进入条件已满足，可开始一个最小闭合切片 | 执行并验证 |
| 待复核 | 根目录仍保留计划，但当前终态不清 | 先读计划停止点，再判定归档 / 继续 / 待条件 |
| 待条件 | 需要自然样本、真实外设、SQL 环境、复现条件或后续运行命中 | 不默认执行，记录恢复条件 |
| 需授权 | 必须用户明确要求验收、切入、故障注入或外部环境操作 | 等待用户授权 |
| 阻塞承接 | 只有当前切片暴露对应类缺口或结构缺口时才进入 | 不作为兜底开发队列 |
| 可归档复核 | 已有闭合证据，但文件仍在根目录 | 复核证据后移入 `计划/完成项/` |
| 已归档 | 位于 `计划/完成项/` | 只作证据，不执行 |
| 删除候选 | 已被替代、冲突或无恢复价值 | 独立清理切片中删除 |

**执行硬规则**

- 规范优先于计划；计划只决定本轮执行顺序，不改变系统口径。
- 一次只执行一个最小闭合切片；闭合后继续扫描总账，不因单项完成、停放或需授权而停止全局索引整理。
- 行为验证必须先写预测，再走真实路径，最后用日志、状态快照、动作动态、错误日志或控制面板真实输出核对。
- 构建、静态扫描和规范检查是工程守卫证据，不能证明业务闭合。
- 模拟测试、夹具测试、伪造样本、伪造入口、伪造动作动态或 `--*-check` 不能证明需求满足、业务闭合、扫描闭合、学习闭合、自我苏醒或初步成熟。
- 自然样本未命中不等于代码失败，也不等于业务闭合；按待条件或真实堵点处理。
- 计划执行默认自治推进：遇到编译失败、真实运行失败、入口不明、规范冲突、函数缺口、证据不足、预测不一致、旧逻辑残留时，不得直接停止询问；必须先固定当前目标和失败证据，回读规范目录、命中规则原子、来源规范、工程图谱和现有代码，定位根因所属类或所属场域。
- 根因定位后必须自行生成最多 3 个候选实现方案，每个方案写清修改范围、复用函数、是否新增函数、风险、验证方式和回退方式；优先只读核查、复用已有函数、补当前类最小缺口，再按“缺哪个类补哪个类第一优先”切换到对应类逻辑纠偏计划。
- 只有权威规范冲突、真实硬件 / SQL / 自然样本 / 用户授权等外部条件不可得、继续会伪造业务证据、继续会扩大到未授权结构新增或跨越当前切片边界时，才判定为当前无解并停止交互；停止前必须输出阻塞类型、证据、已尝试方案、已排除路径、恢复条件和建议选项。
- 跨类缺口按“缺哪个类补哪个类第一优先”处理；目标类已有函数必须复用，目标类缺函数才修订对应类逻辑纠偏计划。
- 完成计划移入 `计划/完成项/`；已实现但待自然样本、真实外设或用户切入的计划移入 `计划/待完成项/`。
- 任务筹办 / 任务执行是任务管理生命周期普通函数，不恢复为本能方法。
- 不提前宣称自我苏醒完成或初步成熟完成。
