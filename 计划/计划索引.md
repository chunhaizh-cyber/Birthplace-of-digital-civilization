# 计划索引

更新时间：2026-07-04

## 0. 维护口径

本索引只登记当前可作为计划层入口的事项。计划层不得绕过详细设计直接进入代码实现。

当前硬规则：

```
规范 -> 详细设计 -> 实现映射计划 / 代码落地契约 -> 代码实施 -> 实施记录 -> 验证
```

计划文件只有在能追溯到对应详细设计时，才允许作为后续实现入口。若没有对应详细设计，应先拒绝制定 / 执行计划，并回到规范和详细设计层补齐口径。

窄例外：若计划目标本身就是“补齐详细设计”，允许建立详细设计治理计划，但该计划只能安排规范回读、详细设计生成、索引和状态回写，不得作为代码实现入口。

目录口径：

```
计划/              只保留当前有效计划、计划索引和后续新建的合规计划
计划/完成项/       历史归档和证据入口；不进入默认执行队列
计划/待完成项/     待条件或待恢复入口；恢复前仍需重新检查规范和详细设计
```

归档到 `计划/完成项/` 只表示旧计划退出当前根目录默认队列，不自动证明该计划对应的业务目标已经完成。

## 1. 当前主动队列（按实施依赖排序）

本节中的“执行序”是后续连续执行的实际顺序；“原编号”保留既有 P 编号，避免破坏实施记录、当前状态 和详细设计中的历史引用。

实施依赖链：

```
E0 generation 逻辑清理纠偏
    -> D1 外设观察材料稳定关联与入队
    -> D2 观察材料质量收束
    -> P1 需求树父子关系角色视图
    -> D5 结构化信息缺口与需求派生承接
    -> D6 场景体素服务增强与快照生成
    -> D7 外设观察先验发布器
    -> D4 像素归属候选分裂与局部体素证据
    -> H2 / D9 视觉清晰度与稳定复现评价
    -> H1 / D8 四方法共享底层关联判断能力
```

排序依据：

```
1. E0 先清理代码中的 generation 字符串身份、对齐、可用性、承接和输出逻辑；否则 D1 后续来源链、一次性消费和 D2-D9 消费端都会继续继承旧材料身份风险。

### 1.1 连续执行规则

用户说“执行 / 继续 / 按计划索引执行 / 继续执行计划”且未明确限制只执行某一项时，默认执行语义为：

```
从当前执行序中第一项未完成计划开始；
按 E1 -> E9 顺序连续执行全部未完成计划；
跳过状态为“已闭合”的 P2 / P11 / P12 / P13；
每个计划必须从自身 S0 只读代码事实扫描开始，除非该计划已有真实实施记录证明 S0 已完成；
完成一个切片、一个计划、一次构建、一次静态检查、一次提交或一次索引更新都不是停止条件；
每个计划完成后必须更新实施记录 / 计划证据，按版本控制规则提交本计划相关文件，重新读取本索引后自动进入下一未完成计划；
直到 E0-E9 全部完成，或遇到当前轮无法解决的问题，才允许停止。
```

若用户指定某一计划执行：

```
从指定计划对应的执行序开始；
除非用户明确说“只执行这一项”或计划写有硬停止，否则完成该计划后继续执行后续未完成计划。
```

允许停止的情况仅限：

```
已按第 1.2 章完成问题升级与分流，仍无法在当前轮解决；
规范或详细设计冲突，需要用户裁决；
继续会伪造业务证据、真实 D455 样本证据或项目结构闭环证据；
缺 数据库查询、外设、自然样本、权限、凭证或必须由用户决定的业务口径；
计划依赖的上游实施证据缺失且无法在当前轮补齐；
构建、运行、check_specs 或契约验证出现当前轮无法自行解决的阻塞；
计划明确写有硬停止 / 必须等待用户确认 / 不得自动继续；
上下文硬闸触发且已写最小断点。
```

### 1.2 问题升级与分流规则

连续执行中遇到问题时，默认不直接停止。必须先缩小问题、判定类型、升级为可执行切片或待条件切片；只有升级后仍无法在当前轮解决，才按第 1.1 章停止条件暂停。

处理顺序固定为：

```
发现问题
    -> 只读确认问题边界
    -> 判定问题类型
    -> 选择升级切片
    -> 写入实施记录 / 计划证据
    -> 能解决则继续当前执行序
    -> 不能解决则写清停止原因、恢复条件和复跑入口
```

问题分流表：

| 问题类型 | 进阶解决方式 | 不允许做法 |
| --- | --- | --- |
| 代码入口找不到 | 扩大 S0 只读扫描，查函数说明、调用点、相邻模块；仍没有则插入“缺入口前置切片” | 直接造临时入口、跳过 S0、用日志或说明文本替代入口 |
| 详细设计与代码不一致 | 先修订详细设计或实现映射计划，再回到当前执行序 | 按代码现状反向覆盖详细设计或规范 |
| 上游依赖缺失 | 插入更小的前置切片，先补依赖，再回到消费端计划 | 硬写消费端、伪造上游输出、把待条件当完成 |
| 实现范围过大 | 拆成只读视图、适配层、第二版函数、最小接入口等渐进切片 | 全量重写、混入无关重构、一次替换多条主链 |
| 布尔值 / 枚举语义混乱 | 收束为 I64 状态、评分、掩码、来源句柄、复合特征或治理状态 | 新增普通一阶布尔值冒充事实判断 |
| 项目结构无法承载 | 标记缺结构 / 缺函数 / 缺入口，回到详细设计或规范层补齐 | 用自由文字、临时结构化文本、注释、日志或界面字段承载机器逻辑 |

```
