# 计划索引

更新时间：2026-06-10

## 0. 索引用途

本文件只作为当前执行路由，不承载完整历史流水账。历史细节从对应计划、实施记录、真实日志、`计划/完成项/` 和 `计划/待完成项/` 查询。

维护规则：

```text
1. 规范优先于计划；计划优先于临时推断。
2. 当前主动队列只保留一个可闭合切片。
3. 已运行内容只保留检查点、证据范围和恢复条件。
4. 待条件项不得混入当前主动队列。
5. 已完成计划移入 计划/完成项/；已实现但待自然样本、待真实外设或待用户切入的计划移入 计划/待完成项/。
6. 旧版本被新版本替代时，只保留仍有恢复价值的版本；与当前规范冲突或已被替代且无引用价值的版本删除。
7. 每次行为验证必须先写预测，再走真实运行路径，最后用日志、状态快照、动作动态和错误日志核对。
8. 严禁新增或依赖模拟测试、夹具测试、伪造样本、伪造入口、伪造动作动态或 `--*-check` 回归命令。
9. 任务筹办 / 任务执行是任务管理生命周期普通函数，不恢复为本能方法。
10. 不提前宣称自我苏醒完成或初步成熟完成。
```

```text
2. 行为证据只能来自真实运行日志、状态快照、动作动态、错误日志或控制面板真实输出。
3. 业务通过不得由旧日志、伪造样本、模拟入口、夹具测试或 `--*-check` 回归命令证明。
4. remote compact / stream disconnected / websocket / network error 只表示远程执行通道中断，不得记成项目实现、业务验证或计划逻辑失败。
5. 纯线程生命周期消息只能进入控制面板信息域；不能生成方法动作动态，不能进入自我治理邮箱。
6. 任务筹办、任务执行、任务管理后处理不作为本能方法注册、选择或动作动态来源。
7. 价值结算只能在叶子任务完成后由任务价值反馈链携带实际改变结果状态、完成度和任务自身权重调用；不得作为安全值 / 服务值根任务的普通筹办候选或当前执行方法。
8. `I64_MAX` 是异常哨兵或未设置值，不得进入真实服务结算。
```
