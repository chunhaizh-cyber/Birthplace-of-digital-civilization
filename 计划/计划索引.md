```text
7. 因果条件缺口必须带目标宿主、特征类型、当前值、比较符、目标值和来源因果。

9. 安全候选和安全评估只能生成候选视图；不得写自我风险安全值、风险安全层总值、自我安全值，不得关闭安全根需求。
10. remote compact / stream disconnected / websocket / network error 只表示远程执行通道中断，不改变项目实现状态、验收状态或业务结论。
11. 只能把有证据的范围标为通过，不扩大解释为内部循环闭合、自我苏醒完成或初步成熟完成。
```
