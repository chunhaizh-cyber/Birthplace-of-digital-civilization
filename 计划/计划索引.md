```text
1. 规范优先于计划；计划优先于临时推断。

7. 任务筹办 / 任务执行是任务管理生命周期普通函数，不恢复为本能方法。

```

## 5. 证据闸门

```text
1. 每个切片必须先写预测，再走真实运行路径，最后用日志、状态快照、动作动态和错误日志核对。
2. 缺真实硬件、真实目标样本或真实日志时，只能记录等待条件，不得补模拟样本、夹具入口或伪造动作动态。
3. D455 外设只提供观察帧、报告、d455://句柄、ROI / 掩码 / 点集 / 深度切片等材料。
4. 外设报告、簇候选、模型输出、几何聚类、地图更新或轨迹关联不得直接证明需求满足、当前场景存在集合明确、风险明确或安全值增加。
5. 当前场景特征值明确只表示当前观察范围有效可观测单位全部稳定对应存在；至少一个稳定对应存在只说明扫描可启动，不等于全场景明确。
6. 扫描 / 跟踪不是当前场景特征值明确的完成子需求；第一次扫描只生成发现存在或发现特征事实，不得伪造成动态或变化动态。
7. 因果条件缺口必须带目标宿主、特征类型、当前值、比较符、目标值和来源因果。
8. 未知不能作为已安全证据；没查过、材料缺失、冲突、不可回查或低质量都不得默认满足。
9. 安全候选和安全评估只能生成候选视图；不得写自我风险安全值、风险安全层总值、自我安全值，不得关闭安全根需求。
10. remote compact / stream disconnected / websocket / network error 只表示远程执行通道中断，不改变项目实现状态、验收状态或业务结论。
11. 只能把有证据的范围标为通过，不扩大解释为内部循环闭合、自我苏醒完成或初步成熟完成。
```
