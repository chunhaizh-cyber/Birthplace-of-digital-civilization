# SQL 控制面板运行态同步写入计划 v0.1

更新时间：2026-06-25

## 0. 定位

本计划只解决 SQL Server 作为控制面板显示镜像的问题：

```text
系统启动时清空控制面板运行态 SQL 表；
运行中在项目结构增 / 删 / 改提交成功后同步写入 SQL；
控制面板只读 SQL 显示；
SQL 不作为业务权威源，不参与需求 / 任务 / 方法 / 世界事实裁决。
```

当前已完成前置切片：

```text
A0：新增预处理宏 `鱼巢_开关_启用SQL控制面板同步写入`。
提交：a64b948 添加SQL控制面板同步写入宏开关。
状态：默认开启；编译时可用 `/D鱼巢_开关_启用SQL控制面板同步写入=0` 关闭 ADO 写命令。
```

## 1. 上级依据

```text
规范/禁止性规范20260611.md
规范/自我线程与任务管理线程权责边界规范20260512.md
规范/线程生命周期状态上报与控制面板线程信息规范20260609.md
docs/工程图谱/08_事实来源与写入权限图谱.md
计划/计划索引.md
```

关键边界：

```text
1. 线程不是动作来源。
2. 控制面板显示不得反向成为机器判断依据。
3. 任务状态、需求状态、方法状态、世界事实仍由各自领域提交入口写入项目结构。
4. SQL 同步写入失败只影响显示诊断，不回滚业务结构提交。
5. 不新增后台队列作为第一版路径；第一版采用提交点同步写 SQL。
```

## 2. 只解决什么

```text
1. 启动时清空 SQL 控制面板运行态镜像。
2. 在内存结构增 / 删 / 改成功后，同步写 SQL 当前态表。
3. 同步追加本次运行事件流水，供控制面板显示变化过程。
4. 用预处理宏统一开关同步写库功能。
5. 控制面板逐步改为读取运行态 SQL 表和同步状态。
```

## 3. 不解决什么

```text
1. 不把 SQL Server 改成业务权威数据库。
2. 不做跨启动历史持久账本。
3. 不用数据库恢复项目内存结构。
4. 不让外设线程、控制面板线程或普通线程裸写业务事实。
5. 不在第一版引入后台写入队列、异步消费器或复杂重放机制。
6. 不把当前全量 SQL 投影立即删除；先降级为校准 / 对照 / 字段恢复比对路径。
```

## 4. 项目结构映射

| 业务概念 | 项目承载结构 | SQL 显示承载 | 写入方 | 读取方 | 验证方式 |
| --- | --- | --- | --- | --- | --- |
| 任务状态 | 任务节点 / 任务主信息 / 任务域提交入口 | 当前任务显示项、控制面板事件流水 | 任务管理线程正式提交点 | 控制面板 | 任务创建 / 状态推进后 SQL 行变化 |
| 需求状态 / 满足 | 需求节点 / 需求类更新指令 | 当前需求显示项、控制面板事件流水 | 需求类 / 自我线程裁决入口 | 控制面板 | 需求更新后 SQL 行变化 |
| 方法状态 / 候选 | 方法节点 / 方法类 / 任务筹办候选填充 | 当前方法显示项、控制面板事件流水 | 方法类或任务筹办合法提交点 | 控制面板 | 方法初始化 / 候选变化后 SQL 行变化 |
| 世界事实 / 动态 | 世界树、场景、状态、动态节点 | 当前世界显示项、当前动态显示项、控制面板事件流水 | 世界树类 / 动态类合法提交点 | 控制面板 | 世界事实确认 / 动态追加后 SQL 行变化 |
| SQL 同步开关 | `预处理开关变量.h` 宏 | 无业务承载，仅编译控制 | 编译配置 | 构建系统 / ADO 模块 | 开关 0/1 构建结果和写命令行为 |
| SQL 同步失败 | 日志 / 控制面板同步状态 | SQL投影同步状态或诊断页 | SQL 同步器 | 控制面板 / 人 | SQL 不可用时业务继续、面板显示诊断 |
