最新定案：

```text
当前观察帧新鲜度状态仍然需要；
但不再作为独立本能方法实现。

新鲜度判定应收束为：
    观察报告承接规则；
    任务管理报告时效过滤规则；
    基础观察事实可用性判定的内部证据。
```

## 1. 目标

本计划目标不是登记：

```text
自我_判断当前观察帧新鲜度
```

而是建立合法生产链：

```text
当前观察帧.观察年龄
当前观察帧.观察新鲜度状态 == 新鲜 / 过期 / 条件不足
当前观察帧.新鲜度判定时间
当前观察帧.新鲜度失败原因
```

兼容摘要允许同步：

```text
自我所在场景.当前观察新鲜度状态
```

但它只能表示：

```text
自我所在场景.当前观察帧指针对应的观察新鲜度摘要。
```

不得把场景级摘要作为多个观察帧共享的权威真值。

## 2. 生产者口径

合法生产者分两层。

### 2.1 当前基础观察链第一版

在外设报告队列尚未进入当前主动队列前，由：

```text
自我_判断基础观察事实可用性
```

内部读取时间证据和失效证据，顺带计算：

```text
当前观察帧.观察年龄
当前观察帧.观察新鲜度状态
```

然后再决定：

```text
当前观察帧.基础观察事实可用状态
```

这不是把新鲜度独立建成一个方法，而是把新鲜度作为基础观察事实可用性的时效证据。

### 2.2 后续外设报告队列版

进入双目相机外设线程 / 逐簇识别报告 / 扫描变化报告 / 跟踪报告线后，由：

```text
任务管理外设消息承接线程
    -> 按等待项最大时效过滤报告
    -> 命中后生成观察事实承接请求
    -> 自我承接观察报告时写入观察年龄和新鲜度证据
```

外设线程只提供：

```text
报告时间戳
采集时间
报告ID
来源外设
失效 / 丢弃 / 过期原因
```

不直接写自我世界树真值。

## 3. 必须纠偏的旧逻辑

当前代码中已有短路风险：

```text
当前观察特征帧取得状态 == 已取得
观察帧容器状态 == 已建立
    -> 当前观察新鲜度状态 == 新鲜
```

该推理不成立。

正确规则：

```text
当前观察帧.采集时间 > 0
当前时间 > 当前观察帧.采集时间
当前观察帧.观察年龄 < 最大允许观察年龄
当前观察帧.失效状态 == 未失效
当前观察帧.来源外设状态 == 可追溯
    -> 当前观察帧.观察新鲜度状态 == 新鲜
```

如果缺任一证据：

```text
当前观察帧.观察新鲜度状态 == 条件不足
```

如果年龄超限或报告已被标记失效：

```text
当前观察帧.观察新鲜度状态 == 过期
```

## 4. 输入与输出

输入：

```text
当前观察帧
当前观察帧.采集时间
当前时间
最大允许观察年龄
当前观察帧.失效状态
当前观察帧.来源外设状态
当前需求类型 / 等待项时效要求
来源观察报告ID，可选
来源动作动态 / 承接动态
```

输出：

```text
当前观察帧.观察年龄
当前观察帧.观察新鲜度状态 == 新鲜 / 过期 / 条件不足
当前观察帧.新鲜度判定时间
当前观察帧.新鲜度失败原因
自我所在场景.当前观察新鲜度状态，兼容摘要，可选
动作动态 / 来源动态证据
```

## 6. 实施步骤

```text
F0 检查现有直接写入当前观察新鲜度状态的代码路径。

F1 取消短路规则：
       不再由“观察特征帧已取得 + 观察帧容器已建立”
       直接推出 新鲜。

F2 补齐或复用时间证据字段：
       当前观察帧.采集时间
       当前观察帧.观察年龄
       当前观察帧.新鲜度判定时间
       当前观察帧.失效状态
       当前观察帧.来源外设状态

F3 在 自我_判断基础观察事实可用性 的实现切片中计算新鲜度证据。

F4 基础观察事实可用性只读取合法的新鲜度判定结果；
       缺时间证据时写 条件不足；
       过期时写 过期；
       不得继续默认写 新鲜。

F5 控制面板和日志显示观察年龄、最大允许观察年龄、新鲜度状态和失败原因。
```
