# S1d-4c 本能方法自身环境阶段诊断方案 v0.1

日期：2026-06-07

## 1. 目标

```text
在 S1d-4b 已证明本能动作管理器外层桥不是主耗时后，
继续定位 自我_提交任务状态变化 动作函数调用内部的统一方法环境成本。
```

## 2. 边界

```text
1. 不在 自我_提交任务状态变化 具体方法体内新增耗时日志。
2. 只在统一 helper 确保本能方法自身环境 中记录慢调用阶段。
3. 仅 调用方=自我_提交任务状态变化 时输出日志。
4. 不跳过本能方法环境、运行虚拟存在、规格确认、任务状态写入、动作动态或运行账。
5. 不改变本能动作函数签名和运行结果返回结构。
```

## 3. 最小实现

```text
在 确保本能方法自身环境 中记录：
    确保本能方法；
    首次同步方法节点到虚拟存在；
    本轮运行虚拟存在；
    方法虚拟存在读取；
    条件 / 结果场景；
    确认规格；
    解析条件节点；
    二次同步方法节点到虚拟存在；
    总耗时与最慢阶段。

日志锚点：
    本能方法自身环境/阶段耗时
```

## 4. 验证预测

```text
构建：
    Debug x64 应通过。

真实运行：
    .\x64\Debug\鱼巢.exe --self-check-log --self-check-log-wait-ms=10000 应退出码 0。

日志：
    应出现 本能方法自身环境/阶段耗时。
    若首次同步或二次同步是主耗时，下一刀治理方法虚拟存在同步快路径。
    若本轮运行虚拟存在或运行账是主耗时，下一刀治理运行账 / 运行存在写入。
    若环境 helper 不是主耗时，则继续定位任务状态写入和动作动态输出。

负向核对：
    不应出现 状态提交确认失败、状态版本错配、后台worker工作项进入死信、拒绝归并完成项。
```
