# P3b 覆盖型同目标任务复用最小实现方案 v0.1

日期：2026-06-09

状态：已闭合。主体复用和已有关联任务引用确认小契约均已落地并通过真实日志验证。

## 1. 依据

```text
P3a 只读复核结论：
    发起任务入口当前只按需求主键幂等。
    界面线程创建任务前可以扫描当前任务树。
    需求类::绑定对应任务 可把新需求挂接到已有任务。
    状态比较器可判断已有任务目标是否覆盖新需求目标。
```

## 2. 目标

```text
在 提交任务治理请求 的 发起任务 分支中，创建新任务前先查找可复用同目标任务。

复用条件：
    候选任务处于活动 / 等待 / 可重筹办状态，不能是完成、已结算、失败、取消、超时或无法执行。
    候选任务来源需求未失效。
    目标宿主一致。
    目标特征类型一致。
    满足关系一致。
    场景兼容。
    已有任务目标状态覆盖新需求目标状态。

复用动作：
    不调用 私有_按需求创建任务并初始化。
    只调用 需求类::绑定对应任务，把新需求挂到已有任务；不得改写既有任务的来源需求。
    后续承接 / 工作项裁决仍走原路径。

配套闭合：
    复用后新需求会绑定到已有任务，但自我线程活动需求任务化仍出现
    `活动需求任务化忽略不可解析旧任务引用`。
    该警告会让同一需求再次发起任务化意图，任务管理入口虽能再次复用并避免新建任务，
    但重复请求和重复复用命中仍是性能与流程闭合问题。
    已按 计划/20260609_P3b已有关联任务引用确认小契约方案_v0.1.md 补只读确认入口；
    真实日志窗口 73645 中旧警告为 0，确认跳过重复发起任务 29 条。
```
