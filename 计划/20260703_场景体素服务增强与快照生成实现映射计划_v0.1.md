## 1. 设计条款清单

### 1.1 必须实现

```text
1. 场景体素服务只生成运行期只读快照，不写世界树事实。
2. 快照必须带场景、版本、坐标系版本、生成时间、存在项集合、缺口集合和统计材料。
3. SceneVoxelPrior 只作为视觉中间层的只读先验材料，不作为事实来源。
4. 缺坐标、缺体素、缺坐标系版本、先验图层缺失、快照过期等必须进入缺口材料。
5. AABB / 点附近 / 射线查询只能返回先验候选或粗查询结果，不能裁决遮挡、命中或存在消失。
6. 快照可用性、新鲜度、图层完整性、遮挡解释和自由空间冲突必须按 1175 收束。
7. 场景体素缺口必须能映射到 D5 结构化信息缺口链。
8. 视觉中间层读取快照后只能输出观察候选、评分、解释、冲突候选和缺口。
```

### 1.2 禁止实现

```text
1. 禁止新增长期业务结构体作为默认解法。
2. 禁止让场景体素服务写稳定存在体素、世界树事实、需求满足、动作动态或价值结算。
3. 禁止让视觉中间层写场景体素缓存。
4. 禁止把 SceneVoxelPrior 中存在项当成当前帧确认事实。
5. 禁止把 AABB 命中当成识别完成。
6. 禁止把射线粗命中当成遮挡成立。
7. 禁止新增普通 bool 一阶特征表达先验可用、快照新鲜、遮挡成立、自由空间冲突成立。
8. 禁止用日志、UI、说明文本、普通函数返回 true 或错误码为 0 作为机器判断依据。
```

### 1.3 后续待补

```text
1. 稳定存在体素解码为场景占据体素索引的完整实现。
2. 存在体素场景 AABB / 投影索引的真实代码承载。
3. ROI、预计深度范围图、预计遮挡区域、已知空闲区、未知区、自由空间冲突候选区等先验图层句柄。
4. 快照可用性、新鲜度和图层完整性的复合特征 / 治理收束入口。
5. 维护事件值域扩展后的事件处理策略。
6. 场景体素缺口到结构化信息缺口链的标准化适配函数。
```
