## 1. 目标

把 `特征类.cpp` 中由 `确保点状态(...)` / `确保布尔(...)` 初始化的枚举和布尔点状态，分成两层处理：

```text
枚举值域初始化：
    只建立抽象特征树 I64 点状态，不需要专用本能方法。

实例枚举特征值写入：
    必须有合法生产者，并留下动作动态 / 来源动态 / 规则证据。
```

本计划不为所有枚举值逐个创建本能方法，只补那些运行时必须通过观察、检查、控制、判断才能得出的实例枚举特征值。

## 3. 证据闸门

```text
1. 枚举值域初始化不是实例值写入。
2. `I64区间::点(...)` 状态节点只是抽象值域刻度。
3. `否 / 是` 的 0/1 点状态只是布尔值域定义。
4. 底层特征快照值仍按 I64 / VecU句柄 / 指针句柄 等通用值处理，不新增专门枚举存储类型。
5. 不为任务状态、需求结构角色、方法节点种类、动作句柄类型等结构类枚举逐值创建本能方法。
6. 运行时外设状态、自我安全状态、观察事实状态必须有专用本能方法或自我判定方法。
7. 任务筹办 / 任务执行仍是生命周期普通函数，不恢复为本能方法。
```

禁止宣称：

```text
不宣称所有枚举都已完成生产者登记；
不宣称无生产者实例值已全部清理；

```
