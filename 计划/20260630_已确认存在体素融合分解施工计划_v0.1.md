## 1. 目标

把已确认存在当前的粗体素模型升级为可持续融合、可分解内部结构、可递归承载子存在体素的加工链。

完成后的最小能力：

```text
新增观察体素特征值触发体素加工任务；
深度轮廓生成父体素融合候选；
彩色轮廓生成子轮廓候选；
深度轮廓补充子轮廓空间占据；
父存在和子存在均使用正立方体体素包围盒；
体素加工线程只产候选；
提交入口裁决后才写父体素或创建子存在。
```

## 2. 不解决什么

```text
不解决 SLAM。
不解决复杂姿态估计。
不解决跨相机融合。
不解决语义部件命名。
不把颜色块直接定义为子存在。
不把体素线程定义为事实写入方。
不宣称视觉系统完成、自我苏醒完成或初步成熟完成。
```

## 4. 分步施工

### P0 规范和索引准入

目标：

```text
规范、规则原子、详细设计、流程图和施工计划落盘。
```

验收：

```text
规范目录挂载 050008。
规则原子索引包含 RULE-VOXEL-FUSION-001..008。
流程图 md/html 文件存在。
git diff --check 通过。
```

### P1 数据契约和消费状态

目标：

```text
定义新增观察体素特征值的消费口径；
定义体素加工任务和候选结果包；
确保同一观察特征值只触发一次。
```

验收：

```text
旧当前特征值不会重复生成体素加工任务。
融合结果写回不会递归触发自己。
候选结果包字段均使用项目结构类型。
```

### P2 正立方体包围盒 helper

目标：

```text
实现 N*N*N 正立方体包围盒规则；
外边界空白检查；
最长实际尺寸方向贴有效区边界；
连通体局部包围盒压紧检查。
```

验收：

```text
8*64 彩色轮廓得到 64*64*64 包围盒。
完整存在最长方向最大占据格数为 N-2，不得误写成 N-1。
最外层占据体素被判定为不完整。
局部连通体整层空白会被发现。
凹陷、孔洞、非满边界面不被强行补满。
```

### P3 体素加工工作线程骨架

目标：

```text
新增单工作线程或复用合适工作线程承接体素加工任务；
线程只读输入快照并输出候选结果包。
```

验收：

```text
线程不直接写存在特征。
线程不直接创建子存在。
线程不生成方法动作动态。
停止流程不影响现有线程生命周期。
```

### P4 深度轮廓融合候选

目标：

```text
用深度轮廓生成父体素融合候选；
检查融合点；
无融合点时输出待融合缺口。
```

验收：

```text
有边界相同 / 相邻 / 投影重叠时生成候选。
无融合点时不写父体素。
补全深度不被提升为真实占据。
```

### P5 父体素提交和版本闸门

目标：

```text
提交入口检查基准体素版本；
版本未变才允许裁决父体素候选；
版本变化时重算、合并或挂起。
```

验收：

```text
V1 加工、V1 提交可以进入裁决。
V1 加工、V2 提交不得覆盖。
父体素版本更新可回查。
```

### P6 彩色分解和深度补空间

目标：

```text
彩色轮廓生成子轮廓候选；
深度轮廓补充空间占据和边界；
统计父基础颜色和子平均颜色。
```

验收：

```text
颜色块无深度支撑时只形成表面区域或未解释候选。
有深度支撑时形成子存在局部体素候选。
父颜色扣除已确认子轮廓后计算。
```

### P7 内部世界子存在提交

目标：

```text
通过提交入口把稳定子候选写入父存在内部世界；
子存在拥有自己的局部正立方体体素模型；
保存父子坐标映射。
```

验收：

```text
子存在不挂在父存在普通字段。
子体素模型不是父完整模型复制。
子体素可投影回父体素空间和观察证据。
```

### P8 控制面板和场景体素只读显示

目标：

```text
显示父体素基础颜色；
子体素颜色覆盖对应区域；
显示层只读，不写回事实。
```

验收：

```text
父颜色和子颜色分开读取。
渲染覆盖不改变父颜色事实。
控制面板显示不能作为世界树事实源。
```

### P9 自然链路验证和实施记录

目标：

```text
用真实观察链或自然任务链验证新增观察体素特征值触发、候选生成、提交裁决和只读显示。
```

验收：

```text
Debug x64 构建通过。
真实观察材料命中。
SQL 投影或项目视图确认父 / 子体素特征。
实施记录写明命令、退出码、关键证据和禁止宣称。
```

## 5. 失败处理

```text
缺尺寸信息：降级为缺尺寸候选，不提交稳定等比例体素。
缺融合点：挂起待融合候选，不扩张父体素。
触碰外边界：标记不完整，不提交稳定模型。
版本变化：重算、合并或挂起，不覆盖新版本。
彩色有分区但深度无支撑：只作为表面颜色区域或未解释区域。
线程异常：报错并记录根因，不静默吞掉。
```
