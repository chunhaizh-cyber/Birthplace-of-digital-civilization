## 2. 只解决什么

```text
1. 当前场景已确认存在到只读体素先验的同步版服务。
2. 合法外设材料与场景体素先验的第一版融合评分。
3. 扫描未覆盖解释中区分视野外、遮挡、深度缺失、自由空间冲突和证据不足。
4. 提交入口对观察域结果包的先验版本可接受状态校验。
5. 识别和跟踪对先验评分 / 丢失解释的只读使用。
```

## 3. 不解决什么

```text
1. 不重写 D455 驱动、采集和外设线程。
2. 不在第一轮引入 SLAM / TSDF / OctoMap / SAM2 / VOS 等新技术主链。
3. 不把场景体素作为世界树、需求树、动作动态或价值结算来源。
4. 不新增模拟样本、夹具入口、伪造外设报告或伪造动作动态。
5. 不在 `鱼巢.vcxproj` / filters 当前脏改归属未确认前强行接入新模块。
6. 不宣称自然业务样本通过，除非真实 D455 / 自然任务链证据已经形成。
```

## 4. 当前堵点

```text
1. `鱼巢.vcxproj` 和 `鱼巢.vcxproj.filters` 当前已有未归属脏改；新增模块接入项目前必须先确认归属。
2. 当前场景权威取得入口还需核验，必要时先补场景类只读 helper。
3. 稳定存在体素特征类型、场景体素版本特征、先验匹配评分特征等需要统一特征绑定表。
4. D455 到当前场景坐标系的外参 / 位姿版本需要真实材料核验，不能用单帧 feed 成功代替对齐证明。
5. 观察域结果包 O 是纯运行期返回结构，还是必须同步落运行存在 / 输出结果场景固定记录节点，需要在 S0 确认。
```

## 5. 项目结构映射摘要

详细映射以来源详细设计第 5 章为准，本计划执行时至少满足：

| 业务概念 | 项目承载结构 | 验收证据 |
| --- | --- | --- |
| SceneVoxelPrior | 运行期只读快照 + I64版本 + 指针句柄 / VecU句柄摘要 | 版本、坐标系版本、只读状态可读 |
| 合法外设材料 | 观察方法承接材料 / `结构_已合法外设数据项` | TTL、质量门、坐标系、可回查、可比较状态成立 |

| 遮挡 / 视野外 / 深度缺失 / 自由空间冲突 | 输出结果场景缺口或扫描未覆盖解释记录 | 不直接生成消失事实 |
| 提交入口版本闸门 | 6150 等提交入口读取 O 的先验版本可接受状态 | 版本过旧时写结构化缺口，不入账 |
