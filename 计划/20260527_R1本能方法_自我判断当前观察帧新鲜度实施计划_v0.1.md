# 20260527_R1本能方法_自我判断当前观察帧新鲜度实施计划 v0.1

## 0. 归属

```text
父计划：计划/20260526_基础观察事实与基础风险判断分层实施计划_v0.1.md
方法名：自我_判断当前观察帧新鲜度
方法分类：自我判定类本能方法
当前状态：待检查是否已有等价登记；未登记前不得宣称该方法已完成。
```

## 1. 目标

```text
判断当前观察帧是否仍满足当前需求的新鲜度要求；
写入 自我所在场景.当前观察新鲜度状态 等于 新鲜 / 过期 / 条件不足。
```

该方法只处理时间有效性，不判断质量、不判断事实完备、不判断基础风险。

## 2. 输入与输出

输入：

```text
当前观察帧
采集时间
当前时间
当前需求类型
最大允许观察年龄
来源外设可追溯状态
```

输出：

```text
观察年龄
当前观察新鲜度状态 = 新鲜 / 过期 / 条件不足
动作动态 / 来源动态证据
失败原因摘要
```

## 4. 禁止越界

```text
不得手写 新鲜 状态；
不得把新鲜度判断等同于质量可用；
不得把新鲜度判断等同于基础观察事实可用；
不得写 基础风险判断状态。
```

## 5. 实施步骤

```text
N1 先检查是否已有等价方法头和动作入口；没有则只登记本方法。
N2 读取当前观察帧采集时间、当前时间和最大允许观察年龄。
N3 计算观察年龄并记录比较依据。
N4 当且仅当观察年龄小于阈值且来源外设可追溯时写 新鲜。
N5 过期或证据不足时写对应失败状态和原因。
```

## 6. 验收

```text
Debug x64 构建通过；
真实日志中 自我_判断当前观察帧新鲜度 有动作动态；
日志能看到采集时间、当前时间、观察年龄和阈值；
过期或缺时间证据时不能写 新鲜；
最新运行段没有 基础风险判断状态=已明确。
```
