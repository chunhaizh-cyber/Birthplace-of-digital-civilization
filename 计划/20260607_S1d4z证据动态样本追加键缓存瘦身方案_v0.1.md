# S1d-4z 证据动态样本追加键缓存瘦身方案 v0.1

日期：2026-06-08

## 1. 目标

```text
承接 S1d-4y。

S1d-4y 已证明：
    命中模板证据动态追加已改为批量入口；
    全局互斥从每模板一次收束为每批一次；
    但 `命中模板证据动态追加` 平均约 37357us，仍是主慢点。

本切片目标：
    保留批量追加入口；
    将同一证据动态主键改为批内只读取一次；
    样本查重和引用创建复用该主键；
    不改变证据动态样本、样本上限、模板计数或因果模板命中语义。
```

## 4. 实施步骤

```text
S1d-4z-1：
    在 `因果类.cpp` 增加按已知动态主键查重的内部 helper。

S1d-4z-2：
    在 `私有_登记证据动态样本_已加锁` 中复用已知动态主键构造引用，避免每个模板重复 `获取主键`。

S1d-4z-3：
    在 `因果类::批量追加证据动态样本` 中批内只取一次证据动态主键。

S1d-4z-4：
    构建 Debug x64，真实运行 `--self-check-log --self-check-log-wait-ms=10000`。
```

## 5. 验证预测

```text
构建：
    Debug x64 构建通过。

真实运行：
    退出码=0。
    日志继续出现 `动态二次特征命中回写因果实例/内部阶段耗时`。
    `命中模板证据动态追加` 平均耗时较 S1d-4y 下降，或至少能证明剩余主耗时不在动态主键重复读取。
    日志保留 `任务状态动作动态=<动态主键>`。
    不出现 `任务状态被动提交/逻辑错误`。
    不出现 `任务状态动作动态逻辑错误`。
    不出现旧路径锚点 `准备本能调用`、`执行本能方法`、`任务域本能输入包`。
```

## 6. 下一步判断

```text
如果证据动态追加下降：
    按最新最慢阶段继续切片。

如果证据动态追加仍高：
    继续拆样本向量查重成本、模板主信息读取和批量追加内部阶段。

如果 `命中回写因果实例` 不再是动态二次特征生成主慢点：
    停止本支线，回到最新高层最慢阶段。
```
