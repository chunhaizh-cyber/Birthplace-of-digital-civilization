```text

已定位到第一处分歧：

    且能被任务管理 / 自我线程承接为观察事实材料。

当前堵点：
    稳定 L1 材料进入后续链路后，
    当前主要命中的提交路径是 `提交_当前观察范围可观测单位存在对应事实`。
    该路径是当前观察范围“对应事实 / 扫描目标上下文”提交，
    不是“确认观察存在事实”的直接生成入口。

    该路径日志中多次出现：
        来源报告层级=1
        来源稳定子集簇数量>0
        观察材料等级=优质
        可进入提交入口组织=1
        稳定子集映射写入数量>0
    但仍然：
        成功=0
        当前观察范围有效可观测单位计数事实取得状态=0
        当前观察范围可观测单位存在对应闭合状态=0
        映射缺口原因掩码=2

根因口径：
    D455 稳定数据质量已不是当前主根因。
    当前根因是稳定材料到“存在生成”的后段链路未闭合：
        1. 稳定 L1 材料已可交付；
        2. 对应事实提交能建立稳定子集映射 / 扫描上下文；
        3. 但有效可观测单位总计数不可读，导致全范围对应闭合不能成立；
        4. 真正创建已确认观察存在的 `提交_确认观察存在事实`
           在已检日志中没有形成自然命中闭环。

确认状态：
    已用 2026-06-13 连续线程日志复核稳定材料质量。
    `--d455-capture-once` 只能作为单帧命令旁支证据：
    它证明单帧不能代表 L1 稳定链路，不再作为本问题根因。
```
