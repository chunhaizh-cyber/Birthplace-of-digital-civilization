# 外设三分法真实 D455 样本实施切片计划 v0.1

日期：2026-06-04

状态：由 `计划/20260602_外设三分法技术储备与实施路线_v0.1.md` 拆出的当前执行计划。

## 1. 目标

把外设三分法从技术储备拆成可连续推进的真实 D455 样本链：

```text
D455 材料包可回查
-> 逐簇识别样本
-> 已识别区域扫描变化样本
-> 指定目标跟踪样本
-> 自我提交入口承接
-> 控制面板回放 / 样本卡
```

本计划只建立真实样本生产和承接条件，不宣称识别、扫描、跟踪已经完整实现。

## 2. 边界

```text
1. D455 / RGB-D 仍是材料供应器，不是世界存在识别器。
2. 识别报告只处理观察材料归属，不直接确认稳定世界存在。
3. 扫描报告只处理已识别区域 / 已确认存在的变化，不替代全场景明确。
4. 跟踪报告只处理指定目标，不证明全场景安全或全场景扫描完成。
5. 外设提交包必须经自我组织和提交入口裁决，不能直接写安全 / 服务结论。
6. 不伪造样本；没有真实 D455 数据时只做接口、字段、队列和控制面板准备。
```

## 3. 执行切片

### P1 D455 材料包最小可回查

目标：

```text
对账并补齐真实 D455 样本所需材料字段：
来源外设、帧号、时间戳、尺寸、深度 / 彩色句柄或摘要、
ROI / 掩码 / 点集 / 深度切片句柄、材料质量、失败原因。
```

验收：

```text
真实运行日志或控制面板能看到一张 D455 材料包的可回查证据卡。
没有相机样本时，只能记录“待真实 D455 数据”，不得构造假帧。
```

### P2 逐簇识别样本

目标：

```text
建立逐簇识别报告的最小样本卡：
观察像素簇集合、有效观察区域、未识别 / 候选 / 冲突区域、
像素归属账本、候选存在集合、证据不足原因。
```

验收：

```text
控制面板能展示逐簇识别报告；
报告只表达材料归属与候选，不写已确认观察存在最终结论。
```

### P3 已识别区域扫描变化样本

目标：

```text
建立扫描变化报告的最小样本卡：
来源已识别区域 / 已确认存在、上一状态、当前状态、
变化摘要、未解释变化、需重识别区域、失败原因。
```

验收：

```text
扫描报告能证明指定已识别区域出现可回查变化；
不得把扫描报告当作全场景明确或安全结论。
```

### P4 指定目标跟踪样本

目标：

```text
建立跟踪报告的最小样本卡：
目标存在、目标窗口 / ROI、目标特征、连续观测摘要、
丢失 / 遮挡 / 重捕获状态、忽略非目标说明。
```

验收：

```text
跟踪报告只证明指定目标特征值持续可观察；
不得替代扫描或全场景识别。
```

### P5 自我提交入口承接

目标：

```text
识别提交包 / 扫描提交包 / 跟踪提交包进入自我提交入口；
自我组织后再决定是否生成存在候选、变化动态、跟踪事实或缺口需求。
```

验收：

```text
外设供包 -> 自我组织 -> 提交入账 -> 因果解释的链路可在日志和控制面板追踪。
```
