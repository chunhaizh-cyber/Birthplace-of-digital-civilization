## 2. 目标

```text
第一目标：
    复核 `状态提交回执同步` 的剩余耗时是否只是必须保留的 `提交任务状态变化` 动作动态账。

第二目标：
    若日志样本不足，优先用现有状态提交阶段日志和被动提交内部日志复测，不先新增宽日志。

第三目标：
    若真实证据指向重复任务虚拟存在同步、重复调度快照、重复运行镜像或同状态重复提交，做最小瘦身。
    若真实证据指向动作动态创建 / 状态动态刷新等核心账本，记录为当前必须保留成本并转向下一热点。
```

## 3. 硬边界

```text
任务状态变化仍必须通过 `提交任务状态变化` 动作入口。
不得裸写任务状态，不得跳过任务状态动作动态。
不得把任务筹办 / 任务执行恢复为本能方法、候选方法或动作动态来源。
不得让 worker 先执行后补任务状态账。
不得把 D455 条件不足、等待或未满足写成完成 / 满足。
不得新增 mock、fixture、伪入口、伪动作动态或 `--*-check` 回归入口。
旧代码若被新路径替代，必须删除旧分支，不保留双路径兜底。
```
