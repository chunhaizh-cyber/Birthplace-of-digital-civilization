# S1d-4l 动态类索引引用解析指针优先方案 v0.1

日期：2026-06-08

## 1. 目标

```text
承接 S1d-4k。

S1d-4k 已定位：
    `状态类::创建状态` 主耗时集中在 `状态动态刷新`；
    最新线程 T24008 状态创建内部采样 33 条；
    `状态动态刷新` 平均约 849007us，最大 2081942us；
    `状态写入后整理` 平均约 207us。

代码复核显示：
    `动态类::查找相邻前状态` 会倒序遍历场景状态索引；
    `动态类::私有_解析状态引用` 当前先按主键查找，再用指针全量扫描兜底；
    场景状态索引和动态索引通常由 `私有_生成引用` 写入，引用中同时带有指针和主键。

本切片目标：
    在不跳过状态动态刷新、不改变动态创建语义的前提下，
    将 `动态类` 内状态 / 动态索引引用解析改为指针有效且主键匹配时优先使用指针；
    主键查找和全量扫描仍保留为兜底路径。
```

## 3. 禁止修改

```text
不删除 `状态记录后刷新动态`。
不删除状态写入后自动生成状态动态。
不改变 `创建叶子动态`、动作动态结构或任务状态动作动态来源。
不把任务状态变化改成裸写状态。
不改变引用合法性：指针存在但主键不匹配时不得直接使用指针。
不新增基础信息全局索引、候选方法索引或因果主果索引。
不新增模拟入口、夹具、伪造样本或 `--*-check` 回归入口。
```

## 4. 实施步骤

```text
S1d-4l-1：
    在 `动态类.cpp` 内增加引用指针快路径判断。

S1d-4l-2：
    `私有_解析状态引用`：
        如果 `引用.指针` 存在；
        且基础信息能取到 `状态节点主信息类`；
        且 `引用.主键` 为空或等于指针节点主键；
        则直接返回该指针。
        否则保持旧的主键查找和全量扫描兜底。

S1d-4l-3：
    `私有_解析动态引用` 同口径处理 `动态节点主信息类`。

S1d-4l-4：
    构建 Debug x64，真实运行 `--self-check-log --self-check-log-wait-ms=10000`。

S1d-4l-5：
    用日志核对任务状态动作动态仍存在，错误锚点为空，并汇总最新状态创建内部阶段耗时。
```

## 5. 验证预测

```text
构建：
    Debug x64 构建通过。

真实运行：
    退出码=0。
    日志保留 `任务状态动作动态=<动态主键>`。
    日志可继续出现 `状态创建/内部阶段耗时`。
    不出现 `任务状态被动提交/逻辑错误`。
    不出现 `任务状态动作动态逻辑错误`。
    不出现旧路径锚点 `准备本能调用`、`执行本能方法`、`任务域本能输入包`。

性能判断：
    如果 `状态动态刷新` 明显下降，记录收益并继续查看下一慢阶段。
    如果下降不明显，保留本优化，因为它减少了索引引用解析的重复主键查找；
    下一步继续拆 `查找相邻前状态` 内部阶段或状态索引扫描条件。
```

## 7. 落地结果

```text
已落实：
    `动态类.cpp` 新增 `私有_尝试按指针解析引用`；
    `私有_解析状态引用` / `私有_解析动态引用` 改为指针有效、主信息类型正确、主键为空或匹配时先返回指针；
    主键不匹配时不使用指针，旧主键查找和全量扫描兜底保留。

验证：
    Debug x64 构建通过；
    `.\x64\Debug\鱼巢.exe --self-check-log --self-check-log-wait-ms=10000` 退出码 0；
    日志/鱼巢_run_20260608.低值g 保留 `任务状态动作动态=<动态主键>`；
    未检出 `任务状态被动提交/逻辑错误`、`任务状态动作动态逻辑错误`、`准备本能调用`、`执行本能方法`、`任务域本能输入包`。

性能结果：
    最新线程 T39044 状态创建内部采样 28 条；
    最慢阶段分布：`状态动态刷新=28`；
    `状态动态刷新` 平均约 642089us，最大 1366770us；
    `状态写入后整理` 平均约 486us；
    任务状态动作动态创建内部采样 29 条，最慢阶段仍为 `新状态节点=29`。

结论：
    指针优先解析有收益，较 S1d-4k 最新线程平均 `状态动态刷新` 约 849007us 下降到约 642089us；
    但热点仍在 `状态动态刷新`，下一步进入 S1d-4m，拆 `动态类::查找相邻前状态` 内部阶段和扫描规模。
```
