## 1. 纠偏目标

```text
1. 外部调用方不得直接解释 方法主信息类 的 variant 角色结构。
2. 外部调用方不得直接读取 / 修改 首节点信息().动作句柄、动作名、方法虚拟存在、来源、能力、成熟度阶段。
3. 外部调用方不得直接遍历方法子链统计条件节点、结果节点或条件结果对。
4. 外部调用方不得直接 push_back 方法结果能力项或修改方法动作句柄。
5. 外部调用方不得把任务筹办、任务执行、回执同步、显示投影或 SQL 投影当成方法动作。
6. `方法主信息类.h` 中普通业务方法节点只允许三类角色：头节点、条件节点、结果节点；三类节点必须通过对应构造函数或方法类创建函数生成。
7. 删除或收口当前没有真实机器逻辑用途的结构体，不为显示、SQL 投影或临时摘要保留长期主信息结构。
8. 方法类不得吞并任务类、需求类、二次特征类、特征类、语素类、世界树类、动态类职责；缺哪个类功能函数就转入哪个类逻辑纠偏计划。
```

## 2. 方法信息操作范围

纳入方法类口径：

```text
1. 方法节点身份解析：按主键、按动作句柄、按动作名、按基础信息主键解析方法节点。
2. 方法节点角色判断：是否方法首节点、条件节点、结果节点。
3. 方法动作入口读取：动作名、动作句柄、本能 ID、动作句柄是否有效、是否指定本能方法。
4. 方法结果能力读取和匹配：结果项集合、目标特征类型、方向掩码、是否可被方法查找命中、是否根写入原语。
5. 方法能力写入：注册方法首节点、注册需求位 / 需求方向方法首节点、声明结果能力项、追加二次特征结果模板。
6. 方法结构统计：方法动作数量、可执行入口数量、条件节点数量、结果节点数量、条件结果对数量。
7. 方法可用性判断：是否达到可用最低判据、不可就绪原因、候选方法是否可直接执行。
8. 方法条件 / 结果节点维护：创建条件节点、创建结果节点、声明条件特征、读取条件判定索引、读取结果方向索引。
9. 方法虚拟存在链接：读取、解析、确保、绑定方法首节点对应的方法虚拟存在。
```

不纳入方法类口径：

```text
1. 默认本能方法 ID、默认动作名、默认自我本能方法集合，归 本能方法类；本能方法类登记时必须调用方法类入口写方法树。
2. 方法虚拟存在上的统计特征、方法状态特征、方法运行账特征，归 方法虚拟存在服务类 / 特征类；方法类只提供方法首节点到方法虚拟存在的结构入口。
3. 任务候选集、当前方法、筹办 / 执行回执同步、任务状态推进，归 任务类 / 任务管理模块。
4. 需求目标语义、是否可进入普通候选方法筹办，归 需求类。
5. 二次特征模板同一性、方向区间、标量区间和概念模板判断，归 二次特征类。
6. 语素入口同一性、动作名词面文本，归 语素类 / 语言类；方法类只返回结构化入口指针或引用。
7. 世界树节点挂接、基础信息树枚举、跨根解析，归 世界树类。
8. 动作动态创建、动态来源链、来源动作名落账，归 动态类；动态类读取方法动作名时应调用方法类只读函数。
9. 控制面板、SQL 投影和语言表达只消费方法类结构化只读结果，不反向参与机器判断。
```

## 3.1 方法主信息类结构体清理口径

当前结构判断：

```text
1. 保留三类节点角色结构：
    结构_方法首节点信息
    结构_方法条件节点信息
    结构_方法结果节点信息
    方法角色信息

2. 保留当前仍有真实逻辑用途的能力 / 动作结构：
    结构体_动作句柄
    结构_方法结果项
    结构_方法结果包
    结构_方法首节点能力面

3. 暂保留但需纠偏：
    结构_方法节点公共信息
        描述信息 / 统计 暂保留；
        公共.节点种类 与 variant 角色形成双重事实源，后续必须收口。

4. 删除候选：
    结构_方法条件项
    结构_方法条件组
    结构_方法条件面
    结构_方法条件节点信息::条件面
```

删除候选依据：

```text
1. 当前机器逻辑主要通过 条件场景、条件判定索引、方法子链上的条件节点 / 结果节点判断条件和条件结果对。
2. `条件面.可用条件组集` 当前只被 SQL 投影和控制面板显示统计读取，没有参与任务筹办、任务执行、参数绑定或条件判断。
3. 若后续确需表达方法条件组，应优先用条件节点、条件场景、二次特征条件索引和项目通用特征结构表达，不恢复一套空转条件面结构。
```

构造约束：

```text
1. 方法根节点允许 `未定义 + monostate`，只作为独立树根或容器。
2. 普通方法业务节点只能是：
    方法首节点
    方法条件节点
    方法结果节点
3. 首节点只能通过 `方法主信息类::构造首节点` 或 `方法类::注册*方法首节点` 创建。
4. 条件节点只能通过 `方法主信息类::构造条件节点` 或 `方法类::创建条件节点` 创建。
5. 结果节点只能通过 `方法主信息类::构造结果节点` 或 `方法类::创建结果节点` 创建。
6. 禁止外部直接改 `公共.节点种类`；发现后回迁到方法类函数或删除该写法。
7. `公共.节点种类` 后续应由 `variant` 角色推导，或至少限制为构造期一次性设置，避免双重事实源不一致。
8. `首节点信息() const / 条件节点信息() const / 结果节点信息() const` 返回静态空结构的行为需要后续审计；机器逻辑不应依赖空结构静默兜底。
```
