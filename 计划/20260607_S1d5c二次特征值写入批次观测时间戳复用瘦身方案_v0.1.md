# S1d-5c 二次特征值写入批次观测时间戳复用瘦身方案 v0.1

日期：2026-06-08

## 1. 目标

```text
承接 S1d-5b。

S1d-5b 已闭合：
    复用已取 `二次特征主信息类*` 后，`分步值写入` 平均由约 82869us 降到约 70124us；
    `二次特征值写入/内部阶段耗时` 0 条，单次值写入未超过慢采样阈值；
    当前主因仍是高次数小写入聚合。

代码证据：
    `结构_统计::记录观测` 只维护 `创建时间`、`最后观测时间` 和 `命中次数`；
    当前每个分步结果值写入都会单独调用 `结构体_时间戳::当前_微秒()`；
    同一 `私有_获取动态二次特征` 分步批次中的派生结果来自同一动态二次特征生成过程，可共用一个非零观测时间戳。

本切片目标：
    在分步结果生成批次开始时生成一次观测时间戳；
    已取主信息值写入入口接收可选观测时间戳；
    每个节点仍调用 `统计.记录观测`，不减少命中次数；
    未传入批次时间戳的旧入口保持原行为。
```
