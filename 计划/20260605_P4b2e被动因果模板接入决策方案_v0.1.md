# P4b2-e 被动因果模板接入决策小切片方案 v0.1

## 目标

在 P4b2-a / b / c / d 已确认内部治理写点与边界后，决定：

```text
1. 哪些内部治理写点需要读取 data/initial_causal_templates.tsv；
2. 哪些内部治理写点只需要内部等价规则；
3. 哪些内部治理写点需要生成可被因果账本引用的等价布尔特征。
```

本切片优先做代码对账和接入决策。除非发现已明确的最小缺口，否则不修改 C++。

## 前置结论

```text
P4b2-b：
    学习本能方法若要改写方法虚拟存在特征值，应调用 方法虚拟存在服务类。

P4b2-c：
    任务筹办不直接执行 自我_提交方法可执行入口，只生成结构缺口。
```

## 决策分类

### A. 需要读取 TSV 的写点

满足以下条件时，写点应读取 TSV 或已加载的初始因果模板：

```text
1. 被动因果是跨领域 / 跨宿主的冷启动遗传依据；
2. 需要从目标结果反推多个前置条件；
3. 需要让需求树生长或任务筹办因果查询能解释“为什么需要这个条件”；
4. 宿主解释由内部治理写点提供，TSV 只提供 条件集合 -> 必然结果。
```

候选：

```text
安全需求树来源因果；
当前场景可观测单位取得路径；
D455 观察确认路径材料与对应事实闭合。
```

### B. 只需要内部等价规则的写点

满足以下条件时，不应接 TSV：

```text
1. 判断只依赖当前目标任务虚拟存在或方法虚拟存在的结构底账；
2. 目标宿主、目标特征和值都由当前写点自然持有；
3. 不需要跨轮作为独立因果账本事实被别的链查询；
4. 写入动作动态或日志已经足以作为本轮治理证据。
```

候选：

```text
方法状态最低可用判定；
任务筹办结构缺口映射；
任务虚拟存在筹办 / 执行回执镜像；
父任务重筹办状态切换。
```

### C. 需要等价布尔特征的写点

满足以下条件时，可新增或复用等价布尔特征：

```text
1. 条件本身是数量底账组合；
2. 该组合需要被跨轮查询、被其他任务筹办或因果账本引用；
3. 直接重复读取数量底账会造成口径分叉；
4. 该布尔特征的宿主和写点权威明确。
```

候选：

```text
方法条件结果对数量已满足状态；
同条件练习样本已达标状态；
同条件新结果分支清零状态；
方法好用 / 稳定维护材料已满足状态。
```
