# 主信息类型按符号三态比较规范收口计划 v0.1

日期：2026-05-18

## 1. 计划目标

根据 `004 特征值符号三态比较底层逻辑规范`，梳理并修订涉及“关系生成”的主信息类型，使系统底层逻辑统一落到：

```text
比较量 r = 比较(左值, 右值)

r < 0：左值小于右值
r = 0：左值等于右值
r > 0：左值大于右值
```

其中，三态比较不是数据结构，而是底层比较协议 / 运算约定。计划不得新增：

```text
三态比较器节点
三态比较器主信息
三态比较器概念树节点
```

进入数据层的是：

```text
比较后的比较量 / 符号
模板允许的方向掩码
比较关系形成的二次特征
因果统计次数
```

本计划只处理底层主信息结构和比较接口收口，不改变任务筹办 / 任务执行普通生命周期函数口径，不恢复 `自我_任务筹办` / `自我_任务执行` 本能方法。

## 3. 当前检查结论

### 3.1 必须修改

```text
二次特征主信息类
```

原因：

```text
当前仍保存 方向区间 / 差值 / 是否满足 / 置信度 等字段。
这些字段混合了比较方向、条件命中和解释统计。
其中 设置差值结果 使用 右值 - 左值，既有溢出风险，也与 004 的 比较(左值, 右值) 符号约定不一致。
```

### 3.2 需要结构收口

```text
因果主信息类
```

原因：

```text
当前已经删除置信度并保留基础计数，方向正确。
但字段仍使用 条件模板 / 因状态迁移模板 / 果状态迁移模板 / 主果状态迁移。
按 004，应收口为 条件比较模板 / 因比较模板 / 果比较模板 / 主果比较模板。
```

### 3.3 需要语义收口

```text
方法主信息类
```

原因：

```text
结构_方法结果项 当前保存 枚举_结果变化方向。
该枚举包含 增加 / 减少 / 保持 / 趋向目标 / 从无到有 / 从有到无 等解释词。
这些词不得作为底层候选查找、筹办判断或因果统计依据。
```

### 3.4 需要接口拆分

```text
基础信息基类::比较(...)
需求主信息类::比较(...)
任务主信息类::比较(...)
方法主信息类::比较(...)
存在 / 场景等主信息比较函数
```

原因：

```text
当前多个比较函数返回 相等 ? 1 : 0。
这属于“条件命中”语义，不是“有符号比较量”语义。
若继续混用，1 会同时表示 大于 和 命中，破坏 004。
```

### 3.5 暂不需要结构修改

```text
动态节点主信息类
状态节点主信息类
特征节点主信息类
抽象特征主信息类
```

原因：

```text
这些类型主要保存原始事实和状态值。
比较应发生在关系生成点，不应在单个事实节点创建时强制解释。
```

## 4. 非目标

本计划不做：

```text
1. 不新增“生成 / 消除 / 增强 / 减弱”等解释枚举。
2. 不把动态节点改成解释节点。
3. 不把因果类改成结算类。
4. 不改任务筹办 / 执行为本能方法。

6. 不通过字符串主键猜测安全 / 服务 / 方法 / 学习维度。
```


### P3. 修订二次特征主信息类

目标：

```text
二次特征不是判断器，而是由比较关系生成的关系性特征。
它表达两个已解析特征值、对象、状态或动态初始 / 结果之间的关系，
不保存 增强 / 减弱 / 出现 / 消除 等解释结果。
```

建议结构：

```text
特征模板 / 特征类型
左状态 / 右状态
比较左值 / 比较右值
比较字段
可选缓存：比较量
关系值：标量值 / 差值 / 余量
模板值域：标量区间 / 允许方向 / 方向区间
度量签名_链键
```

处理旧字段：

```text
方向区间：
    保留为正式关系量域字段。
    它表示比较方向内部的细分域，不等同于允许方向。
    第一版可只保留 正 / 零 / 负 粗区间，后续可扩展为更细量域。

方向掩码 / 允许方向：
    作为新主口径，表示“允许哪些比较方向命中”。
    它只消费比较量符号：
        r < 0
        r == 0
        r > 0
    不生成 增强 / 减弱 / 出现 / 消除 等语义解释。
    条件模板、方法前置、二次特征模板、因果模板和查询筛选应逐步迁到 允许方向。

差值：
    不再通过 右值 - 左值 生成底层方向。
    保留为正式关系量字段，可用于距离、余量和多次特征生成。
    不作为底层方向来源。

比较方向与变化方向：
    允许方向 消费 比较(左值, 右值) 的符号。
    差值 / 方向区间 消费 右值 - 左值 的变化量。
    在状态迁移中二者非零符号相反，不得互相替代。

是否满足：
    仅作为实例二次特征与模板二次特征匹配后的缓存 / 显示 / 兼容结果，
    不作为二次特征主事实。

置信度：
    删除或迁出解释 / 统计层。
```

验收：

```text
1. 二次特征方向由 比较量 <0 / =0 / >0 得到。
2. 二次特征可作为场景关系、方法条件、方法结果、因果条件、因果结果、概念模板使用。
3. 不再依赖 增强 / 减弱 / 出现 / 消除 等解释概念。
4. 相关回归能编译并通过。
```

### P4. 修订因果主信息类

目标：

```text
因果主信息只记录 条件比较 + 因比较 / 因方法 + 果比较 + 基础计数 + 动态证据。
```

建议字段迁移：

```text
条件模板       -> 条件比较模板
因状态迁移模板 -> 因比较模板
果状态迁移模板 -> 果比较模板
主果状态迁移   -> 主果比较模板
```

保持：

```text
因方法模板
因动作名称
因动作语义键
证据动态样本
观察次数 / 条件命中次数 / 因出现次数 / 果出现次数 / 成立次数 / 失败次数
```

禁止新增：

```text
因果作用类型
因果确定性枚举
成功率 / 基线率 / 提升率字段
失败动态样本
时间窗口字段
```

验收：

```text
1. 因果类不保存解释枚举。
2. 因果匹配使用二次特征比较模板。
3. 控制面板显示可以解释，但底层字段不解释。
```

### P5. 修订方法结果能力表达

目标：

```text
方法结果能力不再用解释式 枚举_结果变化方向 作为底层命中依据。
```

建议：

```text
结构_方法结果项 保留：
    特征类型
    特征类型由参数决定
    特征类型参数
    目标值
    最小变化量
    最大变化量

新增或复用：
    目标满足关系 / 三向关系掩码

```

迁移旧 `枚举_结果变化方向`：

```text
短期：仅用于人类显示和兼容日志。
中期：方法查找和筹办判断全部改用目标特征类型 + 比较关系。
长期：删除或迁出解释层。
```

验收：

```text
1. 候选方法查找不依赖 增加 / 减少 / 趋向可用 等解释枚举。
2. 多候选选择规则仍通过。
3. 改变特征值仍不得作为方法候选。
```


## 7. 当前暂停点

实施时遇到以下情况必须暂停确认：

```text
1. 需要删除持久化字段，且无法确认历史数据兼容策略。
2. 某下级规范仍要求把 增强 / 减弱 / 生成 / 消除 作为底层字段。
3. 某回归依赖 是否满足 / 结果变化方向 等旧字段才能通过，或对 方向区间 的正式量域含义有新增要求。
4. 需要改变公开文件格式、存档格式或控制面板协议。
5. 需要把解释层字段重新写回主信息类。
```
