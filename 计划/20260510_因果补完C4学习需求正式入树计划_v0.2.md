## 3. 入树范围

```text
第一版只承认以下三类自然学习需求触发。
```

### 3.1 无既有候选方法安全兜底

```text
触发：
    任务筹办按目标特征类型查找方法能力；
    遍历完整方法树并完成候选集填充后，候选集为空。

当前正常路径：
    任务筹办必须排除 `改变特征值` 这类先天写入逻辑；
    `改变特征值` 不再作为候选方法、当前方法或动作动态来源；
    因此候选集为空只表示没有语义方法能够承接目标特征。

筹办处理：
    立即在方法树中创建面向目标特征 F 的方法头；
    将该方法加入任务方法候选集；
    返回该方法作为当前候选。

后续派生需求：
    不再派生“存在可改变 F 的方法”这种抽象需求；
    围绕新建方法的具体缺口派生：
        目标宿主 = 新建方法的虚拟存在
        目标特征类型 = 方法状态 / 条件结果对状态 / 执行入口状态
        目标状态 = 可用 / 已建立 / 已形成

因果句式：
    要父任务就绪，需要一个能改变目标特征 F 的方法。
    因为当前没有既有候选方法，
    所以任务筹办先创建方法 M 并返回 M。
    因为 M 还不是可用方法，
    所以派生学习需求：M.方法状态 = 可用，或派生更具体的条件结果对 / 执行入口补齐需求。

先天写入逻辑边界：
    `改变特征值` 是外层语义方法共享的底层特征提交原语；
    它不得进入候选集，不得被任务筹办选为当前方法；
    若需要改变目标特征，必须由占位方法或具体语义方法解释“为什么能改、如何改、是否可用”。
```

### 3.2 候选方法不可用

```text
触发：
    候选方法结果能力命中；
    但方法状态未达到可用。

派生需求：
    目标宿主 = 候选方法虚拟存在
    目标特征类型 = 方法状态
    目标状态 = 可用

限制：
    不得在缺口不明确时直接派生“方法动作状态”。
    只有回执明确证明缺执行入口，才派生执行入口相关需求。
```

### 3.3 明确缺执行入口

```text
触发：
    筹办回执明确候选方法缺执行入口或缺方法动作。

派生需求：
    目标宿主 = 候选方法虚拟存在
    目标特征类型 = 执行入口状态 / 方法动作状态
    目标状态 = 已形成
```

### 3.4 明确缺条件结果对

```text
触发：
    候选方法已有方法头或动作；
    但缺有效条件结果对。

派生需求：
    目标宿主 = 候选方法虚拟存在
    目标特征类型 = 条件结果对状态
    目标状态 = 至少一组有效条件结果对已建立

后续闭合：
    尝试学习
    建立条件结果对
    提交方法状态变化
```

## 4. 筹办条件需求边界

```text
参数 / 条件补齐需求第一版不归入学习需求。

例如：
    缺参数 P
        -> 需求：参数 P 已获得 / 已绑定

    方法条件 C 不满足
        -> 需求：条件 C 成立

它们可以支撑筹办，但不作为“学习需求正式入树”的验收项。
```

## 5. 权重来源

```text
学习需求权重来自触发它的父需求 / 父任务剩余压力。
权重只作为调度压力。
不直接作为安全 / 服务结算上限。

禁止：
    I64_MAX 作为真实服务结算值。

轻量结算口径：
    叶子任务结算安全 / 服务值；
    叶子剩余权重减少；
    父任务剩余权重同步减少；
    父任务不重复结算子任务已结算部分。
```

## 6. 父需求挂接策略

```text
学习需求挂在触发它的父需求下面。

挂接规则：
1. 必须有触发父需求。
2. 父需求不能是单纯结构根。
3. 子需求必须有明确目标宿主、目标特征类型、当前状态 / 目标状态、满足关系。
4. 子需求必须带派生归因。
5. 不直接挂到根需求，也不单独挂成全局学习树。
```

## 7. 禁止项

```text
1. 不允许从测试夹具直接执行入树。
2. 不允许复制父需求目标作为学习需求目标。
3. 不允许缺目标宿主 / 目标特征类型 / 当前状态 / 目标状态 / 满足关系时入树。
4. 不允许同时生成外界探索需求。
5. 不允许恢复旧学习主需求链。
6. 不允许把“候选方法不可用”默认派生成“方法动作状态”。
7. 不允许把参数 / 条件补齐需求误归为学习需求。
```
