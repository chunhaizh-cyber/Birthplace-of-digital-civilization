## 2. 目标

```text
在不改变任务状态语义、不跳过任务状态动作动态、不改变 D455 观察事实规则的前提下，
降低 49 个未闭合任务持续巡检时的重复登记、重复重排、重复快照写入和主锁等待。
```

本切片只解决性能放大：

```text
未闭合任务可以继续等待；
D455 观察材料可以继续失败或条件不足；
需求树可以继续未满足；
但同一个任务、同一个状态、同一个等待原因、已有在途工作项时，不应每轮造成新的重排和完整快照刷新。
```

## 3. 硬边界

必须保留：

```text
1. 任务状态变化必须通过任务域被动状态提交动作入口。
2. 任务状态动作动态来源方法固定为 提交任务状态变化。
3. 任务筹办 / 任务执行仍是任务管理生命周期普通函数，不恢复为本能方法。
4. 等待、挂起、未满足、D455 条件不足不能被优化成满足或完成。
5. 外设材料字段不得直接写成世界真值或需求满足事实。
6. 错误 / 致命日志不得关闭。
7. 只读诊断不得隐式创建结构。
```

禁止混入：

```text
D455 事实规则修复；
基础信息全局索引；
候选方法索引；
因果主果全局索引；
价值结算；
需求满足回写；
动态二次特征或因果账本继续削减；
旧完整本能函数执行壳恢复。
```

旧路径删除要求：

```text
如果某一小切片用新幂等 / 合并路径替代旧重复登记、重复重排或重复快照路径，
旧分支必须删除或改为同一入口转调；
不得留下新旧两套并行登记逻辑。
```

## 5. 切片顺序

### S2a-0 断点和预测

建立断点清单，写明：

```text
当前日志基线；
预测改善项；
允许修改范围；
禁止宣称项；
验证命令和日志锚点。
```

### S2a-1 重复等待 / 重复重排幂等裁决

目标：

```text
同一任务、同一工作类型、同一状态版本、同一等待 / 在途原因已经有有效工作项时，
巡检不再构造新工作项并进入等待登记。
```

实现方向：

```text
复用或加强 私有_任务已有有效入队或在途工作项。
必要时在任务状态快照中记录最近等待原因、工作类型、状态版本和最早派发时间。
已有等价工作项时返回跳过，而不是登记后再重排。
```

验收重点：

```text
等待工作项登记/阶段耗时 条数下降；
同任务已有在途工作项，延后重排 条数下降；
任务状态巡检 的 已有工作项 计数可上升，但不应新增逻辑错误。
```

### S2a-2 等待工作项登记合并

目标：

```text
如果工作项已经进入登记函数，并在登记阶段发现同任务在途或许可占用，
优先更新现有队列项的最早派发时间 / 入队原因摘要，不重复 push 新队列项和刷新完整队列快照。
```

实现方向：

```text
登记函数内部增加同任务同类型工作项合并路径。
合并成功返回 已跳过重复工作项 或新增等价结果，不进入完整入队 / 重排路径。
旧的重复重排 push 路径被新合并入口替代。
```

验收重点：

```text
等待工作项登记 的 主锁等待 平均和最大值下降；
重排 最慢阶段条数下降；
任务工作项没有丢失，仍能被正常派发或等待。
```

### S2a-3 调度侧状态快照脏标记

目标：

```text
任务状态、状态版本、最近工作项、等待原因均未变化时，
不重复写任务状态快照和不重复刷新完整队列快照。
```

实现方向：

```text
在 私有_记录调度侧任务状态快照 和登记后的任务快照同步处增加字段变化判断。
无变化时只保留必要计数，不写重复字段，不触发完整队列快照刷新。
错误、终结、状态变化和新工作项仍强制刷新。
```

验收重点：

```text
任务状态巡检/阶段耗时 中 状态快照记录 明显下降；
等待工作项登记/阶段耗时 中 队列快照刷新 和 任务快照同步 不成为新慢点。
```

### S2a-4 主锁范围收缩

目标：

```text
减少等待登记主锁持有时间和竞争。
```

实现方向：

```text
锁外准备任务主键、状态文本、入队原因、快照候选字段。
锁内只做队列查找、合并、插入、必要索引更新。
避免一次登记内重复刷新队列快照。
```

验收重点：

```text
等待工作项登记 主锁等待 平均下降；
主锁内不因锁外准备迁移而上升；
无数据竞争、无死信暴增、无状态版本错配回潮。
```

### S2a-5 复测和下一路由

真实运行后按日志决定：

```text
如果任务状态巡检 / 等待工作项登记下降，且任务状态提交成为第一慢点：
    回到 S1d，只看任务状态被动提交内部动作动态创建是否有新证据。

如果巡检仍慢在 状态快照记录：
    继续 S2a 快照脏标记，不转日志 flush。

如果巡检仍慢在 已有工作项检查：
    再评估任务级活动索引，不直接上全局事件驱动。

如果等待登记仍慢在 主锁等待：
    继续拆锁或合并队列项。

如果 D455 ERR 仍存在：
    记录为业务条件不足，不作为本性能切片失败。
```

## 7. 验收标准

最低验收：

```text
Debug x64 构建通过；
真实运行退出码 0；
任务状态动作动态数量 > 0；
负向锚点均为 0：
    任务状态被动提交/逻辑错误
    任务状态动作动态逻辑错误
    准备本能调用
    执行本能方法
    任务域本能输入包
FTL=0。
```

性能验收：

```text
在同类 10s self-check 窗口中，
任务状态巡检最大耗时、等待工作项登记平均耗时、主锁等待最大耗时至少有一项明显下降；
且不能以减少任务状态动作动态、跳过真实状态提交、删除合法等待任务为代价。
```

失败停点：

```text
出现任务状态动作动态缺失；
出现任务状态逻辑错误；
旧完整本能函数执行锚点回潮；
任务被错误标记为满足 / 完成；
等待任务丢失或工作项无法派发。
```
