## 1. 输入

```text
当前观察帧
质量可用状态
质量失败条件数量
质量失败原因摘要
深度有效率
空间坐标有效率
帧质量评分
融合深度有效率
未解释区域比例
补观察缺口状态
补观察缺失原因
待补观察区域数量
```

## 2. 输出

```text
补观察质量需求集合
建议补救类型：
    多帧重采样
    调整相机参数
    按 ROI 重算观察质量
    低置信补偿观察候选
    调整外设观察姿态，条件具备时
    调整观察位置，条件具备时
质量缺口诊断状态
动作动态 / 来源动态证据
```

## 3. 转换逻辑

```text
深度有效率或空间坐标有效率低于阈值：
    派生 多帧重采样 / 调整相机参数 / ROI 重算 需求。

融合深度有效率明显高于原始深度有效率：
    派生 低置信补偿观察候选 需求。

未解释区域比例或待补观察区域数量高：
    派生 ROI 重观察 或 多帧重采样 需求。

存在可控姿态接口：
    派生 调整外设观察姿态 需求。

存在可控位置接口：
    派生 调整观察位置 需求。
```
