## 1. 核心修正

```text
深度有效率不足
空间坐标有效率不足
```

不得自动推出：

```text
当前观察帧.整体不可用
当前观察帧.质量可用状态 == 不可用
```

它们只能推出：

```text
当前观察帧在需要深度 / 空间坐标的后续处理中存在质量缺口。
```

当前帧仍可继续作为观察事实被使用，例如：

```text
颜色显示
像素回查
控制面板复现
二维轮廓辅助
后续失败归因
低置信观察记录
```

但对下列处理存在降级或硬前置缺口：

```text
空间候选确认
距离判断
范围坐标确认
基础风险空间判断
存在空间归属验证
```

## 6. 与通用任务筹办的边界

S1 只把事实交给世界树和动作动态。后续由通用链路处理：

```text
父需求筹办读取：
    父需求.所需观察特征集合
    当前观察帧.深度观察质量状态
    当前观察帧.空间坐标观察质量状态
    当前观察帧.空间类后续处理适用状态

父需求筹办判断：
    硬阻塞
    软阻塞
    旁路补救

父需求筹办生成派生需求消息：
    新观察材料.深度有效率 大于 最低深度有效率
    新观察材料.空间坐标有效率 大于 最低空间坐标有效率

自我线程裁决：
    通过统一更新指令入树
```

该处理不得依赖方法名 `自我_诊断观察质量缺口并派生补观察需求`，只能依赖通用事实、父需求所需特征和世界树因果信息。
