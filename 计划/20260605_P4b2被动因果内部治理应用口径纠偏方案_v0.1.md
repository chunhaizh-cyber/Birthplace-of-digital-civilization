## 口径修正

被动因果不是任务筹办要查找的动作，也不是需要注册或选择的本能方法。

在本切片中，被动因果的含义固定为：

```text
被动因：
    已正式入账的需求、任务状态、任务回执、方法状态、输出结果状态、动作动态、结算资格状态。

被动果：
    在被动因成立后，由生命周期提交链、后处理链或结算链必须自动出现的治理结果。
```

因此不得再把 P4b2 理解为：

```text
TSV 行 -> 查找某个方法 -> 执行该方法 -> 改方法状态
```

而应理解为：

```text
正式入账事实 / 回执 / 状态动作动态
-> 内部治理写点读取当前宿主和必要依据
-> 内部治理代码自动写任务虚拟存在或方法虚拟存在特征
-> 写入结果进入任务状态动作动态、方法状态动作动态、需求收束事实或结算事实
-> 动作动态再进入统一因果账本
```

关键边界：

```text
1. 任务筹办 / 任务执行只形成过程回执，不是本能方法，也不是方法动作动态来源。
2. 任务虚拟存在承载需求镜像、筹办回执镜像、执行回执镜像、任务状态动作动态材料。
3. 方法虚拟存在承载方法身份、方法结构、方法状态、方法运行统计、方法状态动作动态材料。
4. 安全需求树只表达需求节点和逻辑组织需求节点；生产者 / 提交入口 / 线程维护不进入需求树主干。
5. 第一次扫描只能提交发现存在或发现特征事实；有可比历史后才提交变化事实。
```

## 必须对账的流程图节点

### 任务完成分支

```text
活动需求正式入树
-> 承接需求创建任务
-> 任务语义镜像入任务虚拟存在
-> 筹办回执镜像入任务虚拟存在
-> 提交任务状态变化 D1
-> 执行回执镜像入任务虚拟存在
-> 提交任务状态完成 / 等待 / 待重筹办 / 失败
-> 来源需求收束
-> 叶子任务价值结算 D2
-> 父任务等待中转待重筹办
```

对账要求：

```text
每个节点都要列出：
    被动因是什么；
    被动果是什么；
    写入宿主是任务虚拟存在、需求治理账、结算账宿主还是因果账本；
    当前代码写点函数；
    是否生成动作动态；
    动作动态来源是否符合线程不是动作来源的规则。
```

### 方法完善分支

```text
任务筹办命中方法缺口
-> 方法头确认或创建
-> 确保方法虚拟存在
-> 同步方法节点到方法虚拟存在
-> 读取方法状态材料
-> 计算方法状态
-> 方法状态动作动态
-> 生成具体结构补齐需求
-> 补齐事实入账
-> 重新同步方法虚拟存在并重算方法状态
-> 方法可用后唤醒相关任务重筹办
```

方法状态判定顺序按流程图固定为：

```text
1. 待方法动作
2. 待可执行入口
3. 待条件节点
4. 待结果节点
5. 待条件结果对
6. 可用
```

`好用 / 稳定` 只属于后续方法自检维护材料，不提高任务筹办最低可用阈值。

### 安全需求树消费分支

```text
自我_安全值 = 最大值
-> 风险安全层明确状态 = 已明确
-> 风险安全_场景影响部分已入账状态 = 1
-> 获取当前场景所有可被观测单位 = 1
-> OR组满足状态
-> D455 / 已有缓存 / 交互者说明路径之一完成
```

对账要求：

```text
1. 安全需求树节点只按需求节点和 AND / OR 逻辑组织需求节点处理。
2. 自我线程维护、安全评估、扫描、跟踪、提交入口都只能作为生产者或承接方式。
3. 安全链可以消费 D0 / D1 / D2 / 方法状态动作动态等治理材料，但不拥有任务虚拟存在或方法虚拟存在自动改值权。
```

## TSV 的角色

`data/initial_causal_templates.tsv` 继续只保存被动因果模板：

```text
条件集合 -> 必然结果
```

它不表达动作语义，不登记本能方法，也不负责携带目标任务或目标方法宿主。

若 P4b2 后续需要把方法状态条件写入模板，宿主解释必须来自内部治理写点：

```text
内部治理写点已知道当前目标任务虚拟存在或方法虚拟存在；
TSV 或等价规则只提供条件集合与必然结果依据；
内部治理写点负责读取数量底账、确认条件成立、写入目标特征。
```

## 数量底账口径

P4b1 已确定同条件统计宿主为：

```text
目标方法虚拟存在
-> 条件节点
-> 条件场景
```

当前数量底账特征包括：

```text
样本次数
最近样本时间
结果符合次数
结果不符合次数
新结果分支数量
```

P4b2 的默认执行口径：

```text
1. 方法状态最低可用条件优先由内部治理写点直接读取数量底账。
2. 只有当某个条件需要跨轮成为因果账本可引用事实时，才生成等价布尔特征。
3. 不生成“把新结果分支数量降到 0”的普通学习需求。
```

候选量化关系：

```text
方法条件结果对数量 > 0
    -> 方法状态至少可越过 待条件结果对。

同条件样本次数 >= 4
同条件新结果分支数量 == 0
目标方法最近连续成功次数 >= 4
    -> 方法好用 / 稳定维护材料成立。
```
