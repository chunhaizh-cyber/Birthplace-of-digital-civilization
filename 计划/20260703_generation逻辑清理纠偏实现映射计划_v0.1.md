## 1. 设计条款清单

### 1.1 必须实现

```text
1. 删除或替换 `包头.generation`、`来源材料generation`、`约束generation`、`目标特征generation`、`轨迹状态generation` 等字符串字段产生的机器判断逻辑。
2. 删除 `generation失配` 作为目标观察约束可用性状态的正式判断分支。
3. 删除 `外设提交_材料组代际身份` 和 `D455_构造Tracker轨迹状态generation` 这类自由字符串身份生成函数。
4. 跨报告、跨队列、目标约束、任务承接和自我正式读取只能读取结构化字段：报告编号、报告类型、报告层级、来源原始报告编号、来源外设帧编号、帧号、时间戳、坐标版本、等待项编号、目标观察约束编号、消费状态。
5. 若某处只能依赖 `generation` 才能判断一致性，必须停止并记录为缺结构 / 缺入口，不得以中文改名继续保留。
6. 清理后源码中不得再出现 `generation` 命中；确需保留历史说明，只能进入实施记录，不得留在代码、当前计划执行项或函数说明文档中。
```

### 1.2 禁止实现

```text
1. 不得把 `generation` 改成中文名称后继续作为字段、函数、枚举、状态、日志摘要或机器判断依据。
2. 不得新增字符串字段、临时 JSON、文本标签或日志文本承载材料身份。
3. 不得用自由字符串拼接代替结构化来源字段。
4. 不得扩大重构到 D2-D9 或四方法共享能力。
5. 不得为了清零关键词删除真实结构化来源、消费状态、等待项绑定或合法回查入口。
```

### 1.3 后续待补

```text
1. E0 只清理 `generation` 逻辑；D1 的 L2/L3 来源链补强、一次性消费、材料页过期清理和真实 D455 烟测仍回到 E1 继续。
2. 若清理暴露结构化来源字段缺失，新增“缺来源字段前置切片”，先修订 D1 详细设计和本计划。
3. 若清理后需要调整下游 D2-D9 的字段读取口径，只登记为后续计划依赖，不在 E0 混入。
```
