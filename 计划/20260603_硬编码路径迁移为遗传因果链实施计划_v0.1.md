# 硬编码路径迁移为遗传因果链实施计划 v0.1

日期：2026-06-03

## 1. 问题定性

当前根因果口径已经收束为：

```text
当前主动需求路径必须从世界树因果信息取得；
其中冷启动路径来自 来源类型=遗传 的因果模板；
任务筹办、自我线程和外设承接不得按目标特征名、领域词、固定因素表或固定路径表直接生成业务路径。
```

本轮检查确认，代码中仍存在多处路径硬编码。它们不是单纯的特征 / 方法注册，而是在运行期直接决定：

```text
要生成哪些子需求；
要创建哪些风险因素节点；
哪个目标特征对应哪个外设运行模式；
哪个目标特征对应哪个本能方法；
安全层按哪些固定因素聚合。
```

这些位置必须迁移为读取遗传因果信息、方法结果能力、方法条件节点、需求侧条件或已入树子需求。

## 2. 必删硬编码清单

### 2.1 风险安全层五因素固定表

当前硬编码位置：

```text
自我线程模块.impl.cpp
    安全因果风险树因素_场景影响 / 运行影响 / 资源影响 / 权限影响 / 未知影响
    私有_维护安全因果风险树_线程侧 中固定 因素集[]
    私有_尝试聚合风险安全层候选_线程侧 中固定五因素平均
    私有_风险安全因素兄弟入账掩码_线程侧 / 私有_查找风险安全场景影响因素宿主_线程侧 中固定掩码

任务模块.筹办.ixx
    安全风险树因素_场景影响 / 运行影响 / 资源影响 / 权限影响 / 未知影响
    筹办_展开安全因果风险树 中固定 因素集[]
    安全风险树因素需要通用证据搜索_筹办查询
    补齐安全因果搜索输入参数_筹办 中 风险安全因素ID有效_筹办 和 层级=2/负向补写

自我动作实现.外设模块.ixx
    风险安全层v1因素数量 = 5
    风险安全因素掩码_场景影响 / 运行影响 / 资源影响 / 权限影响 / 未知影响
    平均风险安全层v1因素
    安全_评估当前场景安全性 中按五因素候选投影
```

迁移方向：

```text
风险安全层不再由 C++ 固定五因素表定义。
风险安全层有哪些直接因，必须来自：
    主果比较模板 = 风险安全层明确状态 / 风险安全层候选
    来源类型 = 遗传 或 后天验证因果
    因比较模板集合 = 当前可用因素集合
```

### 2.2 当前场景特征值明确 OR 路径固定表

当前硬编码位置：

```text
自我线程模块.impl.cpp
    私有_确保当前场景特征值OR路径展开_线程侧
    路径集[] = D455观察确认路径 / 读取已有场景缓存路径 / 交互者说明路径
```

迁移方向：

```text
当前场景特征值明确状态 的可取得路径不由 C++ 路径表给出。
同一主果比较可以有多个遗传因果模板：
    当前场景特征值明确状态 <- D455观察确认路径完成
    当前场景特征值明确状态 <- 已有场景缓存路径完成
    当前场景特征值明确状态 <- 交互者说明路径完成

任务 / 需求展开器看到同一主果有多个可用因果模板时，生成 OR 组；
每条路径的完成目标来自对应因果模板的因比较，不来自路径名数组。
```

### 2.3 D455 路径标准子需求固定表

当前硬编码位置：

```text
外设_D455_当前场景特征值需求展开规则.h
    D455观察确认路径标准子需求定义集

自我线程模块.impl.cpp
    私有_确保D455观察确认路径标准子需求_线程侧
```

迁移方向：

```text
D455观察确认路径完成 不再由固定 7 项表展开。
它应由一条遗传 AND 因果模板表达：
    D455观察确认路径完成
        <- 当前观察材料集取得状态
        <- 外设观察材料可回查状态
        <- 当前观察范围有效可观测单位计数事实取得状态
        <- 当前观察范围可观测单位存在稳定对应事实取得状态
        <- 稳定对应存在数量明确状态
        <- 当前观察范围可观测单位存在对应闭合状态

当前观察范围可观测单位存在对应缺口可解释状态
    作为诊断 / 缺口说明因果模板，不作为完成路径的必要因。
```

### 2.4 目标特征到外设观察模式固定映射

当前硬编码位置：

```text
任务模块.管理界面线程.impl.cpp
    私有_外设观察需求口径_按目标特征类型
    识别 / 扫描 / 跟踪 / 汇总目标 的目标特征名集合
    私有_按需求构造外设观察等待项 中按口径生成观察运行模式和报告类型
```

迁移方向：

```text
外设等待项不再根据目标特征名判断识别 / 扫描 / 跟踪。
它应读取当前需求的来源因果、候选方法或方法条件：
    方法 = 自我_识别外设观察材料 -> 需要外设识别提交包 / 陌生环境逐簇识别
    方法 = 自我_扫描已识别区域 -> 需要外设扫描提交包 / 已识别场景扫描变化
    方法 = 自我_跟踪指定存在 -> 需要外设跟踪提交包 / 目标跟踪观察

也就是说：
    运行模式来自方法输入条件或因果模板上的供料要求；
    不来自目标特征名集合。
```

### 2.5 目标特征到本能方法 ID 固定映射

当前硬编码位置：

```text
自我线程模块.impl.cpp
    私有_根必要条件目标方法ID_线程侧
```

迁移方向：

```text
根必要条件不再按目标特征名指定方法 ID。
方法产出关系必须以遗传因果模板或方法结果能力表达：
    子目标比较 <- 因方法模板

任务筹办仍按方法结果能力填充候选集；
若需要冷启动候选召回，则读取 来源类型=遗传 的 方法产出因果模板。
```

### 2.6 需求生产者分级硬编码表

当前硬编码位置：

```text
需求类.cpp
    私有_查询枚举目标生产者分级
```

迁移方向：

```text
该表不应决定业务路径。
后续应迁移为：
    抽象特征定义中的合法生产者；
    方法结果能力；
    因果模板；
    提交入口裁决规则。

短期可保留为兼容诊断，但不得作为生成当前主动需求或选择方法的依据。
```

## 3. 需要补的遗传因果信息

### 3.1 根安全链

已有：

```text
自我安全值目标
    <- 风险安全层明确状态
```

需要补强为可继续展开：

```text
风险安全层明确状态
    <- 风险安全层组成因集合明确状态
    <- 风险安全层各组成因已入账状态
```

其中“组成因集合”不是固定五因素表，而是读取同一主果比较下的遗传因果模板集合。

### 3.2 风险安全层组成因

第一版仍可由遗传模板初始化这些因，但运行期必须读因果模板，不读 C++ 因素表：

```text
风险安全层明确状态
    <- 风险安全_场景影响部分已入账状态

风险安全层明确状态
    <- 风险安全_运行影响部分证据搜索状态 已完成

风险安全层明确状态
    <- 风险安全_资源影响部分证据搜索状态 已完成

风险安全层明确状态
    <- 风险安全_权限影响部分证据搜索状态 已完成

风险安全层明确状态
    <- 风险安全_未知影响部分证据搜索状态 已完成
```

后续若删除、增加或替换某个组成因，只改遗传因果模板，不改筹办代码。

### 3.3 场景影响链

```text
风险安全_场景影响部分已入账状态
    <- 当前场景风险安全值明确状态
    <- 当前场景特征值明确状态
    <- 关键特征变化观察状态
    <- 安全因果候选构造状态
    <- 当前场景持续观察需求明确状态
    <- 当前场景持续观察状态
```

当前场景特征值明确状态的最新口径为：

```text
当前观察范围有效可观测单位全部稳定对应存在。
```

因此它的遗传展开应是：

```text
当前场景特征值明确状态
    <- 当前观察范围可观测单位存在对应闭合状态
```

至少一个稳定对应存在启动扫描，应另有并行动因果：

```text
扫描可启动状态
    <- 稳定对应存在数量明确状态
    <- 稳定对应存在数量 大于 0
```

扫描 / 跟踪不能作为 当前场景特征值明确状态 的完成因。

### 3.4 当前场景特征值明确可取得路径

同一主果的多条遗传模板用于生成 OR 组：

```text
当前场景特征值明确状态
    <- D455观察确认路径完成状态

当前场景特征值明确状态
    <- 已有场景缓存路径完成状态

当前场景特征值明确状态
    <- 交互者说明路径完成状态
```

D455 路径内部：

```text
D455观察确认路径完成状态
    <- 当前观察材料集取得状态
    <- 外设观察材料可回查状态
    <- 当前观察范围有效可观测单位计数事实取得状态
    <- 当前观察范围可观测单位存在稳定对应事实取得状态
    <- 稳定对应存在数量明确状态
    <- 当前观察范围可观测单位存在对应闭合状态
```

诊断链：

```text
D455观察确认路径缺口可解释状态
    <- 当前观察范围可观测单位存在对应缺口可解释状态
```

### 3.5 外设供料方法链

```text
当前观察材料集取得状态
    <- 双目相机_取得当前观察特征帧

外设观察材料可回查状态
    <- 自我_识别外设观察材料

当前观察范围可观测单位存在对应事实提交状态
    <- 提交_当前观察范围可观测单位存在对应事实

观察存在发现状态
    <- 自我_扫描已识别区域
    <- 提交_观察存在发现事实

观察存在特征值变化事实提交状态
    <- 自我_扫描已识别区域
    <- 提交_观察存在特征值变化事实

指定存在跟踪事实提交状态
    <- 自我_跟踪指定存在
    <- 提交_指定存在跟踪事实
```

外设等待项生成只允许从这些方法链读取供料要求：

```text
识别提交包 / 扫描提交包 / 跟踪提交包
```

不允许再从目标特征名集合判断模式。

## 4. 代码迁移顺序

### P1 遗传因果模板补齐

新增或扩展启动期遗传因果模板生成：

```text
安全根链；
风险安全层组成因链；
场景影响链；
当前场景特征值明确 OR 路径；
D455 路径内部 AND 因；
外设供料方法链。
```

验收证据：

```text
日志出现 自我线程/遗传因果信息入账；
每条模板有 主果比较、因比较或因方法；
不直接生成需求、不直接创建任务、不直接结算价值。
```

### P2 风险树维护改读遗传因果

删除风险安全五因素固定表，改为：

```text
从 风险安全层明确状态 的来源因果读取直接因；
每个直接因生成风险树节点；
节点参数来自因果模板 / 因比较目标，不来自 C++ 因素表。
```

### P3 当前场景特征值 OR 路径改读遗传因果

删除 `路径集[]` 和 `D455观察确认路径标准子需求定义集` 的运行期使用。

改为：

```text
同主果多因果模板 -> OR组；
单模板多因比较 -> AND/普通前置缺口；
诊断因果不阻塞父路径。
```

### P4 外设等待项改读方法供料要求

删除 `私有_外设观察需求口径_按目标特征类型` 的目标特征名集合。

改为：

```text
需求来源因果 / 当前候选方法 / 方法条件节点
    -> 外设供料包类型
    -> 外设观察运行模式
    -> 等待项
```

未能解析供料要求时，继续暴露结构化缺口，不做文本兜底。

### P5 安全评估和聚合改读组成因集合

删除固定五因素平均函数和固定掩码。

改为：

```text
从风险安全层因果模板读取组成因集合；
只聚合已入账组成因；
缺失组成因按因果模板生成缺口，不以 0 或固定数量兜底。
```

## 5. 暂不删除但要隔离的内容

```text
特征类.cpp 中的特征模板和值域登记：
    保留。它们是词条 / 值域，不是路径。

本能方法类.cpp / .h 中的方法 ID 注册：
    保留。它们是能力登记，不是选择路径。

外设线程_D455深度相机.ixx 中报告自身的运行模式：
    保留。外设内部按真实等待项/采集结果标记报告类型，不是自我需求路径推导。

自我线程中的遗留固定安全需求清理列表：
    暂保留为历史清理隔离区，但不得参与当前主动需求生成。
```

## 6. 第一阻塞点

如果直接删除硬编码因素表和路径表，而尚未补入对应遗传因果模板，根安全任务将无法继续反推出缺口。

因此第一步不是“裸删”，而是：

```text
补遗传因果模板 -> 验证临时因果视图能读出同等路径 -> 删除硬编码读取捷径。
```

删除后验收必须看真实日志：

```text
自我线程/遗传因果信息入账
安全因果风险树维护完成
提交_生成缺口子需求
当前场景特征值OR路径展开 或 后续替代日志
任务管理界面线程/外设观察等待项...
```

且日志中不得再出现：

```text
由固定因素表生成；
由目标特征名集合映射外设模式；
由路径集[]生成 D455/缓存/交互者路径；
由 D455标准子需求定义集 直接生成子需求。
```
