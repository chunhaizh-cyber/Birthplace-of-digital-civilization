# P3b 已有关联任务引用确认小契约方案 v0.1

日期：2026-06-09

状态：已闭合。

## 1. 依据

```text
P3b 主体复用已在任务管理界面线程落地。
真实日志显示复用后新需求已绑定到既有任务，但自我线程仍无法解析 `对应任务主键=<复用任务>`，
从而反复提交活动需求任务化意图。
```

## 2. 目标

```text
新增一个任务管理界面线程只读确认入口：
    输入自我、需求、已绑定任务主键和当前时间。
    由任务管理权威侧扫描任务树头结点。
    确认该任务存在、仍处于可复用活动状态、来源需求仍有效，并且任务目标覆盖当前需求目标。

自我线程在活动需求任务化中发现 `对应任务` 有效但本地解析失败时：
    先调用该确认入口。
    确认成功则登记该任务为需求当前承接任务，并跳过本轮发起任务。
    确认失败才保留原警告并继续提交任务发起请求。
```

## 3. 禁止范围

```text
不得优化相机外设四个方法。
不得修改 结构_任务工作结果。
不得裸写任务状态。
不得绕过 提交任务状态变化。
不得把任务筹办 / 任务执行恢复为本能方法。
不得新增 mock、fixture、伪入口、伪动作动态或 `--*-check` 回归入口。
```

## 4. 验收

```text
Debug x64 构建通过。
真实运行 self-check-log 退出码 0。
旧警告 `活动需求任务化忽略不可解析旧任务引用` 应清零或明显收敛到真实失效引用。
出现 `活动需求任务化已确认关联任务引用` 时，应对应跳过重复发起任务。
日志不出现任务状态裸写、任务状态逻辑错误、旧完整本能调用锚点或 [FTL]。
若 D455 外设条件不足错误仍出现，按用户边界记录为相机外设专项之外，不在本切片处理。
```
