# P5 学习量化真实日志验证剧本 v0.1

## 目标

验证学习量化缺口与方法状态派生纠偏是否在真实运行路径中保持以下边界：

```text
任务筹办只生成结构化量化缺口；
学习任务仍按统一找方法逻辑筹办；
任务执行才调用 自我_定向学习 / 自我_尝试学习 / 自我_练习；
学习 / 练习主动结果只改变底账；
方法状态由方法虚拟存在服务类按底账被动派生；
方法状态动作动态不得被主动因果反推为可执行本能方法。
```

## 允许范围

```text
允许执行：
    msbuild .\鱼巢.vcxproj /p:Configuration=Debug /p:Platform=x64 /p:LinkIncremental=false /m
    .\x64\Debug\鱼巢.exe --self-check-log

允许读取：
    日志/
    logs/
    运行输出
    状态快照
    错误日志

允许修改：
    实施记录/20260605_P5学习量化真实日志验证记录.md
    计划/计划索引.md

禁止：
    不新增模拟入口；
    不新增夹具测试；
    不伪造动作动态；
    不通过只读查询隐式创建结构；
    不改业务代码来迎合本次验证。
```

## 验证顺序

```text
1. 先写预测；
2. 构建 Debug x64；
3. 真实运行 --self-check-log；
4. 检索日志锚点；
5. 将预测与实际结果写入实施记录；
6. 若没有自然样本，则记录为真实日志验证堵点。
```

## 预测锚点

```text
P5-1 方法无条件结果对：
    筹办应生成 方法条件结果对数量 > 0 的量化缺口；
    再筹办应通过结果能力命中 自我_尝试学习；
    任务执行才调用 自我_尝试学习。

P5-2 方法有条件结果对但未稳定：
    筹办应生成 方法最近连续成功次数 / 样本次数 / 新结果分支数量 等量化缺口；
    再筹办应命中 自我_练习；
    任务执行才调用 自我_练习。

P5-3 方法无动作：
    筹办应生成 方法动作数量 > 0 或 方法可执行入口数量 > 0；
    再筹办应命中 自我_定向学习；
    不把候选动作当真实动作。

P5-4 方法状态更新：
    方法状态只在底账变化后由方法虚拟存在服务类同步；
    日志不应出现任务筹办直接调用学习本能；
    方法状态动作动态存在时应是内部机制动作 / 被动动作语义；
    主动因果反推不得以 提交方法状态变化 为因动作。

P5-5 派生需求消息链：
    回执量化缺口经任务管理工作线程和自我线程后，目标特征、目标主体、当前状态、目标状态、满足关系不应丢失；
    若执行输出场景缺量化状态，应暴露缺口，不得粗状态兜底。
```

## 日志锚点

```text
返回方法结构缺口
方法条件结果对数量
方法动作数量
方法可执行入口数量
方法最近连续成功次数
同条件样本次数
同条件新结果分支数量
自我动作/尝试学习
自我动作/练习
自我动作/定向学习
任务执行调用
任务筹办直接调用
方法状态动作动态
方法域提交/方法状态被动派生动态
提交方法状态变化
因果反推状态
来源因果模板
```

## 堵点定义

```text
构建失败；
--self-check-log 非零退出；
运行日志无法产生任何学习量化链自然样本；
出现任务筹办直接调用学习本能；
出现 提交方法状态变化 被主动反推为候选动作；
派生消息把量化目标规约回 方法状态 / 方法稳定状态。
```
