## 1. 承接需求

根需求：

```text
优化自我场景视频窗口显示画面：增加视野模式。
视野模式下画面不再自动旋转，但可以通过鼠标旋转画面。
鼠标旋转时相机视野判定不变，除非真实相机姿态 / 视野输入发生改变。
视野内显示彩色，视野外显示灰度。
```

禁止宣称：

```text
不宣称真实相机姿态链路已闭合。
不宣称观察、扫描、跟踪、事实提交或自我苏醒阶段完成。
不把 UI 彩色 / 灰度显示反写为世界树事实、需求满足、动作动态或安全 / 服务结算。
```

## 3. 当前绑定方法

用户已选择方法 B：数据源优先。

执行口径：

```text
1. 先从 D455 / 外设材料 / 项目结构中查找真实相机姿态和 FOV 来源。
2. 已确认 D455 原始 / 轻量观察帧含深度内参，可用于计算 FOV。
3. 已确认当前控制面板快照没有相机姿态四元数或 FOV 字段。
4. 本轮优先把深度内参派生出的 FOV 作为只读视野元数据接入控制面板 JSON。
5. 相机姿态数值缺生产者时，只输出姿态状态 / 缺口，不用 UI 假造真实姿态。
6. WebGL 视野模式以只读视野元数据和当前帧版本形成视野判定缓存；鼠标旋转不改判定。
```

## 4. 项目结构映射表

| 业务概念 | 项目承载结构 | 值类型 | 写入方 | 读取方 | 验证方式 |
| --- | --- | --- | --- | --- | --- |
| 相机帧宽高 / 帧号 | 观察宿主特征 | I64 | 自我外设方法 / 报告提交链 | 控制面板只读快照 | JSON 字段、构建 |
| 相机 FOV | 观察宿主特征 | I64，毫度或万分比角度 | D455 内参派生链 | 控制面板只读快照 / WebGL | JSON 字段、渲染分色 |
| 姿态明确状态 | 自我 / 边界参照特征 | I64 | 自我边界参照链 | 控制面板只读快照 | JSON 字段显示为缺口或已明确 |
| 鼠标观察角度 | UI 运行期状态 | JS 数值 | 用户鼠标事件 | WebGL 绘制 | 截图 / 页面行为 |
| 视野内 / 外显示 | WebGL 顶点颜色属性 | 渲染数据 | 控制面板页面脚本 | WebGL | 截图 / HTML 检查 |

## 5. 执行步骤

1. 补充控制面板快照和 JSON 的视野元数据字段。
2. 在外设 / 观察写入路径中补 FOV 特征承接；若姿态数值无正式来源，则只写缺口记录。
3. 修改自我场景窗口 HTML / JS：新增视野模式按钮、鼠标拖拽旋转、视野判定缓存和彩色 / 灰度渲染。
4. 运行构建和必要静态检查。
5. 生成或打开自我场景窗口输出，记录验证结果。

## 6. 失败分流

```text
缺姿态生产者：本轮保留 S6 待条件，不伪造姿态。
缺真实外设 / 自然样本：只验证构建和静态 / 生成 HTML，不宣称真实外设姿态闭合。
构建失败：转实现缺陷阻断，先定位根因。
规范冲突：暂停并回到规范确认。
```
