# 20260606_目标观察约束特征组实现计划_v0.1

## 1. 目标

把自我向外设提供的数据收束为：

```text
目标观察约束特征组
```

它只表达外设观察约束和比较基准：

```text
看谁；
看什么目标特征；
从哪里看；
用哪个当前值 / 基准值比较；
什么误差算稳定；
什么变化需要回报；
什么材料可以舍弃；
结果要回到哪个需求 / 任务 / 等待项。
```

本计划服务当前 P9d 之后的扫描 / 跟踪目标上下文桥，不替代 `计划/计划索引.md` 当前主动队列，也不强行宣称任务 D 的全范围闭合目标已经达成。

```text
    5. 自我侧尚未形成单特征当前值回写外设缓冲区的本能函数 / 契约入口。
```

## 4. 边界

必须遵守：

```text
1. 自我给外设的是约束，不是世界真值。
2. 目标观察约束特征组只允许单个目标存在、单个目标特征、一个当前值、一组观察约束。
3. 外设可以用约束提高扫描 / 识别 / 跟踪效率，但不能直接确认存在同一、需求满足、世界真值、安全值或服务值。
4. 外设输出仍是观察材料队列项，正式入账对象只能是存在、特征、二次特征和状态动态。
5. 任务管理负责等待项、队列视图消费、回执和缺口；自我负责组织结果场景和提交入口裁决。
6. 任务筹办 / 任务执行不恢复为本能方法。
7. `6127 / 6145 / 6146 / 6147` 方法名保持当前代码口径，不按外部命名建议改名。
```

禁止：

```text
外设线程直接写需求树；
外设线程直接写世界树真值；
把目标观察约束特征组实现成存在全量快照；
把队列项被读取解释成需求满足；
把优质观察材料解释成世界存在真值；
把首次扫描伪造成变化动态；
用模拟样本、夹具入口、伪造动作动态或 --*-check 回归命令验收。
```
