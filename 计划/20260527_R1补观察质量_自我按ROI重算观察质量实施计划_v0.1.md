## 1. 输入

```text
当前观察帧
空间候选集合
主候选 / 目标候选 ROI
深度有效性 mask
空间坐标有效性
整帧质量指标
```

## 2. 输出

```text
ROI 质量摘要
ROI 深度有效率
ROI 空间坐标有效率
ROI 帧质量评分
ROI 质量可用候选状态
动作动态 / 来源动态证据
```

## 3. 转换逻辑

```text
当整帧质量不足但目标 ROI 内深度和空间点有效：
    生成 ROI 质量可用候选。

当 ROI 仍不足：
    输出 ROI 质量不足，派生重采样 / 参数调整 / 姿态调整建议。

ROI 质量可用候选只证明目标区域质量，不证明整帧质量可用。
```

## 4. 禁止越界

```text
不得用 ROI 可用替代 当前观察帧.质量可用状态=可用。
不得把 ROI 可用解释为基础观察事实可用。
不得把 ROI 质量摘要写成基础风险已明确。
```
