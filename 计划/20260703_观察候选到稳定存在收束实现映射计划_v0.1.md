## 1. 执行策略

采用 绞杀式渐进重构 渐进重构：

```
不全量重写；
不纯补丁修复；
保留现有模块入口；
逐步新增语义收束函数；
逐步让旧判断点调用新语义函数；
验证通过后再清理旧路径。
```

## 2. 设计条款清单

### 2.1 必须实现

```
1. 先执行 S0 全局只读扫描，确认真实字段、函数、模块边界和旧判断点。
2. 明确像素簇可生成临时 C，但稳定 C 必须经过跨帧复现收束。
3. 明确 C -> E 只能生成同一性候选评分和冲突分流，不能直接写世界树。
4. 明确 场景体素先验快照 只能作为解释偏置层，不是事实源。
5. 明确 结构化信息缺口 是结构化阻断证据，不是需求本身。
6. 后续 P3-P10 的代码切片必须引用本计划的总语义层。
7. 每个切片必须保留旧入口可运行，逐步替换内部判断逻辑。
```

### 2.2 禁止实现

```
1. 不全量重写外设观察报告队列、视觉融合模块、场景体素模块或四方法入口。
2. 不新增长期业务结构体承载 观察候选到稳定存在同一性候选 或语义收束包。
3. 不新增普通一阶 布尔值 表达判断。
4. 不让 C 直接写 E。
5. 不让 场景体素先验快照 生成 C、否定 C 或修改 E。
6. 不让 结构化信息缺口 直接派生需求入树。
7. 不让观察、扫描、识别、跟踪四方法互相调用。
8. 不用日志、说明文本、控制面板或临时结构化文本参与机器判断。
```

### 2.3 后续待补

```
1. S0 后确认旧判断点清单。
2. S0 后确认各模块可复用函数和缺函数。
3. S0 后确认需要先补的最小语义收束函数。
4. S0 后确认存在体素融合内部治理实现映射计划是否需先生成。
5. S0 后确认场景体素先验引导观察材料前处理计划是否需调整顺序。
```

### S1：材料链稳定化对齐 P3

确认 D1 材料页、报告组、来源报告 / 帧编号、时间戳、消费状态、坐标系版本和回查句柄可供后续语义层读取；不得要求 `generation` 或代际身份作为兼容字段、调试摘要或机器判断依据。

### S2：质量 / 清晰度 / 稳定复现对齐 P4 + P10

把旧质量判断、清晰度判断和稳定复现判断收束成评分、状态值域和缺口材料。

### S3：像素簇 -> C 对齐 P5

新增或复用 C 生成收束函数，保持单帧临时 C 与稳定 C 分离。

### S4：场景体素先验快照 解释偏置对齐 P7 + P8

把先验读取统一限制为 感兴趣区域、分裂、评分、遮挡候选和冲突缺口，不允许写事实。

### S5：C -> E 同一性候选

新增或复用共享关联判断入口，只产同一性候选评分、排他性冲突和阻断原因。

### S6：结构化信息缺口 标准化对齐 P6

把材料缺口、质量缺口、分裂冲突、观察候选到稳定存在同一性候选 冲突和先验冲突映射到 D5 缺口链。

### S7：四方法读取共享结果对齐 P9

观察、扫描、识别、跟踪只能读取共享判定结果，不互相调用。

### S8：存在体素融合治理链对齐后续计划

在生成存在体素融合内部治理实现映射计划后，接入 观察候选到稳定存在同一性候选 候选和局部体素证据链。

## 7. 验证剧本

```
V1 单帧高质量像素簇 -> 临时 C，不写 E。
V2 多帧稳定 -> 稳定 C，不直接 C -> E。
V3 粘连簇 + 多个先验投影 -> 多 C 候选，不直接归 E。
V4 C 与多个 E 冲突 -> 结构化信息缺口，不任选 E。
V5 先验预测有 E 但当前无观测 -> 遮挡候选，不写跟踪成功。
V6 当前观测与先验冲突 -> 冲突缺口，不写 E 消失。
V7 局部体素清晰但归属不明 -> 挂 C，不更新 稳定体素主模型。
V8 结构化信息缺口 回流 -> 结构化缺口，不直接需求化。
V9 普通布尔值 负例 -> 不新增一阶 布尔值。
V10 check_specs -> 硬问题 = 0，警告 = 0。
```
