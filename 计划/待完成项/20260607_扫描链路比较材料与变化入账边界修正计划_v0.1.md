# 20260607_扫描链路比较材料与变化入账边界修正计划_v0.1

## 1. 计划定位

当前扫描主链可以保留：

```text
6150 写稳定子集桥
    -> 任务管理界面线程创建扫描等待项
    -> D455 外设线程按等待项生成扫描比较材料
    -> 任务管理工作线程匹配报告并做材料质量分级
    -> 6146 自我_扫描已识别区域生成扫描正式结果
    -> 提交入口决定值域内变化事实是否入账
```

本计划只修正扫描权限和闸门，不推翻现有外设产材料、任务管理分拣、自我方法组织、提交入口裁决的骨架。

核心定案：

```text
扫描不是发现存在；
扫描不是写新特征值；
扫描不是外设报告入账；
扫描是对已归属、非背景、可比较、有基准的存在进行低成本变化比较。
```

## 3. 必须保留的边界

```text
1. D455 不直接写世界树真值。
2. 外设报告只是材料容器。
3. 任务管理工作线程是报告第一承接者。
4. 6146 不直接消费 D455 原始流，只消费任务管理承接后的报告 / 材料和当前正式目标存在。
5. 无变化不写变化动态。
6. 可用但不优质材料不能直接生成扫描变化动态。
7. 提交入口只接受存在、特征、二次特征、状态动态和来源动作动态引用。
```

## 4. 目标状态

```text
D455：
    生成扫描比较材料 / 变化候选材料，不生成正式变化动态。

任务管理：
    不对稳定子集全量创建扫描等待项；
    先按扫描候选筛选。

6146：
    每次扫描前重新判定当前扫描闸门；
    输出无变化、值域内变化候选、冲突 / 待复验三类正式结果；
    不写新一阶特征值；
    不负责发现新存在。

提交入口：
    只有 变化状态 == 值域内变化 时，才允许提交变化事实。
```

## 5. 实施切片

### P0：无历史分支降级

目标：

```text
把 “无历史 -> 创建发现事实 -> 提交_观察存在发现事实”
改为：
    无历史 -> 扫描基准缺失 -> 建立扫描基准缓存 / 输出观察识别线索。
```

修改范围：

```text
自我动作实现.外设模块.ixx
流程图/当前_本能方法_扫描内部实现逻辑流程图.md
```

验收：

```text
真实日志中无历史扫描只写扫描基准状态或观察 / 识别线索；
不进入正式 `提交_观察存在发现事实`；
不写变化动态。
```

### P1：扫描变化报告语义降级

目标：

```text
把 D455 侧 “扫描变化报告” 的正式语义降级为：
    扫描比较材料；
    变化候选材料；
    扫描队列项。
```

规则：

```text
D455 可以输出差异、变化候选、新增线索、消失线索、高风险未知线索、质量不足线索；
D455 不能输出正式存在特征变化事实、正式状态动态或正式世界事实。
```

验收：

```text
日志和摘要不把扫描报告称为正式变化动态；
任务管理承接请求明确其为材料或候选。
```

### P2：6146 当前闸门增强

目标：

```text
6146 每次执行前重新判定：
    有当前存在；
    当前存在.归属状态 == 已归属；
    当前存在.背景状态 != 背景；
    当前存在.扫描优先级值 > 最低扫描优先级；
    目标特征类型已确定；
    目标特征当前值可读；
    目标特征值域可读；
    上一轮扫描基准可读；
    目标观察约束状态 == 可用；
    约束generation匹配；
    目标特征generation匹配；
    来源材料generation匹配；
    扫描材料可复验；
    扫描材料可生成扫描变化候选；
    扫描范围内高价值待识别像素数量 == 0。
```

字段拆分：

```text
扫描可启动缓存状态 == 可启动 / 候选 / 不可用
扫描可启动当前判定状态 == 可启动 / 不可启动
扫描不可启动原因 == 缺基准 / 缺值域 / 约束过期 / 材料不可回查 / 待识别像素过多 / 背景过滤 / generation失配
```

验收：

```text
6146 日志能列出当前闸门各项判定；
不能只凭 6150 写过扫描可启动状态=1 就继续扫描。
```

### P3：变化事实提交闸门收紧

目标：

```text
把变化事实提交条件从：
    变化状态 != 未变化
改为：
    变化状态 == 值域内变化
```

提交条件：

```text
当前存在存在
&& 当前存在.归属状态 == 已归属
&& 扫描正式结果可读
&& 变化结果已生成
&& 变化状态 == 值域内变化
&& 当前值落入目标存在特征值域
&& 当前值与基准差异 >= 最小可记录变化量
&& 来源材料可生成扫描变化候选
&& 来源材料generation匹配
&& 目标特征generation匹配
&& 硬冲突数量 == 0
```

验收：

```text
冲突、证据不足、超值域、待复验均不能提交为变化事实；
只有值域内变化进入 `提交_观察存在特征值变化事实`。
```

### P4：扫描等待项候选筛选

目标：

```text
任务管理创建扫描等待项从“稳定子集全量创建”改为“扫描候选筛选创建”。
```

候选条件：

```text
存在.归属状态 == 已归属
存在.背景状态 != 背景
存在.扫描优先级值 > 最低扫描优先级
存在.最近扫描年龄 > 最小扫描间隔
存在.当前不在高频跟踪中
存在.目标特征值域可读
存在.扫描基准可读
目标观察约束状态 == 可用
```

验收：

```text
日志显示稳定子集数量、扫描候选数量、跳过背景数量、跳过低优先级数量、跳过高频跟踪数量；
等待项数量不再等于稳定子集全量。
```

### P5：背景与待识别像素过滤

目标：

```text
增加背景过滤掩码、扫描候选掩码、净待识别像素掩码。
```

规则：

```text
存在.背景状态 == 背景
    -> 不进入普通扫描。

扫描范围.净待识别像素数量 > 最大允许净待识别像素数量
或
扫描范围.高价值待识别区域数量 > 0
    -> 不生成正式变化动态，输出观察 / 识别线索。
```

验收：

```text
普通扫描跳过背景；
待识别像素过多时进入观察 / 识别线索，不进入变化事实提交。
```

### P6：质量门改为用途门

目标：

```text
质量门至少返回：
    可验证；
    可识别；
    可生成扫描变化候选；
    可进入提交入口。
```

扫描质量范围：

```text
全局优质；
目标区域优质；
目标特征优质。
```

规则：

```text
扫描变化候选只要求目标特征优质；
整帧不优质不等于目标特征不可比较；
可用但不优质只能进入复验 / 观察识别线索。
```

验收：

```text
当前扫描材料等级、目标区域质量、目标特征质量和可生成扫描变化候选分开记录。
```

### P7：D455 扫描强依赖目标观察约束

目标：

```text
D455 侧扫描必须：
    读取扫描等待项；
    读取目标观察约束特征组；
    校验约束状态 / generation / TTL / 材料可回查；
    使用 ROI / 掩码 / 点集 / AABB 限定扫描范围；
    只计算目标特征类型ID 对应的比较材料；
    生成扫描比较材料。
```

验收：

```text
D455 扫描日志显示目标观察约束ID、目标存在ID、目标特征类型ID、三类 generation 匹配结果、ROI / 掩码 / AABB 使用结果；
不能只用上一逐簇报告作为全局基准。
```

### P8：6146 输出拆成二次特征和状态动态输入

目标：

```text
6146 输出拆成：
    二次特征；
    状态动态输入；
    缓存更新。
```

输出：

```text
二次特征：
    当前值_基准值.差异值
    当前值_目标值域.值域判断状态
    当前掩码_基准掩码.重合率
    当前轮廓_基准轮廓.偏差值

状态动态输入：
    扫描无变化状态动态
    扫描值域内变化候选动态
    扫描值域冲突动态
    扫描待复验动态

缓存更新：
    下一轮扫描基准
    最近扫描时间
    稳定计数
```

验收：

```text
输出运行虚拟存在只作为方法运行环境对象；
不作为正式认知事实主体。
```
