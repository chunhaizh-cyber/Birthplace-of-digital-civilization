## 2. 目标

把扫描 / 跟踪从粗目标种子升级为结构化约束链：

```text
正式入账的自我存在.单个目标特征当前值
    + 目标特征generation
    + ROI / 掩码 / 点集 / AABB / 局部图
    + 来源材料generation
        -> 自我_提交目标观察约束特征组
        -> 目标观察约束缓冲区
        -> 任务管理扫描 / 跟踪等待项绑定约束
        -> D455 按约束采集 / 比较 / 跟踪
        -> 三类逻辑队列视图
        -> 优质观察材料判断
        -> 6127 / 6145 / 6146 / 6147 分级消费
        -> 提交入口裁决
        -> 正式存在 / 特征 / 二次特征 / 状态动态入账
        -> 只回写本次变化的单个目标特征当前值
```

核心定案：

```text
目标观察约束特征组 =
    自我提供给外设的单目标、单特征、单当前值、带观察边界和质量阈值的约束集合。

它不是包；
不是存在全量快照；
不是世界真值；
不是需求满足证据。
```

## 5. 边界

必须遵守：

```text
1. 目标观察约束特征组只存单目标、单特征、单当前值和必要观察约束。
2. 目标观察约束缓冲区只属于外设通信数据面，不是世界树事实区。
3. 外设读取约束后只能生成观察材料、误差、状态动态输入、缺口或降级说明。
4. 外设不能直接确认存在同一、需求满足、世界真值、安全值或服务值。
5. 任务管理负责等待项、队列视图消费、材料等级、回执和缺口。
6. 自我方法负责组织结果场景；提交入口负责正式入账裁决。
7. `6127 / 6145 / 6146 / 6147` 方法名保持当前代码口径。
```

禁止：

```text
把目标观察约束写成存在全量快照；
把报告队列项写成世界事实；
把目标观察约束特征组作为提交入口事实主体；
把队列项消费解释成需求满足；
把可用观察材料直接写扫描变化动态或稳定跟踪动态；
把首次扫描伪造成变化动态；
用模拟样本、夹具入口、伪造动作动态或 --*-check 回归命令验收。
```

## 9. 暂停条件

出现以下情况必须暂停并回到计划修订：

```text
1. 必须把目标观察约束做成存在全量快照才能推进。
2. 外设线程必须直接写世界树真值或需求树才能推进。
3. 自我侧无法提供目标存在、目标特征类型或该特征当前值 / 句柄。
4. 目标特征generation 无法取得，且没有明确降级为首帧基准的路径。
5. ROI / 掩码 / 点集 / AABB 全部不可回查，却仍试图强行扫描或跟踪。
6. 扫描或跟踪没有目标种子 / 基准 / generation，却被实现成裸运行。
7. 方法动作动态无法绑定到明确方法。
8. 只能靠模拟样本、伪造入口或 --*-check 命令证明通过。
```
