# 20260607_跟踪链路观测材料与状态动态边界修正计划_v0.1

## 1. 计划定位

当前跟踪主链可以保留：

```text
任务 / 需求命中跟踪口径
    -> 任务管理构造目标跟踪等待项
    -> D455 生成目标跟踪观测材料
    -> 任务管理质量用途门控
    -> 自我线程承接跟踪材料
    -> 6147 自我_跟踪指定存在
    -> 提交_指定存在跟踪事实
```

本计划不推翻这条链，只修正跟踪权限、材料命名、6147 闸门和提交前置。

核心定案：

```text
跟踪不是全场扫描；
跟踪也不是新特征值生产；
跟踪是对指定已归属存在，在目标窗口内，基于已有特征、当前有效基准、值域区间和预测区间，
判断其动态是否连续、合法、稳定。
```

当前状态：

```text
本计划为后续代码修正依据；
不表示 P0-P8 代码已完成；
不表示 6147 自然链已闭合；
不表示 提交_指定存在跟踪事实 已按事实类型拆分。
```

## 3. 必须保留的边界

```text
1. D455 只生成跟踪观测材料，不写世界树真值。
2. 任务管理只做等待项匹配、材料质量用途门、上行请求、回执和缺口。
3. 自我线程承接报告只落材料承接记录和追溯索引，不直接生成世界存在真值。
4. 6147 只基于已有目标特征、基准、值域和预测区间做比较。
5. 6147 不写目标存在新一阶特征值。
6. 提交_指定存在跟踪事实 才能正式提交跟踪状态动态。
7. 跟踪失败不全是条件不足；丢失、遮挡、重捕获、预测超限、身份冲突都可能是状态动态来源。
```

## 4. 目标状态

```text
D455：
    生成跟踪观测材料 / 跟踪比较材料 / 丢失遮挡重捕获候选材料；
    命中时写外设侧当前观测值；
    未命中时写丢失 / 遮挡 / 重捕获候选；
    不写目标正式一阶特征值。

任务管理：
    质量门改为用途门；
    可用但非优质材料可进入跟踪复验；
    稳定跟踪提交必须依赖优质 + 强约束命中 + 提交入口裁决。

自我线程：
    承接跟踪材料时记录等待项、需求、任务、目标约束、三类 generation、报告和来源动作动态。

6147：
    校验目标归属、窗口、基准、值域、预测区间、generation、待识别像素、硬冲突；
    只输出二次特征和状态动态输入。

提交入口：
    按事实类型提交稳定跟踪、区间迁移、丢失、重捕获、遮挡、预测超限和冲突事实。
```

## 5. 实施切片

### P0：未命中目标簇分支降级

目标：

```text
F 未命中目标簇时，不再生成普通跟踪报告；
改为生成：
    丢失候选材料
    遮挡候选材料
    重捕获候选材料
    证据不足材料。
```

禁止：

```text
未命中目标簇时不得写目标特征外设观测值；
不得把未命中当作普通跟踪成功。
```

验收：

```text
真实日志中未命中目标簇时只出现丢失 / 遮挡 / 重捕获候选；
不进入稳定跟踪动态候选。
```

### P1：无强目标观察约束时只允许降级重捕获

目标：

```text
有强约束：
    可生成稳定跟踪候选。

无强约束但有旧目标种子：
    只能降级匹配；
    只能输出候选命中 / 待复验 / 重捕获候选 / 证据不足；
    不能输出稳定跟踪动态；
    不能提交指定存在跟踪事实。
```

强约束至少包括：

```text
目标存在ID
目标特征类型ID
目标特征当前值
目标特征值域
ROI / 掩码 / AABB / 点集之一
约束generation
目标特征generation
来源材料generation
TTL 未过期
```

验收：

```text
目标观察约束缺失或 generation 失配时，跟踪链只进入重捕获 / 待复验；
不提交稳定跟踪事实。
```

### P2：跟踪报告语义降级

目标：

```text
把 “跟踪报告” 的正式语义改成：
    跟踪观测材料；
    跟踪比较材料；
    跟踪队列项。
```

命名修正：

```text
写目标特征观察值
    -> 写目标特征外设观测值
    -> 或 写跟踪当前观测值。
```

验收：

```text
流程图和日志口径不再把外设观测值写成目标存在正式特征值；
报告 / 队列项 / 材料页继续保持通信容器口径。
```

### P3：质量门改为用途门

目标：

```text
质量判断结果至少包含：
    可进入跟踪复验
    可进入跟踪状态判断
    可生成稳定跟踪动态候选
    可进入提交入口
    是否需要观察补特征
    是否需要重捕获
    是否需要识别复验
```

规则：

```text
不合格：
    普通目标只回执 / 清理；
    命中活跃父需求关键缺口时，上报缺口事实或派生需求消息。

可用但非优质：
    可进入 6147 复验；
    不提交稳定跟踪事实。

优质 + 强约束命中：
    可生成跟踪动态候选；
    仍需提交入口裁决。
```

验收：

```text
目标丢失、安全相关跟踪失败或活跃父需求关键缺口不会被静默丢弃；
可用但非优质材料不会提交稳定跟踪事实。
```

### P4：6147 增加正式跟踪闸门

目标：

```text
6147 增加以下闸门：
    目标特征generation
    约束generation
    来源材料generation
    目标特征值域
    预测区间
    目标窗口净待识别像素比例
    硬冲突数量
```

正式跟踪动态候选前置：

```text
目标存在存在
目标存在.归属状态 == 已归属
目标存在.背景状态 != 背景
跟踪窗口明确状态 == 已明确
目标特征当前值可读
目标特征值域可读
当前有效基准状态 == 可用
目标观察约束状态 == 可用
三类 generation 匹配
跟踪材料可复验状态 == 可复验
目标窗口净待识别像素比例 < 最大允许比例
```

验收：

```text
6147 只有在归属、窗口、基准、值域、预测区间和 generation 都成立时才进入稳定候选；
待识别像素过多时冻结基准并回识别 / 观察。
```

### P5：6147 禁止写新一阶特征值

目标：

```text
6147 只写：
    跟踪状态
    跟踪窗口状态
    预测误差值
    当前值域区间ID
    区间迁移状态
    丢失状态
    遮挡状态
    重捕获候选状态
    跟踪动态状态
```

禁止：

```text
目标存在.空间坐标 = 当前观测坐标
目标存在.距离值 = 当前观测距离
目标存在.轮廓 = 当前轮廓
目标存在.颜色 = 当前颜色
```

验收：

```text
需要正式更新目标一阶特征值时，必须回观察并经提交入口裁决。
```

### P6：提交事实类型拆分

目标：

```text
提交_指定存在跟踪事实 增加事实类型：
    稳定跟踪事实
    动态区间迁移事实
    跟踪丢失事实
    重捕获事实
    遮挡事实
    预测偏差超限事实
    跟踪冲突事实
```

验收：

```text
提交结果不再只有 “指定存在跟踪事实已提交”；
日志和状态快照能区分丢失、遮挡、重捕获、预测超限和冲突。
```

### P7：稳定跟踪提交前置加强

目标：

```text
稳定跟踪事实提交必须满足：
    强约束命中
    未丢失
    当前观测值在目标特征值域内
    当前观测值在预测区间内
    预测误差达标
    非法区间跳变次数 == 0
    硬冲突数量 == 0
    来源动作动态可追溯
```

验收：

```text
“来源报告可提交”不再单独足以提交稳定跟踪事实；
目标动态必须在合法值域 / 预测区间内成立。
```

### P8：跟踪基准滚动更新 / 冻结机制

目标：

```text
稳定时滚动更新当前有效基准；
冲突、丢失、遮挡或预测超限时冻结基准。
```

更新条件：

```text
跟踪命中
未丢失
预测误差 < 阈值
连续命中帧数 > 最小连续命中帧数
非法区间跳变次数 == 0
质量可用
```

冻结条件：

```text
未命中
丢失
遮挡
待识别像素增加
值域冲突
身份冲突
预测误差超限
```

验收：

```text
冻结后不提交稳定动态；
进入重捕获 / 识别 / 观察。
```

## 7. 暂停条件

遇到以下情况必须暂停并回到规范 / 计划确认：

```text
1. 现有结构无法区分外设侧当前观测值和目标存在正式一阶特征值。
2. 现有提交入口无法表达跟踪事实类型。
3. 现有质量门无法表达可复验、可生成动态候选、可提交稳定跟踪等用途能力。
4. 现有目标观察约束无法追溯三类 generation。
5. 现有基准结构无法区分当前有效基准、滚动基准和冻结基准。
6. 需要新增主结构字段，但不能证明无法用已有特征、二次特征、状态动态表达。
```

## 8. 最终边界

```text
跟踪报告 != 正式跟踪事实。
外设侧当前观测值 != 目标存在正式特征值。
目标命中 != 可以写新一阶特征值。
无强目标观察约束 != 可以提交稳定跟踪事实。
未命中目标簇 != 普通跟踪成功报告。
可用材料 != 稳定跟踪动态候选。
来源报告可提交 != 稳定跟踪事实可提交。
跟踪失败 != 全部是条件不足。
```
