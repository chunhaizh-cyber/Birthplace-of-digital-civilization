## 0. 目标

```text
把扫描本能方法收束为唯一正式入口：
    自我_扫描当前场景

复用本能方法数字 ID：
    6146

删除旧扫描机器路径：
    自我_扫描已识别区域
    自我扫描已识别区域
    扫描已识别区域

按流程图 v0.13 和规格说明书第 7 节完成完整实现：
    生成本轮扫描关注集合；
    消费已合法外设数据项；
    比较已归属存在的已有特征；
    通过统一写入接口更新当前状态、基准、状态动态、缺口信息；
    输出状态信息、信息缺口或空信息；
    返回扫描方法运行虚拟存在指针。
```

本计划包含实现与验证，不包含：

```text
不重构 D455 外设线程 L0-L3 供料链；
不重新定义观察、识别、跟踪；
不把任务筹办或任务执行登记为本能方法；
不以模拟测试、夹具测试、伪造入口或伪造动作动态完成验收。
```

```text

5. 扫描不直接调用观察、识别、跟踪；缺口只能作为需求来源进入需求、任务、方法闭环。
6. 外设侧 L0-L3 只供料，扫描属于自我侧 L4 承接和当前场景维护。
```

### P5 对应关系与覆盖索引

目标：

```text
对每个已合法外设数据项，判断其对应哪个本轮应覆盖存在；
建立本轮外设覆盖索引；
处理多对一、一对多和候选不唯一。
```

判断函数：

```text
判断空间位置一致
判断空间尺寸一致
判断轮廓一致
判断轮廓极值一致
判断唯一找回
```

硬规则：

```text
空间位置一致时，用空间尺寸和轮廓确认同一存在；

唯一找回必须满足：
    候选数量 == 1
    硬冲突数量 == 0
    用于唯一识别特征数量 > 0
不能只取最高分。
```

输出：

```text

覆盖冲突记录

二次特征评分
```

```text

超值域：
    记录值域冲突；

```

### P7 异常未覆盖解释

目标：

```text
只处理：
    本轮应覆盖存在集合 - 本轮外设覆盖索引
```

实现函数：

```text
预测当前应在空间坐标
判断预测坐标是否视野外
判断遮蔽覆盖证据
判断子层证据是否足够
判断消失候选是否成立
```

规则：

```text
1. 先读取当前场景中既有状态 / 动态信息。
2. 用上一帧状态、上一帧动态、自我移动证据、中间移动存在证据预测当前坐标。
3. 预测坐标在视野外：
       可写空间位置当前值 = 预测坐标；
       来源和视野外状态写入运行存在、状态信息或动态证据；
       不塞入空间位置值本体。
4. 遮蔽 / 覆盖证据成立：
       写遮蔽 / 覆盖状态；
       若子层证据不足，记录信息缺口。
5. 无视野外、无遮挡、无自我移动或中间移动解释：
       写未观测到 / 消失候选；
       不删除世界存在。
```

### 5.6 场景维护用例矩阵

这些用例只能由真实外设样本、真实运行日志或已有真实报告触发；缺样本时登记为待条件项，不使用模拟样本。

| 用例 | 输入条件 | 期望输出 |
| --- | --- | --- |
| 空合法数据集 | 无可处理外设数据项 | 语义输出为空信息；保留处理闭合证据 |
| 缺输入条件 | 缺场景、缺基准、缺值域或缺空间位置 | 信息缺口；建议后续路径结构化 |
| 已覆盖且无变化 | 外设数据项与内部存在一致 | 当前状态可刷新；输出空信息或摘要状态 |
| 已覆盖且值域内变化 | 差异超过阈值且落入值域 | 写当前状态；记录状态变化动态和写入摘要 |
| 值域冲突 | 当前值超出特征值域 | 记录值域冲突；不写正常变化 |
| 候选不唯一 | 多个内部存在都可能对应 | 覆盖冲突 / 对应关系缺口；不强行最高分入账 |
| 新外设数据无归属 | 当前场景和世界树无唯一已见存在 | 不确认新存在；输出识别或观察缺口需求来源 |
| 应覆盖但未覆盖且预测视野外 | 预测坐标在视野外 | 可写预测空间坐标；状态证据记录视野外 |
| 应覆盖但未覆盖且遮蔽成立 | 预测区域被近处存在覆盖 | 写遮蔽 / 覆盖状态或子层证据缺口 |
| 应覆盖但未覆盖且无解释 | 无视野外、无遮挡、无移动解释 | 写未观测到 / 消失候选；不删除存在 |
