## 2. 主剧本

```text
当前状态 / 目标状态之间存在差距
    -> 自动生成或刷新一个更细原子执行子需求
    -> 子需求具备完整目标宿主、目标特征类型、当前状态、目标状态、满足关系
    -> 同目标刷新时复用 / 合并
    -> 子需求任务化
    -> 子任务完成后父需求 / 父任务回流
```

## 3. 分步计划

### P1. 根需求差距执行子需求生成

在根需求状态镜像刷新后，若根需求仍未满足，则为根需求确保一个同目标执行子需求。

硬要求：

```text
1. 子需求必须挂在触发它的根需求下。
2. 子需求必须有被需求存在、当前状态、目标状态、目标特征类型缓存、满足关系。
3. 根驱动需求允许生成同目标执行子需求。
4. 不得生成模糊需求。
```

### P2. 同目标刷新复用 / 合并

再次刷新同一差距时必须复用同父同目标子需求，而不是重复创建。

硬要求：

```text
1. 同父直接子链不得出现重复目标活动需求。
2. 派生归因不能作为身份键。
3. 复用旧子需求时要刷新当前状态镜像。
```

### P3. 子需求权重刷新

子需求权重不再跟随父需求压力刷新；父需求压力只用于方向和主需求选择。

硬要求：

```text
active && 阻塞父任务执行 的子需求，对应方向活动权重为 1。
已满足或非活跃子需求不继续分配权重。
父需求压力不得继承为子需求权重。
```
