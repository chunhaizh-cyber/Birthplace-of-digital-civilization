任一条件出现时，可以把本计划从待完成项取回：

```text

    自我_评估观察帧质量 或 S1 日志内
    深度有效率 < 5000
    或 空间坐标有效率 < 5000

或真实任务筹办日志中出现：
    父需求依赖深度空间=1
    或 观察质量父需求依赖裁决
    或 派生目标宿主=新观察材料
    或 观察质量改善路径学习需求

或真实父需求目标特征属于：
    空间候选集合状态
    距离值
    基础空间风险判断状态
    观察存在确认 / 空间归属验证相关特征
```
