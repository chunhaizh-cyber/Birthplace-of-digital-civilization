# D455 稳定轮廓模块重构计划 v0.1

更新时间：2026-06-14

## 1. 目标

在不删除 `外设线程_D455深度相机.ixx`、不破坏现有 D455 报告链路的前提下，按 `流程图/20260614_D455稳定轮廓项目适配流程图_v0.2.md` 将 D455 稳定轮廓链路重构为可维护的外设侧 L0-L3 供料模块。

最终目标：

```text
外设线程_D455深度相机.ixx
    保留导出契约、线程生命周期、采样循环和报告入队编排。

D455 稳定轮廓相关私有逻辑
    分批抽取为稳定材料能力、坐标系闸门、约束调度、轨迹状态和报告构造等更小的模块 / 辅助区。

自我侧正式链路
    仍然只承接观察方法写出的外设观察存在；
    稳定外设观察材料不得直连识别、扫描、跟踪正式逻辑。
```

## 3. 不做事项

```text
1. 不直接删除 `外设线程_D455深度相机.ixx`。
2. 不改掉 `启动外设线程_D455深度相机` / `停止外设线程_D455深度相机` / `读取外设线程_D455深度相机结果` 的外部契约。

4. 不把稳定外设观察材料直接喂给识别、扫描、跟踪正式逻辑。
5. 不新增兼容层、fallback、新旧字段双写或旧流程并存。
6. 不用模拟测试、夹具测试、伪造样本、伪造入口或伪造动作动态验收。
7. 不宣称自我苏醒完成、内部循环完成或 D455 自然业务样本已全量通过。
```

## 4. 总体策略

```text
1. 保留现有可工作的线程入口和报告链。
2. 先把语义命名和质量门口径收紧。
3. 再把稳定材料能力、坐标系、anchor、轨迹状态等结构化。
4. 再把等待项约束调度和报告生成编排分离。
5. 最后把 `外设线程_D455深度相机.ixx` 收缩为线程编排层。
```

执行原则：

```text
每次只改一个闭合切片；
每个切片先写断点清单和预测；
每个切片完成后构建；
涉及 D455 业务链时必须用真实运行日志或真实 D455 样本验证；
发现独立问题先记录并收束，不在同一上下文里同时推进多个未收束问题。
```

### P2 稳定材料能力等级

目标：

```text
引入或整理以下能力状态：
    平面轮廓稳定状态
    深度锚定状态
    空间可用状态
    外设材料可承接状态
    可承接能力等级
```

核心规则：

```text
平面轮廓稳定材料：
    轮廓 / 掩码 / 中心跨帧稳定，深度可不足。

深度锚定稳定材料：
    平面稳定 + 深度有效率 / 深度稳定性达标。

空间可用稳定材料：
    平面稳定 + 深度锚定 + 空间坐标 / 空间摘要可用。
```

优先改动：

```text
外设观察报告队列.ixx 的材料 / 质量判定结构。
外设线程_D455深度相机.ixx 的 L1 稳定子集生成与摘要写入。
```

验收：

```text
单帧质量、跨帧稳定质量、可承接能力等级可以分别输出。
anchor 不达标不再直接否定平面轮廓稳定材料。
Debug x64 构建通过。
```

### P3 坐标系闸门与 anchor 三指标

目标：

```text
补齐 D455 稳定材料的坐标系声明和 anchor 数量 / 密度 / 覆盖率三指标。
```

新增或整理字段：

```text
主分割坐标系ID
深度材料.坐标系ID
左红外边缘.坐标系ID
RGB裁剪材料.坐标系ID
外设材料.坐标系一致性状态
anchor数量
anchor密度
anchor覆盖率
边界anchor覆盖率，可选
```

硬规则：

```text
坐标系一致性状态 != 一致：
    不得生成空间可用稳定材料。

坐标系一致性状态 == 降级：
    可生成平面轮廓稳定材料；
    不生成空间可用稳定材料。
```

验收：

```text
材料摘要能说明坐标系状态和 anchor 三指标。
空间可用判定不能只看深度或 anchor 数量。
Debug x64 构建通过。
```
