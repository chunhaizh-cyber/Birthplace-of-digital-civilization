## 0. 归属

```text
父线：外设观察特征与自我场景认知链
线程名：外设线程_D455深度相机
当前状态：独立模块已建立；Debug x64 构建通过；`--peripheral-autonomous-observe` 已能进入该模块；2026-05-29 真实 D455 入口已验证逐簇识别 / 扫描变化 / 目标跟踪三种等待项、报告入队、按ID回查和任务管理承接；稳定性已拆成基础采样稳定与观察候选稳定两层，并已通过外设线程内部跨帧观察簇缓存取得真实跨帧证据。扫描变化已改用专用跨帧簇ID匹配，当前真实样本基础采样稳定、观察候选稳定和三种观察链路均已通过，扫描变化报告变化簇=0；掩码 / 彩色轮廓局部图 / 深度轮廓局部图已完成句柄级接入，仍未物化为报告队列中的大块图像缓冲。
```

该线程不是动作来源，不生成方法动作动态。它是 D455 外设观察服务基础模块：当前只做有限诊断采样和稳定性摘要，后续同一线程对外只支持逐簇识别报告、扫描变化报告和跟踪报告。质量诊断、ROI、补观察、稳定特征取值、重捕获、局部细分、变化监测和配置学习只作为内部策略、报告字段或自我后续方法，不为不同能力各造一套外设系统。

最终交互口径：

```text
外设线程持续生产观察材料；
任务管理工作线程按当前正式需求创建观察等待项 / 订阅项；
外设线程根据等待项输出逐簇识别报告、扫描变化报告或跟踪报告；
任务管理工作线程消费报告并生成任务回执 / 派生需求消息；
自我线程裁决是否入需求树 / 世界树。
```

## 1. 目标

```text
由 `外设线程_D455深度相机` 控制双目相机连续获取观察材料；
当前诊断入口先验证打开、采样、释放、样本摘要和稳定性比较；
后续同一线程扩展为输出逐簇识别报告、扫描变化报告或跟踪报告；
相机线程内部能力直接由工程代码、适配器、缓存、队列和私有算法模块实现；
不把逐簇识别、扫描变化、跟踪、补观察、稳定取值、局部细分等设计成多套外设系统；
不把补观察、稳定取值、局部细分、质量诊断或配置学习暴露成自我可见外设模式；
不把任一观察运行模式写成双目相机唯一全局硬切状态。
```

当前稳定性分两层记录，避免把“相机基础采样可稳定运行”和“当前视野候选跨帧稳定”混成一个结论：

```text
基础采样稳定：
    帧尺寸
    像素特征数量
    深度有效率
    空间坐标有效率
    帧质量评分

观察候选稳定：
    空间候选有无和数量
    主候选像素数量 / 中心坐标 / 范围稳定性评分
```

后续对外报告：

```text
陌生环境逐簇识别：
    从未知视野建立当前帧观察像素簇和存在候选输入；
    输出观察像素簇集合、帧级掩码、未解释区域、低置信区域、不可观测区域和稳定特征摘要。

已识别场景扫描变化：
    低频守望已知场景是否出现新增、消失、移动、尺寸变化、质量异常或高风险未知簇；
    输出变化候选、新增 / 消失 / 变化簇、低质量区域和差异摘要。

目标跟踪观察：
    盯住已有观察像素簇 / 存在候选；
    输出外设内部跟踪ID、目标ROI、目标掩码、稳定特征集合、连续成功次数、复现离散度、丢失原因和重捕获候选集合。

其它能力：
    ROI：作为逐簇识别或目标跟踪等待项参数；
    补观察：由任务管理根据质量缺口派生新的逐簇识别、扫描变化或目标跟踪等待项；
    稳定特征取值：作为跟踪报告核心字段；
    重捕获：作为跟踪报告字段；
    局部细分：由自我使用局部图和掩码继续处理；
    变化监测：作为扫描变化报告核心输出，也可由自我比较多次报告；
    质量诊断：作为报告质量字段和失败原因；
    配置学习：作为外设内部学习模块，只暴露配置摘要。
```

## 2. 边界

```text
允许：
    线程直接调用双目相机适配器或私有工程模块打开 / 采集 / 释放；
    线程内部直接用代码实现采集、稳定性比较、逐簇识别报告、扫描变化报告和跟踪报告生成；
    线程记录稳定 / 不稳定结论和原因；
    后续由任务管理提交逐簇识别、扫描变化或目标跟踪外设等待项 / 订阅项；
    后续把真实采样结果转换为外设观察报告队列项。

禁止：
    把线程当作动作来源；
    把相机线程内部算法步骤登记成自我层本能方法；
    把任务筹办 / 任务执行恢复成本能方法；
    为了验证稳定性新增模拟样本、夹具入口或伪造动作动态；
    把单次稳定采样扩大解释成完整视觉分割、跨帧身份稳定或内部循环完成；
    为不同观察运行模式各造一套外设系统；
    让自我线程直接消费相机流。
```
