# 20260527_外设线程_D455深度相机稳定采样实施计划 v0.1（扫描 / 跟踪报告口径修订）

## 0. 归属

```text
父线：外设观察特征与自我场景认知链
线程名：外设线程_D455深度相机
当前状态：独立模块已建立；Debug x64 构建通过；`--peripheral-autonomous-observe` 已能进入该模块；当前环境无 D455 时返回 No device connected；观察意图订阅、外设观察报告队列、稳定特征缓存和任务管理承接仍待后续切片。
```

该线程不是动作来源，不生成方法动作动态。它是 D455 外设观察服务基础模块：当前只做有限诊断采样和稳定性摘要，后续同一线程对外只支持扫描报告和跟踪报告。质量诊断、ROI、补观察、稳定特征取值、重捕获、局部细分、变化监测和配置学习只作为内部策略、报告字段或自我后续方法，不为不同能力各造一套外设系统。

最终交互口径：

```text
外设线程持续生产观察材料；
任务管理工作线程按当前正式需求创建观察等待项 / 订阅项；
外设线程根据等待项输出扫描报告或跟踪报告；
任务管理工作线程消费报告并生成任务回执 / 派生需求消息；
自我线程裁决是否入需求树 / 世界树。
```

## 1. 目标

```text
由 `外设线程_D455深度相机` 控制双目相机连续获取观察材料；
当前诊断入口先验证打开、采样、释放、样本摘要和稳定性比较；
后续同一线程扩展为输出扫描报告或跟踪报告；
相机线程内部能力直接由工程代码、适配器、缓存、队列和私有算法模块实现；
不把扫描、跟踪、补观察、稳定取值、局部细分等设计成多套外设系统；
不把补观察、稳定取值、局部细分、质量诊断或配置学习暴露成自我可见外设模式；
不把任一观察意图写成双目相机唯一全局模式。
```

当前稳定性以连续样本的通用观察指标比较为准：

```text
帧尺寸
像素特征数量
深度有效率
空间坐标有效率
帧质量评分
空间候选有无和数量
可选主候选像素数量 / 中心坐标 / 范围稳定性评分
```

后续对外报告：

```text
扫描观察：
    看当前视野里大概有什么；
    输出观察像素簇集合、帧级掩码、未解释区域、低置信区域、不可观测区域和稳定特征摘要。

跟踪观察：
    盯住已有观察像素簇 / 存在候选；
    输出外设内部跟踪ID、目标ROI、目标掩码、稳定特征集合、连续成功次数、复现离散度、丢失原因和重捕获候选集合。

其它能力：
    ROI：作为扫描 / 跟踪等待项参数；
    补观察：由任务管理根据质量缺口派生新的扫描或跟踪等待项；
    稳定特征取值：作为跟踪报告核心字段；
    重捕获：作为跟踪报告字段；
    局部细分：由自我使用局部图和掩码继续处理；
    变化监测：由自我比较多次扫描 / 跟踪报告；
    质量诊断：作为报告质量字段和失败原因；
    配置学习：作为外设内部学习模块，只暴露配置摘要。
```

## 2. 边界

```text
允许：
    线程直接调用双目相机适配器或私有工程模块打开 / 采集 / 释放；
    线程内部直接用代码实现采集、稳定性比较、扫描报告和跟踪报告生成；
    线程记录稳定 / 不稳定结论和原因；
    后续由任务管理提交扫描型或跟踪型外设等待项 / 订阅项；
    后续把真实采样结果转换为外设观察报告队列项。

禁止：
    把线程当作动作来源；
    把相机线程内部算法步骤登记成自我层本能方法；
    把任务筹办 / 任务执行恢复成本能方法；
    为了验证稳定性新增模拟样本、夹具入口或伪造动作动态；
    把单次稳定采样扩大解释成完整视觉分割、跨帧身份稳定或内部循环完成；
    为不同观察意图各造一套外设系统；
    让自我线程直接消费相机流。
```

## 3. 实施切片

```text
S0 已完成基础模块：
       新增 `外设线程_D455深度相机.ixx`；
       支持启动 / 请求停止 / 等待完成 / 读取结果；
       支持有限样本数诊断；
       输出线程生命周期、样本摘要和稳定性摘要。

S1 保留诊断入口：
       `--peripheral-autonomous-observe` 继续作为真实硬件诊断入口；
       入口默认执行有限扫描型采样；
       不宣称已经完成正式外设观察报告队列；
       不要求诊断采样过程拆成本能方法。

S2 增加观察等待项 / 订阅项结构：
       来源需求；
       目标外设；
       观察意图类型 = 扫描 / 跟踪；
       目标区域 / 目标簇 / 目标候选，可空；
       ROI / 掩码 / 跟踪种子，可空；
       期望报告类型 = 扫描报告 / 跟踪报告；
       期望特征类型集合；
       最小稳定性要求；
       最大允许报告年龄；
       是否允许缓存报告。

S3 输出扫描观察报告：
       当前观察帧；
       观察像素簇集合；
       簇ID掩码；
       未解释像素掩码；
       低置信像素掩码；
       不可观测区域掩码；
       每个簇的彩色轮廓局部图 / 深度轮廓局部图 / 稳定特征摘要。

S4 输出跟踪观察报告：
       外设内部跟踪ID；
       来源观察帧；
       来源观察像素簇；
       目标ROI；
       目标掩码；
       稳定特征集合；
       连续成功次数；
       复现离散度；
       丢失原因；
       重捕获候选集合。

S5 同一线程内调度扫描 / 跟踪：
       高优先级安全跟踪优先；
       低频扫描保留；
       质量不足时在扫描 / 跟踪报告中写入质量字段和失败原因；
       跟踪丢失时在跟踪报告中写入丢失状态和重捕获候选；
       扫描发现高风险未知簇时可提升为跟踪观察。

S6 接入队列和任务管理承接：
       写入外设观察报告队列；
       更新最新观察缓存；
       更新稳定特征缓存；
       任务管理工作线程匹配等待项 / 订阅项；
       命中后只生成任务回执 / 派生需求消息 / 观察事实承接请求；
       自我线程裁决后才可能入树。
```
