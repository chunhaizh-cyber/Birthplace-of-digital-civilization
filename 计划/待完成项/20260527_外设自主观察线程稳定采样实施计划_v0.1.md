# 20260527_外设自主观察线程稳定采样实施计划 v0.1

## 0. 归属

```text
父线：外设观察特征与自我场景认知链
线程名：外设自主观察线程
当前状态：代码已建立；Debug x64 构建通过；命令入口已验证可启动线程并在等待超时时退出；真实 D455 稳定采样日志待条件具备后复验。
```

该线程不是动作来源，不生成方法动作动态。它只负责调度现有双目相机 / 自我观察方法链，连续取得观察特征快照，并在线程侧形成稳定性结论。

## 1. 目标

```text
由外设自主观察线程控制双目相机连续获取观察特征值；
不预设必须取得哪一种特征；
重点检查连续取得的特征值是否稳定。
```

稳定性以连续样本的通用观察指标比较为准：

```text
帧尺寸
像素特征数量
深度有效率
空间坐标有效率
帧质量评分
空间候选有无和数量
可选主候选像素数量 / 中心坐标 / 范围稳定性评分
```

## 2. 边界

```text
允许：
    线程调度现有观察方法链；
    线程读取控制面板快照形成采样摘要；
    线程记录稳定 / 不稳定结论和原因。

禁止：
    把线程当作动作来源；
    把任务筹办 / 任务执行恢复成本能方法；
    为了验证稳定性新增模拟样本、夹具入口或伪造动作动态；
    把单次稳定采样扩大解释成完整视觉分割、跨帧身份稳定或内部循环完成。
```

## 3. 实施切片

```text
S1 增加命令行入口：
       --peripheral-autonomous-observe
       --autonomous-observe
       --auto-observe-stable

S2 建立 类_外设自主观察线程：
       启动线程；
       在线程内调用现有自我场景观察链；
       连续取得 3 个真实观察快照；
       每次采样写入 外设自主观察线程/采样 日志。

S3 建立稳定性裁决：
       基础特征可比样本数量 >= 2；
       最新连续窗口稳定；
       至少存在 1 条稳定连接。

S4 输出命令结果：
       稳定返回 0；
       不稳定或无可比样本返回 2；
       控制台和日志记录样本摘要与不稳定原因。
```

## 4. 验收

```text
可立即验收：
    Debug x64 构建通过；
    命令行入口能编译并调度线程；
    线程不新增本能方法、不改变任务筹办逻辑。

待条件具备后验收：
    真实 D455 连续采样日志出现 外设自主观察线程/启动；
    出现至少 3 条 外设自主观察线程/采样；
    出现 外设自主观察线程/完成；
    样本中帧尺寸、像素特征、深度有效率、空间坐标有效率等稳定性依据可回查；
    若不稳定，日志给出首个不稳定原因。
```

    msbuild .\鱼巢.vcxproj /p:Configuration=Debug /p:Platform=x64 /p:LinkIncremental=false /m

构建结果：
    0 错误；
    1 个既有 LNK4075 警告。

    .\x64\Debug\鱼巢.exe --peripheral-autonomous-observe

实际结果：
    外设自主观察线程已启动；
    45 秒等待上限触发；

结论：
