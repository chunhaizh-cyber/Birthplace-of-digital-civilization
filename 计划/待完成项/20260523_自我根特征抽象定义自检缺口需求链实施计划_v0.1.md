## 2. 主线目标

把当前安全 / 服务根需求主链改成：

```text
世界树.抽象特征树.安全 / 服务定义
    + 自我存在.自我_安全值 / 自我_服务值 当前实例
        -> 根特征自检
            -> 缺口报告
                -> 缺口生成需求
                    -> 未满足需求生成任务
```

最终不再依赖：

```text
硬编码目标安全值 / 目标服务值；
硬编码服务值增加必要条件；
自检候选统一挂安全根；
根需求差距同目标子需求；
服务对象缺失时仍尝试服务值结算。
```

当前差距：

```text
1. 自我类::根目标安全值 / 根目标服务值 仍是硬编码目标来源。

5. 自检线程当前主要围绕方法类自检，尚未产生安全 / 服务根特征自检报告。
6. 服务对象状态变化集已有消息字段，语义上承载服务对象外在特征状态变化证据，但尚未成为服务值结算的硬证据链。
```

## 4. 不做范围

本计划不做：

```text
1. 不把安全 / 服务建成两个独立存在对象。
2. 不恢复任务筹办 / 任务执行本能方法。
3. 不新增 `--*-check` 回归入口。
4. 不用模拟样本、夹具样本或伪造动作动态验证。
5. 不把服务值差距本身当作服务事实证据。
6. 不把自检报告生成直接结算为安全值或服务值增加。
```
