# 20260607_识别链路唯一性识别与提交分级修正计划_v0.1

## 1. 计划定位

当前识别链路骨架可以保留：

```text
任务管理创建逐簇识别等待项
    -> D455 外设线程生成逐簇识别材料
    -> 任务管理工作线程匹配报告并做质量用途门
    -> 自我线程承接材料候选
    -> 6127 自我_验证外设观察像素簇候选
    -> 6128 自我_确认外设观察存在候选
    -> 6145 自我_识别外设观察材料
    -> 6129 提交_确认观察存在事实
    -> 6150 提交_当前观察范围可观测单位存在对应事实
```

本计划不推翻这条链，只修正识别权限、成功条件和提交前置。

核心定案：

```text
识别不要求比较所有特征；
识别只要求在当前识别范围内唯一确定存在。

候选唯一且无硬冲突：
    识别完成，建立归属映射。

候选不唯一：
    观察补特征。

无匹配候选：
    待复验观察存在承接，不直接新建已确认存在。

候选唯一但硬冲突：
    观察复验，不写归属。
```

当前状态：

```text
本计划为后续代码修正依据；
不表示 P0-P7 代码已完成；
不表示 6129 已经完成分级提交拆分；
不表示扫描启动闸门已经由 6145 强状态改为扫描当前判定。
```

## 3. 必须保留的边界

```text
1. D455 只产逐簇识别材料，不裁决世界真值。
2. 任务管理线程只做报告承接、等待项匹配、质量用途门、回执和缺口。
3. 自我线程承接报告只落内部世界候选材料，不确认世界存在真值。
4. 6127 只验证材料可回查、候选材料有效和单轮可复验性。
5. 6128 只生成识别候选方案，不创建观察存在。
6. 6145 只生成同一性二次特征、归属映射和识别状态动态，不写新一阶特征值。
7. 6129 才是观察存在正式提交入口。
8. 6150 只把已归属稳定子集桥接给扫描目标观察约束；扫描是否启动仍由扫描闸门判定。
```

## 4. 目标状态

```text
6127：
    输出材料可回查状态、候选材料验证状态、簇投影有效状态、单轮可复验状态。
    不输出观察完成、识别完成或已确认观察存在。

6128：
    从“固定分数确认方案”改为“候选集合唯一性筛选方案”。
    输出同一候选、无匹配候选、冲突、证据不足、待复验。

6145：
    成功条件从 观察完成 + 稳定复现 + 可复验 改为 候选唯一 + 硬冲突为 0。
    输出扫描候选线索，不直接输出长期有效的扫描可启动状态。

6129：
    拆成待复验观察存在提交和已确认观察存在提交。
    已确认提交必须通过唯一性、硬冲突、归属映射和材料等级闸门。
```

## 5. 实施切片

### P0：6145 识别完成条件改为唯一性

目标：

```text
把 “观察完成 + 稳定复现 + 可复验” 从识别完成充分条件降级为材料质量 / 可复验输入；
把识别完成条件改为：
    识别范围状态 == 已确定
    候选集合数量 == 1
    硬冲突数量 == 0
    用于唯一识别特征数量 > 0
    归属映射状态 == 已建立。
```

修改范围：

```text
自我动作实现.外设模块.ixx
流程图/当前_本能方法_识别内部实现逻辑流程图.md
```

验收：

```text
真实日志或状态快照中，6145 成功不再只依赖 观察完成状态；
候选不唯一或硬冲突时，6145 不写识别完成和已归属。
```

### P1：6128 改为候选集合筛选算法

目标：

```text
把 6128 的正式算法改成：
    候选召回
    -> 特征组逐步筛选
    -> 候选集合数量判断
    -> 硬冲突验算
    -> 输出识别候选方案。
```

规则：

```text
固定匹配分数仍可作为默认视觉特征组评分；
不得让固定分数替代唯一性原则。
```

验收：

```text
方案项可区分：
    同一候选
    无匹配候选
    候选不唯一
    冲突
    证据不足
    待复验。
```

### P2：新建方案降级

目标：

```text
把 “最佳分不足 -> 方案项=新建” 降级为：
    无匹配候选
    或 新外设观察存在待承接
    或 待复验观察存在。
```

禁止：

```text
无最佳匹配不得直接等价为正式新建已确认观察存在。
```

验收：

```text
无匹配候选时：
    同一性状态 == 无匹配候选
    归属状态 == 未归属
    允许提交 == 0
    或仅允许进入待复验观察存在提交。
```

### P3：6129 提交入口分级

目标：

```text
拆分提交语义：
    提交_外设观察存在待复验事实
    提交_确认观察存在事实
```

已确认提交前置：

```text
候选集合数量 == 1
硬冲突数量 == 0
归属映射状态 == 已建立
材料等级允许进入提交入口
```

验收：

```text
D455 优质逐簇报告不能直接经 6128 新建方案进入已确认观察存在；
待复验观察存在和已确认观察存在在状态上可区分。
```

### P4：阈值从硬编码语义改为识别策略特征

目标：

```text
把 7500 / 1200 / 0..10000 等固定阈值改为可读取策略特征：
    识别策略.最低同一性评分
    识别策略.最低唯一性分差
    识别策略.候选匹配评分值域
    识别策略.最小同一性证据帧数
```

合法来源：

```text
特征类型默认比较值域
当前任务容差
外设测量不确定度
目标存在历史稳定值域
外设学习结果
安全 / 服务根需求约束
```

验收：

```text
不同特征组可使用不同策略值；
默认视觉策略仍可保留，但不能作为所有识别的唯一硬前置。
```

### P5：识别冲突量化

目标：

```text
把 “冲突” 拆成可统计硬冲突：
    空间冲突
    掩码冲突
    轮廓冲突
    身份冲突
    值域冲突
```

输出：

```text
外设观察存在.硬冲突数量
外设观察存在.识别冲突类型
外设观察存在.冲突二次特征集合
```

验收：

```text
候选唯一但硬冲突数量 > 0 时，不写已归属；
日志能指出冲突类型，而不是只有说明性文字。
```

### P6：6145 扫描可启动状态降级

目标：

```text
把 6145 输出的强 “扫描可启动状态” 改成：
    扫描候选线索状态 == 已生成
```

扫描启动另由扫描闸门判定：

```text
已归属
目标特征当前值可读
目标特征值域可读
上一轮基准可读
目标观察约束可用
generation 匹配
非背景
扫描优先级达标
待识别像素不过多
```

验收：

```text
识别通过一次不再让目标长期无条件可扫描；
6146 / 任务管理每次扫描前重新判定当前闸门。
```

### P7：质量用途门接入识别分级

目标：

```text
可用材料：
    可进入 6127 和识别待复验；
    不进入强确认提交。

优质材料：
    可进入识别候选和提交入口组织；
    仍必须通过唯一性、硬冲突和 6129 裁决。
```

验收：

```text
可用材料不会被完全丢弃；
可用但非优质材料不会生成已确认观察存在；
优质材料不会绕过唯一性识别。
```

## 7. 暂停条件

遇到以下情况必须暂停并回到规范 / 计划确认：

```text
1. 现有结构无法区分待复验观察存在和已确认观察存在。
2. 现有特征系统无法表达候选数量、硬冲突数量或用于唯一识别特征数量。
3. 6129 无法在不破坏旧提交链的情况下拆分提交状态。
4. 扫描链仍强依赖 6145 写死的扫描可启动状态，无法改为当前判定。
5. 需要新增主结构字段，但不能证明无法用已有特征、二次特征、状态动态表达。
```

## 8. 最终边界

```text
报告生成 != 识别完成。
观察完成 != 识别完成。
优质报告 != 已确认观察存在。
固定匹配分数最高 != 当前范围唯一。
无匹配候选 != 可以直接新建已确认观察存在。
候选唯一但硬冲突 != 已归属。
识别成功 != 扫描可启动。
识别不写新一阶特征值。
```
