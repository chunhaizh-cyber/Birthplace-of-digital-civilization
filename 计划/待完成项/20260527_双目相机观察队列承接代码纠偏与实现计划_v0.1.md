# 20260527_双目相机观察队列承接代码纠偏与实现计划 v0.1

## 0. 定位

状态：

```text
基于当前代码现状制定；
未进入当前主动队列；
未实施代码；
等待计划索引选择双目相机观察像素簇接入线后执行。
```

本计划用于把现有代码从：

```text
命令级双目相机采样
    -> 观察特征帧摘要
    -> 像素索引 / 空间候选 / 控制面板快照
```

纠偏到：

```text
外设主动生产
    -> 同一外设线程输出扫描报告 / 跟踪报告
    -> 外设观察报告队列 / 最新观察缓存 / 稳定特征缓存
        -> 任务管理外设消息承接线程按正式需求创建扫描型或跟踪型等待项 / 订阅项并消费
            -> 任务回执 / 派生需求消息 / 动作动态输入 / 观察事实承接请求
                -> 自我线程裁决入账
```

约束：

```text
不让安全 / 服务根需求直接消费外设原始队列；
不把外设线程作为动作动态来源；
不把任务筹办 / 任务执行恢复成本能方法；
不把观察像素簇宣称为稳定世界存在；
不把旧像素级 100% 表述继续作为当前主目标。
不为扫描、跟踪、补观察、稳定取值、局部细分等各造一套并行外设系统；
不把补观察、稳定取值、局部细分、质量诊断或配置学习做成自我可见外设模式；
不把任一观察意图写成相机唯一全局模式。
```

## 2. 纠偏原则

### 2.1 不平行重造观察链

```text
现有观察帧、像素索引、质量诊断和空间候选链继续保留；
新增观察像素簇时，先从空间候选过渡映射；
后续再把真实簇级掩码、局部图和稳定特征逐步补齐。
```

### 2.2 像素层只作为可回查底座

```text
保留像素覆盖、坐标回查、帧内编号回查和像素特征索引；
不再把 W * H 个像素观察存在节点作为当前主目标；
涉及旧字段时，用兼容旧链路的底座实现形态解释。
```

### 2.3 队列消息不是事实权威

```text
外设观察报告队列项只是外设观察材料；
任务管理承接线程只是分拣和转译；
正式观察事实、观察像素簇、存在候选仍由自我线程裁决和自我承接方法入账。
```

### 2.4 任务管理只承接，不越权写需求树

```text
任务管理可以生成任务回执、派生需求消息、动作动态输入和观察事实承接请求；
正式需求入树仍由自我线程裁决；
任务筹办和任务执行仍是任务管理生命周期普通函数。
```

### 2.5 观察意图不是全局模式

```text
同一个双目相机外设线程持续生产观察材料；
任务管理工作线程按正式需求创建外设等待项 / 订阅项；
等待项 / 订阅项携带观察意图类型；
外设线程按等待项输出扫描报告或跟踪报告；
任务管理工作线程消费报告并生成任务回执 / 派生需求消息；
自我线程裁决是否入需求树 / 世界树。
```

第一版观察意图类型只包括：

```text
扫描
跟踪
```

ROI、补观察、稳定特征取值、重捕获、质量诊断和配置学习只能作为等待项参数、内部策略或报告字段；局部细分和变化监测由自我在承接扫描 / 跟踪报告后继续处理。

禁止：

```text
扫描外设系统 + 跟踪外设系统 + 补观察外设系统 并行重造；
双目相机全局模式 = 任一观察意图 的硬切；
自我线程直接吃相机流。
```


