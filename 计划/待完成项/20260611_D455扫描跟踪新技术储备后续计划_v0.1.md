状态：暂时搁置，待 `D455 稳定观察子集与轮廓跨帧稳定化实现计划` P0-P3 至少闭合后恢复。

## 1. 定位

本计划记录观察方法之后的扫描 / 跟踪技术路线储备，不抢当前主动计划。

当前主动计划主要解决：

```text
L0 原始观察材料
-> L1 稳定观察子集
-> 任务管理观察事实承接 / 提交入口候选
```

本计划后续解决：

```text
扫描：
    L1 稳定观察子集
    -> 可比历史 / 基准帧 / 空间地图
    -> 变化候选
    -> 提交入口裁决

跟踪：
    L1 稳定观察子集
    -> 轨迹预测 / 观测关联 / 丢失重捕获
    -> 跟踪报告
    -> 提交入口裁决
```

## 3. 硬边界

```text
1. 扫描 / 跟踪算法只能作为外设内部或材料生成层技术，不直接写世界树真值。
2. 外部算法输出只能形成观察材料、变化候选、轨迹候选、质量缺口或可回查证据。
3. 正式入账仍必须经过任务管理承接和提交入口裁决。
4. 不把 SLAM 地图、TSDF 网格、占据图、tracklet、mask propagation 或检测框直接当作已确认观察存在。
5. 不把扫描变化或跟踪动态写成需求满足、安全值或服务值。
6. 不新增本能方法来包装外设内部算法步骤。
7. 不引入模拟样本、夹具入口、伪造报告或伪动作动态。
8. 若后续接入第三方库，必须先做隔离层设计，不污染自我动作实现模块和 C++20 module 边界。
```

## 4. 扫描技术储备

### S1 RGB-D / Stereo SLAM 可比基准

候选技术：

```text
RTAB-Map；
ORB-SLAM3。
```

用途：

```text
生成相机位姿、关键帧、可比历史和局部场景基准；
支持扫描时判断当前 L1 稳定观察子集是否能与历史观察范围对齐。
```

鱼巢落点：

```text
外设线程内部生成扫描基准材料；
任务管理承接扫描基准摘要；
自我提交入口只裁决稳定对应存在上的变化候选。
```

恢复前提：

```text
L1 稳定观察子集已可自然生成；
当前帧 / 历史帧至少有可对齐的稳定子集；
需要扫描变化而不是单纯识别闭合。
```

### S2 TSDF / 多帧深度融合

候选技术：

```text
Open3D RGB-D integration；
TSDF / voxel block integration。
```

用途：

```text
把多帧深度融合成稳定局部表面；
降低单帧深度噪声；
为平面轮廓、空间范围、表面变化和遮挡判断提供更稳定材料。
```

鱼巢落点：

```text
只生成融合深度材料、局部表面材料、质量摘要和变化候选；
不得把融合表面直接写成世界存在。
```

恢复前提：

```text
D455 多帧静止窗口可稳定采样；
L1 稳定子集仍受深度噪声影响；
需要比平面轮廓更稳的扫描材料。
```

### S3 占据图 / 空间变化

候选技术：

```text
OctoMap；
局部体素占据栅格；
二维 / 三维 occupancy map。
```

用途：

```text
表达空间占据、空闲、未知；
支持障碍物、新增占据、消失占据和可通行区域变化候选。
```

鱼巢落点：

```text
占据图是扫描材料，不是世界真值；
正式变化动态必须绑定已稳定对应存在或明确观察范围。
```

恢复前提：

```text
需要扫描空间占据变化；
已有稳定子集和可比历史；
需要区分未知、空闲、占据和材料不足。
```

### S4 动态场景剥离

候选技术：

```text
DynaSLAM 类动态对象剥离思路；
静态背景建图 + 动态目标排除；
动态区域 mask 过滤。
```

用途：

```text
把静态环境扫描和动态目标跟踪拆开；
避免动态目标污染扫描基准。
```

鱼巢落点：

```text
动态区域只形成需跟踪 / 需重识别材料；
不得输出“背景存在”；
视觉背景必须转写为静止存在、环境存在或低动态存在候选。
```

恢复前提：

```text
扫描基准被动态目标污染；
同一观察范围同时存在静态环境扫描和指定目标跟踪需求。
```

## 5. 跟踪技术储备

### T1 轨迹预测与数据关联

候选技术：

```text
Kalman Filter；
Hungarian assignment；
ByteTrack 类高低置信候选联合关联。
```

用途：

```text
用中心、范围、速度、深度、轮廓评分和置信度维护 tracklet；
支持短时丢失、遮挡和重捕获；
降低单帧检测抖动对跟踪报告的影响。
```

鱼巢落点：

```text
tracklet 是外设内部轨迹材料；
跟踪报告只提交目标可见性、目标窗口、候选关联、丢失 / 重捕获状态和稳定特征样本；
正式跟踪动态仍由提交入口裁决。
```

恢复前提：

```text
L1 稳定观察子集已能提供目标种子；
指定目标跟踪等待项自然出现；
现有跨帧簇ID不足以覆盖遮挡 / 丢失 / 重捕获。
```

### T2 视频对象分割跟踪

候选技术：

```text
SAM 2 视频分割 / memory；
Cutie 类 video object segmentation；
XMem / mask propagation 思路。
```

用途：

```text
在目标种子明确后，跨帧传播目标 mask；
比框级跟踪更适合轮廓、遮挡边界和局部变形目标。
```

鱼巢落点：

```text
VOS 输出是目标 mask 材料；
可用于更新 L1 稳定观察子集、跟踪窗口和目标轮廓候选；
不得直接确认已观察存在状态或需求满足。
```

恢复前提：

```text
平面轮廓 / 中心点跟踪无法稳定覆盖目标；
有明确目标种子；
需要 mask 级目标连续性而不是只要中心轨迹。
```

### T3 检测 + 跟踪轻量方案

候选技术：

```text
YOLO / Grounding DINO 检测候选；
ByteTrack / OC-SORT 类轨迹关联；
规则化轮廓与深度门控。
```

用途：

```text
当需要语义提示、用户指定目标或外部类别候选时，先生成检测候选，再用轨迹过滤抖动。
```

鱼巢落点：

```text
检测类别只作为候选提示，不直接生成语义世界事实；
仍需要自我识别 / 提交入口裁决。
```

恢复前提：

```text
目标由语言、任务或交互者指定；
仅靠几何轮廓不能稳定召回目标；
需要先做候选召回再做鱼巢内部识别。
```

## 6. 分阶段恢复路线

### P0 技术再评估

```text
重新读取当前主动计划结果；
确认 L1 稳定观察子集是否已闭合；
确认扫描还是跟踪先恢复；
确认是否允许引入第三方库，或先用现有 C++ 规则实现最小版本。
```

### P1 扫描最小版

```text
基于 L1 稳定观察子集和已有报告队列，实现可比历史 / 基准帧最小扫描。
不先引入 SLAM / TSDF。
验收目标是：同一稳定存在可形成当前 / 历史可比材料和变化候选。
```

### P2 跟踪最小版

```text
基于 L1 稳定观察子集、跨帧簇ID、中心 / 范围 / 深度 / 轮廓评分，实现 tracklet、丢失宽限和重捕获候选。
不先引入 VOS 大模型。
验收目标是：指定目标能形成连续跟踪报告，短时丢失不误报世界动态。
```

### P3 扫描增强

```text
若 P1 证明现有材料不足，再评估 RTAB-Map / ORB-SLAM3 / TSDF / OctoMap。
先做隔离层和材料 DTO；
再决定是否接入具体库。
```

### P4 跟踪增强

```text
若 P2 证明中心 / 范围 / 轮廓规则不足，再评估 ByteTrack / SAM 2 / Cutie / XMem。
先做目标种子、mask 材料和轨迹材料边界；
再决定是否接入具体库。
```

## 7. 验收口径

```text
构建：
    Debug x64 构建通过。

真实运行：
    只能用真实 D455 或等价真实外设材料验证；
    不用模拟样本、夹具入口、伪造动作动态或旧 --*-check。

扫描证据：
    来源 L1 稳定观察子集；
    可比历史 / 基准帧存在；
    变化候选能追到来源报告、来源稳定子集、左右材料和比较规则；
    不直接写世界真值。

跟踪证据：
    来源目标种子明确；
    tracklet / mask / 预测窗口可回查；
    丢失、重捕获、稳定样本数量有日志证据；
    跟踪动态候选必须经提交入口裁决。
```
