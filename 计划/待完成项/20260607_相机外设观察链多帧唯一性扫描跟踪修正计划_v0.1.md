本计划不推翻当前代码主链：

```text

```

## 3. 必须保留的边界

```text
1. D455 外设线程只生产观察材料、队列项、材料页和状态输入，不直接写需求树或世界树真值。
2. 任务管理工作线程是外设消息第一承接者，只做等待项、队列视图、质量门、回执和缺口。
3. 自我线程承接报告只落候选材料，不确认世界存在真值。
4. 提交入口只接受存在、特征、二次特征、状态动态和来源动作动态引用。
5. 报告 / 包 / 队列项 / 材料页 / 目标观察约束都不是正式事实主体。
6. 扫描 / 跟踪不是新一阶特征裸写入口；需要新值时回观察并经提交入口裁决。
7. 质量门的“优质”只表示可组织提交候选，不能绕过多帧稳定、唯一性和硬冲突检查。
```

## 4. 目标状态

```text
观察：
    单帧只建立材料和基准；
    多帧稳定统计才产生观察完成状态。

6127：
    只输出材料可回查、单轮候选验证、质量用途门和后续入口能力。

识别：
    在当前识别范围内用已有特征把候选集合收敛到唯一；
    输出同一性二次特征、归属映射特征和识别状态动态。

6129：
    分成待复验观察存在入账和已确认观察存在入账；
    已确认入账必须通过多帧稳定、唯一性、硬冲突和归属映射前置。

扫描 / 跟踪：
    只生成二次比较特征、值域冲突、变化候选、跟踪状态和状态动态输入；
    净待识别像素增加、遮挡、拆分、合并或身份冲突时冻结基准并回识别 / 观察。

目标观察约束：
    使用目标观察约束缓冲区；
    generation 拆成约束generation、目标特征generation、来源材料generation。
```

### P2：多帧稳定统计层

目标：

```text
建立同一外设观察存在的帧序列统计：
    连续观察帧数；
    连续稳定帧数；
    关键特征误差；
    丢失 / 漂移 / 拆分 / 合并 / 冲突计数；
    多帧稳定复现状态；
    观察完成状态。
```

边界：

```text
第一帧只建立基准；
多帧稳定才允许观察完成；
稳定复现只限本次任务 / 当前视野 / 当前外设配置 / 当前时间窗口。
```

验收：

```text
真实运行日志能区分：
    材料可复验；
    单轮候选验证；
    多帧稳定复现；
    观察完成。
```

### P3：唯一性识别闸门

目标：

```text
在 6128 / 识别链路中引入当前范围候选集合过滤：
    识别范围状态 == 已确定；
    外设观察存在.可复验状态 == 可复验；
    候选集合数量 == 1；
    硬冲突数量 == 0；
    用于唯一识别特征数量 > 0；
    归属映射状态 == 已建立。
```

处理规则：

```text
候选数量 > 1：
    继续用已有特征缩小候选。

已有特征不足以唯一：
    进入观察补完。

候选唯一但硬冲突数量 > 0：
    进入复验或观察补完。
```

验收：

```text
识别完成日志必须带候选数量、硬冲突数量、用于唯一识别特征数量和识别范围；
识别不写新的存在一阶特征值。
```

### P4：6129 提交分级

目标：

```text
把 6129 提交结果拆成：
    待复验观察存在入账；
    已确认观察存在入账。
```

规则：

```text
待复验观察存在：
    用于保存外设观察存在和特征材料；
    状态为待复验 / 待识别 / 待归属；
    不写已确认观察存在。

已确认观察存在：
    必须通过多帧稳定、唯一性、归属映射和硬冲突检查；
    才能创建或合并已确认观察存在。
```

验收：

```text
优质逐簇报告不能直接等价为已确认观察存在；
6129 日志显示本次走待复验还是已确认分支；
已确认分支写来源动作动态和关系二次特征。
```

### P5：扫描 / 跟踪只比较不写新值

目标：

```text
扫描只写：
    二次比较特征；
    值域冲突；
    变化候选；
    状态动态输入。

跟踪只写：
    跟踪状态；
    预测误差；
    丢失 / 遮挡 / 重捕获；
    区间迁移动态输入。
```

规则：

```text
如果需要把新一阶特征值正式入账：
    回到观察路径取得新特征；
    由提交入口裁决。
```

验收：

```text
6146 / 6147 不裸写存在一阶特征当前值；
扫描变化报告可用但非优质时，只形成待复验材料或首帧基准；
跟踪材料可用但非优质时，不生成稳定跟踪动态候选。
```

### P6：目标观察约束 generation 拆分

目标：

```text
目标观察约束缓冲区记录三类 generation：
    约束generation；
    目标特征generation；
    来源材料generation。
```

验收：

```text
扫描 / 跟踪等待项和 D455 读取逻辑能分别判断：
    约束自身是否新鲜；
    目标特征当前值是否仍是最新；
    ROI / mask / 点集 / AABB 来源材料是否可回查。
```

### P7：质量门返回用途能力

目标：

```text
质量门不只返回 不合格 / 可用 / 优质；
还必须返回：
    可进入验证方法；
    可进入识别方法；
    可生成扫描变化候选；
    可生成跟踪动态候选；
    可进入提交入口组织。
```

验收：

```text
可用材料可进入验证 / 待复验；
可用但非优质材料不能生成正式扫描变化动态或稳定跟踪动态；
优质材料进入提交入口组织仍必须经过提交入口裁决。
```

### P8：待识别像素过滤和基准冻结

目标：

```text
新增或对账：
    粗待识别像素掩码；
    净待识别像素掩码；
    初始基准；
    当前有效基准；
    滚动基准；
    基准冻结状态。
```

规则：

```text
观察优先处理净待识别区域；
扫描中净待识别像素增加时，不能生成变化动态，应回识别 / 观察；
跟踪窗口内净待识别像素增加时，冻结基准并进入复验；
稳定、未丢失、误差低、连续帧足够、无非法跳变时才滚动更新基准。
```

验收：

```text
真实日志能解释：
    为什么某区域被跳过；
    为什么某次扫描只形成待复验；
    为什么某次跟踪冻结基准；
    为什么某次基准可滚动更新。
```
