## 1. 设计条款清单

### 1.1 必须实现

```
1. 发布器作为运行期只读视图生成链，不作为外设线程、四方法或事实裁决者。
2. 第一版只做 场景体素先验快照 到目标观察约束 / 本帧处理策略的非阻塞发布桥。
3. 发布器读取 场景体素先验快照、目标观察约束、外设位姿 / 坐标版本 / 当前时间材料。
4. 发布器输出目标观察约束材料、报告项伴随材料、感兴趣区域 / 掩码 / 空间范围句柄、处理模式 / 优先级和结构化缺口。
5. D455 每帧前只读先验；无先验、过期、坐标不一致或投影材料缺失时必须降级，不得阻塞采集。
6. 发布器缺口必须标准化到 D5 结构化信息缺口链。
7. 判断型状态必须按 1175 由版本、时间、存活时限、坐标系、来源链、消费状态、缺口数量和阈值材料收束；不得用 `generation` 或代际身份字段作为机器判断依据。
```

### 1.2 禁止实现

```
1. 禁止新增 C++ 长期业务结构体作为默认解法。
2. 禁止发布器写世界树事实、稳定存在体素、场景体素缓存、需求满足、动作动态或价值结算。
3. 禁止发布器直接调用观察 / 扫描 / 识别 / 跟踪。
4. 禁止 D455 采集线程等待发布器或场景体素线程。
5. 禁止把先验匹配评分当作 C -> E 最终归属。
6. 禁止把先验可用性、强匹配、降级匹配、遮挡成立、自由空间冲突成立写成普通布尔值 一阶特征。
7. 禁止把缺先验、缺位姿、快照过期或图层缺失直接需求化。
```

### 1.3 后续待补

```
1. 完整先验 感兴趣区域、预计深度范围、遮挡、空闲、未知和自由空间冲突图层句柄。
2. 外设位姿和 D455 到场景坐标变换材料的真实承载入口。
3. 目标观察约束兼容 布尔值 字段的治理迁移。
4. 发布器缺口到任务管理派生需求消息的标准化适配。
5. 与场景体素先验引导观察材料前处理实现映射计划的总收束。
```

## 7. 最小切片计划

```
只读扫描场景体素模块、外设观察报告队列、视觉观察融合模块和 D5 缺口承接入口。

```

允许修改范围：

```
实施记录/ 或计划断点记录。
```

禁止修改范围：

```
源码、规范、详细设计、计划索引。
```

验证：

```
形成 S0 扫描记录，列出真实函数签名、可复用入口、缺函数、缺结构、风险和下一切片准入条件。
```

### S1 发布函数最小入口

目标：

```
新增或登记普通函数，不新增结构体：
发布外设观察先验_由场景体素先验快照
生成目标观察约束_由场景体素先验快照
读取最新外设处理先验_按目标
```

输入：

```
场景体素先验快照
目标外设编号
目标存在编号，可空
目标特征类型编号，可空
当前时间
最大允许先验年龄
```

输出：

```
提交目标观察约束特征组；
或返回已有目标观察约束编号；
或生成结构化缺口。
```

```

```

约束：

```
不得直接派生需求；必须经 D5 结构化信息缺口与需求派生承接链。

目标：

```
现有 `generation` / 代际身份兼容字段不得作为发布器输入、输出、调试摘要或机器判断依据继续保留；若 S0 发现代码路径仍依赖这些字段，先转 D1 兼容清理或字段替换切片。
