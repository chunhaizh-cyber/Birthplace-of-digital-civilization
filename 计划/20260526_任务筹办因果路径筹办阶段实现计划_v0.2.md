## 2. 目标

在任务筹办中新增“因果路径筹办阶段”：

```text
需求目标比较
-> 世界树因果只读查询
-> 临时因果视图
-> 派生需求消息
-> 自我线程裁决入树
-> 任务管理侧接收入树回执
-> 子任务生成后父任务等待
```

第一轮只证明派生需求消息能规范生成、上报、裁决、回执并生成子任务；不把子任务完成、父需求目标回查或完整因果反馈统计塞入同一切片。

## 4. 当前边界

```text
1. 临时因果视图仍是函数局部 DTO，不是权威结构。
2. 任务管理线程仍不得直接写需求树。
3. 派生需求消息不是正式需求；正式入树由自我线程裁决。
4. 方法候选仍按结果能力命中需求目标，不因因果模板存在而绕过候选集。
5. 父需求不能因为派生消息上报成功或入树成功被视为已满足。
6. 当前不宣称子任务完成、父需求目标回查已由最新自然样本验证或完整因果反馈统计已闭合。
```
