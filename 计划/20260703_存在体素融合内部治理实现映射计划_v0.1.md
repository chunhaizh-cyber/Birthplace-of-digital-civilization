## 1. 设计条款清单

### 1.1 必须实现

```
1. 存在体素融合只能承接已确认存在 E 的新增、未消费、可回查观察体素材料。
2. 观察候选到稳定存在同一性候选 同一性候选和局部体素证据链只能作为融合前置输入，不得直接写 E 或 稳定体素主模型。
3. 输入必须先形成待处理材料，再提取输入证据子轮廓，再生成子体素候选，再生成稳定体素主模型更新候选。
4. 稳定体素主模型写入必须经 E 体素特征主模型写入治理入口或对应领域类执行最小材料一致性校验。
5. 体素加工线程或耗时计算链只能输出候选结果包、计数、评分、版本、缺口和可回查句柄。
6. 来源观察候选的报告编号、材料页编号、来源帧编号、时间戳、坐标系版本和消费状态必须参与幂等；已有稳定体素基准摘要可作为候选失效 / 重算材料，但 E 无稳定体素主模型时不得阻塞第一版写入。
7. 无融合点、外边界占据、来源链 / 坐标版本失配、质量不足、归属不可信或自由空间冲突时，只能挂起候选、输出候选阻断原因，或在需要跨方法承接时进入结构化缺口。
8. 稳定体素主模型写入或更新后，P12 第一版到 E 体素主模型写入闭合；场景体素刷新请求后续由 D6 / D7 或场景体素服务增强计划承接。
```

### 1.2 禁止实现

```
1. 禁止外设、视觉中间层、场景体素服务、控制面板或日志直接写稳定存在体素。
2. 禁止单帧局部体素候选直接覆盖稳定体素主模型。
3. 禁止子体素候选入链等同于主模型更新。
4. 禁止体素加工线程直接创建内部世界子存在、生成方法动作动态、写需求满足或安全 / 服务结算。
5. 禁止由外设原始帧、旧当前特征值、融合写回、控制面板刷新或场景体素快照触发体素融合。
6. 禁止用普通布尔值、判断型枚举、日志文本、临时结构化文本或说明字段承载可融合、可提交、归属可信、材料可回查等判断。
7. 禁止新增持久业务结构体绕过存在、特征、特征值、二次特征、状态节点、VecU / VecIU64 句柄和 E 体素特征主模型写入治理入口。
```

### 1.3 后续待补

```
1. E 体素特征主模型写入治理入口的最终函数名和调用点，必须由 S5 实施前扫描后确定。
2. 子体素候选入稳定体素子链的现有承载位置，必须由 S0 扫描后确定。
3. 结构化融合缺口到 D5 缺口治理链的完整映射，可在 D5 实施计划进入代码后补齐。
4. 场景体素刷新事件和值域不作为 P12 第一版实施目标，可在场景体素服务增强计划进入代码后补齐。
```

### S1：体素融合输入组只读视图

目标：读取 E 稳定体素、观察候选到稳定存在同一性候选 候选、局部体素证据、来源报告 / 材料页 / 帧编号、时间戳、消费状态和坐标系版本，形成只读输入摘要。

禁止：写稳定体素主模型、创建子存在、生成动作动态。

验证：缺任一关键输入时只输出缺口或挂起原因。

### S2：待处理材料和幂等闸

目标：把同一 E、同一 C、同一来源材料页、同一基准体素版本归并为同一待处理材料。

禁止：由外设原始帧或场景体素快照直接触发。

验证：重复触发不重复生成子体素候选。

### S3：输入证据子轮廓和子体素候选

目标：复用或补齐子轮廓提取、局部体素候选检查和正立方体包围盒检查。

禁止：彩色轮廓无深度支撑时生成子存在或稳定体素更新。

验证：外边界占据、无融合点、质量不足均进入候选阻断原因。

### S4：主模型融合候选

目标：只生成主模型更新候选，记录基准版本、融合点、冲突计数、越界计数和来源证据。

禁止：候选生成即写入主模型。

验证：既有主模型基准摘要失配时挂起重算；无旧稳定体素主模型时不阻塞第一版候选。

### S5：E 体素特征主模型写入治理入口

目标：新增或接入轻量写入治理入口，将合格主模型融合候选经最小材料一致性校验后写入 E 的稳定三维体素主模型。

禁止：外设、视觉融合层、场景体素服务、控制面板或体素加工线程绕过写入治理入口裸写 E 的稳定三维体素主模型。

验证：目标 E 句柄无效、融合后体素模型为空、包围盒不合法、轮廓支撑不足或明显冲突时，直接丢弃本次候选；校验通过时可回读 E 的稳定三维体素主模型。

### S6：验证和实施记录

目标：运行 `python .\tools\check_specs.py`；代码切片进入时按范围运行 `生成函数功能说明文档.py`、`git diff --check` 和 调试 x64 构建。

禁止：把 S5 代码写入、静态检查或构建通过扩大宣称为存在体素融合内部治理链完整闭合；不得宣称场景体素刷新链已接入。

父计划回写：S6 完成后，更新 `计划/计划索引.md`、`docs/current-state.md` 和实施记录；不得宣称 C -> E 最终裁决、稳定存在更新治理链全闭环或场景体素先验图层已完整实现。
