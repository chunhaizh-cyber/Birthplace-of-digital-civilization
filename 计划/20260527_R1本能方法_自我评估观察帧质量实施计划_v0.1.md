
## 1. 目标

```text
评估当前观察帧的观察质量；
写入 当前观察帧.质量可用状态 等于 可用 / 降级可用 / 不可用。
```

该方法只判断观察帧质量，不补全原始深度，不覆盖原始事实，不计算基础风险值。

## 2. 输入与输出

输入：

```text
当前观察帧
RGB 有效率
原始深度有效率
滤波 / 补全 / 融合深度摘要，若已有
轮廓置信度
未解释区域比例
质量阈值配置
```

输出：

```text
质量可用状态 = 可用 / 降级可用 / 不可用 / 条件不足
质量摘要
质量失败原因
动作动态 / 来源动态证据
```

## 4. 禁止越界

```text
不得让补全深度覆盖原始深度；
不得把质量可用解释为观察事实完备；
不得把质量可用解释为基础风险已明确；
不得直接写安全值 / 服务值结算。
```

## 5. 实施步骤

```text
Q1 先检查是否已有等价方法头和动作入口；没有则只登记本方法。
Q2 读取观察帧质量诊断已有摘要和阈值。
Q3 区分原始深度、滤波深度和补全深度的证据口径。
Q4 根据阈值写质量可用状态，并记录降级或不可用原因。
Q5 控制面板展示质量状态时不得把它显示为风险明确。
```

```text

质量状态有输入指标、阈值和失败原因；
补全 / 融合输出只作为低置信候选，不覆盖原始事实；
最新运行段没有 基础风险判断状态=已明确。
```
