```

## 3. 设计条款清单

### 3.1 必须实现

```
M1. 像素观察归属图不能只是句柄名，必须有材料页契约、版本、来源报告、来源帧、坐标系版本和状态值域版本。

M2. 像素观察归属状态值域 第一版 必须随材料页可回查。

M3. 像素只允许归属观察候选 C，不允许直接归属世界树稳定存在 E。

M4. 候选分裂必须至少能承接深度连续性、彩色边界、场景体素投影、承载面边界、遮挡边界和低质量区域六类依据。

M5. 场景体素先验只能产生评分、处理提示、候选和缺口，不得裁决 C -> E。

M6. 局部体素证据必须挂到 C，不能直接写 E 的稳定体素。

M7. 局部体素进入稳定存在体素前，必须经过 C 已归属 E、材料可回查、质量收束通过、来源链 / 坐标版本 / 消费状态校验和存在体素融合治理入口；不得用 `generation` 作为闭合身份。

M8. 缺口必须结构化输出或登记待 D5 承接，不能静默丢弃。
```

### 3.2 禁止实现

```
F1. 禁止新增结构体解决像素归属图、候选分裂结果或局部体素证据承载。
F2. 禁止新增 `是否归属 / 是否可信 / 是否可用 / 是否可融合` 等普通布尔值 特征。
F3. 禁止像素直接绑定世界树 E。
F4. 禁止局部体素候选直接更新稳定存在体素。
F5. 禁止视觉观察融合模块写场景体素或世界树事实。
F6. 禁止把“背景”写成稳定存在类别或普通布尔值。
F7. 禁止把 场景体素先验快照 匹配评分写成识别结论。
F8. 禁止用日志、控制面板、说明文本或临时结构化文本作为机器判断依据。
```

### S3 候选分裂处理

目标：

```
候选分裂使用深度、颜色、场景体素先验、承载面、遮挡边界和低质量区域。
```

分阶段：

```
S3.1 深度 + 彩色分裂：
    基于当前子轮廓候选生成逻辑，补深度连续性和低质量区域统计。

S3.2 先验引导分裂：
    将 场景体素先验快照 的 轴对齐包围盒 / 先验匹配结果下沉到候选分裂输入。
    先只使用场景体素版本、匹配先验短编号、投影重叠率、深度一致评分和自由空间冲突数量。

S3.3 承载面和遮挡边界分裂：
    先用已有轮廓 / 空间范围 / 遮挡像素数 / 未解释像素数作为材料。
    若没有承载面设计入口，输出缺口，不强做。
```

允许文件：

```
视觉观察融合模块.ixx
