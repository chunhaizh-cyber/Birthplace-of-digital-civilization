关键说明

v0.2 的核心是补清“材料有什么能力、能交给谁、交到哪一步为止”。D455 稳定材料只能先成为可交付观察方法材料，经过任务管理和观察方法后，才分流到识别、扫描、跟踪或补观察 / 复验。

禁止路径：
1. D455 外设侧字段叫“提交状态”并被误解为可入世界树。
2. anchor 不达标时直接否定平面轮廓稳定材料。
3. RGB 显示补边覆盖主分割轮廓。
4. PCL 聚类替换二维主平面轮廓或输出世界事实。
5. 稳定外设观察材料绕过观察方法，直连识别、扫描、跟踪正式逻辑。
6. 静止环境存在候选直接等于已归属静止存在。
材料能力等级：
平面轮廓稳定材料 = 轮廓 / 掩码 / 中心跨帧稳定，深度可以不足。
深度锚定稳定材料 = 平面稳定 + 深度有效率和稳定性达标。
空间可用稳定材料 = 平面稳定 + 深度锚定 + 空间坐标可用 + 坐标系一致。
