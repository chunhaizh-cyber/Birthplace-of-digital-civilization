本能方法：跟踪内部实现逻辑流程图 v0.1

跟踪不是看全场，而是持续专注扫描某一个指定存在，并持续获得该存在的动态信息。

流程图

flowchart TD
    START["跟踪本能方法启动
目标: 持续获得指定存在动态"]
    IN0["读取输入现实特征
指定存在ID / 目标ROI / 跟踪窗口 / 期望动态特征类型"]
    G0{"指定存在是否已稳定归属?"}
    GAP0["输出缺口
指定存在跟踪不可启动状态=1
退回扫描或识别"]

    BASE["读取跟踪基准
目标上一轮特征快照 / 空间位置 / 掩码 / 点集"]
    SUB["创建或刷新跟踪等待项 / 订阅项
观察运行模式=目标跟踪观察"]
    PKG["取得跟踪提交包
目标连续特征 / 丢失状态 / 遮挡 / 重捕获候选"]
    V0{"提交包目标是否匹配指定存在?"}
    MISMATCH["目标不匹配
输出跟踪身份冲突数量>0
退回局部扫描 / 识别"]

    Q0{"跟踪质量是否合格?"}
    LOWQ["输出跟踪质量缺口
补观察 / 调整ROI / 降低结论强度"]
    L0{"目标是否丢失或遮挡?"}
    LOST["输出目标丢失 / 遮挡状态
生成重捕获候选
必要时退回扫描"]

    READ["读取目标当前动态特征值
位置 / 距离 / 姿态 / 速度趋势 / 接近远离"]
    CMP["与上一轮或跟踪基准比较
同一存在 + 同一特征类型"]
    C0{"是否发生变化?"}
    DYN["提交指定存在变化事实
生成指定存在动态信息"]
    SAME["提交本轮稳定事实
持续跟踪状态=稳定"]
    UPD["更新跟踪基准快照
进入下一轮跟踪窗口"]
    CONT{"持续条件仍满足?"}
    LOOP["继续跟踪"]
    END["结束跟踪
输出跟踪完成状态"]

    B0["边界
跟踪只盯一个指定存在"]
    B1["边界
跟踪不能证明全场扫描完成"]
    B2["边界
跟踪丢失不能直接确认新存在"]
    B3["边界
中间帧可入统计
不必全部入树"]

    subgraph INPUT["输入与启动闸门"]
        START --> IN0 --> G0
        G0 -->|否| GAP0 --> END
        G0 -->|是| BASE --> SUB --> PKG
    end

    subgraph VERIFY["目标与质量校验"]
        PKG --> V0
        V0 -->|否| MISMATCH --> END
        V0 -->|是| Q0
        Q0 -->|否| LOWQ --> CONT
        Q0 -->|是| L0
        L0 -->|丢失 / 遮挡| LOST --> CONT
        L0 -->|稳定可见| READ
    end

    subgraph TRACK["持续动态取得"]
        READ --> CMP --> C0
        C0 -->|有变化| DYN --> UPD --> CONT
        C0 -->|无变化| SAME --> UPD --> CONT
        CONT -->|是| LOOP --> PKG
        CONT -->|否| END
    end

    subgraph RULES["硬边界"]
        B0 -.约束.-> IN0
        B1 -.约束.-> END
        B2 -.约束.-> LOST
        B3 -.约束.-> UPD
    end

    classDef input fill:#e8f4ff,stroke:#2f6f9f,color:#102030;
    classDef process fill:#eef7ed,stroke:#3f7f4f,color:#102010;
    classDef output fill:#eef8f7,stroke:#397b77,color:#102827;
    classDef gate fill:#fff8e8,stroke:#9a6a1a,color:#24160a;
    classDef warn fill:#ffecec,stroke:#b84a4a,color:#401111;

    class START,IN0,BASE,SUB,PKG input;
    class READ,CMP,UPD,LOOP process;
    class DYN,SAME,END output;
    class G0,V0,Q0,L0,C0,CONT gate;
    class GAP0,MISMATCH,LOWQ,LOST,B0,B1,B2,B3 warn;
