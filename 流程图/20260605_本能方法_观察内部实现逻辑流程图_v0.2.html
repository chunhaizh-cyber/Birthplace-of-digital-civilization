本能方法：观察内部实现逻辑流程图 v0.2

观察完成 ≠ 第一帧发现一个存在；观察完成 = 一个外设观察存在在多帧中，其关键特征值能够稳定复现。第一帧只建立基准观察存在，后续多帧围绕同一基准计算误差并落入对应特征值域。

关键口径

观察完成不是第一帧发现一个存在；第一帧只写入 外设观察存在.基准状态 == 已建立 和 观察状态 == 待复现。
观察完成必须来自多帧比较：关键特征持续有效，误差持续在对应特征值域内，且丢失、漂移、冲突、拆分、合并均低于阈值。

第一帧基准输出

宿主特征类型特征值 / 内容用途
外设观察存在来源帧第一帧帧号 / 时间戳 / 外设配置标记基准来源。
外设观察存在像素集合掩码目标像素集合 / 掩码区域作为后续掩码重合率比较对象。
外设观察存在彩色轮廓局部图彩色局部图 / 轮廓裁剪图作为颜色和轮廓复现比较对象。
外设观察存在深度轮廓局部图深度局部图 / 深度轮廓裁剪图作为深度轮廓和局部三维范围比较对象。
外设观察存在基准特征值集合颜色 / 深度 / 空间坐标 / AABB / 轮廓 / 掩码后续帧不从零识别，而是与该集合比较。
外设观察存在基准状态已建立只表示基准已建立。
外设观察存在观察状态待复现表示需要后续多帧复现。

边界

观察完成只说明在本次观察任务、当前视野、当前外设配置、当前时间窗口内稳定复现。它不说明世界存在永久成立、语义类别已知、跨场景身份确定或永远不会变化。自我承接后可写入 自我观察存在.复验状态 == 待复验 / 已复验，再经过多次观察、多源验证和动作因果验证，才可能归并为世界存在。
