三线程消息传递清单与流程图 v0.1

按 2026-06-09 当前规范和代码整理：自我线程发意图和许可；任务管理界面线程承接、裁决任务域状态并派发工作项；任务管理工作线程只跑一轮筹办 / 执行 / 外设承接并返回回执和上行材料。

边界摘要

自我线程 负责需求树、需求估权、任务发起意图、调度意图、执行前许可和任务回执后的需求裁决。
任务管理界面线程 负责任务请求承接、任务虚拟存在维护、工作项构造、调度队列、状态提交和上行消息桥接。
任务管理工作线程 负责执行一轮筹办或执行工作包，承接外设等待项，生成工作结果与上行消息。

禁止误读

  • 自我线程不直接写任务状态、当前方法、候选方法集、执行输入参数场景、筹办 / 执行缺口。
  • 任务管理工作线程不裸写任务状态、需求树或世界真值。
  • 外设报告、等待项、材料页和目标观察约束只是通信容器，不是正式世界事实。
  • 任务状态动作动态必须由任务域被动状态提交动作入口生成，来源方法固定为 提交任务状态变化。

执行前许可流程

sequenceDiagram
    participant UI as 任务管理界面线程
    participant SELF as 自我线程
    participant WK as 任务管理工作线程

    UI->>UI: 准备派发执行工作项
    UI->>UI: 检查同任务在途工作项和许可占用
    alt 当前方法命中免审批默认集
        UI->>UI: 记录许可通过
        UI->>WK: 派发结构_任务工作项
    else 需要自我审批
        UI->>SELF: 结构_任务管理执行前许可请求消息
        UI->>UI: 登记执行前许可等待表并重排工作项
        SELF->>SELF: 治理消息归并或抢占审批
        SELF->>UI: 结构_任务执行前许可结果
        alt 允许执行
            UI->>WK: 派发结构_任务工作项
        else 需要等待
            UI->>UI: 重排等待执行前许可工作项
        else 阻断或收束
            UI->>UI: 构造执行前许可阻断工作结果
        end
    end

当前代码落点

  • 自我线程构造任务发起请求：私有_提交任务发起请求到任务管理界面线程_线程侧
  • 任务请求承接：任务管理界面线程::提交任务治理请求
  • 工作线程执行一轮：任务管理工作线程::提交任务工作项
  • 工作线程外设承接：任务管理外设消息承接_处理一次
  • 上行消息统一载体：结构_任务管理上行消息
  • 上行消息入自我线程：上报任务管理上行消息
  • 上行消息转治理消息：从任务管理上行消息构造治理消息
  • 内部任务状态推进：任务管理界面线程::提交任务状态推进请求
