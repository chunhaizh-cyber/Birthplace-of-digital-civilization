# 外设优质观察材料判断标准与依据 v0.1

更新时间：2026-06-06

## 用途

本文件定义 D455 / 双目相机外设侧“优质观察材料”的判断标准和依据，用于：

```text
外设侧：
    从目标观察约束缓冲区读取扫描 / 跟踪种子、目标特征ID和该特征当前值；
    判断当前采集材料是否足够好；
    决定是否缩小 ROI、mask 限域、多帧重采样、静态融合或降级输出。

自我侧：
    按需求从识别 / 扫描 / 跟踪队列视图读取观察材料；
    判断观察材料是否可消费；
    用完删除；
    清理过期或不可回查数据。
```

本标准只判断“观察材料质量”，不判断世界真值、需求满足、安全值或服务值。

## 总原则

```text
1. 优质观察材料 = 新鲜、完整、可回查、稳定、目标相关、可比较、可被自我消费的观察材料。
2. 优质观察材料不是世界真值；它只允许进入自我侧组织、验证、确认和提交入口。
3. 外设侧不得使用过期、generation 失配、材料不可回查或目标已失效的数据继续生成新鲜报告。
4. generation 至少拆成约束generation、目标特征generation、来源材料generation。
5. 任务管理 / 自我侧从队列视图读取观察材料后，应删除已消费项；未消费项必须受 TTL、容量和 generation 清理。
6. 扫描和跟踪的优质观察材料必须有来自目标观察约束缓冲区的目标上下文；全帧材料只能作为识别或外设观察存在材料。
7. 报告 / 包 / 队列项 / 材料页只是通信容器；正式承接对象只能是存在、特征、二次特征和状态动态。
8. 扫描变化候选只要求目标特征优质，不要求整帧优质；但仍必须满足目标约束、基准、值域和 generation 闸门。
9. 跟踪稳定动态候选必须是强约束命中、未丢失、观测值在目标特征值域和预测区间内，且预测误差、非法跳变和硬冲突均达标；可用但非优质材料只能进入跟踪复验或降级状态。
```

## 三级判定

| 等级 | 判定 | 用途 | 处置 |
| --- | --- | --- | --- |
| 不合格观察材料 | 采集失败、材料过期、句柄不可回查、目标种子缺失、基础结构不完整、任务所需质量指标低于硬底线 | 不得作为新鲜观察证据 | 删除、拒绝等待项、生成缺口、触发补观察 |
| 可用观察材料 | 新鲜、可回查、基础结构完整，达到对应范围硬底线，但存在低置信、局部缺口或稳定性不足 | 可作为外设观察存在、草案、待验证材料 | 进入对应队列视图，但自我侧不得直接确认；必要时派生补观察 |
| 优质观察材料 | 满足对应范围硬底线，并且目标相关、稳定复现、低缺口、低未解释、可比较、可追溯 | 可优先供自我侧验证、扫描、跟踪和提交入口组织结果场景 | 入识别 / 扫描 / 跟踪队列视图；自我消费后删除 |
| 目标特征优质材料 | 整帧可不优质，但目标区域内目标特征深度有效率、空间坐标有效率、掩码重合率、值域和基准均可比较 | 可生成扫描变化候选 | 只能进入 6146 值域内变化候选；仍需提交入口裁决 |

## 优质范围

```text
优质观察材料可以是：
    全局优质；
    目标区域优质；
    指定特征优质。

全帧深度或空间质量不足，不必然否定目标 ROI / mask 内材料可用；
对扫描 / 跟踪 / 指定目标复验，应优先检查目标区域质量；
对颜色、轮廓、二维回查类需求，深度 / 空间不足可以降级，不应直接判整份材料不合格。
```

## 通用硬底线

| 维度 | 标准 | 不合格条件 | 依据 |
| --- | --- | --- | --- |
| 新鲜度 | 报告时间不得超过等待项 `最大允许报告年龄毫秒`；材料页不得超过保留时间 | 当前时间 - 报告时间 > 最大允许年龄；材料页过期 | `外设观察_报告满足等待项`；`D455材料页保留毫秒=60000` |
| 容量有效 | 队列不得无限保留旧数据 | 报告队列超过容量时旧项被裁剪；材料页超过容量时旧页被清理 | `队列容量=64`；`D455材料页容量=6` |
| 可回查 | `d455://` 句柄必须可解析并命中材料页 | 空句柄、格式错误、未找到、已过期、材料未就绪、类型不匹配 | `解析D455观察材料句柄` |
| 结构完整 | 帧尺寸、预期像素数、颜色 / 深度 / 空间材料结构与像素数一致 | 宽高无效、预期像素数不匹配、颜色/深度/空间结构缺失 | `D455_帧像素数量有效` 等材料有效性函数 |
| 基础质量 | 需要全帧深度 / 空间材料时，全帧深度有效率和空间坐标有效率不能低于硬底线；扫描 / 跟踪优先检查目标 ROI / mask 内质量 | 对全帧任务：`深度有效率 < 5000` 或 `空间坐标有效率 < 5000`；对目标任务：目标区域有效点不足或空间点集不可回查 | `双目相机本能适配器.cpp` 补观察缺失原因；050002 局部质量口径 |
| 目标上下文 | 扫描 / 跟踪必须有目标种子或目标区域 | `目标区域或目标簇` 为空 | `D455_扫描变化等待项前置满足`；`D455_目标跟踪等待项前置满足` |
| 边界合法 | 不得把外设报告直接当世界事实或需求满足 | 未经自我组织和提交入口直接写真值 | 050004 / 050005 边界 |

## 优质观察材料推荐门槛

说明：

```text
硬底线来自当前代码；
优质门槛用于外设侧优化采集和自我侧优先消费。
若代码尚未实现对应等级字段，可先作为判断契约和日志口径。
```

| 维度 | 可用门槛 | 优质门槛 | 依据 |
| --- | --- | --- | --- |
| 帧质量评分 | `帧质量评分 > 0`，且未触发硬失败 | `帧质量评分 >= 7000` | 代码按深度有效率 35%、空间坐标有效率 35%、候选验证通过率 20%、低未解释比例 10% 计算 |
| 全局深度有效率 | `>= 5000` | `>= 7000`，且深度空洞不支配全局任务所需范围 | 只用于需要全帧深度 / 空间材料的任务 |
| 全局空间坐标有效率 | `>= 5000` | `>= 7000`，且全局点集可回查 | 只用于需要全帧深度 / 空间材料的任务 |
| 目标区域深度有效率 | 目标 ROI / mask 内有效点数达标 | 目标 ROI / mask 主体深度有效，空洞不支配目标特征 | 扫描 / 跟踪 / 指定目标复验优先使用该指标 |
| 目标区域空间坐标有效率 | 目标点集可回查，且覆盖目标 ROI / mask 主体 | 目标点集连续、稳定、可比较 | 扫描 / 跟踪 / 指定目标复验优先使用该指标 |
| 轮廓闭合度 | `>= 7000` 才不视为明显断裂 | `>= 8000`，且无跨越深度断裂 / 无穿过无效深度区域 | 轮廓闭合度 `< 7000` 触发轮廓断裂 |
| 轮廓置信度 | `>= 7000` 才不视为低置信 | `>= 8000`，且不依赖补全深度 | 低置信轮廓状态以 `< 7000` 或依赖补全深度触发 |
| 空间连续性 / 范围稳定性 | `>= 5000` | `>= 7000` | 低于 5000 触发边界不稳定 |
| 有效点 | 候选有效点数 `>= 16`，有效点比例 `>= 3000` | 有效点充足且覆盖目标 ROI / mask 主体 | 低于该值触发有效点不足 |
| 未解释区域 | 允许少量局部未解释 | 目标 ROI 内未解释区域比例低，且不影响目标轮廓归属 | 未解释像素计入缺口和帧质量评分 |
| 补观察缺口 | 可存在，但只能作为待验证材料 | `补观察缺口状态=0`；待补观察区域数量为 0 | 补观察缺失原因、待补观察区域、低置信轮廓等聚合 |
| 多帧稳定性 | 至少有可读多帧材料 | 多帧低稳定像素为 0 或不落在目标 ROI；融合深度稳定性高 | 融合低稳定像素触发补观察建议 |

## 识别数据标准

识别观察材料用于：

```text
当前观察范围内的外设观察存在、未知区域、冲突区域、像素簇归属验证。
```

| 项 | 优质标准 | 降级 / 补观察条件 | 依据 |
| --- | --- | --- | --- |
| 识别观察材料队列项 | 队列项新鲜、采集成功、帧结构完整、至少一个空间候选或明确无候选材料 | 采集失败、帧结构缺失、材料不可回查 | `D455_从调用结果生成逐簇识别报告` |
| 外设观察存在材料 | 每个外设观察存在至少具备 ROI / 掩码 / 点集 / 空间候选 / 像素归属材料之一，且句柄可回查 | 句柄空、过期、未找到、材料未就绪 | `结构_外设观察像素簇摘要`；`解析D455观察材料句柄` |
| 像素归属 | 像素归属验证状态成立，外设观察存在验证通过率高 | 空间匹配点数为 0，外设观察存在条件不足 | `像素归属验证状态`；`外设观察存在验证通过率` |
| 轮廓质量 | 轮廓闭合、置信高、深度/颜色/空间至少两类支持 | 轮廓断裂、低置信、依赖补全深度 | 轮廓闭合度、轮廓置信度、轮廓来源类型 |
| 未知 / 冲突 | 未知区和冲突区被明确标注，不伪装成已确认存在 | 未解释区域多但未生成缺口 | 050004 / 050005 |

识别观察材料即使优质，也只允许进入自我侧验证和确认流程；不得由外设直接创建世界存在。

## 扫描数据标准

扫描观察材料用于：

```text
已识别区域或已确认存在的变化检查。
首次扫描只建立扫描基准或形成观察 / 识别线索；
有可比历史后才允许形成变化候选材料。
```

| 项 | 优质标准 | 降级 / 补观察条件 | 依据 |
| --- | --- | --- | --- |
| 扫描种子 | 目标观察约束缓冲区中有目标存在、ROI / mask / 点集、基准报告或下一轮扫描基准 | 目标区域或目标簇为空；基准不可回查；目标已过期 | 等待项目标字段；v0.2 缓冲区流程 |
| 可比较基准 | 当前材料与基准在同一目标上下文，且约束generation、目标特征generation、来源材料generation 未失配或存在可解释关系 | 缺上一逐簇识别基准时只建立首帧基准 | `D455_从逐簇识别报告生成扫描变化报告` |
| 变化判定 | 跨帧簇 ID 稳定且连续命中 >= 2 时优先判稳定；否则检查中心、像素数、轮廓置信度差异 | 中心 X/Y 差异 > 30，Z > 50，像素数超容差，轮廓置信度差异 > 1500 | `D455_观察像素簇存在明显变化` |
| 目标约束 | 扫描只比较目标 ROI、mask、边界带或已识别区域 | 全帧变化直接替代目标变化 | 050004：扫描处理可扫描的已识别区域 |
| 输出口径 | 输出无变化、值域内变化候选、冲突、待复验、需重识别、未解释残差 | 无基准却提交发现事实或变化动态；未变化仍提交变化事实；冲突 / 待复验被当作变化事实 | 20260607 扫描修正口径 |

扫描优质观察材料的核心不是“全帧都清楚”，而是“目标区域可比较、基准可追溯、变化判断有材料依据”。
扫描优质观察材料可以是全局优质、目标区域优质或目标特征优质；生成扫描变化候选只要求目标特征优质，不要求整帧优质。

扫描变化候选用途门必须额外满足：

```text
目标存在.归属状态 == 已归属
目标存在.背景状态 != 背景
目标特征当前值可读
目标特征值域可读
上一轮扫描基准可读
目标观察约束状态 == 可用
约束generation匹配
目标特征generation匹配
来源材料generation匹配
扫描范围.高价值待识别区域数量 == 0
```

## 跟踪数据标准

跟踪观察材料用于：

```text
指定已确认存在的连续观察。
跟踪只盯一个目标，不替代全场景识别或扫描。
跟踪材料不是目标存在正式一阶特征值。
```

| 项 | 优质标准 | 降级 / 补观察条件 | 依据 |
| --- | --- | --- | --- |
| 强目标观察约束 | 目标存在ID、目标特征类型ID、目标特征当前值、目标特征值域、ROI / 掩码 / AABB / 点集之一、TTL 和三类 generation 均可用 | 无强约束但有旧目标种子时，只能降级重捕获 / 待复验，不能提交稳定跟踪事实 | 目标观察约束缓冲区；20260607 跟踪修正口径 |
| 跟踪种子 | 自我缓冲区或等待项提供目标存在 / 目标簇 ID / 预测窗口 / 上一轮中心 | 目标种子不可解析或为空；约束过期；generation 失配 | `D455_从逐簇识别报告生成跟踪报告` |
| 目标命中 | 当前逐簇识别材料能命中目标簇或来源空间候选，且命中与目标约束匹配 | 未命中时只生成丢失 / 遮挡 / 重捕获候选材料，不写目标特征外设观测值 | 跟踪报告生成逻辑 |
| 连续稳定 | 有上一帧，连续成功次数 >= 2 | 连续样本不足则证据不足 | `D455_记录跟踪成功到缓存` |
| 复现离散度 | 坐标离散度 <= 150 | 大于 150 则复现离散或质量未达标 | 跟踪状态值计算 |
| 目标质量 | 命中簇深度有效率 >= 5000，空间坐标有效率 >= 5000 | 低于硬底线则跟踪状态不稳定 | 跟踪状态值计算 |
| 目标窗口待识别像素 | 目标窗口净待识别像素比例低于阈值 | 待识别像素增加时，输出遮挡候选 / 身份复验线索，冻结基准 | 20260607 跟踪修正口径 |
| 当前值域区间ID | 目标当前值能归入明确细分区间 | 当前值无法归区间或区间来源不可回查 | 目标特征当前值 / 特征值域 |
| 预测区间 | 有预测窗口或预测区间，且与上一轮状态连续 | 缺预测区间或预测窗口过期 | 跟踪预测区间状态 |
| 预测误差值 | 预测误差在目标特征允许范围内 | 预测误差持续扩大或超过允许范围 | 跟踪预测误差 |
| 非法区间跳变次数 | 非法区间跳变次数为 0 或在复验阈值内 | 出现不可解释区间跳变 | 跟踪区间迁移状态 |
| 合法区间迁移状态 | 动态变化连续、可预测，区间迁移有来源材料 | 区间迁移无来源材料或跳变不可解释 | 目标存在区间迁移动态 |
| 硬冲突数量 | 身份、值域、掩码、轮廓和空间冲突数量为 0 | 硬冲突数量 > 0 时不提交稳定跟踪事实，进入识别复验或观察 | 识别唯一性 / 跟踪修正口径 |
| 非目标处理 | 主动忽略非目标存在，只输出目标连续观察材料 | 用跟踪报告替代全场景扫描 | 050004 / 用户口径 |

跟踪优质观察材料的核心是“目标连续可复现，并且动态变化合法、连续、可预测”，不是“场景整体明确”。

跟踪用途门：

```text
不合格：
    若不影响活跃父需求，只回执 / 清理；
    若命中活跃父需求关键缺口，上报缺口事实或派生需求消息。

可用但非优质：
    可进入 6147 跟踪复验；
    只能输出待复验 / 证据不足 / 降级跟踪状态；
    不得提交稳定跟踪事实。

优质 + 强约束命中：
    可进入 6147；
    可生成跟踪动态候选；
    仍需提交入口裁决。
```

稳定跟踪动态候选必须额外满足：

```text
目标存在.归属状态 == 已归属
目标存在.背景状态 != 背景
目标特征generation匹配
约束generation匹配
来源材料generation匹配
跟踪目标命中状态 == 命中
目标存在.丢失状态 == 未丢失
当前观测值落入目标特征值域
当前观测值落入预测区间
预测误差值 < 最大允许预测误差
非法区间跳变次数 == 0
硬冲突数量 == 0
来源动作动态可追溯
```

## 自我消费与删除标准

| 队列 | 自我读取条件 | 用完删除条件 | 过期清理条件 |
| --- | --- | --- | --- |
| 识别观察材料队列视图 | 需求目标是外设观察存在验证、观察存在确认、未知区域识别 | 自我已读取并生成结果场景或缺口 | 超过最大允许年龄、句柄不可回查、队列超容量 |
| 扫描特征变化材料队列视图 | 需求目标是已识别区域扫描、目标特征变化、发现事实承接 | 自我已读取并提交发现 / 变化 / 无变化结果或派生复验缺口 | 目标约束过期、基准失效、generation 失配、队列超容量 |
| 跟踪观测材料队列视图 | 需求目标是指定存在跟踪、丢失 / 遮挡 / 重捕获 / 区间迁移 | 自我已读取并提交对应类型跟踪事实、状态动态或派生前置缺口；不得直接写目标新一阶特征值 | 目标种子过期、主动目标切换、连续失败超策略、队列超容量、generation 失配 |
| 可回查观察材料页 | 自我按 d455:// 句柄回查材料 | 被队列项消费完成后仍可保留到 TTL | 过期时间到达、材料页队列超容量 |
| 目标观察约束缓冲区 | 外设侧扫描或跟踪读取目标约束 | 目标任务完成、目标被替代、需求撤销 | TTL 到期、约束generation / 目标特征generation / 来源材料generation 失配、来源报告不可回查 |

## 补观察触发依据

| 触发原因 | 典型字段 | 建议补观察动作 |
| --- | --- | --- |
| 深度空洞 / 未解释区域 | `深度空洞数量`、`未解释区域比例`、`未解释像素数` | 重新取得观察特征帧；继续观察未解释区域 |
| 有效点不足 | 全帧任务：`深度有效率 < 5000`、`空间坐标有效率 < 5000`；目标任务：目标 ROI / mask 内有效点不足、候选有效点数 `< 16` | 缩小 ROI 重新观察 |
| 轮廓断裂 / 低置信 | `轮廓闭合度 < 7000`、`轮廓置信度 < 7000`、低置信轮廓状态 | 内部世界细分；目标边界重采样 |
| 对齐缺失 | 彩色深度对齐状态不成立 | 调整双目相机工作模式 |
| 补全依赖高 / 融合低稳定 | 轮廓依赖补全深度、融合低稳定像素数量 | 融合稳定观察帧深度；多帧重采样 |
| 目标种子缺失 | `目标区域或目标簇` 空、跟踪种子不可解析 | 回到自我侧补目标存在 / 目标窗口 / 基准特征 |
| 基准不可回查 | 来源报告过期、材料页未找到、generation 失配 | 重新建立扫描基准或目标跟踪基准 |

## 最小判断函数口径

可落成代码时，建议按以下顺序判断：

```text
判断优质观察材料(队列项, 需求类型, 目标上下文):
    1. 检查采集成功、报告类型、外设ID、时间戳；
    2. 检查报告年龄 <= 等待项最大允许报告年龄；
    3. 检查 d455:// 材料句柄可回查，且未过期；
    4. 若需求类型是扫描 / 跟踪，检查目标观察约束缓冲区中目标上下文新鲜；
    5. 检查适用范围质量硬底线：
           全帧任务检查全局深度 / 空间质量；
           目标任务检查目标 ROI / mask 内深度 / 空间质量；
           颜色、轮廓、二维回查任务允许深度 / 空间不足时降级；
    6. 检查优质推荐门槛：
           帧质量评分 >= 7000；
           轮廓闭合度 >= 8000；
           轮廓置信度 >= 8000；
           空间连续性 / 范围稳定性 >= 7000；
           补观察缺口状态 = 0；
    7. 按识别 / 扫描 / 跟踪分别检查模式专属条件；
       跟踪还要检查强目标观察约束、三类 generation、目标窗口待识别像素比例、当前值域区间ID、预测区间、预测误差值、非法区间跳变次数、合法区间迁移状态和硬冲突数量；
    8. 返回：
           不合格 / 可用 / 优质；
           质量依据字段；
           需补观察原因；
           建议外设动作。
```

## 定案

```text
优质观察材料不是“看到了东西”，而是：

新鲜：
    报告、材料页、目标上下文未过期；

完整：
    帧结构、ROI、mask、点集、空间候选、基准材料可回查；

稳定：
    深度、空间、轮廓、多帧复现达到硬底线，优先达到推荐门槛；

相关：
    扫描 / 跟踪数据必须绑定自我提供的目标存在和目标约束；

可消费：
    能进入识别 / 扫描 / 跟踪队列视图，被任务管理按等待项读取、删除和追溯，并由自我侧裁决。

只有满足这些条件的观察材料，才是外设侧应优先生产和自我侧应优先消费的优质观察材料。
```
