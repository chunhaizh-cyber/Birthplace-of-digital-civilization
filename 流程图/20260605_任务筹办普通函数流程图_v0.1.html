任务筹办普通函数流程图 v0.1

只展开任务筹办普通函数内部的找下一步可选步骤、找方法、找条件；外部逻辑以模块表示，不展开内部细节。

flowchart TD
    TASK["任务信息节点
任务状态 / 来源需求 / 任务虚拟存在"]
    DEMAND["来源需求
目标宿主 / 目标特征 / 当前状态 / 目标状态"]
    CONTEXT["任务上下文
场景 / 子任务 / 子需求 / 当前方法 / 回执缓存"]

    M_TARGET_VIEW["外部模块: 需求目标语义视图读取
不展开"]
    M_CAUSAL_VIEW["外部模块: 临时因果视图生成
世界树因果 / 遗传因果 / 已入树子需求"]
    M_DEMAND_SUBMIT["外部模块: 需求提交入口
派生需求 / 更新指令 / 缺口入树裁决"]
    M_METHOD_TREE["外部模块: 方法树与结果能力索引
候选召回 / 结果能力命中"]
    M_METHOD_HEAD["外部模块: 待学习方法头创建或复用
新建后等待重筹办"]
    M_COND_RESULT["外部模块: 条件结果对服务
读取 / 建立 / 验证"]
    M_PARAM_BIND["外部模块: 参数绑定器
任务上下文 -> 方法输入参数"]
    M_INPUT_SCENE["外部模块: 可执行输入参数场景构造
输入条件包 / 目标方法 / 目标宿主"]
    M_STATE_SUBMIT["外部模块: 同步筹办回执 / 提交任务状态变化
任务管理界面线程负责调用"]
    M_PRESSURE["外部模块: 全循环压力账
失败退出 / 阻断 / 反复等待"]

    ENTER["进入任务筹办普通函数
单步循环，不递归执行子链"]
    READ["读取任务 / 来源需求 / 任务层级
只读上下文，不裸写状态"]
    TARGET_GATE{"来源需求目标
是否完整可解析?"}
    TARGET_SOURCE_GATE{"不可解析来源
逻辑错误还是真实需求?"}
    LOGIC_ERROR["逻辑错误处理
弹窗提醒 + 记录日志
不生成分支 / 不派生需求"]
    STATE_GATE{"任务是否可筹办?
未终结 / 未取消 / 未失败"}
    CHILD_GATE{"是否存在活动子需求
或阻塞父任务的子任务?"}
    LEAF_GATE{"是否已是普通可任务化叶子任务?"}

    PATH_START["找下一步可选步骤
读取目标语义和因果视图"]
    PATH_VIEW["生成下一步候选步骤视图
促成 / 避免 / 条件补齐 / 方法就绪 / 证据补齐 / 副作用约束 / 学习缺口"]
    PATH_CLASSIFY["归类下一步候选项
可直接尝试方法 / 待补前置 / 禁用副作用 / 学习缺口 / 空视图"]
    PATH_TRANSLATE["翻译候选项为本轮可提交目标
缺口报告 / 派生需求消息 / 更新指令输入草案"]
    PATH_DRAFT_GATE{"翻译后是否存在
阻塞缺口草案?"}
    PATH_SOURCE_GATE{"缺口草案来源
逻辑错误还是真实需求?"}
    PATH_GATE{"本轮是否已得到
下一步普通可任务化目标?"}
    PATH_DRAFT["形成下一步缺口报告或派生需求草案
不得在筹办函数内直接生成需求节点"]
    PATH_WAIT["筹办回执: 等待下一步条件闭合
派生需求消息 / 更新指令输入草案"]

    METHOD_START["找方法
按目标特征查方法结果能力"]
    CANDIDATE_FILL["填充候选方法集
先填充，再选择"]
    CANDIDATE_GATE{"候选方法集
是否为空?"}
    METHOD_HEAD_RECEIPT["筹办回执: 已建立方法头待重入
本轮不直接执行新生方法头"]
    SELECT_GATE{"候选数量"}
    BIND_ONE["单候选直接绑定当前方法"]
    SELECT_RULE["多候选按确定规则选择
排序 / 权重 / 稳定度 / 禁止项"]
    CURRENT_METHOD["当前方法确定
只代表候选选择完成"]

    CONDITION_START["找条件
检查当前方法自身状态 / 入口 / 条件 / 参数"]
    METHOD_READY_GATE{"当前方法状态
是否可用?"}
    ENTRY_GATE{"是否有可执行动作入口?"}
    CR_GATE{"是否存在有效条件结果对?"}
    PARAM_GATE{"参数是否可绑定?"}
    COND_GATE{"方法条件是否满足
且禁止项未命中?"}
    INPUT_SCENE_GATE{"可执行输入参数场景
是否可构造?"}
    READY_RECEIPT["筹办回执: 可就绪
当前方法 + 可执行输入参数场景 + 无筹办缺口"]

    TARGET_GAP["真实需求分支: 目标补齐缺口
缺目标宿主 / 特征 / 当前值 / 目标值"]
    STATE_WAIT["筹办回执: 任务不可筹办
已终结 / 取消 / 失败 / 等待外部恢复"]
    CHILD_WAIT["筹办回执: 等待活动子需求或子任务
父任务待重筹办"]
    METHOD_STATE_GAP["筹办回执: 候选方法不可用
方法状态缺口"]
    ENTRY_GAP["筹办回执: 缺执行入口
方法可调用动作缺口"]
    CR_GAP["筹办回执: 缺条件结果对
经验配对缺口"]
    PARAM_GAP["筹办回执: 参数配对失败
缺参数 / 参数未绑定 / 场景不闭合"]
    CONDITION_GAP["筹办回执: 条件不满足
需求侧条件 / 因果条件 / 方法条件"]
    INPUT_SCENE_GAP["筹办回执: 输入场景不可构造
可执行输入参数场景缺口"]

    RECEIPT_OUT["输出任务推进回执
建议状态 / 建议阶段 / 缺口类型 / 派生提示 / 诊断摘要"]
    NO_DIRECT_WRITE["边界: 筹办只产出回执
不直接写需求树 / 不直接写任务状态 / 不执行方法"]

    subgraph INPUTS["筹办输入"]
        TASK --> ENTER
        DEMAND --> ENTER
        CONTEXT --> ENTER
    end

    subgraph ENTRY_CHECK["入口检查"]
        ENTER --> READ --> M_TARGET_VIEW --> TARGET_GATE
        TARGET_GATE -->|否| TARGET_SOURCE_GATE
        TARGET_SOURCE_GATE -->|逻辑错误 / 结构损坏| LOGIC_ERROR
        TARGET_SOURCE_GATE -->|真实需求缺口| TARGET_GAP
        TARGET_GATE -->|是| STATE_GATE
        STATE_GATE -->|否| STATE_WAIT
        STATE_GATE -->|是| CHILD_GATE
        CHILD_GATE -->|是| CHILD_WAIT
        CHILD_GATE -->|否| LEAF_GATE
    end

    subgraph FIND_PATH["第一段: 找下一步可选步骤"]
        LEAF_GATE -->|否, 仍需下一步筹办| PATH_START
        PATH_START --> M_CAUSAL_VIEW --> PATH_VIEW --> PATH_CLASSIFY --> PATH_TRANSLATE --> PATH_DRAFT_GATE
        PATH_DRAFT_GATE -->|有阻塞草案| PATH_SOURCE_GATE
        PATH_SOURCE_GATE -->|逻辑错误 / 不可目标化| LOGIC_ERROR
        PATH_SOURCE_GATE -->|真实需求缺口| PATH_DRAFT --> M_DEMAND_SUBMIT --> PATH_WAIT
        PATH_DRAFT_GATE -->|无阻塞草案| PATH_GATE
        PATH_GATE -->|未得到下一步| PATH_WAIT
        PATH_GATE -->|已得到下一步| METHOD_START
        LEAF_GATE -->|是| METHOD_START
    end

    subgraph FIND_METHOD["第二段: 找方法"]
        METHOD_START --> M_METHOD_TREE --> CANDIDATE_FILL --> CANDIDATE_GATE
        CANDIDATE_GATE -->|空| M_METHOD_HEAD --> METHOD_HEAD_RECEIPT
        CANDIDATE_GATE -->|非空| SELECT_GATE
        SELECT_GATE -->|1 个| BIND_ONE --> CURRENT_METHOD
        SELECT_GATE -->|多个| SELECT_RULE --> CURRENT_METHOD
    end

    subgraph FIND_CONDITION["第三段: 找条件"]
        CURRENT_METHOD --> CONDITION_START --> METHOD_READY_GATE
        METHOD_READY_GATE -->|否| METHOD_STATE_GAP
        METHOD_READY_GATE -->|是| ENTRY_GATE
        ENTRY_GATE -->|否| ENTRY_GAP
        ENTRY_GATE -->|是| M_COND_RESULT --> CR_GATE
        CR_GATE -->|否| CR_GAP
        CR_GATE -->|是| M_PARAM_BIND --> PARAM_GATE
        PARAM_GATE -->|否| PARAM_GAP
        PARAM_GATE -->|是| COND_GATE
        COND_GATE -->|否| CONDITION_GAP
        COND_GATE -->|是| M_INPUT_SCENE --> INPUT_SCENE_GATE
        INPUT_SCENE_GATE -->|否| INPUT_SCENE_GAP
        INPUT_SCENE_GATE -->|是| READY_RECEIPT
    end

    subgraph OUTPUTS["回执输出"]
        TARGET_GAP --> RECEIPT_OUT
        STATE_WAIT --> RECEIPT_OUT
        CHILD_WAIT --> RECEIPT_OUT
        PATH_WAIT --> RECEIPT_OUT
        METHOD_HEAD_RECEIPT --> RECEIPT_OUT
        METHOD_STATE_GAP --> RECEIPT_OUT
        ENTRY_GAP --> RECEIPT_OUT
        CR_GAP --> RECEIPT_OUT
        PARAM_GAP --> RECEIPT_OUT
        CONDITION_GAP --> RECEIPT_OUT
        INPUT_SCENE_GAP --> RECEIPT_OUT
        READY_RECEIPT --> RECEIPT_OUT
        RECEIPT_OUT --> M_STATE_SUBMIT
    end

    subgraph PRESSURE_FLOW["压力材料"]
        TARGET_GAP -.真实缺口反复出现.-> M_PRESSURE
        STATE_WAIT -.等待失效.-> M_PRESSURE
        PATH_WAIT -.下一步长期无进展.-> M_PRESSURE
        METHOD_STATE_GAP -.方法长期不可用.-> M_PRESSURE
        ENTRY_GAP -.缺入口.-> M_PRESSURE
        CR_GAP -.缺经验配对.-> M_PRESSURE
        PARAM_GAP -.参数长期不可配.-> M_PRESSURE
        CONDITION_GAP -.条件长期不满足.-> M_PRESSURE
    end

    subgraph RULES["硬规则"]
        NO_DIRECT_WRITE -.约束.-> PATH_DRAFT
        NO_DIRECT_WRITE -.约束.-> RECEIPT_OUT
        NO_DIRECT_WRITE -.约束.-> M_STATE_SUBMIT
        NO_DIRECT_WRITE -.逻辑错误不生成业务分支.-> LOGIC_ERROR
    end

    classDef pressure fill:#fff0f3,stroke:#b4234a,color:#3a0d18;

    class ENTER,READ,PATH_START,PATH_VIEW,PATH_CLASSIFY,PATH_TRANSLATE,PATH_DRAFT,METHOD_START,CANDIDATE_FILL,BIND_ONE,SELECT_RULE,CURRENT_METHOD,CONDITION_START,READY_RECEIPT,RECEIPT_OUT prep;
    class TARGET_GATE,TARGET_SOURCE_GATE,STATE_GATE,CHILD_GATE,LEAF_GATE,PATH_DRAFT_GATE,PATH_SOURCE_GATE,PATH_GATE,CANDIDATE_GATE,SELECT_GATE,METHOD_READY_GATE,ENTRY_GATE,CR_GATE,PARAM_GATE,COND_GATE,INPUT_SCENE_GATE gate;
    class M_TARGET_VIEW,M_CAUSAL_VIEW,M_DEMAND_SUBMIT,M_METHOD_TREE,M_METHOD_HEAD,M_COND_RESULT,M_PARAM_BIND,M_INPUT_SCENE,M_STATE_SUBMIT external;
    class TARGET_GAP,STATE_WAIT,CHILD_WAIT,PATH_WAIT,METHOD_HEAD_RECEIPT,METHOD_STATE_GAP,ENTRY_GAP,CR_GAP,PARAM_GAP,CONDITION_GAP,INPUT_SCENE_GAP receipt;
    class NO_DIRECT_WRITE,LOGIC_ERROR warn;
    class M_PRESSURE pressure;
