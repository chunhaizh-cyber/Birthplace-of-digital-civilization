口径

内部治理主链全部按被动因果表达。任务筹办、任务执行只是普通函数事实，其回执是被动因；同步回执、提交任务状态变化、需求收束、父任务重筹办和叶子任务价值结算是被动果。

D0 世界事实动作动态是上游证据，进入治理树后只作为被动因输入，不把内部治理链改写成主动因果。

被动因果规则

被动因被动果动作动态口径
活动需求正式入树创建任务信息节点和任务虚拟存在任务创建动态属于任务域提交链
筹办回执已形成候选方法、当前方法、输入场景、筹办缺口入任务账被动整理，不生成主链动作动态
筹办回执给出建议任务状态提交任务状态变化D1 任务状态动作动态
方法状态未达可用方法结构补齐需求或父任务重筹办事实被动缺口治理，不是普通任务选择方法
执行回执给出完成 / 等待 / 重筹办建议提交任务状态变化D1 任务状态动作动态
任务状态完成且输出证据满足来源需求来源需求收束当前口径不生成独立需求状态方法动作动态
叶子任务完成且结算资格成立结算叶子任务价值D2 结算叶子任务价值动作动态
子任务状态动作动态、子需求满足、方法状态可用变化父任务等待中转待重筹办必须串到权威任务状态动作动态

任务虚拟存在材料

任务虚拟存在
├── 需求镜像材料：发起存在 / 作用对象 / 上下文 / 当前状态 / 目标状态 / 满足关系 / 权重
├── 筹办回执材料：候选方法虚拟存在集 / 当前方法虚拟存在 / 输入场景 / 筹办缺口
├── 执行回执材料：目标是否达成 / 推进量 / 剩余差距 / 方法运行存在 / 输出结果场景
└── 状态动作动态材料：D1 / 父任务重筹办证据 / 结算资格证据

方法虚拟存在材料

方法虚拟存在
├── 方法身份材料：方法来源 / 动作名 / 动作句柄类型 / 成熟度阶段
├── 方法结构材料：父方法 / 前置方法 / 后续方法 / 条件场景 / 结果场景 / 结果数量
├── 方法状态材料：待方法动作 -> 待可执行入口 -> 待条件节点 -> 待结果节点 -> 待条件结果对 -> 可用
└── 方法状态动作动态材料：方法状态旧值 -> 新值 / 最近动作动态
