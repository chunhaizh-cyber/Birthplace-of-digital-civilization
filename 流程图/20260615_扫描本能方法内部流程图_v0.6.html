扫描本能方法内部流程图 v0.6

流程开始后先做上游契约错误检测；命中时按预编译开关控制错误日志和弹窗，不进入普通需求来源。合法外设数据集仍全量处理。

1. 上游错误检测与本轮初始化

flowchart TD
    A["扫描任务
已选择扫描方法"] --> B["前置契约：外设当前数据集已生成"]
    B --> B0["执行上游契约错误检测
检测输出受预编译开关控制"]
    B0 --> C{"发现上游错误？"}
    C -- "是" --> C1["记录逻辑错误日志
项目运行错误日志/项目记录异常日志"]
    C1 --> C2["按开关弹窗提示
项目弹窗错误提示"]
    C2 --> C3["标记扫描输入异常
不生成观察/识别/跟踪需求来源"]
    C3 --> Z["进入异常收口
返回运行存在/输出结果场景"]
    C -- "否" --> D["上游已排除
坐标系/时间戳/generation/对齐/来源ID不可用"]
    D --> D1["上游已排除
重复/过期/已消费/空材料/无有效点/无轮廓"]
    D1 --> E["初始化本轮累积器"]
    E --> E1["状态信息计数=0
需求来源集合=空
临时证据集合=空
已处理数据计数=0"]
    E1 --> F["读取自我内部场景指针
内部场景基准 / 已确认存在集合"]
    E1 --> G["读取外设当前数据集
全部数据项"]
    F --> H{"内部场景指针
和数据集可读？"}
    G --> H
    H -- "否" --> H1["记录输入结构逻辑错误
错误日志/弹窗受预编译开关控制"]
    H1 --> Z
    H -- "是" --> I["展开外设数据集
形成待处理数据项队列"]

2. 外设数据集全量处理

flowchart TD
    A["待处理数据项队列"] --> B{"还有数据项？"}
    B -- "否" --> Z["进入本轮汇总"]
    B -- "是" --> C["取下一个外设数据项"]
    C --> D["已处理数据计数+1
该数据项必须入账"]
    D --> E["解析该数据项的
空间位置 / 尺寸 / 轮廓 / 彩图 / 深度图 / 轮廓极值"]
    E --> F{"可解析为
可处理材料？"}
    F -- "否" --> F1["记录上游契约漏检
错误日志/弹窗受预编译开关控制"]
    F1 --> B
    F -- "是" --> G["进入对应关系判断"]
    G --> B

3. 对应关系判断与需求来源生成

flowchart TD
    A["当前外设数据项"] --> B{"空间位置与内部场景
某存在基本一致？"}
    B -- "是" --> C{"空间尺寸和轮廓
基本一致？"}
    C -- "是" --> D["确认同一存在
进入特征级比较"]
    C -- "否" --> C1{"轮廓/深度显示
可能拆分、合并或层次不清？"}
    C1 -- "是" --> C2["记录细分存在子层特征需求来源
用轮廓/深度生成更细子层特征"]
    C2 --> D1["当前数据项处理继续
可比较部分仍进入特征级比较"]
    C1 -- "否" --> C3["记录识别类需求来源
对应关系需要重新确认"]
    C3 --> X["当前数据项需求来源已入账
继续下一数据项"]
    B -- "否" --> E{"能用空间尺寸和轮廓
在当前场景唯一找回？"}
    E -- "是" --> E1["记录跟踪类需求来源
目标存在当前空间坐标=已取得"]
    E1 --> D1
    E -- "否" --> E2["记录识别类需求来源
当前材料对应已有存在状态=已确定"]
    E2 --> X
    D1 --> D

4. 特征级处理：可比较就扫描，不可比较就生成需求来源

flowchart TD
    A["已锁定同一存在的数据项"] --> B["展开特征材料队列
位置/尺寸/轮廓/彩图/深度图/轮廓极值"]
    B --> C{"还有特征材料？"}
    C -- "否" --> Z["当前数据项处理完成
继续下一数据项"]
    C -- "是" --> D["取下一个特征材料"]
    D --> E{"该特征材料
本轮可比较？"}
    E -- "否" --> E1["记录观察类需求来源
该特征当前值=已取得/可比较"]
    E1 --> C
    E -- "是" --> F{"已有可比历史
或当前状态基准？"}
    F -- "否" --> F1["首次扫描该特征
更新当前特征值并建立当前状态基准"]
    F1 --> F2["状态信息计数+1
不生成发现语义
不生成变化动态"]
    F2 --> C
    F -- "是" --> G["比较内部基准
与外设当前特征值"]
    G --> H{"当前特征值
发生变化？"}
    H -- "否" --> H1["无变化
刷新必要当前值和下一轮基准"]
    H1 --> C
    H -- "是" --> I["更新内部场景当前特征值
记录状态信息和状态变化候选"]
    I --> I1["状态信息计数+1
状态变化交给内部治理/因果补完"]
    I1 --> C

5. 内部已有存在未被本轮数据覆盖

flowchart TD
    A["外设数据集全量处理完成"] --> B["反查内部场景中
本轮应关注的已有存在"]
    B --> C{"存在是否有
本轮对应数据项？"}
    C -- "有" --> Z["已由数据项处理链处理"]
    C -- "没有" --> D["记录未覆盖状态候选
可能移动 / 遮蔽 / 暂时不可见"]
    D --> E{"需要取得新坐标？"}
    E -- "是" --> E1["记录跟踪类需求来源
目标存在当前空间坐标=已取得"]
    E -- "否" --> F{"需要判断遮蔽层次？"}
    F -- "是" --> F1["记录细分存在子层特征需求来源
用轮廓/深度判断遮蔽或层次"]
    F -- "否" --> G["只记录暂时不可见或未覆盖状态候选"]
    E1 --> H["进入本轮汇总"]
    F1 --> H
    G --> H
    Z --> H

6. 本轮汇总与语义输出

flowchart TD
    A["本轮扫描处理完成"] --> B["校验处理闭合
已处理数据计数=外设数据项总数"]
    B --> B1{"处理计数闭合？"}
    B1 -- "否" --> B2["记录扫描处理闭合逻辑错误
错误日志/弹窗受预编译开关控制"]
    B2 --> Z0["异常收口
返回运行存在/输出结果场景"]
    B1 -- "是" --> C["输出结果场景写入
状态信息 / 空信息 / 需求来源 / 临时证据引用"]
    C --> D["结构化需求来源集合"]
    D --> D1["识别类：对应关系缺口"]
    D --> D2["跟踪类：坐标缺口 / 移动疑似"]
    D --> D3["观察类：当前特征值不可比较或需补充"]
    D --> D4["细分存在子层特征：拆分/合并/遮蔽/层次不清"]
    D1 --> E["需求生成"]
    D2 --> E
    D3 --> E
    D4 --> E
    E --> F["任务创建"]
    F --> G["任务筹办"]
    G --> H["方法选择
识别 / 跟踪 / 观察 / 细分存在子层特征 / 其它方法"]
    C --> I{"状态信息计数
是否大于0？"}
    I -- "是" --> J["语义输出：状态信息"]
    I -- "否" --> K["语义输出：空信息"]
    J --> Z["返回运行存在
输出结果场景"]
    K --> Z

7. 扫描内部硬边界

flowchart TD
    A["扫描本能方法"] --> B["必须：外设数据集
所有数据项全量处理"]
    A --> C["必须：流程开始后先做
上游契约错误检测"]
    A --> D["允许：处理数据时生成
观察/识别/跟踪/细分子层需求来源"]
    A --> E["允许：缺口不阻断整轮扫描
继续处理其它数据和特征"]
    A --> F["允许：最终统一决定
状态信息或空信息"]
    A -.-> G["禁止：把上游错误
当作普通需求来源或空信息"]
    A -.-> H["禁止：硬性扫描范围约束
导致数据项不处理"]
    A -.-> I["禁止：材料质量不可比较
就停止整轮扫描"]
    A -.-> J["禁止：缺口一出现
就返回空信息"]
    A -.-> K["禁止：静默丢弃
外设数据项"]
    A -.-> L["禁止：把临时证据
长期写入存在特征集合"]
    A -.-> M["禁止：直接创建新存在
或直接调用观察/识别/跟踪"]
    A -.-> N["禁止：关闭日志或弹窗
掩盖逻辑错误"]

依据：规范/禁止性规范20260611.md，规范/当前场景特征值明确标准规范20260602.md，规范/相机外设综合工作流程规范20260607.md，说明书/自我侧观察识别扫描跟踪本能方法规格说明.md，实施记录/20260612_日志输出预编译控制登记表.md。

边界：上游错误先检测，命中后走预编译控制的错误日志和弹窗；合法外设数据集全量处理；空信息只表示本轮没有状态信息产出。
