扫描本能方法内部流程图 v0.13

扫描正式核对外设数据前，先生成本轮扫描关注集合；只有本轮应覆盖存在未被外设覆盖时，才进入异常未覆盖解释。

0. 定位与返回信息

flowchart TD
    A["上级治理需求"] --> B["需要当前场景事实可用性"]
    B --> C["扫描目标
维护本轮应覆盖存在的当前状态"]
    C --> D["输入
自我内部场景指针
当前扫描范围 / ROI / 外设视野
已合法外设当前数据集"]
    D --> E["前置筛选
生成本轮扫描关注集合"]
    E --> F["执行中写场景
当前状态值 / 当前基准 / 状态动态"]
    F --> G["输出结果场景
状态信息 / 信息缺口 / 空信息
写入摘要 / 处理闭合证据"]
    G --> H["函数返回
扫描方法运行虚拟存在指针"]

1. 本轮扫描关注集合生成

flowchart TD
    A["当前场景存在集合"] --> B["读取扫描目的
来源需求 / 来源任务 / 当前扫描范围"]
    B --> C{"属于当前扫描范围
或当前任务目标范围？"}
    C -- "否" --> J["本轮可忽略存在集合
范围外"]
    C -- "是" --> D{"空间位置或预测投影
可判断？"}
    D -- "否" --> K["本轮需补条件存在集合
缺空间位置 / 预测依据"]
    D -- "是" --> E{"与当前外设视野
重合率达标？"}
    E -- "否" --> J
    E -- "是" --> F{"低频维护
本轮是否到期？"}
    F -- "否" --> J
    F -- "是" --> G{"已被高优先级
跟踪任务接管？"}
    G -- "是" --> J
    G -- "否" --> H["计算扫描优先级
安全 / 服务 / 动态 / ROI / 最近扫描年龄"]
    H --> I{"扫描优先级达标？"}
    I -- "否" --> J
    I -- "是" --> L["本轮应覆盖存在集合"]

2. 主链与覆盖索引

flowchart TD
    A["扫描方法启动"] --> B["建立扫描方法运行虚拟存在"]
    B --> C["读取输入参数场景"]
    C --> D["生成本轮扫描关注集合"]
    D --> E["展开已合法外设数据项队列"]
    E --> F{"还有外设数据项？"}
    F -- "有" --> G["取出并解析数据项"]
    G --> H["判断对应关系
只对本轮应覆盖集合和可归属数据项建索引"]
    H --> I["更新本轮外设覆盖索引"]
    I --> J["处理已覆盖存在的可比较特征"]
    J --> K["闭合该数据项"]
    K --> F
    F -- "无" --> L["计算本轮异常未覆盖存在集合
应覆盖集合 - 外设覆盖索引"]
    L --> M["处理异常未覆盖存在"]
    M --> N["构造输出结果场景
同步运行虚拟存在"]

    A -. "仅诊断构建" .-> P["预编译上游契约诊断"]
    P -. "发现上游错误" .-> Q["逻辑错误日志 / 弹窗
不进入普通需求分支"]

    I -.-> M

5. 异常未覆盖解释

flowchart TD
    A["本轮异常未覆盖存在集合"] --> B["读取当前场景既有状态 / 动态"]
    B --> C["预测当前应在空间坐标"]
    C --> D{"预测位置有对应数据项？"}
    D -- "有" --> E["回到数据项处理链"]
    D -- "无" --> F{"存在正在移动？"}
    F -- "是" --> G["闸门5
预测坐标是否在视野外"]
    G -- "视野外" --> H["写空间位置当前值=预测坐标
来源不写入空间位置值"]
    H --> I["记录移动出视野状态 / 动态证据"]
    G -- "仍在视野内" --> J["进入遮蔽覆盖判断"]
    F -- "否" --> K{"自我移动或中间存在移动
有证据？"}
    K -- "有" --> J
    K -- "无" --> L["写消失状态
消失=突然不见了"]
    J --> M["闸门6
遮蔽 / 覆盖证据"]
    M -- "成立" --> N["闸门7
子层特征证据足够？"]
    N -- "足够" --> O["写遮蔽 / 覆盖状态"]
    N -- "不足" --> P["记录信息缺口
需要子层特征"]
    M -- "不成立" --> L
    M -- "证据不足" --> P

6. 运行虚拟存在与治理输出

flowchart TD
    A["扫描处理完成"] --> B["同步扫描方法运行虚拟存在"]
    B --> B1["身份来源特征
运行ID / 来源需求 / 来源任务 / 当前场景"]
    B --> B2["筛选集合特征
应覆盖 / 可忽略 / 需补条件 / 异常未覆盖"]
    B --> B3["进度特征
数据项总数 / 取出计数 / 解析计数 / 闭合计数"]
    B --> B4["覆盖与写入特征
覆盖索引 / 冲突数量 / 写入摘要 / 批次状态"]
    B --> B5["缺口与证据特征
信息缺口 / 临时证据 / 值域冲突 / 视野外证据"]
    B --> C["构造输出结果场景"]
    C --> D{"治理状态信息集合为空？"}
    D -- "否" --> E["语义输出=状态信息
附写入摘要和证据引用"]
    D -- "是" --> F["语义输出=空信息
仍保留缺口集合 / 写入摘要 / 处理证据"]
    C --> G["信息缺口集合
作为需求来源进入需求生成"]
    E --> H["内部治理接收"]
    F --> H
    G -. "只能经任务链" .-> I["需求生成 -> 任务创建 -> 任务筹办 -> 方法选择"]
关键边界： 筛选结果只写入扫描方法运行虚拟存在；未覆盖解释输入必须是本轮应覆盖存在集合减去本轮外设覆盖存在集合。 本轮可忽略和需补条件的存在不写消失、不写遮蔽。
