# 扫描本能方法内部流程图 v0.5

更新时间：2026-06-15

## 依据

```text
规范/禁止性规范20260611.md
规范/当前场景特征值明确标准规范20260602.md
规范/相机外设综合工作流程规范20260607.md
说明书/自我侧观察识别扫描跟踪本能方法规格说明.md
用户口径：
    外设当前数据集中的所有数据都需要处理；
    观察、跟踪、识别的需求都来自处理外设数据集时；
    对应冲突应生成细分存在子层特征需求来源；
    材料质量不是扫描全局停止条件；
    空信息只表示本轮没有状态信息产出，不表示没有处理结果。
```

## 说明

v0.5 是按最新口径重画的分段可读版。扫描内部不再把缺口直接导向空信息；它全量处理外设当前数据集，边处理边记录状态信息、需求来源和临时证据。观察、识别、跟踪以及“细分存在子层特征”的需求来源，都在处理外设数据项时形成，再进入需求-任务-方法闭环。

## 流程图

### 1. 前置契约与本轮初始化

```mermaid
flowchart TD
    A["扫描任务<br/>已选择扫描方法"] --> B["前置契约：外设当前数据集已生成"]
    B --> C["上游已排除<br/>坐标系/时间戳/generation/对齐/来源ID不可用"]
    B --> D["上游已排除<br/>重复/过期/已消费/空材料/无有效点/无轮廓"]
    C --> E["初始化本轮累积器"]
    D --> E
    E --> E1["状态信息计数=0<br/>需求来源集合=空<br/>临时证据集合=空<br/>已处理数据计数=0"]
    E1 --> F["读取自我内部场景指针<br/>内部场景基准 / 已确认存在集合"]
    E1 --> G["读取外设当前数据集<br/>全部数据项"]
    F --> H{"内部场景指针<br/>和数据集可读？"}
    G --> H
    H -- "否" --> H1["记录输入结构异常<br/>按逻辑错误处理"]
    H1 --> Z["进入本轮汇总"]
    H -- "是" --> I["展开外设数据集<br/>形成待处理数据项队列"]
```

### 2. 外设数据集全量处理

```mermaid
flowchart TD
    A["待处理数据项队列"] --> B{"还有数据项？"}
    B -- "否" --> Z["进入本轮汇总"]
    B -- "是" --> C["取下一个外设数据项"]
    C --> D["已处理数据计数+1<br/>该数据项必须入账"]
    D --> E["解析该数据项的<br/>空间位置 / 尺寸 / 轮廓 / 彩图 / 深度图 / 轮廓极值"]
    E --> F{"可解析为<br/>可处理材料？"}
    F -- "否" --> F1["记录数据结构异常<br/>或上游契约漏检"]
    F1 --> B
    F -- "是" --> G["进入对应关系判断"]
    G --> B
```

### 3. 对应关系判断与需求来源生成

```mermaid
flowchart TD
    A["当前外设数据项"] --> B{"空间位置与内部场景<br/>某存在基本一致？"}
    B -- "是" --> C{"空间尺寸和轮廓<br/>基本一致？"}
    C -- "是" --> D["确认同一存在<br/>进入特征级比较"]
    C -- "否" --> C1{"轮廓/深度显示<br/>可能拆分、合并或层次不清？"}
    C1 -- "是" --> C2["记录细分存在子层特征需求来源<br/>用轮廓/深度生成更细子层特征"]
    C2 --> D1["当前数据项处理继续<br/>可比较部分仍进入特征级比较"]
    C1 -- "否" --> C3["记录识别类需求来源<br/>对应关系需要重新确认"]
    C3 --> X["当前数据项需求来源已入账<br/>继续下一数据项"]
    B -- "否" --> E{"能用空间尺寸和轮廓<br/>在当前场景唯一找回？"}
    E -- "是" --> E1["记录跟踪类需求来源<br/>目标存在当前空间坐标=已取得"]
    E1 --> D1
    E -- "否" --> E2["记录识别类需求来源<br/>当前材料对应已有存在状态=已确定"]
    E2 --> X
    D1 --> D
```

### 4. 特征级处理：可比较就扫描，不可比较就生成需求来源

```mermaid
flowchart TD
    A["已锁定同一存在的数据项"] --> B["展开特征材料队列<br/>位置/尺寸/轮廓/彩图/深度图/轮廓极值"]
    B --> C{"还有特征材料？"}
    C -- "否" --> Z["当前数据项处理完成<br/>继续下一数据项"]
    C -- "是" --> D["取下一个特征材料"]
    D --> E{"该特征材料<br/>本轮可比较？"}
    E -- "否" --> E1["记录观察类需求来源<br/>该特征当前值=已取得/可比较"]
    E1 --> C
    E -- "是" --> F{"已有可比历史<br/>或当前状态基准？"}
    F -- "否" --> F1["首次扫描该特征<br/>更新当前特征值并建立当前状态基准"]
    F1 --> F2["状态信息计数+1<br/>不生成发现语义<br/>不生成变化动态"]
    F2 --> C
    F -- "是" --> G["比较内部基准<br/>与外设当前特征值"]
    G --> H{"当前特征值<br/>发生变化？"}
    H -- "否" --> H1["无变化<br/>刷新必要当前值和下一轮基准"]
    H1 --> C
    H -- "是" --> I["更新内部场景当前特征值<br/>记录状态信息和状态变化候选"]
    I --> I1["状态信息计数+1<br/>状态变化交给内部治理/因果补完"]
    I1 --> C
```

### 5. 内部已有存在未被本轮数据覆盖

```mermaid
flowchart TD
    A["外设数据集全量处理完成"] --> B["反查内部场景中<br/>本轮应关注的已有存在"]
    B --> C{"存在是否有<br/>本轮对应数据项？"}
    C -- "有" --> Z["已由数据项处理链处理"]
    C -- "没有" --> D["记录未覆盖状态候选<br/>可能移动 / 遮蔽 / 暂时不可见"]
    D --> E{"需要取得新坐标？"}
    E -- "是" --> E1["记录跟踪类需求来源<br/>目标存在当前空间坐标=已取得"]
    E -- "否" --> F{"需要判断遮蔽层次？"}
    F -- "是" --> F1["记录细分存在子层特征需求来源<br/>用轮廓/深度判断遮蔽或层次"]
    F -- "否" --> G["只记录暂时不可见或未覆盖状态候选"]
    E1 --> H["进入本轮汇总"]
    F1 --> H
    G --> H
    Z --> H
```

### 6. 本轮汇总与语义输出

```mermaid
flowchart TD
    A["本轮扫描处理完成"] --> B["校验处理闭合<br/>已处理数据计数=外设数据项总数"]
    B --> C["输出结果场景写入<br/>状态信息 / 空信息 / 需求来源 / 临时证据引用"]
    C --> D["结构化需求来源集合"]
    D --> D1["识别类：对应关系缺口"]
    D --> D2["跟踪类：坐标缺口 / 移动疑似"]
    D --> D3["观察类：当前特征值不可比较或需补充"]
    D --> D4["细分存在子层特征：拆分/合并/遮蔽/层次不清"]
    D1 --> E["需求生成"]
    D2 --> E
    D3 --> E
    D4 --> E
    E --> F["任务创建"]
    F --> G["任务筹办"]
    G --> H["方法选择<br/>识别 / 跟踪 / 观察 / 细分存在子层特征 / 其它方法"]
    C --> I{"状态信息计数<br/>是否大于0？"}
    I -- "是" --> J["语义输出：状态信息"]
    I -- "否" --> K["语义输出：空信息"]
    J --> Z["返回运行存在<br/>输出结果场景"]
    K --> Z
```

### 7. 扫描内部硬边界

```mermaid
flowchart TD
    A["扫描本能方法"] --> B["必须：外设数据集<br/>所有数据项全量处理"]
    A --> C["允许：处理数据时生成<br/>观察/识别/跟踪/细分子层需求来源"]
    A --> D["允许：缺口不阻断整轮扫描<br/>继续处理其它数据和特征"]
    A --> E["允许：最终统一决定<br/>状态信息或空信息"]
    A -.-> F["禁止：硬性扫描范围约束<br/>导致数据项不处理"]
    A -.-> G["禁止：材料质量不可比较<br/>就停止整轮扫描"]
    A -.-> H["禁止：缺口一出现<br/>就返回空信息"]
    A -.-> I["禁止：静默丢弃<br/>外设数据项"]
    A -.-> J["禁止：把临时证据<br/>长期写入存在特征集合"]
    A -.-> K["禁止：直接创建新存在<br/>或直接调用观察/识别/跟踪"]
```

## 关键边界

```text
1. 外设当前数据集中的所有数据都必须被处理，不能因为范围、质量或对应缺口而静默跳过。
2. 坐标系、时间戳、generation、对齐状态、外设来源ID、重复/过期/空材料等，应在生成数据集前排除；若进入扫描，按上游契约错误记录。
3. 观察、跟踪、识别的需求来源都来自处理外设数据集时形成的结构化缺口。
4. 一对多 / 多对一对应冲突优先生成“细分存在子层特征”需求来源，用轮廓和深度取得更细子层特征。
5. 内部已有存在未被本轮数据覆盖时，按移动、遮蔽或暂时不可见处理；通常先生成跟踪类需求来源，必要时生成细分子层需求来源。
6. 空信息只表示本轮没有状态信息产出，不表示本轮没有需求来源或处理结果。
```
