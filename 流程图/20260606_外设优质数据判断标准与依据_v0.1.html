外设优质观察材料判断标准与依据 v0.1

优质观察材料 = 新鲜、完整、可回查、稳定、目标相关、可比较、可被自我消费的观察材料。它不是世界真值，也不是需求满足结论；报告 / 包 / 队列项 / 材料页只是通信容器。

总原则

1. 优质观察材料不是世界真值；它只允许进入自我侧组织、验证、确认和提交入口。
2. 外设侧不得使用过期、generation 失配、材料不可回查或目标已失效的数据继续生成新鲜报告。
3. 任务管理 / 自我侧从队列视图读取观察材料后，应删除已消费项；未消费项必须受 TTL、容量和 generation 清理。
4. 扫描和跟踪的优质观察材料必须有来自自我缓冲区的目标上下文；全帧材料只能作为识别或外设观察存在材料。
5. 报告 / 包 / 队列项 / 材料页只是通信容器；正式承接对象只能是存在、特征、二次特征和状态动态。

优质范围

优质观察材料可以是：全局优质、目标区域优质、指定特征优质。

全帧深度或空间质量不足，不必然否定目标 ROI / mask 内材料可用；
对扫描 / 跟踪 / 指定目标复验，应优先检查目标区域质量；
对颜色、轮廓、二维回查类需求，深度 / 空间不足可以降级，不应直接判整份材料不合格。

最小判断函数口径

判断优质观察材料(队列项, 需求类型, 目标上下文):
    1. 检查采集成功、报告类型、外设ID、时间戳；
    2. 检查报告年龄 <= 等待项最大允许报告年龄；
    3. 检查 d455:// 材料句柄可回查，且未过期；
    4. 若需求类型是扫描 / 跟踪，检查自我存在信息缓冲区中目标上下文新鲜；
    5. 检查适用范围质量硬底线：全帧任务检查全局深度 / 空间质量；目标任务检查目标 ROI / mask 内深度 / 空间质量；颜色、轮廓、二维回查任务允许深度 / 空间不足时降级；
    6. 检查优质门槛：帧质量评分 >= 7000，轮廓闭合度 >= 8000，轮廓置信度 >= 8000，补观察缺口状态 = 0；
    7. 按识别 / 扫描 / 跟踪分别检查模式专属条件；跟踪还要检查当前值域区间ID、预测区间、预测误差值、非法区间跳变次数和合法区间迁移状态；
    8. 返回不合格 / 可用 / 优质、质量依据字段、需补观察原因、建议外设动作。
