外设优质数据判断标准与依据 v0.1

优质数据 = 新鲜、完整、可回查、稳定、目标相关、可比较、可被自我消费的观察材料。它不是世界真值，也不是需求满足结论。

总原则

1. 优质数据不是世界真值；它只允许进入自我侧组织、验证、确认和提交入口。
2. 外设侧不得使用过期、generation 失配、材料不可回查或目标已失效的数据继续生成新鲜报告。
3. 自我侧从队列读取数据后，应删除已消费项；未消费项必须受 TTL、容量和 generation 清理。
4. 扫描和跟踪的优质数据必须有来自自我缓冲区的目标上下文；全帧材料只能作为识别或候选材料。

最小判断函数口径

判断优质数据(数据项, 需求类型, 目标上下文):
    1. 检查采集成功、报告类型、外设ID、时间戳；
    2. 检查报告年龄 <= 等待项最大允许报告年龄；
    3. 检查 d455:// 材料句柄可回查，且未过期；
    4. 若需求类型是扫描 / 跟踪，检查自我存在信息缓冲区中目标上下文新鲜；
    5. 检查硬底线：深度有效率 >= 5000，空间坐标有效率 >= 5000，有效点达标；
    6. 检查优质门槛：帧质量评分 >= 7000，轮廓闭合度 >= 8000，轮廓置信度 >= 8000，补观察缺口状态 = 0；
    7. 按识别 / 扫描 / 跟踪分别检查模式专属条件；
    8. 返回不合格 / 可用 / 优质、质量依据字段、需补观察原因、建议外设动作。
