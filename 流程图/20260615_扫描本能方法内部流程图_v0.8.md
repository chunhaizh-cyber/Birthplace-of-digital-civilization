```text
用户口径：
    流程开始后先排除上游错误，用预编译控制的检测报错日志和弹窗实现；
    外设当前数据集中的所有数据都需要处理；
    场景中的当前数据在扫描处理中途直接修改完成；
    语义输出是给内部治理用的，不是用于最后才回写场景；
    观察、跟踪、识别的需求都来自处理外设数据集时；
    内部已有存在未被本轮数据覆盖时，必须由明确变量判断；
    空信息只表示本轮没有给内部治理的状态信息产出，不表示没有处理结果。
```

## 说明

v0.8 将扫描内部拆成两条通道：场景写入通道和治理语义通道。场景写入通道在扫描处理中途直接更新自我内部场景中的当前特征值、当前状态基准、覆盖状态和下一轮基准；治理语义通道只在最后整理给内部治理使用的输出类型、状态信息集合、需求来源集合和证据引用。

## 流程图

### 1. 上游错误检测与本轮初始化

```mermaid
flowchart TD
    A["扫描任务<br/>已选择扫描方法"] --> B["前置契约：外设当前数据集已生成"]
    B --> B0["执行上游契约错误检测<br/>检测输出受预编译开关控制"]
    B0 --> C{"发现上游错误？"}
    C -- "是" --> C1["记录逻辑错误日志<br/>项目运行错误日志/项目记录异常日志"]
    C1 --> C2["按开关弹窗提示<br/>项目弹窗错误提示"]
    C2 --> C3["写运行存在异常状态<br/>异常类型=上游契约错误"]
    C3 --> Z["异常收口<br/>不生成普通需求来源"]
    C -- "否" --> D["确认上游已排除<br/>坐标系/时间戳/generation/对齐/来源ID不可用"]
    D --> D1["确认上游已排除<br/>重复/过期/已消费/空材料/无有效点/无轮廓"]
    D1 --> E["初始化本轮累积器"]
    E --> E1["治理状态信息集合=空<br/>需求来源集合=空<br/>临时证据集合=空<br/>已处理数据计数=0"]
    E1 --> F["读取自我内部场景指针<br/>内部场景基准 / 已确认存在集合"]
    E1 --> G["读取外设当前数据集<br/>全部数据项"]
    F --> H{"内部场景指针<br/>和数据集可读？"}
    G --> H
    H -- "否" --> H1["记录输入结构逻辑错误<br/>错误日志/弹窗受预编译开关控制"]
    H1 --> Z
    H -- "是" --> I["展开外设数据集<br/>形成待处理数据项队列"]
```

### 5. 内部已有存在未被本轮数据覆盖：可实现判定链

```mermaid
flowchart TD
    A["外设数据集全量处理完成"] --> B["建立内部存在关注集合"]
    B --> B1["来源：扫描需求目标存在<br/>当前场景活动存在<br/>上轮基准中仍标记为当前场景的存在"]
    B1 --> C["读取判定变量"]
    C --> C1["本轮覆盖状态<br/>有对应数据项 / 无对应数据项"]
    C --> C2["空间找回候选数<br/>尺寸+轮廓相似但坐标不同的数据项数量"]
    C --> C3["遮蔽证据状态<br/>上一坐标区域是否被其它深度/轮廓材料占据"]
    C --> C4["子层特征证据状态<br/>遮蔽、拆分、合并、层次是否足够判断"]
    C --> C5["观察保持状态<br/>该存在是否仍需在当前场景持续确认"]
    C1 --> D{"本轮覆盖状态<br/>有对应数据项？"}
    D -- "是" --> Z["已由数据项处理链处理"]
    D -- "否" --> E{"观察保持状态<br/>仍需确认？"}
    E -- "否" --> E1["场景写入：更新该存在<br/>本轮覆盖状态=未覆盖但无需保持"]
    E1 --> H["进入本轮汇总"]
    E -- "是" --> F{"空间找回候选数<br/>是否等于1？"}
    F -- "是" --> F1["记录跟踪类需求来源<br/>用唯一候选取得新空间坐标"]
    F1 --> H
    F -- "大于1" --> F2["记录细分存在子层特征需求来源<br/>多候选需用轮廓/深度细分"]
    F2 --> H
    F -- "等于0" --> G{"遮蔽证据状态<br/>是否成立？"}
    G -- "是" --> G1{"子层特征证据<br/>是否足够？"}
    G1 -- "足够" --> G2["场景写入：更新覆盖/可见性状态<br/>遮蔽或暂不可见候选"]
    G2 --> G3["治理语义累积：追加遮蔽/暂不可见状态信息"]
    G3 --> H
    G1 -- "不足" --> G4["记录细分存在子层特征需求来源<br/>需要用轮廓/深度确认遮蔽层次"]
    G4 --> H
    G -- "否" --> G5["记录跟踪类需求来源<br/>无覆盖且无遮挡证据，需取得新坐标"]
    G5 --> H
    Z --> H
```

### 7. 扫描内部硬边界

```mermaid
flowchart TD
    A["扫描本能方法"] --> B["必须：外设数据集<br/>所有数据项全量处理"]
    A --> C["必须：流程开始后先做<br/>上游契约错误检测"]
    A --> D["必须：可确认的场景数据<br/>在处理中途直接写入内部场景"]
    A --> E["必须：未覆盖分支<br/>用明确变量判定"]
    A --> F["必须：语义输出<br/>只供内部治理使用"]
    A --> G["允许：处理数据时生成<br/>观察/识别/跟踪/细分子层需求来源"]
    A -.-> H["禁止：把治理语义输出<br/>当作最后回写场景的通道"]
    A -.-> I["禁止：凭空判断<br/>需要取得新坐标"]
    A -.-> J["禁止：把上游错误<br/>当作普通需求来源或空信息"]
    A -.-> K["禁止：硬性扫描范围约束<br/>导致数据项不处理"]
    A -.-> L["禁止：缺口一出现<br/>就返回空信息"]
    A -.-> M["禁止：静默丢弃<br/>外设数据项"]
    A -.-> N["禁止：直接创建新存在<br/>或直接调用观察/识别/跟踪"]
```

## 关键边界

```text
1. 可确认的自我内部场景数据在扫描处理中途直接写入，不等到语义输出阶段。
2. 语义输出只给内部治理使用，表达本轮是否有治理状态信息、有哪些需求来源、有哪些处理证据。
3. “内部已有存在未被本轮数据覆盖”必须引入明确变量：本轮覆盖状态、空间找回候选数、遮蔽证据状态、子层特征证据状态、观察保持状态。
4. 跟踪类需求来源的判断依据不是“感觉需要新坐标”，而是存在仍需确认且无本轮覆盖，并根据找回候选和遮蔽证据决定。
5. 语义输出字段为：输出类型=状态信息或空信息；空信息原因=本轮无治理状态信息产出。
6. 即使输出类型=空信息，需求来源集合、场景写入摘要、临时证据引用和处理闭合证据仍必须交给内部治理。
```
