    GOAL["识别任务目标
当前观察范围内的有效可观测单位
稳定对应到存在"]
    G1["子目标1: 明确观察范围

    G2["子目标2: 列出有效可观测单位
观察簇 / ROI / 掩码 / 点集 / 深度切片"]
    G3["子目标3: 建立候选归属

    P_HANDLE["可回查材料

    P_GAP["缺口材料

    %% 处理层
    T0["读取识别包

    T_BAD["输入不是识别包

    T1["核对材料可回查
缺关键句柄则形成材料缺口"]
    T2["整理观察范围
排除无效区域

    T3["整理候选归属
新存在候选 / 已有存在候选 / 背景候选 / 冲突候选"]
    T4["逐单位判断
稳定对应 / 未稳定 / 多重冲突 / 证据不足"]
    T5["生成事实草案

    %% 达成判断
    A0{"草案是否可提交?"}
    A_REJECT["不可提交

    SUBMIT["提交对应事实

    A1{"对应事实是否闭合?"}
    DONE["识别目标达成

    PARTIAL["识别目标部分达成

    EMPTY["无有效可观测单位

    EVIDENCE["证据回查

    %% 禁止边界
    R1["边界: 识别任务只要识别包"]
    R2["边界: 原始特征先组织到单位、候选、事实
再进入提交入口"]
    R3["边界: 不生成状态、动态、安全或服务结论"]
    R4["边界: 识别包不直接等同需求满足"]

达成口径

识别目标达成 = 当前观察范围有效可观测单位数量 > 0 AND 已稳定对应存在可观测单位数量 == 当前观察范围有效可观测单位数量 AND 未稳定对应存在可观测单位数量 == 0 AND 多重对应冲突可观测单位数量 == 0 AND 稳定对应存在数量 > 0

判断口径

  • 识别任务从目标展开，不从 D455 设备动作展开。
  • 外设只负责让供料条件、材料条件、单位条件和候选材料具备。
  • 自我处理的关键是把原始特征组织成观察范围、可观测单位、候选归属、稳定对应和缺口说明。
  • 提交入口裁决后，识别任务才形成正式对应事实。
  • 稳定对应存在数量大于等于 1 时，可以并行激活扫描任务，但这不是识别任务继续消费扫描包。
  • 识别任务不生成被观察存在状态、变化动态、扫描事实、跟踪事实、安全值、服务值或风险状态明确。
