扫描本能方法内部流程图 v0.10

正常运行只处理已合法数据集；上游错误检测是预编译诊断旁路。未覆盖分支读取当前场景既有状态/动态，先预测当前帧应在位置，再判断移动出视野、遮蔽/覆盖、跟踪、细分子层需求来源或消失状态。

1. 正常入口与预编译诊断旁路

flowchart TD
    A["扫描任务
已选择扫描方法"] --> B["正常入口：读取已合法的外设当前数据集"]
    B --> C["读取自我内部场景指针
内部场景基准 / 既有状态与动态信息"]
    C --> D["初始化本轮累积器
治理状态集合=空
需求来源集合=空
已处理数据计数=0"]
    D --> E["展开外设数据集
形成待处理数据项队列"]

    A -. "仅诊断构建" .-> P0["预编译诊断旁路
扫描上游契约检测开关"]
    P0 -.-> P1{"发现上游契约错误？"}
    P1 -. "是" .-> P2["记录逻辑错误日志
项目运行错误日志 / 项目记录异常日志"]
    P2 -.-> P3["按UI开关弹窗
项目弹窗错误提示"]
    P3 -.-> P4["异常收口
不生成普通需求来源"]
    P1 -. "否" .-> B

2. 外设数据集全量处理与覆盖索引

flowchart TD
    A["待处理数据项队列"] --> B{"还有数据项？"}
    B -- "否" --> Z["进入内部存在覆盖反查"]
    B -- "是" --> C["取下一个外设数据项"]
    C --> D["已处理数据计数+1
该数据项必须入账"]
    D --> E["解析数据项
空间位置 / 尺寸 / 轮廓 / 彩图 / 深度图 / 轮廓极值"]
    E --> F{"可解析为
可处理材料？"}
    F -- "否" --> F1["诊断构建：记录上游契约漏检
正常运行不应命中"]
    F1 --> B
    F -- "是" --> G["进入对应关系判断"]
    G --> H["更新本轮覆盖索引
存在ID/候选ID -> 数据项、坐标、特征、置信度"]
    H --> B

3. 数据项对应关系与需求来源

flowchart TD
    A["当前外设数据项"] --> B{"空间位置与内部场景
某存在基本一致？"}
    B -- "是" --> C{"空间尺寸和轮廓
基本一致？"}
    C -- "是" --> D["确认同一存在
进入特征级处理"]
    C -- "否" --> C1{"轮廓/深度显示
可能拆分、合并或层次不清？"}
    C1 -- "是" --> C2["记录细分存在子层特征需求来源
用轮廓/深度生成更细子层特征"]
    C2 --> D1["可比较部分仍进入特征级处理"]
    C1 -- "否" --> C3["记录识别类需求来源
对应关系需要重新确认"]
    C3 --> X["当前数据项处理完成
继续下一数据项"]
    B -- "否" --> E{"能用空间尺寸和轮廓
在当前场景唯一找回？"}
    E -- "是" --> E1["记录跟踪类需求来源
目标存在当前空间坐标=已取得"]
    E1 --> D1
    E -- "否" --> E2["记录识别类需求来源
当前材料对应已有存在状态=已确定"]
    E2 --> X
    D1 --> D

4. 特征级处理：场景直接写入，语义累积给治理

flowchart TD
    A["已锁定同一存在的数据项"] --> B["展开特征材料队列
位置/尺寸/轮廓/彩图/深度图/轮廓极值"]
    B --> C{"还有特征材料？"}
    C -- "否" --> Z["当前数据项处理完成
继续下一数据项"]
    C -- "是" --> D["取下一个特征材料"]
    D --> E{"该特征材料
本轮可比较？"}
    E -- "否" --> E1["记录观察类需求来源
该特征当前值=已取得/可比较"]
    E1 --> C
    E -- "是" --> F{"已有可比历史
或当前状态基准？"}
    F -- "否" --> F1["首次扫描该特征"]
    F1 --> F2["场景写入：直接更新当前特征值
建立当前状态基准"]
    F2 --> F3["治理语义累积：追加
当前状态基准已建立"]
    F3 --> C
    F -- "是" --> G["比较内部基准
与外设当前特征值"]
    G --> H{"当前特征值
发生变化？"}
    H -- "否" --> H1["场景写入：刷新必要当前值
和下一轮基准"]
    H1 --> C
    H -- "是" --> I["场景写入：直接更新内部场景当前特征值
刷新当前状态基准/下一轮基准"]
    I --> I1["治理语义累积：追加状态信息
状态变化候选交给内部治理/因果补完"]
    I1 --> C

5. 内部已有存在未被本轮数据覆盖

flowchart TD
    A["外设数据集全量处理完成"] --> B["建立内部存在关注集合"]
    B --> B1["来源：当前场景活动存在
扫描需求目标存在
上一帧仍在场景中的存在"]
    B1 --> C["读取当前场景既有状态/动态信息
由前序扫描、跟踪或状态记录产生"]
    C --> P["计算或预测当前帧
该存在应该所处的空间位置"]
    P --> C1["存在移动动态
移动方向 / 速度 / 前一空间位置"]
    P --> C2["预测位置边缘关系
应在位置是否在视野边缘或接近边缘"]
    P --> C3["自我移动动态
自我上一帧到本帧是否移动"]
    P --> C4["中间存在移动证据
自我与预测位置之间是否有存在正在移动"]
    P --> C5["遮蔽/覆盖证据
预测位置区域是否被其它轮廓/深度占据"]
    P --> C6["本轮覆盖状态
预测位置或该存在是否有对应数据项"]

6. 未覆盖判定：移动出视野、遮蔽覆盖、跟踪、细分或消失

flowchart TD
    A["已根据当前场景既有状态/动态
预测当前帧应在位置"] --> A1["取得本轮覆盖状态
按预测位置和存在索引对照"]
    A1 --> B{"预测位置或该存在
有对应数据项？"}
    B -- "有" --> Z["已由数据项处理链处理"]
    B -- "无" --> C{"既有状态/动态是否显示
该存在正在移动？"}
    C -- "是" --> C1{"预测位置是否在
视野边缘或接近边缘？"}
    C1 -- "是" --> C2["场景写入：生成移动出视野动态
更新当前覆盖状态=视野外"]
    C2 --> C3["治理语义累积：追加
移动出视野状态信息"]
    C1 -- "否" --> C4["记录跟踪类需求来源
存在移动但未出边缘，需要取得新坐标"]
    C -- "否" --> D{"自我上一帧到本帧
是否移动？"}
    D -- "是" --> D1["记录视角变化候选
需要判断覆盖/遮蔽或视野变化"]
    D -- "否" --> E{"自我与目标之间
是否有存在正在移动？"}
    E -- "是" --> E1["记录中间移动存在候选
进入遮蔽/覆盖判断"]
    E -- "否" --> F["场景写入：更新消失状态
没有移动证据、自我移动证据或遮蔽/覆盖前因"]
    D1 --> G{"遮蔽/覆盖证据
是否成立？"}
    E1 --> G
    G -- "成立" --> G1{"子层特征证据
是否足够区分遮蔽/覆盖？"}
    G1 -- "足够" --> G2["场景写入：更新遮蔽/覆盖状态
覆盖和遮蔽用同一证据逻辑"]
    G2 --> G3["治理语义累积：追加遮蔽/覆盖状态信息"]
    G1 -- "不足" --> G4["记录细分存在子层特征需求来源
用轮廓/深度确认遮蔽/覆盖层次"]
    G -- "不成立" --> G5["场景写入：更新消失状态
未覆盖且遮蔽/覆盖解释不成立"]
    F --> F1["治理语义累积：追加消失状态信息
消失=存在突然不见了"]
    C3 --> H["进入治理语义汇总"]
    C4 --> H
    G3 --> H
    G4 --> H
    G5 --> G6["治理语义累积：追加消失状态信息
消失=存在突然不见了"]
    G6 --> H
    F1 --> H
    Z --> H

7. 给内部治理的语义输出结构

flowchart TD
    A["本轮扫描处理完成"] --> B["校验处理闭合
已处理数据计数=外设数据项总数"]
    B --> B1{"处理计数闭合？"}
    B1 -- "否" --> B2["诊断构建：记录处理闭合逻辑错误
正常运行不应命中"]
    B2 --> Z0["异常收口
返回运行存在/治理语义结果"]
    B1 -- "是" --> C["构造治理语义结果
不用于最后回写场景"]
    C --> C1["场景写入摘要
当前特征值 / 当前基准 / 覆盖状态 / 移动出视野动态 / 消失状态"]
    C --> C2["治理状态信息集合
状态基准建立 / 状态变化 / 遮蔽覆盖 / 移动出视野 / 消失"]
    C --> C3["需求来源集合
识别 / 跟踪 / 观察 / 细分子层"]
    C --> C4["处理闭合证据
数据项总数 / 已处理数据计数"]
    C --> C5["临时证据引用
用后丢弃，不写长期特征"]
    C2 --> D{"治理状态信息集合
是否为空？"}
    D -- "否" --> E["语义输出字段
输出类型=状态信息
状态信息集合=本轮治理状态集合"]
    D -- "是" --> F["语义输出字段
输出类型=空信息
空信息原因=本轮无治理状态信息产出"]
    E --> G["内部治理接收
状态信息链"]
    F --> H["内部治理接收
空信息 + 需求来源 + 处理证据"]
    C3 --> I["需求生成 -> 任务创建 -> 任务筹办 -> 方法选择"]
    I --> I1["可选方法
识别 / 跟踪 / 观察 / 细分存在子层特征 / 其它方法"]
    G --> Z["返回运行存在
治理语义结果"]
    H --> Z
    I1 --> Z

8. 扫描内部硬边界

flowchart TD
    A["扫描本能方法"] --> B["正常运行主链
只处理已合法数据集"]
    A --> C["预编译诊断旁路
才检测上游契约错误并弹窗"]
    A --> D["场景数据
在处理中途直接写入"]
    A --> E["未覆盖分支
必须读取当前场景既有状态/动态
并预测应在位置"]
    A --> F["语义输出
只供内部治理使用"]
    A -.-> G["禁止：正常运行中
用弹窗替代需求分支"]
    A -.-> H["禁止：把上游错误
转成普通观察/识别/跟踪需求"]
    A -.-> I["禁止：凭空判断
需要取得新坐标"]
    A -.-> J["禁止：不计算预测位置
直接判断遮蔽或跟踪"]
    A -.-> K["禁止：把治理语义输出
当作最后回写场景通道"]
    A -.-> L["禁止：静默丢弃
外设数据项"]
    A -.-> M["禁止：未覆盖且无解释证据时
继续悬空生成观察/识别需求"]

依据：规范/禁止性规范20260611.md，规范/当前场景特征值明确标准规范20260602.md，规范/相机外设综合工作流程规范20260607.md，说明书/自我侧观察识别扫描跟踪本能方法规格说明.md，实施记录/20260612_日志输出预编译控制登记表.md。

边界：正常运行不应有弹窗报错；弹窗属于预编译诊断旁路。未覆盖分支必须读取当前场景既有状态/动态并预测应在位置；没有可成立解释时直接输出消失状态；治理语义输出只供内部治理使用。
