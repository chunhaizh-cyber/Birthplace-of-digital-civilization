扫描本能方法内部流程图 v0.8

修正版：场景当前数据在扫描处理中途直接写入；最终语义输出只给内部治理使用，表达状态信息、空信息、需求来源和处理证据。

1. 上游错误检测与本轮初始化

flowchart TD
    A["扫描任务
已选择扫描方法"] --> B["前置契约：外设当前数据集已生成"]
    B --> B0["执行上游契约错误检测
检测输出受预编译开关控制"]
    B0 --> C{"发现上游错误？"}
    C -- "是" --> C1["记录逻辑错误日志
项目运行错误日志/项目记录异常日志"]
    C1 --> C2["按开关弹窗提示
项目弹窗错误提示"]
    C2 --> C3["写运行存在异常状态
异常类型=上游契约错误"]
    C3 --> Z["异常收口
不生成普通需求来源"]
    C -- "否" --> D["确认上游已排除
坐标系/时间戳/generation/对齐/来源ID不可用"]
    D --> D1["确认上游已排除
重复/过期/已消费/空材料/无有效点/无轮廓"]
    D1 --> E["初始化本轮累积器"]
    E --> E1["治理状态信息集合=空
需求来源集合=空
临时证据集合=空
已处理数据计数=0"]
    E1 --> F["读取自我内部场景指针
内部场景基准 / 已确认存在集合"]
    E1 --> G["读取外设当前数据集
全部数据项"]
    F --> H{"内部场景指针
和数据集可读？"}
    G --> H
    H -- "否" --> H1["记录输入结构逻辑错误
错误日志/弹窗受预编译开关控制"]
    H1 --> Z
    H -- "是" --> I["展开外设数据集
形成待处理数据项队列"]

2. 外设数据集全量处理与覆盖索引

flowchart TD
    A["待处理数据项队列"] --> B{"还有数据项？"}
    B -- "否" --> Z["进入内部存在覆盖反查"]
    B -- "是" --> C["取下一个外设数据项"]
    C --> D["已处理数据计数+1
该数据项必须入账"]
    D --> E["解析该数据项的
空间位置 / 尺寸 / 轮廓 / 彩图 / 深度图 / 轮廓极值"]
    E --> F{"可解析为
可处理材料？"}
    F -- "否" --> F1["记录上游契约漏检
错误日志/弹窗受预编译开关控制"]
    F1 --> B
    F -- "是" --> G["进入对应关系判断"]
    G --> H["更新本轮覆盖索引
存在ID/候选ID -> 数据项、坐标、特征、置信度"]
    H --> B

3. 对应关系判断与需求来源生成

flowchart TD
    A["当前外设数据项"] --> B{"空间位置与内部场景
某存在基本一致？"}
    B -- "是" --> C{"空间尺寸和轮廓
基本一致？"}
    C -- "是" --> D["确认同一存在
进入特征级处理"]
    C -- "否" --> C1{"轮廓/深度显示
可能拆分、合并或层次不清？"}
    C1 -- "是" --> C2["记录细分存在子层特征需求来源
用轮廓/深度生成更细子层特征"]
    C2 --> D1["可比较部分仍进入特征级处理"]
    C1 -- "否" --> C3["记录识别类需求来源
对应关系需要重新确认"]
    C3 --> X["当前数据项需求来源已入账
继续下一数据项"]
    B -- "否" --> E{"能用空间尺寸和轮廓
在当前场景唯一找回？"}
    E -- "是" --> E1["记录跟踪类需求来源
目标存在当前空间坐标=已取得"]
    E1 --> D1
    E -- "否" --> E2["记录识别类需求来源
当前材料对应已有存在状态=已确定"]
    E2 --> X
    D1 --> D

4. 特征级处理：场景直接写入，语义只累积给治理

flowchart TD
    A["已锁定同一存在的数据项"] --> B["展开特征材料队列
位置/尺寸/轮廓/彩图/深度图/轮廓极值"]
    B --> C{"还有特征材料？"}
    C -- "否" --> Z["当前数据项处理完成
继续下一数据项"]
    C -- "是" --> D["取下一个特征材料"]
    D --> E{"该特征材料
本轮可比较？"}
    E -- "否" --> E1["记录观察类需求来源
该特征当前值=已取得/可比较"]
    E1 --> C
    E -- "是" --> F{"已有可比历史
或当前状态基准？"}
    F -- "否" --> F1["首次扫描该特征"]
    F1 --> F2["场景写入：直接更新当前特征值
建立当前状态基准"]
    F2 --> F3["治理语义累积：追加
当前状态基准已建立"]
    F3 --> C
    F -- "是" --> G["比较内部基准
与外设当前特征值"]
    G --> H{"当前特征值
发生变化？"}
    H -- "否" --> H1["场景写入：刷新必要当前值
和下一轮基准"]
    H1 --> C
    H -- "是" --> I["场景写入：直接更新内部场景当前特征值
刷新当前状态基准/下一轮基准"]
    I --> I1["治理语义累积：追加状态信息
状态变化候选交给内部治理/因果补完"]
    I1 --> C

5. 内部已有存在未被本轮数据覆盖：可实现判定链

flowchart TD
    A["外设数据集全量处理完成"] --> B["建立内部存在关注集合"]
    B --> B1["来源：扫描需求目标存在
当前场景活动存在
上轮基准中仍标记为当前场景的存在"]
    B1 --> C["读取判定变量"]
    C --> C1["本轮覆盖状态
有对应数据项 / 无对应数据项"]
    C --> C2["空间找回候选数
尺寸+轮廓相似但坐标不同的数据项数量"]
    C --> C3["遮蔽证据状态
上一坐标区域是否被其它深度/轮廓材料占据"]
    C --> C4["子层特征证据状态
遮蔽、拆分、合并、层次是否足够判断"]
    C --> C5["观察保持状态
该存在是否仍需在当前场景持续确认"]
    C1 --> D{"本轮覆盖状态
有对应数据项？"}
    D -- "是" --> Z["已由数据项处理链处理"]
    D -- "否" --> E{"观察保持状态
仍需确认？"}
    E -- "否" --> E1["场景写入：更新该存在
本轮覆盖状态=未覆盖但无需保持"]
    E1 --> H["进入本轮汇总"]
    E -- "是" --> F{"空间找回候选数
是否等于1？"}
    F -- "是" --> F1["记录跟踪类需求来源
用唯一候选取得新空间坐标"]
    F1 --> H
    F -- "大于1" --> F2["记录细分存在子层特征需求来源
多候选需用轮廓/深度细分"]
    F2 --> H
    F -- "等于0" --> G{"遮蔽证据状态
是否成立？"}
    G -- "是" --> G1{"子层特征证据
是否足够？"}
    G1 -- "足够" --> G2["场景写入：更新覆盖/可见性状态
遮蔽或暂不可见候选"]
    G2 --> G3["治理语义累积：追加遮蔽/暂不可见状态信息"]
    G3 --> H
    G1 -- "不足" --> G4["记录细分存在子层特征需求来源
需要用轮廓/深度确认遮蔽层次"]
    G4 --> H
    G -- "否" --> G5["记录跟踪类需求来源
无覆盖且无遮挡证据，需取得新坐标"]
    G5 --> H
    Z --> H

外设当前数据集引用"]
    C --> C2["处理闭合证据
数据项总数 / 已处理数据计数"]
    C --> C3["场景写入摘要
已更新当前特征值 / 当前基准 / 覆盖状态"]
    C --> C4["治理状态信息集合
状态基准建立 / 状态变化 / 遮蔽候选"]
    C --> C5["需求来源集合

    C --> C6["临时证据引用

    D -- "是" --> F["语义输出字段
输出类型=空信息

    E --> G["内部治理接收
状态信息链"]
    F --> H["内部治理接收
空信息 + 需求来源 + 处理证据"]
    C5 --> I["需求生成 -> 任务创建 -> 任务筹办 -> 方法选择"]
    I --> I1["可选方法
识别 / 跟踪 / 观察 / 细分存在子层特征 / 其它方法"]
    G --> Z["返回运行存在
治理语义结果"]
    H --> Z
    I1 --> Z

7. 扫描内部硬边界

flowchart TD
    A["扫描本能方法"] --> B["必须：外设数据集
所有数据项全量处理"]
    A --> C["必须：流程开始后先做
上游契约错误检测"]
    A --> D["必须：可确认的场景数据
在处理中途直接写入内部场景"]
    A --> E["必须：未覆盖分支
用明确变量判定"]
    A --> F["必须：语义输出
只供内部治理使用"]
    A --> G["允许：处理数据时生成
观察/识别/跟踪/细分子层需求来源"]
    A -.-> H["禁止：把治理语义输出
当作最后回写场景的通道"]
    A -.-> I["禁止：凭空判断
需要取得新坐标"]
    A -.-> J["禁止：把上游错误
当作普通需求来源或空信息"]
    A -.-> K["禁止：硬性扫描范围约束
导致数据项不处理"]
    A -.-> L["禁止：缺口一出现
就返回空信息"]
    A -.-> M["禁止：静默丢弃
外设数据项"]
    A -.-> N["禁止：直接创建新存在
或直接调用观察/识别/跟踪"]
