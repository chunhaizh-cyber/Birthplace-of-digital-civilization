状态机口径

stateDiagram-v2
    [*] --> 待筹办
    待筹办 --> 筹办中: 调度筹办工作项
    筹办中 --> 就绪: 方法可执行
    就绪 --> 排队中: 入执行队列
    排队中 --> 执行中: 派发执行工作项
    执行中 --> 执行中: 持续观察批次推进, 有推进未达成, 批次结果已提交
    执行中 --> 待重筹办: 目标/对象/参数/方法/约束变化, 或无推进未达成
    执行中 --> 等待中: 缺条件 / 等子需求 / 阻塞派生
    执行中 --> 完成: 目标结果符合
    执行中 --> 失败: 动作失败且无恢复路径
    待重筹办 --> 筹办中: 重新填充候选集并选择方法
    等待中 --> 待重筹办: 条件更新或子需求回写
    完成 --> 已结算: 完成后价值结算后处理
    已结算 --> [*]
    失败 --> [*]

当前代码落点

私有_任务推进回执是持续观察批次推进 识别执行阶段的持续观察批次推进；命中时任务状态推导为 执行中，下一步去向进入运行。正式价值结算仍要求任务完成后走结算链。
