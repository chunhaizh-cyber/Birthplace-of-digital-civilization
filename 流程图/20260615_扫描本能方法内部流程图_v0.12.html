扫描本能方法内部流程图 v0.12

扫描维护当前场景事实可用性；函数返回运行虚拟存在指针，状态信息、缺口和空信息写入输出结果场景。扫描只消费已合法外设数据项，不从原始材料生产新观察特征。

0. 定位与返回信息

flowchart TD
    A["上级治理需求"] --> B["需要当前场景事实可用性"]
    B --> C["扫描目标
维护当前场景中已知存在的当前状态"]
    C --> D["输入
自我内部场景指针
已合法外设当前数据集"]
    D --> E["执行中写场景
当前状态值 / 当前基准 / 状态动态"]
    E --> F["输出结果场景
状态信息 / 信息缺口 / 空信息
写入摘要 / 处理闭合证据"]
    F --> G["函数返回
扫描方法运行虚拟存在指针"]
    G -.-> H["禁止
返回裸状态码
返回裸错误码
把语义输出当 C++ 返回值"]

1. 主链与诊断旁路

flowchart TD
    A["扫描方法启动"] --> B["建立扫描方法运行虚拟存在"]
    B --> C["读取输入参数场景

    C --> D["展开外设数据项队列"]
    D --> E{"还有外设数据项？"}
    E -- "有" --> F["取出数据项
已取出计数加一"]
    F --> G["解析已合法数据项
位置 / 尺寸 / 轮廓 / 彩图 / 深度图 / 轮廓极值"]
    G --> H["判断对应关系并更新覆盖索引"]
    H --> I["处理该数据项可比较特征"]
    I --> J["闭合该数据项
已闭合计数加一"]
    J --> E
    E -- "无" --> K["处理未被覆盖的内部已知存在"]
    K --> L["构造输出结果场景
同步运行虚拟存在"]

    A -. "仅诊断构建" .-> P["预编译上游契约诊断"]
    P -. "发现上游错误" .-> Q["逻辑错误日志 / 弹窗
不进入普通需求分支"]

4. 未覆盖内部存在

flowchart TD
    A["内部已知存在未被本轮覆盖"] --> B["读取当前场景既有状态 / 动态"]
    B --> C["预测当前应在空间坐标"]
    C --> D{"预测位置有对应数据项？"}
    D -- "有" --> E["已由数据项链处理"]
    D -- "无" --> F{"存在正在移动？"}
    F -- "是" --> G["闸门5
预测坐标是否在视野外"]
    G -- "视野外" --> H["写空间位置当前值=预测坐标
来源不写入空间位置值"]
    H --> I["记录移动出视野状态 / 动态证据"]
    G -- "仍在视野内" --> J["进入遮蔽覆盖判断"]
    F -- "否" --> K{"自我移动或中间存在移动
有证据？"}
    K -- "有" --> J
    K -- "无" --> L["写消失状态
消失=突然不见了"]
    J --> M["闸门6
遮蔽 / 覆盖证据"]
    M -- "成立" --> N["闸门7
子层特征证据足够？"]
    N -- "足够" --> O["写遮蔽 / 覆盖状态"]
    N -- "不足" --> P["记录信息缺口
需要子层特征"]
    M -- "不成立" --> L
    M -- "证据不足" --> P

5. 运行虚拟存在与治理输出

flowchart TD
    A["扫描处理完成"] --> B["同步扫描方法运行虚拟存在"]
    B --> B1["身份来源特征
运行ID / 来源需求 / 来源任务 / 当前场景"]
    B --> B2["进度特征
数据项总数 / 取出计数 / 解析计数 / 闭合计数"]
    B --> B3["覆盖与写入特征
覆盖索引 / 冲突数量 / 写入摘要 / 批次状态"]
    B --> B4["缺口与证据特征
信息缺口 / 临时证据 / 值域冲突 / 视野外证据"]
    B --> C["构造输出结果场景"]
    C --> D{"治理状态信息集合为空？"}
    D -- "否" --> E["语义输出=状态信息
附写入摘要和证据引用"]
    D -- "是" --> F["语义输出=空信息
仍保留缺口集合 / 写入摘要 / 处理证据"]
    C --> G["信息缺口集合
作为需求来源进入需求生成"]
    E --> H["内部治理接收"]
    F --> H
    G -. "只能经任务链" .-> I["需求生成 -> 任务创建 -> 任务筹办 -> 方法选择"]
关键边界： 扫描不直接调用观察、识别或跟踪；缺口只能进入需求、任务、方法闭环。 预测坐标可以写入空间位置当前值，但来源和视野外状态只能写入状态信息、动态证据或临时证据。 局部 C++ 上下文只是扫描方法运行虚拟存在特征的缓存视图，不是新的权威上下文结构。
