内部循环四模块流程图 v0.1

总体链路：自我产生需求 -> 生成任务 -> 执行任务 -> 满足需求。若无法显示图形，请确认当前环境可以访问 jsDelivr 的 Mermaid 脚本。

01 自我产生需求

flowchart TD
    STATE["已入账自我状态
安全值 / 服务值 / 世界事实 / 需求状态"]
    MSG["治理消息
任务回执 / 派生需求消息 / 自检报告 / 观察事实"]
    EMOTION["情绪模块（待完善）
分析安全值变化 / 因果值变化 / 压力信息"]
    EMOTION_DATA["情绪基础数据
安全变化量 / 因果变化量 / 压力状态"]
    ADMIT["事实与材料准入
只消费已入账事实和合格材料"]
    MIRROR["根需求状态镜像
读取安全值 / 服务值当前状态"]
    ROOT_GAP["根缺口与方向重判
安全 / 服务目标差只说明缺口"]
    DIR["目标方向计算
目标方向 = 目标值 - 当前值
只取 >0 / =0 / <0"]
    GLOBAL_PRESSURE["全循环压力账本 / 压力值
需求 / 任务 / 批准 / 执行 / 满足共同写入"]
    PRESSURE_DATA["压力材料读取
全循环压力值 / 自检异常 / 治理负荷"]
    PRESSURE["压力读取与情绪化解释
影响紧迫度和调度优先级"]
    GAP_CHECK{"是否存在
未满足目标或治理缺口?"}
    DEMAND_BUILD["生成或刷新需求节点
根需求 / 派生需求 / 维护需求"]
    WEIGHT["需求估权与活动集刷新
安全权重 / 服务权重 / 活跃状态"]
    MAIN_NEED["选择当前主需求
为什么做 / 做哪个 / 优先做什么"]
    IDLE["无新需求或已满足
待机 / 低频自检 / 等待新事实"]

    SELF_CHECK["自检旁路
只发现缺失或差距"]
    PERIPHERAL["外设旁路
观察材料先提交入账"]
    REJECT["拒绝入树
缺目标宿主 / 特征 / 当前值 / 目标值 / 来源证据"]
    FAIL_EXIT["失败退出事实
拒绝 / 阻断 / 不可比 / 无推进"]

    STATE --> EMOTION
    MSG -->|进入治理前采样| EMOTION
    SELF_CHECK -->|压力与缺失材料| EMOTION
    PERIPHERAL -->|外部刺激材料| EMOTION
    EMOTION --> EMOTION_DATA --> ADMIT
    ADMIT --> MIRROR --> ROOT_GAP --> DIR --> GAP_CHECK
    GLOBAL_PRESSURE --> PRESSURE_DATA
    ADMIT --> PRESSURE_DATA --> PRESSURE --> WEIGHT
    GLOBAL_PRESSURE -.下一轮压力值.-> EMOTION
    GAP_CHECK -->|是| DEMAND_BUILD --> WEIGHT --> MAIN_NEED
    GAP_CHECK -->|否| IDLE
    ADMIT -->|材料不合格| REJECT --> FAIL_EXIT --> GLOBAL_PRESSURE

02 生成任务

flowchart TD
    MAIN_NEED["当前主需求
来自需求树治理结果"]
    TARGET_CHECK{"需求目标完整?"}
    TARGET_DETAIL["目标宿主 + 目标特征类型
当前状态 + 目标状态 + 满足关系"]
    TASK_EXISTS{"已有未终结任务
承接该需求?"}
    INTENT["自我线程生成任务发起 / 调度意图
不裸写任务状态"]
    TASK_IF["任务管理界面线程
接收任务治理请求"]
    CREATE["创建或复用任务
任务信息节点 + 任务虚拟存在"]
    INIT["初始化任务承接信息
来源需求 / 权重上限 / 初始状态"]
    QUEUE["放入任务管理队列
待筹办 / 待执行 / 等待"]
    RECEIPT["任务创建或承接回执
上报自我线程"]
    WAIT["等待已有任务回执
不重复创建"]
    REJECT["拒绝任务化
需求目标不完整或已截止"]
    FAIL_EXIT["失败退出事实
拒绝任务化 / 创建失败 / 等待复用失效"]
    PRESSURE_SOURCE["压力材料上报
任务堆积 / 任务无法创建 / 重复等待"]
    GLOBAL_PRESSURE["全循环压力账本 / 压力值
任务生成失败写入同一压力账"]

    MAIN_NEED --> TARGET_CHECK
    TARGET_CHECK -->|是| TARGET_DETAIL --> TASK_EXISTS
    TARGET_CHECK -->|否| REJECT --> FAIL_EXIT --> PRESSURE_SOURCE
    TASK_EXISTS -->|否| INTENT --> TASK_IF --> CREATE --> INIT --> QUEUE --> RECEIPT
    TASK_EXISTS -->|是| WAIT
    WAIT -->|等待失效或任务堆积| FAIL_EXIT
    PRESSURE_SOURCE --> GLOBAL_PRESSURE
    WAIT --> RECEIPT

03 执行任务

flowchart TD
    TASK_QUEUE["任务管理队列
待筹办 / 就绪 / 待执行"]
    STATE_READ["读取任务状态和来源需求
任务目标来自对应需求"]
    PREP["任务筹办普通函数
找路径 / 找方法 / 找条件"]
    CANDIDATE["填充候选方法集
先填充候选集"]
    SELECT["选择当前方法
单候选可绑定, 多候选按规则选择"]
    READY_CHECK{"条件 / 参数 / 输入场景
是否闭合?"}
    SYNC_PREP["同步筹办回执到任务
就绪 / 等待 / 缺口"]
    APPROVAL_REQ["执行批准申请
当前任务 / 当前方法 / 输入参数场景 / 风险价值依据"]
    APPROVAL["批准执行模块
执行前治理闸门"]
    APPROVAL_GATE{"是否批准执行?"}
    APPROVAL_RECEIPT["批准执行回执
批准 / 暂缓 / 拒绝 / 补证据"]
    EXEC["任务执行普通函数
只执行已绑定当前方法的叶子任务"]
    ACTION["当前方法动作入口
读取可执行输入参数场景"]
    OUTPUT["输出结果场景 / 运行存在
事实材料, 不是任务状态权威"]
    DYNAMIC["方法动作动态
由当前方法造成事实变化"]
    SYNC_EXEC["同步执行或批准回执到任务
完成建议 / 执行缺口 / 等待 / 拒绝"]
    STATE_SUBMIT["提交任务状态变化
任务完成 / 等待 / 待重筹办"]
    UP_MSG["任务管理上行消息
结果状态 / 派生需求 / 观察事实"]

    PREP_GAP["筹办缺口
无确定候选 / 方法不可用 / 缺入口 / 条件不满足"]
    APPROVAL_GAP["执行批准缺口
风险未闭合 / 价值依据不足 / 状态已变化"]
    EXEC_GAP["执行缺口
输出不满足来源需求 / 需要派生更细需求"]
    REPLAN["重筹办 / 等待 / 派生需求消息
交给自我线程裁决入树"]
    FAIL_EXIT["失败退出事实
筹办缺口 / 执行批准缺口 / 执行缺口 / 阻塞 / 反复重筹办"]
    PRESSURE_SOURCE["压力材料上报
任务无法推进 / 方法不可用 / 批准被拒 / 队列堆积"]
    GLOBAL_PRESSURE["全循环压力账本 / 压力值
批准 / 筹办 / 执行失败写入同一压力账"]

    TASK_QUEUE --> STATE_READ --> PREP --> CANDIDATE --> SELECT --> READY_CHECK
    READY_CHECK -->|是| SYNC_PREP --> APPROVAL_REQ --> APPROVAL --> APPROVAL_GATE
    APPROVAL_GATE -->|批准| APPROVAL_RECEIPT --> EXEC --> ACTION --> OUTPUT --> DYNAMIC --> SYNC_EXEC --> STATE_SUBMIT --> UP_MSG
    APPROVAL_GATE -->|暂缓 / 拒绝 / 补证据| APPROVAL_GAP --> SYNC_EXEC
    READY_CHECK -->|否| PREP_GAP --> SYNC_PREP --> REPLAN --> UP_MSG
    OUTPUT -->|未满足来源需求| EXEC_GAP --> SYNC_EXEC
    PREP_GAP --> FAIL_EXIT
    APPROVAL_GAP --> FAIL_EXIT
    EXEC_GAP --> FAIL_EXIT
    REPLAN -->|反复重筹办或等待失效| FAIL_EXIT --> PRESSURE_SOURCE --> GLOBAL_PRESSURE --> UP_MSG

04 满足需求

flowchart TD
    UP_MSG["任务完成或结果回执
来自任务管理线程"]
    SOURCE_NEED["解析来源需求
目标宿主 / 目标特征 / 当前状态 / 目标状态"]
    OUTPUT_FACT["读取输出事实和证据
输出结果场景 / 方法动作动态 / 任务回执"]
    COMPARE_READY{"结果与目标
是否可比较?"}
    TARGET_DIR["目标方向
目标值 - 当前值"]
    ACTUAL_DIR["实际方向
结果值 - 初始值"]
    DIR_GATE{"方向一致性
是否朝目标收束?"}
    SAT_CHECK{"目标特征
是否满足?"}
    WRITEBACK["回写需求满足
需求域正式提交入口"]
    LEAF_CHECK{"来源任务
是否可结算叶子任务?"}
    SETTLE["结算叶子任务价值
安全值 / 服务值合法增量"]
    LEDGER["更新自我状态账本
需求账 / 结算账 / 最近结算任务"]
    NEXT["下一轮需求重判
重新评估安全 / 服务 / 派生需求"]

    NO_PROGRESS["无推进
回到缺口 / 等待 / 重筹办"]
    CONFLICT["反向或不可比
拒绝回写 / 记录错误 / 冲突材料"]
    GAP["派生需求或父任务重筹办
由自我线程裁决"]
    NO_SETTLE["只回写需求
不做价值结算"]
    FAIL_EXIT["失败退出事实
不可比 / 反向 / 无推进 / 未满足 / 拒绝结算"]
    PRESSURE_SOURCE["压力材料入账
满足需求失败写入同一压力账"]
    GLOBAL_PRESSURE["全循环压力账本 / 压力值
供下一轮情绪模块读取"]

    UP_MSG --> SOURCE_NEED --> OUTPUT_FACT --> COMPARE_READY
    COMPARE_READY -->|可比较| TARGET_DIR --> DIR_GATE
    COMPARE_READY -->|不可比较| CONFLICT
    OUTPUT_FACT --> ACTUAL_DIR --> DIR_GATE
    DIR_GATE -->|同向 / 有推进| SAT_CHECK
    DIR_GATE -->|零推进| NO_PROGRESS --> GAP
    DIR_GATE -->|反向| CONFLICT --> GAP
    SAT_CHECK -->|满足| WRITEBACK --> LEAF_CHECK
    SAT_CHECK -->|未满足| GAP
    LEAF_CHECK -->|是| SETTLE --> LEDGER --> NEXT
    LEAF_CHECK -->|否| NO_SETTLE --> LEDGER
    NO_PROGRESS --> FAIL_EXIT
    CONFLICT --> FAIL_EXIT
    GAP --> FAIL_EXIT
    NO_SETTLE -->|应结算但证据不足| FAIL_EXIT
    FAIL_EXIT --> PRESSURE_SOURCE --> GLOBAL_PRESSURE --> LEDGER
