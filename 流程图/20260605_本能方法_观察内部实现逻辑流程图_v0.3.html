本能方法：观察内部实现逻辑流程图 v0.3

关键口径

观察 = 根据外设现实特征发现外设观察存在，或完善已有观察存在 / 待复验存在的特征集合。
识别 = 比较自我所在场景存在特征与外设观察存在特征，判断是否同一。

观察输出特征

宿主特征类型特征值说明
外设观察存在外设观察存在发现状态已发现 / 未发现外设特征已经组织出观察层面的存在。
外设观察存在基准状态未建立 / 已建立第一帧只建立基准。
外设观察存在观察完成状态未完成 / 部分完成 / 已完成 / 证据不足来自多帧稳定复现判断。
外设观察存在特征补全状态未补全 / 部分补全 / 已补全表示本次观察是否完善了特征集合。
外设观察存在新增特征类型数量 / 新增特征值数量>= 0本次观察补入的现实特征。
外设观察存在可比较特征类型集合颜色 / 深度 / 空间 / 轮廓 / 掩码 / 点集等供识别比较使用。
外设观察存在多帧稳定证据帧数>= 0供识别判断证据是否足够。

边界

观察能回答外设当前看到了哪些可稳定复现的特征，以及这些特征是否能组织成外设观察存在或补充到已有特征集合。它不能直接回答是否为自我所在场景中已经登记的同一个存在；需要时进入识别任务。
