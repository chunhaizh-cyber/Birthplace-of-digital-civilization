本能方法：扫描内部实现逻辑流程图 v0.1

扫描为了获取动态；无归属特征值没有比较对象，不能生成状态或动态，必须派生识别任务把特征值归入存在。

流程图

flowchart TD
    START["扫描本能方法启动
目标: 获取动态"]
    IN0["读取输入现实特征
扫描范围 / 已归属存在集合 / 上一轮可比特征快照"]
    IN1["读取当前可视范围特征值
来自观察结果场景或扫描提交包组织结果"]
    G0{"扫描范围内是否有特征值?"}
    NO_MATERIAL["输出: 扫描材料可用状态=0
观察质量缺口数量>0"]

    PART["按归属状态分流当前特征值"]
    U0{"存在无归属特征值?"}
    U1["输出: 无归属特征值数量 > 0"]
    U2["输出: 无归属特征值动态不可生成状态 = 1"]
    U3["派生识别任务
目标: 无归属特征值归入存在"]
    U4["等待识别提交入口
可观测单位 -> 存在映射表更新"]

    A0["读取已归属特征值
目标宿主=已稳定对应存在"]
    A1{"是否有基准或上一轮可比值?"}
    FIRST["首次扫描
提交发现存在 / 发现特征事实
不得生成变化动态"]
    COMPARE["同一存在 + 同一特征类型
比较当前值与基准 / 上一轮值"]
    C0{"比较结果是否变化?"}
    DYN["生成动态
观察存在特征值变化事实
存在状态变化动态"]
    STATIC["输出本轮无变化事实
动态发现状态=已明确"]

    O0["输出: 扫描完成状态"]
    O1["输出: 观察目标动态发现状态"]
    O2["输出: 已知存在变化动态生成状态"]
    O3["输出: 观察存在特征值变化事实提交状态"]
    O4["输出: 下一轮扫描基准快照"]

    B0["边界
扫描不能直接确认新存在"]
    B1["边界
无归属特征值不能生成状态 / 动态"]
    B2["边界
第一次扫描不是变化动态"]
    B3["边界
扫描结果不反推全场景明确"]

    subgraph INPUT["输入"]
        START --> IN0 --> IN1 --> G0
        G0 -->|否| NO_MATERIAL
    end

    subgraph ATTR["归属闸门"]
        G0 -->|是| PART --> U0
        U0 -->|是| U1 --> U2 --> U3 --> U4 --> PART
        U0 -->|否| A0
    end

    subgraph SCAN["动态扫描"]
        A0 --> A1
        A1 -->|否| FIRST --> O0
        A1 -->|是| COMPARE --> C0
        C0 -->|有变化| DYN --> O2 --> O3 --> O4 --> O0
        C0 -->|无变化| STATIC --> O1 --> O4 --> O0
    end

    subgraph RULES["硬边界"]
        B0 -.约束.-> U3
        B1 -.约束.-> U2
        B2 -.约束.-> FIRST
        B3 -.约束.-> O0
    end

    class PART,A0,FIRST,COMPARE,DYN,STATIC process;
    class U1,U2,U3,U4,O0,O1,O2,O3,O4 output;
    class G0,U0,A1,C0 gate;
    class NO_MATERIAL,B0,B1,B2,B3 warn;

现实层特征口径

位置目标宿主特征类型特征值
输入当前扫描范围扫描范围明确状态1
输入当前扫描范围已归属可扫描存在数量>0
输入当前扫描范围可视范围特征归属分区状态1
输入当前扫描范围 / 已归属存在上一轮可比特征快照非空时可生成变化动态
闸门当前扫描范围无归属特征值数量0 才允许全部进入动态比较
输出当前扫描范围无归属特征值动态不可生成状态1 表示必须先识别
输出当前扫描范围无归属特征值归入存在需求派生状态1/0
输出当前扫描范围 / 已归属存在观察目标动态发现状态已明确 / 未明确
输出已归属存在已知存在变化动态生成状态1/0
输出已归属存在观察存在特征值变化事实提交状态1/0/2/3
输出当前扫描范围下一轮扫描基准快照指针 / 引用型特征值
发现无归属特征值 = 无归属特征值数量 > 0 -> 无归属特征值动态不可生成状态 = 1 -> 派生识别任务 -> 识别任务目标: 无归属特征值归入存在
