## 1. 核心定义

`当前场景特征值明确状态` 是历史目标名，在本层应解释为：

```text
当前观察范围内所有有效可观测单位，是否都已经能稳定对应到存在。
```

它不是：

```text
安全意义明确；
风险状态明确；
自我边界影响明确；
特征质量全部达标；
所有特征都能直接用于安全评估；
观察完成后自动满足需求。
```

本层只关注：

```text
可观测单位 -> 存在
```

不关注：

```text
存在是否危险；
存在是否靠近自我；
存在是否影响服务；
特征是否进入安全因果候选；
安全值、服务值或需求满足。
```

自我层没有“帧”的概念。帧只属于外设材料来源，例如 D455 外设帧、外设帧ID、外设采集时间。自我层承接的是：

```text
当前观察材料集；
当前观察范围；
可观测单位；
可观测单位到存在的对应事实。
```

接口层本能方法可以使用外设帧作为技术参数和材料索引，例如当前外设帧、上一外设帧、来源外设帧ID、外设采集时间。该使用只允许停留在接口 / 外设材料组织层；输出到自我需求、事实和场景层时，必须转换成观察材料集、观察范围、可观测单位和对应事实。

因此，本规范把原先过重的安全因果判定下移到后续层。当前层的正式输出应是事实：

```text
当前观察范围可观测单位存在对应事实。
```

## 2. 现实前提

现实世界中，每个有效可观测单位必然来自某个存在。

所以：

```text
未知区域不能作为最终归属。
```

系统内部可以临时记录：

```text
未识别；
待确认；
冲突；
证据不足；
需补观察；
需重识别。
```

但这些只是识别过程状态或缺口状态，不是最终闭合归属。

最终闭合归属只能表达为：

```text
有效可观测单位已经稳定对应到某个存在。
```

地面、墙面、桌面、空气中可观测介质、固定支架、无效材料承载体等，不得写成“背景”认知对象。可观测且可归属者应作为静止存在、环境存在或低动态存在处理；确实无效或不可观测者应作为材料排除事实处理。不得用“未知区域已记录”替代存在对应闭合。

## 3. 当前观察范围可观测单位存在对应事实

本层新增或明确的事实口径：

```text
当前观察范围可观测单位存在对应事实
```

最小字段：

```text
场景ID；
观察材料集ID；
来源外设ID；
来源报告ID；
来源外设帧ID；
来源材料页ID；

当前观察范围有效可观测单位数量；
已稳定对应存在可观测单位数量；
未稳定对应存在可观测单位数量；
多重对应冲突可观测单位数量；
稳定对应存在数量；

可观测单位到存在映射表；
映射稳定性状态；
映射缺口原因掩码；
扫描可启动状态；
当前观察范围可观测单位存在对应闭合状态。
```

这个事实回答三件事：

```text
1. 当前观察范围有多少个有效可观测单位；
2. 这些可观测单位是否都能稳定对应到存在；
3. 当前观察范围稳定对应出了多少个存在。
```

## 4. 明确状态判定

`当前场景特征值明确状态` 可以由 `当前观察范围可观测单位存在对应事实` 派生，但不得直接由 D455 报告、材料页、外设帧、像素簇、扫描包或跟踪包满足。

最低判定公式：

```text
当前场景特征值明确状态 = 已明确
当且仅当：

当前观察范围有效可观测单位数量 > 0
AND 已稳定对应存在可观测单位数量 == 当前观察范围有效可观测单位数量
AND 未稳定对应存在可观测单位数量 == 0
AND 多重对应冲突可观测单位数量 == 0
AND 稳定对应存在数量 > 0
```

如果当前观察范围有效可观测单位数量为 0，不能直接写全场景明确；只能写：

```text
当前观察范围无有效可观测单位事实
```

后续是否构成空场景明确，必须由观察范围、观察能力和场景覆盖事实另行裁决。

## 5. 扫描可启动阈值

上级需求不需要等待全场景 100% 对应闭合后才启动扫描。

扫描可启动阈值：

```text
稳定对应存在数量 >= 1
```

也就是说：

```text
只要当前观察范围已有至少一个稳定对应存在，
就可以开始扫描该存在的状态、变化和动态。
```

这和 `当前场景特征值明确状态=已明确` 是两件事：

```text
扫描可启动：
    至少有一个稳定对应存在。

当前场景特征值明确：
    当前观察范围全部有效可观测单位都稳定对应存在。
```

因此不到 100% 闭合时，不能冒充全场景明确，但已经稳定对应的存在可以进入扫描和动态关注。

## 6. 识别、扫描、跟踪边界

### 识别

识别只做：

```text
判断当前获取到的存在材料有没有见过；
见过则输出已有存在指针；
没见过则输出空指针；
暴露未稳定对应、冲突、证据不足和需补观察缺口。
```

识别不创建新存在，不补写一阶特征值，不产生被观察存在的状态和动态。当前观察范围可观测单位存在对应事实由提交入口消费识别输出、观察材料和过程证据后生成；不得把该对应事实当成识别方法的语义输出。

注意这里的“状态和动态”指被观察存在的业务状态、位置变化、趋势变化、遮挡、丢失等存在状态 / 存在动态；方法运行自身仍可按 001 规范留下方法动作动态作为因果账本记录，但该动作动态不得冒充被观察存在的状态或动态。

识别输出不是：

```text
当前观察范围可观测单位存在对应事实；
存在当前状态；
存在变化动态；
安全因果候选；
风险状态明确；
需求满足。
```

识别输出是：

```text
已有存在指针 | 空指针。
```

### 扫描

扫描从自我内部场景指针中的稳定对应存在开始，以外设当前获取的数据集作为本轮比较材料。

扫描负责：

```text
读取自我内部场景指针、稳定对应存在集合和内部场景基准；
读取已合法进入系统的外设当前获取数据集、当前候选材料和材料质量状态；
按对应关系、空间位置、空间尺寸、轮廓和当前特征值比较规则进行比较；
用已合法外设数据项更新已稳定对应存在的当前状态值 / 当前特征值；
无可比历史时建立当前状态基准，输出当前状态信息或空信息；
有可比历史且发生变化时生成该存在的状态信息、特征变化和状态变化；
比较过程中发现无法继续比较时，在输出结果场景记录结构化需求来源。
```

扫描写入 / 输出：

```text
首次扫描：
    来自已合法外设数据项的当前状态值 / 当前特征值；
    当前状态基准；
    状态信息或空信息；
    来源动作动态引用；

后续扫描：
    存在当前特征状态；
    存在特征变化事实；
    位置 / 范围 / 深度 / 遮挡 / 丢失 / 稳定性状态信息；
    状态变化信息；
    对应关系 / 坐标 / 当前特征值 / 材料质量等需求来源。
```

这里的“更新 / 写入当前特征值”不表示扫描从原始外设材料生产新的观察特征值。若材料尚未被观察方法或提交入口处理成合法外设数据项，扫描不得写入已确认存在，只能在输出结果场景记录结构化缺口。

第一次扫描不得因为缺少历史基准而伪造变化动态，也不得生成发现存在或发现特征语义。它只能说明：

```text
当前观察范围内这个已稳定对应存在的当前特征值和当前状态基准已经取得。
```

只有自我内部场景中存在上一轮、历史基准或其他可比观察材料集时，才允许生成变化动态。

扫描不负责：

```text
确认新存在；
把未稳定特征强行归属；
证明全场景明确。
```

### 跟踪

跟踪从指定稳定存在或目标种子开始。

跟踪负责：

```text
持续观察指定存在；
输出目标当前状态、目标变化动态、连续性、遮挡、丢失和趋势。
```

跟踪不负责：

```text
非目标存在；
全场景扫描；
全场景特征值明确。
```

## 7. 三类外设提交包

D455 外设线程只供材料和提交包，不写自我账本。

```text
识别提交包：
    提供当前观察范围有效可观测单位、候选映射、冲突和缺口材料；
    供自我生成当前观察范围可观测单位存在对应事实。

扫描提交包：
    针对已稳定对应存在和本轮外设当前数据集，提供当前特征、材料质量、后续变化、遮挡、丢失和无法比较材料；
    供扫描与自我内部场景基准比较，并由提交入口写当前状态事实、当前特征值、特征值变化事实，或记录结构化需求来源。

跟踪提交包：
    针对指定稳定存在，提供连续特征、趋势、遮挡和丢失材料；
    供提交入口写目标状态和目标变化动态。
```

外设提交包都不是账本提交入口。

## 8. 自我本能方法与提交入口

第一版链路：

```text
外设识别提交包
-> 自我_识别外设观察材料
-> 当前观察范围可观测单位存在对应事实
-> 当前场景特征值明确状态 / 扫描可启动状态

外设扫描提交包
-> 自我_扫描已识别区域
-> 扫描结果场景
-> 提交_观察存在当前状态事实 / 提交_观察存在特征值变化事实
-> 当前状态信息 / 当前特征值 / 特征值变化事实可读

外设跟踪提交包
-> 自我_跟踪指定存在
-> 跟踪结果场景
-> 提交_指定存在跟踪事实
-> 目标状态和目标变化动态可读
```

应补或明确的提交入口：

```text
提交_当前观察范围可观测单位存在对应事实
提交_观察存在当前状态事实
```

该入口消费识别组织结果，写入：

```text
当前观察范围有效可观测单位数量；
已稳定对应存在可观测单位数量；
未稳定对应存在可观测单位数量；
多重对应冲突可观测单位数量；
稳定对应存在数量；
可观测单位到存在映射表；
当前观察范围可观测单位存在对应闭合状态；
扫描可启动状态。
```

`提交_观察存在当前状态事实` 消费扫描结果，写入：

```text
目标存在；
来源外设帧ID；
当前特征快照；
当前状态信息或空信息；
当前状态基准；
状态时间；
来源动作动态。
```

`提交_观察存在当前状态事实` 不得写成发现事实，也不得写成变化动态。只有存在上一外设帧、上一轮或其他可比历史观察材料集且特征值发生变化时，才可转入 `提交_观察存在特征值变化事实`。

`提交_当前观察范围可观测单位存在对应事实` 不得写：

```text
存在状态；
存在动态；
```

上述两个入口均不得写：

```text
安全值；
服务值；
需求满足；
风险状态明确。
```

## 9. 与安全因果链的关系

安全因果链可以反推出 `当前场景特征值明确状态` 这个需求，但本层的满足标准不是安全意义明确，而是特征值到存在的稳定对应事实闭合。

后续安全评估如果需要自我边界、距离、靠近、遮挡、趋势等信息，应继续读取：

```text
扫描产生的存在状态和变化动态；
跟踪产生的目标状态和目标变化动态；
自我边界参照；
坐标转换；
安全因果模板。
```

这些是下游安全解释层，不得塞回本层作为 `当前场景特征值明确状态` 的最低标准。

## 10. 标准子需求生长链

第一版标准子链应调整为两段。第一段只服务 `当前场景特征值明确状态`，第二段由稳定对应存在事实触发扫描事实 / 动态取得；扫描不是 `当前场景特征值明确状态` 的完成子需求。

```text
当前场景特征值明确状态
└── OR组满足状态：可观测单位存在对应取得路径
    └── D455观察确认路径：方法路径完成状态
        ├── 材料型子需求
        │   ├── 当前观察特征帧取得状态
        │   └── 外设观察材料可回查状态
        ├── 对应事实型子需求
        │   ├── 当前观察范围有效可观测单位计数事实取得状态
        │   ├── 当前观察范围可观测单位存在稳定对应事实取得状态
        │   ├── 稳定对应存在数量明确状态
        │   └── 当前观察范围可观测单位存在对应闭合状态
        └── 缺口解释子需求
            └── 当前观察范围可观测单位存在对应缺口可解释状态

当前观察范围可观测单位存在对应事实
└── 扫描可启动状态
    └── 当前观察范围稳定对应存在扫描事实 / 动态取得状态
        ├── 当前观察范围稳定对应存在扫描状态
        ├── 自我内部场景基准读取状态
        ├── 外设当前数据集取得状态
        ├── 稳定对应关系比较状态
        ├── 当前状态基准建立状态
        ├── 观察存在当前状态事实提交状态
        ├── 已知存在当前状态取得状态
        ├── 已知存在状态变化信息生成状态
        ├── 观察存在特征值变化事实提交状态
        └── 扫描比较需求来源记录状态

指定目标种子 / 指定稳定存在
└── 指定存在跟踪动态取得状态
    ├── 指定存在跟踪状态
    ├── 指定存在状态变化明确状态
    └── 指定存在跟踪事实提交状态
```

生成规则：

```text
1. 当前场景特征值明确状态只负责触发标准子链，不直接生成外设等待项。
2. OR组负责表达多种取得路径，不直接写明确状态。
3. D455观察确认路径不能停成空叶子；路径激活后必须继续生成材料型、对应事实型或缺口解释子需求。
4. 当前观察范围全部有效可观测单位稳定对应存在时，才可写当前场景特征值明确状态。
5. 稳定对应存在数量 >= 1 时，可以生成或激活扫描事实 / 动态取得需求；该需求不是当前场景特征值明确状态的完成条件。
6. 扫描事实 / 动态取得的最低输入是自我内部场景指针和已合法进入系统的外设当前获取数据集；比较项至少包括对应关系、空间位置、空间尺寸、轮廓、当前特征值和材料质量。
7. 扫描事实 / 动态取得必须区分首次扫描和后续扫描：首次扫描只用已合法外设数据项建立当前特征值和当前状态基准，不生成发现语义或变化动态；后续有可比历史且特征值变化后才生成状态变化信息和特征值变化事实。
8. 扫描比较过程中的对应关系缺口、坐标缺口、当前特征值缺口、材料质量缺口和状态变化只能记录为结构化需求来源；是否形成观察、识别、跟踪或其它需求，由需求树和任务筹办决定。
9. 跟踪动态取得只有在有目标种子或指定稳定存在时激活；该需求也不是当前场景特征值明确状态的完成条件。
10. 对应事实未全闭合时，未稳定对应部分继续走缺口解释或识别补充；已稳定对应部分可以并行走扫描事实 / 动态取得。
11. 任务管理线程只能按结构化目标特征和已入树子需求生成等待项，不得从目标特征文本猜测。
```

## 11. 生产者边界

```text
D455外设线程：
    只生产观察报告、材料页、句柄和识别 / 扫描 / 跟踪提交包。

自我识别方法：
    只返回已有存在指针或空指针；
    不生成被观察存在状态、动态或对应事实。

扫描 / 跟踪方法：
    扫描用已合法外设数据项更新已确认存在当前状态值 / 当前特征值，并输出状态信息或空信息；
    跟踪输出新空间坐标或空信息。

提交入口：
    裁决并写入对应事实、当前状态事实、扫描变化事实和跟踪事实。

安全 / 服务评估方法：
    只读取已提交事实和后续状态 / 动态；
    不把识别结果直接当安全意义。

自我线程：
    可以根据事实变化派生需求和重筹办；
    不裸写当前场景特征值明确状态。
```

## 12. 禁止规则
