# 已确认观察存在内部结构递归细分规范 20260525

上级规范：

```text
050 自我所在场景认知工作区规范20260525
```

本规范是 050 的下级细则，定义自我在已经确认一个当前帧观察存在后，如何进入该存在的内部世界，递归认知其当前可见内部结构。

核心口径：

```text
存在不是简单对象；
存在 = 外部可观测壳 + 内部世界入口。
```

存在节点在父场景中表现为一个成员；`存在.内部世界` 表现为该成员可展开的子场景。递归细分不是重新发现外部存在，而是在已确认观察存在的内部世界中继续认知当前帧可见的子存在、子结构和叶子特征块。

本阶段不得宣称：

```text
已经知道该存在完整内部世界
已经获得跨帧稳定部件
已经完成语义分类
当前帧观察结构等同于真实永久内部结构
```

## 1. 存在与内部世界关系

更精确的定义：

```text
存在节点：
    负责在父场景中占据一个位置、范围、轮廓和身份。

内部世界场景节点：
    负责承载这个存在内部的子存在、子结构、局部特征和递归认知结果。
```

也就是：

```text
存在 = 父场景中的一个东西
存在.内部世界 = 这个东西里面的一个场景
```

因此，下列内容不得直接堆在父存在普通字段里：

```text
子存在
子轮廓
子结构
叶子特征块
内部未解释区域
内部冲突区域
```

它们应进入：

```text
父存在.内部世界.成员存在集合
父存在.内部世界.未解释区域
父存在.内部世界.冲突区域
父存在.内部世界.细分状态
```

内部世界成员可以按类型区分：

```text
空间子存在
表面特征存在
纹理区域存在
深度结构存在
叶子特征块存在
未解释区域存在
冲突区域存在
```

## 2. 存储边界

当前帧观察事实和内部认知结构分两条线挂载。

```text
自我所在场景
    -> 当前观察帧存在
        -> 像素观察事实 / 像素观察存在

自我所在场景
    -> 已确认观察存在A
        -> A.内部世界
            -> A的子存在 / 子结构 / 叶子特征块
```

用途边界：

```text
观察帧存在：
    保存这次相机观察到的像素、颜色、深度、空间坐标等原始观察事实。

存在.内部世界：
    保存自我已经把这些观察事实组合、验证后形成的内部认知结构。
```

硬规则：

```text
像素观察事实在观察帧里；
认知出的子存在在父存在的内部世界里；
局部观察切片可以引用观察帧像素事实，但不得复制出失联数据。
```

每个局部像素仍必须能回到：

```text
观察帧编号 + 像素坐标 / 帧内像素编号
```

## 3. 内部世界场景基本特征

当一个存在需要进一步细分时，必须先解析或创建：

```cpp
存在.内部世界
```

内部世界至少应具备以下场景口径：

```text
内部世界.场景类型 = 存在内部世界
内部世界.所属父存在 = 当前存在
内部世界.父场景 = 当前存在所在的外部场景，可选
内部世界.坐标单位 = 与父存在一致，通常为毫米
内部世界.局部坐标原点 = 父存在范围最小点，第一阶段默认
内部世界.边界 = 父存在的范围坐标或局部边界
内部世界.成员存在集合 = 子存在集合
内部世界.接口集合 = 与父场景、观察帧、OpenGL快照的接口
内部世界.未解释区域
内部世界.冲突区域
内部世界.细分状态
内部世界.可绘制状态
```

第一阶段的最小集合：

```text
1. 场景类型
2. 所属父存在
3. 坐标单位
4. 局部坐标原点
5. 空间范围AABB
6. 成员存在集合
7. 接口集合
8. 细分状态
9. 未解释区域
10. 可绘制状态
```

## 4. 内部世界坐标口径

父存在在外部场景中至少有：

```text
存在A.中心空间坐标
存在A.范围坐标AABB
存在A.外轮廓
存在A.像素归属掩码
```

内部世界使用父存在内部局部坐标。

第一阶段采用：

```text
父存在的 AABB 最小点 = 内部世界原点
父存在的 AABB 大小 = 内部世界边界
```

坐标换算：

```text
局部X = 子点X - 父存在AABB.minX
局部Y = 子点Y - 父存在AABB.minY
局部Z = 子点Z - 父存在AABB.minZ
```

这样子存在的范围坐标应落在：

```text
0 <= 子X <= 父宽度
0 <= 子Y <= 父高度
0 <= 子Z <= 父深度
```

若后续需要以父存在中心描述内部姿态，可在接口中增加中心原点换算，但第一阶段不得混用两套未声明坐标口径。

## 5. 存在内外接口

既然 `存在.内部世界` 是场景，就必须建立它与外部场景和观察帧之间的接口。

```text
存在内外接口 {
    接口类型 = 存在内外接口 / 坐标换算接口 / 投影接口
    外部场景 = 父存在所在场景
    父存在 = 当前存在
    内部场景 = 当前存在.内部世界

    外部到内部坐标变换
    内部到外部坐标变换

    观察帧像素到内部局部坐标映射
    内部局部坐标到观察帧像素投影

    接口状态 = 已建立 / 待验证 / 失效
}
```

用途：

```text
1. 把原帧中的局部像素映射到存在内部世界。
2. 把内部子存在投影回原帧，验证像素归属。
3. 把内部子存在渲染到 OpenGL。
4. 把子存在坐标换算回父场景。
```

没有内外接口时，不允许宣称内部子存在与父场景坐标已经闭合。

## 6. 递归细分主流程

旧流程不得再写成：

```text
确认存在 -> 细分子轮廓 -> 生成子结构 -> 直接挂到父存在字段
```

新流程：

```text
确认存在
    -> 确保存在.内部世界存在
    -> 建立内外接口
    -> 将局部观察切片映射到内部世界
    -> 在内部世界中发现子存在
    -> 将子存在挂入内部世界.成员存在集合
    -> 对子存在继续递归
```

完整链路：

```text
1. 在自我所在场景中确认存在A。
2. 若需要细分A，则解析或创建 A.内部世界。
3. 建立 A所在外部场景 <-> A.内部世界 的内外接口。
4. 从当前观察帧中按 A.像素归属掩码 提取局部彩图、局部深度图、局部空间坐标。
5. 将这些局部特征映射为 A.内部世界 的观察材料。
6. 在 A.内部世界 中提取子空间候选 / 子轮廓候选。
7. 确认子存在 A1、A2、A3。
8. 将 A1、A2、A3 写入 A.内部世界.成员存在集合。
9. 若 A1 还需要细分，则进入 A1.内部世界。
10. 若局部投影边界框 <= 8*8，则停止递归，生成叶子特征块存在。
```

递归认知统一为：

```text
场景中发现存在；
进入存在的内部世界；
在内部世界中继续发现存在。
```

## 7. 存在局部观察切片

存在局部观察切片不是新相机帧，而是当前观察帧中的局部视窗和索引映射。

```text
存在局部观察切片 {
    来源观察帧
    父观察存在
    父存在内部世界
    外轮廓掩码
    像素归属掩码
    局部边界框
    局部彩图
    局部深度图
    局部空间坐标图
    局部像素索引表
    局部坐标到观察帧坐标变换
    观察帧坐标到自我场景坐标变换
    观察帧坐标到内部世界坐标变换
}
```

局部彩图、局部深度图、局部空间坐标图可以是视图、索引或快照；但每个局部像素必须能回查到原观察帧像素事实。

## 8. 子存在存储结构

内部世界成员仍然是普通存在，只是它的所在场景变为父存在的内部世界。

```text
子存在 {
    所在场景 = 父存在.内部世界
    父存在 = 当前父存在，可选
    来源观察帧
    来源局部观察切片

    存在类型 =
        空间子存在 / 表面特征存在 / 纹理区域存在 /
        深度结构存在 / 叶子特征块存在 / 未定

    中心局部坐标
    范围局部坐标AABB
    原帧坐标范围
    外轮廓 / 子轮廓
    像素归属掩码 / 索引引用

    颜色摘要
    深度摘要
    空间连续性评分
    轮廓闭合评分
    验证状态
    是否稳定 = 否，第一阶段默认

    内部世界，可为空
}
```

判断口径：

```text
如果子轮廓有独立空间范围、深度边界、形状稳定：
    可生成 空间子存在。

如果子轮廓只有颜色差异，没有空间独立性：
    生成 表面特征存在 / 纹理区域存在。

如果区域很小，只能描述局部颜色 / 深度：
    生成 叶子特征块存在。

如果深度无效或边界不稳定：
    标记为 未确认子区域或内部未解释区域。
```

## 9. 8*8 停止条件

递归停止条件表达为：

```text
在当前存在.内部世界中，若某个子候选的局部投影边界框 <= 8*8，
则不再为其创建新的内部世界，只生成叶子特征块存在。
```

叶子特征块存在：

```text
叶子特征块存在 {
    所在场景 = 父存在.内部世界
    存在类型 = 叶子特征块存在
    来源观察帧
    来源局部观察切片

    局部边界框
    宽度 <= 8
    高度 <= 8
    像素数

    平均颜色
    主颜色
    颜色方差
    平均深度
    深度方差
    空间坐标范围
    深度有效比例

    不再细分 = true
    内部世界 = 空 / 未创建
}
```

保护条件：

```text
1. 最大递归层级，防止异常纹理无限切分。
2. 最小有效像素数，低于阈值时停止。
3. 特征变化不足时停止。
4. 分裂收益不足时停止。
5. 子轮廓碎片过多时合并为纹理噪声区域。
6. 深度无效比例过高时停止空间细分，只保留颜色叶子块。
```

## 10. 当前观察内部场景与稳定内部世界

相机看到的是当前帧中可见的表面和局部结构，不代表已经知道存在的完整内部。

第一阶段允许：

```text
存在.内部世界.成员存在集合 = 当前帧确认出的子存在
```

但每个成员必须携带：

```text
来源观察帧
观察时间
验证状态
是否稳定 = 否
```

后续可演化为：

```text
存在.内部世界
    -> 当前观察内部场景
        -> 本帧子存在
    -> 历史观察内部场景
        -> 过去帧子存在
    -> 稳定子存在集合
        -> 跨帧归并后的子存在
```

在没有跨帧归并和稳定验证前，只能称为：

```text
该存在内部世界中的当前可见观察结构。
```

## 11. 细分依据

当前阶段顶层存在确认默认以平面轮廓为主：

```text
平面轮廓稳定性
平面轮廓匹配评分
掩码重合率
深度摘要辅助
空间坐标摘要辅助
子轮廓辅助
颜色 / 纹理辅助
```

需要机械作用、碰撞、支撑、抓取、完整三维占位或平面轮廓不够唯一时，再升级使用：

```text
空间坐标连续性
范围坐标稳定性
深度一致性
投影覆盖一致性
空间极值轮廓
局部三维模型
```

存在内部细分时，彩图轮廓和深度轮廓的权重可以提高，因为此时问题已经变成：

```text
这个已确认存在内部有哪些可区分的局部结构？
```

内部细分依据：

```text
1. 颜色边界：颜色突变、色块边界、纹理边界。
2. 深度边界：深度突变、表面凹凸、台阶。
3. 空间坐标边界：局部空间点断裂或曲面变化。
4. 父存在归属掩码：子候选不得越过父存在像素归属。
5. 局部尺寸约束：小于等于 8*8 时进入叶子特征块。
```

硬边界：

```text
顶层存在确认：
    当前阶段以平面轮廓为主，深度摘要和空间坐标摘要为辅助；
    空间操作或三维占位任务再升级为空间坐标、范围坐标、空间极值轮廓或局部三维模型主导。

存在内部细分：
    彩图轮廓 + 深度轮廓共同主导，
    空间坐标用于验证子结构是否稳定。
```

## 12. 自我本能方法

外设边界不变：双目相机只提供观察帧、像素特征、颜色、深度、空间坐标。外设内部采集、滤波、分割不登记成自我层方法。

本规范建议登记或预留以下自我本能方法。

### 12.1 自我_确保存在内部世界

输出能力：

```text
目标存在.内部世界 -> 已建立
```

输入：

```text
目标存在
父场景
坐标单位
内部世界边界口径
```

输出：

```text
目标存在.内部世界 = 场景节点
内部世界.场景类型 = 存在内部世界
内部世界.所属父存在 = 目标存在
```

### 12.2 自我_建立存在内外场景接口

输出能力：

```text
目标存在.内部世界.接口集合 -> 已更新
```

输入：

```text
目标存在
目标存在所在父场景
目标存在.内部世界
目标存在.范围坐标AABB
目标存在.像素归属掩码
当前观察帧
```

输出：

```text
内外接口 {
    父场景
    内部世界
    外部到内部坐标变换
    内部到外部坐标变换
    像素到内部局部坐标映射
}
```

### 12.3 自我_将存在局部观察切片映射到内部世界

输出能力：

```text
目标存在.内部世界.当前观察材料 -> 已建立
```

输入：

```text
目标存在
当前观察帧
目标存在.像素归属掩码
目标存在.内部世界
```

输出：

```text
内部世界.局部彩图
内部世界.局部深度图
内部世界.局部空间坐标图
内部世界.局部像素索引
```

这些输出可以是引用，不要求复制全部数据。

### 12.4 自我_在内部世界提取子候选

输出能力：

```text
目标存在.内部世界.子候选集合 -> 已生成
```

输入：

```text
目标存在.内部世界
内部世界.局部彩图
内部世界.局部深度图
内部世界.局部空间坐标图
递归参数
```

输出：

```text
子候选集合 {
    来源内部世界
    层级
    局部轮廓
    局部像素集合
    局部中心坐标
    内部世界范围坐标AABB
    颜色摘要
    深度摘要
    空间连续性评分
    轮廓闭合评分
    子候选类型 =
        空间子候选
        表面特征候选
        纹理候选
        叶子候选
}
```

### 12.5 自我_确认内部世界子存在

输出能力：

```text
目标存在.内部世界.成员存在集合 -> 已更新
```

输入：

```text
子候选
内部世界
局部彩图 / 深度图 / 空间坐标图
最小尺寸阈值
```

输出：

```text
子存在集合
叶子特征块存在集合
未解释区域
冲突区域
```

如果子候选尺寸小于等于 8*8：

```text
生成叶子特征块存在
不再创建新的内部世界
```

### 12.6 自我_递归细分存在内部世界

输出能力：

```text
目标存在.内部世界.细分状态 -> 已完成 / 部分完成
```

它是组合父方法，内部顺序为：

```text
确保内部世界
建立内外接口
映射局部观察切片
提取子候选
确认子存在
对子存在递归
生成叶子特征块
```

动作动态必须记录：

```text
输入引用 = 目标存在 + 当前观察帧 + 父掩码
输出引用 = 内部世界 + 子存在集合 + 叶子特征块存在集合
递归层数
子存在数量
叶子块数量
停止原因统计
未解释区域 / 冲突区域摘要
```

## 13. 认知需求目标

需求不要写成泛泛的：

```text
细分存在
```

应落到内部世界目标：

```text
目标存在.内部世界 -> 已建立
目标存在.内部世界.成员存在集合 -> 已更新
目标存在.内部世界.细分状态 -> 已完成
目标存在.内部世界.未解释区域比例 -> 已更新
目标存在.内部世界.OpenGL复现快照 -> 已生成
```

示例：

```text
需求：获取杯子A内部结构
```

落成：

```text
杯子A.内部世界.成员存在集合 -> 已更新
```

筹办链：

```text
杯子A.内部世界 -> 已建立
杯子A.内部世界.当前观察材料 -> 已建立
杯子A.内部世界.成员存在集合 -> 已更新
杯子A.内部世界.细分状态 -> 已完成
```

## 14. OpenGL 复现口径

控制面板和 OpenGL 复现只能读取自我所在场景及存在内部世界中的认知结果，不得把相机原始预览当真值。

递归绘制口径：

```text
绘制自我所在场景
    -> 绘制场景成员存在
        -> 若存在.内部世界已展开
            -> 绘制内部世界成员
                -> 若子存在.内部世界已展开
                    -> 继续绘制
```

显示模式：

```text
外部叠加模式：
    父存在外轮廓
    + 子存在边界
    + 子存在颜色 / 深度 / 局部坐标

内部展开模式：
    父存在内部世界画布
    -> 子存在
    -> 表面区域
    -> 纹理块
    -> 叶子特征块
```

视觉层级应表达：

```text
父场景存在范围
内部世界边界
内部子存在范围
叶子特征块
未解释区域 / 冲突区域
```

## 15. 预期好处

递归统一：

```text
不需要设计 子结构集合 / 子子结构集合 / 子子子结构集合；
只需要 存在.内部世界.成员存在集合。
```

不污染父场景：

```text
父场景只关心这里有某个存在、它的位置、范围和外轮廓；
内部细节进入该存在的内部世界。
```

场景机制可复用：

```text
边界
坐标
接口
成员存在
未解释区域
可绘制状态
```

都可以沿用场景机制表达。

## 16. 禁止事项

禁止把内部世界当作真实完整内部：

```text
第一阶段只能说：存在.内部世界中记录了当前观察可见的内部结构。
```

禁止把颜色花纹都当成独立物理存在：

```text
内部世界成员应区分 空间子存在 / 表面特征存在 / 纹理块存在 / 叶子特征块存在。
```

禁止每个存在都立即创建内部世界：

```text
内部世界应按需求懒创建；
未细分的存在保持内部世界空引用即可。
```

禁止绕过观察帧像素索引：

```text
内部世界观察材料必须能追溯到来源观察帧和帧内像素编号。
```

禁止用控制面板绘制结果反推业务成功：

```text
复现画布只是证据视图；
业务结论必须以自我所在场景、动作动态、状态快照、日志和验证结果为证据。
```

## 17. 最终定案

```text
存在节点拥有“内部世界”字段，类型为可解析引用<场景节点类>。当自我需要认知某个存在的内部结构时，应解析或创建该存在的内部世界场景。父存在的子存在、子轮廓、子结构、叶子特征块、未解释区域和冲突区域，均应作为该内部世界场景中的成员或特征存储，而不是直接堆叠在父存在普通字段中。存在在父场景中表现为一个成员；存在的内部世界表现为该成员可展开的子场景。递归细分时，对每个子存在同样使用其内部世界继续展开，直到局部轮廓或局部区域尺寸小于等于 8*8，停止递归并生成叶子特征块。
```

一句话压缩：

```text
存在在外部是一个对象，向内部展开就是一个场景；子存在不挂在父存在身上，而是住进父存在的内部世界里。
```
