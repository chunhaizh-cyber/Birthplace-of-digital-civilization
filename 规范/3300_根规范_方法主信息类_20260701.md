# 3300 根规范 方法主信息类

编号：3300
日期：20260701
状态：正式根规范
代码锚点：`方法主信息类.h:231`

## 1. 根定位

`方法主信息类` 承载方法头、方法条件节点、方法结果节点、条件结果对、动作句柄和方法状态。

## 2. 承载边界

1. 方法头只做大范围召回；具体执行依据是条件节点、结果节点、条件结果对和方法虚拟存在。
2. 方法查找必须先填充候选集，再从候选集中选择。
3. 方法名称、动作名称、显示文本、语素文本或函数名称不得作为执行语义依据。

## 3. 子规范约束

方法子规范必须区分方法能力、方法动作、结果能力、条件节点、执行入口和动作动态来源。

## 4. 当前整理判断

方法规范已有主链，但缺按 `方法主信息类` 独立根规范形式重排的候选文件。
