## 1. 定案

`基础风险判断状态 == 已明确` 不是第一阶段观察闭环的直接目标。

第一阶段最多先达到：

```text
当前观察帧.基础观察事实可用状态 等于 可用
```

只有在进一步提取风险相关特征、判断必要因子、计算风险值并满足证据阈值后，才允许进入：

```text
自我所在场景.基础风险判断状态 等于 已明确
```

像素级 100% 只表示当前帧内像素可寻址、可回查、无遗漏、无重复；不表示已经理解稳定真实对象，也不表示风险已经判断。

本文所有写入实例节点的 `已建立 / 已取得 / 已覆盖 / 已完成 / 已完备 / 新鲜 / 可用 / 已明确` 等枚举型实例特征值，都必须按 `枚举型实例特征值合法来源规范20260526.md` 追溯到合法生产者、输入证据、判定标准、输出宿主、输出特征和动作动态 / 来源动态 / 规则证据。枚举值域定义本身不需要通过本能方法获取。

一句话：

```text
已明确不是看见了一帧，而是证据够了、因子全了、不确定度低了、风险值算出来了。
```

## 2. 第一阶段：基础观察事实可用

基础观察事实可用目标为：

```text
当前观察帧.基础观察事实可用状态 等于 可用
```

第一阶段必须拆成三层，不得把 `当前观察帧存在状态` 做成过重状态。

### 2.1 观察帧存在已建立

这是帧容器成立：

```text
自我所在场景.当前观察帧存在状态 等于 已建立
```

只表示：

```text
自我所在场景中已经创建一个当前观察帧存在；
该观察帧存在有来源外设、帧宽、帧高、帧号、预期像素数量等基本元信息；
该观察帧存在可以承载后续像素观察存在。
```

不要求此时所有像素观察存在都已经生成。

当且仅当这些比较成立：

```text
当前观察帧.来源外设 等于 双目相机
当前观察帧.所属上下文 等于 自我所在场景
当前观察帧.帧宽度 大于 0
当前观察帧.帧高度 大于 0
当前观察帧.预期像素数量 等于 当前观察帧.帧宽度 * 当前观察帧.帧高度
当前观察帧.彩色帧号状态 等于 已取得
当前观察帧.深度帧号状态 等于 已取得，若本轮观察需要深度
当前观察帧.创建动作动态状态 等于 已记录
```

合法生产者：

```text
自我_建立观察帧存在
```

输入：

```text
双目相机_取得当前观察特征帧 的输出
自我所在场景
来源外设
帧宽度
帧高度
彩色帧号
深度帧号
```

输出：

```text
自我所在场景.当前观察帧存在状态 等于 已建立
```

该旧字段仅按兼容口径解释为观察帧容器成立。后续新实现优先使用更明确的枚举特征：

```text
当前观察帧.观察帧容器状态 等于 已建立
```

不要把它与下列事实完备目标混在一起：

```text
当前观察帧.观察事实完备状态 等于 已完备
```

`观察事实完备状态 等于 已完备` 至少依赖：

```text
当前观察帧.像素覆盖状态 等于 已覆盖
当前观察帧.像素特征值承接状态 等于 已完成
当前观察帧.坐标回查可用状态 等于 可用
当前观察帧.帧内编号回查可用状态 等于 可用
```

### 2.2 像素观察存在覆盖已完成

这是每个像素都有对应的像素观察存在：

```text
当前观察帧.像素覆盖状态 等于 已覆盖
```

标准是：

```text
当前观察帧.像素观察存在数量 等于 当前观察帧.预期像素数量
当前观察帧.缺失像素数量 等于 0
当前观察帧.重复映射数量 等于 0
当前观察帧.坐标回查可用状态 等于 可用
当前观察帧.帧内编号回查可用状态 等于 可用
```

这里的存在是：

```text
像素观察存在
```

不是稳定外部对象。

合法生产者：

```text
自我_建立像素观察存在集合
```

第一版如果沿用既有方法名，可由：

```text
自我_建立像素观察事实索引
```

承接，但输出状态必须写成 `当前观察帧.像素覆盖状态 等于 已覆盖`，不得继续把像素覆盖混入 `当前观察帧存在状态 等于 已建立`。

### 2.3 像素特征值承接已完成

这是每个像素观察存在上有对应的颜色、深度有效性、深度值、空间坐标等特征值：

```text
当前观察帧.像素特征值承接状态 等于 已完成
```

最低标准：

```text
每个像素观察存在.颜色R值状态 等于 已取得
每个像素观察存在.颜色G值状态 等于 已取得
每个像素观察存在.颜色B值状态 等于 已取得
每个像素观察存在.深度有效性值状态 等于 已取得
```

如果本阶段要求深度：

```text
深度有效性 等于 1 的像素:
    像素观察存在.深度值 大于 0

深度有效性 等于 0 的像素:
    像素观察存在.深度值状态 等于 无效
```

如果本阶段要求空间坐标：

```text
深度有效性 等于 1 的像素:
    像素观察存在.空间坐标X值状态 等于 已取得
    像素观察存在.空间坐标Y值状态 等于 已取得
    像素观察存在.空间坐标Z值状态 等于 已取得
```

如果空间坐标暂未实现：

```text
当前观察帧.空间坐标承接状态 等于 条件不足
```

或：

```text
当前观察帧.空间坐标承接状态 等于 待补齐
```

此时不得写：

```text
当前观察帧.像素特征值承接状态 等于 已完成
```

合法生产者：

```text
自我_承接像素特征值
```

### 2.4 当前观察新鲜度

`新鲜` 也必须由合法生产者计算；本观察链中由自我判定方法输出，不得手写。

目标：

```text
自我所在场景.当前观察新鲜度状态 等于 新鲜
```

当且仅当：

```text
自我所在场景.当前观察帧存在状态 等于 已建立
当前观察帧.采集时间 大于 0
当前观察帧.观察年龄 小于 当前需求.最大允许观察年龄
当前观察帧.失效状态 等于 未失效
当前观察帧.来源外设状态 等于 可追溯
```

合法生产者：

```text
自我_判断当前观察帧新鲜度
```

输入：

```text
当前观察帧
当前时间
最大允许观察年龄
当前需求类型，安全 / 服务 / 内部世界细分
```

输出：

```text
当前观察帧.观察年龄
自我所在场景.当前观察新鲜度状态 等于 新鲜 / 过期
```

成立条件全部用三比较表达：

```text
自我所在场景.当前观察特征帧取得状态 等于 已取得
自我所在场景.当前观察帧存在状态 等于 已建立
当前观察帧.像素覆盖状态 等于 已覆盖
当前观察帧.像素特征值承接状态 等于 已完成
当前观察帧.观察事实完备状态 等于 已完备
当前观察帧.质量可用状态 等于 可用
自我所在场景.当前观察新鲜度状态 等于 新鲜
```

这一阶段只能证明：

```text
自我拥有一份可用的当前观察事实。
```

不得证明或暗示：

```text
基础风险判断状态 等于 已明确
基础风险值已计算
基础风险等级已确定
场景安全
稳定真实对象已理解
```

## 3. 第二阶段：基础风险判断已明确

基础风险判断状态是派生枚举型实例特征值，不得由单一观察帧存在直接推出。

正式目标为：

```text
自我所在场景.基础风险判断状态 等于 已明确
```

当且仅当以下三比较条件全部成立：

```text
自我所在场景.基础风险评估范围状态 等于 已确定
自我所在场景.基础风险评估范围类型 等于 当前观察帧可见范围
当前观察帧.基础观察事实可用状态 等于 可用
当前观察帧.观察年龄 小于 最大允许风险判断观察年龄
当前观察帧.质量可用状态 等于 可用
自我所在场景.基础风险未判断因子数量 等于 0
自我所在场景.基础风险证据完整度 大于 最低基础风险证据完整度
自我所在场景.基础风险不确定度 小于 最大允许基础风险不确定度
自我所在场景.基础风险值计算状态 等于 已计算
```

第一版风险评估范围只采用：

```text
当前观察帧可见范围
```

不得混入：

```text
自我近距安全范围
执行器作用范围
当前服务目标区域
```

这些范围可作为后续扩展，但必须以独立范围类型和独立评估口径进入。

## 4. 基础风险必要因子

基础风险必要因子至少包含：

```text
1. 观察依据可用性；
2. 观察新鲜度；
3. 观察质量；
4. 未解释区域比例；
5. 近距空间占据状态；
6. 已知危险候选状态。
```

对应统计特征为：

```text
自我所在场景.基础风险必要因子总数
自我所在场景.基础风险已判断因子数量
自我所在场景.基础风险未判断因子数量
```

已明确的必要条件为：

```text
自我所在场景.基础风险未判断因子数量 等于 0
```

如果当前系统尚未实现空间候选、近距空间占据或危险候选判断，则不得写：

```text
自我所在场景.基础风险判断状态 等于 已明确
```

只能写成：

```text
自我所在场景.基础风险判断状态 等于 条件不足
```

或：

```text
自我所在场景.基础风险判断状态 等于 证据不足
```

## 5. 证据完整度、不确定度和风险值

风险证据完整度值域：

```text
0 ~ 1000000
```

第一版建议阈值：

```text
最低基础风险证据完整度 = 800000
```

成立条件：

```text
自我所在场景.基础风险证据完整度 大于 最低基础风险证据完整度
```

风险不确定度值域：

```text
0 ~ 1000000
```

第一版建议阈值：

```text
最大允许基础风险不确定度 = 200000
```

成立条件：

```text
自我所在场景.基础风险不确定度 小于 最大允许基础风险不确定度
```

基础风险值口径：

```text
0 = 无风险
1000000 = 极高风险
```

风险值计算完成条件：

```text
自我所在场景.基础风险值计算状态 等于 已计算
```

风险是否可接受必须另立目标：

```text
自我所在场景.基础风险值 小于 最大允许基础风险值
```

不得把：

```text
基础风险判断状态 等于 已明确
```

等同于：

```text
场景安全
```

一个场景可以同时满足：

```text
自我所在场景.基础风险判断状态 等于 已明确
自我所在场景.基础风险值 大于 最大允许基础风险值
```

这表示风险很明确，而且很高。

## 6. 基础风险判断状态值域

`基础风险判断状态` 的建议值域为：

```text
未判断
条件不足
观察过期
观察质量不足
证据不足
必要因子未覆盖
已明确
```

风险等级应作为独立特征：

```text
自我所在场景.基础风险等级 等于 低风险
自我所在场景.基础风险等级 等于 中风险
自我所在场景.基础风险等级 等于 高风险
```

`基础风险判断状态` 只表示判断是否有足够证据成立；`基础风险值 / 基础风险等级` 才表示风险高低。

## 7. 任务筹办派生消息口径

第一阶段不得直接派生：

```text
自我所在场景.基础风险判断状态 等于 已明确
```

应先派生：

```text
当前观察帧.基础观察事实可用状态 等于 可用
```

派生需求消息字段为：

```text
目标宿主 = 当前观察帧
目标特征类型 = 基础观察事实可用状态
目标比较符 = 等于
目标值 = 可用
生成类型 = 条件补齐 / 证据补齐，按上级路径角色决定
```

随后再派生基础观察事实可用的子目标：

```text
自我所在场景.当前观察特征帧取得状态 等于 已取得
自我所在场景.当前观察帧存在状态 等于 已建立
双目相机.可用状态 等于 可用
双目相机.运行可用性值 大于 0
当前观察帧.像素覆盖状态 等于 已覆盖
当前观察帧.像素特征值承接状态 等于 已完成
当前观察帧.观察事实完备状态 等于 已完备
当前观察帧.质量可用状态 等于 可用
自我所在场景.当前观察新鲜度状态 等于 新鲜
```

上述 `已取得 / 已建立 / 已覆盖 / 已完成 / 已完备 / 可用 / 新鲜` 均是枚举型实例特征值，派生消息只能把它们作为目标值；实例取值本身必须由合法生产者写入，并记录输入证据、判定标准、输出宿主、输出特征和动作动态 / 来源动态 / 规则证据。像素数量、缺失数量、重复映射数量、坐标回查状态、帧内编号回查状态等比较，是 `自我_建立像素观察存在集合` 或兼容的像素索引方法推出 `像素覆盖状态 等于 已覆盖` 的内部成立证据，不应再混作第一层观察帧容器已建立。

这些目标闭合之后，才允许生成或推进基础风险判断目标：

```text
自我所在场景.基础风险判断状态 等于 已明确
```

## 8. 禁止项

```text
1. 禁止用“已经观察了一帧”推出“基础风险判断状态 == 已明确”。
2. 禁止用“像素 100% 可回查”推出“基础风险判断状态 == 已明确”。
3. 禁止把观察质量可用状态等同于风险已判断。
4. 禁止把基础风险判断状态已明确等同于风险可接受或场景安全。
5. 禁止在空间候选、近距空间占据或危险候选缺失时写已明确。
6. 禁止把相机内部采集、对齐、滤波、分割步骤登记成自我层本能方法。
7. 禁止把补全深度、融合轮廓或未验证候选升级为基础风险已明确证据。
8. 禁止由普通线程、任务筹办普通函数、控制面板、日志解析器或只读快照直接写入 已建立 / 已取得 / 已覆盖 / 已完成 / 已完备 / 新鲜 / 可用 / 已明确 等枚举型实例特征值。
```

## 9. 最终定义

```text
基础观察事实可用状态：
    表示当前观察帧已经具备可寻址、可回查、无遗漏、无重复且质量可用的观察事实。

基础风险判断状态：
    表示自我在确定评估范围内，拥有未过期、质量可用的观察依据，
    基础风险必要因子全部已判断，
    风险证据完整度超过阈值，
    风险不确定度低于阈值，
    基础风险值已经计算完成。
```

最短版：

```text
看见一帧只是风险判断的前置，不是风险判断本身。
```
