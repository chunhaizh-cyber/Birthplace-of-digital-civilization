## 1. 定案

枚举必须分为两层：

```text
枚举值域初始化：
    在抽象特征树中建立某个特征类型允许取哪些值。

实例上的枚举特征值写入：
    某个存在 / 场景 / 外设 / 需求 / 任务 / 方法 / 因果 / 动态节点上的某个特征，
    当前实际落到某个枚举值。
```

枚举值域初始化不需要专用本能方法。它是抽象特征树的值域定义。

实例上的枚举特征值写入必须有合法生产者。其中一部分需要专用本能方法或专用自我判定方法；另一部分只需要任务生命周期、需求树统一更新、方法登记 / 沉淀、因果解释规则、数值比较规则、初始化流程或外部反馈承接流程作为合法生产者。

一句话：

```text
值域不用本能方法，实例值必须有生产者；
运行时状态才优先需要专用本能 / 判定方法，结构类枚举由对应生命周期或规则流程生产。
```

## 2. 当前实现口径

根据 2026-05-26 的 `特征类.cpp`：

```text
确保点状态(...)
    把枚举值 static_cast<I64>(...) 后，初始化为抽象特征树中的 I64区间::点(...) 状态节点。

确保布尔(...)
    把 否 / 是 初始化为 0 / 1 点状态。
```

因此，当前工程里的许多“枚举值”不是 C++ `enum` 实例值直接存入世界树，而是抽象特征树里的 I64 点值域。

底层特征快照值仍按通用特征值口径处理：

```text
I64
VecU句柄 / VecIU64 类向量证据
指针句柄
```

不是另有一套专门的枚举存储类型。

结论：

```text
1. 抽象特征树中的枚举值域初始化，不等于实例状态写入。
2. 值域节点不需要逐个配本能方法。
3. 实例节点把某个枚举型特征写成某个值时，才需要合法生产者和证据。
```

## 3. 需求比较规则

需求比较符仍只有：

```text
大于
小于
等于
```

枚举型目标只能使用：

```text
目标宿主.目标特征类型 等于 目标枚举值
```

例如：

```text
当前观察帧.像素覆盖状态 等于 已覆盖
当前观察帧.质量可用状态 等于 可用
双目相机.可用状态 等于 可用
服务反馈.可信状态 等于 已验证
```

数值型目标才使用 `大于 / 小于`，例如：

```text
当前观察帧.深度有效率 大于 最低深度有效率
当前观察帧.观察年龄 小于 最大允许观察年龄
自我.安全值 大于 安全值基线
```

`新鲜 / 已建立 / 可用 / 已明确 / 正常 / 足够 / 可控` 都是目标值，不是方向。

## 4. 合法生产者分类

实例枚举特征值的合法生产者包括：

```text
1. 专用本能方法输出
2. 专用自我判定方法输出
3. 任务生命周期 / 任务回执 / 任务结算流程
4. 任务筹办派生消息经自我线程裁决后的需求树更新
5. 需求目标回查 / 需求树统一更新规则
6. 方法登记 / 方法沉淀 / 方法结构维护流程
7. 因果解释 / 规则推导后的派生结果
8. 数值比较规则
9. 系统初始化流程
10. 外部反馈承接方法
```

禁止来源：

```text
随手赋值
日志里说成功
控制面板显示了
任务管理线程直接写树
没有动作动态 / 来源动态 / 规则证据的状态修改
```

## 5. 是否需要专用本能 / 判定方法的判定规则

需要专用本能方法或专用自我判定方法的条件：

```text
1. 该枚举实例值代表运行时世界状态、外设状态、自我安全状态或观察事实状态。
2. 该值不能只靠已有特征比较、结构初始化、任务生命周期或规则推导得出。
3. 该值需要通过观察、检查、控制、验证或综合判断才能成立。
4. 该值会参与需求判断、因果判断、任务筹办、价值结算或世界状态更新。
```

不需要逐值专用本能方法的条件：

```text
1. 它只是抽象值域定义。
2. 它是结构分类、注册分类、句柄类型、任务生命周期标记或需求结构角色。
3. 它可由统一生命周期流程、需求目标回查、方法登记流程、因果解释规则或数值比较规则产生。
4. 它不需要为每个枚举值单独设计动作。
```

## 6. 需要专用本能方法 / 自我判定方法的类型

### 6.1 外设状态类

```text
外设可用性 等于 可用 / 不可用
双目相机.可用状态 等于 可用 / 不可用
双目相机.运行状态 等于 正常 / 异常 / 降级可用
双目相机.占用状态 等于 已释放 / 已占用
```

```text
双目相机_使达到可用状态
双目相机_检查运行状态
双目相机_释放
```

结论：

```text
需要专用外设本能方法。
```

### 6.2 观察事实承接类


```text
双目相机_取得当前观察特征帧
```

```text
需要专用外设本能方法或自我判定方法。
```

### 6.3 安全根必要条件类

`特征类.cpp` 已把以下状态接入安全值必要条件：

```text
自我运行状态明确状态
自我运行状态正常状态
资源状态明确状态
资源状态足够状态
权限边界明确状态
风险状态明确状态
风险状态可控状态
```

建议合法生产者：

```text
自我_确认自我运行状态
自我_判断自我运行是否正常
自我_确认资源状态
自我_判断资源是否足够
自我_确认权限边界
自我_判断风险状态
自我_判断风险是否可控
```

结论：

```text
需要专用自我判定方法。
若判定失败后需要改变世界状态，再另接恢复 / 释放 / 降级类方法。
```

### 6.4 待机状态

```text
待机状态 等于 运行 / 待机
```

判定：

```text
若只作为线程内部标记，不需要专用本能方法。
若参与需求、因果、安全 / 服务调度或世界状态更新，需要自我控制方法。
```

建议方法：

```text
自我_进入待机
自我_退出待机
自我_切换待机状态
```

## 9. 枚举型特征类型登记要求

每个枚举型特征类型至少登记四件事：

```text
1. 值域
2. 合法写入者
3. 判定标准
4. 证据要求
```

示例：

```text
当前观察帧.像素覆盖状态
    值域:
        未建立 / 已覆盖 / 缺失 / 冲突
    合法写入者:
        自我_建立像素观察存在集合
        自我_校验像素覆盖状态
    已覆盖标准:
        当前观察帧.像素观察存在数量 等于 当前观察帧.预期像素数量
        当前观察帧.缺失像素数量 等于 0
        当前观察帧.重复映射数量 等于 0
    证据要求:
        观察帧存在、像素观察存在集合、坐标回查索引、帧内编号回查索引、动作动态

当前观察帧.质量可用状态
    值域:
        未评估 / 可用 / 降级可用 / 不可用
    合法写入者:
        自我_评估观察帧质量
    可用标准:
        当前观察帧.质量评分 大于 最低质量评分
        当前观察帧.深度有效率 大于 最低深度有效率
        当前观察帧.像素覆盖状态 等于 已覆盖
    证据要求:
        观察帧特征、深度有效性统计、缺失统计、动作动态

自我所在场景.基础风险判断状态
    值域:
        未判断 / 条件不足 / 观察过期 / 观察质量不足 / 证据不足 / 必要因子未覆盖 / 已明确
    合法写入者:
        自我_判断基础风险状态
    已明确标准:
        自我所在场景.基础风险评估范围状态 等于 已确定
        当前观察帧.基础观察事实可用状态 等于 可用
        当前观察帧.观察年龄 小于 最大允许风险判断观察年龄
        自我所在场景.基础风险未判断因子数量 等于 0
        自我所在场景.基础风险证据完整度 大于 最低基础风险证据完整度
        自我所在场景.基础风险不确定度 小于 最大允许基础风险不确定度
        自我所在场景.基础风险值计算状态 等于 已计算
```

## 10. 任务筹办和自我线程校验

任务筹办生成派生需求消息时，不得写：

```text
方向 = 建立
方向 = 新鲜
方向 = 明确
方向 = 确认
```

应写：

```text
比较符 = 等于
目标值 = 已建立 / 新鲜 / 已明确 / 已确认
```

自我线程入树校验必须检查：

```text
1. 比较符是否为 大于 / 小于 / 等于。
2. 如果目标值是枚举，比较符必须是 等于。
3. 目标枚举值是否属于该特征类型值域。
4. 该枚举型实例特征值是否有合法生产者。
5. 当前派生需求是否能通过某个合法生产者满足。
```

如果没有合法生产者，不得进入普通执行路径，应生成：

```text
特征值生产方法状态 等于 待补齐
```

或：

```text
目标特征判定规则状态 等于 待建立
```

## 11. 禁止项

```text
1. 禁止把枚举型实例特征值当作说明文字直接写入。
2. 禁止随手赋值、日志说成功、控制面板显示了就写入枚举状态。
3. 禁止任务管理线程直接写需求树枚举特征。
4. 禁止没有动作动态 / 来源动态 / 规则证据的枚举状态修改。
5. 禁止把枚举值域初始化误当成实例枚举特征值写入。
6. 禁止为每个结构类枚举值盲目创建专用本能方法。
7. 禁止把多个层级状态合并成一个过重状态。
```

## 13. 最终定义

```text
枚举值域初始化 = 抽象特征树中允许取值的静态刻度，当前实现通常落成 I64区间::点(...)。

枚举型实例特征值 = 某个实例节点上的枚举型特征当前落到某个刻度的结论。

枚举型实例特征值必须由合法生产者产生，并留下动作动态 / 来源动态 / 规则证据。

不是所有枚举型特征都需要专用本能方法。
只有运行时必须通过观察、检查、控制、判断才能得出的枚举实例值，才需要专用本能方法或专用自我判定方法。
```
