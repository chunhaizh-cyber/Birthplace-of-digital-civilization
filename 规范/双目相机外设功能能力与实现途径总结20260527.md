## 1. 核心口径

```text
双目相机不是“世界存在识别器”；
双目相机是“稳定观察特征供应器”。
```

外设线程输出：

```text
扫描报告
跟踪报告
观察像素簇
掩码
彩色轮廓局部图
深度轮廓局部图
簇级稳定特征
```

自我负责：

```text
承接观察报告
将观察像素簇转为存在候选
根据需求验证、确认、入场景
```

实现口径：

```text
相机线程内部能力直接由工程代码实现；
本能方法不下沉为相机内部算法步骤；
本能方法只保留为自我 / 任务管理侧请求、承接、判断外设结果的边界契约。
```

旧文档中的“像素级 100% 识别”只保留为底层可回查能力，即：

```text
帧内可寻址
帧内可回查
无遗漏
无重复
```

它不表示：

```text
稳定对象识别
语义识别
目标可见性闭合
跨帧身份闭合
```

## 2. 功能总结

### 2.1 外设观察功能

双目相机外设需要提供的核心功能是：

```text
持续观察视野；
把视野内像素聚成观察像素簇；
为每个簇输出稳定特征值；
输出扫描报告和跟踪报告；
将高频观察信息写入外设队列 / 缓存；
由任务管理工作线程按需求消费。
```

外设线程不直接给出：

```text
世界存在
已确认观察存在
安全判断
服务判断
需求满足
价值结算
```

它只给出：

```text
观察材料
簇级特征
稳定性信息
质量缺口
失败原因
配置摘要
```

### 2.2 扫描功能

扫描回答：

```text
当前视野里有哪些观察像素簇？
每个簇有哪些稳定特征？
哪些区域低质量、未归簇、不可观测？
```

扫描报告最小输出：

```text
扫描报告 {
    报告ID
    来源外设
    时间戳
    帧宽度
    帧高度
    外设配置摘要

    观察像素簇集合
    簇ID掩码
    低质量区域集合
    未归簇区域集合
    不可观测区域集合
}
```

可直接满足的观察材料层特征目标：

```text
外设观察报告.生成状态 == 已生成
当前观察帧.观察像素簇集合状态 == 已生成
当前观察帧.簇ID掩码状态 == 已生成
```

### 2.3 跟踪功能

跟踪回答：

```text
指定观察簇 / 存在候选是否还在？
它的目标特征值是否能够稳定复现？
```

跟踪报告最小输出：

```text
跟踪报告 {
    跟踪ID
    跟踪种子:
        观察像素簇ID / 存在候选ID / ROI / 掩码

    最近观察时间
    最近观察簇
    跟踪状态
    丢失状态
    重捕获候选集合

    稳定特征集合:
        距离
        空间中心坐标
        空间范围AABB
        颜色摘要
        轮廓摘要
        深度摘要

    每个特征:
        特征值
        复现离散度
        连续成功次数
        失败次数
        稳定状态
        失败原因
}
```

可直接满足的观察材料层特征目标：

```text
目标观察簇.跟踪状态 == 稳定
目标观察簇.丢失状态 == 未丢失
目标观察簇.最近观测年龄 < 最大允许观测年龄
目标观察簇.距离复现离散度 < 最大允许距离离散度
目标观察簇.空间坐标复现离散度 < 最大允许坐标离散度
```

### 2.4 观察像素簇功能

观察像素簇是双目相机外设输出的核心单位。

```text
观察像素簇 =
    当前观察帧内的一组像素集合
  + 像素集合掩码
  + 彩色轮廓局部图
  + 深度轮廓局部图
  + 颜色 / 深度 / 空间 / 轮廓 / 稳定性特征
```

每个观察像素簇至少包含：

```text
来源观察帧
来源外设
外设内部簇ID
像素集合引用
像素数量
边界框
图像中心点
```

掩码类特征：

```text
像素集合掩码
轮廓掩码
彩色轮廓掩码
深度轮廓掩码
深度有效性掩码
空间坐标有效性掩码
```

局部图特征：

```text
彩色轮廓局部图
深度轮廓局部图
局部图边界框
局部图到原帧坐标映射
```

这些不是证据附件，而是正式特征。它们后续用于：

```text
子轮廓提取
三维建模
像素归属判断
存在候选生成
当前帧识别情况统计
控制面板回查
```

## 3. 能力总结

双目相机外设能力仍分为三类：

```text
控制
检查
使用
```

外设本能方法只描述自我面向外设的动作契约，不描述相机内部采集、校正、匹配、滤波、分割等实现过程；这些内部过程属于外设私有领域。

因此，本节的控制、检查、使用能力是自我和任务管理可见的外设契约，不是双目相机线程内部的实现方式。相机线程内部可以直接用普通 C++ 类、线程循环、缓存、队列、算法模块和私有学习模块达成目标，只要最终输出符合外设命令、等待项、扫描报告和跟踪报告的契约即可。

### 3.1 控制能力

控制能力改变外设自身状态。

```text
双目相机.可用状态 == 可用
双目相机.工作模式 == 指定模式
双目相机.观察配置状态 == 已应用
双目相机.占用状态 == 已释放
```

其中 `双目相机.工作模式` 只能表达物理采集配置或运行配置，不得表达扫描、跟踪、补观察、局部细分等观察意图。

自我 / 任务管理侧可见的边界方法或等价命令：

```text
双目相机_使达到可用状态
双目相机_设置观察配置
双目相机_释放
```

### 3.2 检查能力

检查能力确认外设自身状态。

```text
双目相机.运行可用性值 > 0
双目相机.工作质量状态 == 可用 / 降级可用 / 不可用
双目相机.当前配置对目标特征适用状态 == 适用 / 不适用
双目相机.目标特征稳定获取能力状态 == 已知
```

建议数值：

```text
双目相机.运行可用性值:
    0 = 不可用
    1 = 降级可用
    2 = 正常
```

自我 / 任务管理侧可见的边界方法或等价命令：

```text
双目相机_检查运行状态
双目相机_检查当前观察能力
```

### 3.3 使用能力

使用能力通过外设向自我提供观察材料。

```text
外设观察报告.生成状态 == 已生成
当前观察帧.观察像素簇集合状态 == 已生成
目标观察簇.稳定特征集合状态 == 已生成
```

自我 / 任务管理侧可见的边界方法或等价命令：

```text
双目相机_取得扫描报告
双目相机_取得跟踪报告
```

这两个方法或命令只表达“需要取得观察材料”的请求和承接契约，不要求相机线程内部通过本能方法实现扫描、跟踪、分簇、掩码、局部图或稳定特征计算。它们也不直接生成存在候选、已确认观察存在、安全判断或服务结算。

## 4. 自我侧承接能力

相机输出观察材料后，自我侧负责承接和解释。

### 4.1 承接观察报告

```text
自我_承接双目相机观察报告
```

输出：

```text
当前观察帧.观察帧容器状态 == 已建立
外设观察报告.承接状态 == 已承接
```

### 4.2 承接观察像素簇集合

```text
自我_承接观察像素簇集合
```

输出：

```text
当前观察帧.观察像素簇集合承接状态 == 已承接
当前观察帧.观察像素簇数量 > 0
```

### 4.3 由观察像素簇生成存在候选

```text
自我_由观察像素簇生成存在候选
```

输出：

```text
当前观察帧.存在候选集合状态 == 已生成
当前观察帧.存在候选数量 > 0
```

存在候选必须引用：

```text
来源观察像素簇
像素集合掩码
彩色轮廓局部图
深度轮廓局部图
空间范围AABB
簇质量状态
稳定复现状态
```

### 4.4 统计当前帧识别情况

```text
自我_统计当前帧存在识别情况
```

输出：

```text
当前观察帧.存在识别摘要状态 == 已生成
当前观察帧.已解释像素比例
当前观察帧.未解释像素比例
当前观察帧.冲突像素比例
当前观察帧.低置信像素比例
当前观察帧.不可观测区域比例
当前观察帧.存在识别达标状态 == 达标 / 未达标
```

注意：

```text
存在识别达标 != 世界对象全部确认
存在候选 != 已确认观察存在
观察像素簇 != 稳定世界存在
```

## 5. 线程与消息模型

### 5.1 外设线程

双目相机有独占观察线程。

职责：

```text
1. 持续采集视野。
2. 生成扫描报告。
3. 生成跟踪报告。
4. 生成观察像素簇集合。
5. 生成簇级掩码。
6. 生成彩色轮廓局部图。
7. 生成深度轮廓局部图。
8. 输出簇级稳定特征。
9. 写入外设观察队列和最新缓存。
```

### 5.2 任务管理工作线程

外设线程消息的第一接收者是任务管理工作线程。

职责：

```text
1. 接收外设观察消息。
2. 校验消息完整性。
3. 去重、时效检查。
4. 更新扫描 / 跟踪缓存。
5. 匹配等待任务。
6. 匹配活跃需求。
7. 生成任务回执。
8. 生成派生需求消息。
9. 生成动作动态输入。
10. 上报自我线程裁决。
```

### 5.3 自我线程

自我线程不直接消费相机原始流。

职责：

```text
1. 接收任务管理侧上报。
2. 校验目标宿主、目标特征、比较符、目标值。
3. 校验来源因果 / 来源动态。
4. 去重、合并、循环截断。
5. 通过需求树统一更新指令入树。
6. 裁决哪些观察结果进入世界树。
```

## 6. 生产与消费模型

采用：

```text
外设主动生产；
队列缓存；
需求驱动消费。
```

流程：

```text
双目相机外设线程
    -> 外设观察消息队列
    -> 最新扫描报告缓存
    -> 最新跟踪报告缓存
    -> 最新稳定特征缓存
        -> 任务管理工作线程按正式需求消费
            -> 自我线程裁决入树 / 入世界
```

不是：

```text
自我根需求直接消费原始相机流。
```

## 7. 需求与因果接入

安全 / 服务根需求不直接消费相机队列。

正确流程：

```text
安全 / 服务根需求
    -> 任务筹办生成临时因果视图
    -> 派生观察需求消息
    -> 自我线程裁决入树
    -> 任务管理建立外设等待项
    -> 任务管理消费扫描 / 跟踪报告
    -> 生成任务回执 / 动作动态输入
    -> 自我线程承接结果
```

示例需求：

```text
当前观察帧.观察像素簇集合状态 == 已生成
当前观察帧.存在候选集合状态 == 已生成
目标观察簇.跟踪状态 == 稳定
目标观察簇.距离复现离散度 < 最大允许距离离散度
```

其中 `当前观察帧.存在候选集合状态 == 已生成` 只能由自我承接和解释链满足，不能由相机报告直接满足。

所有需求比较符只允许：

```text
大于
小于
等于
```

“扫描、跟踪、生成、稳定、承接”都是特征值或生成类型，不是方向。

## 8. 实时性与舍弃策略

实时性靠：

```text
少入账
少复制
少全图
按需深挖
分级报告
该舍弃的舍弃
```

### 8.1 报告分级

报告分级是扫描 / 跟踪报告内部材料的详细度分级，不是第三类外设模式。

```text
L0 快速报告:
    帧号、时间、粗簇、低质量区域、基础统计

L1 标准报告:
    观察像素簇集合、掩码、彩色轮廓局部图、深度轮廓局部图、摘要特征

L2 精细材料:
    稳定特征、跟踪结果、子轮廓、局部点集、三维范围
```

`L2 精细材料` 可以作为扫描 / 跟踪报告的附带字段，或作为自我后续方法产物；不得被解释为独立的“局部细分外设模式”。

### 8.2 可以舍弃

```text
过期扫描报告
重复扫描报告
无需求命中的观察材料
低优先级局部细分
中间跟踪帧
低优先级配置学习样本
```

### 8.3 不能舍弃

```text
安全事件
活跃任务回执
状态跃迁
跟踪目标丢失
外设错误
影响父需求判断的缺口事实
```

### 8.4 实时性特征

```text
外设观察报告.报告年龄 < 最大允许报告年龄
外设观察报告.处理耗时 < 最大允许处理耗时
外设观察队列.积压数量 < 最大允许积压数量
外设观察线程.实时性达标状态 == 达标
外设观察线程.丢帧率 < 最大允许丢帧率
```

## 9. 外设内部学习能力

最多新增一个外设内部学习模块：

```text
双目相机稳定特征获取学习模块
```

学习目标：

```text
观察条件 + 外设配置 + 目标特征类型
    -> 特征稳定复现结果
```

输入：

```text
距离
ROI
分辨率
工作模式
光照摘要
纹理摘要
相机运动状态
目标运动状态
深度有效率
空间坐标有效率
复现离散度
失败次数
连续成功次数
```

输出给自我的摘要：

```text
双目相机.推荐观察配置状态 == 已生成
双目相机.当前配置对目标特征适用状态 == 适用
双目相机.目标特征稳定获取成功率 > 最低成功率
```

外设内部可以使用需求、任务、方法、学习逻辑，但属于外设内部，不进入自我需求树。

## 10. 控制面板功能

可显示：

```text

跟踪报告
观察像素簇
簇ID掩码
存在候选ID掩码
彩色轮廓局部图
深度轮廓局部图
未解释像素掩码
冲突像素掩码
低置信像素掩码
存在识别摘要
```

鼠标命中回查：

```text
像素坐标
```

## 12. 验收标准

### 12.1 外设侧

```text
双目相机观察线程运行中。
扫描报告可生成。
跟踪报告可生成。
观察像素簇集合状态 == 已生成。
每个簇有像素集合掩码。
每个簇有彩色轮廓局部图。
每个簇有深度轮廓局部图。
每个簇至少有一类稳定特征摘要。
```

### 12.2 任务管理侧

```text
能接收外设消息。
能匹配等待项。
能根据报告生成任务回执。
能根据质量缺口生成派生需求消息。
不会直接改需求树。
```

### 12.3 自我侧

```text
能承接观察报告。
能承接观察像素簇集合。
能由簇生成存在候选。
能统计当前帧存在识别情况。
能通过统一更新指令入树 / 入世界。
```

### 12.4 禁止宣称

```text
不宣称观察像素簇就是世界存在。
不宣称存在候选已经确认。
不宣称跨帧身份稳定。
不宣称语义识别完成。
不把控制面板显示成功当作业务验收通过。
不把旧文档中的像素级 100% 识别作为当前主目标。
```

## 13. 最终收束

```text
双目相机外设能力实现 =
    外设独占观察线程
  + 扫描报告 / 跟踪报告
  + 观察像素簇作为主要输出单位
  + 掩码、彩色轮廓局部图、深度轮廓局部图作为簇级正式特征
  + 任务管理工作线程接收和消费外设消息
  + 自我线程裁决入树 / 入世界
  + 自我将观察像素簇承接为存在候选
  + 实时性分级与舍弃策略
```

一句话：

```text
相机负责把视野稳定切成带特征的观察簇；
任务管理负责把有需求命中的报告领走；
自我负责把这些簇变成存在候选，并决定哪些进入自己的世界。
```
