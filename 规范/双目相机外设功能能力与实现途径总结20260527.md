## 1. 核心口径

```text
双目相机不是“世界存在识别器”；
双目相机是“稳定观察特征供应器”。
```

外设线程输出：

```text
逐簇识别报告
扫描变化报告
跟踪报告
观察像素簇
稳定外设观察存在
可提交观察材料
掩码
彩色轮廓局部图
深度轮廓局部图
簇级稳定特征
```

自我负责：

```text
承接观察报告
将观察像素簇转为存在候选
根据需求验证、确认、入场景
```

实现口径：

```text
相机线程内部能力直接由工程代码实现；
本能方法不下沉为相机内部算法步骤；
本能方法只保留为自我 / 任务管理侧请求、承接、判断外设结果的边界契约。
```

2026-06-12 补充口径：

```text
RealSense / OpenCV / 跟踪 / SLAM / TSDF / VOS 不能理解为“接入后自我就会识别”。
它们只能放在外设内部稳定化、跨帧关联、空间基准、表面融合、占据表达或高价值目标 mask 跟踪层。

自我正式承接的仍然只能是：
    存在
    特征
    二次特征
    状态动态
```

D455 类外设第一阶段主线是：

```text
原始帧 / 原始簇
    -> 深度与掩码稳定化
    -> 跨帧观察轨迹
    -> 稳定外设观察存在
    -> 可提交观察材料
    -> 任务管理承接
    -> 自我观察 / 识别 / 扫描 / 跟踪
```

第一阶段不得把 SLAM、TSDF、OctoMap、SAM2 / VOS 接成默认全场主链；它们只能在稳定观察子集链路闭合后按需求作为增强模块进入外设侧。

旧文档中的“像素级 100% 识别”只保留为底层可回查能力，即：

```text
帧内可寻址
帧内可回查
无遗漏
无重复
```

它不表示：

```text
稳定对象识别
语义识别
目标可见性闭合
跨帧身份闭合
```

## 2. 功能总结

### 2.1 外设观察功能

双目相机外设需要提供的核心功能是：

```text
持续观察视野；
把视野内像素聚成观察像素簇；
把单帧原始簇推进为候选簇、稳定外设观察存在和可提交观察材料；
为达到稳定门的簇输出稳定特征值；
输出逐簇识别报告、扫描变化报告和跟踪报告；
将高频观察信息写入外设队列 / 缓存；
由任务管理工作线程按需求消费。
```

三类报告不是整场景串行阶段。同一帧可以按区域归属状态并行分工：

```text
已识别区域 -> 扫描变化报告
未识别区域 / 候选区域 / 冲突区域 -> 逐簇识别报告
指定目标所在已识别区域 -> 跟踪报告
无效区域 -> 失败原因 / 补观察缺口
静止 / 环境区域 -> 已归属静止存在、环境存在或静止存在候选记录
```

外设线程不直接给出：

```text
世界存在
已确认观察存在
安全判断
服务判断
需求满足
价值结算
```

它只给出：

```text
观察材料
簇级特征
稳定性信息
跨帧轨迹摘要
稳定观察子集
质量缺口
失败原因
配置摘要
```

### 2.2 陌生环境逐簇识别模式

逐簇识别处理未识别区域、候选区域和冲突区域。它回答：

```text
这些未归属像素 / 点集 / ROI / 掩码 / 簇应归到谁？
哪些是新存在候选？
哪些可能匹配已有存在？
哪些是静止存在或环境存在候选？
哪些冲突？
哪些证据不足？
哪些是无效材料？
```

识别的闭合标准不是世界对象全部确认，而是有效观察材料没有无主漂浮项。

逐簇识别报告最小输出：

```text
逐簇识别报告 {
    报告ID
    来源外设
    时间戳
    帧宽度
    帧高度
    外设配置摘要

    区域范围
    有效观察区域
    未识别区域
    候选区域
    像素归属账本
    观察像素簇集合
    每个簇的像素集合掩码
    每个簇的平面轮廓
    每个簇的平面轮廓中心点
    每个簇的平面轮廓稳定状态
    每个簇的彩色轮廓局部图
    每个簇的深度轮廓局部图
    每个簇的颜色 / 深度 / 空间 / 稳定性特征
    簇ID掩码
    新存在候选
    已有存在匹配候选
    未知区域
    冲突区域
    静止存在候选 / 环境存在候选 / 无效材料
    低置信区域
    不可观测区域
    证据不足原因
    可观测单位对应摘要
}
```

当前阶段默认主特征为 `平面轮廓`。平面轮廓用当前观察平面中的中心点和按遍历顺序保存的边界点表达，值类型为 `VecIU64 / VECIU64`。深度摘要、空间坐标摘要、子轮廓和颜色是辅助特征；空间极值轮廓和局部三维模型是升级特征，不作为逐簇识别报告可用的默认前置条件。

逐簇识别完成后可核对的三比较目标：

```text
双目相机.主观察运行模式 == 陌生环境逐簇识别
外设观察报告.生成状态 == 已生成
当前观察帧.观察像素簇集合状态 == 已生成
当前观察帧.存在候选集合状态 == 已生成
当前观察帧.已解释像素比例 > 最低解释比例
当前观察帧.未解释高价值区域数量 == 0
当前观察材料集.可观测单位对应摘要状态 == 已生成
```

其中 `当前观察帧.存在候选集合状态` 仍是接口层材料组织状态；`当前观察材料集.可观测单位对应摘要状态` 不是相机报告直接写入的事实，必须由自我承接观察像素簇后生成。相机报告本身只直接提供观察像素簇、掩码、局部图、稳定特征、质量缺口和失败原因。

注意：这里的“识别”不是语义识别，也不是稳定世界存在确认。旧文档里的像素级“100%”只表示外设帧材料内可寻址、可回查、无遗漏、无重复；当前规范里的对应闭合表示有效可观测单位已有稳定存在对应结果。

### 2.3 已识别场景扫描变化模式

扫描变化处理已识别区域中的已确认存在、已归属静止存在和环境存在。它回答：

```text
已知存在的位置变了吗？
范围变了吗？
深度变了吗？
距离变了吗？
遮挡状态变了吗？
像素归属变了吗？
是否出现未解释变化？
是否有新未知区域？
```

扫描不要求全场景已识别，只要求存在可扫描的已识别区域、该区域内的已确认存在 / 已归属静止存在 / 环境存在。没有上一外设帧 / 上一轮可比观察材料集时，只能用已合法外设数据项更新当前状态值 / 当前特征值并建立当前状态基准，不得输出发现存在或变化动态；有可比历史且特征值发生变化时，才输出状态变化信息。

扫描变化报告最小输出：

```text
扫描变化报告 {
    扫描变化报告ID
    来源外设
    时间戳
    区域基准ID / 场景基准ID
    扫描范围
    来源外设帧ID
    已知存在列表
    每个已知存在的当前特征值
    每个已知存在的特征值变化
    变化方向
    变化时间
    未解释变化区域
    需重识别区域
    扫描覆盖率
    材料质量
    冲突 / 证据不足原因
}
```

可直接满足的观察材料层特征目标：

```text
双目相机.主观察运行模式 == 已识别场景扫描变化
外设观察报告.生成状态 == 已生成
当前观察帧.变化候选集合状态 == 已生成
当前观察帧.扫描变化报告年龄 < 最大允许扫描变化报告年龄
当前观察帧.新增观察簇候选数量 == 0
当前观察帧.高风险未知簇数量 == 0
```

扫描变化模式应低频、低成本、保最新报告；旧扫描可丢弃，无变化时只更新缓存，不默认做局部细分或三维建模。扫描发现新区域、匹配失败或未解释变化过大时，只能输出未知区域 / 需重识别区域，不得直接确认新存在。

### 2.4 目标跟踪观察模式

跟踪处理指定已确认存在，主动忽略非目标存在。它回答：

```text
目标还在吗？
目标在哪里？
目标是否靠近 / 远离？
目标是否被遮挡？
目标是否丢失？
目标的目标特征是否变化？
```

第一版跟踪目标只允许已确认存在。跟踪必须有目标存在指针 / 引用、目标上一轮空间位置、空间尺寸、轮廓、ROI / 掩码 / 点集、目标特征和持续观察窗口。空间位置是跟踪定位的关键入口；如果空间位置不一致，必须用空间尺寸、轮廓等当前场景中可作为唯一凭证的特征找回目标，再输出新的空间坐标或空信息。外设内部候选编号、帧内编号或自我世界树内部 ID 只能作为回查引用，不得作为跟踪对应关键。候选目标跟踪只能作为后续扩展，不得把候选跟踪稳定直接写成已确认观察存在。

跟踪报告最小输出：

```text
跟踪报告 {
    目标存在指针 / 目标存在引用
    目标种子
    当前外设帧ID
    上一外设帧ID
    上一空间位置
    新空间坐标或空信息
    目标当前特征值
    目标变化量
    目标稳定性
    靠近 / 远离趋势
    遮挡状态
    丢失状态
    跟踪置信度
    冲突 / 证据不足原因
}
```

可直接满足的观察材料层特征目标：

```text
双目相机.主观察运行模式 == 目标跟踪观察
目标观察簇.跟踪状态 == 稳定
目标观察簇.丢失状态 == 未丢失
目标观察簇.最近观测年龄 < 最大允许观测年龄
目标观察簇.距离复现离散度 < 最大允许距离离散度
目标观察簇.空间坐标复现离散度 < 最大允许坐标离散度
```

跟踪报告不能证明当前场景存在集合明确、全场扫描完成或全场风险状态明确，只能证明指定目标的特征值变化明确。

### 2.5 观察像素簇功能

观察像素簇是双目相机外设输出的核心单位。

```text
观察像素簇 =
    当前观察帧内的一组像素集合
  + 像素集合掩码
  + 彩色轮廓局部图
  + 深度轮廓局部图
  + 颜色 / 深度 / 空间 / 轮廓 / 稳定性特征
```

每个观察像素簇至少包含：

```text
来源观察帧
来源外设
外设内部簇ID
像素集合引用
像素数量
边界框
图像中心点
```

掩码类特征：

```text
像素集合掩码
轮廓掩码
彩色轮廓掩码
深度轮廓掩码
深度有效性掩码
空间坐标有效性掩码
```

局部图特征：

```text
彩色轮廓局部图
深度轮廓局部图
局部图边界框
局部图到原帧坐标映射
```

这些不是证据附件，而是正式特征。它们后续用于：

```text
子轮廓提取
三维建模
像素归属判断
存在候选生成
当前观察材料集可观测单位对应情况统计
控制面板回查
```

## 3. 能力总结

双目相机外设能力仍分为三类：

```text
控制
检查
使用
```

外设本能方法只描述自我面向外设的动作契约，不描述相机内部采集、校正、匹配、滤波、分割等实现过程；这些内部过程属于外设私有领域。

因此，本节的控制、检查、使用能力是自我和任务管理可见的外设契约，不是双目相机线程内部的实现方式。相机线程内部可以直接用普通 C++ 类、线程循环、缓存、队列、算法模块和私有学习模块达成目标，只要最终输出符合外设命令、等待项、三种观察运行模式和对应报告的契约即可。

### 3.1 控制能力

控制能力改变外设自身状态。

```text
双目相机.可用状态 == 可用
双目相机.工作模式 == 指定模式
双目相机.观察配置状态 == 已应用
双目相机.占用状态 == 已释放
```

其中 `双目相机.工作模式` 只能表达物理采集配置或运行配置，不得表达逐簇识别、扫描变化、目标跟踪、补观察、局部细分等观察意图。对外观察意图应写入 `双目相机.主观察运行模式` 或外设等待项的 `观察运行模式`，且只允许三种外显模式。

自我 / 任务管理侧可见的边界方法或等价命令：

```text
双目相机_使达到可用状态
双目相机_设置观察配置
双目相机_释放
```

### 3.2 检查能力

检查能力确认外设自身状态。

```text
双目相机.运行可用性值 > 0
双目相机.工作质量状态 == 可用 / 降级可用 / 不可用
双目相机.当前配置对目标特征适用状态 == 适用 / 不适用
双目相机.目标特征稳定获取能力状态 == 已知
```

建议数值：

```text
双目相机.运行可用性值:
    0 = 不可用
    1 = 降级可用
    2 = 正常
```

自我 / 任务管理侧可见的边界方法或等价命令：

```text
双目相机_检查运行状态
双目相机_检查当前观察能力
```

### 3.3 使用能力

使用能力通过外设向自我提供观察材料。

```text
外设观察报告.生成状态 == 已生成
当前观察帧.观察像素簇集合状态 == 已生成
目标观察簇.稳定特征集合状态 == 已生成
```

自我 / 任务管理侧可见的边界方法或等价命令：

```text
双目相机_取得逐簇识别报告
双目相机_取得扫描变化报告
双目相机_取得跟踪报告
```

这些方法或等价命令只表达“需要取得观察材料”的请求和承接契约，不要求相机线程内部通过本能方法实现采集、校正、匹配、滤波、分割、分簇、掩码、局部图、重捕获或稳定特征计算。它们也不直接生成已确认观察存在、安全判断或服务结算。

## 4. 自我侧承接能力

相机输出观察材料后，自我侧负责承接和解释。

### 4.1 承接观察报告

```text
自我_承接双目相机观察报告
```

输出：

```text
当前观察帧.观察帧容器状态 == 已建立
外设观察报告.承接状态 == 已承接
```

### 4.2 承接观察像素簇集合

```text
自我_承接观察像素簇集合
```

输出：

```text
当前观察帧.观察像素簇集合承接状态 == 已承接
当前观察帧.观察像素簇数量 > 0
```

### 4.3 由观察像素簇生成存在候选

```text
自我_由观察像素簇生成存在候选
```

输出：

```text
当前观察帧.存在候选集合状态 == 已生成
当前观察帧.存在候选数量 > 0
```

存在候选必须引用：

```text
来源观察像素簇
像素集合掩码
彩色轮廓局部图
深度轮廓局部图
空间范围AABB
簇质量状态
稳定复现状态
```

### 4.4 统计当前观察材料集可观测单位对应情况

```text
自我_统计当前观察材料集可观测单位对应情况
```

输出：

```text
当前观察材料集.可观测单位对应摘要状态 == 已生成
当前观察材料集.有效可观测单位数量
当前观察材料集.已稳定对应存在可观测单位数量
当前观察材料集.未稳定对应存在可观测单位数量
当前观察材料集.多重对应冲突可观测单位数量
当前观察材料集.稳定对应存在数量
当前观察材料集.可观测单位存在对应闭合状态 == 闭合 / 未闭合
```

注意：

```text
可观测单位存在对应闭合 != 世界对象全部确认
存在候选 != 已确认观察存在
观察像素簇 != 稳定世界存在
```

## 5. 线程与消息模型

### 5.1 外设线程

双目相机有独占观察线程。

职责：

```text
1. 持续采集视野。
2. 生成逐簇识别报告。
3. 生成扫描变化报告。
4. 生成跟踪报告。
5. 生成观察像素簇集合。
6. 生成簇级掩码。
7. 生成彩色轮廓局部图。
8. 生成深度轮廓局部图。
9. 输出簇级稳定特征。
10. 写入外设观察队列和最新缓存。
```

### 5.2 任务管理工作线程

外设线程消息的第一接收者是任务管理工作线程。

职责：

```text
1. 接收外设观察消息。
2. 校验消息完整性。
3. 去重、时效检查。
4. 更新逐簇识别 / 扫描变化 / 跟踪缓存。
5. 匹配等待任务。
6. 匹配活跃需求。
7. 生成任务回执。
8. 生成派生需求消息。
9. 生成动作动态输入。
10. 上报提交入口裁决。
```

### 5.3 自我线程

自我线程不直接消费相机原始流。

职责：

```text
1. 接收任务管理侧上报。
2. 校验目标宿主、目标特征、比较符、目标值。
3. 校验来源因果 / 来源动态。
4. 去重、合并、循环截断。
5. 通过需求树统一更新指令入树。
6. 裁决哪些观察结果进入世界树。
```

## 6. 生产与消费模型

采用：

```text
外设主动生产；
队列缓存；
需求驱动消费。
```

流程：

```text
双目相机外设线程
    -> 外设观察消息队列
    -> 最新逐簇识别报告缓存
    -> 最新扫描变化报告缓存
    -> 最新跟踪报告缓存
    -> 最新稳定特征缓存
        -> 任务管理工作线程按正式需求消费
            -> 提交入口裁决入树 / 入世界
```

不是：

```text
自我根需求直接消费原始相机流。
```

## 7. 需求与因果接入

安全 / 服务根需求不直接消费相机队列。

正确流程：

```text
安全 / 服务根需求
    -> 任务筹办生成临时因果视图
    -> 观察缺口报告 / 派生观察需求消息
    -> 提交入口裁决入树
    -> 任务管理建立外设等待项
    -> 任务管理消费逐簇识别 / 扫描变化 / 跟踪报告
    -> 生成任务回执 / 动作动态输入
    -> 自我线程承接结果
```

示例需求：

```text
当前观察帧.观察像素簇集合状态 == 已生成
当前观察帧.存在候选集合状态 == 已生成
目标观察簇.跟踪状态 == 稳定
目标观察簇.距离复现离散度 < 最大允许距离离散度
```

其中 `当前观察帧.存在候选集合状态 == 已生成` 只能由自我承接和解释链满足，不能由相机报告直接满足。

所有需求比较符只允许：

```text
大于
小于
等于
```

“逐簇识别、扫描变化、跟踪、生成、稳定、承接”都是特征值或生成类型，不是方向。

## 8. 实时性与舍弃策略

实时性靠：

```text
少入账
少复制
少全图
按需深挖
分级报告
该舍弃的舍弃
```

### 8.1 报告分级

报告分级是三种外显运行模式报告内部材料的详细度分级，不是第四类外设模式。

```text
L0 快速报告:
    帧号、时间、粗簇、低质量区域、基础统计

L1 标准报告:
    观察像素簇集合、掩码、彩色轮廓局部图、深度轮廓局部图、摘要特征

L2 精细材料:
    稳定特征、跟踪结果、子轮廓、局部点集、三维范围
```

`L2 精细材料` 可以作为逐簇识别 / 扫描变化 / 跟踪报告的附带字段，或作为自我后续方法产物；不得被解释为独立的“局部细分外设模式”。

### 8.2 可以舍弃

```text
过期扫描变化报告
重复扫描变化报告
无需求命中的观察材料
低优先级局部细分
中间跟踪帧
低优先级配置学习样本
```

### 8.3 不能舍弃

```text
安全事件
活跃任务回执
状态跃迁
跟踪目标丢失
外设错误
影响父需求判断的缺口事实
```

### 8.4 实时性特征

```text
外设观察报告.报告年龄 < 最大允许报告年龄
外设观察报告.处理耗时 < 最大允许处理耗时
外设观察队列.积压数量 < 最大允许积压数量
外设观察线程.实时性达标状态 == 达标
外设观察线程.丢帧率 < 最大允许丢帧率
```

## 9. 外设内部学习能力

最多新增一个外设内部学习模块：

```text
双目相机稳定特征获取学习模块
```

学习目标：

```text
观察条件 + 外设配置 + 目标特征类型
    -> 特征稳定复现结果
```

输入：

```text
距离
ROI
分辨率
工作模式
光照摘要
纹理摘要
相机运动状态
目标运动状态
深度有效率
空间坐标有效率
复现离散度
失败次数
连续成功次数
```

输出给自我的摘要：

```text
双目相机.推荐观察配置状态 == 已生成
双目相机.当前配置对目标特征适用状态 == 适用
双目相机.目标特征稳定获取成功率 > 最低成功率
```

外设内部可以使用需求、任务、方法、学习逻辑，但属于外设内部，不进入自我需求树。

控制面板只读取自我承接后的结果，不读取相机原始预览作为真值。

可显示：

```text

扫描变化报告
跟踪报告
```

## 12. 验收标准

### 12.1 外设侧

```text
双目相机观察线程运行中。
逐簇识别报告可生成。
扫描变化报告可生成。
跟踪报告可生成。
观察像素簇集合状态 == 已生成。
每个簇有像素集合掩码。
每个簇有彩色轮廓局部图。
每个簇有深度轮廓局部图。
每个簇至少有一类稳定特征摘要。
```

### 12.2 任务管理侧

```text
能接收外设消息。
能匹配等待项。
能根据报告生成任务回执。
能根据质量缺口生成派生需求消息。
不会直接改需求树。
```

### 12.3 自我侧

```text
能承接观察报告。
能承接观察像素簇集合。
能由簇生成存在候选。
能统计当前观察材料集可观测单位对应情况。
能通过统一更新指令入树 / 入世界。
```

### 12.4 禁止宣称

```text
不宣称观察像素簇就是世界存在。
不宣称存在候选已经确认。
不宣称跨帧身份稳定。
不宣称语义识别完成。
不把控制面板显示成功当作业务验收通过。
不把旧文档中的像素级 100% 识别作为当前主目标。
```

## 13. 最终收束

```text
双目相机外设能力实现 =
    外设独占观察线程
  + 逐簇识别报告 / 扫描变化报告 / 跟踪报告
  + 观察像素簇作为主要输出单位
  + 掩码、彩色轮廓局部图、深度轮廓局部图作为簇级正式特征
  + 任务管理工作线程接收和消费外设消息
  + 提交入口裁决入树 / 入世界
  + 自我将观察像素簇承接为存在候选
  + 实时性分级与舍弃策略
```

一句话：

```text
相机负责把视野稳定切成带特征的观察簇；
任务管理负责把有需求命中的报告领走；
自我负责把这些簇变成存在候选，并决定哪些进入自己的世界。
```
