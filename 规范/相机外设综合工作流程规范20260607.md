## 1. 核心定案

```text
自我侧：
    产生需求、生成目标观察约束、消费外设结果、裁决入树、更新世界。

外设侧：
    独占线程运行，读取自我给出的目标观察约束，生成外设观察存在及相关特征。

任务管理工作线程：
    是外设消息第一承接者，负责接收、缓存、匹配等待项、转成任务回执 / 派生需求消息 / 动作动态输入。

正式认知链只承接：
    存在
    特征
    二次特征
    状态动态

D455 / RGB-D 工程技术定位：
    RealSense / OpenCV / 跟踪 / SLAM / TSDF / VOS 只能作为外设内部稳定化、关联、建图或供料技术；
    不得因为接入这些库就让自我直接识别世界存在。

D455 类外设综合链路分层：
    L0 原始帧层：RGB / Depth / IR / aligned depth。
    L1 深度与掩码稳定化层：深度后处理、形态学处理、孔洞填充、面积阈值、轮廓简化。
    L2 跨帧关联层：外设观察轨迹、中心 / 面积 / 深度 / 轮廓 / 掩码关联、预测和匹配。
    L3 稳定观察子集层：连续命中、丢失宽限、误差稳定和值域初步形成。
    L4 自我认知承接层：观察写新特征，识别定唯一，扫描比较变化，跟踪判断动态连续性。

层级归属：
    L0-L3 属于 D455 外设侧；
    L4 属于自我侧。

自我认知中不存在“背景”这个存在类别：
    视觉工程里所谓背景，必须转写为已归属静止存在、环境存在或低动态存在。
    过滤只能降低高成本处理频率，不能把存在从认知链中删除。

包 / 报告 / 队列项：
    只是线程通信容器，不能作为正式世界事实。
```

一句话：

```text
自我给外设观察约束，外设给自我外设观察存在；
任务管理分拣消息，自我裁决入账。
```

## 2. 总体链路

```text
自我根需求 / 普通需求
    -> 任务筹办生成临时因果视图
    -> 判断需要观察 / 识别 / 扫描 / 跟踪
    -> 生成目标观察约束特征组
    -> 任务管理创建外设等待项
    -> 相机外设线程读取约束并工作
    -> 外设线程生成外设观察存在 / 二次特征 / 状态动态输入
    -> 任务管理工作线程消费外设队列
    -> 自我线程裁决是否入需求树 / 世界树
    -> 自我方法完成观察、识别、扫描、跟踪、提交
```

该链路中：

```text
目标观察约束特征组不是世界事实；
外设等待项不是需求满足证据；
外设报告不是正式认知结果；
队列项不是因果节点；
提交入口裁决后的存在 / 特征 / 二次特征 / 状态动态，才可进入正式认知链。
```

## 3. 自我侧职责

自我侧负责：

```text
1. 从自我根需求、普通需求和世界树因果生成观察相关缺口。
2. 通过任务筹办生成临时因果视图，判断需要观察、识别、扫描还是跟踪。
3. 生成目标观察约束特征组。
4. 让任务管理创建外设等待项 / 订阅项。
5. 消费任务管理承接后的外设结果。
6. 校验目标宿主、目标特征、比较符、目标值、来源因果和来源动态。
7. 去重、合并、循环截断。
8. 经提交入口裁决入需求树 / 世界树。
```

自我侧不得：

```text
1. 直接吃相机原始流。
2. 把外设报告、队列项、材料页或目标观察约束写成正式事实主体。
3. 把外设结果直接解释成安全值、服务值或需求满足。
4. 用控制面板显示层反写世界树真值。
```

## 4. 目标观察约束特征组

目标观察约束特征组是自我给外设的观察约束，不是存在全量快照，也不是世界树事实。

第一版只允许表达：

```text
单目标存在
单目标特征
当前值
目标比较值域 / 误差
ROI / 掩码 / AABB / 点集
待识别像素掩码
TTL
约束generation
目标特征generation
来源材料generation
来源需求 / 来源任务 / 约束ID
```

目标观察约束用于：

```text
1. 指导观察只处理待识别区域。
2. 指导扫描只处理已归属、可比较且扫描优先级达标的区域。
3. 指导跟踪只处理指定目标窗口。
4. 让外设使用合法阈值、值域和质量约束生产材料。
```

目标观察约束不得用于：

```text
1. 作为提交入口事实主体。
2. 代替自我存在的一阶特征。
3. 证明当前场景明确、风险明确或需求满足。
```

## 5. 任务管理工作线程职责

任务管理工作线程是外设消息第一承接者。

负责：

```text
1. 接收外设观察消息。
2. 缓存外设观察报告、材料页、稳定特征摘要和错误状态。
3. 校验完整性、去重和时效。
4. 匹配外设等待项 / 订阅项。
5. 匹配活跃任务和活跃需求。
6. 根据质量门判断可用 / 优质 / 不合格。
7. 命中等待项时生成任务回执。
8. 发现缺口时生成派生需求消息。
9. 生成动作动态输入或观察事实承接请求。
10. 无需求命中时仅缓存或按舍弃策略丢弃。
```

不得：

```text
1. 直接写需求树。
2. 直接写世界树真值。
3. 直接结算安全 / 服务值。
4. 把报告、包、队列项或目标观察约束当事实主体。
```

## 6. 外设侧职责

双目相机 / D455 类外设侧负责：

```text
1. 独立控制域 / 独占线程运行。
2. 读取命令队列中的控制 / 检查 / 使用请求。
3. 读取目标观察约束特征组。
4. 按三种观察运行方式执行观察、扫描或跟踪。
5. 先在外设内部完成 L0-L3 稳定观察子集生成，再生成可供自我承接的外设观察存在、观察特征、二次比较特征和状态动态输入。
6. 把结果写入外设消息队列 / 缓存。
7. 记录外设错误、超时、降级、丢弃和质量不足原因。
```

外设侧不得：

```text
1. 直接写自我需求树。
2. 直接写世界树真值。
3. 直接确认自我所在场景中的已确认观察存在。
4. 直接完成安全 / 服务价值结算。
5. 把外设内部跟踪ID当作自我世界存在ID。
6. 把内部采集、校正、滤波、分割、跟踪、重捕获等私有步骤登记成自我层本能方法。
```

### 6.1 D455 内部稳定观察子集生成层

D455 外设线程必须把“单帧簇”与“稳定外设观察存在”分开。

```text
原始簇：
    单帧分割结果，只能作为 L0 / L1 材料缓存、诊断和回查，不能提交为观察存在。

候选簇：
    已通过单帧质量门，但跨帧未稳定，只能进入 L2 轨迹关联。

稳定外设观察存在：
    跨帧关联稳定，连续命中、丢失宽限、中心 / 面积 / 深度 / 轮廓 / 掩码误差已达标，特征值域初步形成。

可提交观察材料：
    稳定外设观察存在 + 关键特征达标 + 来源可回查 + generation / TTL 有效。
```

外设报告质量不得再只用一个“优质”状态承接全部判断，必须至少区分：

```text
单帧材料质量等级
跨帧稳定质量等级
外设观察存在提交状态
```

只有三者同时成立，才允许进入观察正式链、识别唯一性判断、扫描变化候选或跟踪动态候选。

稳定观察子集成立条件至少包括：

```text
连续命中帧数 > 最小命中帧数
连续丢失帧数 < 最大丢失帧数
中心误差方差 < 最大中心误差方差
面积误差方差 < 最大面积误差方差
深度误差方差 < 最大深度误差方差
轮廓误差方差 < 最大轮廓误差方差
硬冲突数量 == 0
```

由此形成的：

```text
外设观察存在.平面轮廓值域
外设观察存在.中心坐标值域
外设观察存在.面积值域
外设观察存在.深度摘要值域
```

仍然只是外设观察值域 / 观察稳定值域，不是世界存在永久值域。识别成功并入自我场景后，才可能转成自我观察存在的特征值域。

可选增强模块只能按下列归属接入：

```text
RealSense 深度后处理：
    D455 内部深度稳定化模块。输出过滤后深度、深度有效性掩码、深度稳定性摘要和处理配置摘要；不得覆盖原始深度事实。

OpenCV / Kalman / Hungarian / ByteTrack 类关联：
    D455 内部跨帧观察轨迹模块。用于预测、匹配、重捕获和低置信候选恢复；外设内部轨迹ID不得当作自我世界存在ID。

SLAM：
    可选提供相机位姿、关键帧、空间基准和地图坐标系状态；不得直接写世界存在。

TSDF：
    可选用于高价值静止存在或操作对象的局部表面稳定化；不得作为默认识别路径。

OctoMap / 占据栅格：
    可选用于空间占据、未知空间、障碍和安全风险材料；不是存在同一性识别器。

SAM2 / VOS：
    可选用于指定目标 mask 级跟踪、复杂遮挡或高价值服务目标；不得进入第一阶段默认全场主链。
```

## 7. 四个自我侧本能方法关系

四个方法不是非此即彼，而是互相支撑。

```text
观察：
    消费稳定外设观察存在。
    合法写入新的外设观察存在和新的外设观察一阶特征值。
    当前阶段默认主一阶观察特征为平面轮廓。
    完成条件不得只看单帧优质，必须看稳定外设观察存在数量、净待识别像素数量和关键稳定值域。

识别：
    不写新一阶特征。
    用稳定外设观察存在与自我场景已有存在的已有特征，判断是否对应当前识别范围中的唯一自我存在。
    平面轮廓可作为当前阶段确定唯一存在的主特征。
    不得依赖跳动的单帧候选直接新建已确认存在。

扫描：
    不作为新一阶观察特征生产者。
    只比较已归属存在、上一轮基准、当前稳定观察子集和特征值域，发现变化候选、值域冲突或状态动态。
    当前阶段默认比较已归属存在的平面轮廓变化。
    若需要把新一阶特征值正式入世界，必须回观察或经提交入口另行裁决。
    大量新增、不稳定或未归属材料出现时，停止生成变化动态，转入观察或识别。

跟踪：
    不作为新一阶观察特征生产者。
    只围绕指定已归属存在、稳定目标种子、轨迹预测、观测关联、值域区间和预测区间判断动态连续性。
    当前阶段默认用平面轮廓中心预测目标窗口，用平面轮廓匹配确认目标连续性。
    如果需要新特征值，回到观察。
    低置信候选可用于重捕获和轨迹恢复，但不得直接写成跟踪成功事实。
```

### 7.1 平面轮廓特征定案

当前阶段的相机观察默认特征优先级为：

```text
默认主特征：
    平面轮廓

辅助特征：
    平面中心坐标
    轮廓面积
    轮廓掩码
    子轮廓
    深度摘要
    空间坐标摘要
    颜色

升级特征：
    空间极值轮廓
    局部三维模型
```

`平面轮廓` 的底层值类型为 `VecIU64 / VECIU64`，但业务读取时必须按 `平面轮廓` 特征类型解释为 `VecI64` 二维坐标链：第一个二维坐标为轮廓中心点，后续二维坐标为按轮廓遍历顺序保存的边界点。写入时先形成逻辑 `VecI64`，再通过 I64 到 U64 的 ZigZag 编码存入底层 `VecIU64`；读取时按相同规则解码。类型信息不放入 `特征值主信息类`，由特征类型解释。

`空间极值轮廓` 的底层值类型同样为 `VecIU64 / VECIU64`，业务读取时按 `空间极值轮廓` 特征类型解释为 `VecI64` 三维坐标链：第一个三维坐标为空间中心，后续三维坐标为空间极值点 / 边界点，后续点按采集顺序保存。它只在平面轮廓不够唯一或任务需要空间操作、碰撞、支撑、抓取、距离和三维占位判断时升级使用。

平面轮廓适用于当前视野内稳定识别、扫描变化、目标跟踪和场景复现。空间极值轮廓、立方体中心和局部三维模型不作为当前默认路径。

平面轮廓匹配状态必须由量化二次特征推出：

```text
掩码重合率 > 最低掩码重合率
轮廓点平均误差 < 最大允许平均误差
轮廓点最大误差 < 最大允许最大误差
综合轮廓匹配评分 > 最低轮廓匹配评分
硬冲突数量 == 0
    -> 平面轮廓匹配状态 == 匹配
```

## 8. 三种相机运行方式

外设侧只暴露三种高层运行方式：

```text
1. 陌生环境逐个观察
2. 已识别场景扫描变化
3. 目标跟踪观察
```

### 8.1 陌生环境逐个观察

用途：

```text
场景未知；
待识别像素多；
需要生成新的外设观察存在。
```

核心输入：

```text
待识别像素掩码
ROI
期望特征类型
质量阈值
稳定阈值
```

核心输出：

```text
外设观察存在
外设观察存在.平面轮廓
外设观察存在.平面轮廓状态 == 已生成
外设观察存在.平面轮廓基准状态 == 已建立
外设观察存在.平面轮廓稳定状态 == 稳定 / 不稳定 / 证据不足
外设观察存在.基准状态 == 已建立
外设观察存在.稳定复现状态 == 稳定
外设观察存在.观察完成状态 == 已完成 / 部分完成 / 证据不足
```

### 8.2 已识别场景扫描变化

用途：

```text
场景已有归属存在集合；
扫描只找已有存在有没有变化。
```

核心输入：

```text
已归属存在掩码
已归属静止存在低优先级处理掩码
已归属静止存在空间占位集
扫描候选掩码
上一轮基准特征
存在特征值域
```

核心输出：

```text
变化候选
值域冲突
无变化事实
当前平面轮廓_基准平面轮廓.轮廓差异值
当前平面轮廓_基准平面轮廓.掩码重合率
当前平面轮廓_基准平面轮廓.变化候选状态
下一轮基准更新线索
```

扫描不能写：

```text
存在.平面轮廓 = 新轮廓
```

如果需要新平面轮廓正式入账，必须进入观察。扫描只允许生成平面轮廓变化二次特征、值域冲突、变化候选或状态动态。

扫描不直接确认新存在。若扫描中发现大量新区域或新特征：

```text
扫描范围.净待识别像素数量 > 阈值
或
扫描范围.未归属外设观察存在数量 > 阈值
```

则进入观察或识别。

### 8.3 目标跟踪观察

用途：

```text
存在或自我处于移动 / 变化过程中；
需要连续获得指定目标的动态状态。
```

核心输入：

```text
目标存在ID
ROI / 掩码 / AABB / 点集
当前有效基准
细分值域区间
预测区间
最大允许预测误差
```

核心输出：

```text
目标存在.跟踪状态 == 稳定 / 不稳定 / 丢失 / 遮挡 / 冲突
目标存在.轮廓跟踪状态 == 稳定 / 不稳定 / 丢失 / 冲突
目标存在.预测误差值
目标存在.平面中心预测误差值
目标存在.轮廓匹配评分
目标存在.当前值域区间ID
目标存在.非法区间跳变次数
状态动态
```

## 9. 待识别像素与过滤机制

外设不能重复完整观察已经完成的区域。

```text
粗待识别像素 =
    全部像素 - 已归入观察存在像素

已归入观察存在像素包含：
    动态存在像素
    静止存在像素
    环境存在像素

净待识别像素 =
    粗待识别像素
    - 不可观测区域像素
    - 低于最小识别尺寸区域像素
    - 已解释但暂不需要细分的低价值区域像素
```

不得再使用 `背景像素` 作为扣减项。墙面、地面、桌面、固定支架等如果已稳定归属，应计入 `已归入观察存在像素` 中的静止存在或环境存在；如果尚未稳定归属，则仍是待识别、待复验或低质量材料，不得直接写成背景。

对应特征：

```text
当前观察帧.已归属静止存在像素掩码状态 == 已生成
当前观察帧.已归属动态存在像素掩码状态 == 已生成
当前观察帧.净待识别像素掩码状态 == 已生成
当前观察帧.净待识别像素数量 < 最大允许净待识别像素数量
当前观察帧.高价值待识别区域数量 == 0
当前场景.已归属静止存在空间占位集状态 == 已生成
当前场景.静止存在低频维护状态 == 运行中 / 暂停 / 过期
```

过滤输入：

```text
已观察完成掩码
已归属存在掩码
已归属静止存在低优先级处理掩码
已归属静止存在空间占位集
待识别像素掩码
扫描候选掩码
跟踪目标掩码
空间占位过滤集合
```

作用：

```text
观察只处理待识别区域；
扫描只处理已归属、可比较、扫描优先级达标且当前任务 / 安全 / 服务相关的区域；
跟踪只处理指定目标窗口；
静止存在默认不进入高频扫描，但进入低频扫描维护；
静止存在发生特征变化、值域冲突、遮挡变化或安全 / 服务需求命中时，可以重新进入观察、识别、扫描或跟踪；
已观察完成区域默认不再完整观察。
```

静止存在状态不得由画面像素不动直接写入。只有在场景坐标、空间坐标或相机位姿补偿后的坐标中满足量化稳定条件时，才可写入：

```text
存在.运动状态 == 静止
存在.静止确认状态 == 已确认
```

最小判定条件：

```text
存在.空间中心变化值 < 最大静止中心变化阈值
存在.空间范围变化值 < 最大静止范围变化阈值
存在.轮廓偏差值 < 最大静止轮廓偏差阈值
存在.掩码变化率 < 最大静止掩码变化阈值
存在.连续静止观测次数 > 最小静止确认次数
存在.非法跳变次数 == 0
```

如果没有相机位姿或空间坐标补偿，只能写：

```text
存在.图像相对稳定状态 == 稳定
```

不能直接写：

```text
存在.运动状态 == 静止
```

## 10. 识别唯一性原则

识别不要求所有特征都比完。

识别完成条件：

```text
当前识别范围状态 == 已确定
外设观察存在.可复验状态 == 可复验
候选集合数量 == 1
硬冲突数量 == 0
用于唯一识别特征数量 > 0
归属映射状态 == 已建立
```

只要一个特征或多个特征组合能够在当前识别范围内确定唯一存在，就可以完成识别。

```text
候选数量 > 1:
    继续使用已有特征缩小候选。

已有特征不足以唯一:
    进入观察补完。

唯一但硬冲突 > 0:
    进入观察复验。
```

## 11. 基准更新规则

观察和跟踪不能永远围绕第一帧比较。应区分：

```text
初始基准
当前有效基准
滚动基准
```

基准更新条件：

```text
匹配状态 == 匹配
丢失状态 == 未丢失
关键特征误差值 < 最大允许误差
连续稳定帧数 > 最小稳定帧数
非法区间跳变次数 == 0
质量状态 == 可用 / 降级可用
```

基准冻结条件：

```text
掩码重合率 < 最低掩码重合率
轮廓偏差 > 最大允许轮廓偏差
当前值超出特征值域
目标区域待识别像素增加
疑似拆分 / 合并 / 遮挡
```

## 12. 启动相机外设运行的需求因果

相机不是为某个固定方法启动，而是当父需求需要外设观察材料时自然派生启动需求。

通用因果：

```text
父需求需要：
    外设观察存在
    或 新的一阶观察特征值
    或 已归属存在变化比较材料
    或 指定存在跟踪比较材料

因此需要：
    双目相机线程.运行状态 == 运行中
    双目相机.可用状态 == 可用
    双目相机.运行可用性值 > 0
    外设等待项.状态 == 已建立
    目标观察约束特征组.状态 == 可用，若扫描/跟踪需要约束
```

因果链：

```text
父需求目标
    -> 临时因果视图
    -> 选择观察 / 识别 / 扫描 / 跟踪路径
    -> 发现外设材料前置缺口
    -> 双目相机线程.运行状态 == 运行中
    -> 双目相机.可用状态 == 可用
    -> 双目相机.运行可用性值 > 0
    -> 外设等待项.状态 == 已建立
    -> 外设产生对应观察材料
    -> 任务管理消费
    -> 自我方法输出存在 / 特征 / 二次特征 / 状态动态
    -> 提交入口裁决
    -> 父需求目标回查
```

## 13. 合法来源规则

必须作为硬规则执行：

```text
所有特征值必须有合法来源。
所有阈值必须有来源。
所有枚举状态必须有量化判定规则。
所有状态动态必须有输入特征、输出特征、来源方法和来源需求。
```

例如：

```text
外设观察存在.匹配状态 == 匹配
```

必须由：

```text
匹配评分 > 最低匹配评分
硬冲突数量 == 0
连续匹配帧数 > 最小连续匹配帧数
```

推出。

`最大允许误差` 来源必须是：

```text
特征类型默认值域
外设测量不确定度
存在历史稳定值域
当前任务容差
安全 / 服务约束
外设学习结果
```

## 14. 实时性和舍弃策略

为保证效率：

```text
已经观察完成的区域不完整重观察；
静止存在不进入高频扫描，改由低频扫描维护；
扫描不扫所有簇，只扫扫描候选；
跟踪只处理指定目标；
无需求命中的外设消息只缓存或丢弃。
```

可以舍弃：

```text
过期扫描材料
重复扫描材料
无需求命中的材料
低优先级局部细分
中间跟踪帧
低优先级配置学习样本
```

不能舍弃：

```text
安全事件
活跃任务回执
状态跃迁
跟踪目标丢失
外设错误
影响父需求判断的缺口事实
```

## 16. 禁止项

```text
1. 不得让外设线程直接写需求树、世界树、安全值或服务值。
2. 不得让自我线程直接消费高频相机原始流。
3. 不得把包 / 报告 / 队列项 / 材料页 / 目标观察约束作为事实主体。
4. 不得把扫描或跟踪写成新一阶特征裸写入口。
5. 不得把识别写成全特征比对完成。
6. 不得把当前范围唯一扩大成全世界唯一。
7. 不得把外设内部跟踪ID当成自我世界存在ID。
8. 不得把控制面板显示成功当作业务验收通过。
9. 不得把无需求命中的外设消息上报成正式认知。
10. 不得用模拟样本、夹具入口或伪造动作动态证明相机链路通过。
11. 不得把背景写成自我认知对象、非存在、无意义区域或归属目标。
12. 不得把图像相对稳定直接写成存在运动状态静止。
```

## 17. 最终定案

```text
相机外设综合工作流程分为自我侧和外设侧。

自我侧：
    根据需求和世界树因果选择观察、识别、扫描或跟踪路径；
    向外设提供目标观察约束特征组；
    由任务管理线程消费外设结果；
    自我线程裁决入树；
    正式承接存在、特征、二次特征和状态动态。

外设侧：
    独占线程运行；
    读取目标观察约束；
    根据模式执行观察、扫描或跟踪；
    观察可合法写入新的外设观察特征值；
    扫描和跟踪只做比较，不裸写新特征值；
    输出结果进入队列，由任务管理消费。

识别：
    不写新特征值；
    用已有特征在当前场景范围内收敛唯一存在。
```

一句话：

```text
自我决定看什么、为什么看、结果是否入账；
相机负责按约束稳定给出外设观察存在和可比较特征；
观察写新值，识别定唯一，扫描记变化，跟踪守动态。
```
