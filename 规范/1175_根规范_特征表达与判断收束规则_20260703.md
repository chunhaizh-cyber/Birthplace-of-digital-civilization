# 1175 根规范 特征表达与判断收束规则

编号：1175
日期：20260703
状态：正式根规范
权威等级：正式根规范
代码锚点：无单一主信息类代码锚点；本规范约束特征、特征值、复合特征、二次特征、状态和外设材料的表达方式。

## 1. 根定位

本规范定义全项目特征系统的基础表达语法：

```text
材料是什么；
测量值是什么；
状态是什么；
判断是什么；
判断如何由证据收束；
什么可以写成一阶特征；
什么必须写成复合特征、二次特征、状态节点或治理方法结果。
```

本规范不替代：

```text
规范/1120_根规范_抽象特征主信息类_20260701.md
规范/1130_根规范_特征节点主信息类_20260701.md
规范/1180_根规范_二次特征主信息类_20260701.md
规范/2100_根规范_特征值主信息类_20260701.md
```

它只规定这些结构在表达“材料、测量、状态、判断和收束”时的合法边界。

## 3. 核心原则

```text
特征系统不得把判断结果伪装成直接事实。
```

普通一阶特征只能记录可直接取得、可测量、可计数、可评分、可引用、可追溯的材料值。

凡特征值依赖其它特征、评分、数量、版本、来源、阈值、任务上下文或治理裁决推导而来，无论其值类型是 bool、I64 枚举还是其它离散状态，都属于判断型特征值，必须声明：

```text
依赖特征族
收束规则
写入方
读取方
失败分流
验证证据
来源动态 / 规则证据
```

判断型枚举不是一阶事实。判断型 bool 也不是一阶事实。二者必须由复合特征、二次特征、内部治理节点或指定方法收束产生。

## 4. 基本分类

### 4.1 一阶特征

一阶特征是宿主上可直接取得、测量、计数、评分、引用或追溯的材料值。它可以是：

```text
原始材料句柄
测量值
计数值
评分值
版本值
来源值
可解析引用
直接采集到的原始分类码
由唯一生命周期入口推进的生命周期码
```

一阶特征不得承载：

```text
需求满足结论
任务完成结论
材料是否满足当前任务阈值
世界树稳定存在确认
材料与已有存在唯一归属
安全 / 服务可结算结论
根据多个证据综合得出的可用 / 不可用 / 已明确 / 已完成状态
```

### 4.2 复合特征

复合特征表示具名子特征组成关系。复合特征的直接子链只能保存组成子特征，不得混入：

```text
判定日志
普通函数返回值
错误码
UI 状态
临时缓存
说明文本
硬编码领域词
```

综合判定规则应放在定义视图、规则节点、二次特征、状态节点、治理方法或运行期只读视图中。复合特征本体不是判断日志容器。

### 4.3 二次特征

二次特征承载关系性、比较性、方向性和聚合性判断。它可以表达：

```text
值是否完整
是否可比较
变化方向
距离关系
覆盖关系
稳定性关系
归属冲突
候选唯一性
任务范围内是否满足某个阈值
```

二次特征不得替代一阶特征值、状态事实、动态事实或因果账本。二次特征的判断必须能回查输入事实和比较规则。

### 4.4 状态节点与治理收束状态

状态节点或治理收束状态用于记录内部流程或方法执行后的阶段性结论。它可以承载判断收束结果，但必须保留：

```text
来源方法或合法流程入口
输入材料
判定规则
输出宿主
输出特征或状态
来源动态 / 规则证据
有效范围和有效期
```

状态收束结果不得被反向解释为对象本体永久属性。

## 5. 值类型合法边界

### 5.1 直接取得值

直接取得值来自外设、用户输入、内部结构读取或明确提交入口。它必须满足：

```text
来源可追溯
宿主明确
特征类型明确
值域明确
写入入口明确
```

普通函数返回值、日志文本、控制台输出和 UI 显示不构成直接取得值。

### 5.2 测量值、计数值和评分值

测量值、计数值和评分值可以是一阶特征，但只能表示材料证据本身。例如：

```text
观察帧时间戳
帧宽
帧高
有效深度像素数量
无效深度像素数量
深度缺失比例Q10000
深度噪声评分Q10000
曝光评分Q10000
运动模糊评分Q10000
彩色深度对齐残差Q10000
坐标变换版本
```

评分值不得直接替代判断结论。`质量评分高` 不能直接等同于 `材料质量状态 = 可用`，除非经过正式收束规则、任务阈值和证据回查。

### 5.3 句柄值、版本值和来源值

句柄值、版本值和来源值可以是一阶特征，用于追溯材料和建立引用关系。例如：

```text
原始深度帧句柄
原始颜色帧句柄
空间点材料句柄
材料页句柄
来源外设句柄
D455 到场景变换版本
场景体素版本
```

句柄有效不等于材料可用；版本一致不等于判断已完成。它们只是后续收束的输入材料。

### 5.4 原始分类型枚举

原始分类型枚举可以作为一阶状态，前提是来源和值域明确。例如：

```text
外设类型：D455 / 麦克风 / 触觉传感器
帧格式：深度帧 / 彩色帧 / 红外帧
数据来源类型：原始外设 / 派生材料 / 场景体素先验
坐标系类型：D455局部 / 自我坐标 / 场景坐标
材料存储层：短期材料页 / 运行期仓库 / 可回查归档
```

原始分类型枚举只表达分类码，不表达质量、可用性、完成度、归属或满足结论。

### 5.5 生命周期型枚举

生命周期型枚举可以作为一阶状态，前提是唯一写入方和回执证据明确。例如：

```text
观察帧存在状态：已生成 / 已归档 / 已过期
任务状态：筹办中 / 执行中 / 已收束
材料页状态：已创建 / 已释放 / 句柄失效
```

生命周期型枚举若参与需求、任务、因果、安全 / 服务调度或世界状态更新，必须记录合法流程入口和动作动态 / 来源动态 / 规则证据。

### 5.6 判断型枚举

判断型枚举不得作为外设、日志、普通函数或控制面板直接写入的一阶事实。例如：

```text
材料质量状态：可用 / 低质量 / 不可用 / 部分可用 / 需复验
归属状态：已归属 / 冲突 / 证据不足
稳定复现状态：稳定 / 不稳定 / 需复验
提交候选判定状态：可提交 / 阻断 / 需复验
遮挡解释状态：未遮挡 / 部分遮挡 / 自由空间冲突
基础风险判断状态：已明确 / 未明确 / 证据不足
```

判断型枚举必须由其它特征、评分、数量、版本、来源、阈值、任务上下文或治理裁决收束而来。它必须声明输入特征族和收束规则。

### 5.7 bool 与二值状态

普通函数返回 `bool` 不得直接入账为特征值。

判断型 bool 只能作为复合特征、二次特征、状态节点或治理方法的收束结果进入后续判断。若某个二态值确实来自直接采集或唯一生命周期入口，不按判断型 bool 处理，应按原始分类型枚举、生命周期型枚举或明确值域的一阶材料值表达，并写清来源。

不得用 `true / false` 掩盖：

```text
材料证据是否齐全
阈值是否满足
候选是否唯一
归属是否冲突
状态是否已明确
需求是否满足
任务是否完成
```

这些都必须展开为依赖特征族和收束规则。

## 6. 判断收束要求

凡是判断型特征值，必须至少给出：

| 项 | 要求 |
| --- | --- |
| 输入特征族 | 哪些一阶特征、二次特征、状态、动态或因果证据参与判断 |
| 收束规则 | 如何从输入推出目标状态，包含阈值、比较规则和冲突处理 |
| 写入方 | 哪个方法、治理节点或合法流程入口写入 |
| 读取方 | 哪些需求、任务、方法、提交入口或后续判断可以读取 |
| 失败分流 | 输入不足、冲突、过期、不可回查、阈值不满足时如何输出缺口 |
| 可回查证据 | 输入材料、来源动态、规则证据和有效期如何回查 |

判断收束不得靠以下方式成立：

```text
日志里写成功
UI 显示可用
外设报告文本写可提交
普通函数返回 true
错误码为 0
单个评分超过阈值
控制面板显示了叠加结果
说明书或详细设计描述了应当成功
```

## 7. 外设材料边界

外设侧是材料来源，不是自我事实裁决者。D455 等外设观察材料应分为：

```text
原始外设材料
观察派生材料
低层诊断候选
自我 / 中间层收束状态
```

外设侧可以直接生成：

```text
观察帧时间戳
来源外设句柄
帧宽
帧高
深度图句柄
颜色图句柄
空间点句柄
原始材料页句柄
帧序号
外设温度
曝光参数
帧间隔
丢帧计数
深度有效像素数量
无效深度像素数量
深度缺失比例
深度噪声评分
彩色深度对齐残差
相机姿态置信度
D455 到场景变换版本
低层分割候选
轮廓掩码材料
局部体素证据
质量评分候选
```

外设侧不得直接生成：

```text
材料质量状态 = 可用
观察结果包可提交
观察候选可入账
当前材料满足需求阈值
当前观察足以更新某存在的某特征
稳定存在确认
世界树存在归属
需求满足状态
安全 / 服务可结算结论
```

上述判断必须由观察侧、中间层质量收束方法、自我认知链或指定治理方法结合当前需求、任务、场景上下文和证据回查后产生。

## 8. 材料质量状态示例

`材料质量状态` 可以保留为内部收束状态，但不得写成外设直接产出的一阶普通特征。它应是观察材料质量判定复合特征或质量收束方法的结果状态。

材料质量状态至少依赖以下特征族：

```text
来源与可回查
时间与新鲜度
深度有效性
彩色 / 红外质量
坐标基准
ROI / 掩码 / 候选完整性
当前任务阈值
跨帧稳定性
先验冲突
```

状态值只表示收束出口：

```text
未评估：质量判定尚未运行，或必要一阶特征不足。
可用：当前目标所需材料、坐标基准、时效和质量评分达到当前任务阈值。
低质量：材料可回查，但不足以支撑正式确认，可作为弱证据或缺口来源。
不可用：关键材料缺失、句柄失效、坐标基准无法建立、过期或错域。
部分可用：局部 ROI、候选或特征族可用，但全帧或全目标不可完整使用。
需复验：存在冲突、过期、遮挡、候选争议或跨帧不稳定，单次材料不足以裁决。
```

不得为每个状态值新建独立结构。应由同一组质量判定特征族经不同判定路径收束到不同状态。

## 10. 禁止项

```text
1. 禁止把判断结果伪装成一阶事实。
2. 禁止把判断型枚举写成外设直接产出。
3. 禁止把普通函数 bool 返回值写成正式特征值。
4. 禁止把单个评分、错误码或日志文本替代收束规则。
5. 禁止把材料质量状态、归属状态、稳定复现状态或可提交状态写成无来源状态。
6. 禁止用说明书、详细设计、控制面板或运行日志承载机器判断。
7. 禁止为判断型状态新增自由字段、说明字段或临时结构体绕过项目通用结构。
8. 禁止把外设候选编号、帧内编号或内部跟踪 ID 当作世界树稳定存在 ID。
9. 禁止把二次特征或治理收束状态反写成对象本体永久一阶特征。
10. 禁止在没有输入特征族、收束规则和证据回查的情况下声明需求满足、任务完成或判断已明确。
```

2. 本规范只给出特征表达和判断收束语法，不声明任何具体代码已实现。
3. 本规范不能作为业务闭环完成、自我苏醒完成或初步成熟完成的证据。
4. 需要展开历史论证时，只能把 `规范/旧规范/` 中的原文件作为追溯材料，不得让旧文件反向覆盖本规范。
