# 0300 规范冲突与前后矛盾清单

编号：0300
日期：20260701
状态：正式冲突处理记录

## 1. 处理原则

本清单记录旧规范中的冲突锚点和当前正式处理结果。旧规范已迁入 `规范/旧规范/`，只作历史参考。

当前 `规范/` 根目录中的正式规范和 `规范/规范目录.md` 是后续实现、计划和验收的权威依据；旧规范不得反向覆盖当前正式规范。

## 2. 冲突处理清单

| 编号 | 冲突锚点 | 当前代码 / 上级口径 | 当前处理结果 |
| --- | --- | --- | --- |
| C001 | 旧规范仍出现 `词性主信息类` | 当前代码定义为 `语素入口主信息类`，其中 `词性` 是人类词性兼容字段和入口候选来源 | 当前正式规范统一为 `语素入口主信息类`，保留“人类词性 / 信息入口类型”区分 |
| C002 | 旧规范出现 `实例特征主信息类` | 当前代码只定义 `特征节点主信息类`，实例特征由特征节点加抽象特征、宿主和值承载 | 当前正式规范删除独立 `实例特征主信息类` 口径 |
| C003 | 旧规范出现 `抽象存在主信息类` | 当前代码只定义 `存在节点主信息类`；抽象存在是普通存在节点的概念侧用法 | 当前正式规范删除独立 `抽象存在主信息类` 口径 |
| C004 | “动态模板根”与“变化 / 抽象动态”边界混用 | `变化` 保留为动态抽象链最高兜底根名；可用于匹配、筹办和规范表达的有效动态抽象单元统一称为 `抽象动态` | 当前正式规范将“动态模板根”统一迁移为“抽象动态”，不再作为独立根名或并列结构 |
| C005 | “状态集合 / 抽象状态树”与抽象特征树边界混用 | 抽象状态树不再作为独立权威结构；状态抽象直接由抽象特征树承载 | 当前正式规范删除独立抽象状态树口径，统一回归抽象特征根规范 |
| C006 | 部分观察规范把外设帧、报告、材料页写得接近事实入口 | 已确认外设只供应材料，自我提交入口裁决后才能形成世界树事实 | 当前正式规范按材料供应与提交入口裁决分层，观察、识别、扫描、跟踪不得绕过提交入口 |
| C007 | 因果规范中历史置信分字段口径 | `因果主信息类` 只存基础计数和证据锚点；置信分只允许作为解释层、调试层或统计层派生值 | 当前正式规范禁止把置信分、成功率、稳定度写成因果主信息本体字段 |
| C008 | 任务筹办 / 任务执行被描述成能力入口的旧语义 | 当前硬规则要求任务筹办 / 任务执行只是任务管理生命周期普通函数 | 当前正式规范删除本能方法化口径，任务筹办 / 任务执行不得作为方法注册、选择或动作动态来源 |

## 3. 当前结论

当前正式规范已按当前代码和上级硬规则收束 C001-C008。旧规范目录中的历史表述不得作为后续实现、计划或验收的当前权威依据。
