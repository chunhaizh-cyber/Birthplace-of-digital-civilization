# 0100 编号规则与重排预留说明

编号：0100
日期：20260701
状态：正式编号规则
权威等级：正式编号规则

## 1. 命名格式

当前正式规范文件采用：

```text
编号_文档类型_主题_YYYYMMDD.md
```

示例：

```text
1120_根规范_抽象特征主信息类_20260701.md
```

## 2. 编号原则

1. 编号是当前 `规范/规范目录.md` 使用的正式目录编号。
2. 编号按大段预留，允许后续重排。
3. 同族主信息类优先放在相邻十位，方便插入新的中间层根规范。
4. 后续重排必须同步更新 `规范/规范目录.md`、文件名、引用矩阵和修订记录。

## 3. 日期规则

1. 文件内容实质修改时，文件名尾部日期必须更新。
2. 只改错字、链接或格式但不改变规范含义时，也必须在修订记录中说明。
3. 日期更新后，引用矩阵和总索引中的文件名必须同步更新。

## 4. 重排规则

1. 重排编号不得改变规范含义。
2. 重排必须保留旧编号到新编号的映射记录。
3. 重排后必须检查总索引、覆盖矩阵、冲突清单和缺失清单中的文件引用。
