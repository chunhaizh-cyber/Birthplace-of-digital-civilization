## 0. 总原则

双目相机相关本能方法分为两层：

```text
外设本能方法：
    控制外设
    检查外设
    取得当前观察特征帧

自我本能方法：
    接收观察特征
    建立观察材料集、可观测单位和像素事实
    组合空间候选
    组织可观测单位到存在的对应事实
    展开存在内部世界
    发现变化
    导出可绘制快照
```

2026-06-02 口径补充：帧是外设 / 接口层材料来源概念，接口层本能方法可以使用当前外设帧、上一外设帧和来源外设帧ID作为技术参数。自我层需求、事实和场景输出不得以帧为认知单位，必须转换为观察材料集、观察范围、可观测单位和对应事实。

2026-06-15 口径补充：当前阶段只有扫描生产外界存在的当前特征和状态。扫描需求由内部治理过程产生：安全 / 服务增加根需求为了确认当前状态、验证任务结果或维护当前场景状态，生成扫描需求；扫描输出状态信息或空信息，状态信息再接回需求、任务、方法、学习虚拟存在特征变化形成的被动因果链。观察只负责补充存在的特征值集合；识别只返回已有存在指针或空指针；跟踪只返回新空间坐标或空信息。四者不得直接互相调用，只能通过需求生成任务、任务筹办和方法选择间接衔接。

新的因果链：

```text
安全 / 服务增加根需求
    -> 内部治理判断需要当前状态或任务结果验证
    -> 生成扫描需求
    -> 外设控制 / 检查使外设可用
    -> 外设使用取得当前观察材料
    -> 扫描更新已确认存在当前特征值
    -> 扫描输出状态信息 / 空信息
    -> 状态信息接回需求、任务、方法、学习虚拟存在特征变化链

扫描缺少可用特征
    -> 生成观察需求

扫描遇到未知材料
    -> 生成识别需求

扫描找不到已确认存在当前位置
    -> 生成跟踪需求
```

定案句：

```text
内部治理要状态，扫描产状态；
相机只供料，不直接发现自我世界存在；
观察补特征，识别返指针，跟踪返坐标。
```

## 1. 方法分层

### 1.1 外设本能方法

外设本能方法只保留三类：

```text
控制类：
    改变双目相机自身状态。

检查类：
    确认双目相机自身状态。

使用类：
    通过双目相机取得当前观察特征。
```

外设适配器、驱动、采集、校正、匹配、视差、深度、滤波、分割等属于外设私有领域。自我只通过控制、检查、使用入口看到外设能力。

外设使用类的核心输出是：

```text
当前观察特征帧
```

不是：

```text
候选存在
像素归属
已确认观察存在
语义类别
目标可见性 / 在场状态
```

### 1.2 自我本能方法

自我本能方法分为六类：

```text
A. 观察接收类
B. 像素事实类
C. 空间候选与存在确认类
D. 存在内部世界递归认知类
E. 变化发现类
F. 场景复现类
```

自我本能方法负责把外设返回的当前外设帧材料转成：

```text
自我所在场景里的观察材料集
可观测单位
像素观察事实
空间候选
存在假设
已确认观察存在
存在内部世界
变化事件
可绘制快照
```

## 2. 外设本能方法

第一阶段最小外设方法集：

```text
1. 双目相机_使达到可用状态
2. 双目相机_释放
3. 双目相机_检查运行状态
4. 双目相机_取得当前观察特征帧
```

第二阶段可加入：

```text
双目相机_设置观察工作模式
双目相机_检查是否满足当前观察需求
```

其中 `双目相机_设置观察工作模式` 只允许表达物理采集配置或运行配置，例如分辨率、曝光、深度质量、低延迟或 ROI 配置。陌生环境逐簇识别、已识别场景扫描变化、目标跟踪观察是双目相机外设线程对自我暴露的高层观察运行模式，应由任务管理等待项 / 订阅项表达，不应作为额外外设本能方法或相机唯一全局状态扩散。

### 2.1 双目相机_使达到可用状态

输出能力：

```text
双目相机.可用状态 -> 可用 / 不可用
```

输入：

```text
调用者
目标外设 = 双目相机
目标宿主 = 双目相机
目标特征类型 = 可用状态
目标状态 = 可用
使用场景
允许占用策略
超时参数
```

前置条件：

```text
外设管理入口存在
调用者具备外设控制权限
```

输出：

```text
双目相机.可用状态
双目相机.连接状态
双目相机.占用状态
双目相机.能力摘要
```

因果用途：

```text
为 双目相机_取得当前观察特征帧 提供前置条件。
```

### 2.2 双目相机_释放

输出能力：

```text
双目相机.占用状态 -> 已释放
双目相机.工作状态 -> 已停止 / 空闲
```

因果用途：

```text
任务结束、外设冲突处理、外设资源回收。
```

### 2.3 双目相机_检查运行状态

输出能力：

```text
双目相机.运行状态 -> 正常 / 异常 / 降级可用
```

输入：

```text
调用者
目标外设 = 双目相机
检查范围
当前任务需求，可选
```

输出：

```text
双目相机.运行状态
双目相机.异常摘要
双目相机.工作质量状态
```

检查方法原则上不启动、重启、修复、切换模式或长期占用外设；如果检查必须改变主要工作状态，应返回控制类缺口。

### 2.4 双目相机_取得当前观察特征帧

这是外设使用类核心方法。

输出能力：

```text
自我所在场景.当前观察特征帧取得状态 -> 已取得
```

或更具体地落到：

```text
观察特征帧.观察特征取得状态 -> 已取得
```

输入：

```text
调用者
目标外设 = 双目相机
目标宿主 = 自我所在场景
目标特征类型 = 当前观察特征帧
目标状态 = 已取得
观察参数：
    ROI
    最大等待时间
    最低帧质量
    是否需要深度
    是否需要空间坐标
```

前置条件：

```text
双目相机.可用状态 = 可用
双目相机.运行状态 = 正常 / 降级可用
```

输出结果：

```text
观察特征帧 {
    来源外设 = 双目相机
    彩色帧号
    深度帧号
    帧宽度
    帧高度
    颜色缓冲 / 颜色特征
    深度缓冲 / 深度特征
    深度有效性
    空间坐标缓冲 / 空间坐标特征
    坐标单位
    帧质量摘要
}
```

禁止输出：

```text
候选存在
像素归属
已确认观察存在
语义类别
目标可见性 / 在场状态
```

## 3. 旧外设方法迁移

### 3.1 双目相机_刷新当前观察场景

保留为兼容组合入口或历史名称，不再作为最小外设本能方法。

真实因果链应写成：

```text
双目相机_取得当前观察特征帧
    -> 自我_建立观察帧存在
    -> 自我_建立像素观察事实索引
    -> 自我_承接像素特征值
    -> 自我_识别当前场景可见信息
```

### 3.2 双目相机_发现候选存在

保留为兼容桥接方法时，动作动态必须写清：

```text
外设输出 = 当前观察特征帧
自我输出 = 空间候选 / 存在假设 / 已确认观察存在
```

不得写成：

```text
双目相机发现了存在
```

真实因果：

```text
双目相机只取得观察特征；
候选存在由自我承接外设观察材料后，根据平面轮廓、掩码、深度摘要、空间坐标摘要和稳定性证据生成。
```

当前阶段的相机观察主特征定案：

```text
默认主特征：
    平面轮廓

辅助特征：
    平面中心坐标
    轮廓面积
    轮廓掩码
    子轮廓
    深度摘要
    空间坐标摘要
    颜色

升级特征：
    空间极值轮廓
    局部三维模型
```

空间坐标、范围坐标和深度仍是重要证据，但第一版不得把它们写成识别稳定存在的唯一主轴。深度或空间坐标不稳定时，平面轮廓可以作为当前观察范围内稳定识别、扫描变化和目标跟踪的默认主特征。空间极值轮廓和局部三维模型只在平面轮廓不够唯一、需要空间操作、碰撞判断、抓取或完整三维占位时升级使用。

## 4. 自我本能方法

第一阶段最小自我方法集：

```text
1. 自我_建立观察帧存在
2. 自我_建立观察帧到自我场景接口
3. 自我_建立像素观察事实索引
4. 自我_承接像素特征值
5. 自我_评估观察帧质量
6. 自我_判断基础观察事实可用性
7. 自我_按像素坐标回查观察事实
8. 自我_从观察事实提取空间候选
9. 自我_判断空间候选相对独立性
10. 自我_生成空间候选观察队列
11. 自我_观察单个空间候选并生成存在假设
12. 自我_用空间范围覆盖原帧验证像素归属
13. 自我_确认观察存在并写入当前场景
```

当前观察帧新鲜度是观察材料承接和基础观察事实可用性判定中的时效证据，不作为独立自我本能方法登记。

这些方法只能宣称完成：

```text
当前观察材料集可观测单位存在对应
```

这里的“识别”只表示当前观察材料集内有效可观测单位已经被组织成观察像素簇、存在候选或对应缺口，不表示语义识别、稳定世界存在确认、跨外设帧身份闭合或目标可见性闭合。

不能宣称：

```text
存在内部世界递归细分完成
变化发现完成
OpenGL复现闭合
跨帧身份稳定
语义识别完成
```

第二阶段自我方法：

```text
11. 自我_确保存在内部世界
12. 自我_建立存在内外场景接口
13. 自我_将存在局部观察切片映射到内部世界
14. 自我_在内部世界提取子候选
15. 自我_确认内部世界子存在
16. 自我_递归细分存在内部世界
17. 自我_导出当前场景识别快照
18. 自我_导出OpenGL复现数据
```

第三阶段自我方法：

```text
19. 自我_匹配当前观察存在与历史观察存在
20. 自我_比较存在特征变化
21. 自我_生成观察变化事件
```

### 4.1 观察接收类

#### 自我_建立观察帧存在

输出能力：

```text
自我所在场景.当前观察帧存在状态 -> 已建立
当前观察帧.观察帧容器状态 -> 已建立
```

输入：

```text
自我所在场景
双目相机_取得当前观察特征帧 的输出
来源外设
帧宽度
帧高度
彩色帧号
深度帧号
```

输出：

```text
观察帧存在 {
    所属上下文 = 自我所在场景
    来源 = 观察生成
    来源外设 = 双目相机
    彩色帧号
    深度帧号
    帧宽度
    帧高度
    预期像素数量 = 宽度 * 高度
    像素覆盖状态 = 未覆盖
}
```

`当前观察帧存在状态 等于 已建立` 是兼容旧字段，只表示 `当前观察帧.观察帧容器状态 等于 已建立`：自我已在自我所在场景中建立可承载像素观察存在的观察帧节点，并记录来源外设、帧号、宽高和预期像素数量。它不表示像素覆盖已完成，也不表示像素特征值已承接。事实完备另由 `当前观察帧.观察事实完备状态 等于 已完备` 表达。

#### 自我_建立观察帧到自我场景接口

输出能力：

```text
观察帧存在.到自我所在场景接口 -> 已建立
```

输出：

```text
场景接口 {
    来源场景 = 观察帧存在 / 观察帧场景
    目标场景 = 自我所在场景
    接口类型 = 观察接口 / 坐标换算接口
    坐标单位
    坐标变换
    接口状态 = 已建立
}
```

### 4.2 像素事实类

#### 自我_建立像素观察事实索引

输出能力：

```text
观察帧存在.像素观察事实索引 -> 已建立
观察帧存在.像素覆盖状态 -> 已覆盖 / 未覆盖
```

像素观察事实包含：

```text
观察帧编号
帧内像素编号
像素坐标X
像素坐标Y
颜色R/G/B
深度值
深度有效性
空间坐标X/Y/Z
```

因果用途：

```text
为所有后续识别提供最小观察事实；
为 100% 坐标回查 / 编号回查 提供依据。
```

`像素覆盖状态 等于 已覆盖` 的成立标准是：

```text
当前观察帧.像素观察存在数量 等于 当前观察帧.预期像素数量
当前观察帧.缺失像素数量 等于 0
当前观察帧.重复映射数量 等于 0
当前观察帧.坐标回查可用状态 等于 可用
当前观察帧.帧内编号回查可用状态 等于 可用
```

该状态只表示当前观察帧中的每个像素位置都有对应像素观察存在，不表示已经理解稳定真实对象。

#### 自我_承接像素特征值

输出能力：

```text
观察帧存在.像素特征值承接状态 -> 已完成 / 条件不足 / 待补齐
```

输入：

```text
观察帧存在
双目相机_取得当前观察特征帧 的颜色缓冲 / 深度缓冲 / 深度有效性 / 空间坐标缓冲
像素观察存在集合
本轮观察阶段要求
```

最低成立标准：

```text
每个像素观察存在.颜色R值状态 等于 已取得
每个像素观察存在.颜色G值状态 等于 已取得
每个像素观察存在.颜色B值状态 等于 已取得
每个像素观察存在.深度有效性值状态 等于 已取得

深度有效性 等于 1 的像素：
    像素观察存在.深度值 大于 0

深度有效性 等于 0 的像素：
    像素观察存在.深度值状态 等于 无效
```

若本阶段要求空间坐标，还必须满足：

```text
深度有效性 等于 1 的像素：
    像素观察存在.空间坐标X值状态 等于 已取得
    像素观察存在.空间坐标Y值状态 等于 已取得
    像素观察存在.空间坐标Z值状态 等于 已取得
```

若空间坐标暂未实现或本轮前置条件不足，只能输出：

```text
观察帧存在.空间坐标承接状态 -> 条件不足 / 待补齐
```

不得写成：

```text
观察帧存在.像素特征值承接状态 -> 已完成
```

#### 当前观察帧新鲜度判定规则（非独立本能方法）

输出能力：

```text
自我所在场景.当前观察新鲜度状态 -> 新鲜 / 过期
当前观察帧.观察年龄 -> 已计算
```

成立标准：

```text
自我所在场景.当前观察帧存在状态 等于 已建立
当前观察帧.采集时间 大于 0
当前观察帧.观察年龄 小于 当前需求.最大允许观察年龄
当前观察帧.失效状态 等于 未失效
当前观察帧.来源外设状态 等于 可追溯
```

该规则由观察材料承接链或 `自我_判断基础观察事实可用性` 内部读取，不进入方法树、候选方法集或动作动态来源。

#### 自我_评估观察帧质量

输出能力：

```text
当前观察帧.质量可用状态 -> 可用 / 降级可用 / 不可用
```

成立标准可由阶段阈值决定，但不得跳过质量证据：

```text
当前观察帧.质量评分 大于 最低风险判断质量评分
当前观察帧.深度有效率 大于 最低风险判断深度有效率，若本轮观察需要深度
当前观察帧.空间坐标有效率 大于 最低风险判断空间坐标有效率，若本轮观察需要空间坐标
当前观察帧.像素覆盖状态 等于 已覆盖
```

#### 自我_判断基础观察事实可用性

输出能力：

```text
当前观察帧.观察事实完备状态 -> 已完备 / 条件不足
当前观察帧.基础观察事实可用状态 -> 可用 / 条件不足 / 质量不足 / 过期
```

成立标准：

```text
自我所在场景.当前观察特征帧取得状态 等于 已取得
自我所在场景.当前观察帧存在状态 等于 已建立
当前观察帧.像素覆盖状态 等于 已覆盖
当前观察帧.像素特征值承接状态 等于 已完成
当前观察帧.质量可用状态 等于 可用
自我所在场景.当前观察新鲜度状态 等于 新鲜
```

其中 `观察事实完备状态 等于 已完备` 只覆盖像素覆盖、像素特征值承接和回查可用，不包含质量阈值、新鲜度阈值或基础风险判断。

#### 自我_按像素坐标回查观察事实

输出能力：

```text
像素坐标.对应像素观察事实 -> 已知
```

输出：

```text
像素观察事实引用
颜色
深度
空间坐标
```

坐标回查和帧内编号回查必须保持：

```text
每个像素坐标唯一回查；
每个帧内编号唯一回查；
回查结果反写同一观察帧编号和坐标。
```

### 4.3 空间候选与存在确认类

#### 自我_从观察事实提取空间候选

输出能力：

```text
观察帧存在.空间候选集合 -> 已生成
```

输出：

```text
空间候选 {
    来源观察帧
    候选编号
    像素索引集合 / 掩码引用

    范围坐标AABB

    有效点比例
    深度范围
    空间连续性评分
    范围稳定性评分

}
```

当前阶段默认主依据：

```text
平面轮廓稳定性
平面轮廓匹配评分
掩码重合率
```

辅助依据：

```text
深度摘要稳定性
空间坐标摘要稳定性
空间连续性
范围坐标稳定性
颜色稳定性
```

空间坐标连续性、范围坐标稳定性和深度一致性在需要空间验证、机械作用、碰撞判断、支撑关系或三维占位时升级为强证据；在普通当前视野识别、扫描变化和目标跟踪中，不要求先构造立方体中心、空间极值轮廓或局部三维模型。


输出：

```text
相对独立
不独立
待拆分
待合并
不确定
```

#### 自我_生成空间候选观察队列


用途：

```text
自我不是一次性理解整张画面；
自我按候选队列一次确认一个存在。
```

#### 自我_观察单个空间候选并生成存在假设

```text
空间候选.存在假设状态 -> 已生成
```

输出：

```text
存在假设 {
    来源观察帧
    来源空间候选
    中心空间坐标
    范围坐标AABB
    距离
    尺寸
    方位
    平面轮廓
    投影轮廓，可选
    有效点比例
    空间连续性评分
    范围稳定性评分
    平面轮廓匹配评分
    轮廓支持评分
    验证状态 = 待验证
}
```

#### 自我_用空间范围覆盖原帧验证像素归属

输出能力：

```text
存在假设.像素归属验证状态 -> 已验证 / 待修正 / 已否定
```

判定原则：

```text
当前视野识别默认以平面轮廓为主；
深度摘要、空间坐标摘要、子轮廓和颜色为辅助；
需要空间操作、碰撞、支撑或完整三维占位时，空间坐标和范围坐标升级为强证据；
颜色只在轮廓不唯一、服务目标需要颜色或低深度降级时参与。
```

#### 自我_确认观察存在并写入当前场景

输出能力：

```text
观察帧存在.已确认观察存在集合 -> 已更新
自我所在场景.当前可见存在集合 -> 已更新
```

输出：

```text
已确认观察存在 {
    来源观察帧
    来源空间候选
    中心空间坐标
    范围坐标AABB
    距离
    尺寸
    方位
    像素归属掩码
    验证结果
    置信度
    确认状态 = 已确认
    内部世界 = 可解析引用<场景节点类>{}
}
```

边界：

```text
这不是跨帧稳定世界对象；
这不是语义分类；
这是当前观察帧内已确认的可见存在。
```

### 4.4 存在内部世界递归认知类

本类方法以 `已确认观察存在内部结构递归细分规范20260525.md` 为准。

方法名称：

```text
自我_确保存在内部世界
自我_建立存在内外场景接口
自我_将存在局部观察切片映射到内部世界
自我_在内部世界提取子候选
自我_确认内部世界子存在
自我_递归细分存在内部世界
```

输出目标应落到：

```text
目标存在.内部世界 -> 已建立
目标存在.内部世界.当前观察材料 -> 已建立
目标存在.内部世界.成员存在集合 -> 已更新
目标存在.内部世界.细分状态 -> 已完成 / 部分完成 / 无法细分
```

子存在、子结构、叶子特征块、内部未解释区域和内部冲突区域必须进入：

```text
目标存在.内部世界
```

不得直接堆在父存在普通字段里。

变化发现类方法：

```text

自我_比较存在特征变化

```

匹配主依据：

```text

范围坐标
尺寸
距离
```

轮廓、颜色、内部子结构只作辅助。没看到不等于消失；目标不在当前视野、被遮挡或深度无效时，只能记录未命中或不确定。

场景复现类方法：


快照数据源只能来自：


控制面板和 OpenGL 只能作为观察复现证据，不得反向回写世界树，不得替代动作动态、状态快照、日志和验证结果。

## 5. 组合父方法

高层需求可以登记组合父方法，但动作动态必须保留子方法因果链。

### 5.1 自我_识别当前场景可见信息



## 6. 动作动态与因果链

每个本能方法必须写入动作动态。动作动态不是成功 / 失败日志，而是因果账本。

统一字段建议：

```text
动作动态 {
    动作动态ID
    方法ID
    方法类别:
        外设控制 / 外设检查 / 外设使用 / 自我认知 / 场景复现

    调用者
    目标外设，可空
    目标宿主
    目标特征类型
    目标状态

    输入特征引用[]
    输入存在引用[]
    输入场景引用[]

    前置条件判定[]
    缺口[]

    输出特征写入[]
    输出存在引用[]
    输出场景引用[]

    因果边:
        输入特征 -> 输出特征

    命中的需求目标
    是否满足需求目标，作为普通结果特征
}
```

动作动态必须能说明：

```text
相机取得了哪些观察特征；
自我基于哪些观察特征建立了哪些观察帧和像素事实；
自我基于哪些空间候选确认了哪些观察存在；
自我基于哪些已确认存在展开了哪些内部世界；
自我导出的复现快照来自哪些场景认知结果。
```

## 7. 任务筹办口径

任务筹办仍然只看：

```text
目标宿主.目标特征类型 -> 目标状态
```

候选集填充依据仍然是：

```text
方法结果能力是否命中任务目标
```

不得把：

```text
外设控制 / 外设检查 / 外设使用
观察接收 / 像素事实 / 存在确认 / 场景复现
```

硬编码成任务筹办分派规则。

示例：

```text
需求：
    自我所在场景.当前可见存在集合 -> 已更新

可命中：
    自我_确认观察存在并写入当前场景
    或组合父方法 自我_发现当前场景存在

缺前置时派生：
    观察帧存在.空间候选集合 -> 已生成
    观察帧存在.像素观察事实索引 -> 已建立
    自我所在场景.当前观察特征帧 -> 已取得
    双目相机.可用状态 -> 可用
    双目相机.运行状态 -> 正常
```

## 8. 最小验收口径

第一阶段只能宣称：

```text
双目相机取得当前观察特征帧；
自我建立观察材料集；
自我建立像素观察事实索引；
像素坐标 / 帧内编号可唯一回查；
自我从观察事实提取空间候选；
自我确认当前观察范围内的可见观察存在；
自我将已确认观察存在写入当前场景。
```

第一阶段不得宣称：

```text
相机发现了存在；
相机知道像素属于哪个存在；
像素观察事实就是稳定外部对象；
当前外设帧材料内可见存在就是跨外设帧稳定世界对象；
已完成语义识别；
控制面板显示成功等于业务链路通过。
```

缺真实 D455 或真实画面时只能记录等待验证，不得误宣称通过。控制面板复现画布必须读取自我所在场景中的观察帧、像素观察事实、空间候选和已确认观察存在特征；相机预览只可作为辅助观察面。

## 9. 最终定案

```text
外设本能方法只负责控制外设、检查外设、取得当前观察特征帧；
自我本能方法负责把当前观察特征帧转化为观察帧存在、像素观察事实、空间候选、存在假设、已确认观察存在、存在内部世界、变化事件和场景复现快照。

所有方法都必须通过“输入特征 -> 输出特征”的动作动态形成因果链。
当前场景可见信息识别不是一个黑箱方法，而是由外设使用方法和自我认知方法组合出的可追踪因果链。
```

一句话：

```text
相机只给特征，自我把特征变成场景里的存在和内部世界。
```
