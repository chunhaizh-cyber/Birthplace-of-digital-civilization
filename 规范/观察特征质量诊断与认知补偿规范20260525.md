## 0. 核心边界

本规范必须区分两种“提升”：

```text
提升相机输出的观察特征质量：
    让颜色、深度、空间坐标更稳定、更完整。

提升自我对不完整特征的认知补偿能力：
    不要求相机直接给出完美轮廓，
    而是让自我用空间坐标、深度、彩图、轮廓和历史帧共同验证。
```

不得把问题理解成：

```text
让相机直接识别得更准
```

定案句：

```text
相机只提供观察特征；
像素观察存在只是当前帧最小观察事实单位；
稳定真实对象、已确认观察存在、内部世界和变化事件只能由自我认知链生成。
```

像素观察存在包含：

```text
颜色
深度
深度有效性
空间坐标
观察帧编号
像素坐标 / 帧内像素编号
```

它不等同于：

```text
稳定真实对象
跨帧身份
语义目标
已确认观察存在
```

## 1. 质量诊断层

当轮廓或深度不完整时，第一步不是直接调算法，而是把问题分类落账。

当前观察帧存在应增加或派生以下质量摘要：

```text
观察帧.深度有效率
观察帧.深度空洞数量
观察帧.深度空洞区域集合
观察帧.彩色深度对齐状态
观察帧.对齐目标
观察帧.轮廓闭合率
观察帧.轮廓断裂数量
观察帧.空间点有效率
观察帧.边界深度稳定率
观察帧.候选存在验证通过率
观察帧.未解释区域比例
```

质量摘要用途：

```text
区分深度空洞、对齐缺失、距离异常、反光 / 低纹理、轮廓算法证据不足、孔洞填充污染等不同原因；
给任务筹办提供条件缺口；
给控制面板提供诊断层；
给自我生成重新观察、调整工作模式、缩小 ROI、融合多帧等后续需求。
```

质量摘要不是权威事实集合。它必须能追溯到：

```text
像素观察事实
深度有效性 mask
空间坐标有效性
轮廓集合
空间候选集合
已确认观察存在集合
未解释区域 / 冲突区域
```

质量摘要可以支撑：

```text
当前观察帧.质量可用状态 等于 可用
当前观察帧.基础观察事实可用状态 等于 可用
```

但 `质量可用状态` 和 `基础观察事实可用状态` 仍然是枚举型实例特征值：前者必须由 `自我_评估观察帧质量` 输出，后者必须由 `自我_判断基础观察事实可用性` 输出。质量诊断摘要只能作为这些方法的输入证据，不能直接把状态写成 `可用`。

但不得直接支撑：

```text
自我所在场景.基础风险判断状态 等于 已明确
```

基础风险判断已明确还必须满足评估范围、新鲜度、必要因子覆盖、证据完整度、不确定度和风险值计算等条件，具体以 `基础观察事实可用与基础风险判断分层规范20260526.md` 为准。

## 2. 完整观察特征帧

外设使用方法 `双目相机_取得当前观察特征帧` 的目标输出应从摘要帧升级为可被自我认知链完整使用的 RGB-D + XYZ 观察特征帧。

最小 DTO 建议：

```cpp
struct 双目相机观察特征帧结果 {
    bool 成功;
    std::string 错误摘要;

    int64_t 彩色帧号;
    int64_t 深度帧号;
    int64_t 帧宽度;
    int64_t 帧高度;

    bool 彩色深度已对齐;
    bool 空间坐标可用;

    std::vector<uint8_t> 颜色RGB;          // W * H * 3
    std::vector<uint16_t> 原始深度毫米;    // W * H
    std::vector<uint16_t> 滤波深度毫米;    // W * H，可空
    std::vector<uint16_t> 补全深度毫米;    // W * H，可空
    std::vector<uint8_t> 深度有效性;       // W * H
    std::vector<int32_t> 空间坐标毫米XYZ;  // W * H * 3

    double 深度有效率;
    double 空间坐标有效率;
    double 帧质量评分;
};
```

值域要求：

```text
颜色RGB：0-255。
深度毫米：深度有效时 > 0；深度无效时不得把 I64_MAX 当真实值。
空间坐标毫米XYZ：必须声明单位和参考坐标系；无效坐标不得作为真实空间事实。
深度有效性：0 / 1。
彩色深度已对齐：必须显式给出 true / false。
```

## 3. 深度三套口径

深度事实必须区分：

```text
像素观察存在.原始深度
像素观察存在.滤波深度
像素观察存在.补全深度
像素观察存在.深度来源 =
    原始 / 滤波 / 补全 / 无效
```

存在确认优先级：

```text
原始有效深度 > 滤波深度 > 补全深度
```

硬规则：

```text
1. 滤波深度不得覆盖原始深度事实。
2. 补全深度不得覆盖原始深度或滤波深度。
3. 补全深度只能降低“不完整”，不能提高“真实性”。
4. 由补全深度支撑的轮廓、候选或像素归属必须标记为低置信或待验证。
5. I64_MAX 在真实深度 / 真实空间坐标中只能表示异常哨兵或未设置值；在安全 / 服务结算中可作为满刻度和比例分母，但不得作为未知、默认成功、异常兜底或无证据满分入账。
```

## 4. 外设内部后处理链

D455 / RealSense 后处理链属于双目相机适配器私有能力，不登记成自我本能方法。

可配置链路：

```text
原始深度
    -> 深度范围裁剪
    -> Decimation
    -> Depth to Disparity
    -> Spatial filter
    -> Temporal filter
    -> Disparity to Depth
    -> Hole filling，可选
    -> 深度有效性 mask
    -> XYZ 空间坐标
```

项目口径：

```text
Decimation：
    可用于降低深度图复杂度和噪声，适合候选存在粗召回，不直接替代最终像素回查。

Spatial filter：
    用于边缘保持平滑，减少空间噪声，参数过强时可能抹平真实边界。

Temporal filter：
    适合相机和目标稳定时降低时间噪声；目标高速变化时应降低权重。

Hole filling：
    只生成补全深度候选，不生成原始观察真值。
```

官方 RealSense 文档把这些滤波器作为深度质量改善的 SDK 后处理能力，并给出 `Depth Frame -> Decimation -> Depth2Disparity -> Spatial -> Temporal -> Disparity2Depth -> Hole Filling -> Filtered Depth` 的推荐演示顺序。项目实现可以按真实场景调参，但不得改变本规范的事实口径。

## 5. 静态条件下的多帧融合

当满足：

```text
相机不移动
目标场景静止
连续帧坐标口径一致
彩色深度对齐有效
```

可以由自我认知层生成多帧融合结果。

建议自我方法：

```text
自我_融合稳定观察帧深度
```

输入：

```text
连续 N 帧观察特征帧
相机稳定状态
目标场景静止状态
像素坐标一致性
深度有效性 mask
```

输出：

```text
观察帧组.融合深度图
观察帧组.融合深度有效性
观察帧组.深度稳定性图
观察帧组.每像素深度方差
观察帧组.融合依据帧集合
```

融合策略：

```text
1. 同一像素多帧有效深度优先取中位数。
2. 无效深度像素只可引用最近几帧有效值作为融合候选。
3. 方差过大的像素标记为不稳定，不参与强存在确认。
4. 边界区域多帧跳变时标记为边界不稳定。
5. 融合结果不得覆盖任一单帧观察事实。
```

推荐参数：

```text
N = 3 到 7 帧
中位数优先于均值
必须保留每像素方差或等价稳定性评分
```

## 6. 轮廓分层

轮廓不得再只有一个“相机轮廓”口径。

观察帧应区分：

```text
观察帧.彩图轮廓集合
观察帧.深度轮廓集合
观察帧.空间候选投影轮廓集合
观察帧.融合轮廓集合
```

彩图轮廓来源：

```text
RGB 图像边缘
颜色分块
纹理边界
```

深度轮廓来源：

```text
深度突变
深度无效边界
深度梯度
```

空间候选投影轮廓来源：

```text
XYZ 点云聚类
空间连续性断裂
范围坐标 AABB / OBB 投影
```

融合轮廓不是相机直接识别出的存在边界，而是自我将彩图、深度和空间候选共同验证后的派生边界。

## 7. 轮廓和深度置信度

轮廓至少携带：

```text
轮廓.来源类型 =
    彩图 / 深度 / 空间投影 / 融合
轮廓.置信度
轮廓.闭合度
轮廓.深度支持率
轮廓.颜色支持率
轮廓.空间支持率
轮廓.是否跨越深度断裂
轮廓.是否穿过深度无效区域
轮廓.是否依赖补全深度
```

深度至少携带：

```text
像素.深度来源
像素.深度稳定性
像素.深度有效性
像素.深度邻域一致性
像素.深度是否补全
```

解释口径：

```text
颜色清楚但没有深度支持：只能作为颜色轮廓或表面特征候选。
深度连续但颜色轮廓不清：可以支撑空间候选，但轮廓置信降低。
补全深度支撑的区域：可进入补全候选或待验证区域，不直接成为真实边界。
边界深度方差高：标记为边界不稳定，存在确认应降低置信或暂缓。
```

## 8. 彩色深度对齐

相机输出必须显式包含：

```text
彩色深度已对齐 = true / false
对齐目标 = depth_to_color / color_to_depth / none
对齐后宽度
对齐后高度
```

若：

```text
彩色深度已对齐 = false
```

则不得把彩图轮廓直接套到深度图上确认存在。应输出：

```text
观察帧.识别状态 = 条件不足
缺口 = 彩色深度对齐缺失
```

允许继续做的工作：

```text
单独记录彩图观察特征；
单独记录深度观察特征；
生成对齐缺口；
触发 双目相机_设置观察工作模式 或重新取得观察特征帧需求。
```

## 9. 顶层存在确认与内部世界细分

顶层存在确认：

```text
像素观察事实
    -> 有效深度 / XYZ 点集
    -> 空间聚类
    -> 空间候选
    -> 范围坐标 AABB
    -> 投影回原帧
    -> 用彩图轮廓和深度轮廓辅助修边
    -> 覆盖原帧验证像素归属
    -> 已确认观察存在
```

不得走：

```text
彩图轮廓
    -> 直接认为是存在
```

顶层证据权重：

```text
空间坐标连续性和范围坐标稳定性为主；
深度一致性和投影覆盖为强辅助；
轮廓和颜色为边界、拆分、显示和低层补偿辅助。
```

内部世界细分：

```text
已确认观察存在
    -> 目标存在.内部世界
    -> 局部彩图
    -> 局部深度图
    -> 局部空间坐标
    -> 子彩图轮廓
    -> 子深度轮廓
    -> 子结构候选
    -> 递归到 8*8 停止
```

内部世界证据权重：

```text
彩图轮廓 + 深度轮廓共同主导；
空间坐标用于验证子结构是否稳定；
子存在、子结构、叶子特征块、内部未解释区域和冲突区域进入目标存在.内部世界。
```

## 10. 认知补偿与缺口生成

深度和轮廓不完整时，自我不得把算法猜测直接落成真值。

候选存在应输出：

```text
候选存在.确认状态 =
    已确认 / 部分确认 / 待验证 / 已否定 / 条件不足
候选存在.缺失原因 =
    深度空洞 / 轮廓断裂 / 对齐缺失 / 有效点不足 / 边界不稳定 / 补全依赖过高
候选存在.未解释区域
候选存在.待补观察区域
候选存在.补全候选
候选存在.低置信轮廓
```

可派生需求：

```text
重新取得观察特征帧
调整双目相机工作模式
缩小 ROI 重新观察
融合稳定观察帧深度
对目标存在进行内部世界细分
对未解释区域继续观察
```

不得落成：

```text
真实深度
真实轮廓
已确认存在
跨帧稳定对象
```

## 11. 方法边界

外设侧可新增或强化：

```text
双目相机_设置观察工作模式
    输出：双目相机.工作模式 -> 高深度质量 / 低延迟 / 指定 ROI

双目相机_检查观察帧质量
    输出：双目相机.当前观察质量状态 -> 可用 / 不可用 / 降级可用

双目相机_取得当前观察特征帧
    输出：RGB、深度、深度有效性、XYZ、对齐状态、质量摘要
```

外设内部的采集、对齐、曝光、激光功率、ROI、滤波、视差变换和孔洞处理不登记为自我本能方法。

自我侧可新增或强化：

```text
自我_评估观察帧质量
自我_从观察事实生成深度有效区域
自我_融合稳定观察帧深度
自我_生成彩图轮廓
自我_生成深度轮廓
自我_融合彩图轮廓与深度轮廓
自我_基于空间候选修正轮廓
自我_对未解释区域生成补观察需求
自我_递归细分存在内部世界
```

其中 `自我_融合彩图轮廓与深度轮廓` 的输出建议：

```text
融合轮廓 {
    来源彩图轮廓
    来源深度轮廓
    来源空间候选
    轮廓闭合率
    深度支持率
    空间支持率
    颜色支持率
    置信度
}
```

## 12. 控制面板诊断层

控制面板必须继续读取自我所在场景快照，不得把原始相机画面当作自我识别真值。

可显示层：

```text
原图参考层
深度层
深度有效性 mask
空间点层
彩图轮廓
深度轮廓
空间候选投影轮廓
融合轮廓
深度空洞区域
补全深度区域
未解释区域
轮廓断裂区域
置信度 / 质量摘要
```

控制面板显示成功不等于业务验收通过。验收仍以：

```text
自我所在场景
观察帧存在
像素观察事实
空间候选
已确认观察存在
动作动态
状态快照
真实运行日志
错误日志
```

为证据。

## 13. 禁止事项

```text
1. 禁止把相机输出命名为已确认存在。
2. 禁止把彩图轮廓单独作为顶层存在确认依据。
3. 禁止把补全深度当作原始观察真值。
4. 禁止在彩色深度未对齐时硬套轮廓和深度。
5. 禁止把像素观察存在宣称为稳定真实对象。
6. 禁止把质量评分替代权威事实集合。
7. 禁止把控制面板叠加结果反写世界树。
8. 禁止在缺真实 D455 / 真实样本时用模拟样本宣称通过。
9. 禁止宣称跨帧身份稳定、语义识别完成、目标可见性闭合、自我苏醒完成或初步成熟完成。
```

## 14. 验收口径

第一阶段可以宣称：

```text
观察特征帧包含 RGB、深度、深度有效性、XYZ、对齐状态和质量摘要；
观察帧能输出深度有效率、空间点有效率、空洞区域和未解释区域；
原始深度、滤波深度、补全深度三套口径已区分；
彩图轮廓、深度轮廓、空间候选投影轮廓和融合轮廓已分层；
自我能基于质量诊断生成补观察、调模式、融合多帧或内部细分需求。
```

第一阶段不得宣称：

```text
相机直接识别存在更准；
补全后的深度就是真实深度；
融合后的轮廓就是真实对象边界；
目标跨帧身份稳定；
语义识别完成；
内部世界完整已知。
```

```text
提升观察特征质量，是外设适配层让 RGB、深度、有效性和 XYZ 更稳定、更完整；
提升认知补偿能力，是自我在不完整观察上建立诊断、置信、补观察、融合和内部细分链。

相机不负责把不完整观察变成真实对象；
自我也不得把补全猜测写成真值。
```
