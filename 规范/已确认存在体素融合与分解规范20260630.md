## 1. 目标

当前已确认观察存在已有第一版粗体素特征时，后续观察应继续提升体素精度、颜色和内部结构，而不是停留在一层 AABB 粗长方体。

本规范定义以下内容：

```text
1. 新增观察体素特征值触发体素加工。
2. 深度轮廓用于父存在体素融合。
3. 彩色轮廓用于子轮廓分解，深度轮廓补充子轮廓空间占据。
4. 所有体素模型统一使用正立方体包围盒。
5. 父存在保留完整体素模型；子存在确认后拥有自己的局部体素模型。
6. 体素加工线程只能生成候选结果，不能直接写正式世界树事实。
```

核心口径：

```text
新增观察证据触发加工；
深度负责融合，彩色负责分解，深度再补子轮廓空间信息；
候选先于事实，提交入口裁决后才入账；
线程只做计算，不做事实来源。
```

## 2. 触发条件

体素加工只由以下事件触发：

```text
某个已确认存在新增一组未消费的观察体素特征值。
```

这里的“新增”指新的观察证据特征值进入该存在，而不是当前特征值再次被读到。

不得作为触发源：

```text
外设原始帧新增。
旧观察特征值再次成为当前特征值。
体素融合结果写回。
控制面板刷新。
场景体素快照生成。
日志输出。
```

若一组新观察最终确认目标状态没有变化，但提供了新角度、新覆盖区域或新来源证据，仍可作为新增观察证据触发加工。

已消费观察体素特征值必须记录消费状态或来源版本，避免融合写回后递归触发自己。

## 3. 合法输入

本流程只接收已经归属到同一已确认存在的观察材料：

```text
已确认存在指针
新增观察体素特征值 ID
深度轮廓图或深度轮廓材料
彩色轮廓图或彩色轮廓材料
来源观察帧 / 观察批次 / 特征值句柄
该存在当前体素模型快照和版本
该存在尺寸、位置、AABB 或局部坐标映射
```

合法输入的含义：

```text
观察链已经确认该材料属于这个存在；
来源可回查；
材料作为该存在的观察特征值进入项目结构；
质量门、TTL、坐标系或归属检查已满足当前入口要求。
```

合法输入不等于融合和分解结果直接成为事实。融合和分解只能先生成候选结果包，正式体素更新和内部世界子存在创建必须经提交入口裁决。

## 4. 体素包围盒规则

所有存在体素模型使用正立方体包围盒：

```text
N * N * N
```

第一版分辨率取彩色轮廓图最大边：

```text
N = max(彩色轮廓图宽度, 彩色轮廓图高度)
```

例如：

```text
彩色轮廓图 8 * 64 -> 体素包围盒 64 * 64 * 64
```

包围盒外边界层必须为空：

```text
x == 0 或 x == N-1
y == 0 或 y == N-1
z == 0 或 z == N-1
```

若外边界层出现占据体素，判定为：

```text
模型越界 / 观察截断 / 分辨率不足 / 不完整候选
```

有效占据区间为：

```text
1 .. N-2
```

存在真实尺寸的最长方向应贴近有效区边界；其他方向按实际尺寸比例缩放，不强制撑满。

```text
有效长度 = N - 2
最长实际尺寸方向体素长度 = 有效长度
其他方向体素长度 = round(该方向实际尺寸 / 最长实际尺寸 * 有效长度)
```

正立方体包围盒是模型坐标容器，不代表存在本身是立方体。存在真实比例由尺寸特征、位置特征、占据体素和场景坐标映射共同决定。

## 5. 连通体边界规则

相互黏连的占据体素属于同一连通体。

同一连通体在自身局部有效包围盒中必须压紧：

```text
局部包围盒不能存在整层空白边界。
```

但不得要求局部包围盒六个面全部填满。真实形状造成的凹陷、孔洞、斜面、弯曲和非立方边界允许保留。

判定口径：

```text
最外层正立方体边界被占据 -> 不完整 / 越界。
有效区最长方向贴边 -> 正常比例归一化。
局部连通体包围盒存在整层空白 -> 局部包围盒未压紧。
局部边界面不满 -> 正常，不能因此补成立方体。
```

## 6. 融合规则

深度轮廓用于更新父存在体素占据候选和覆盖置信度。

融合必须存在融合点。满足下列条件之一才允许融合：

```text
新观察体素候选与现有体素存在部分边界相同。
新观察体素候选与现有体素边界相邻并能通过坐标映射对齐。
新观察体素候选可投影到同一父包围盒，且与现有体素有可验证重叠区域。
```

没有融合点时：

```text
不得写入父体素模型；
不得直接扩张父存在尺寸；
不得创建子存在；
只能挂起为待融合观察候选或结构化缺口。
```

融合结果不得把补全深度或推测空间直接提升为真实占据。补全深度只能降低不完整程度，不能提高真实性。

## 7. 分解规则

彩色轮廓图用于生成颜色分区和子轮廓候选。

彩色分解后，必须用深度轮廓补充空间占据信息：

```text
彩色轮廓 -> 子轮廓候选
深度轮廓 -> 子轮廓空间占据 / 深度连续性 / 深度边界
颜色统计 -> 平均颜色
投影回查 -> 来源证据
```

彩色轮廓不能单独证明子存在。红色花纹、阴影、反光、表面纹理或局部颜色块可形成子轮廓候选，但没有独立空间占据或深度支撑时，不得写成内部世界子存在。

子轮廓成为子存在至少需要：

```text
父存在已确认。
父存在内部世界可解析或可创建。
子轮廓来源可回查。
子轮廓能投影回观察材料。
深度轮廓提供空间占据或边界支撑。
子区域在父体素空间中有明确占据。
质量、稳定性和提交入口裁决通过。
```

## 8. 颜色规则

父存在基础颜色：

```text
从彩色轮廓图扣除已确认子轮廓后的剩余区域计算平均颜色。
```

子存在颜色：

```text
从子轮廓区域计算平均颜色。
```

渲染规则：

```text
父基础颜色先画；
子存在体素颜色覆盖其占据区域；
覆盖只表示显示优先级，不表示父存在颜色事实被删除。
```

父颜色、子颜色和渲染覆盖关系必须分开表达，不能用显示覆盖反向改写父存在基础颜色事实。

## 9. 父子体素模型关系

父存在必须保留自己的完整正立方体体素模型。

子存在确认后，也必须拥有自己的正立方体局部体素模型。子存在模型初始来源于父体素模型中的子区域，但不得复制父存在完整体素模型。

```text
父存在体素模型 =
    正立方体包围盒
    + 父占据体素
    + 父基础颜色
    + 子区域引用
    + 来源观察证据集合

子存在体素模型 =
    正立方体局部包围盒
    + 子占据体素
    + 子平均颜色
    + 父子坐标映射
    + 来源观察证据集合
```

子存在局部体素模型也适用正立方体包围盒、外边界空白、有效区贴边和局部连通体压紧规则。

子存在后续可独立融合、分解、跟踪和递归生成自己的内部世界。没有子体素模型的子结构只能称为颜色区域、表面特征或内部结构候选，不得宣称为可递归存在。

## 10. 体素加工线程边界

允许新增独立体素加工工作线程，用于执行耗时计算：

```text
深度轮廓融合
彩色轮廓分解
子轮廓深度补充
平均颜色统计
局部体素生成
边界完整性检查
质量诊断
```

体素加工线程不得直接写正式事实：

```text
不得直接修改存在三维体素特征。
不得直接创建内部世界子存在。
不得直接生成方法动作动态。
不得作为动作来源。
不得绕过提交入口。
```

线程输出只能是结构化候选结果包。正式写入必须回到提交入口或对应领域类裁决。

候选结果包至少包含：

```text
父存在 ID
输入观察特征值 ID
基准体素版本
融合后父体素候选
父基础颜色候选
子轮廓候选集合
子存在局部体素候选集合
父子坐标映射
来源观察证据句柄
是否存在融合点
是否触碰外边界
是否局部包围盒压紧
质量诊断状态
可提交状态
```

提交时必须检查基准版本：

```text
加工开始读取父体素版本 = V1
提交时父体素版本仍为 V1 -> 可按候选裁决
提交时父体素版本已变为 V2 -> 不得直接覆盖，必须重算、合并或挂起
```

## 12. 规则原子

### RULE-VOXEL-FUSION-001：体素加工只由新增观察证据触发

体素加工不得由外设原始帧、旧当前特征值、融合写回、控制面板刷新或场景体素快照触发。触发源只能是已确认存在新增的未消费观察体素特征值。

### RULE-VOXEL-FUSION-002：融合必须存在融合点

新观察体素候选必须与现有体素存在边界相同、边界相邻或可投影重叠的融合点。没有融合点时，只能形成待融合候选或缺口，不得写入父体素模型。

### RULE-VOXEL-FUSION-003：所有体素包围盒必须是正立方体且外边界为空

父存在、子存在和局部体素候选都必须使用正立方体包围盒。包围盒最外层出现占据体素时，候选判定为越界、截断或不完整，不得作为稳定模型提交。

### RULE-VOXEL-FUSION-004：最长真实尺寸方向贴有效区边界

正立方体包围盒中的有效占据区为 `1..N-2`。存在真实尺寸最长方向应贴近有效区边界，其他方向按尺寸比例缩放，不得把所有存在强行补成立方体。

### RULE-VOXEL-FUSION-005：彩色分解必须由深度补空间

彩色轮廓只能生成颜色分区和子轮廓候选。子轮廓要进入内部世界子存在候选，必须由深度轮廓或空间占据证据补充，不得只凭颜色成为子存在。

### RULE-VOXEL-FUSION-006：父体素和子体素分别建模

父存在保留完整体素模型；子存在确认后拥有自己的局部正立方体体素模型。子模型来源于父体素子区域和观察证据，不得复制父完整模型冒充子存在体素。

### RULE-VOXEL-FUSION-007：颜色覆盖只属于渲染优先级

父基础颜色和子存在颜色必须分开记录。渲染时子体素颜色可覆盖父颜色显示，但不得用显示覆盖反向改写父颜色事实。

### RULE-VOXEL-FUSION-008：体素加工线程只能返回候选

体素加工线程可以融合、分解和统计，但不得直接写世界树事实、创建子存在或生成动作动态。正式入账必须经过提交入口和版本闸门。

## 13. 验收边界

允许作为规范和工程守卫证据：

```text
规范目录已挂载本规范。
规则原子已索引。
新增观察体素特征值只触发一次。
无融合点时产生待融合候选而不是写父体素。
外边界被占据时标记不完整。
子存在局部体素不复制父完整体素。
体素加工线程输出候选结果包，正式写入仍走提交入口。
```

不得作为业务闭合证据：

```text
控制面板显示了彩色体素。
体素加工线程跑通。
单帧材料成功分解出颜色块。
AABB 粗体素已经可绘制。
日志显示融合函数被调用。
```

业务闭合必须等待真实观察材料、自然触发、提交入口裁决、父子体素特征和内部世界子存在投影回证据形成同一窗口证据。
