# 2210 根规范 语素入口主信息类

编号：2210
日期：20260701
状态：正式根规范
代码锚点：`语素主信息类.h:388`

## 1. 根定位

`语素入口主信息类` 承载“词面 -> 信息入口类型 -> 基础信息类型 / 存储树”的路由桥接。

## 2. 承载边界

1. 可以保存人类词性、信息入口类型、对应基础信息类型和对应基础信息引用。
2. `词性` 是人类词性兼容字段，不是当前主信息类型名。
3. 不得把语素入口当作任务、需求、方法状态或世界事实本体。

## 3. 子规范约束

旧规范中的 `词性主信息类` 应统一修订为 `语素入口主信息类`，并区分人类词性和程序信息入口类型。

## 4. 当前整理判断

该类型是语素层到基础信息层的核心桥，必须有独立根规范。
