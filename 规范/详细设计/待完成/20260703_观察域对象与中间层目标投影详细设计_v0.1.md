## 1. 核心口径

观察域对象不是世界树稳定事实。

```
观察域对象 =
    外设材料进入自我事实治理之前的运行期对象、候选、证据、约束、缺口和结果包。

中间层目标 =
    自我层需求或任务投影到观察域后形成的目标特征值约束。
```

中间层目标不是自我需求本身，不是安全、服务、价值结算这样的终极目标，也不是稳定世界事实。

正式链路：

```
自我需求 / 任务
    -> 投影为中间层目标 G
    -> G 指定目标宿主、目标特征类型、期望值 / 当前参照值、质量阈值、稳定要求、提交目标类型
    -> 外设观察队列 / D455 线程 / 视觉中间层按 G 处理当前材料
    -> 输出观察域对象 F / C / R / T / O / 结构化信息缺口
    -> 自我侧观察 / 扫描 / 识别 / 跟踪裁决是否入账世界树
```

压缩口径：

```
G 说明本轮观察域应看什么、按什么约束看、结果应交给哪个观察域目标。
F/C/R/T/O/结构化信息缺口 只承载当前观察域材料、候选、结果和缺口。
E、世界树事实、需求满足和任务完成仍由自我侧治理链裁决。
```

## 5. 目标宿主类型值域

本文定义概念值域，不要求新增 枚举；第一版可由纯推导函数或运行期只读视图返回 I64 状态值。

```
0 未指定
1 D455观察帧 F
2 观察候选 C
3 关系候选 R
4 轨迹候选 T
5 观察域结果包 O
6 信息缺口候选 结构化信息缺口
```

推导建议：

```
目标观察簇编号 >= 0
    -> 2 观察候选 C

报告类型 == 跟踪报告 或 观察运行模式 == 目标跟踪观察
    -> 4 轨迹候选 T

报告类型 == 扫描变化报告 且存在变化 / 冲突 / 缺口
    -> 5 或 6，按是否有有效候选决定

只有帧、感兴趣区域、掩码、空间范围，没有具体 C
    -> 1 D455观察帧 F

仅产生缺失材料 / 质量问题 / 不可回查 / 来源链或坐标版本失配
    -> 6 信息缺口 结构化信息缺口
```

目标宿主类型是推导结果，不得由外设线程自由填文本。

## 9. 与场景体素先验的关系

场景体素模块只提供只读快照和查询服务，不写世界树事实、需求满足、价值结算或动作动态；场景体素先验只能辅助观察域候选、评分、解释和缺口。


当前待实现映射核查的缺口：

### 11.2 现在冻结的边界型结论

#### DQ-1：G 的根定义

现在确认：

```
中间层目标 G =
    自我层需求投影到观察域后形成的目标特征值约束。
```

G 只表达：

```

```

```
最终世界事实；
稳定存在事实；

```


```
结构_目标观察约束特征组

```

后置复核：

```
若后续结构化信息缺口、任务承接、方法选择或因果链要求追溯 G 的生命周期，
```

#### DQ-3：O 第一版 是否独立入账

现在确认：

```
O 第一版 不作为独立长期存在入账。
```

```
O 中携带关系候选集合句柄；

```

```
目标特征稳定阈值
感兴趣区域 / 掩码 / 点集 / 空间范围

```

```
不能把“现在看到多少”误当成“目标要达到多少”。
```

```
像素 -> 观察候选 C
```

禁止：

```

像素归属图直接写稳定存在事实；
候选分裂结果直接当识别结果；
局部体素证据直接写稳定存在体素。
```
