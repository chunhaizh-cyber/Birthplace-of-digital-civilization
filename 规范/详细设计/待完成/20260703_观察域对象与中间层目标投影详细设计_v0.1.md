## 1. 核心口径

观察域对象不是世界树稳定事实。

```text
观察域对象 =
    外设材料进入自我事实治理之前的运行期对象、候选、证据、约束、缺口和结果包。

中间层目标 =
    自我层需求或任务投影到观察域后形成的目标特征值约束。
```

中间层目标不是自我需求本身，不是安全、服务、价值结算这样的终极目标，也不是稳定世界事实。

正式链路：

```text
自我需求 / 任务
    -> 投影为中间层目标 G
    -> G 指定目标宿主、目标特征类型、期望值 / 当前参照值、质量阈值、稳定要求、提交目标类型
    -> 外设观察队列 / D455 线程 / 视觉中间层按 G 处理当前材料
    -> 输出观察域对象 F / C / R / T / O / G_gap
    -> 自我侧观察 / 扫描 / 识别 / 跟踪裁决是否入账世界树
```

压缩口径：

```text
G 说明本轮观察域应看什么、按什么约束看、结果应交给哪个观察域目标。
F/C/R/T/O/G_gap 只承载当前观察域材料、候选、结果和缺口。
E、世界树事实、需求满足和任务完成仍由自我侧治理链裁决。
```
