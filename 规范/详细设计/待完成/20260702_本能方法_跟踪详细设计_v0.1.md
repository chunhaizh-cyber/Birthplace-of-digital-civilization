## 1. 方法定位

跟踪是对确定目标集合连续获取当前变化、位置、丢失状态或重捕获候选的过程。

跟踪对象可以是一个，也可以是多个，但必须是确定目标集合。移动或变化是常见触发，不是必要条件；静止服务对象也可能需要持续确认位置、遮挡、丢失或姿态变化。

## 2. 与扫描的区别

```text
扫描：
    范围驱动，关心当前扫描范围内应覆盖存在集合。

跟踪：
    目标驱动，关心确定目标集合。
```

跟踪不负责全范围状态维护，也不能用目标局部稳定替代全场景识别完成。

## 3. 输入

```text
目标存在指针或目标候选
跟踪目标集合
目标观察约束
ROI / 掩码 / 点集 / 目标特征摘要
跟踪报告
当前观察窗口
最大允许观测年龄
最大允许离散度
重捕获规则
```

## 4. 输出

```text
目标当前空间坐标
目标当前空间范围
跟踪状态
丢失状态
稳定特征集合
重捕获候选集合
空信息
结构化缺口
```

## 5. 允许写入

```text
目标当前坐标或当前状态过程材料
输出结果场景或运行存在中的跟踪结果
丢失、遮挡、重捕获候选等过程证据
跟踪缺口和派生需求来源
```

## 6. 禁止写入

```text
不得把外设内部跟踪 ID 写成自我世界存在 ID。
不得把目标局部稳定反推为全场景识别完成。
不得把跟踪材料直接当需求满足证据。
不得把跟踪写成新一阶特征裸写入口。
不得替代扫描维护全范围当前状态。
不得替代观察补写存在长期特征集合。
```

## 7. 消费的数据层

主要消费：

```text
L3 跟踪报告
目标观察约束
等待项 / 订阅项
已有目标特征或观察材料句柄
```

跟踪用途不建议拆成独立队列。用途应写在等待项、订阅项或目标观察约束中，例如：

```text
观察补证
扫描复核
服务目标保持
重捕获
安全高优先级跟踪
```

## 8. 共享底层能力

跟踪可以使用底层关联判断能力：

```text
目标与当前材料匹配
空间范围比较
轮廓 / 掩码匹配
反证检查
重捕获候选过滤
```

这不等于调用识别本能方法。若跟踪目标丢失、候选不唯一或需要重新建立材料与已有存在关系，应输出结构化缺口，由需求 / 任务 / 方法链决定是否选择识别或观察。

## 9. 与其他方法边界

```text
与观察：
    观察补材料，跟踪持续复现确定目标。

与扫描：
    扫描看范围，跟踪看目标。

与识别：
    识别建立已有存在对应关联，跟踪使用确定目标集合进行连续复现。
```

## 10. 缺口分流

```text
目标不存在或目标不确定 -> 识别需求来源
目标特征不足 -> 若目标存在已确认具备该特征类型，则生成特征值补完需求来源；否则生成观察补证或识别复核缺口
跟踪报告缺失或过期 -> 外设等待项 / 订阅项来源
目标丢失 -> 重捕获或识别需求来源
目标变化影响安全 / 服务 -> 扫描或服务验证需求来源
```

跟踪可以成为特征值补完需求的后续候选方法，例如补全目标当前空间位置、遮挡状态、连续变化状态或重捕获材料；但跟踪不是长期一阶特征裸写入口。需要沉淀为存在长期特征集合时，必须回到观察事实承接或正式提交入口。
