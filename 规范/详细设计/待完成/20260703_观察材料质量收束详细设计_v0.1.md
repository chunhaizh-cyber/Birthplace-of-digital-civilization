## 1. 核心口径

观察材料质量收束是内部治理判断，不是外设直接读数。

```
外设侧：
    提供原始材料、派生材料、句柄、来源、时间戳、版本、计数、评分和低层诊断候选。

质量收束侧：
    读取外设材料证据和当前任务 / 目标约束，收束出材料质量状态、承接能力、失败分流和可回查证据。

自我侧方法：
    读取质量收束结果，决定观察 / 识别 / 扫描 / 跟踪 / 体素融合是否继续承接。
```

因此：

```
材料质量状态是判断型枚举；
判断型枚举和判断型 布尔值 一样，必须由其它特征族收束；
外设材料只能作为证据包进入质量收束；
质量收束通过也不等于世界事实确认。
```

## 5. 收束输出值域

### 5.1 规范质量状态

材料质量状态统一按 1175 作为判断型枚举收束：

```
0 未评估
1 可用
2 低质量
3 不可用
4 部分可用
5 需复验
```

这些状态不是外设一阶事实，不得由 D455 采集线程直接写入。

### 5.2 兼容质量等级

当前实现锚点中的 `枚举_观察材料等级` 可作为兼容等级，不等同于规范质量状态：

```
未定义
不合格
可用
优质
```

兼容映射：

```
未定义：
    对应质量收束未运行或未评估。

不合格：
    可能对应不可用、低质量或需复验，必须结合缺口码和证据族判断。

可用：
    可能对应可用或部分可用，必须结合能力等级、目标约束和证据族判断。

优质：
    是可用状态下的高等级证据强度，不是第七个质量状态。
```

### 5.3 承接能力等级

承接能力等级用于说明材料能承接到哪一层处理，不替代质量状态：

```
未定义
```


## 6. 状态判定路径

### 6.1 未评估

典型条件：

```
质量收束入口尚未运行；
报告尚未生成；
报告类型未确定；
必要输入特征族不足以收束。
```

分流：

```
等待材料；
继续采集；
不触发识别 / 扫描 / 跟踪 / 体素融合。
```

### 6.2 不可用

典型条件之一：

```
报告类型未指定；
采集失败；
报告超出等待项最大允许年龄且材料不可回查；
无报告材料句柄且无可回查簇材料；
需要簇材料但簇集合为空；
关键深度 / 坐标 / 材料句柄完全缺失；
短期材料页已过期或无法解析；
目标约束要求的定位材料不可回查且不允许降级。
```

分流：

```
生成材料质量缺口；
不得生成识别、扫描、跟踪强候选；
不得触发稳定存在体素更新。
```

### 6.3 低质量

典型条件：

```
材料可回查；
至少存在平面轮廓、感兴趣区域、掩码、点集或空间候选之一；
但深度有效率、空间坐标有效率、帧质量评分、锚点密度或边界覆盖率不足以支撑正式确认；
或候选低置信、未解释区域较高、低质量区域较多。
```

分流：

```
观察可生成弱候选或缺口；
识别不得直接确认唯一归属；
扫描 / 跟踪不得用其生成强动态；
可派生补深度、补坐标、补稳定复现或补观察需求。
```

### 6.4 部分可用

典型条件：

```
全局材料不足；
但目标 感兴趣区域、某个候选或某类材料可用；
彩色缺失但几何可用；
空间坐标不足但平面轮廓可用；
深度锚定可用但完整空间模型不可用。
```

分流：

```
可用于观察候选；
可用于结构化信息缺口；
不可用于稳定存在确认；
若目标需要空间证据，则输出坐标 / 空间缺口。
```

### 6.5 可用

典型条件：

```
材料存在并可回查；
报告未过期或仍在当前任务允许范围内；
有报告材料或可回查簇材料；
需要簇材料时簇集合非空；
全局基础可用、目标区域基础可用或平面轮廓稳定至少一项成立；
材料达到当前目标或默认最低门槛。
```

分流：

```
观察方法可继续生成候选或局部体素证据；
识别可进入候选承接阶段；
扫描 / 跟踪可读取为当前材料，但仍需各自方法规则裁决；
不得直接确认世界树稳定事实。
```

### 6.6 需复验

典型条件：

```
报告过旧但材料可回查；
目标约束来源链、目标特征或坐标版本失配；
候选跨帧稳定不足；
候选不唯一或争议像素过多；
遮挡或自由空间冲突；
坐标系不一致但可降级；
低质量材料可能通过继续观察补足；
材料来自补全 / 融合深度且置信度不足。
```

分流：

```
输出复验观察缺口；
若目标已知，建议定向观察或跟踪重捕获；
若候选不唯一，建议识别承接；
不得把当前材料直接写成稳定事实。
```

## 7. 写入方、读取方和禁止方

### 7.1 合法写入方

质量状态的合法写入方是：

```
观察材料质量收束治理入口；
观察材料质量收束运行期只读视图；
```

当前代码中的 `判断外设观察材料质量(...)` 只能视为待核实现锚点。后续实现映射计划必须确认它是否适合作为第一版收束入口，以及是否需要拆出不新增结构体的 I64 状态计算函数。

### 7.2 合法读取方

```

本能方法：跟踪

目标观察约束匹配逻辑
```

读取方只能把质量收束结果作为证据或前置条件，不得把它解释为最终事实。

### 7.3 禁止方

```
控制面板；
界面 显示；
错误码；
普通函数裸真假值返回；

```

## 10. 与四个感知方法边界

### 10.1 观察

观察读取质量收束结果决定：

```
是否可生成观察候选；
是否只能生成缺口；
是否可输出局部体素证据；
是否需要定向补观察。
```

观察不得把“质量可用”解释成“存在已确认”。

### 10.2 识别

识别只能消费：

```
质量达标的 L1 稳定子集；
显式等待项绑定的可回查材料；
观察输出的候选材料。
```

识别不得直接消费低质量 L0 并宣布唯一归属。

### 10.3 扫描

扫描需要：

```
当前扫描范围；
已归属存在集合；
可比历史；
质量达标的当前材料。
```

扫描材料若缺可比历史或 L1 稳定子集，应输出缺口，不得把未覆盖区域写成消失。

### 10.4 跟踪

跟踪需要：

```
确定目标集合；
目标观察约束；
质量达标的当前候选；
跨帧复现材料。
```

跟踪材料若质量不足，应输出重捕获、补观察或需复验缺口。

## 11. 与存在体素融合边界

存在体素融合只能消费：

```
已确认存在 E 上已归属、可回查、质量收束通过的深度轮廓 / 彩色轮廓 / 局部体素材料。
```

质量收束不足时：

```
不得触发稳定存在体素主模型更新；
只能挂候选证据或输出体素融合缺口。
```

## 12. 当前实现风险清单

### Q1：普通布尔值 判断仍可能被误读

风险：

```
现有 `结构_观察材料质量判定` 若包含多个 布尔值 字段，上层可能继续把它们当作一阶事实。
```

处理：

```
第一版不新增 布尔值；
后续通过 I64 状态视图、能力等级、缺口集合或复合特征结果替代上层直接读取 布尔值。
```

### Q2：兼容质量等级不足以表达六态

风险：

```
`未定义 / 不合格 / 可用 / 优质` 无法精确表达低质量、部分可用和需复验。
```

处理：

```
第一版用质量等级 + 能力等级 + 缺口集合 + 目标约束状态组合表达；
后续实现映射计划确认是否新增统一 I64 质量收束状态函数或特征值条目。
```

### Q3：材料可回查不能只看句柄存在

风险：

```
句柄存在不等于材料可解析、未过期或可复验。
```

处理：

```
将短期材料页解析状态、存活时限、来源链和材料页生命周期纳入可回查特征族。
```

### Q4：先验冲突尚未具备完整上游

风险：

```
场景体素版本、先验冲突、遮挡解释若未设计清楚，容易绑架质量收束。
```

处理：

```
第一版仅预留先验冲突特征族；
待场景体素服务增强与外设观察先验发布器设计落地后再纳入硬门。
```

### Q5：阈值不能硬编码成永久规则

风险：

```
现有阈值若直接固化，无法适配不同目标特征、任务质量阈值或最大允许观察年龄。
```

处理：

```
第一版可保留现有阈值作为兼容默认；
任务阈值、等待项和目标观察约束应具备覆盖入口；
阈值来源必须能回查。
```

```
兼容质量等级可为优质；
```

输入：

```
目标约束与报告来源链、目标特征或坐标版本不一致；
```

预期：

```
质量状态 = 需复验 或 不可用；
缺口 = 目标约束材料失配；
不得强匹配。
```

### V8：先验冲突预留

```
场景体素预测占据，但当前观察明确为空。
```

预期：

