## 1. 设计目标

本设计解决 P3-P10 进入代码前的总口径问题：

```text
像素簇什么时候生成观察候选 C；
C 什么时候可以成为稳定观察候选；
C 什么时候可以提出 E 同一性候选；
SceneVoxelPrior 如何影响视觉解释路径；
冲突、缺失和不确定如何进入 G_gap；
后续代码如何按 Strangler 渐进重构落地。
```

一句话口径：

```text
C 负责“当前看到什么”；
E 负责“世界稳定是什么”；
SceneVoxelPrior 负责“当前应如何解释材料”；
G_gap 负责“证据链哪里断了以及如何回流治理”。
```

## 2. 基本边界

允许：

```text
像素簇生成临时观察候选 C；
跨帧稳定后提升 C 的可信等级；
C 形成 E 同一性候选评分；
SceneVoxelPrior 改变 ROI、分裂、评分、遮挡解释和冲突缺口；
G_gap 记录结构化阻断证据。
```

禁止：

```text
像素直接归属世界树 E；
C 直接写世界树 E；
SceneVoxelPrior 直接生成 C；
SceneVoxelPrior 直接否定 C；
SceneVoxelPrior 直接修改 E；
局部体素直接更新稳定存在体素主模型；
外设线程写需求满足、动作动态或稳定存在确认；
用普通 bool 表达是否清晰、是否稳定、是否可融合、是否可提交、是否当前存在。
```

## 3. 对象定义

```text
F：观察帧 / 外设报告材料页。
P_cluster：像素簇 / 分割簇 / 轮廓簇。
C：观察候选 / 观察域可观测单位。
C_stable：稳定观察候选，是 C 的收束状态，不是新对象类型。
S：SceneVoxelPrior / 当前场景体素只读先验。
E_candidate：C 对世界树稳定存在 E 的同一性候选关系。
E：世界树稳定存在。
E_voxel：稳定存在体素主模型。
G_gap：观察域结构化信息缺口。
```

其中 `C_stable` 和 `E_candidate` 只能用特征族、评分、状态值域、句柄和二次特征表达，不新增长期 C++ 结构体。

## 4. 像素簇到 C 的收束规则

### 4.1 关键修正

单帧材料可以生成临时观察候选 C，但不能直接生成稳定 C，更不能写 E。

```text
空间一致 + 质量门成立
    -> 可生成临时 C。

跨帧稳定 + 清晰度 / 质量继续成立
    -> C 可提升为稳定观察候选。
```

如果硬性禁止单帧生成 C，系统会失去后续跟踪和复现的对象。因此禁止项应写为：

```text
禁止单帧 C 直接成为稳定 C；
禁止单帧 C 直接触发 C -> E；
禁止噪声簇生成 C。
```

### 4.2 C 生成条件

临时 C 生成必须满足：

```text
1. 来源材料可回查：
   来源报告 ID、帧 ID、材料页 ID、generation、坐标系版本存在。

2. 空间一致性达到最低门：
   深度连续性评分达到最低阈值；
   空间连通性评分达到最低阈值；
   2D / 3D 范围可计算。

3. 质量门达到最低门：
   深度有效率达到最低阈值；
   空间坐标有效率达到最低阈值；
   轮廓闭合 / 轮廓置信材料可计算；
   低质量区域比例未超过最低门。

4. 像素归属边界可表达：
   有像素归属图句柄或可记录缺像素归属图缺口。
```

满足后输出：

```text
C.来源报告ID
C.来源帧ID
C.来源像素簇ID
C.来源材料页ID
C.像素掩码句柄
C.ROI句柄
C.点集句柄
C.空间范围
C.候选清晰度评分Q10000
C.候选生成状态值
C.候选生成阻断原因集合
```

### 4.3 C 不生成分流

```text
空间不连通：
    转 D4 候选分裂，不生成完整 C。

质量门不足：
    进入 G_gap：观察材料质量 / 清晰度缺口。

来源不可回查：
    进入 G_gap：材料来源链缺口。

像素归属图缺失：
    进入 G_gap：像素归属材料缺口。
```

## 5. C 到稳定观察候选的收束规则

稳定观察候选不是新对象，而是 C 上的判断型状态。

稳定收束输入：

```text
C.跨帧簇ID
C.连续命中次数
C.连续丢失次数
C.跨帧 IoU 评分Q10000
C.空间中心离散度Q10000
C.投影范围离散度Q10000
C.轨迹连续性评分Q10000
C.generation一致性
C.坐标系版本一致性
C.稳定特征样本数量
```

稳定收束输出：

```text
C.稳定复现评分Q10000
C.稳定复现等级状态
C.稳定复现阻断原因集合
```

判定口径：

```text
连续命中、IoU、空间离散度、轨迹连续和 generation 一致性达到当前任务阈值
    -> C 可进入稳定观察候选状态。

否则
    -> C 保持临时候选 / 待复验候选 / 丢失中候选 / 冲突候选。
```

禁止：

```text
稳定观察候选不等于 E；
稳定复现不等于跟踪成功；
稳定复现不等于需求满足；
稳定复现不直接写动作动态。
```

## 6. C 到 E 同一性候选收束规则

### 6.1 基本口径

`C -> E` 在本设计中只产出同一性候选评分和冲突分流，不直接写世界树。

```text
C 与 E 的同一性候选成立
    -> 交给识别 / 跟踪 / 存在体素融合治理链和正式提交入口。

C 与 E 的同一性候选不成立
    -> 新候选 E 分支 / 冲突池 / G_gap。
```

### 6.2 同一性候选输入

```text
C.稳定复现评分Q10000
C.候选清晰度评分Q10000
C.空间范围
C.局部体素候选句柄
C.局部体素清晰度评分Q10000
C.来源报告ID / 帧ID / 材料页ID
E.稳定存在引用
E.历史空间范围
E.稳定体素句柄
E.场景位姿
S.SceneVoxelPrior版本
S.坐标系版本
```

### 6.3 同一性候选三条件

```text
时序稳定性：
    C 持续出现，轨迹连续，位姿变化可解释。

空间一致性：
    C 与 E 的 AABB 重合、体素重叠、投影误差、距离误差达到阈值。

排他性：
    同一区域内不存在多个高评分 C 同时映射到同一个 E；
    同一个 C 不同时高评分映射到多个 E。
```

### 6.4 输出状态

```text
C_E.同一性评分Q10000
C_E.时序稳定评分Q10000
C_E.空间一致评分Q10000
C_E.排他性冲突数量
C_E.候选关系状态值
C_E.阻断原因集合
```

这些输出属于二次特征 / 判断型状态，不是 E 事实。

### 6.5 分流

```text
三条件成立：
    输出 C -> E 同一性候选；
    交给识别 / 跟踪 / 存在体素融合治理链和正式提交入口。

空间不一致：
    新候选 E 分支或观察缺口。

排他性冲突：
    进入识别冲突 / 跟踪冲突缺口。

时序不足：
    保持 C 候选，等待复验或跟踪。

局部体素清晰但归属不明：
    只挂 C 的局部体素证据链，不更新 E_voxel。
```

## 7. SceneVoxelPrior 解释偏置机制

SceneVoxelPrior 是视觉认知偏置层，不是事实源。

允许影响：

```text
ROI 选择；
处理优先级；
候选分裂；
先验匹配评分；
遮挡解释候选；
自由空间冲突候选；
G_gap 缺口类型和后续建议。
```

禁止：

```text
直接生成 C；
直接否定 C；
直接确认遮挡；
直接确认离开；
直接确认 E 当前存在；
直接确认 E 消失；
直接更新稳定体素。
```

### 7.1 ROI 偏置

```text
已知 E 投影区域：
    提高处理优先级；
    保留更细 ROI；
    降低复验成本但不降低事实写入门槛。

未知区域：
    可降采样或低频处理；
    仍必须保留最低全局观察，不能被先验永久屏蔽。
```

### 7.2 遮挡解释候选

```text
IF SceneVoxelPrior 预测某区域有 E
AND 当前帧该区域无有效观测
AND 遮挡几何 / 深度边界 / 前景候选支持遮挡
THEN 输出遮挡解释候选
ELSE 输出缺观测 / 离开候选 / 先验冲突候选
```

遮挡解释候选不是遮挡事实，也不是跟踪成功。

### 7.3 粘连簇分裂

```text
IF 一个像素簇覆盖多个 E 投影区域
THEN SceneVoxelPrior 可作为分裂依据之一
     输出多个 C 候选及分裂评分
```

分裂后的 C 仍需通过 C 生成规则、稳定复现和同一性候选收束，不得直接归 E。

### 7.4 冲突机制

```text
当前观测与 SceneVoxelPrior 不一致：
    输出冲突候选；
    记录先验版本、坐标系版本、来源 C、候选 E、冲突类型和评分；
    进入 G_gap。
```

冲突可能表示：

```text
先验过期；
坐标系版本错误；
新存在；
遮挡；
局部体素证据不足；
观察材料低质量。
```

不得直接把冲突解释为 E 消失或新 E 成立。

## 8. G_gap 回流口径

G_gap 是阻断证据，不是需求本身。

进入 G_gap 的典型缺口：

```text
缺材料来源链；
缺像素归属图；
空间不一致；
质量 / 清晰度不足；
稳定复现不足；
候选分裂冲突；
C -> E 多重归属冲突；
SceneVoxelPrior 坐标系不一致；
SceneVoxelPrior 过期；
自由空间冲突；
遮挡解释不足；
局部体素不可生成；
稳定体素融合前置不足。
```

G_gap 输出必须包含：

```text
来源层级；
来源报告 ID / 帧 ID / 材料页 ID；
来源 C ID；
相关 E 候选；
相关 SceneVoxelPrior 版本；
坐标系版本；
阻断阶段；
证据评分 / 计数；
建议后续方法类型；
派生策略建议。
```

是否派生需求、派生哪类子需求，必须交给 D5 缺口承接与任务管理 / 父需求角色视图治理。

## 9. 渐进重构落地原则

执行策略采用 Strangler 渐进重构：

```text
保留现有模块入口；
新增语义收束函数或只读视图；
旧判断点逐步改为调用新收束函数；
验证通过后再清理旧判断；
任何时刻系统都保持可回退和可运行。
```

第一阶段：结构不动，只补语义层协议。

```text
固化 C / E / S / G_gap 不可变职责；
固化候选 vs 事实边界；
固化判断型状态收束证据；
固化 SceneVoxelPrior 解释偏置而非事实源。
```

第二阶段：局部替换模块。

```text
像素归属 / 候选生成；
SceneVoxelPrior 使用方式；
G_gap 标准化；
C -> E 同一性候选链；
存在体素融合前置链。
```

第三阶段：执行层收敛。

```text
四方法读取共享判定结果；
存在体素融合治理链读取 C_E 候选；
正式提交入口更新 E 和 E_voxel。
```

## 11. 验证剧本

```text
V1 单帧高质量像素簇：
    可生成临时 C；不得生成稳定 C；不得写 E。

V2 多帧稳定 C：
    可生成稳定复现评分；不得直接 C -> E。

V3 粘连簇覆盖多个先验投影：
    SceneVoxelPrior 参与分裂；生成多个 C 候选；不得直接归 E。

V4 C 与多个 E 均高相似：
    输出排他性冲突和 G_gap；不得任选一个 E。

V5 先验预测有 E 但当前无观测：
    输出遮挡解释候选或缺观测缺口；不得写跟踪成功。

V6 当前观测与先验冲突：
    输出冲突候选和 G_gap；不得写 E 消失。

V7 局部体素清晰但归属不明：
    只挂 C 的局部体素证据链；不得更新 E_voxel。

V8 G_gap 回流：
    缺口先结构化，再由 D5 / 任务管理决定是否需求化。

V9 普通 bool 负例：
    不新增是否清晰、是否稳定、是否可融合、是否当前存在等一阶 bool。
```
