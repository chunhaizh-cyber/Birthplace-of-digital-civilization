## 1. 设计对象

外设观察先验发布器是运行期只读视图发布链，负责把场景体素服务生成的当前场景心像翻译成外设当前帧处理提示。

核心链路：

```text
SceneVoxelPrior
    + 目标观察约束
    + 外设位姿 / 坐标系版本 / 当前帧时间
    -> 外设处理先验材料
    -> D455 / 视觉中间层每帧非阻塞读取
```

它的职责：

```text
读取 SceneVoxelPrior；
读取目标观察约束；
读取或接收外设位姿、坐标系版本和当前帧时间材料；
校验版本、TTL、generation 和坐标系；
生成外设处理提示；
提交到目标观察约束缓冲区或外设报告项伴随材料；
供 D455 / 视觉中间层每帧前非阻塞读取。
```

它不是：

```text
外设采集线程；
场景体素服务本体；
观察 / 扫描 / 识别 / 跟踪方法；
任务调度器；
世界树事实写入方。
```

一句话：

```text
发布器负责把“场景心像”翻译成“外设处理提示”；
外设负责继续提供当前帧证据；
自我侧方法负责裁决事实。
```

本设计不新增 C++ 结构体解决问题。

本文中的这些概念：

```text

本帧处理策略
先验 ROI

预计遮挡区
已知空闲区
未知区
自由空间冲突候选区

```

均应表达为：

```text

```

不得因为使用“快照”“计划”“策略”等词而新增自由结构体绕过项目通用结构。

## 4. 发布器归属

建议归属：

```text
场景体素服务伴随发布器 / 运行期只读视图生成链。
```

逻辑位置：

```text
场景体素服务之后；

视觉观察融合模块之前；
自我侧观察 / 扫描 / 识别 / 跟踪方法之外。
```

逻辑流程：

```text
场景体素维护线程
    -> 发布 SceneVoxelPrior
        -> 外设观察先验发布器读取快照
            -> 生成或刷新外设处理先验材料
                -> D455 / 视觉中间层非阻塞读取
```

实现第一版可不新增线程，优先作为同步函数或运行期服务函数挂在现有模块旁：

```text
生成外设处理先验_由SceneVoxelPrior
提交外设处理先验_到目标观察约束缓冲区
读取最新外设处理先验_按外设和目标
```

这些函数名只是实现映射候选，进入代码前必须由 S0 扫描函数说明文档和真实源码后确认。

## 8. 发布流程

### 8.1 场景体素快照发布

```text
场景体素维护线程或同步服务生成 SceneVoxelPrior。
快照必须有版本、坐标系版本、生成时间、场景引用、存在项集合、缺口集合和统计。
```

### 8.2 发布器读取快照

```text
读取最新 SceneVoxelPrior 副本。
不得读取正在写的场景体素缓存。
不得返回可写引用。
```

### 8.3 读取目标观察约束

```text
按等待项 / 目标存在 + 目标特征类型 / 当前任务上下文读取最新目标观察约束。
```

如果没有目标观察约束：

```text
生成开放观察处理提示；
优先使用未知区、已知空闲区、新占据候选区、低频全局观察；
不得因为无目标约束停止采集。
```

### 8.4 校验版本和 TTL

收束材料：

```text
先验版本是否有效；
坐标系版本是否匹配；
快照年龄是否小于阈值；
目标约束是否过期；
目标特征 generation 是否匹配；
来源材料 generation 是否可回查。
```

失败时：

```text
不阻塞 D455 采集；
写降级策略材料；
输出结构化信息缺口；
进入默认轻量 / 全局观察策略。
```

### 8.5 投影成外设处理材料

第一版粗投影：

```text
SceneVoxelPrior 存在项集合
    -> AABB / 点附近 / 射线粗查询
    -> 目标观察 ROI / 空间范围 / 本帧处理掩码句柄
```

后续增强：

```text
先验 ROI
预计深度范围图
预计遮挡区
已知空闲区
未知区
自由空间冲突候选区
分区处理频率表
```

### 8.6 发布到外设观察队列伴随材料

第一版优先复用：

```text
提交目标观察约束特征组
目标观察约束缓冲区
```

也可在 D455 报告项里记录：

```text
目标观察约束ID
约束generation
本帧处理模式
本帧处理优先级
本帧处理掩码句柄
目标约束使用状态
```

### 8.7 D455 / 视觉中间层非阻塞读取

每帧处理前：

```text
读取最新可用外设处理先验；
若可用，按 ROI / mask / 优先级 / 分区策略处理；
若不可用，走默认轻量 / 全局处理；
不得等待发布器；
不得因为无先验而停止采集。
```

## 9. 降级策略

降级必须结构化，不得用日志或 bool 替代。

建议值域：

```text
0 未评估
1 强先验处理
2 降级先验处理
3 默认轻量全局观察
4 默认全局观察
5 只输出缺口
6 暂停使用先验但继续采集
```

触发示例：

```text
缺 SceneVoxelPrior -> 默认轻量全局观察 + 先验缺口
坐标系版本缺失 -> 默认全局观察 + 坐标缺口
快照过期 -> 降级先验处理 / 复验缺口
目标约束过期 -> 默认观察 / 重新筹办目标约束
投影材料缺失 -> 默认观察 + 投影缺口
```

## 15. 验证剧本

```text
V1 有 SceneVoxelPrior + 有目标约束：
    生成可用处理先验，视觉融合只能输出先验评分、候选和解释。

V2 缺 SceneVoxelPrior：
    默认观察，不阻塞采集，输出缺先验缺口。

V3 坐标系版本缺失：
    不得按先验裁决，输出坐标缺口。

V4 快照过期：
    降级策略材料生效，不判定存在消失。

V5 目标约束过期：
    不强匹配，重新选择或默认观察。

V6 无先验图层：
    粗 AABB 可作为先验候选，图层缺失进入缺口。

V7 未知区保底：
    有 ROI 仍保留低频全局处理，不让未知区永久不处理。

V8 高先验评分：
    不得写稳定存在确认。

V9 发布器越权负例：
    发布器不得直接调用观察 / 扫描 / 识别 / 跟踪。

V10 场景体素越权负例：
    发布器不得写场景体素缓存。
```
