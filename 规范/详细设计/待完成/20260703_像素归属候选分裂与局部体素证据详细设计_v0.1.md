```

4. 局部体素证据如何挂到观察候选 C。
5. 局部体素和稳定存在体素如何分开。
```

## 4. 像素归属图表达

### 4.1 基本口径

像素归属图是 D455 观察帧 F 的观察域材料，不是世界树事实。

它表达：

```
每个像素当前归到哪个观察候选 C；
每个像素的观察域状态；
像素是否处于遮挡、争议、深度缺失、先验投影、自由空间冲突等材料区域；
像素可选绑定哪个先验短 编号 或先验投影区域。
```

它不得表达：

```
像素直接属于世界树稳定存在 E；
E 当前已确认存在；
E 当前已消失；
观察候选 C 已正式归属 E。
```

### 4.2 项目承载

像素归属图作为运行期材料页或可回查材料句柄表达：

```
F.像素观察归属图句柄        -> VecU句柄 / 材料页句柄
F.像素观察归属图版本        -> I64
F.像素观察归属图生成方法编号    -> I64 / 方法编号 / 句柄
F.像素观察归属图坐标系版本    -> I64
F.像素观察归属图来源报告编号    -> I64
F.像素观察归属图来源帧编号      -> I64
F.像素观察归属图使用先验版本  -> I64，可空
F.像素观察归属图状态值域版本  -> I64
```

当前实现锚点中的 `结构_外设观察报告队列项.像素归属账本句柄` 第一版应作为 `F.像素观察归属图句柄` 的承载入口。

### 4.3 像素归属图材料页最小内容

不新增业务结构体。材料页内部可采用版本化二进制、VecU 或外部材料仓库格式。项目层最小要求是能通过句柄回查：

```
图宽
图高
状态值域版本
来源报告编号
来源帧编号
坐标系版本
每像素观察候选局部编号
每像素状态值
每像素可选先验短编号
每像素可选先验评分Q10000
每像素可选深度差摘要
```

项目层只暴露句柄、版本、计数、评分和状态收束结果，不把每个像素拆成世界树特征。

```

候选分裂不得输出世界树稳定存在，只能输出观察候选 C、候选掩码、局部体素候选、遮挡候选、冲突候选和缺口。

## 8. 局部体素证据挂到 C

### 8.1 基本口径

局部体素证据是观察候选 C 的当前观察域证据，不是稳定存在 E 的长期体素模型。

它应挂到：

```
观察候选 C
    -> 局部体素证据特征族
```

而不是：

```
世界树稳定存在 E
    -> 稳定三维体素主模型
```

### 8.2 C 的局部体素证据特征族

```
C.局部体素候选句柄                 VecU / VecIU64 / 材料句柄

## 9. 局部体素、稳定存在体素和场景体素边界

### 9.1 局部体素

```
身份：
    当前观察候选 C 的观察域证据。

生命周期：
    短期，可过期，可清理，可被复验。

来源：
    当前观察帧、轮廓、掩码、空间点、场景体素先验、候选分裂过程。

写入方：
    外设 / 视觉中间层 / 体素加工候选线程。

读取方：
    观察、识别、跟踪、扫描、存在体素融合内部治理。

不得：
    直接成为稳定存在体素；
    直接写世界树事实；
    直接触发场景体素刷新。
```

### 9.2 稳定存在体素

```
身份：
    已确认存在 E 的长期三维形状记忆。

生命周期：
    长期，由正式提交入口和存在体素融合内部治理更新。

来源：
    已归属、可回查、质量收束通过、跨帧稳定或治理允许的局部体素证据。

写入方：
    存在体素融合内部治理方法 / 提交入口。

读取方：
    场景体素服务、识别、跟踪、扫描、观察。

不得：
    由外设、视觉中间层、控制面板、场景体素服务直接写入。
```

### 9.3 场景体素

```
身份：
    当前场景运行期三维心像缓存。

来源：
    当前场景中已确认存在的稳定体素、位姿、自我 / 外设姿态、场景边界、已确认关系。

写入方：
    场景体素服务 / 维护线程。

读取方：
    视觉中间层、外设前处理、路径规划、显示、风险评估。

不得：
    成为世界树事实源；
    直接证明 E 当前存在；
    由视觉中间层写入。
```

## 11. 缺口分流

```
缺像素归属图句柄
    -> 像素归属材料缺口

像素状态值域版本缺失
    -> 像素归属图格式缺口

争议像素过多
    -> 候选分裂缺口 / 需补观察

深度缺失区域过大
    -> 深度材料质量缺口

先验版本缺失
    -> 场景体素先验缺口，可降级全局观察

场景体素坐标系版本失配
    -> 先验不可用缺口

候选不唯一
    -> 识别需求来源

局部体素不可生成
    -> 局部体素证据缺口

局部体素与稳定体素冲突
    -> 存在体素融合缺口 / 识别复核来源
```

正式“缺口如何进入需求树”由 D5 `结构化信息缺口与需求派生承接详细设计` 补齐。D5 未完成前，本文只定义缺口来源和语义，不定义需求派生入口。
