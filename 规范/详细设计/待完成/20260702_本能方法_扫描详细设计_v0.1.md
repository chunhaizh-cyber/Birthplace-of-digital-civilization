## 1. 方法定位

扫描的目标是维护当前扫描范围内已归属、可比较、应覆盖存在的当前状态。

扫描不是全世界所有存在的无限巡检。扫描范围应由当前任务、安全、服务、场景维护或任务结果验证给出。

扫描和跟踪的主要区别：

```text
扫描：范围驱动，关心当前扫描范围内应覆盖存在集合。
跟踪：目标驱动，关心确定目标集合。
```

## 2. 输入

```text
自我内部场景指针
当前扫描范围
本轮扫描关注集合
已合法外设当前数据集
扫描变化报告
已归属存在集合
当前特征值基准
比较规则和阈值
任务 / 安全 / 服务相关性
```

## 3. 输出

```text
当前状态值或当前特征值更新材料
状态变化候选
空信息
扫描未覆盖解释
对应关系缺口
坐标缺口
当前特征值缺口
材料质量缺口
派生需求三件套
```

## 4. 允许写入

```text
输出结果场景或运行存在中的扫描结果
已确认存在的当前状态值 / 当前特征值
扫描缺口和派生需求来源
动作动态所需的输入状态、输出状态、来源方法和来源需求材料
```

## 5. 禁止写入

```text
不得从原始外设材料生产新的观察特征值。
不得把未归属材料直接写成新增存在或状态变化。
不得把扫描写成新一阶特征裸写入口。
不得直接调用观察、识别或跟踪本能方法来完成扫描。
不得把未覆盖区域直接写成消失或遮蔽。
不得把外设报告文本、等待项或日志反推成派生需求。
```

## 6. 消费的数据层

主要消费：

```text
L2 扫描变化报告
已合法外设当前数据集
内部场景基准
```

扫描可以使用观察或识别已经形成的合法结构，但不得直接消费 D455 稳定外设观察材料来完成正式扫描状态更新。

## 7. 共享底层能力

扫描可以使用底层关联判断能力：

```text
已确认存在与当前材料的对应计算
特征匹配
反证检查
范围内覆盖判断
```

这不等于调用识别本能方法。若对应失败、候选不唯一、硬冲突或缺特征，扫描应输出结构化缺口，由需求 / 任务 / 方法链决定后续方法。

## 8. 与其他方法边界

```text
与观察：
    观察补特征材料；扫描维护当前状态。

与识别：
    识别建立材料与已有存在的对应关联；扫描只消费已合法对应或输出对应缺口。

与跟踪：
    跟踪关注确定目标集合；扫描关注当前范围内应覆盖存在集合。
```

## 9. 缺口分流

```text
对应关系未确定 -> 识别需求来源
当前特征值缺失、不完整或不可比较 -> 特征值补完需求来源，后续由任务筹办选择观察、扫描复核或其他补完方法
目标需要持续复现 -> 跟踪需求来源
材料质量不足 -> 补观察或外设等待项来源
范围外 / 视野外 / 低频跳过 / 优先级不足 -> 仅写扫描未覆盖解释
```

这里的“材料质量不足”必须来自共同边界中定义的材料质量收束状态或其可回查证据，不得由外设报告文本、低层候选名称、日志或单个评分直接推出。

扫描发现特征值缺口时，只输出结构化缺口和派生需求来源，不直接调用观察，也不直接补写长期一阶观察特征。扫描本身不要求存在具备完整体素；只有当前扫描目标需要完整体素、可比较体素或遮挡下识别时，体素缺口才进入补完需求。
