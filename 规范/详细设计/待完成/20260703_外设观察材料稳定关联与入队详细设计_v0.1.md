## 1. 设计目标

本设计解决：

```
一帧 D455 外设材料如何形成可回查的短期材料页；
深度帧、彩色帧、对齐帧、空间点、像素归属账本和候选摘要如何按同一帧组回查；
L0、L1、L2、L3 报告层如何形成来源链；
报告编号、外设帧编号、材料页编号、坐标版本、等待项编号和目标观察约束编号如何防止跨队列错配；
队列类型、队列容量、存活时限、等待项绑定、消费标记、用后丢弃和过期清理如何表达；
采集速度、入队速度、消费速度如何作为一阶测量特征进入后续治理。
```

本设计的核心口径：

```
外设侧负责提供可追溯材料；
观察域中间层负责组织材料成熟度和报告分层；
自我侧方法负责事实裁决和需求承接；
材料链稳定性先于质量收束、像素候选、局部体素、场景体素先验和四方法实现映射。
```

## 2. 基础定义

### 2.1 材料页

材料页是外设一次成功采集或一次报告生成后形成的短期可回查证据页。材料页保存或引用：

```
来源外设；
来源外设帧；
报告编号；
采集时间戳；
过期时间戳；
原始帧 / 深度帧 / 彩色帧 / 对齐帧 / 空间点 / 像素归属账本 / 候选摘要的句柄；
坐标系版本；
报告项副本或可回查句柄。
```

材料页不是世界树事实，也不是需求满足证据本身。材料页只证明“某时某外设提供过一组可回查材料”。

### 2.2 外设临时队列

外设临时队列是外设线程和观察域之间的短期材料缓冲，不是事实库、不是记忆、不是稳定身份表、不是复用缓存。队列必须按数据类型分开，队列内只保存同一种材料，并按时间戳 / 帧号顺序读取。

```
L0 原始逐簇报告队列；
L1 稳定观察子集队列；
L2 扫描变化报告队列；
L3 跟踪报告队列；
D455 短期材料页队列；
目标观察约束队列；
工程性能测量只读摘要。
```

队列项只能由结构化字段参与机器判断，包括报告编号、报告类型、报告层级、时间戳、过期时间、深度帧号、彩色帧号、来源原始报告编号、来源外设帧编号、等待项编号、目标观察约束编号和消费状态。不得新增或继续扩散 `来源材料generation` 作为材料身份、调试摘要、兼容字段或机器判断依据。

### 2.3 报告层级

外设观察材料按成熟度和用途分为四层：

| 层级 | 名称 | 来源 | 作用 | 禁止事项 |
| --- | --- | --- | --- | --- |
| L0 | 原始帧 / 原始簇 / 短期材料页 | 外设一次采集或一次低层报告生成 | 原始材料、低层诊断、候选摘要和回查 | 不写世界树事实；不写最终材料质量状态 |
| L1 | 稳定观察子集 / 逐簇识别报告 | L0 可回查材料和低层稳定门 | 提供观察候选、感兴趣区域、掩码、点集、质量证据 | 不确认稳定世界存在；不裁决 C -> E |
| L2 | 扫描变化报告 | L1 或已绑定可比较材料 | 提供面向扫描的变化材料 | 不从原始材料直接伪造已确认变化事实 |
| L3 | 跟踪报告 | L1、目标观察约束或已确定目标集合 | 提供面向跟踪的连续复现、位置、丢失和重捕获材料 | 不把外设跟踪编号 当世界树存在编号 |

L0 报告层级必须显式写为 `0`。历史未指定值只能作为兼容读取口径，不得作为新写入口径。

## 4. 一帧 D455 材料形成短期材料页

规则 D455-MP-001：

```
一次成功 D455 调用结果必须先形成 L0 报告和短期材料页。
短期材料页以报告编号 / 材料页编号 / 时间戳 / 帧号作为回查入口；材料页被读取承接后必须标记消费或从可消费集合移除，不得作为后续帧复用材料。
```

规则 D455-MP-002：

```
L0 材料页只承载短期可回查证据，不承载世界树事实。
```

规则 D455-MP-003：

```
L1 稳定子集不得复制成新的原始事实页。
L1 必须通过来源原始报告编号、来源外设帧编号、时间戳和坐标版本回查 L0。
```

规则 D455-MP-004：

```
若后续需要“稳定材料页”口径，第一版不新增结构体。
稳定材料页只能表达为：
    L1 稳定子集报告
    + L0 短期材料页
    + 来源原始报告编号
    + 来源外设帧编号
    + 时间戳 / 坐标版本
的运行期只读组合视图。该视图只在当前消费窗口内有效，不得作为可复用缓存。
```

失败分流：

```
调用结果失败 -> 不形成 L0 正式报告；可形成外设错误测量材料；
材料页无法创建 -> 输出材料页缺口，不得提交可回查报告；
材料页创建后句柄缺失 -> 输出句柄缺口，后续不得宣称材料完整；
材料页过期 -> 输出材料过期缺口，不得伪造可回查。
```

## 5. 帧、点、掩码和账本的来源回查

规则 D455-GROUP-001：

```
每次 D455 调用结果必须形成 L0 报告和对应短期材料页。
```

L0 报告和材料页必须携带以下结构化回查材料：

```
来源外设编号；
报告类型；
报告层级；
深度帧号；
彩色帧号；
采集 / 到达时间戳；
坐标系版本；
报告生成方法编号；
报告生成方法版本编号；
来源原始报告编号；
目标观察约束编号；
等待项编号。
```

规则 D455-GROUP-002：

```
原始帧、深度帧、彩色帧、对齐帧、空间候选队列、像素归属账本、簇感兴趣区域、簇点集、簇掩码、局部彩色材料、局部深度材料必须能通过报告编号、材料页编号、帧号、时间戳和坐标版本回查到本次采集材料。
```

规则 D455-GROUP-003：

```
对齐帧不存在时，对齐帧句柄必须为空或无效状态；
彩色通道 / 深度对齐状态必须写成一阶对齐材料状态；
坐标系一致性不得被强写成一致。
```

规则 D455-GROUP-004：

```
资源句柄可以作为 不透明句柄参与回查；
不得通过解析自由文字统一资源标识符、日志文本或控制面板显示来完成机器判断。
若现有实现使用 d455:// 形式，只能视为当前实现锚点或人读标识；
正式判断应依赖报告编号、材料页编号、报告层级、时间戳、帧号、消费状态、坐标版本和项目句柄。
```

## 6. L0 到 L1 / L2 / L3 的来源继承

规则 D455-LAYER-001：

```
L0 报告层级必须为 0。
L1 报告层级必须为 1。
L2 报告层级必须为 2。
L3 报告层级必须为 3。
```

规则 D455-LAYER-002：

```
L1 必须携带：
    来源原始报告编号；
    来源外设帧编号；
    来源报告时间戳；
    坐标系版本；
    报告生成方法编号；
    报告生成方法版本编号。
```

规则 D455-LAYER-003：

```
L2 / L3 若由 L1 派生，必须继承 L1 的来源原始报告编号、来源外设帧编号、来源报告时间戳和坐标系版本。
缺失任一关键来源材料时，应输出结构化缺口，不得进入扫描 / 跟踪正式承接。
```

规则 D455-LAYER-004：

```
L1 稳定门不得由日志、控制面板显示或单个评分直接生成。
L1 稳定门只能由连续命中计数、复现离散度、深度锚定、空间可用、可回查状态和必要质量材料共同收束。
稳定门的成立是复合特征或治理节点结论，不是外设一阶布尔值。
```

## 7. 分类队列与一次性消费规则

规则 D455-QUEUE-TYPE-001：

```
外设观察材料必须按数据类型进入对应临时队列，不得用一个混合队列加自由文本身份区分业务语义。
```

第一版至少区分：

```
L0 原始逐簇报告；
L1 稳定观察子集报告；
L2 扫描变化报告；
L3 跟踪报告；
D455 短期材料页；
目标观察约束。
```

规则 D455-QUEUE-TYPE-002：

```
每个队列内部只允许按时间戳 / 帧号 / 报告编号顺序读取未消费且未过期的材料。
读取方不得跨帧回退旧材料伪造当前可用。
```

规则 D455-QUEUE-TYPE-003：

```
报告或材料页被观察、扫描、识别、跟踪、质量收束或等待项承接后，必须标记消费或从可消费集合移除。
已消费材料不得再次作为新一轮业务判断输入。
```

规则 D455-QUEUE-TYPE-004：

```
过期材料必须在读写路径清理。过期材料不得被解析为可回查成功，也不得参与质量收束或四方法正式承接。
```

规则 D455-QUEUE-TYPE-005：

```
跨队列对齐只能使用结构化字段：报告编号、来源原始报告编号、来源外设帧编号、深度帧号、彩色帧号、时间戳、坐标版本、等待项编号和目标观察约束编号。
不得使用 `来源材料generation` 或任何自由字符串承担对齐、去重、复用或自我判断。
```

## 8. 队列容量、存活时限、等待项绑定和消费回查

规则 D455-QUEUE-001：

```
外设观察报告队列是运行期中间层。
队列和短期材料页不写数据库，不直接写世界树事实。
```

规则 D455-QUEUE-002：

```
队列裁剪应优先清理过期项和已消费项。
容量裁剪不得抢先删除同外设、同类型、同层级的最新未过期报告。
```

规则 D455-QUEUE-003：

```
等待项绑定必须显式记录等待项编号、匹配报告编号和消费时间。
未绑定等待项的报告可被最新窗口读取，但不得伪装成某个等待项的专属结果。
```

规则 D455-QUEUE-004：

```
报告被消费后，应保留消费状态、消费等待项编号和消费时间戳作为运行期测量材料。
已消费不是事实入账完成；它只表示该报告已被某个承接入口读取或绑定。
```

规则 D455-QUEUE-005：

```
材料页过期后，句柄解析应返回过期 / 不可回查状态。
不得为了让后续流程继续而伪造材料仍可回查。
```

## 9. 工程性能测量材料

工程性能测量材料用于代码效率优化、队列治理诊断和调度调参，不是自我为了认识外部世界而需要的特征类型。

```
采集尝试帧数；

观察报告入队统计帧数；

采集平均微秒；

队列容量；
队列数量；
材料页数量；

过期清理数量；
容量裁剪数量；

```

规则 D455-SPEED-001：

```
采集速度、入队速度和消费速度必须以计数、时间戳、毫秒、微秒或 百倍帧率形式表达。
这些值只用于工程性能观察、队列治理诊断和调度调参。
```

规则 D455-SPEED-002：

```
消费延迟毫秒 = 消费时间戳 - 报告入队时间戳。
若当前实现没有报告入队时间戳，第一版可登记为实现映射待补入口；
不得从日志文本反推消费延迟并写入机器判断。
```

规则 D455-SPEED-003：

```
工程性能测量材料不得作为材料质量收束的直接证据族。
“速度正常 / 速度异常 / 队列拥塞 / 采集过慢”这类判断若后续需要进入系统治理，必须另行设计为运行治理状态或诊断结论，不能伪装成观察材料质量特征。
材料质量收束只能读取与当前观察材料本身有关的来源、可回查、时间新鲜度、深度、彩色、坐标、感兴趣区域、任务阈值、跨帧稳定和先验冲突材料。
```

## 11. 失败分流

| 失败情况 | 输出材料 | 后续承接 |
| --- | --- | --- |
| 采集失败 | 外设错误码、失败计数、时间戳 | 外设线程治理 / 任务缺条件 |
| 材料页创建失败 | 材料页缺口、报告编号、来源帧编号 | 观察材料缺口 |
| 来源报告 / 帧号 / 时间戳缺失 | 来源链缺口 | 不进入 L1/L2/L3 正式承接 |
| 坐标版本缺失或不一致 | 坐标缺口、坐标版本材料 | 坐标复验 / 观察补证 |
| 对齐帧缺失 | 对齐材料缺口 | 质量收束降权或复验 |
| 材料页过期 | 过期状态材料、过期时间 | 复验观察 / 放弃当前材料 |
| 队列容量裁剪 | 裁剪计数、裁剪原因 | 速度 / 队列治理测量 |
| 等待项不匹配 | 等待项匹配缺口 | 任务继续等待或重筹办 |
| L1 缺 L0 回查 | 来源缺口 | 不允许稳定子集承接 |
| L2/L3 缺来源继承 | 来源缺口 | 不允许扫描 / 跟踪正式承接 |

## 14. 验证剧本

V1 单帧成功入队：

```
输入：一帧成功 D455 调用结果。
期望：生成 L0 报告、短期材料页、帧级句柄、簇级句柄、报告编号、帧号和时间戳。
禁止：直接写世界树事实或材料质量最终状态。
```

V2 材料同帧组回查：

```
输入：读取深度帧、彩色帧、空间候选、像素归属账本、簇感兴趣区域、点集、掩码。
期望：所有材料能回查同一来源外设、报告编号、外设帧编号、时间戳和坐标版本。
```

V3 L1 来源回查：

```
输入：连续多帧生成稳定观察子集。
期望：L1 报告层级为 1，携带来源原始报告编号、来源外设帧编号、来源报告时间戳和坐标版本。
```

V4 用后丢弃：

```
输入：同一队列材料被读取承接后再次请求。
期望：已消费材料不再作为新业务输入；若没有新材料，返回等待、缺材料或过期分流。
```

V5 过期材料页：

```
输入：材料页超过存活时限后解析句柄。
期望：返回过期 / 不可回查状态，不伪造可回查材料。
```

V6 工程性能测量：

```
输入：运行外设线程固定样本数量。
期望：可读取采集尝试、采集成功、入队帧数、窗口毫秒、百倍帧率、队列数量和材料页数量。
禁止：从日志文本解析速度并参与机器判断。
```

V7 L2 / L3 来源缺失：

```
输入：构造缺少来源原始报告、来源外设帧或来源时间戳的扫描 / 跟踪报告。
期望：输出来源缺口，不进入扫描 / 跟踪正式承接。
```
