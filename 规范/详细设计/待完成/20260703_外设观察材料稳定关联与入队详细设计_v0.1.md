## 1. 设计目标

本设计解决：

```text
一帧 D455 外设材料如何形成可回查的短期材料页；
深度帧、彩色帧、对齐帧、空间点、像素归属账本和候选摘要如何同源绑定；
L0、L1、L2、L3 报告层如何形成来源链；
报告 ID、外设帧 ID、材料页 ID、来源材料 generation 和坐标版本如何参与幂等；
队列容量、TTL、等待项绑定、消费标记和过期清理如何表达；
采集速度、入队速度、消费速度如何作为一阶测量特征进入后续治理。
```

本设计的核心口径：

```text
外设侧负责提供可追溯材料；
观察域中间层负责组织材料成熟度和报告分层；
自我侧方法负责事实裁决和需求承接；
材料链稳定性先于质量收束、像素候选、局部体素、场景体素先验和四方法实现映射。
```

## 2. 基础定义

### 2.1 材料页

材料页是外设一次成功采集或一次报告生成后形成的短期可回查证据页。材料页保存或引用：

```text
来源外设；
来源外设帧；
来源材料 generation；
报告 ID；
采集时间戳；
过期时间戳；
原始帧 / 深度帧 / 彩色帧 / 对齐帧 / 空间点 / 像素归属账本 / 候选摘要的句柄；
坐标系版本；
报告项副本或可回查句柄。
```

材料页不是世界树事实，也不是需求满足证据本身。材料页只证明“某时某外设提供过一组可回查材料”。

### 2.2 材料组 generation

材料组 generation 是同源材料的运行期身份。它必须至少能区分：

```text
来源外设；
报告类型；
报告层级；
深度帧号；
彩色帧号；
采集 / 到达时间；
坐标系版本；
报告生成方法；
报告生成方法版本；
来源原始报告；
目标观察约束和约束 generation。
```

第一版不得为 generation 新增持久业务结构体。generation 可以作为 I64 / VecI64 / VecIU64 / 语素化身份 / 运行期只读计算结果承载；若现有实现暂以字符串资源句柄辅助回查，字符串不得作为机器判断依据。

### 2.3 报告层级

外设观察材料按成熟度和用途分为四层：

| 层级 | 名称 | 来源 | 作用 | 禁止事项 |
| --- | --- | --- | --- | --- |
| L0 | 原始帧 / 原始簇 / 短期材料页 | 外设一次采集或一次低层报告生成 | 原始材料、低层诊断、候选摘要和回查 | 不写世界树事实；不写最终材料质量状态 |
| L1 | 稳定观察子集 / 逐簇识别报告 | L0 可回查材料和低层稳定门 | 提供观察候选、ROI、掩码、点集、质量证据 | 不确认稳定世界存在；不裁决 C -> E |
| L2 | 扫描变化报告 | L1 或已绑定可比较材料 | 提供面向扫描的变化材料 | 不从原始材料直接伪造已确认变化事实 |
| L3 | 跟踪报告 | L1、目标观察约束或已确定目标集合 | 提供面向跟踪的连续复现、位置、丢失和重捕获材料 | 不把外设跟踪 ID 当世界树存在 ID |

L0 报告层级必须显式写为 `0`。历史未指定值只能作为兼容读取口径，不得作为新写入口径。

## 4. 一帧 D455 材料形成短期材料页

规则 D455-MP-001：

```text
一次成功 D455 调用结果必须先形成 L0 报告和短期材料页。
短期材料页以报告 ID / 材料页 ID / 来源材料 generation 作为回查入口。
```

规则 D455-MP-002：

```text
L0 材料页只承载短期可回查证据，不承载世界树事实。
```

规则 D455-MP-003：

```text
L1 稳定子集不得复制成新的原始事实页。
L1 必须通过来源原始报告 ID、来源外设帧 ID 和来源材料 generation 回查 L0。
```

规则 D455-MP-004：

```text
若后续需要“稳定材料页”口径，第一版不新增结构体。
稳定材料页只能表达为：
    L1 稳定子集报告
    + L0 短期材料页
    + 来源原始报告 ID
    + 来源外设帧 ID
    + 来源材料 generation
的运行期只读组合视图。
```

失败分流：

```text
调用结果失败 -> 不形成 L0 正式报告；可形成外设错误测量材料；
材料页无法创建 -> 输出材料页缺口，不得提交可回查报告；
材料页创建后句柄缺失 -> 输出句柄缺口，后续不得宣称材料完整；
材料页过期 -> 输出材料过期缺口，不得伪造可回查。
```

## 5. 帧、点、掩码和账本的同源绑定

规则 D455-GROUP-001：

```text
每次 D455 调用结果必须形成材料组 generation。
```

generation 至少由以下一阶材料或身份材料收束：

```text
来源外设 ID；
报告类型；
报告层级；
深度帧号；
彩色帧号；
采集 / 到达时间戳；
坐标系版本；
报告生成方法 ID；
报告生成方法版本 ID；
来源原始报告 ID；
目标观察约束 ID；
约束 generation。
```

规则 D455-GROUP-002：

```text
原始帧、深度帧、彩色帧、对齐帧、空间候选队列、像素归属账本、簇 ROI、簇点集、簇掩码、局部彩色材料、局部深度材料必须能回查到同一材料组 generation。
```

规则 D455-GROUP-003：

```text
对齐帧不存在时，对齐帧句柄必须为空或无效状态；
RGB / 深度对齐状态必须写成一阶对齐材料状态；
坐标系一致性不得被强写成一致。
```

规则 D455-GROUP-004：

```text
资源句柄可以作为 opaque handle 参与回查；
不得通过解析自由文本 URI、日志文本或控制面板显示来完成机器判断。
若现有实现使用 d455:// 形式，只能视为当前实现锚点或人读标识；
正式判断应依赖报告 ID、材料页 ID、generation、坐标版本和项目句柄。
```

## 6. L0 到 L1 / L2 / L3 的来源继承

规则 D455-LAYER-001：

```text
L0 报告层级必须为 0。
L1 报告层级必须为 1。
L2 报告层级必须为 2。
L3 报告层级必须为 3。
```

规则 D455-LAYER-002：

```text
L1 必须携带：
    来源原始报告 ID；
    来源外设帧 ID；
    来源材料 generation；
    坐标系版本；
    报告生成方法 ID；
    报告生成方法版本 ID。
```

规则 D455-LAYER-003：

```text
L2 / L3 若由 L1 派生，必须继承 L1 的来源原始报告 ID、来源外设帧 ID、来源材料 generation 和坐标系版本。
缺失任一关键来源材料时，应输出结构化缺口，不得进入扫描 / 跟踪正式承接。
```

规则 D455-LAYER-004：

```text
L1 稳定门不得由日志、控制面板显示或单个评分直接生成。
L1 稳定门只能由连续命中计数、复现离散度、深度锚定、空间可用、可回查状态和必要质量材料共同收束。
稳定门的成立是复合特征或治理节点结论，不是外设一阶 bool。
```

## 7. 幂等规则

规则 D455-IDEMP-001：

```text
报告幂等键不得只使用报告 ID。
```

幂等键应由以下材料收束：

```text
来源外设 ID；
报告类型；
报告层级；
深度帧号；
彩色帧号；
采集 / 到达时间戳；
坐标系版本；
报告生成方法 ID；
报告生成方法版本 ID；
来源原始报告 ID；
目标观察约束 ID；
约束 generation。
```

规则 D455-IDEMP-002：

```text
第一版不新增持久结构体表达幂等键。
幂等键可以写入来源材料 generation，或由运行期只读函数从一阶材料动态计算。
```

规则 D455-IDEMP-003：

```text
提交外设观察报告前，应按幂等键扫描未过期的同外设、同类型、同层级报告。
若存在同幂等键报告，应返回已有报告 ID、替换同层材料或复用材料页；
若不存在，才允许分配新报告 ID。
```

规则 D455-IDEMP-004：

```text
提交短期材料页时，除报告 ID 外，还应检查同来源材料 generation 的材料页。
同 generation 材料页不得无条件重复创建。
```

规则 D455-IDEMP-005：

```text
坐标系版本、外参版本或 D455 到场景变换版本必须纳入来源材料 generation。
坐标版本不一致的材料不得合并到同一幂等组。
```

## 8. 队列容量、TTL、等待项绑定和消费回查

规则 D455-QUEUE-001：

```text
外设观察报告队列是运行期中间层。
队列和短期材料页不写数据库，不直接写世界树事实。
```

规则 D455-QUEUE-002：

```text
队列裁剪应优先清理过期项和可替换重复项。
容量裁剪不得抢先删除同外设、同类型、同层级的最新未过期报告。
```

规则 D455-QUEUE-003：

```text
等待项绑定必须显式记录等待项 ID、匹配报告 ID 和消费时间。
未绑定等待项的报告可被最新窗口读取，但不得伪装成某个等待项的专属结果。
```

规则 D455-QUEUE-004：

```text
报告被消费后，应保留消费状态、消费等待项 ID 和消费时间戳作为运行期测量材料。
已消费不是事实入账完成；它只表示该报告已被某个承接入口读取或绑定。
```

规则 D455-QUEUE-005：

```text
材料页过期后，句柄解析应返回过期 / 不可回查状态。
不得为了让后续流程继续而伪造材料仍可回查。
```

## 9. 工程性能测量材料

工程性能测量材料用于代码效率优化、队列治理诊断和调度调参，不是自我为了认识外部世界而需要的特征类型。

```text
采集尝试帧数；
采集成功帧数；
观察报告入队帧数；
观察报告入队统计帧数；
观察报告入队窗口毫秒；
观察报告入队 FPSx100；
采集平均微秒；
迁移分割平均微秒；
发布编排平均微秒；
样本写入平均微秒；
轻量相机总平均微秒；
轻量结果构建平均微秒；
轻量候选摘要平均微秒；
队列容量；
队列数量；
材料页数量；
等待项数量；
过期清理数量；
容量裁剪数量；
报告入队时间戳；
消费时间戳；
消费延迟毫秒。
```

规则 D455-SPEED-001：

```text
采集速度、入队速度和消费速度必须以计数、时间戳、毫秒、微秒或 FPSx100 形式表达。
这些值只用于工程性能观察、队列治理诊断和调度调参。
```

规则 D455-SPEED-002：

```text
消费延迟毫秒 = 消费时间戳 - 报告入队时间戳。
若当前实现没有报告入队时间戳，第一版可登记为实现映射待补入口；
不得从日志文本反推消费延迟并写入机器判断。
```

规则 D455-SPEED-003：

```text
工程性能测量材料不得作为材料质量收束的直接证据族。
“速度正常 / 速度异常 / 队列拥塞 / 采集过慢”这类判断若后续需要进入系统治理，必须另行设计为运行治理状态或诊断结论，不能伪装成观察材料质量特征。
材料质量收束只能读取与当前观察材料本身有关的来源、可回查、时间新鲜度、深度、彩色、坐标、ROI、任务阈值、跨帧稳定和先验冲突材料。
```

## 11. 失败分流

| 失败情况 | 输出材料 | 后续承接 |
| --- | --- | --- |
| 采集失败 | 外设错误码、失败计数、时间戳 | 外设线程治理 / 任务缺条件 |
| 材料页创建失败 | 材料页缺口、报告 ID、来源帧 ID | 观察材料缺口 |
| 来源 generation 缺失 | 来源链缺口 | 不进入 L1/L2/L3 正式承接 |
| 坐标版本缺失或不一致 | 坐标缺口、坐标版本材料 | 坐标复验 / 观察补证 |
| 对齐帧缺失 | 对齐材料缺口 | 质量收束降权或复验 |
| 材料页过期 | 过期状态材料、过期时间 | 复验观察 / 放弃当前材料 |
| 队列容量裁剪 | 裁剪计数、裁剪原因 | 速度 / 队列治理测量 |
| 等待项不匹配 | 等待项匹配缺口 | 任务继续等待或重筹办 |
| L1 缺 L0 回查 | 来源缺口 | 不允许稳定子集承接 |
| L2/L3 缺来源继承 | 来源缺口 | 不允许扫描 / 跟踪正式承接 |
