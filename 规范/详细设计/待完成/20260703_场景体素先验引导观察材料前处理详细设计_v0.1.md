## 1. 设计目标

本设计解决：

```text
如何让自我所在场景中的已确认信息反向参与外设观察材料处理；
如何在不让外设直接裁决世界事实的前提下，降低 D455 / 视觉中间层每帧处理成本；
如何把场景体素、目标观察约束和当前帧材料组织成可回查的观察候选、冲突候选、遮挡解释和信息缺口；
如何避免先验绑架观察。
```

本设计不解决：

```text
具体 D455 算法实现；
具体阈值取值；
新增 C++ 结构体；
观察 / 扫描 / 识别 / 跟踪的事实入账裁决；
自我苏醒、初步成熟或业务闭环完成声明。
```

## 2. 核心结论

应采纳“场景体素 / 存在体素反向参与感知”的方向，但必须表达为：

```text
自我侧异步发布外设观察先验快照；
外设 / 视觉中间层每帧处理前只读该快照；
外设侧据此选择处理区域、处理频率和特征提取内容；
外设侧仍只输出当前帧证据、候选、评分、解释和缺口；
观察 / 扫描 / 识别 / 跟踪仍由自我侧方法裁决是否入账事实。
```

不得表达为：

```text
外设侧融合自我事实后自行判断世界事实；
外设侧读取世界树可变事实作为裁决依据；
场景体素预测直接等于当前观察结果；
先验存在 E 直接推出当前帧确认 E；
未命中先验区域直接推出 E 消失。
```

压缩口径：

```text
自我侧给“该怎么看”的先验；
外设侧给“当前实际看到了什么”的证据；
中间层比较先验和当前帧；
自我侧裁决事实。
```

## 3. 三层数据边界

### 3.1 场景事实层

场景事实层由自我侧维护，来源是当前场景中已经通过合法提交入口入账的存在、特征、特征值、坐标、体素和关系。

允许：

```text
作为场景体素服务生成只读快照的输入；
作为目标观察约束、扫描关注集合和跟踪目标集合的来源；
作为后续观察 / 扫描 / 识别 / 跟踪裁决事实的依据之一。
```

禁止：

```text
直接交给外设线程写回；
直接作为外设候选归属结论；
直接替代当前帧观察证据；
直接写入需求满足、安全 / 服务结算或方法动作动态。
```

### 3.2 场景体素先验层

场景体素先验层是由场景体素服务从场景事实层只读生成的运行期快照。它可用于检索、投影、过滤、解释和显示。

可包含一阶材料：

```text
来源场景ID
场景体素版本
坐标系版本
体素分辨率
只读快照句柄
已确认存在体素索引句柄
已知稳定体素区句柄
已知空闲区句柄
未知区句柄
场景边界句柄
快照生成时间戳
快照 generation
TTL
```

这些值是材料、句柄、版本、来源或生命周期材料，不等于“先验可用”判断。

### 3.3 外设处理先验层

外设处理先验层是面向某个外设和当前外设位姿投影后的处理提示。它不是世界树事实，也不是正式观察结果。

可包含一阶材料：

```text
来源场景体素版本
来源坐标系版本
来源目标观察约束ID
约束 generation
外设ID
D455到场景变换版本
D455位姿时间戳
先验快照生成时间戳
先验快照TTL
图像ROI集合句柄
处理mask句柄
预计深度范围图句柄
已知稳定区mask句柄
已知空闲区mask句柄
未知区mask句柄
预计遮挡区mask句柄
自由空间冲突关注区mask句柄
高价值目标区mask句柄
分区处理频率表句柄
特征提取计划句柄
```

这些材料应尽量转成外设坐标系或图像坐标系，避免 D455 线程理解世界树、需求树或存在关系。

## 4. 异步发布流程

### 4.1 发布链路

```text
自我当前场景事实
    ↓
场景体素服务生成世界坐标下的只读场景体素快照
    ↓
外设观察先验发布器读取外设位姿和目标观察约束
    ↓
投影成面向 D455 的外设处理先验快照
    ↓
D455 / 视觉中间层每帧处理前读取最新有效快照
    ↓
有效：按先验分区处理
无效 / 过期 / 坐标不一致：退回轻量全局观察或默认处理策略
```

### 4.2 异步更新触发

外设处理先验快照应在以下条件变化时异步更新：

```text
当前场景事实版本变化；
场景体素版本变化；
自我 / 外设位姿变化；
D455 到场景坐标变换版本变化；
目标观察约束变化；
扫描关注集合变化；
跟踪目标集合变化；
上一轮外设报告产生自由空间冲突、遮挡解释不足或信息缺口；
快照 TTL 到期；
快照 generation 失配；
外设材料质量长期低于当前任务阈值，需要调整处理策略。
```

仅“场景事实未变”不能证明先验快照仍可用。相机位姿、坐标版本、目标约束和 TTL 都可能让旧 ROI 失效。

### 4.3 外设采集不得被先验阻塞

D455 线程不得等待先验快照而阻塞采集。

```text
有有效快照：按先验减负。
无快照：按默认轻量 / 全局策略运行。
快照过期：降权、复验或生成结构化缺口。
坐标不一致：不得按旧 ROI 裁决事实。
```

### 4.4 外设观察先验发布器权责边界

外设观察先验发布器不是新的事实裁决者，也不是外设线程的世界树读取口。它应被定位为：

```text
运行期只读视图生成链 / 场景体素服务伴随发布器。
```

归属：

```text
由自我侧或场景体素服务侧的只读发布链承接；
可以由运行期服务、只读视图生成器或任务管理触发的发布步骤实现；
不得归入 D455 采集线程的事实裁决职责；
不得作为观察、扫描、识别、跟踪本能方法。
```

读取：

```text
场景体素只读快照；
目标观察约束；
D455 位姿材料；
D455 到场景坐标变换版本；
当前任务最大允许报告年龄；
扫描关注集合；
跟踪目标集合；
上一轮外设报告中的冲突 / 遮挡 / 信息缺口材料。
```

写入：

```text
外设处理先验快照运行期只读材料；
ROI / mask / 预计深度范围句柄；
分区处理频率表句柄；
特征提取计划句柄；
先验版本、坐标系版本、目标约束ID、generation、TTL 等一阶材料；
必要的结构化缺口材料。
```

禁止：

```text
写世界树事实；
写需求满足、安全 / 服务结算；
写方法动作动态；
创建观察 / 扫描 / 识别 / 跟踪运行；
直接裁决候选 C -> 已确认存在 E；
直接修改场景体素、稳定存在体素或外设原始材料。
```

## 5. 前处理策略

外设 / 视觉中间层读取外设处理先验快照后，可在每帧处理前生成本帧处理策略。

### 5.1 先验 ROI 裁剪

```text
已知存在 E
    + E 的稳定体素 / AABB / 当前位姿
    + D455 当前外参
    -> 投影到当前图像平面
    -> 生成 ROI / mask / 预计深度范围
```

ROI 只能作为处理建议，不能作为事实结论。

允许输出：

```text
当前帧在 E 的预计区域内发现候选材料；
当前帧在 E 的预计区域内未发现足够材料；
当前帧在 E 的预计区域内存在遮挡候选；
当前帧在 E 的预计区域内存在自由空间冲突候选；
当前帧证据不足，需要复验或识别。
```

禁止输出：

```text
E 当前存在；
E 当前消失；
候选 C 已归属 E；
当前需求已满足。
```

### 5.2 已知稳定区低频维护

场景体素中长期稳定的墙、地面、桌面、固定设备等区域，可作为低频维护区域。

工程表达应避免把“背景”当成自我认知中的存在类别。应表达为：

```text
已知稳定存在投影区；
暂不需要高频处理的稳定区域；
低关注维护区域；
已知空闲区；
未知区。
```

不得将背景作为稳定存在类别、普通 bool 特征或世界树事实。相关处理只能表达为：

```text
处理频率策略；
已知稳定区句柄；
已知空闲区句柄；
未知区句柄；
低关注维护区句柄；
差异像素数量；
一致性评分Q10000；
新占据像素数量；
自由空间冲突数量。
```

当前帧与预测区域差异低时，只能记录一致性评分、差异像素数量或低频维护材料；不得直接宣称“无需观察”或“场景无变化”。

当前帧与预测区域差异高时，输出：

```text
新占据候选；
自由空间冲突候选；
场景变化候选；
遮挡解释不足；
需复验缺口。
```

### 5.3 候选分裂

当一个大连通域可能粘连多个已知存在、承载面或未知区域时，可使用先验投影辅助候选分裂：

```text
大连通域
    -> 按已知存在投影 mask
    -> 按预计深度层
    -> 按承载面 / 空闲区边界
    -> 分裂为多个观察候选 C
```

候选分裂不是识别完成。输出必须停在观察域材料：

```text
来源分割区域ID
使用场景体素版本
先验投影重合率Q10000
先验深度一致评分Q10000
候选争议像素数量
候选像素归属质量评分Q10000
候选分裂来源状态
```

最终 C 是否对应世界树稳定存在 E，仍由自我侧观察 / 扫描 / 跟踪 / 识别裁决。

### 5.4 遮挡解释优先

当先验预测 E 应在当前视野中，但当前帧未取得足够材料时，不得直接判定 E 消失。

应先区分：

```text
预计区域前方有更近深度 / 其它候选 -> 遮挡候选
预计区域超出当前视野 -> 视野外候选
预计区域深度缺失 -> 深度缺失候选
预计区域当前深度明确为空 -> 自由空间冲突候选
材料质量不足 -> 材料质量缺口
坐标 / 版本 / TTL 不满足 -> 先验不可用缺口
```

`遮挡解释状态`、`自由空间冲突成立状态`、`需复验状态` 均属于判断型状态。外设侧只能提供深度差、遮挡像素数量、前景候选数量、视野边界关系、缺失像素数量、版本和时间材料；状态由复合特征、二次特征或治理方法收束。

### 5.5 多频率处理

先验可指导分区处理频率：

```text
高频：
    当前任务目标 ROI
    跟踪目标
    高风险未知区
    自由空间冲突区
    复验关注区

中频：
    一般已知存在区域
    普通新候选区
    扫描关注集合

低频：
    已知稳定存在投影区
    长期不变区域
    低价值远距区域
```

频率策略是处理策略，不是世界事实。不得由“低频处理”推出“该区域无变化”。

### 5.6 特征提取按需化

外设侧不应每帧全量提取全部特征族。应根据当前任务目标、目标观察约束和先验分区选择特征族。

示例：

```text
跟踪位置：
    中心、AABB、深度一致、连续命中、复现离散度。

补体素：
    局部体素、有效深度点、体素命中率、缺失体素范围。

判断遮挡：
    预计深度范围、前景更近深度、遮挡像素数量、视野外比例。

发现新存在：
    已知空闲区 / 未知区的新占据、轮廓闭合、局部体素证据。
```

外设 / 视觉中间层可以输出：

```text
局部体素证据；
ROI / mask / 点集句柄；
先验投影重合率；
先验深度一致评分；
可见体素命中率；
被遮挡体素比例；
自由空间冲突数量；
新占据像素数量；
先验冲突数量；
候选争议像素数量；
材料质量一阶证据；
结构化信息缺口；
建议后续方法类型材料。
```

外设 / 视觉中间层不得输出：

```text
世界树稳定存在确认；
存在消失确认；
候选 C 已归属 E 的最终裁决；
材料质量状态 = 可用；

需求满足状态；
安全 / 服务可结算状态；
方法动作动态。
```

建议后续方法类型材料只是一阶建议或缺口材料，不得直接调用观察、扫描、识别或跟踪本能方法。后续必须经需求树、任务筹办和方法选择承接。

进一步禁止：

```text
D455 前处理策略函数不得直接调用观察 / 扫描 / 识别 / 跟踪；
视觉中间层不得直接创建四方法运行；
外设观察先验发布器不得直接创建四方法运行；
建议后续方法类型不得被任务管理绕过候选方法选择直接执行；
建议后续方法类型必须先转为结构化缺口、目标观察约束、候选材料或需求来源材料。
```

## 7. 判断型状态收束

以下状态不得作为外设直接生成的一阶事实：

```text
先验可用状态
先验新鲜度状态
先验使用策略状态
目标观察约束可用性状态
稳定区低频维护处理状态
遮挡解释状态
自由空间冲突成立状态
候选与先验一致状态
新存在候选成立状态
需复验状态
```

它们应声明依赖特征族、收束方法、写入方、读取方、失败分流和可回查证据。

### 7.1 先验可用性依赖特征族

```text
场景体素版本
坐标系版本
D455到场景变换版本
D455位姿时间戳
快照生成时间戳
TTL
目标观察约束 generation
外设帧时间戳
坐标变换残差Q10000
相机姿态置信度Q10000
先验ROI覆盖率Q10000
当前任务最大允许报告年龄
```

收束出口只能用于：

```text
允许按先验处理；
降权使用；
请求复验；
退回默认轻量 / 全局处理；
生成结构化缺口。
```

不得用于确认事实。

### 7.2 先验新鲜度依赖特征族

`先验新鲜度状态` 是判断型状态，不得由 D455 采集线程或外设报告直接填写。

一阶材料：

```text
快照生成时间戳
TTL
外设帧时间戳
当前任务最大允许报告年龄
D455位姿时间戳
场景体素版本
坐标系版本
目标观察约束generation
外设处理先验快照generation
```

收束写入方：

```text
先验可用性收束方法；
前处理策略生成链；
运行期只读视图治理节点。
```


## 9. 与四个本能方法的消费边界

```text

    消费已合法外设当前数据集、扫描变化报告和先验冲突材料。

    消费候选与已知存在的先验匹配评分、轮廓 / 深度 / 体素一致性证据。

    消费目标观察约束、目标 ROI、预计深度范围和连续帧复现证据。
```

## 10. 防先验绑架规则

必须写死以下防线：

```text
1. 先验快照只读。
2. 当前观察证据和先验预测分开记录。
3. 预测投影不能直接当作观察结果。
4. 先验匹配评分不能单独完成 C -> E 归属。
5. 没看到不得直接推出不存在或消失。
6. 遮挡、视野外、深度缺失、自由空间冲突必须分开。
7. 先验过旧、坐标失配或 TTL 到期时，只能降权、复验或写缺口。
8. 外设线程不得等待先验快照阻塞采集。
9. 必须保留低频全局 / 未知区处理，不能让 ROI 永久过滤未知存在。
10. 先验由旧观察生成时，不能用同一先验反向证明旧观察正确，只能作为当前帧处理辅助。
11. 不得将背景作为稳定存在类别、普通 bool 特征或世界树事实。
12. 稳定区 / 空闲区 / 未知区 / 低关注维护区只能作为处理提示、mask句柄、计数或评分材料。
13. D455 前处理策略函数不得直接调用观察 / 扫描 / 识别 / 跟踪。
14. 建议后续方法类型只能作为缺口或需求来源材料，不能直接触发方法执行。
```
