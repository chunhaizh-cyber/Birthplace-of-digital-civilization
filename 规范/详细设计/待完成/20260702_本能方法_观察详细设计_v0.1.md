## 1. 方法定位

观察的目标是把外设材料组织成可承接的观察事实、可观测单位对应、存在信息新建或更新材料、特征补充材料和缺口。

观察看起来会使用连续帧、稳定性、掩码、ROI、点集和候选归属，因此局部上像跟踪；但观察不是跟踪。观察的目标不是持续盯住确定对象，而是让：

```text
外设材料 -> 观察材料集 -> 可观测单位 / 存在信息新建或更新材料 / 特征补充材料 / 缺口
```

形成可被自我后续方法、任务链和提交入口承接的结构化材料。

## 2. 输入

```text
观察范围或目标观察约束
逐簇识别报告
可回查原始材料句柄
观察像素簇集合
ROI / 掩码 / 点集 / 局部图
材料质量状态
当前需求的质量阈值或最大允许观察年龄
可选：已确认存在的指定特征值补完需求
```

## 3. 输出

```text
观察材料集可用状态
可观测单位对应摘要
存在信息新建或更新材料
观察像素簇事实
特征补充材料
不可观测区域 / 低质量区域 / 未解释区域缺口
输出结果场景或运行存在中的过程证据
```

## 4. 允许写入

```text
观察事实承接所需的场景 / 存在 / 特征 / 特征值结构
观察像素簇、可观测单位对应状态、存在信息新建或更新材料
质量状态、材料可回查状态、不可观测原因
结构化缺口和补观察需求来源
```

## 5. 禁止写入

```text
不得把原始帧直接写成世界树事实。
不得把外设候选编号写成稳定世界存在 ID。
不得仅凭单帧材料宣称稳定存在确认。
不得替代识别宣称材料与已有存在唯一对应。
不得替代扫描维护所有已归属存在当前状态。
不得替代跟踪宣称确定目标连续复现。
不得把特征值缺口补完写成观察成立的必要条件。
不得因为新建存在缺少任意可能特征就批量生成补完需求。
```

## 6. 消费的数据层

主要消费：

```text
L0 原始材料句柄 / 短期材料页
L1 逐簇识别报告
```

不得直接消费自我不可见高频原始流。

## 7. 共享底层能力

观察可以使用底层关联判断能力：

```text
像素归属
簇归属
材料质量判断
候选过滤
范围内对应计算
```

这些能力不是直接调用识别本能方法。若观察过程中需要正式判断当前材料对应哪个已有存在，应输出结构化缺口或候选材料，由需求 / 任务 / 方法链决定是否选择识别。

## 8. 观察触发来源

观察可以由多种来源触发。特征值缺口补完只是观察执行中可能派生补完子需求的一种来源，不限制观察任务自身继续执行。

```text
开放观察：
    目标存在可以为空，目标特征可以为空，只给场景、区域、原始材料范围或观察窗口。
    用于初始建账、新存在发现、场景材料承接和自然观察。

定向观察：
    目标存在已知，目标特征类型已知，目标是补全该特征类型的值。
    用于已确认存在的特征值缺口补完、识别比较特征补充、扫描当前值补证或跟踪观察补证。
```

## 9. 特征值缺口补完闭环

```text
存在 E 已确认具备特征类型 FT
-> E.FT 当前值不完整 / 不可比较 / 当前无效
-> 二次特征或状态比较记录 E.FT 存在补完缺口
-> 缺口被上级任务、扫描、识别、跟踪、安全 / 服务需要或认知加深策略选中
-> 生成补完需求
-> 任务筹办选择观察或其他补完方法
-> 观察读取外设材料并补充 E.FT 的事实材料
-> E.FT 的一阶值或当前状态按正式提交入口更新
-> 二次判断更新，需求按当前值与目标值重新结算
```

这里的目标是补全已确认特征类型的值，不是让观察自动追求所有可能特征。若 FT 尚未确认属于 E，不能直接生成 E.FT 补完需求，只能作为观察发现或识别 / 归属缺口继续分流。

## 10. 父观察任务收束时的子需求治理

观察任务执行中发现特征值缺口并派生补完子需求后，观察任务自身仍可继续执行。父观察任务准备结束时，应检查自身派生且尚未完成的子需求：

```text
子需求是父观察任务完成前置：
    父观察任务暂缓结束，先等待或执行该子需求。

子需求只是观察中发现的补完缺口，且没有更高优先级任务：
    父观察任务暂缓结束，先执行该子需求。

子需求只是观察中发现的补完缺口，且已有更高优先级任务：
    放弃该子需求的当前活动承接，父观察任务结束。

子需求已被安全 / 服务 / 扫描 / 识别 / 跟踪 / 认知加深策略接管：
    不随父观察任务结束而放弃，转由新父需求或更高来源继续承接。
```

该治理点可能需要修改自我线程、需求活动集、需求截止 / 放弃、任务收束或父子需求关系清理相关程序。当前详细设计只记录后续实现影响，不声明当前代码已具备该能力。

已正式入树的子需求放弃时，应优先写成截止、取消活动承接或失去活动依据；未入树的运行期子需求候选可以直接丢弃。

## 11. 与其他方法边界

```text
与扫描：
    观察补充材料和特征事实，扫描维护已归属存在的当前状态。

与识别：
    观察可生成对应材料和特征补充材料，识别负责限定范围内已有存在的对应关联判断。

与跟踪：
    观察可使用连续帧稳定材料，跟踪只面向确定目标集合持续复现。
```

## 12. 缺口分流

```text
材料不可回查 -> 材料质量缺口
可观测单位未闭合 -> 补观察或局部细分需求来源
候选不唯一 -> 识别需求来源
已有目标需要连续复现 -> 跟踪需求来源
已归属存在需要当前状态维护 -> 扫描需求来源
已确认特征类型的值不完整 / 不可比较 / 当前无效 -> 特征值补完需求来源
```
