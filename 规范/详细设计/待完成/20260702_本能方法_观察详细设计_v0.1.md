## 1. 方法定位

观察的目标是把外设材料组织成可承接的观察事实、可观测单位对应、存在信息新建或更新材料、特征补充材料和缺口。

观察看起来会使用连续帧、稳定性、掩码、ROI、点集和候选归属，因此局部上像跟踪；但观察不是跟踪。观察的目标不是持续盯住确定对象，而是让：

```text
外设材料 -> 观察材料集 -> 可观测单位 / 存在信息新建或更新材料 / 特征补充材料 / 缺口
```

形成可被自我后续方法、任务链和提交入口承接的结构化材料。

## 2. 输入

```text
观察范围或目标观察约束
逐簇识别报告
可回查原始材料句柄
观察像素簇集合
ROI / 掩码 / 点集 / 局部图
外设一阶材料值、质量评分、计数、版本和低层诊断候选
可选：已由观察 / 中间层质量收束方法产生的材料质量状态引用
当前需求的质量阈值或最大允许观察年龄
可选：已确认存在的指定特征值补完需求
```

## 3. 输出

```text
观察材料集可用状态
观察材料质量收束状态、质量评分、阻断原因集合和可回查证据引用
可观测单位对应摘要
存在信息新建或更新材料
观察像素簇事实
特征补充材料
不可观测区域 / 低质量区域 / 未解释区域缺口
输出结果场景或运行存在中的过程证据
```

## 4. 允许写入

```text
观察事实承接所需的场景 / 存在 / 特征 / 特征值结构
观察像素簇、可观测单位对应状态、存在信息新建或更新材料
由质量收束方法产生的材料质量状态、材料质量评分、材料可回查状态、不可观测原因和证据引用
结构化缺口和补观察需求来源
```

## 5. 禁止写入

```text
不得把原始帧直接写成世界树事实。
不得把外设候选编号写成稳定世界存在 ID。
不得仅凭单帧材料宣称稳定存在确认。
不得替代识别宣称材料与已有存在唯一对应。
不得替代扫描维护所有已归属存在当前状态。
不得替代跟踪宣称确定目标连续复现。
不得把特征值缺口补完写成观察成立的必要条件。
不得因为新建存在缺少任意可能特征就批量生成补完需求。
不得把外设直接输出的质量候选、错误码、评分或报告文本写成材料质量状态。
```

## 7. 共享底层能力

观察可以使用底层关联判断能力：

```text
像素归属
簇归属
观察材料质量收束
候选过滤
范围内对应计算
```

这些能力不是直接调用识别本能方法。若观察过程中需要正式判断当前材料对应哪个已有存在，应输出结构化缺口或候选材料，由需求 / 任务 / 方法链决定是否选择识别。

## 8. 判断型枚举与材料质量收束规则

普通一阶特征只记录可直接取得、可测量、可引用、可计数、可评分、可追溯的材料值。凡是根据若干材料判断出来的状态，无论是 bool 还是枚举，都不应伪装成外设直接取得的一阶事实。

观察详细设计中出现的 `材料质量状态`、`材料可回查状态`、`当前观察新鲜度状态`、`观察候选有效状态`、`归属状态`、`稳定复现状态`、`提交候选判定状态` 等枚举值，若其取值依赖其它特征、评分、数量、来源、版本、阈值或任务上下文，则属于判断型枚举。判断型枚举只能由复合特征、内部治理节点收束状态或方法执行后的阶段性结论状态产生。

外设侧可以直接提供：

```text
原始材料句柄
设备状态
时间戳
帧序号
帧宽 / 帧高
深度图 / 彩色图 / 空间点材料句柄
有效深度像素数量
无效深度像素数量
深度缺失比例
深度噪声评分
曝光 / 模糊 / 对齐评分
坐标变换版本
外设错误码
低层诊断候选
```

外设侧不得直接提供：

```text
材料质量状态 = 可用
观察结果包可提交
观察候选可入账
当前材料满足需求阈值
当前观察足以更新 E.FT
需求满足状态
稳定存在确认
世界树存在归属
```

材料质量状态可以保留为内部收束状态，但它的工程角色是观察材料质量判定复合特征或质量收束方法的结果状态。状态值只是收束出口，不是材料本体。

材料质量收束至少声明以下输入特征族：

```text
来源与可回查：
    来源外设句柄、观察帧序号、时间戳、材料页句柄、原始材料句柄、句柄有效状态。

时间与新鲜度：
    帧年龄、最大允许观察年龄、帧序号连续性、丢帧计数、时钟偏差、场景体素版本差、坐标系版本差。

深度有效性：
    总像素数量、有效 / 无效深度像素数量、缺失比例Q10000、噪声评分Q10000、孔洞面积比例Q10000、有效覆盖率Q10000。

彩色 / 红外质量：
    曝光评分、过曝 / 欠曝比例、运动模糊评分、颜色噪声评分、红外纹理质量评分、彩色深度对齐残差。

坐标基准：
    内参 / 外参版本、D455 到场景变换版本、变换残差、姿态置信度、空间点有效比例。

ROI / 掩码 / 候选完整性：
    ROI 有效覆盖率、候选像素数量、候选有效深度点数量、争议像素数量、边界闭合评分、轮廓连续性评分。

任务 / 需求阈值：
    当前需求质量阈值、目标特征类型、目标需要深度 / 颜色证据状态、允许降级策略、允许输出缺口策略。

跨帧稳定性与先验冲突：
    连续有效帧数、复现率、中心 / 尺寸漂移评分、候选不唯一状态、自由空间冲突数量、遮挡解释状态。
```

材料质量状态推荐值只表示收束结果：

```text
未评估：
    质量判定尚未运行，或必要一阶特征不足。

可用：
    当前目标所需材料、坐标基准、时效、ROI / 候选覆盖和质量评分均达到当前任务阈值。

低质量：
    材料可回查，但评分、覆盖、噪声、曝光、模糊、对齐或候选争议不足以支撑正式确认，可作为弱证据或缺口来源。

不可用：
    原始材料句柄失效，关键材料缺失，坐标基准无法建立，帧过期到不可复验，或材料与目标错域。

部分可用：
    全帧或全目标不能完整使用，但某个 ROI、候选或特征族仍可用于局部体素、候选发现、遮挡解释或信息缺口输出。

需复验：
    当前材料存在冲突、过期、遮挡、候选争议或跨帧不稳定，单次材料不足以裁决。
```

每个状态值都必须能回查依赖特征族、收束方法、写入方、读取方、失败分流和证据引用。不得为每个枚举值新建独立结构；同一组质量判定特征族经不同判定路径收束到不同状态。

## 9. 观察触发来源

观察可以由多种来源触发。特征值缺口补完只是观察执行中可能派生补完子需求的一种来源，不限制观察任务自身继续执行。

```text
开放观察：
    目标存在可以为空，目标特征可以为空，只给场景、区域、原始材料范围或观察窗口。
    用于初始建账、新存在发现、场景材料承接和自然观察。

定向观察：
    目标存在已知，目标特征类型已知，目标是补全该特征类型的值。
    用于已确认存在的特征值缺口补完、识别比较特征补充、扫描当前值补证或跟踪观察补证。
```

## 10. 特征值缺口补完闭环

```text
存在 E 已确认具备特征类型 FT
-> E.FT 当前值不完整 / 不可比较 / 当前无效
-> 二次特征或状态比较记录 E.FT 存在补完缺口
-> 缺口被上级任务、扫描、识别、跟踪、安全 / 服务需要或认知加深策略选中
-> 生成补完需求
-> 任务筹办选择观察或其他补完方法
-> 观察读取外设材料并补充 E.FT 的事实材料
-> E.FT 的一阶值或当前状态按正式提交入口更新
-> 二次判断更新，需求按当前值与目标值重新结算
```

这里的目标是补全已确认特征类型的值，不是让观察自动追求所有可能特征。若 FT 尚未确认属于 E，不能直接生成 E.FT 补完需求，只能作为观察发现或识别 / 归属缺口继续分流。

## 11. 父观察任务收束时的子需求治理

观察任务执行中发现特征值缺口并派生补完子需求后，观察任务自身仍可继续执行。该补完子需求默认先视为来源于父观察任务的非必须子需求，除非父观察任务目标定义、当前绑定方法条件或更高来源把它推导为必须子需求或可选路径子需求。

完整的父子需求关系角色、父任务收束和活动承接规则，统一见：


## 12. 与其他方法边界

```text
与扫描：
    观察补充材料和特征事实，扫描维护已归属存在的当前状态。

与识别：
    观察可生成对应材料和特征补充材料，识别负责限定范围内已有存在的对应关联判断。

与跟踪：
    观察可使用连续帧稳定材料，跟踪只面向确定目标集合持续复现。
```

## 13. 缺口分流

```text
材料质量收束所需一阶特征不足 -> 材料质量缺口
材料质量收束结果为不可用 / 低质量 / 需复验 -> 补观察或外设等待项来源
可观测单位未闭合 -> 补观察或局部细分需求来源
候选不唯一 -> 识别需求来源
已有目标需要连续复现 -> 跟踪需求来源
已归属存在需要当前状态维护 -> 扫描需求来源
已确认特征类型的值不完整 / 不可比较 / 当前无效 -> 特征值补完需求来源
```
