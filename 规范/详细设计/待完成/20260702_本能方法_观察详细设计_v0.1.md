## 1. 方法定位

观察的目标是把外设材料组织成可承接的观察事实、存在候选、可观测单位对应和特征补充材料。

观察看起来会使用连续帧、稳定性、掩码、ROI、点集和候选归属，因此局部上像跟踪；但观察不是跟踪。观察的目标不是持续盯住确定对象，而是让：

```text
外设材料 -> 观察材料集 -> 可观测单位 / 存在候选 / 特征补充材料 / 缺口
```

形成可被自我后续方法、任务链和提交入口承接的结构化材料。

## 2. 输入

```text
观察范围或目标观察约束
逐簇识别报告
可回查原始材料句柄
观察像素簇集合
ROI / 掩码 / 点集 / 局部图
材料质量状态
当前需求的质量阈值或最大允许观察年龄
```

## 3. 输出

```text
观察材料集可用状态
可观测单位对应摘要
存在候选集合
观察像素簇事实
特征补充材料
不可观测区域 / 低质量区域 / 未解释区域缺口
输出结果场景或运行存在中的过程证据
```

## 4. 允许写入

```text
观察事实承接所需的场景 / 存在 / 特征 / 特征值结构
观察像素簇、存在候选、可观测单位对应状态
质量状态、材料可回查状态、不可观测原因
结构化缺口和补观察需求来源
```

## 5. 禁止写入

```text
不得把原始帧直接写成世界树事实。
不得把外设候选编号写成稳定世界存在 ID。
不得仅凭单帧材料宣称稳定存在确认。
不得替代识别宣称材料与已有存在唯一对应。
不得替代扫描维护所有已归属存在当前状态。
不得替代跟踪宣称确定目标连续复现。
```

## 6. 消费的数据层

主要消费：

```text
L0 原始材料句柄 / 短期材料页
L1 逐簇识别报告
```

不得直接消费自我不可见高频原始流。

## 7. 共享底层能力

观察可以使用底层关联判断能力：

```text
像素归属
簇归属
材料质量判断
候选过滤
范围内对应计算
```

这些能力不是直接调用识别本能方法。若观察过程中需要正式判断当前材料对应哪个已有存在，应输出结构化缺口或候选材料，由需求 / 任务 / 方法链决定是否选择识别。

## 8. 与其他方法边界

```text
与扫描：
    观察补充材料和候选，扫描维护已归属存在的当前状态。

与识别：
    观察可生成候选和对应材料，识别负责限定范围内已有存在的对应关联判断。

与跟踪：
    观察可使用连续帧稳定材料，跟踪只面向确定目标集合持续复现。
```

## 9. 缺口分流

```text
材料不可回查 -> 材料质量缺口
可观测单位未闭合 -> 补观察或局部细分需求来源
候选不唯一 -> 识别需求来源
已有目标需要连续复现 -> 跟踪需求来源
已归属存在需要当前状态维护 -> 扫描需求来源
```
