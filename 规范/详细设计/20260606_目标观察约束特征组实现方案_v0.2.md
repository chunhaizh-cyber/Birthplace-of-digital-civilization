
兼容说明：

正式定义：

```text
目标观察约束特征组 =
    自我提供给外设的单目标、单特征、单当前值、带观察边界和质量阈值的约束集合。
```

它允许外设知道：

```text

什么材料可以舍弃；

```

它不允许外设直接得出：

```text

目标同一性已确认；
目标特征变化已成立；
需求已经满足；
安全 / 服务值可以结算。
```

## 3. generation 与 TTL

generation 拆成三类：

```text
约束generation：
    目标观察约束特征组自身版本。
    约束重新写入、ROI / mask / AABB 更新、TTL 更新、质量阈值更新时变化。
    用于等待项和队列项匹配，防止旧约束误匹配新任务。

目标特征generation：
    自我正式入账的该目标特征当前值版本。
    目标特征当前值正式入账变化时变化。
    用于判断外设使用的当前值是否仍是最新基准。

来源材料generation：
    ROI / 掩码 / 点集 / 局部图等来源观察材料版本。
    来源报告、来源帧、掩码、点集材料更新或失效时变化。
    用于判断约束中的材料句柄是否仍可回查。
```

TTL 拆成四类：

```text
约束TTL：
    目标观察约束特征组还能不能被使用。

最大允许报告年龄：
    外设报告还能不能满足当前等待项。

最大允许观测年龄：
    跟踪目标最近一次有效观测距今多长后应视为丢失或待重捕获。

材料页TTL：
    d455:// 材料句柄还能不能回查。
```

判断顺序：

```text
1. 当前时间 - 约束写入时间 > 约束TTL
       -> 约束已过期。

2. 当前时间 - 报告时间 > 最大允许报告年龄
       -> 报告过期。

3. 当前时间 - 目标最近观测时间 > 最大允许观测年龄
       -> 目标可能丢失或需要重捕获。

4. 材料页TTL到期
       -> 材料不可回查。
```

## 5. 统一可用性判断

```cpp
export struct 结构_目标观察约束可用性判定 {
    枚举_目标观察约束可用性 状态 = 枚举_目标观察约束可用性::未定义;
    bool 可强匹配 = false;
    bool 可降级匹配 = false;
    std::string 原因{};
};

export 结构_目标观察约束可用性判定 判断目标观察约束可用性(
    const 结构_目标观察约束特征组& 约束,
    std::int64_t 当前时间毫秒,
    const 结构_外设观察等待项* 等待项);
```

所有位置统一调用：

```text
等待项创建；
D455 前置满足；
队列项匹配；
观察材料质量判断；
清理器；
撤销或替代判断。
```

判断规则：

```text
缺目标存在ID -> 缺目标存在；
缺目标特征类型ID -> 缺目标特征；
目标特征当前值类型未定义 -> 缺当前值；
句柄型当前值缺句柄 -> 缺当前值；
TTL 到期 -> 已过期；
约束generation 与等待项不一致 -> generation失配；
目标特征generation 与等待项不一致 -> generation失配；
来源材料generation 与等待项不一致 -> 可降级使用或 generation失配；
ROI / 掩码 / 点集 / AABB 全部缺失 -> 缺定位材料；
材料句柄不可回查 -> 材料不可回查；
状态为已撤销 -> 已撤销。
```

强匹配成立：

```text
目标存在ID 明确；
目标特征类型ID 明确；
当前值或句柄明确；
约束generation 匹配；
目标特征generation 匹配；
至少一种定位材料可回查；
未过期；
未撤销。
```

降级匹配成立：

```text
等待项允许降级；
目标存在或目标区域明确；
目标特征类型ID 明确；
约束未过期；
至少有 ROI / AABB / 目标区域之一；
但缺 mask / 点集 / 来源材料generation 或部分材料不可回查。
```

降级匹配只允许：

```text
建立首帧基准；
待复验；
目标重捕获线索；
材料质量缺口。
```

降级匹配不允许：

```text
生成扫描变化动态；
生成稳定跟踪动态；
确认同一存在；
关闭需求。
```

## 10. D455 使用规则

扫描：

```text
读取等待项；
读取目标观察约束；
调用 判断目标观察约束可用性；
强匹配：按 ROI / mask / 点集 / AABB 比较目标特征；
降级匹配：只建立基准或待复验；
输出目标特征当前观察值、误差值、generation、使用状态。
```

扫描报告必须区分：

```text
首次基准：
    只建立当前状态值、当前特征值和当前状态基准，不生成发现事实或变化动态。

无变化：
    更新下一轮基准，不生成变化动态。

值域内变化：
    生成变化动态候选。

超值域：
    生成值域冲突 / 待复验，不生成正常变化动态。

目标约束过期 / generation失配：
    生成缺口，不生成新鲜扫描报告。
```

跟踪：

```text
读取等待项；
读取目标观察约束；
调用 判断目标观察约束可用性；
用目标种子、ROI / mask / 点集 / AABB 找目标；
持续读取目标特征当前观察值；
输出当前值、误差值、预测误差、区间ID、非法跳变次数、丢失 / 遮挡 / 重捕获状态。
```

跟踪报告必须区分：

```text
稳定：
    当前值在值域内；
    当前值在预测区间内；
    预测误差小于阈值；
    连续命中帧数达标。

丢失：
    目标最近观测年龄超限；
    或重捕获失败。

遮挡：
    掩码 / 轮廓 / 深度显示被遮挡。

区间迁移：
    目标动态合法进入新细分区间。

非法跳变：
    当前值超出允许区间或非法跨区间迁移。

值域冲突：
    当前值超出目标特征值域。
```

## 11. 观察材料质量判定

```cpp
export struct 结构_观察材料质量判定 {
    枚举_观察材料等级 等级 = 枚举_观察材料等级::未判定;
    bool 可进入验证方法 = false;
    bool 可进入识别方法 = false;
    bool 可生成扫描变化候选 = false;
    bool 可生成跟踪动态候选 = false;
    bool 可进入提交入口组织 = false;
    std::string 依据{};
    std::string 需补观察原因{};
    std::string 建议外设动作{};
};

export 结构_观察材料质量判定 判断优质观察材料(
    const 结构_外设观察报告队列项& 队列项,
    const 结构_外设观察等待项* 等待项,
    const 结构_目标观察约束特征组* 目标约束);
```

判断重点：

```text
1. 不合格：
       不能进入自我方法；
       只能入缺口事实或被清理。

2. 可用：
       可以进入 6127 / 6145 做验证、识别、待复验；
       不能直接进入最终提交入口；
       不能生成扫描变化动态或稳定跟踪动态确认。

3. 优质：
       可以进入 6146 / 6147 生成可提交的变化 / 跟踪动态候选；
       仍需提交入口裁决。
```

方法准入：

```text
6127:
    接受 可用 / 优质 材料。
    不合格只生成缺口事实。

6145:
    接受 可用 / 优质 材料。
    可用材料输出候选同一 / 待复验；
    优质材料可输出同一 / 非同一 / 冲突。

6146:
    值域内变化动态必须要求优质材料；
    可用材料只能输出待复验 / 值域疑似变化。

6147:
    稳定跟踪动态必须要求优质材料；
    可用材料只能输出跟踪降级 / 待复验。
```

目标区域优质：

```text
全帧深度或空间质量不足，不必然否定目标 ROI / mask 内材料可用；
扫描 / 跟踪 / 指定目标复验应优先检查目标区域质量；
颜色、轮廓、二维回查类需求可以在深度 / 空间不足时降级。
```

## 12. 提交入口边界

提交入口不接受以下对象作为事实主体：

```text
报告；
包；
队列项；
材料页；
目标观察约束特征组；
目标观察约束缓冲区记录。
```

提交主体必须是：

```text
存在；
特征；
二次特征；
状态动态；
以及来源动作动态引用。
```

提交成功后：

```text
只回写本次提交涉及的单个目标特征当前值；
不回写存在全量；
不回写所有可见特征；
不回写报告本身。
```

## 16. 验收矩阵

| 切片 | 证据 | 通过标准 |
| --- | --- | --- |
| P0b | 文档和日志口径 | 命名、generation、TTL、材料等级、提交主体规则冻结 |
| P1 | 日志 + 队列状态摘要 | 目标约束可写、可读、可判断、可撤销、可清理 |
| P2 | 任务管理日志 | 扫描 / 跟踪等待项带约束ID、目标特征generation 和强 / 降级匹配状态 |
| P3 | 当前本能ID / 动作动态 / 缓冲区摘要 | 只写单特征约束，不写世界真值 |
| P4 | D455 日志 | 外设按约束读取 ROI / mask / 当前值 / generation；过期拒绝或降级 |
| P5 | 质量判定日志 | 不合格 / 可用 / 优质分级和方法准入布尔门可追溯 |
| P6 | 队列状态日志 | 三类视图不污染；已消费项不重复命中；消费不等于需求满足 |
| P7 | 方法动作动态 + 提交入口日志 | 正式入账对象不是报告 / 包 / 队列项 / 材料页 / 目标观察约束 |
| P8 | 构建 + 真实 D455 日志 | 目标约束 -> 外设约束观察 -> 队列视图 -> 方法分级消费 -> 提交入口 -> 单特征回写闭环，或停在明确真实堵点 |

## 17. 最终链路

```text
正式入账的自我存在.单个目标特征当前值
    + 该特征generation
    + ROI / 掩码 / 点集 / AABB / 局部图
    + 来源材料generation
        -> 自我_提交目标观察约束特征组
        -> 目标观察约束缓冲区

任务管理创建扫描 / 跟踪等待项
    + 目标观察约束ID
    + 约束generation
    + 目标特征generation
        -> D455 读取并判断约束可用性

D455 约束采集 / 比较 / 跟踪
    -> 报告队列项携带:
        目标观察约束ID
        目标特征当前观察值
        误差值
        generation
        材料等级

任务管理消费队列视图
    -> 判断优质观察材料
    -> 不合格: 清理或缺口
    -> 可用: 复验 / 候选
    -> 优质: 进入对应自我方法组织结果

自我方法输出:
    存在 / 特征 / 二次特征 / 状态动态

提交入口裁决通过:
    -> 正式入账
    -> 更新单个目标特征当前值
    -> 生成下一轮目标观察约束特征组
```

一句话：

```text
v0.2 把自我给外设的观察基准变成可过期、可匹配、可降级、可撤销、可追溯的目标观察约束；它永远只是外设观察约束，不能滑成世界真值。
```
