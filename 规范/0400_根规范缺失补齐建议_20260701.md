# 0400 根规范缺失补齐建议

编号：0400
日期：20260701
状态：正式补齐记录

## 1. 结论

按当前代码扫描，当前正式 `规范/规范目录.md` 已为所有自定义主信息数据类型建立独立根规范入口。

旧规范已迁入 `规范/旧规范/`，当前主信息根规范以 `规范/` 根目录文件和 `规范/规范目录.md` 为准。

## 2. 补齐完成路径

1. 第一阶段：生成主信息根规范整理包。
2. 第二阶段：确认动态、状态、外设材料和因果置信分边界。
3. 第三阶段：将正式根规范迁入 `规范/` 根目录。
4. 第四阶段：将旧规范迁入 `规范/旧规范/`，不再作为当前权威。
5. 第五阶段：修订 `规范/规范目录.md` 和项目入口引用。

## 3. 优先级建议

| 优先级 | 类型 | 原因 |
| --- | --- | --- |
| P0 | 存在、特征、特征值、状态、动态、因果、二次特征 | 直接承载世界树事实和因果账本 |
| P1 | 需求、任务、方法 | 直接承载内部循环和执行链 |
| P2 | 语素入口、词、语言记录、文章、段落、自然句、子句、指代 | 主要承载入口、解析和引用，不应承载业务事实 |
| P3 | 因果模板别名型规范 | 需要与因果主信息根规范保持一致 |

## 4. 禁止回退口径

1. 不得用旧规范目录中的历史表述覆盖当前根目录正式规范。
2. 不得同时保留 `词性主信息类`、`实例特征主信息类` 或 `抽象存在主信息类` 作为当前规范口径。
3. 不得把“动态模板根”恢复为独立根名或并列结构。
