## 1. 定案

双目相机外设线程或外设使用方法的主要观察输出单位不应是：

```text
整帧像素全部直接变成自我关心的对象
```

也不应是：

```text
相机发现世界存在
```

更合理的链路是：

```text
观察帧
    -> 观察像素簇集合
        -> 每个观察像素簇携带一组稳定特征值
            -> 自我承接观察像素簇
                -> 自我生成存在候选
                    -> 自我验证候选
                        -> 已确认观察存在
```

定案句：

```text
外设给观察簇；
自我把观察簇解释成存在候选；
候选经过验证后才可以成为已确认观察存在。
```

观察像素簇不是稳定世界存在。它是当前观察材料集内一组像素事实和稳定特征值构成的证据集合。

自我认知中不存在“背景”这个存在类别。视觉工程里的背景只能作为工程低关注区域描述，在自我体系中必须转写为：

```text
已归属静止存在；
静止环境存在；
暂不需要高频处理的稳定存在；
低动态存在。
```

因此不得输出：

```text
归属目标 == 背景
背景存在
背景区域不识别
```

必须输出为：

```text
外设观察存在.自我归属状态 == 已归属
归属目标 == 某静止存在 / 某环境存在
```

或在证据不足时输出为：

```text
外设观察存在.自我归属状态 == 待复验
外设观察存在.静止存在候选状态 == 候选
```

## 2. 层级定位

### 2.1 外设观察帧 / 观察材料集

帧是外设侧概念，不是自我层认知单位。外设观察帧是本轮观察材料的来源锚点；自我层承接的是观察材料集、观察范围和可观测单位。外设观察帧记录：

```text
来源外设
来源外设帧号
帧宽度
帧高度
观察生成时间
像素特征索引引用
观察像素簇集合引用
低质量区域集合引用
未归簇区域集合引用
失败原因摘要
```

外设观察帧 / 观察材料集仍必须保证像素可寻址、可回查、无遗漏、无重复；但这不要求每次都把所有像素物化成自我直接关心的对象。

### 2.2 观察像素簇

观察像素簇是当前观察材料集内的一组像素集合及其稳定特征摘要。它可以由颜色、深度、空间坐标、边界、连续性或稳定性等一致性生成。

更完整地说：

```text
观察像素簇 =
    像素集合
  + 掩码
  + 平面轮廓
  + 彩色轮廓局部图
  + 深度轮廓局部图
  + 颜色特征
  + 深度特征
  + 空间特征
  + 稳定性特征
```

观察像素簇是：

```text
当前观察材料集的可观测单位
存在候选的证据集合
可被自我继续验证的观察事实包
```

不是：

```text
稳定世界存在
语义对象
跨帧身份
已确认观察存在
基础风险判断结论
```

### 2.2.1 D455 观察像素簇稳定层级

D455 原始单帧簇数量、轮廓、新建、匹配和丢失都可能跳动。因此“观察像素簇”在外设侧必须继续分层：

```text
原始簇：
    单帧分割结果，不能提交为观察存在。
    用途：L0 原始材料缓存、诊断、回查、跨帧关联输入。

候选簇：
    已通过单帧质量门，但跨帧未稳定。
    用途：进入外设观察轨迹关联，不进入自我正式承接。

稳定外设观察存在：
    跨帧关联稳定，特征值域初步稳定。
    用途：可作为观察 / 识别 / 扫描 / 跟踪的材料候选。

可提交观察材料：
    稳定外设观察存在 + 关键特征达标 + 来源可回查 + generation / TTL 有效。
    用途：任务管理可匹配等待项，自我侧可进入正式观察承接或提交入口候选。
```

稳定外设观察存在不等于：

```text
自我已确认观察存在
世界存在
世界存在永久值域
需求满足证据
安全 / 服务值结算证据
```

它只表示：

```text
可提交给观察 / 识别的稳定外设观察存在。
```

外设稳定观察值域必须标记为观察值域：

```text
外设观察存在.平面轮廓值域
外设观察存在.中心坐标值域
外设观察存在.面积值域
外设观察存在.深度摘要值域
```

识别成功并入自我场景后，才可能成为自我观察存在或世界存在的特征值域。

### 2.3 存在候选

存在候选是自我对观察像素簇的一层解释包装。存在候选必须引用来源观察像素簇，不应复制所有像素事实。

```text
存在候选 {
    来源观察帧
    来源观察像素簇
    候选ID

    候选中心位置
    候选范围坐标
    候选平面轮廓
    候选颜色摘要
    候选深度摘要
    候选空间坐标摘要
    候选质量状态
    候选稳定状态

    确认状态:
        未确认
        待验证
        已确认观察存在
        已否定
        待拆分
        待合并
}
```

### 2.4 平面轮廓特征类型

当前阶段新增并采用的默认主特征类型为：

```text
特征类型：
    平面轮廓

宿主：
    外设观察存在 / 自我观察存在 / 世界存在

特征值类型：
    VecIU64 / VECIU64
```

存储规则：

```text
底层值：
    VecIU64

解释规则：
    按 `平面轮廓` 特征类型解释为 VecI64 二维坐标链。
    每 2 个 I64 表示一个二维坐标。
    第一个二维坐标表示轮廓中心点。
    后续二维坐标表示轮廓边界点。
    边界点按轮廓遍历顺序存储。
```

逻辑格式：

```text
[
    中心X, 中心Y,
    点1X, 点1Y,
    点2X, 点2Y,
    点3X, 点3Y,
    ...
]
```

编码规则：

```text
VecI64 坐标序列
    -> I64 到 U64 的 ZigZag 编码
        -> VecIU64
            -> 特征值主信息类::值
```

读取规则：

```text
读取 `外设观察存在.平面轮廓`、`自我观察存在.平面轮廓` 或 `世界存在.平面轮廓` 时，必须先由特征类型确认这是 `平面轮廓`，再把底层 VecIU64 解码为 VecI64 二维坐标链。
不得仅根据特征值主信息类判断这是坐标、颜色、掩码或其它向量值。
```

值域校验：

```text
解码后的 VecI64 长度必须是 2 的倍数。
解码后的 VecI64 长度 >= 2。
```

坐标为当前观察平面坐标。坐标系、ROI、来源帧和 generation 仍应记录在来源材料或伴随特征中，不写入 `特征值主信息类`。

`VecIU64` 本体不直接进入 I64 区间比较。需要识别、扫描或跟踪比较时，必须先由规则或方法生成 I64 二次特征，例如中心偏差值、面积差异值、周长差异值、长宽比差异值、掩码重合率、轮廓点平均误差、轮廓点最大误差和综合轮廓匹配评分。

### 2.5 已确认观察存在

已确认观察存在只能由自我验证链生成。仅有观察像素簇或存在候选时，不得宣称已经确认稳定世界对象。

## 3. 外设观察报告

外设自主观察线程或双目相机使用类方法可以输出：

```text
外设观察报告 {
    来源观察帧
    来源外设
    帧宽度
    帧高度
    深度帧号
    彩色帧号
    外设配置摘要

    像素特征索引引用
    观察像素簇集合
    低质量区域集合
    未归簇区域集合
    失败原因摘要
}
```

其中：

```text
观察像素簇集合
```

是后续生成存在候选的主要输入。

外设内部采集、校正、滤波、补全、分割、跟踪等仍属于外设私有领域。自我只能通过外设控制、检查、使用入口接收可落账的观察报告或当前观察特征帧结果。

### 3.1 三种外显观察运行模式与报告

同一个双目相机外设线程可以按任务管理工作线程提交的等待项输出报告，但对自我可见的高层观察运行模式只收敛为三种：

```text
陌生环境逐簇识别模式 -> 逐簇识别报告
已识别场景扫描变化模式 -> 扫描变化报告
目标跟踪观察模式 -> 跟踪报告
```

其它能力不作为自我可见的外设模式暴露。质量诊断、ROI 观察、补观察、稳定特征取值、重捕获、局部细分、变化监测和配置学习分别归入外设内部策略、三种报告字段或自我后续方法。

三类能力正式定义：

```text
识别：
    处理未识别区域、候选区域和冲突区域。
    让有效观察特征值稳定对应到存在；未能稳定对应的只能记录为识别缺口、冲突缺口、证据不足或需补观察，不作为最终归属。

扫描：
    处理已经稳定对应到存在的特征值集合。
    第一次扫描只生成发现存在或发现特征事实；有上一轮 / 历史可比观察材料集后，才生成存在状态变化和变化动态。

跟踪：
    处理指定稳定存在或目标种子。
    对目标存在进行持续观察，主动忽略非目标存在。
    第一版目标必须是已确认存在；没有目标种子、目标存在 ID、目标特征和持续观察窗口时不得启动跟踪。
```

三者不是整场景串行阶段。同一观察范围可以按可观测单位归属状态并行分工：

```text
稳定对应存在 -> 扫描
未稳定对应特征值 -> 识别
候选 / 冲突对应 -> 识别或自我侧验证裁决
指定稳定存在 -> 跟踪
无效区域 -> 记录无效原因或派生补观察需求
静止 / 环境区域 -> 归入已归属静止存在、环境存在或静止存在候选，不当作非存在
```

识别闭合标准不是“所有像素都变成已确认存在”，而是：

```text
当前观察范围内所有有效可观测单位都已经稳定对应到存在。
```

当前观察范围内像素 / 点云 / ROI 等可观测单位可归入这些对应状态：

```text
已识别区域：
    已归属到已确认存在、已归属静止存在或环境存在。

未稳定对应特征：
    有有效观察材料，但尚未稳定对应到存在。

候选区域：
    已生成存在候选，但尚未确认 / 合并 / 冲突裁决。

冲突区域：
    多个存在或候选争用同一区域，归属不唯一。

无效区域：
    深度无效、材料缺失、不可解引用或质量不足。

静止存在 / 环境存在：
    已作为存在承接，不当作“未知区域”闭合，也不得当作“背景”归属。
```

有效观察材料的归属结果可以是：

```text
已确认存在；
新存在候选；
候选存在；
冲突对应缺口；
静止存在 / 环境存在；
噪声 / 无效材料。
```

其中 `候选存在`、`冲突对应缺口`、`证据不足` 都只是过程状态；最终闭合必须能回到某个存在或无效材料排除事实，不允许把 `未知区域` 作为最终归属类型。

这里的“识别”不是语义识别，不是稳定世界存在确认，也不是目标可见性闭合。

识别报告面向：

```text
当前场景里有什么？
这些像素 / 点集 / ROI / 掩码 / 簇分别属于谁？
哪些能确认成存在？
哪些只是候选？
哪些冲突？
哪些尚未稳定对应？
哪些已归属为静止存在或环境存在？
```

识别包 / 逐簇识别报告应包含：

```text
报告ID；
来源外设帧ID；
有效观察区域；
区域范围；
未识别区域；
候选区域；
像素归属账本；
候选簇列表；
ROI / 掩码 / 点集 / 深度切片句柄；
新存在候选；
已有存在匹配候选；
未稳定对应特征；
冲突区域；
静止存在候选 / 环境存在候选 / 无效材料；
证据不足原因。
```

扫描报告面向：

```text
这是第一次发现该稳定对应存在，还是已有历史后的变化？
如果有历史：位置变了吗？
如果有历史：范围变了吗？
如果有历史：深度变了吗？
如果有历史：距离变了吗？
如果有历史：遮挡状态变了吗？
如果有历史：像素归属变了吗？
是否出现未解释变化？
是否有新的未稳定对应特征需要回到识别？
```

扫描必须依赖：

```text
至少一个稳定对应存在；
当前观察材料集。
```

第一次扫描不要求历史可比观察材料集，只能生成发现存在或发现特征事实。后续扫描若要生成变化动态，才必须读取上一轮 / 历史可比观察材料集。

扫描前提不是全场景特征值存在对应闭合。只要有至少一个稳定对应存在，就可以对该存在扫描；扫描结果的范围只能落在该稳定对应存在及其当前观察材料集内。

扫描包 / 扫描变化报告应包含：

```text
区域基准ID / 场景基准ID；
扫描范围；
来源外设帧ID；
已知存在列表；
每个已知存在的当前特征值；
首次扫描发现存在 / 发现特征事实候选；
每个已知存在的特征值变化；
变化方向；
变化时间；
未解释变化区域；
需重识别区域；
扫描覆盖率；
材料质量；
冲突 / 证据不足原因。
```

扫描发现无法归属的新区域时，只能输出：

```text
未稳定对应特征 / 需重识别区域。
```

不得由扫描报告直接创建新存在。

跟踪观察面向：

```text
目标还在吗？
目标在哪里？
目标是否靠近 / 远离？
目标是否被遮挡？
目标是否丢失？
目标的目标特征是否变化？
```

跟踪必须有：

```text
目标种子；
目标存在ID；
目标特征；
持续观察窗口。
```

第一版跟踪目标只允许已确认存在。候选目标跟踪只能作为后续扩展，不得把候选跟踪稳定直接当作已确认观察存在。

跟踪包 / 跟踪报告应包含：

```text
目标存在ID；
目标种子；
当前外设帧ID；
上一外设帧ID；
目标当前特征值；
目标变化量；
目标稳定性；
靠近 / 远离趋势；
遮挡状态；
丢失状态；
跟踪置信度；
冲突 / 证据不足原因。
```

跟踪报告可以服务指定存在或存在候选的持续验证，但不得直接写成已确认观察存在，也不得证明全场存在集合明确。

```text
外设内部跟踪ID != 自我世界存在ID
```

三者关系：

```text
识别建立特征值到存在的稳定对应事实；
扫描在稳定对应存在上生成首次发现存在 / 发现特征事实或后续变化动态；
跟踪盯指定目标。
```

同一外设观察周期可以同时输出识别包、扫描包和跟踪包，但每个包必须携带范围或目标，不能互相替代。

防混用规则：

```text
识别不能被当成扫描。
    只有识别结果时，不得宣称已知存在特征值变化明确；若进入第一次扫描，只能生成发现存在或发现特征事实。

扫描不能被当成识别。
    扫描发现新区域，只能输出未稳定对应特征 / 需重识别区域，不能直接确认新存在。

首次扫描不能被当成变化。
    第一次扫描稳定对应存在时，只能生成发现存在或发现特征事实；只有有上一外设帧 / 上一轮可比观察材料集后，才允许生成变化动态。

跟踪不能被当成全场扫描。
    跟踪指定目标时，非目标存在被主动忽略；只能证明指定目标的状态 / 变化明确。

局部明确不能被当成全场明确。
    稳定对应存在扫描成功，只能支撑该存在的发现或变化事实；不能支撑全场景特征值明确、全场景存在集合明确或全场风险状态明确。
```

其它能力与观察像素簇的关系：

```text
定向观察：
    作为逐簇识别或目标跟踪等待项的目标区域 / ROI 参数。

补观察：
    任务筹办根据质量缺口派生新的逐簇识别、扫描变化或目标跟踪等待项；旧帧质量不足是事实，不修旧帧。

稳定特征取值：
    是跟踪报告的核心字段，不另建报告类型。

重捕获：
    是跟踪报告里的丢失处理、重捕获候选集合和失败原因。

局部细分：
    由自我方法使用彩色轮廓局部图、深度轮廓局部图和掩码生成子轮廓、子簇、局部点集和局部三维范围。

变化监测：
    是扫描变化模式的核心输出，也可由自我比较多次报告后生成新增、消失或变化区域候选。

质量诊断：
    是三种报告里的低质量区域、不可观测区域、质量摘要和失败原因。

配置学习：
    属于外设内部学习模块，只在报告中暴露配置摘要、推荐配置和适用性。
```

因此，相机报告只能直接满足观察材料层需求；存在候选、可观测单位对应摘要、变化候选、局部细分和已确认观察存在，都必须由自我方法在承接报告后生成。

## 4. 观察像素簇内容

观察像素簇建议至少包含：

```text
观察像素簇 {
    来源观察帧
    来源外设
    外设内部簇ID

    像素集合引用 / 掩码引用 / 像素索引集合
    帧内像素数量
    像素覆盖边界框
    图像中心点
    平面轮廓
    平面轮廓状态
    平面轮廓稳定状态
    平面轮廓基准状态
    轮廓引用 / 轮廓摘要
    像素集合掩码句柄
    轮廓掩码句柄
    彩色轮廓掩码句柄
    深度轮廓掩码句柄
    深度有效性掩码句柄
    空间坐标有效性掩码句柄
    彩色轮廓截图句柄
    深度轮廓截图句柄
    截图边界框
    截图缩放比例，可选
    彩色轮廓掩码句柄，可选
    深度轮廓掩码句柄，可选

    颜色特征:
        平均颜色
        主颜色
        颜色方差
        颜色稳定性

    深度特征:
        深度有效率
        深度最小值
        深度最大值
        深度中位数
        深度方差
        深度稳定性

    空间特征:
        空间坐标有效率
        空间中心坐标
        空间范围AABB
        空间连续性评分
        空间坐标稳定性

    质量特征:
        簇质量可用状态
        稳定复现状态
        连续观测次数
        失败原因集合
        使用配置摘要
}
```

取得不到的特征不得伪造。应显式写成特征状态：

```text
观察像素簇.深度特征状态 等于 不足
观察像素簇.空间坐标特征状态 等于 不足
观察像素簇.平面轮廓状态 等于 已生成
观察像素簇.平面轮廓稳定状态 等于 稳定 / 不稳定 / 证据不足
观察像素簇.颜色特征状态 等于 可用
```

观察是唯一可以合法写新的平面轮廓一阶观察特征值的路径。识别、扫描和跟踪只能读取当前平面轮廓、基准平面轮廓或候选平面轮廓并生成二次特征、状态动态或缺口；不得直接把比较得到的新轮廓写回为世界存在的一阶平面轮廓。

### 4.1 局部图像证据

观察像素簇除了数值摘要特征外，还应允许挂接局部图像证据：

```text
彩色轮廓截图
深度轮廓截图
```

这两类截图是观察像素簇的附属观察证据，不是观察像素簇的权威真值本身，也不能替代存在候选确认逻辑。

观察像素簇的权威事实仍是：

```text
像素集合引用
簇轮廓
边界框
像素数量
颜色统计
深度统计
空间坐标统计
质量状态
稳定状态
```

彩色轮廓截图 / 深度轮廓截图的作用是：

```text
便于控制面板显示；
便于人工复核；
便于后续递归细分；
便于跨帧比较；
便于外设内部学习模块保存样本证据；
便于复查某次稳定性判断所依赖的局部观察材料。
```

### 4.2 截图定义

彩色轮廓截图：

```text
从当前观察帧的彩图中，
按该观察像素簇的边界框或轮廓区域裁剪出的局部图像。
```

深度轮廓截图：

```text
从当前观察帧的深度图中，
按该观察像素簇的边界框或轮廓区域裁剪出的局部深度图像。
```

第一版优先支持：

```text
轮廓包围框截图
```

后续需要更精细时，再增加：

```text
轮廓掩码截图
```

### 4.3 截图挂接字段

彩色轮廓截图和深度轮廓截图不得作为普通数值特征直接塞入 I64。它们应以句柄、缓冲引用或场景引用的方式挂接到观察像素簇：

```text
观察像素簇.彩色轮廓截图句柄
观察像素簇.深度轮廓截图句柄
观察像素簇.截图边界框
观察像素簇.来源观察帧
观察像素簇.截图生成时间
观察像素簇.截图缩放比例，可选
观察像素簇.彩色轮廓掩码句柄，可选
观察像素簇.深度轮廓掩码句柄，可选
```

最低必需字段：

```text
彩色轮廓截图句柄
深度轮廓截图句柄
截图边界框
来源观察帧
```

这些字段用于回答：

```text
截图来自哪一帧；
裁剪的是哪一块；
截图是否与当前簇的像素集合一致；
截图能否用于后续细分、复核、比较或学习。
```

### 4.4 截图与存在确认边界

有了彩色轮廓截图或深度轮廓截图，不能直接推出：

```text
观察像素簇.存在候选生成状态 等于 已生成
存在候选.确认状态 等于 已确认
自我所在场景.已确认观察存在集合状态 等于 已更新
```

它们只能说明：

```text
观察像素簇.局部图像证据状态 等于 可用
```

或：

```text
观察像素簇.局部图像证据状态 等于 不足
```

真正链路仍是：

```text
观察像素簇
    -> 生成存在候选
        -> 候选验证
            -> 已确认观察存在
```

## 5. 掩码类特征

掩码不是证据附件。掩码是观察帧、观察像素簇和存在候选的重要特征，直接参与：

```text
存在候选生成
子轮廓提取
像素归属判断
当前观察材料集可观测单位对应情况统计
三维建模
```

掩码的最低定位：

```text
局部图给内容；
掩码给边界和归属。
```

### 5.1 第一层：像素级有效性掩码

像素级有效性掩码挂在当前观察帧或外设观察报告上：

```text
当前观察帧.颜色有效性掩码
当前观察帧.深度有效性掩码
当前观察帧.空间坐标有效性掩码
当前观察帧.低质量像素掩码
```

用途：

```text
判断哪些像素能用于颜色分析；
判断哪些像素能用于深度；
判断哪些像素能用于空间坐标；
判断哪些像素应降低权重或暂不使用。
```

### 5.2 第二层：簇级掩码

簇级掩码挂在观察像素簇上：

```text
观察像素簇.像素集合掩码
观察像素簇.轮廓掩码
观察像素簇.彩色轮廓掩码
观察像素簇.深度轮廓掩码
观察像素簇.局部有效深度掩码
观察像素簇.局部空间坐标有效掩码
```

用途：

```text
明确这个簇到底包含哪些像素；
支持从原帧回查像素；
支持子轮廓提取；
支持局部彩图 / 深度图裁剪；
支持三维点集和表面建模；
支持后续像素归属判断；
把一组像素稳定打包成一个可处理单元。
```

### 5.3 第三层：外设帧级归属掩码

外设帧级归属掩码挂在当前观察帧上，用于接口层判断外设帧材料内的区域归属情况：

```text
当前观察帧.簇ID掩码
当前观察帧.存在候选ID掩码
当前观察帧.已解释像素掩码
当前观察帧.未解释像素掩码
当前观察帧.冲突像素掩码
当前观察帧.低置信像素掩码
当前观察帧.不可观测区域掩码
当前观察帧.已归属静止存在像素掩码
当前观察帧.已归属环境存在像素掩码
```

用途：

```text
判断当前外设帧材料内哪些区域已经被解释；
判断哪些区域还没有解释；
判断哪些区域发生候选冲突；
判断哪些区域因为深度、反光、遮挡等原因不可用；
判断哪些区域已归属为静止存在或环境存在；
为当前观察材料集可观测单位对应情况统计提供输入。
```

### 5.4 掩码存储形态

掩码和局部图可能比较大，不得把它们当普通 I64 值塞入数值特征。可以作为：

```text
VecU句柄
图像缓冲句柄
掩码缓冲句柄
点集缓冲句柄
指针句柄
场景引用句柄
```

特征本身记录句柄和可比较状态：

```text
观察像素簇.像素集合掩码句柄
观察像素簇.彩色轮廓局部图句柄
观察像素簇.深度轮廓局部图句柄
观察像素簇.局部点集句柄

观察像素簇.像素集合掩码状态 等于 已生成
观察像素簇.彩色轮廓局部图状态 等于 已承接
观察像素簇.深度轮廓局部图状态 等于 已承接
```

### 5.5 掩码需求表达

掩码相关需求仍只使用大于 / 小于 / 等于：

```text
观察像素簇.像素集合掩码状态 等于 已生成
观察像素簇.彩色轮廓掩码状态 等于 已生成
观察像素簇.深度轮廓掩码状态 等于 已生成
观察像素簇.彩色轮廓局部图状态 等于 已承接
观察像素簇.深度轮廓局部图状态 等于 已承接
观察像素簇.局部图宽度 大于 0
观察像素簇.局部图高度 大于 0
当前观察帧.簇ID掩码状态 等于 已生成
当前观察帧.存在候选ID掩码状态 等于 已生成
```

不得写：

```text
方向=生成
方向=识别
方向=明确
```

## 6. 当前观察材料集可观测单位对应情况类特征

当前观察材料集可观测单位对应情况不得写成一个模糊字段，应拆成可计算、可回查的事实集合。接口层可以继续保存 `当前观察帧.*` 掩码和来源外设帧索引，但自我需求层只读取观察材料集内有效可观测单位与存在的对应事实：

```text
当前观察材料集.可观测单位集合状态
当前观察材料集.有效可观测单位数量
当前观察材料集.已稳定对应存在可观测单位数量
当前观察材料集.未稳定对应存在可观测单位数量
当前观察材料集.多重对应冲突可观测单位数量
当前观察材料集.稳定对应存在数量
当前观察材料集.可观测单位到存在映射表状态
当前观察材料集.可观测单位存在对应闭合状态
当前观察材料集.扫描可启动状态
```

可以定义：

```text
当前观察材料集.可观测单位存在对应闭合状态 等于 闭合
```

当且仅当：

```text
当前观察材料集.有效可观测单位数量 大于 0
当前观察材料集.已稳定对应存在可观测单位数量 等于 当前观察材料集.有效可观测单位数量
当前观察材料集.未稳定对应存在可观测单位数量 等于 0
当前观察材料集.多重对应冲突可观测单位数量 等于 0
```

该状态只表示：

```text
当前观察材料集中的有效可观测单位都已经稳定对应到存在。
```

不表示：

```text
世界对象全部确认
跨外设帧身份稳定
语义识别完成
基础风险判断已明确
```

每个有效可观测单位必须进入以下对应结果之一：

```text
稳定对应已有存在
稳定对应新存在候选
多重对应冲突
证据不足，未稳定对应
```

其中 `多重对应冲突` 和 `证据不足，未稳定对应` 只能作为缺口，不得作为最终闭合归属。无效或不可观测材料应在接口层材料记录中说明原因，不进入“有效可观测单位全部对应”的完成计数；已归属静止存在或环境存在仍是存在对应结果，可以进入对应闭合统计，但通常降低扫描或处理优先级。

## 7. 存在候选由簇生成

外设线程输出：

```text
观察像素簇集合
```

自我承接后生成：

```text
存在候选集合
```

成立条件可以定义为：

```text
当前观察帧.存在候选集合状态 等于 已生成
```

当且仅当：

```text
当前观察帧.观察像素簇集合状态 等于 已承接
当前观察帧.簇ID掩码状态 等于 已生成
每个存在候选都引用至少一个观察像素簇
每个存在候选都有像素集合掩码
每个存在候选都有边界框
每个存在候选都有来源观察帧
```

如果簇质量不足，也可以生成候选，但候选状态应为：

```text
存在候选.确认状态 等于 待验证
```

不得直接写：

```text
存在候选.确认状态 等于 已确认
```

## 8. 掩码对子轮廓提取和三维建模的作用

### 8.1 子轮廓提取

子轮廓提取应从以下材料开始：

```text
观察像素簇.彩色轮廓局部图
观察像素簇.深度轮廓局部图
观察像素簇.彩色轮廓掩码
观察像素簇.深度轮廓掩码
观察像素簇.像素集合掩码
```

链条：

```text
观察像素簇
    -> 彩色轮廓局部图 + 彩色轮廓掩码
        -> 彩色子轮廓集合

观察像素簇
    -> 深度轮廓局部图 + 深度轮廓掩码
        -> 深度子轮廓集合

彩色子轮廓集合 + 深度子轮廓集合
    -> 子观察像素簇集合
    -> 子存在候选集合
```

对应特征：

```text
观察像素簇.子轮廓集合状态 等于 已生成
观察像素簇.子观察像素簇集合状态 等于 已生成
观察像素簇.子轮廓数量 大于 0
```

如果没有子轮廓，不应直接记为失败，可以写：

```text
观察像素簇.子轮廓集合状态 等于 无可分子轮廓
```

### 8.2 三维建模

三维建模应使用：

```text
观察像素簇.深度轮廓局部图
观察像素簇.局部深度有效性掩码
观察像素簇.局部空间坐标有效掩码
观察像素簇.像素集合掩码
观察像素簇.局部图到原帧坐标映射
```

链条：

```text
深度轮廓局部图
    + 深度有效性掩码
    + 空间坐标有效性掩码
    + 像素集合掩码
        -> 局部点集
        -> 局部三维范围AABB
        -> 局部表面模型 / 体素模型 / 网格模型
```

对应特征：

```text
观察像素簇.局部点集状态 等于 已生成
观察像素簇.局部三维范围状态 等于 已生成
观察像素簇.局部表面模型状态 等于 已生成
```

数值条件：

```text
观察像素簇.局部深度有效率 大于 最低建模深度有效率
观察像素簇.局部空间坐标有效率 大于 最低建模空间坐标有效率
观察像素簇.局部点数量 大于 最小建模点数量
```

## 9. 当前观察材料集可观测单位对应统计方法建议

本文只定义规范口径，不要求立即登记本能方法。后续实现可新增自我判定方法：

```text
自我_统计当前观察材料集可观测单位对应情况
```

输入：

```text
当前观察材料集
观察像素簇集合
存在候选集合
簇ID掩码
存在候选ID掩码
未解释像素掩码
冲突像素掩码
低置信像素掩码
不可观测区域掩码
已归属静止存在像素掩码
已归属环境存在像素掩码
```

输出：

```text
当前观察材料集.可观测单位对应摘要状态 等于 已生成
当前观察材料集.有效可观测单位数量
当前观察材料集.已稳定对应存在可观测单位数量
当前观察材料集.未稳定对应存在可观测单位数量
当前观察材料集.多重对应冲突可观测单位数量
当前观察材料集.稳定对应存在数量
当前观察材料集.可观测单位到存在映射表状态
当前观察材料集.可观测单位存在对应闭合状态 等于 闭合 / 未闭合
当前观察材料集.扫描可启动状态 等于 可启动 / 不可启动
```

这一步是自我层统计，不是外设直接决定“世界识别完成”。接口层本能方法可以读取当前外设帧、上一外设帧和外设帧内掩码；自我层方法输出时必须落到观察材料集与可观测单位对应事实。

## 10. 像素级数据保留方式

像素级数据仍然需要保留，但默认通过索引、掩码和懒展开方式保留：

```text
像素特征索引
像素掩码
像素集合引用
懒展开像素观察存在
```

不得因为引入观察像素簇而破坏：

```text
观察帧编号 + 像素坐标 / 帧内像素编号 的唯一回查目标
```

推荐分层为：

```text
第一层：观察帧特征索引，保证像素可回查。
第二层：观察像素簇，作为主要观察输出单位。
第三层：存在候选，作为自我认知单位。
第四层：已确认观察存在，作为自我场景中的确认结果。
```

## 11. 需求表达

需求表达仍只使用三比较，不使用“生成 / 发现 / 改善 / 建立”作为方向词。

合法表达示例：

```text
当前观察帧.观察像素簇集合状态 等于 已生成
当前观察帧.观察像素簇数量 大于 0
观察像素簇.稳定复现状态 等于 稳定
观察像素簇.深度有效率 大于 最低深度有效率
观察像素簇.空间坐标有效率 大于 最低空间坐标有效率
观察像素簇.像素数量 大于 最小簇像素数量
观察像素簇.存在候选生成状态 等于 已生成
当前观察帧.存在候选集合状态 等于 已生成
```

扫描观察需求示例：

```text
当前观察帧.观察像素簇集合状态 等于 已生成
当前观察帧.簇ID掩码状态 等于 已生成
当前观察帧.低质量区域集合状态 等于 已生成
当前观察帧.未归簇区域集合状态 等于 已生成
当前观察帧.观察像素簇数量 大于 0
```

跟踪观察需求示例：

```text
目标观察候选.跟踪状态 等于 稳定
目标观察候选.最近观测年龄 小于 最大允许观测年龄
目标观察候选.特征复现离散度 小于 最大允许离散度
目标观察候选.丢失状态 等于 未丢失
目标观察候选.稳定特征集合状态 等于 已生成
```

三种相机报告可以支持但不能直接满足的自我认知需求示例：

```text
当前观察帧.存在候选集合状态 等于 已生成
当前观察材料集.可观测单位对应摘要状态 等于 已生成
观察像素簇.存在候选生成状态 等于 已生成
观察像素簇.子轮廓集合状态 等于 已生成
观察像素簇.子观察像素簇集合状态 等于 已生成
当前观察帧.变化候选集合状态 等于 已生成
存在候选.确认状态 等于 已确认
```

观察订阅自身可以写成：

```text
外设观察订阅.观察运行模式 等于 陌生环境逐簇识别
外设观察订阅.观察运行模式 等于 已识别场景扫描变化
外设观察订阅.观察运行模式 等于 目标跟踪观察
```

不推荐表达：

```text
观察簇集合 方向=生成
存在候选 方向=发现
相机发现存在
双目相机全局模式 等于 补观察
双目相机全局模式 等于 质量诊断
双目相机全局模式 等于 局部细分
```

涉及 `已生成 / 稳定 / 可用 / 已确认` 等枚举型实例特征值时，必须按 `枚举型实例特征值合法来源规范20260526.md` 追溯合法生产者、输入证据、判定标准、输出宿主、输出特征和动作动态 / 来源动态 / 规则证据。

## 12. 自我侧方法建议

本文只定义规范口径，不要求立即登记本能方法。后续实现可按以下方法拆分。

### 7.1 自我_承接观察像素簇集合

输入：

```text
外设观察报告
观察像素簇集合
像素特征索引引用
```

输出：

```text
当前观察帧.观察像素簇集合状态 等于 已承接
当前观察帧.观察像素簇数量 大于 0
```

该方法只承接外设观察报告，不确认存在。

### 7.2 自我_由观察像素簇生成存在候选

输入：

```text
观察像素簇集合
簇特征
稳定性
质量状态
像素集合引用
```

输出：

```text
当前观察帧.存在候选集合状态 等于 已生成
观察像素簇.存在候选生成状态 等于 已生成
```

该方法把观察像素簇解释为存在候选，但不得写已确认观察存在。

### 7.3 自我_验证存在候选

输入：

```text
存在候选
来源观察像素簇
像素集合引用
空间范围
轮廓
稳定性证据
质量状态
```

输出：

```text
存在候选.确认状态 等于 已确认
```

或：

```text
存在候选.确认状态 等于 已否定
存在候选.确认状态 等于 待拆分
存在候选.确认状态 等于 待合并
存在候选.确认状态 等于 待验证
```

只有验证结果满足已确认标准时，才可以派生或写入自我所在场景中的已确认观察存在。

## 13. 与既有空间候选口径的关系

历史计划和实现中的：

```text
空间候选
空间候选观察事实
存在假设
```

应按语义区分：

```text
如果它只是外设帧材料内的像素 / 深度 / 空间连续簇：
    应逐步收束为 观察像素簇。

如果它已经是自我对观察簇的解释包装：
    应逐步收束为 存在候选。

如果它已经完成自我验证：
    才能进入 已确认观察存在。
```

历史字段或旧方法名只允许作为归档说明或迁移前只读定位线索；不得继续参与当前机器判断、当前计划验收或新实现。新计划、新规范和新实现必须使用：

```text
观察像素簇
存在候选
已确认观察存在
```

来减少“外设输出”和“自我解释”混淆。

## 14. 外设线程边界

外设自主观察线程可以控制双目相机持续取得观察材料，但线程不是动作来源。凡是需要写动作动态或实例特征值的变化，必须绑定明确方法。

相机线程内部能力直接由工程代码实现。采集、校正、滤波、分割、掩码生成、局部图裁剪、扫描调度、跟踪调度、重捕获和配置学习都属于外设私有过程，不要求也不得逐项登记为自我层本能方法。

同一个外设线程可以根据任务管理提交的外设等待项 / 订阅项输出逐簇识别报告、扫描变化报告或跟踪报告。逐簇识别报告用于从未知视野生成当前观察材料集内观察像素簇、外设帧级掩码、未解释区域、低置信区域、不可观测区域和可观测单位对应摘要；扫描变化报告用于低成本输出新增、消失、变化、高风险未知和低质量区域；跟踪报告用于为已有观察簇 / 存在候选持续提供稳定特征、丢失状态和重捕获候选。补观察、稳定特征取值、局部细分、变化监测、质量诊断和配置学习不作为自我可见外设模式，只能作为内部策略、报告字段或自我后续方法。

外设等待项 / 订阅项至少应区分：

```text
观察运行模式 = 陌生环境逐簇识别 / 已识别场景扫描变化 / 目标跟踪观察
目标区域 / 目标簇 / 目标候选，可空
ROI / 掩码 / 跟踪种子，可空
期望报告类型 = 逐簇识别报告 / 扫描变化报告 / 跟踪报告
期望特征类型集合
最小稳定性要求
最大允许报告年龄
是否允许缓存报告
质量要求 / 内部策略提示，可空
```

外设使用类方法、外设命令或观察等待项可以把目标能力表述为：

```text
当前观察帧.观察像素簇集合状态 等于 已生成
外设观察报告.生成状态 等于 已生成
```

这些表达是自我 / 任务管理侧的边界契约，不是相机线程内部算法步骤。

外设线程不得输出：

```text
世界存在 等于 已发现
目标在场状态 等于 已确认
基础风险判断状态 等于 已明确
双目相机全局模式 等于 补观察
双目相机全局模式 等于 质量诊断
双目相机全局模式 等于 局部细分
把补观察、稳定取值、局部细分、质量诊断或配置学习写成外设观察订阅的观察运行模式
```

这些只能由自我认知链在证据满足后生成。

## 15. 禁止项

禁止：

```text
1. 把整帧像素全部直接提升为自我关心的对象。
2. 把观察像素簇等同于稳定世界对象。
3. 把外设内部分割 / 跟踪结果直接写成已确认观察存在。
4. 因为观察像素簇稳定，就宣称跨帧身份稳定。
5. 因为存在候选已生成，就宣称基础风险判断已明确。
6. 为缺失的颜色、深度、空间坐标、轮廓或稳定性特征伪造默认值。
7. 用控制面板显示层或补全结果反写原始观察真值。
8. 把彩色轮廓截图 / 深度轮廓截图当作已确认观察存在的直接结论。
9. 把截图显示效果当成像素集合、深度统计或空间坐标统计的替代权威。
10. 把掩码当成仅用于显示的证据附件。
11. 缺少簇ID掩码 / 存在候选ID掩码时宣称当前观察材料集可观测单位存在对应闭合。
12. 把当前观察材料集可观测单位存在对应闭合解释成世界对象全部确认。
13. 为不同观察意图各造一套并行外设系统。
14. 把外设内部跟踪ID当作自我世界存在ID。
15. 让自我线程直接消费相机流或未被正式需求领走的外设报告。
16. 把补观察、稳定取值、局部细分、质量诊断或配置学习写成自我可见的外设模式或相机唯一全局模式。
```

一句话：

```text
相机线程不要把世界认出来；
它按任务管理提交的三种观察运行模式等待项输出逐簇识别报告、扫描变化报告或跟踪报告；
陌生时逐簇识别，熟悉后低频扫变化，需要时盯住目标；
补观察、稳定取值、局部细分、变化监测、质量诊断和配置学习只作为内部策略、报告字段或自我后续方法；
观察像素簇既要有数值摘要，也要有局部图像证据；
掩码给边界和归属，当前观察材料集可观测单位对应统计给阶段达标判断；
自我再把簇解释成存在候选。
```
