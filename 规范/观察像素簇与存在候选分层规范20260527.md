## 1. 定案

双目相机外设线程或外设使用方法的主要观察输出单位不应是：

```text
整帧像素全部直接变成自我关心的对象
```

也不应是：

```text
相机发现世界存在
```

更合理的链路是：

```text
观察帧
    -> 观察像素簇集合
        -> 每个观察像素簇携带一组稳定特征值
            -> 自我承接观察像素簇
                -> 自我生成存在候选
                    -> 自我验证候选
                        -> 已确认观察存在
```

定案句：

```text
外设给观察簇；
自我把观察簇解释成存在候选；
候选经过验证后才可以成为已确认观察存在。
```

观察像素簇不是稳定世界存在。它是当前观察帧内一组像素事实和稳定特征值构成的证据集合。

## 2. 层级定位

### 2.1 观察帧

观察帧是本轮观察材料的来源锚点，记录：

```text
来源外设
帧号
帧宽度
帧高度
观察生成时间
像素特征索引引用
观察像素簇集合引用
低质量区域集合引用
未归簇区域集合引用
失败原因摘要
```

观察帧仍必须保证像素可寻址、可回查、无遗漏、无重复；但这不要求每次都把所有像素物化成自我直接关心的对象。

### 2.2 观察像素簇

观察像素簇是当前观察帧内的一组像素集合及其稳定特征摘要。它可以由颜色、深度、空间坐标、边界、连续性或稳定性等一致性生成。

更完整地说：

```text
观察像素簇 =
    像素集合
  + 掩码
  + 彩色轮廓局部图
  + 深度轮廓局部图
  + 颜色特征
  + 深度特征
  + 空间特征
  + 稳定性特征
```

观察像素簇是：

```text
当前帧观察材料的聚合单位
存在候选的证据集合
可被自我继续验证的观察事实包
```

不是：

```text
稳定世界存在
语义对象
跨帧身份
已确认观察存在
基础风险判断结论
```

### 2.3 存在候选

存在候选是自我对观察像素簇的一层解释包装。存在候选必须引用来源观察像素簇，不应复制所有像素事实。

```text
存在候选 {
    来源观察帧
    来源观察像素簇
    候选ID

    候选中心位置
    候选范围坐标
    候选轮廓
    候选颜色摘要
    候选深度摘要
    候选空间坐标摘要
    候选质量状态
    候选稳定状态

    确认状态:
        未确认
        待验证
        已确认观察存在
        已否定
        待拆分
        待合并
}
```

### 2.4 已确认观察存在

已确认观察存在只能由自我验证链生成。仅有观察像素簇或存在候选时，不得宣称已经确认稳定世界对象。

## 3. 外设观察报告

外设自主观察线程或双目相机使用类方法可以输出：

```text
外设观察报告 {
    来源观察帧
    来源外设
    帧宽度
    帧高度
    深度帧号
    彩色帧号
    外设配置摘要

    像素特征索引引用
    观察像素簇集合
    低质量区域集合
    未归簇区域集合
    失败原因摘要
}
```

其中：

```text
观察像素簇集合
```

是后续生成存在候选的主要输入。

外设内部采集、校正、滤波、补全、分割、跟踪等仍属于外设私有领域。自我只能通过外设控制、检查、使用入口接收可落账的观察报告或当前观察特征帧结果。

### 3.1 扫描报告与跟踪报告

同一个双目相机外设线程可以按任务管理工作线程提交的等待项输出报告，但第一版对自我可见的数据产品只收敛为两类：

```text
扫描报告
跟踪报告
```

其它能力不作为自我可见的外设模式暴露。质量诊断、ROI 观察、补观察、稳定特征取值、重捕获、局部细分、变化监测和配置学习分别归入外设内部策略、扫描 / 跟踪报告字段或自我后续方法。

扫描报告面向：

```text
我现在视野里大概有什么？
哪些区域有观察像素簇？
哪些区域未解释、低质量、不可观测？
是否有值得进一步观察的候选？
```

扫描报告应包含：

```text
当前观察帧
观察像素簇集合
簇ID掩码
未解释像素掩码
低置信像素掩码
不可观测区域掩码
每个簇的彩色轮廓局部图
每个簇的深度轮廓局部图
每个簇的稳定特征摘要
```

跟踪观察面向：

```text
我已经有一个目标簇 / 存在候选，
现在要持续获得它的稳定特征值。
```

跟踪报告应包含：

```text
外设内部跟踪ID
来源观察帧
来源观察像素簇
目标ROI
目标掩码
彩色轮廓局部图
深度轮廓局部图
稳定特征集合
连续成功次数
复现离散度
丢失原因
重捕获候选集合
```

跟踪报告可以服务存在候选的后续验证，但不得直接写成已确认观察存在。

```text
外设内部跟踪ID != 自我世界存在ID
```

其它能力与观察像素簇的关系：

```text
定向观察：
    作为扫描或跟踪等待项的目标区域 / ROI 参数。

补观察：
    任务筹办根据质量缺口派生新的扫描或跟踪等待项；旧帧质量不足是事实，不修旧帧。

稳定特征取值：
    是跟踪报告的核心字段，不另建报告类型。

重捕获：
    是跟踪报告里的丢失处理、重捕获候选集合和失败原因。

局部细分：
    由自我方法使用彩色轮廓局部图、深度轮廓局部图和掩码生成子轮廓、子簇、局部点集和局部三维范围。

变化监测：
    由自我比较多次扫描 / 跟踪报告后生成新增、消失或变化区域候选。

质量诊断：
    是扫描 / 跟踪报告里的低质量区域、不可观测区域、质量摘要和失败原因。

配置学习：
    属于外设内部学习模块，只在报告中暴露配置摘要、推荐配置和适用性。
```

因此，相机报告只能直接满足观察材料层需求；存在候选、存在识别摘要、变化候选、局部细分和已确认观察存在，都必须由自我方法在承接报告后生成。

## 4. 观察像素簇内容

观察像素簇建议至少包含：

```text
观察像素簇 {
    来源观察帧
    来源外设
    外设内部簇ID

    像素集合引用 / 掩码引用 / 像素索引集合
    帧内像素数量
    像素覆盖边界框
    图像中心点
    轮廓引用 / 轮廓摘要
    像素集合掩码句柄
    轮廓掩码句柄
    彩色轮廓掩码句柄
    深度轮廓掩码句柄
    深度有效性掩码句柄
    空间坐标有效性掩码句柄
    彩色轮廓截图句柄
    深度轮廓截图句柄
    截图边界框
    截图缩放比例，可选
    彩色轮廓掩码句柄，可选
    深度轮廓掩码句柄，可选

    颜色特征:
        平均颜色
        主颜色
        颜色方差
        颜色稳定性

    深度特征:
        深度有效率
        深度最小值
        深度最大值
        深度中位数
        深度方差
        深度稳定性

    空间特征:
        空间坐标有效率
        空间中心坐标
        空间范围AABB
        空间连续性评分
        空间坐标稳定性

    质量特征:
        簇质量可用状态
        稳定复现状态
        连续观测次数
        失败原因集合
        使用配置摘要
}
```

取得不到的特征不得伪造。应显式写成特征状态：

```text
观察像素簇.深度特征状态 等于 不足
观察像素簇.空间坐标特征状态 等于 不足
观察像素簇.轮廓特征状态 等于 可用
观察像素簇.颜色特征状态 等于 可用
```

### 4.1 局部图像证据

观察像素簇除了数值摘要特征外，还应允许挂接局部图像证据：

```text
彩色轮廓截图
深度轮廓截图
```

这两类截图是观察像素簇的附属观察证据，不是观察像素簇的权威真值本身，也不能替代存在候选确认逻辑。

观察像素簇的权威事实仍是：

```text
像素集合引用
簇轮廓
边界框
像素数量
颜色统计
深度统计
空间坐标统计
质量状态
稳定状态
```

彩色轮廓截图 / 深度轮廓截图的作用是：

```text
便于控制面板显示；
便于人工复核；
便于后续递归细分；
便于跨帧比较；
便于外设内部学习模块保存样本证据；
便于复查某次稳定性判断所依赖的局部观察材料。
```

### 4.2 截图定义

彩色轮廓截图：

```text
从当前观察帧的彩图中，
按该观察像素簇的边界框或轮廓区域裁剪出的局部图像。
```

深度轮廓截图：

```text
从当前观察帧的深度图中，
按该观察像素簇的边界框或轮廓区域裁剪出的局部深度图像。
```

第一版优先支持：

```text
轮廓包围框截图
```

后续需要更精细时，再增加：

```text
轮廓掩码截图
```

### 4.3 截图挂接字段

彩色轮廓截图和深度轮廓截图不得作为普通数值特征直接塞入 I64。它们应以句柄、缓冲引用或场景引用的方式挂接到观察像素簇：

```text
观察像素簇.彩色轮廓截图句柄
观察像素簇.深度轮廓截图句柄
观察像素簇.截图边界框
观察像素簇.来源观察帧
观察像素簇.截图生成时间
观察像素簇.截图缩放比例，可选
观察像素簇.彩色轮廓掩码句柄，可选
观察像素簇.深度轮廓掩码句柄，可选
```

最低必需字段：

```text
彩色轮廓截图句柄
深度轮廓截图句柄
截图边界框
来源观察帧
```

这些字段用于回答：

```text
截图来自哪一帧；
裁剪的是哪一块；
截图是否与当前簇的像素集合一致；
截图能否用于后续细分、复核、比较或学习。
```

### 4.4 截图与存在确认边界

有了彩色轮廓截图或深度轮廓截图，不能直接推出：

```text
观察像素簇.存在候选生成状态 等于 已生成
存在候选.确认状态 等于 已确认
自我所在场景.已确认观察存在集合状态 等于 已更新
```

它们只能说明：

```text
观察像素簇.局部图像证据状态 等于 可用
```

或：

```text
观察像素簇.局部图像证据状态 等于 不足
```

真正链路仍是：

```text
观察像素簇
    -> 生成存在候选
        -> 候选验证
            -> 已确认观察存在
```

## 5. 掩码类特征

掩码不是证据附件。掩码是观察帧、观察像素簇和存在候选的重要特征，直接参与：

```text
存在候选生成
子轮廓提取
像素归属判断
当前帧存在识别情况统计
三维建模
```

掩码的最低定位：

```text
局部图给内容；
掩码给边界和归属。
```

### 5.1 第一层：像素级有效性掩码

像素级有效性掩码挂在当前观察帧或外设观察报告上：

```text
当前观察帧.颜色有效性掩码
当前观察帧.深度有效性掩码
当前观察帧.空间坐标有效性掩码
当前观察帧.低质量像素掩码
```

用途：

```text
判断哪些像素能用于颜色分析；
判断哪些像素能用于深度；
判断哪些像素能用于空间坐标；
判断哪些像素应降低权重或暂不使用。
```

### 5.2 第二层：簇级掩码

簇级掩码挂在观察像素簇上：

```text
观察像素簇.像素集合掩码
观察像素簇.轮廓掩码
观察像素簇.彩色轮廓掩码
观察像素簇.深度轮廓掩码
观察像素簇.局部有效深度掩码
观察像素簇.局部空间坐标有效掩码
```

用途：

```text
明确这个簇到底包含哪些像素；
支持从原帧回查像素；
支持子轮廓提取；
支持局部彩图 / 深度图裁剪；
支持三维点集和表面建模；
支持后续像素归属判断；
把一组像素稳定打包成一个可处理单元。
```

### 5.3 第三层：帧级识别掩码

帧级识别掩码挂在当前观察帧上，用于判断当前帧识别情况：

```text
当前观察帧.簇ID掩码
当前观察帧.存在候选ID掩码
当前观察帧.已解释像素掩码
当前观察帧.未解释像素掩码
当前观察帧.冲突像素掩码
当前观察帧.低置信像素掩码
当前观察帧.不可观测区域掩码
当前观察帧.背景区域掩码
```

用途：

```text
判断当前帧哪些区域已经被解释；
判断哪些区域还没有解释；
判断哪些区域发生候选冲突；
判断哪些区域因为深度、反光、遮挡等原因不可用；
判断哪些区域属于背景；
为当前帧存在识别情况统计提供输入。
```

### 5.4 掩码存储形态

掩码和局部图可能比较大，不得把它们当普通 I64 值塞入数值特征。可以作为：

```text
VecU句柄
图像缓冲句柄
掩码缓冲句柄
点集缓冲句柄
指针句柄
场景引用句柄
```

特征本身记录句柄和可比较状态：

```text
观察像素簇.像素集合掩码句柄
观察像素簇.彩色轮廓局部图句柄
观察像素簇.深度轮廓局部图句柄
观察像素簇.局部点集句柄

观察像素簇.像素集合掩码状态 等于 已生成
观察像素簇.彩色轮廓局部图状态 等于 已承接
观察像素簇.深度轮廓局部图状态 等于 已承接
```

### 5.5 掩码需求表达

掩码相关需求仍只使用大于 / 小于 / 等于：

```text
观察像素簇.像素集合掩码状态 等于 已生成
观察像素簇.彩色轮廓掩码状态 等于 已生成
观察像素簇.深度轮廓掩码状态 等于 已生成
观察像素簇.彩色轮廓局部图状态 等于 已承接
观察像素簇.深度轮廓局部图状态 等于 已承接
观察像素簇.局部图宽度 大于 0
观察像素簇.局部图高度 大于 0
当前观察帧.簇ID掩码状态 等于 已生成
当前观察帧.存在候选ID掩码状态 等于 已生成
```

不得写：

```text
方向=生成
方向=识别
方向=明确
```

## 6. 当前帧存在识别情况类特征

当前帧存在识别情况不得写成一个模糊字段，应拆成可计算、可回查的特征集合：

```text
当前观察帧.观察像素簇集合状态
当前观察帧.观察像素簇数量
当前观察帧.存在候选集合状态
当前观察帧.存在候选数量
当前观察帧.已解释像素比例
当前观察帧.未解释像素比例
当前观察帧.冲突像素比例
当前观察帧.低置信像素比例
当前观察帧.不可观测区域比例
当前观察帧.高价值未解释区域数量
当前观察帧.存在识别摘要状态
当前观察帧.存在识别达标状态
```

可以定义：

```text
当前观察帧.存在识别达标状态 等于 达标
```

当且仅当：

```text
当前观察帧.观察像素簇集合状态 等于 已生成
当前观察帧.存在候选集合状态 等于 已生成
当前观察帧.已解释像素比例 大于 最低解释比例
当前观察帧.未解释像素比例 小于 最大允许未解释比例
当前观察帧.冲突像素比例 小于 最大允许冲突比例
当前观察帧.高价值未解释区域数量 等于 0
```

该状态只表示：

```text
当前帧中的可见像素区域已经被解释到当前阶段要求。
```

不表示：

```text
世界对象全部确认
跨帧身份稳定
语义识别完成
基础风险判断已明确
```

每个像素可以被解释为：

```text
属于某观察像素簇
属于某存在候选
属于背景
属于不可观测区域
属于低置信区域
属于冲突区域
```

不要求所有像素都必须归到存在候选。

## 7. 存在候选由簇生成

外设线程输出：

```text
观察像素簇集合
```

自我承接后生成：

```text
存在候选集合
```

成立条件可以定义为：

```text
当前观察帧.存在候选集合状态 等于 已生成
```

当且仅当：

```text
当前观察帧.观察像素簇集合状态 等于 已承接
当前观察帧.簇ID掩码状态 等于 已生成
每个存在候选都引用至少一个观察像素簇
每个存在候选都有像素集合掩码
每个存在候选都有边界框
每个存在候选都有来源观察帧
```

如果簇质量不足，也可以生成候选，但候选状态应为：

```text
存在候选.确认状态 等于 待验证
```

不得直接写：

```text
存在候选.确认状态 等于 已确认
```

## 8. 掩码对子轮廓提取和三维建模的作用

### 8.1 子轮廓提取

子轮廓提取应从以下材料开始：

```text
观察像素簇.彩色轮廓局部图
观察像素簇.深度轮廓局部图
观察像素簇.彩色轮廓掩码
观察像素簇.深度轮廓掩码
观察像素簇.像素集合掩码
```

链条：

```text
观察像素簇
    -> 彩色轮廓局部图 + 彩色轮廓掩码
        -> 彩色子轮廓集合

观察像素簇
    -> 深度轮廓局部图 + 深度轮廓掩码
        -> 深度子轮廓集合

彩色子轮廓集合 + 深度子轮廓集合
    -> 子观察像素簇集合
    -> 子存在候选集合
```

对应特征：

```text
观察像素簇.子轮廓集合状态 等于 已生成
观察像素簇.子观察像素簇集合状态 等于 已生成
观察像素簇.子轮廓数量 大于 0
```

如果没有子轮廓，不应直接记为失败，可以写：

```text
观察像素簇.子轮廓集合状态 等于 无可分子轮廓
```

### 8.2 三维建模

三维建模应使用：

```text
观察像素簇.深度轮廓局部图
观察像素簇.局部深度有效性掩码
观察像素簇.局部空间坐标有效掩码
观察像素簇.像素集合掩码
观察像素簇.局部图到原帧坐标映射
```

链条：

```text
深度轮廓局部图
    + 深度有效性掩码
    + 空间坐标有效性掩码
    + 像素集合掩码
        -> 局部点集
        -> 局部三维范围AABB
        -> 局部表面模型 / 体素模型 / 网格模型
```

对应特征：

```text
观察像素簇.局部点集状态 等于 已生成
观察像素簇.局部三维范围状态 等于 已生成
观察像素簇.局部表面模型状态 等于 已生成
```

数值条件：

```text
观察像素簇.局部深度有效率 大于 最低建模深度有效率
观察像素簇.局部空间坐标有效率 大于 最低建模空间坐标有效率
观察像素簇.局部点数量 大于 最小建模点数量
```

## 9. 当前帧存在识别情况统计方法建议

本文只定义规范口径，不要求立即登记本能方法。后续实现可新增自我判定方法：

```text
自我_统计当前帧存在识别情况
```

输入：

```text

冲突像素掩码
低置信像素掩码
不可观测区域掩码
背景区域掩码
```

输出：

当前观察帧.未解释像素比例

## 10. 像素级数据保留方式

像素级数据仍然需要保留，但默认通过索引、掩码和懒展开方式保留：

```text
像素特征索引
像素掩码
像素集合引用
懒展开像素观察存在
```

不得因为引入观察像素簇而破坏：

```text
观察帧编号 + 像素坐标 / 帧内像素编号 的唯一回查目标
```

推荐分层为：

```text
第一层：观察帧特征索引，保证像素可回查。
第二层：观察像素簇，作为主要观察输出单位。
第三层：存在候选，作为自我认知单位。
第四层：已确认观察存在，作为自我场景中的确认结果。
```

## 11. 需求表达

需求表达仍只使用三比较，不使用“生成 / 发现 / 改善 / 建立”作为方向词。

合法表达示例：

```text
当前观察帧.观察像素簇集合状态 等于 已生成
当前观察帧.观察像素簇数量 大于 0
观察像素簇.稳定复现状态 等于 稳定
观察像素簇.深度有效率 大于 最低深度有效率
观察像素簇.空间坐标有效率 大于 最低空间坐标有效率
观察像素簇.像素数量 大于 最小簇像素数量
观察像素簇.存在候选生成状态 等于 已生成
当前观察帧.存在候选集合状态 等于 已生成
```

扫描观察需求示例：

```text
当前观察帧.观察像素簇集合状态 等于 已生成
当前观察帧.簇ID掩码状态 等于 已生成
当前观察帧.低质量区域集合状态 等于 已生成
当前观察帧.未归簇区域集合状态 等于 已生成
当前观察帧.观察像素簇数量 大于 0
```

跟踪观察需求示例：

```text
目标观察候选.跟踪状态 等于 稳定
目标观察候选.最近观测年龄 小于 最大允许观测年龄
目标观察候选.特征复现离散度 小于 最大允许离散度
目标观察候选.丢失状态 等于 未丢失
目标观察候选.稳定特征集合状态 等于 已生成
```

扫描 / 跟踪报告可以支持但不能直接满足的自我认知需求示例：

```text
当前观察帧.存在候选集合状态 等于 已生成
当前观察帧.存在识别摘要状态 等于 已生成
观察像素簇.存在候选生成状态 等于 已生成
观察像素簇.子轮廓集合状态 等于 已生成
观察像素簇.子观察像素簇集合状态 等于 已生成
当前观察帧.变化候选集合状态 等于 已生成
存在候选.确认状态 等于 已确认
```

观察订阅自身可以写成：

```text
外设观察订阅.观察意图类型 等于 扫描
外设观察订阅.观察意图类型 等于 跟踪
```

不推荐表达：

```text
观察簇集合 方向=生成
存在候选 方向=发现
相机发现存在
双目相机全局模式 等于 扫描
双目相机全局模式 等于 跟踪
双目相机全局模式 等于 补观察
双目相机全局模式 等于 局部细分
```

涉及 `已生成 / 稳定 / 可用 / 已确认` 等枚举型实例特征值时，必须按 `枚举型实例特征值合法来源规范20260526.md` 追溯合法生产者、输入证据、判定标准、输出宿主、输出特征和动作动态 / 来源动态 / 规则证据。

## 13. 与既有空间候选口径的关系

历史计划和实现中的：

```text
空间候选
空间候选观察事实
存在假设
```

应按语义区分：

```text
如果它只是当前帧内的像素 / 深度 / 空间连续簇：
    应逐步收束为 观察像素簇。

如果它已经是自我对观察簇的解释包装：
    应逐步收束为 存在候选。

如果它已经完成自我验证：
    才能进入 已确认观察存在。
```

过渡期允许保留旧字段和旧方法名，但新计划、新规范和新实现应优先使用：

```text
观察像素簇
存在候选
已确认观察存在
```

来减少“外设输出”和“自我解释”混淆。

## 14. 外设线程边界

外设自主观察线程可以控制双目相机持续取得观察材料，但线程不是动作来源。凡是需要写动作动态或实例特征值的变化，必须绑定明确方法。

同一个外设线程可以根据任务管理提交的外设等待项 / 订阅项输出扫描报告或跟踪报告。扫描报告用于生成当前帧观察像素簇、帧级掩码、低质量区域、未归簇区域和不可观测区域；跟踪报告用于为已有观察簇 / 存在候选持续提供稳定特征、丢失状态和重捕获候选。补观察、稳定特征取值、局部细分、变化监测、质量诊断和配置学习不作为自我可见外设模式，只能作为内部策略、报告字段或自我后续方法。

外设等待项 / 订阅项至少应区分：

```text
观察意图类型 = 扫描 / 跟踪
目标区域 / 目标簇 / 目标候选，可空
ROI / 掩码 / 跟踪种子，可空
期望报告类型 = 扫描报告 / 跟踪报告
期望特征类型集合
最小稳定性要求
最大允许报告年龄
是否允许缓存报告
质量要求 / 内部策略提示，可空
```

外设使用类方法可以把目标能力表述为：

```text
当前观察帧.观察像素簇集合状态 等于 已生成
外设观察报告.生成状态 等于 已生成
```

外设线程不得输出：

```text
世界存在 等于 已发现
目标在场状态 等于 已确认
基础风险判断状态 等于 已明确
双目相机全局模式 等于 扫描
双目相机全局模式 等于 跟踪
双目相机全局模式 等于 补观察
双目相机全局模式 等于 局部细分
把补观察、稳定取值、局部细分、质量诊断或配置学习写成外设观察订阅的观察意图类型
```

这些只能由自我认知链在证据满足后生成。

## 15. 禁止项

禁止：

```text
1. 把整帧像素全部直接提升为自我关心的对象。
2. 把观察像素簇等同于稳定世界对象。
3. 把外设内部分割 / 跟踪结果直接写成已确认观察存在。
4. 因为观察像素簇稳定，就宣称跨帧身份稳定。
5. 因为存在候选已生成，就宣称基础风险判断已明确。
6. 为缺失的颜色、深度、空间坐标、轮廓或稳定性特征伪造默认值。
7. 用控制面板显示层或补全结果反写原始观察真值。
8. 把彩色轮廓截图 / 深度轮廓截图当作已确认观察存在的直接结论。
9. 把截图显示效果当成像素集合、深度统计或空间坐标统计的替代权威。
10. 把掩码当成仅用于显示的证据附件。
11. 缺少簇ID掩码 / 存在候选ID掩码时宣称当前帧存在识别达标。
12. 把当前帧存在识别达标解释成世界对象全部确认。
13. 为不同观察意图各造一套并行外设系统。
14. 把外设内部跟踪ID当作自我世界存在ID。
15. 让自我线程直接消费相机流或未被正式需求领走的外设报告。
16. 把补观察、稳定取值、局部细分、质量诊断或配置学习写成自我可见的外设模式或相机唯一全局模式。
```

一句话：

```text
相机线程不要把世界认出来；
它按任务管理提交的扫描 / 跟踪等待项输出扫描报告或跟踪报告；
扫描找视野里的簇，跟踪盯住目标簇并给稳定特征；
补观察、稳定取值、局部细分、变化监测、质量诊断和配置学习只作为内部策略、报告字段或自我后续方法；
观察像素簇既要有数值摘要，也要有局部图像证据；
掩码给边界和归属，当前帧识别统计给阶段达标判断；
自我再把簇解释成存在候选。
```
