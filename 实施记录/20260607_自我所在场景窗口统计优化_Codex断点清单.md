# 20260607 自我所在场景窗口统计优化 Codex 断点清单

## 当前切片

优化自我所在场景窗口显示：增加已知存在数量、未知区域占整个窗口的像素点占比。

## 验证预测

- Debug x64 构建应通过。
- 自我场景复现 JSON 应包含 `knownExistenceCount`、`unknownWindowPixels`、`unknownWindowPixelTotal`、`unknownWindowPixelRatio`。
- 自我所在场景窗口的场景快照区应出现 `已知存在` 和 `未知区域占比` 两个统计卡片。
- `已知存在` 只取现有 `已验证观察存在数量`，不把候选、观察像素簇或未确认区域计为已知存在。
- `未知区域占比` 按未解释像素数除以整个窗口像素数计算，窗口像素数优先取预期像素数量，缺失时退回宽高乘积或像素特征数量。
