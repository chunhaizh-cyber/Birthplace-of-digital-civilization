## 当前判断

本轮已不再是原始 D455 分割质量问题，也不是 6150 计数闭合问题。第一个后续断点收束为：

```text
扫描等待项已经存在，扫描变化报告也已入队；
但 D455 生成报告时按等待项读取目标观察约束发生宽松串线，
导致报告的目标观察约束ID与等待项目标观察约束ID不一致，
随后被任务管理强一致门控拒绝。
```

## 下一步

只追查以下最短路径：

```text
任务管理创建 已识别场景扫描变化 等待项
-> 外设线程是否读取/接收该等待项或处理模式请求
-> D455 外设线程是否生成 扫描变化报告
-> 任务管理是否能匹配并上行
```

当前最小修正点：

```text
目标观察约束_匹配等待项：
等待项已经携带显式 目标观察约束ID 时，只允许按该 ID 精确匹配；
不得再回退到目标存在ID / 目标区域宽松匹配。
```
