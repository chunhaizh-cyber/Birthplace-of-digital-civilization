# S6-N2a-P1 外设提交包结构化承载实施记录

时间：2026-06-02

## 1. 实施范围

本轮只实现外设报告到外设提交包的结构化承载层。

代码修改：

```text
外设观察报告队列.ixx
```

未修改：

```text
自我线程模块.impl.cpp
任务模块.管理工作线程.ixx
任务模块.管理界面线程.impl.cpp
自我动作实现.外设模块.ixx
需求树写入链
安全评估链
```

本轮不写需求树、不确认存在、不写安全值、不把外设报告当作提交入口。

## 2. 已实现内容

### 2.1 修正扫描别名

已将：

```text
枚举_外设观察运行模式::扫描
```

从误指：

```text
陌生环境逐簇识别
```

修正为：

```text
已识别场景扫描变化
```

并新增：

```text
枚举_外设观察运行模式::识别 = 陌生环境逐簇识别
```

检索结果显示当前业务代码没有使用短别名 `扫描`，因此本次修正不改变当前 D455 已运行长枚举名路径。

### 2.2 新增统一提交包基础类型

新增：

```text
枚举_外设提交包类型
枚举_外设触发来源
枚举_外设特征值形态
枚举_外设特征宿主类型
枚举_外设区域归属状态
枚举_扫描匹配状态
枚举_跟踪状态
枚举_外设提交缺口码
枚举_外设特征类型ID
```

新增：

```text
结构_外设空间中心
结构_外设空间范围AABB
结构_外设向量3D
结构_外设提交包头
结构_外设特征值条目
```

其中 `结构_外设特征值条目` 采用结构化 `枚举_外设特征类型ID`，不是自然语言文本命中。

### 2.3 新增三类外设提交包结构

新增：

```text
结构_外设识别提交包
结构_外设扫描提交包
结构_外设跟踪提交包
```

配套新增：

```text

```

三类提交包都携带统一 `结构_外设提交包头`，包头包含：

```text

帧ID
场景ID

触发来源

提交时间毫秒
外设ID

坐标系ID
标定版本
generation
有效截止时间毫秒
材料句柄集
缺失材料
质量问题
```

### 2.4 新增只读规范化包装函数

新增导出函数：

```text
外设提交包类型文本
外设提交包类型_由报告类型
构造外设提交包头_由观察报告
构造外设识别提交包_由观察报告
构造外设扫描提交包_由观察报告
构造外设跟踪提交包_由观察报告
```

这些函数只从现有 `结构_外设观察报告队列项` 构造提交包视图：

```text
逐簇识别报告 -> 结构_外设识别提交包
扫描变化报告 -> 结构_外设扫描提交包
跟踪报告 -> 结构_外设跟踪提交包
```

报告类型不匹配时返回 `std::nullopt`。

### 2.5 保留现有 D455 报告队列

本轮没有删除或改造：

```text

提交外设观察报告
提交D455短期观察材料页

```

因此现有 D455 采集、报告缓存、等待项匹配和任务管理承接链没有被重写。

## 3. 明确边界

本轮提交包仍然是：

```text
外设供料层 / 特征包视图
```

不是：

```text
自我内部账本提交入口
已确认观察存在
当前场景风险明确
需求满足
安全值变化
```

扫描包中没有已确认存在 ID 时，会保留结构并写入：

```text
缺已确认存在ID
```

跟踪包中没有目标存在 ID / 目标种子时，也只写缺口码，不把跟踪成功解释成已确认事实。
