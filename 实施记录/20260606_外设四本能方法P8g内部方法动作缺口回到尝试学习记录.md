# 20260606 外设四本能方法 P8g 内部方法动作缺口回到尝试学习记录

## 切片目标

将真实日志中暴露的 `方法动作数量 / 方法动作状态` 内部补齐路由，从 `自我_定向学习` 撤回到 `自我_尝试学习`。

## 依据

- `规范/学习相关本能函数规范20260505.md`：`定向学习` 只属于外界信息处理链，不得在自我内部方法补齐闭环中替代 `尝试学习`。
- `规范/方法规范20260425.md`：自我内部方法补齐闭环固定为方法补齐入口 -> 结构自检 -> 缺口子需求 -> `尝试学习` -> 练习验证；内部因果样本缺失或不可用时不命中 `定向学习`。
- 用户口径：值域是特征类内部概念，自我层不主动裁决值域；本切片不修改值域判断。

## 修改预测

1. Debug x64 构建应通过，不新增 `--*-check` 或模拟入口。
2. 30 秒 `--self-check-log` 真实运行中，`方法动作数量 / 方法动作状态` 内部缺口不应再选择 `自我_定向学习`。
3. 日志中不应再出现由内部方法动作缺口触发的 `自我_定向学习/动作目标不可闭合`。
4. 若目标方法仍缺可内化的内部因果动作样本，`自我_尝试学习` 应显式暴露 `目标已有方法动作=0`、`值_自我动作缺失` 或继续生成真实缺口，而不是伪造方法动作。
