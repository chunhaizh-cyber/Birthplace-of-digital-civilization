# 20260616 ADO数据库能力 Codex断点清单

## 0. 恢复摘要

当前切片目标：增加项目级 ADO 数据库访问能力，并把控制面板静态 HTML 的 SQL 读取路径从 `sqlcmd` 临时文件改为 ADO 查询。

边界：

```text
1. ADO 本切片只作为数据库访问能力层，不改变世界树、任务树、方法树或动作动态链的权威写入位置。
2. 控制面板仍读取 `FishnestProjection` / `fishnest.v_latest_*` SQL 投影视图。
3. 后续因果信息、任务信息、方法信息等实时写入数据库，必须从各自正式提交点接入，数据库写入只能作为投影 / 审计副本，不能绕过领域动作和状态提交链。
4. 本切片不实现因果 / 任务 / 方法实时写库业务表和触发点。
```

## 3. 后续实时写库接入原则

```text
1. 因果信息：从动作动态 / 因果账本正式提交链路写数据库投影，不新造权威因果结构。
2. 任务信息：从任务管理线程状态推进和任务虚拟存在维护链路写数据库投影，自我线程不得裸写任务状态。
3. 方法信息：从方法头、方法虚拟存在、条件结果对、方法状态和方法动作动态提交链路写数据库投影。
4. 写库失败必须记录错误并保留原领域事实状态；不得用数据库写入成功替代业务事实闭环。
```
