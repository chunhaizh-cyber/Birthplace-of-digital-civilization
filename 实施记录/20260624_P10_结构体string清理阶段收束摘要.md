## 1. 阶段结论

P10 结构体 / string 清理当前可执行轮已告一段落。

当前口径：
- 主键 / ID / 键 / 句柄类 string 排除，不作为结构体清理目标。

- 非主键 string / 摘要 / 原因 / 说明 / 等待原因类字段若进入机器判断，必须继续清理或替换为具体结构化特征、枚举、方向、主键或句柄。
