# S6-N2a-P3 扫描 / 跟踪提交入口实施记录

日期：2026-06-02

## 1. 目标

```text
在 P1 外设提交包结构化承载和 P2 自我外设组织方法壳之后，新增两个正式提交入口：
    提交_观察存在特征值变化事实；
    提交_指定存在跟踪事实。

提交入口只消费自我组织后的扫描 / 跟踪结果场景和确认后的事实输入，
不直接消费外设提交包，不写需求满足，不写安全值。
```

## 3. 边界结论

```text
提交_观察存在特征值变化事实：
    读取外设扫描结果场景状态；
    读取当前观察存在；
    读取观察存在变化结果；
    条件齐备时写入存在当前特征状态、存在特征变化动态和已识别区域扫描入账状态；
    条件不足时写条件不足状态。

提交_指定存在跟踪事实：
    读取目标存在；
    读取外设跟踪结果场景状态；
    条件齐备时写入目标存在跟踪状态、目标存在特征变化动态和目标观察窗口状态；
    条件不足时写条件不足状态。

两个入口都不直接消费外设提交包；
两个入口都不写需求满足；
两个入口都不写安全值；
两个入口都不把外设特征值脱离区域 / 存在 / 场景 / 任务输入 / 因果模板直接入账为安全意义。
```
