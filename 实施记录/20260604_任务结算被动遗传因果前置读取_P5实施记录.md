## 1. 目标

```text
任务状态=已结算 或 任务完成后结算资格成立
```

## 2. 代码对账结论

已确认 `结算叶子任务价值` 仍不进入普通筹办候选：

```text
任务模块.筹办.ixx:
    候选集填充跳过任务完成后处理方法；
    已绑定方法跳过任务完成后处理方法；
    结算叶子任务价值普通筹办已拦截。
```

已确认主链为：

```text
私有_提交任务已结算状态_线程侧
-> 读取任务状态动作动态
-> 任务价值反馈结算被动因已形成
-> 确认 任务状态=已结算 -> 结算被动果 的遗传因果模板
-> 调用 自我_结算叶子任务价值
-> 用 D2 结算动作动态增强被动遗传因果
```

## 3. 本轮修改

文件：`自我线程模块.impl.cpp`

1. 增加 `私有_确保任务结算被动遗传因果_线程侧` 的前置声明。
2. 在 `私有_处理任务价值反馈_线程侧` 中，任务已结算状态动态形成后、调用 `结算叶子任务价值` 之前，先确认 / 确保结算被动遗传因果模板。
3. 若遗传因果模板缺失或创建失败，结算链报错返回，不进入结算本能方法。
4. 新增日志锚点：

```text

来源=遗传因果信息组
被动因=任务虚拟存在.任务状态=已结算
承接=任务完成后结算资格成立
自动果=结算叶子任务价值被动果出现/安全服务值账务变化
动态职责=结算前读取遗传因果信息组
```

5. 将结算被动规则的 `承接条件描述` 补为：

```text
任务完成后结算资格成立
```
