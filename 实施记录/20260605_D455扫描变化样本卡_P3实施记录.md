# D455 扫描变化样本卡 P3 实施记录

日期：2026-06-05

## 当前切片

计划：`计划/20260604_外设三分法真实D455样本实施切片计划_v0.1.md`

切片：P3 已识别区域扫描变化样本。

目标：

```text
建立扫描变化报告的最小样本卡：
    来源已识别区域 / 已确认存在；
    上一状态；
    当前状态；
    变化摘要；
    未解释变化；
    需重识别区域；
    失败原因。
```

边界：

```text
扫描报告只处理已识别区域 / 已确认存在的变化；
不得替代全场景明确；
不得写安全结论；
首次扫描没有可比历史时，只能生成发现存在 / 发现特征事实候选或首帧基准说明；
不得伪造成变化动态。
```

## 预测

对账前预测：

```text
1. 外设观察报告队列中已有 扫描变化报告 和 扫描提交包 结构；
2. D455 线程中已有从逐簇识别报告生成扫描变化报告的代码；
3. 当前命令行单帧样本卡只输出 D455材料包证据卡 和 D455逐簇识别样本卡；
4. 当前还没有 D455扫描变化样本卡 摘要函数；
5. 因此真实 `--d455-capture-once` 预计不会输出扫描变化样本卡；
6. 补齐后，单帧命令若没有上一帧基准，应输出扫描变化样本卡但标明 首帧基准 / 缺可比历史，不得写成变化动态已生成。
```

必查日志 / 输出：

```text
外设线程_D455深度相机/单帧材料包证据卡
外设线程_D455深度相机/单帧逐簇识别样本卡
外设线程_D455深度相机/单帧扫描变化样本卡
D455扫描变化样本卡
首次扫描
首帧基准
变化动态
安全结论
```

禁止出现：

```text
把扫描变化报告当全场景明确；
把首次扫描写成变化动态；
把 D455 材料直接写安全 / 服务值；
伪造样本或使用夹具样本。
```

## 本轮实施

代码改动：

```text
1. 外设观察报告队列新增 构造D455扫描变化样本卡摘要；
2. 扫描提交包在缺少上一帧逐簇识别基准时将 上一帧ID 收束为 0；
3. D455 首帧扫描变化报告不再把当前观察簇计入 新增观察像素簇数量；
4. 自然 D455 线程在扫描变化报告入队后追加 扫描变化样本卡 日志；
5. --d455-capture-once 单帧真实命令同步输出 单帧扫描变化样本卡；
6. 单帧命令使用命令上下文生成扫描报告，不创建、不提交外设观察等待项。
```

口径：

```text
首帧基准：
    只输出发现存在 / 发现特征候选口径；
    不生成变化结论。

有可比历史：
    才输出新增 / 消失 / 变化计数作为扫描变化候选材料。

扫描样本卡：
    只读展示扫描变化材料；
    不确认全场景明确；
    不写安全结论。
```

## 追加自然扫描预测

```text
命令：
    .\x64\Debug\鱼巢.exe --self-check-log --self-check-log-wait-ms=30000

预测：
    1. 若当前自检 / 需求链触发 D455 扫描等待项，自然 D455 线程会输出 扫描变化报告入队；
    2. 首个扫描报告若缺少上一帧逐簇识别基准，应输出 状态=首帧基准；
    3. 第二个及以后扫描报告若已有可比历史，应输出 状态=有可比历史；
    4. 若本轮未触发 D455 扫描等待项，则不伪造样本，只保留单帧首帧基准验收证据，并把可比历史变化样本留给自然等待项触发后复验。
```
