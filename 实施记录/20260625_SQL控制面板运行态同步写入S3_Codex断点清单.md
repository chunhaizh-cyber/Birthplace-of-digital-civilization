设计口径：

```text
1. 只在任务类合法状态写入成功后同步 SQL 显示镜像。
2. SQL 写失败只写日志和 SQL 同步状态诊断，不回滚任务状态。
3. 任务状态仍由任务管理线程和任务域提交入口裁决；SQL 同步不是状态来源。
4. 为保证同步接口有运行批次，自我环境初始化成功后本进程一次性初始化运行态 SQL；失败不影响业务初始化返回值。
```
