# 20260610 服务值动态衰减与服务意识强化规则规范修订 Codex 断点清单

## 当前切片

根据用户修正口径，将服务值从固定衰减或单纯结算累积模型，提升为“服务值动态衰减与服务意识强化规则”：服务值随时间自动衰减，衰减率由安全值、距离上一次成功服务事件的时间间隔、服务当前值共同决定；成功服务事件只能饱和增长服务值，不得导致服务值越界或溢出。

## 禁止修改范围

- 不改代码。
- 不把服务值衰减解释为惩罚、遗忘、信用下降或服务质量变差。
- 不让服务值下降反推服务意识下降；服务值下降应作为服务意识重新唤醒条件。
- 不允许普通无界加法写服务值。
- 不把服务值衰减产生的服务意识直接写成服务对象、服务目标、服务结果或服务值结算证据。

## 当前判断

现有规范已经限定服务值增加必须来自可验证的人类服务对象改善，但缺少动态衰减和服务意识调谐规则。需要补齐：`0 <= S <= Smax` 边界、成功服务事件饱和增长、时间自动衰减、动态衰减率公式、安全值调节、服务间隔调节、当前值调节、服务意识与服务值分离，以及防溢出安全加法要求。
