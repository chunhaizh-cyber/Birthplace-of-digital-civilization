## 3. 代码改动口径

在 `场景体素模块.ixx` 中新增纯计算 helper：

```text
结构_正立方体体素包围盒规格

体素局部包围盒边界压紧
检查正立方体体素包围盒
```

实现边界：

```text
只读取输入尺寸或 VecIU64 占据位块。
只返回结构化检查结果。
不写世界树事实。
不创建存在。
不生成方法动作动态。
不改变已有三维体素链写入格式。
```

关键规则：

```text
按来源分辨率：8*64 -> N=64。
有效占据区：1..N-2。
完整存在最长方向最大占据格数：N-2。
按占据尺寸建盒：N = 最大占据尺寸 + 2。
外边界任一占据位为 true -> 触碰外边界，不是完整候选。
局部包围盒压紧只要求六个边界面各有占据支撑，不要求六面填满。
```
