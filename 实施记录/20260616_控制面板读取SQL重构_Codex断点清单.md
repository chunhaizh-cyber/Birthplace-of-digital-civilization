# 20260616 控制面板读取 SQL 重构 Codex 断点清单

## 0. 恢复摘要

当前切片目标：重构控制面板静态 HTML 生成入口，使控制面板数据从 SQL Server 最新读模型读取。

边界：

```text
1. `--panel-html` 不再为了生成控制面板而初始化自我环境或读取 live 控制面板快照。
2. 控制面板静态 HTML 的数据源收束为 `FishnestProjection` 中的 `fishnest.v_latest_*` 视图。
3. SQL 仍是控制面板查询投影，不是世界树、任务树、动作动态链的权威写入口。
4. 本切片不改 WebView2 动态展开 / 刷新接口，避免在同一切片里把 SQL 读源和 live 指针展开混成一套机器路径。
```

已读依据：

```text
规范/禁止性规范20260611.md
规范/规范目录.md
计划/计划索引.md
说明书/函数功能说明文档.md
控制面板类.ixx
控制面板类.cpp
鱼巢.cpp
tools/sql_projection/fishnest_sql_projection.py
```

预测：

```text
1. `.\x64\Debug\鱼巢.exe --panel-html` 应直接查询 SQL 并生成 控制面板.html。
2. 控制面板.html 应出现 SQL 批次、SQL 读模型、线程信息、面板指标、动作动态/因果边等来自 SQL 视图的内容。
3. 运行日志不应再出现 `鱼巢::main/控制面板/HTML` 对应的自我环境初始化路径。
```

## 1. 本切片实际修改

```text
1. 控制面板类.ixx：
   - 新增 `保存控制面板HTML(const std::filesystem::path& 输出路径)` 声明。
2. 控制面板类.cpp：
   - 新增 SQL 读模型结构 `结构_SQL控制面板数据`。
   - 新增 SQL 查询脚本生成、临时文件、sqlcmd 调用、输出拆分和 HTML 生成辅助函数。
   - 新增 `保存控制面板HTML(const std::filesystem::path&)`，从 SQL Server 最新投影视图读取数据后生成 HTML。
3. 鱼巢.cpp：
   - `--panel-html` 分支不再初始化自我环境，也不再读取 live 控制面板快照。
   - `--panel-html` 改为调用 SQL 读模型版本的 `保存控制面板HTML(输出路径)`，控制台输出追加 `来源=SQL`。
4. 说明书/函数功能说明文档.md：
   - 已重新生成，包含 SQL 控制面板新增函数条目。
```

## 3. 当前判断

```text
1. 静态控制面板生成入口 `--panel-html` 已改为读取 SQL Server 投影视图。
2. 当前生成页面包含来自 SQL 最新批次的线程信息、动作动态、因果边、特征类型和字段目录。
3. 本切片没有把 SQL 作为世界树、任务树或动作动态链的写入口；SQL 仍是查询投影。
4. WebView2 动态刷新、展开和详情接口仍是后续单独迁移范围，本切片不宣称动态控制面板已全部改为 SQL。
5. 浏览器直接打开 `file://D:/鱼巢/控制面板.html` 被 Browser 安全策略拦截，未做绕过；本切片浏览器渲染核验未完成。
```

## 4. 后续切片建议

```text
1. 迁移 WebView2 动态刷新接口：
   - 读取控制面板页面刷新JSON
   - 读取控制面板节点子项JSON

2. 把动态控制面板的数据契约统一到 SQL 读模型，避免 live 快照和 SQL 投影在同一 UI 路径混用。
3. 若需要浏览器视觉核验，改由后续明确允许的本地 HTTP 静态服务入口验证，不在本切片绕过 file URL 策略。
```
