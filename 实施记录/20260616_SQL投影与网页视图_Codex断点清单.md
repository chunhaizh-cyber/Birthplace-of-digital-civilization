## 0. 恢复摘要

当前切片目标：把项目基础信息与运行结果做成 SQL Server 查询投影，并生成可打开的网页快照。

边界：

- SQL 只作为查询投影与复验索引，不替代世界树、需求树、方法树或动作动态账本。
- 动作动态和因果信息仍以现有运行链路为权威来源。
- 本切片不修改 C++ 运行主路径，不新增本能方法，不生成伪造动作动态。

依据文件：

- `规范/禁止性规范20260611.md`
