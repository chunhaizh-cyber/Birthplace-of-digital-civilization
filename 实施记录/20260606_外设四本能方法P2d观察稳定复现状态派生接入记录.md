# 外设四本能方法 P2d 观察稳定复现状态派生接入记录

## 目标

在 P2b 第一帧基准状态基础上，把 `自我_建立观察帧存在` 的观察存在三状态从固定 `待复现 / 未完成 / 待复验` 改为由已落账多帧融合材料派生。

## 修改

文件：

```text
自我动作实现.外设模块.ixx
```

改动：

```text
新增 观察多帧稳定最低评分 = 7000；
新增 结构_外设观察存在多帧派生状态；
新增 计算外设观察存在多帧派生状态；
写入自我观察帧存在摘要 改为写入派生后的：
    外设观察存在稳定复现状态；
    外设观察存在观察完成状态；
    外设观察存在可复验状态；
确认自我建立观察帧存在规格 补充稳定 / 部分稳定、已完成 / 部分完成、可复验 / 证据不足结果能力。
```

## 派生规则

```text
单帧或缺少融合材料：
    稳定复现状态 = 待复现；
    观察完成状态 = 未完成；
    可复验状态 = 待复验。

多帧融合材料成立但质量或稳定性不足：
    稳定复现状态 = 部分稳定；
    观察完成状态 = 部分完成；
    可复验状态 = 证据不足。

多帧融合材料、观察质量、融合有效率、融合稳定性和低稳定像素均达标：
    稳定复现状态 = 稳定；
    观察完成状态 = 已完成；
    可复验状态 = 可复验。
```

达标条件：

```text
观察帧组状态 == 1；
观察帧组帧数 >= 2；
融合依据帧集合状态 == 1；
融合深度毫米结构状态 == 1；
融合深度有效性结构状态 == 1；
多帧深度稳定性结构状态 == 1；
每像素深度方差结构状态 == 1；
融合深度有效像素数量 > 0；
观察帧质量诊断摘要 == 1；
帧质量评分 >= 5000；
深度有效率 >= 5000；
空间坐标有效率 >= 5000；
融合深度有效率 >= 5000；
融合深度稳定性平均值 >= 7000；
融合低稳定像素数量 <= 0。
```

## 边界

```text
没有启用 自我_执行多帧重采样并择优；
没有新增模拟测试、夹具测试、伪造入口或伪造动作动态；
没有把 D455 线程内部局部跟踪稳定写成全观察完成；
观察完成只代表本次观察帧存在在当前外设、当前视野和当前时间窗口内的材料状态；
不宣称观察自然业务链已通过。
```
