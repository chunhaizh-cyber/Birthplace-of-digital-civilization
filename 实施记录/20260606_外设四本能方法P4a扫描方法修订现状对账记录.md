## 代码现状

```text
确认自我扫描已识别区域规格：
    已声明 当前观察存在 / 历史观察存在 / 目标宿主 / 当前方法运行存在等形参；
    已声明 当前观察存在 条件特征；
    结果表已有 观察存在发现状态、观察存在变化结果、扫描入账状态、扫描基准特征状态、
    基准差异状态 / 值、目标存在特征值域状态和值域冲突状态。

自我_扫描已识别区域：
    通过 解析当前观察存在 取得当前存在；
    通过 解析历史观察存在 取得历史存在；
    当前存在 + 历史存在 同时存在时计算匹配关系、变化结果和变化事件；
    只有当前存在、没有历史存在时创建观察存在发现事实，日志写 首次扫描不写变化动态=1；
    未取得当前存在时执行失败。

提交_观察存在发现事实：
    只在上游扫描发现状态为 已发现 时成功；
    日志写 第一次扫描只写发现存在或发现特征事实=1、不写变化动态=1。

提交_观察存在特征值变化事实：
    需要扫描入账状态已生成且变化结果可读；
    首次扫描没有变化结果时不会成功提交变化事实。
```

## 已满足项

```text
1. 首次扫描路径没有进入计算观察存在变化结果 / 计算观察变化事件。
2. 首次扫描提交入口只承接发现事实，不写变化动态。
3. 扫描方法和提交入口日志均明确不写安全值、需求满足和外设提交包。
4. 扫描规格已具备基准差异和值域冲突正式特征的结果能力。
5. 扫描自身未写 当前场景特征值明确状态；对应事实提交入口另行处理识别对应闭合。
```

## 未闭合项

```text
1. 扫描入口只要求 当前观察存在，当前存在只需满足 已确认观察存在节点；
   尚未显式读取 外设观察存在自我归属状态 == 已归属 或 扫描可启动状态 == 1。

2. 识别阶段会写 外设观察存在自我归属状态 和 扫描可启动状态，
   但扫描阶段尚未把这些正式状态作为条件闸门消费。

3. 有历史存在且匹配后，即使变化状态为 未变化，扫描仍会生成变化结果 / 变化事件，
   提交_观察存在特征值变化事实 也可能把该结果提交为变化事实；
   这不满足“无变化只更新基准、时间和稳定计数”的 P4 口径。

4. 值域冲突当前主要由历史对应冲突推导；
   还没有针对目标特征值域的独立区间读取、超值域变化复验缺口或冲突动态拆分。
```

## 下一步拆分

```text
P4b：扫描入口已归属与扫描可启动闸门最小接入。
    在扫描规格中声明 外设观察存在自我归属状态 和 扫描可启动状态 条件；
    自我_扫描已识别区域 执行时读取当前存在 / 目标宿主 / 输出场景上的正式状态；
    未达到 已归属 或 扫描可启动=1 时失败并保留为条件缺口，不生成发现事实或变化结果。

P4c：无变化不提交变化事实最小接入。
    有历史但变化状态为 未变化 时，只更新基准、时间和稳定计数口径；
    不写 存在特征变化动态，不让 提交_观察存在特征值变化事实 成功。

P4d：目标特征值域冲突 / 复验缺口接入。
    独立读取目标特征值域；
    值域外变化进入冲突动态或复验缺口，不与普通基准差异混写。
```
