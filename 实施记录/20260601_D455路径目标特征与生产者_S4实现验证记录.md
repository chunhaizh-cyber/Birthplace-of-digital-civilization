## 1. 目标

本切片补齐 D455 观察确认路径中可比较目标特征、值域和合法生产者映射：

```text
外设观察材料可回查状态
外设像素簇候选验证状态
外设观察存在候选确认方案取得状态
已确认观察存在提交入账状态
当前场景存在集合明确状态
当前场景各存在特征值可读状态
```

边界：

```text
D455 只提供观察帧、报告、d455:// 句柄、ROI、掩码、点集、深度切片等观察材料；
观察材料不得直接等同于当前场景存在集合明确、风险明确或安全值增加；
当前场景各存在特征值可读 第一版只能写 部分可读 / 证据不足；
完整 可读 必须等 P4 的材料门定义后再写。
```

## 2. 代码落点

```text
特征类.cpp
    补外设观察材料可回查状态、当前场景存在集合明确状态等布尔特征初始化；
    补外设像素簇候选验证状态、已确认观察存在提交入账状态、当前场景各存在特征值可读状态等点状态值域。

需求类.cpp
    将上述目标纳入专用方法生产范围，避免由任务筹办、控制面板或只读快照隐式写入。

自我线程模块.impl.cpp
    将根必要条件目标映射到对应方法：
        外设观察材料可回查状态 / 外设像素簇候选验证状态 -> 自我_验证外设观察像素簇候选
        外设观察存在候选确认方案取得状态 -> 自我_确认外设观察存在候选
        已确认观察存在提交入账状态 / 当前场景存在集合明确状态 -> 提交_确认观察存在事实
        当前场景各存在特征值可读状态 -> 安全_评估当前场景安全性

任务模块.管理界面线程.impl.cpp
    外设等待项匹配目标补入上述 D455 路径目标特征。

自我动作实现.外设模块.ixx
    自我_验证外设观察像素簇候选 写入外设观察材料可回查状态和外设像素簇候选验证状态；
    自我_确认外设观察存在候选 读取新的外设像素簇候选验证状态，兼容旧的外设观察像素簇候选已验证状态；
    提交_确认观察存在事实 写入已确认观察存在提交入账状态、当前场景存在集合明确状态、当前场景各存在特征值可读状态；
    安全_评估当前场景安全性 写入当前场景各存在特征值可读状态的保守结果。
```
