# 世界树坐标读取接入自我边界 P3 修订记录

日期：2026-06-02

## 修订原因

用户指出 `世界树类` 中已经生成坐标转换函数。核查后确认：

```text
世界树类::读取存在场景绝对坐标
世界树类::写入存在场景绝对坐标
世界树类::计算场景绝对坐标_由参考存在相对坐标
世界树类::写入存在场景绝对坐标_由参考存在相对坐标
世界树类::计算场景绝对坐标_由相对坐标表
世界树类::写入存在场景绝对坐标_由相对坐标表
```

因此，自我边界链路不应再把“缺坐标转换函数”作为当前堵点。

## 本次修订

`自我动作实现.外设模块.ixx` 已接入已有世界树坐标接口：

```text
自我_建立最小自我边界参照：
    优先读取 世界树.自我指针 的 存在_场景绝对坐标；
    若可读，则通过 世界树.写入特征_I64 同步写入 自我_场景绝对坐标明确状态 / X / Y / Z 摘要；
    仍不把 ROI、像素簇或场景坐标本身当作自我边界。

自我_生成存在自我相对安全特征：
    自我坐标优先来自 世界树.自我指针 的 存在_场景绝对坐标；
    场景内各存在坐标统一通过 世界树.读取存在场景绝对坐标 读取；
    只有自我坐标、存在坐标和边界参照同时可读时，才生成相对距离、进入、接触、靠近和遮挡候选。
```

2026-06-02 二次修订：

```text
世界树类已存在特征值操作函数：
    世界树类::写入特征_I64
    世界树类::写入特征_指针
    世界树类::写入特征_VecU
    世界树类::读取特征_I64
    世界树类::读取特征_指针
    世界树类::读取特征快照

本轮新增的自我场景坐标摘要写入已改为直接调用 世界树.写入特征_I64；
不再把这一步表述为外设模块自建特征值写入口。
```

## 剩余边界

```text
1. 世界树坐标转换函数已存在，不能再记成缺口。
2. 世界树特征值读写函数已存在，不能再记成缺口。
3. 仍需真实运行中自我存在场景绝对坐标自然入账。
4. 自我_场景绝对姿态明确状态 仍未接入真实来源，本轮仅保留第一版平移换算。
5. 不把 D455 像素簇、ROI、权限边界或普通场景绝对坐标替代为自我边界。
```
