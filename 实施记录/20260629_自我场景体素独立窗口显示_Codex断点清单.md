## 4. R1 体素形状视频取证切片

用户新要求：
- 先通过视频证明已经获取到了存在的正确体素信息。

当前定位：
- 现有控制面板已经从自我所在场景只读同步场景体素快照，并把存在指针、体素特征指针、体素根句柄、原点和最小体素边长输出到 `voxels`。
- 但现有 `voxels` 只足以画“每个存在一个体素根盒 / 原点”，没有把三维体素模型根句柄对应的二分层链解码成占据体素块。
- 因此现有视频只能证明“读到体素根句柄”，不能证明“读到了正确体素构成形状”。

本切片预测：
- 只读遍历体素根句柄对应的特征值树，解析根节点、满块 / 叶子块和占据数量。
- 控制面板 JSON 增加每个存在的体素链元数据和占据体素块列表。
- WebGL 按解码占据块绘制体素形状；状态栏和体素列表显示根句柄、占据数、解码块数。
- 生成静态控制面板 HTML 后，通过浏览器录制自我场景页视频作为人工复核证据。

禁止宣称：
- 不把显示视频当作世界树事实来源。
- 不宣称 D455 观察链或扫描链闭合。
- 不宣称外部存在的坐标精校完成；视频只证明显示层按存在体素模型句柄解码并绘制局部体素形状。

已修改：
- `控制面板类.ixx`：`结构_控制面板自我场景体素复现项` 增加根层级、根边长、原始宽高深、根占据体素数、解码块数和体素块列表；新增显示用 `结构_控制面板自我场景体素块`。
- `控制面板类.cpp`：新增只读解码流程，从体素根句柄进入 `世界树.值池()`，解析三维体素根节点和子链满块 / 叶子块，转换为视频显示用场景坐标盒。
- `控制面板类.cpp`：`voxels` JSON 输出 `gridEdge`、`originalSize`、`occupiedVoxels`、`decodedBlocks` 和 `blocks`。
- `控制面板类.cpp`：WebGL 优先按 `blocks` 绘制体素形状，顶部状态显示“解码体素块 / 占据体素 / 体素存在”。
