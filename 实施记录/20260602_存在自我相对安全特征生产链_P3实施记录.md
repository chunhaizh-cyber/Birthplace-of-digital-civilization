# 存在自我相对安全特征生产链 P3 实施记录

日期：2026-06-02

## 目标

在已建立最小自我边界参照之后，补齐 `存在_自我相对安全特征明确状态` 的合法生产方法，使安全候选构造不再停在“没有生产者”。

## 本次实现

新增默认本能方法：

```text
自我_生成存在自我相对安全特征
```

新增自我场景坐标值字段：

```text
自我_场景绝对坐标X
自我_场景绝对坐标Y
自我_场景绝对坐标Z
```

需求目标生产者分级已调整：

```text
存在_自我相对安全特征明确状态 -> 专用方法生产
```

## 运行口径

方法读取：

```text
自我边界参照状态
自我_场景绝对坐标明确状态
自我_场景绝对坐标X/Y/Z
已确认观察存在集合
存在_场景绝对坐标明确状态
存在_场景绝对坐标X/Y/Z
自我_近身安全缓冲半径
自我_接触边界半径
```

满足条件时写入：

```text
存在_自我相对安全特征明确状态 = 已明确
存在_相对自我边界距离
存在_进入自我边界缓冲区候选状态
存在_接触自我边界候选状态
存在_靠近自我候选状态
存在_遮挡关键观察区域候选状态
```

缺条件时仅写：

```text
存在_自我相对安全特征明确状态 = 未明确
安全因果候选材料缺口数量
```

## 边界

本方法第一版只做平移距离换算，不接入姿态旋转，不启动外设线程，不把场景绝对坐标直接当安全候选，不写安全值或风险安全值。

当前默认运行仍会因缺自我场景绝对坐标真实来源而保持未明确；这是业务条件不足，不是构建失败。
