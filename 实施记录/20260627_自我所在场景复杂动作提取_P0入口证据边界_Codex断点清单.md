## 3. P1b 位置变化原子动态视图最小样本

### 3.1 预测

```text
输入：已入账场景动态目录中的动态节点。
处理：逐条读取动态双状态端点，再读取初始 / 结果状态的主体、特征和值。
命中条件：
    1. 初始状态和结果状态都存在；
    2. 初始 / 结果状态主体一致；
    3. 初始 / 结果状态特征一致；
    4. 特征语义类型命中位置变化类结构入口；
    5. 初始值和结果值不同；
    6. 动态仍可通过既有来源场景、时间段、来源低层动态等入口继续回查证据。
输出：位置变化原子动态候选节点列表。
禁止：不新增主信息字段、不新增动作提取持久结构、不读取原始外设报告或控制面板缓存、不把外部变化写成自我方法动作动态。
```

### 8.4 判断

```text
P2c 审计结论：当前没有可直接复用的二主体关系动态只读片段组入口。

已有能力边界：
    观察关系二次特征能承载主体 / 客体 / 关系名 / 来源动态 / 标量值；
    动态来源链可读取；
    同主体位置变化片段组和位置运动基元候选已形成只读样式；
    动态二次特征和聚合动态已有生成入口。

缺口：
    缺少把已入账观察关系二次特征按主体、客体、关系类型和时间连续性分组的只读视图；
    缺少关系类运动基元候选；
    接触、支撑、遮挡、开合、相对距离变化等关系事实来源仍未形成统一输入覆盖；
    自我相机位姿变化排除标记仍未覆盖。

下一步最小补口范围：
    在 动态类 内新增关系片段组运行期结构和只读读取函数；
    在 世界树类 内新增薄封装；
    只读取 二次特征主信息类::观察关系、所属场景、主体、客体、概念名称/类型、来源动态、来源时间段、标量值；
    不创建二次特征、不创建动态、不创建聚合动态、不生成复杂动作候选、不生成方法候选。
```
