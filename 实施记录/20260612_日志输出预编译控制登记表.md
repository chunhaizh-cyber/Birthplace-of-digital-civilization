## 3. 建议开关表

| 开关 | 默认 | 管控范围 | 关闭语义 |
| --- | --- | --- | --- |
| `鱼巢_开关_启用所有输出` | 1 | 所有普通输出分类的总开关 | 只关闭输出，不改变任务、需求、方法、世界树、因果账本和价值结算行为 |
| `鱼巢_开关_启用登记管理日志输出` | 继承总开关 | 运行链路、任务推进、状态登记、外设报告、控制面板摘要 | 不写登记日志；机器事实仍按原路径写入 |
| `鱼巢_开关_启用逻辑错误日志输出` | 继承总开关 | 错误、致命、异常、弹窗错误提示的日志文本 | 只关闭输出水位；不能删除检测、吞异常或把错误改成成功 |
| `鱼巢_开关_启用调试日志输出` | 继承总开关 | 耗时、采样、候选评分、中间统计、自检专项诊断 | 关闭后应尽量编译掉字符串构造 |
| `鱼巢_开关_启用控制台输出` | 继承总开关 | `std::cout`、`std::cerr` 命令行输出 | 不向控制台写用户可见文本 |
| `鱼巢_开关_启用调试器输出` | 继承总开关 | `OutputDebugStringW` | 不向调试器写文本 |
| `鱼巢_开关_启用UI直接提示输出` | 继承总开关 | 直接 `MessageBoxW` 和项目弹窗错误提示的 UI 弹出层 | 关闭 UI 弹出，不等于关闭逻辑错误检测 |
| `鱼巢_开关_启用项目弹窗错误` | 现有，1 | 当前项目弹窗错误局部开关 | P1 应挂到 `鱼巢_开关_启用UI直接提示输出` 下 |
| `鱼巢_开关_启用不允许空指诊断` | 现有，1 | 空指逻辑错误检测本身 | 不属于普通输出开关，不能为静默输出而关闭检测 |
| `鱼巢_开关_启用不允许空指弹窗` | 现有，继承项目弹窗错误 | 空指逻辑错误弹窗输出 | P1 应继续只控制弹窗输出 |
| `鱼巢_开关_启用自检日志入口` | 现有，1 | 自检专项日志入口 | P1 可复用或挂接到调试日志输出 |
