## 2. 现状证据

```text
动态类::读取位置变化运动基元候选：
    当前只输出 移动 / 停止。
    已能回查主体、参数特征、起止时间、最大端点变化量和证据动态集合。

扫描链路：
    自我动作实现.扫描.ixx 创建扫描空间位置变化动作动态，状态端点为 0 -> 变化量，起止时间同为 now。
    该动态可证明扫描方法造成了空间位置变化量事实，但不能直接计算真实速度、方向或上升 / 下降。

存在坐标写入链：
    世界树类::写入存在场景绝对坐标 -> 存在类::写入存在场景绝对坐标。
    现有实现写入存在_场景绝对坐标X/Y/Z 和明确状态，但未同步创建 X/Y/Z 坐标状态节点，因此后续场景动态事实目录缺少可复算轨迹的坐标轴状态迁移动态。
```

## 3. 根因判断

当前没有自然复杂动作候选，根因不是单纯样本少，而是前置事实材料不足：

```text
速度：
    需要带真实时间跨度的坐标状态迁移动态。
    当前扫描空间位置变化量动作动态起止时间同为 now，不能作为速度分母。

高度 / 上升 / 下降：
    需要正式存在场景绝对坐标 Y 轴状态迁移动态。
    当前坐标写入只更新特征，不生成 Y 轴状态动态，无法从场景动态目录只读提取。

同步移动：
    需要至少两个主体的同时间窗坐标轴动态，并且要有身份连续和自我姿态变化排除材料。
    当前仅有单主体移动 / 停止和通用关系基元，不能安全组合。
```

## 4. 本切片实现口径

最小补口：

```text
1. 在 世界树类::写入存在场景绝对坐标 成功后，为 X/Y/Z 坐标创建当前场景状态节点。
2. 首次坐标写入只建立基准状态；后续坐标轴值变化时由状态类既有刷新机制生成状态迁移动态。
3. 动态类::读取位置变化运动基元候选 在参数特征为 存在_场景绝对坐标Y 且片段单调增大 / 减小时，输出 上升 / 下降。
4. 不生成复杂动作候选，不生成方法候选，不创建稳定动作规则。
```
