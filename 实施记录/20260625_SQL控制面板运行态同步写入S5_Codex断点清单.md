# SQL 控制面板运行态同步写入 S5 断点清单

## 0. 恢复摘要

当前切片：S5 方法、语素、世界树、动态逐步接入。

本轮先选最小闭合范围：

```text
方法树初始化 / 方法首节点注册成功后，同步写入 SQL 控制面板当前方法显示项和事件流水。
```

依据：

```text
规范/方法动作动态硬规则规范20260512.md
规范/方法规范20260425.md
规范/任务筹办父方法与协作子方法链规范20260513.md
docs/工程图谱/01_任务需求方法闭环图谱.md
docs/工程图谱/08_事实来源与写入权限图谱.md
计划/计划索引.md
计划/20260625_SQL控制面板运行态同步写入计划_v0.1.md
```

边界：

```text
SQL 只作为控制面板显示镜像。
方法头、方法状态、条件节点、结果节点仍以方法类 / 方法虚拟存在 / 项目结构为权威源。
不得把 SQL 写入做成动作动态来源。
不得把任务筹办 / 方法候选筛选注册成方法动作。
SQL 写失败不得回滚方法树写入。
```

待执行：

```text
1. 检查方法类现有注册、创建和 SQL 投影函数。
2. 补齐方法类文件头部规则注释模块。
3. 增加方法显示项同步 helper。
4. 在方法首节点注册或结构创建成功后同步当前方法显示项。
5. 刷新函数说明文档。
6. 构建、真实运行和 SQL 查询验证。
```

## 1. 真实验证预测

```text
命令：.\x64\Debug\鱼巢.exe --self-check-log --self-check-log-wait-ms=5000
预测：
1. 程序退出码为 0。
2. 控制面板运行态 SQL 初始化发生在自我环境初始化前，方法注册期间已有运行批次。
3. [鱼巢].[当前方法显示项] 行数应大于 0。
4. [鱼巢].[控制面板事件流水] 应包含方法域新增或更新事件。
5. 日志中不应出现 `方法SQL控制面板同步失败`、`当前方法显示项`、ADO 写入错误。
```
