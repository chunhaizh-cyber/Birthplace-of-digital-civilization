## 1. 验证前预测

硬件前置命令：

```powershell
.\x64\Debug\鱼巢.exe --d455-capture-once
```

预测：

```text
若硬件当前可用，应退出码 0，并输出 D455 单帧材料包 / 逐簇识别 / 扫描变化样本卡相关日志。
该结果只证明硬件和单帧材料包可用，不作为 P4 业务闭合证据。
```

自然样本命令：

```powershell
.\x64\Debug\鱼巢.exe --self-check-log --self-check-log-wait-ms=60000
```

预测：

```text
若自然命中稳定子集扫描约束：
    1. 出现 `任务管理界面线程/稳定子集全量扫描等待项承接`。
    2. 出现 `扫描入账派生需求消息生成数量 > 0`。
    3. 自我线程派生需求入树。
    4. `提交_生成缺口子需求` 成功。
    5. 目标特征为 `已识别区域扫描入账状态`。

若自然样本未命中：
    只记录退出码、D455 前置状态、日志锚点计数和未命中原因；
    不伪造扫描样本，不用旧日志 / TSV / capture-once 替代自然业务证据。
```

禁止宣称：

```text
不宣称扫描需求自然生长闭合，除非本次真实运行命中上述业务锚点。
不宣称 D455 单帧成功等于内部治理自然长到外设需求。
不宣称自我苏醒完成或初步成熟完成。
```

### 2.2 当前判断

```text
本轮 P4 未进入自然样本验证窗口。
原因不是扫描链业务失败，也不是内部治理闭环失败；
而是当前 Windows 会话下鱼巢进程无法访问 D455 设备。
```

不继续执行 `--self-check-log --self-check-log-wait-ms=60000` 的原因：

```text
P4 本轮恢复前提是“真实外设自然样本”。
当前 D455 打开失败且系统未枚举到设备，继续跑自然窗口只能得到无外设样本窗口；
这不能推进 P4，也容易把硬件访问失败误记成自然业务未命中。
```

后续恢复条件：

```text
1. 当前 Windows 会话能枚举到 D455 / RealSense 设备；
2. `.\x64\Debug\鱼巢.exe --d455-capture-once` 退出码为 0；
3. 再执行 P4 自然样本窗口：
   `.\x64\Debug\鱼巢.exe --self-check-log --self-check-log-wait-ms=60000`。
```

禁止扩展：

```text
不切入外部动作提取。
不把 `No device connected` 解释为扫描需求自然生长失败。
不使用历史 D455 日志替代本轮真实外设样本。
```
