## 1. 验证前预测

硬件前置命令：

```powershell
.\x64\Debug\鱼巢.exe --d455-capture-once
```

预测：

```text
若硬件当前可用，应退出码 0，并输出 D455 单帧材料包 / 逐簇识别 / 扫描变化样本卡相关日志。
该结果只证明硬件和单帧材料包可用，不作为 P4 业务闭合证据。
```

自然样本命令：

```powershell
.\x64\Debug\鱼巢.exe --self-check-log --self-check-log-wait-ms=60000
```

预测：

```text
若自然命中稳定子集扫描约束：
    1. 出现 `任务管理界面线程/稳定子集全量扫描等待项承接`。
    2. 出现 `扫描入账派生需求消息生成数量 > 0`。
    3. 自我线程派生需求入树。
    4. `提交_生成缺口子需求` 成功。
    5. 目标特征为 `已识别区域扫描入账状态`。

若自然样本未命中：
    只记录退出码、D455 前置状态、日志锚点计数和未命中原因；
    不伪造扫描样本，不用旧日志 / TSV / capture-once 替代自然业务证据。
```

禁止宣称：

```text
不宣称扫描需求自然生长闭合，除非本次真实运行命中上述业务锚点。
不宣称 D455 单帧成功等于内部治理自然长到外设需求。
不宣称自我苏醒完成或初步成熟完成。
```

### 2.4 当前判断

```text
P4 本轮已越过“设备不可访问”前置。
D455 硬件、单帧材料包、稳定子集材料可以工作。

但 P4 业务闭合仍未通过：
    自然窗口没有出现稳定子集全量扫描等待项承接；
    没有扫描入账派生需求消息；
    没有自我线程围绕 `已识别区域扫描入账状态` 入树；
    没有 `提交_生成缺口子需求` 命中该目标特征。

当前停止点不是硬件问题，也不是外部动作提取问题；
而是“内部需求 / 任务链尚未自然生成可消费 D455 稳定子集材料的扫描入账承接”。
```

后续恢复条件：

```text
1. 自然运行中出现稳定子集全量扫描等待项承接；
2. 同一自然窗口中 D455 产生可承接稳定子集材料；
3. 出现扫描入账派生需求消息；
4. 自我线程派生需求入树；
5. `提交_生成缺口子需求` 成功；
6. 目标特征为 `已识别区域扫描入账状态`。
```

禁止扩展：

```text
不切入外部动作提取。
不把单帧 capture-once 成功解释为扫描需求自然生长闭合。
不把外设观察等待项或稳定子集材料本身解释为扫描入账派生需求。
不宣称自我苏醒完成或初步成熟完成。
```
