# 自我初始场景坐标锚点 S6-N2b 实施记录

日期：2026-06-02

## 目标

补齐自我存在场景绝对坐标的最小初始化生产入口，使自我边界方法能从 `世界树.自我指针` 读取自我存在的 `存在_场景绝对坐标`。

## 本次实现

```text
需求类.cpp：
    自我_场景绝对坐标明确状态 -> 初始化生产；
    自我_场景绝对姿态明确状态 仍保持待补齐。

世界树类.cpp：
    世界树类::取或创建自我存在 创建 / 取得自我存在后，
    若该存在尚无 存在_场景绝对坐标，
    写入 Vector3D{0,0,0} 作为自我初始场景原点坐标；
    坐标来源写为当前自我现实场景。
```

## 边界

```text
只写自我存在自身的初始场景绝对坐标。
不批量改写其他存在。
不写当前场景特征值明确状态、风险状态、安全值或服务值。
不把 D455 像素簇、ROI、权限边界或普通场景坐标替代为自我边界。
姿态仍未接入真实来源，本轮不硬写姿态。
```
