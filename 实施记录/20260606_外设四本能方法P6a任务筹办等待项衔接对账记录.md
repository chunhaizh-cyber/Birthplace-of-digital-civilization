## 对账结论

```text
1. 任务筹办候选选择主链仍符合规范：
   - 先由 解析或创建任务目标方法 填充 本轮候选方法集；
   - 再写入 回执.候选方法集 和 回执.当前方法；

2. 任务管理等待项生成位置正确：
   - 工作结果需要等待，或方法已执行但推进失败 / 错误码非 0 时才尝试；
   - 等待项只进入外设观察队列；
   - 日志仍记录 直接写需求树=0 / 直接写世界树=0。

3. 当前明确缺口：
   - 私有_外设观察需求口径_按方法供料要求 仍优先查旧结果能力：
       外设识别结果场景状态
       外设扫描结果场景状态
       外设跟踪结果场景状态
   - P1-P5 已把识别 / 扫描 / 跟踪收口为正式结果特征；
   - 当前四方法规格不再声明这些旧结果场景状态；
   - 因此等待项口径实际主要靠兼容本能ID兜底映射，不是正式结果能力优先命中。

4. 观察 / 验证入口仍没有单独等待项口径：
   - 这是 P0c 已记录残留；
   - 本切片先不扩大 enum 和运行模式；
   - P6b 先修正式结果能力映射，P6c 再评估观察 / 验证等待项是否需要单独口径。
```
