# SQL 控制面板运行态同步写入 S6 断点清单

## 0. 恢复摘要

当前切片：

```text
S6：控制面板读取运行态 SQL。
```

允许修改范围：

```text
控制面板类.cpp
说明书/函数功能说明文档.md
计划/20260625_SQL控制面板运行态同步写入计划_v0.1.md
计划/计划索引.md
实施记录/20260625_SQL控制面板运行态同步写入S6_Codex断点清单.md
```

禁止修改范围：

```text
控制面板.html
鱼巢.vcxproj
鱼巢.vcxproj.filters
```

边界：

```text
SQL 只作为控制面板显示镜像。
控制面板读取运行态 SQL 不反向写任务、需求、方法、世界事实或动态。
旧全量 SQL 投影只作为校准 / 对照路径，读不到时不得让运行态控制面板失败。
```

## 1. 真实验证预测

```text
1. 函数说明文档生成通过。
2. Debug x64 构建 0 警告 0 错误。
3. .\x64\Debug\鱼巢.exe --panel-html 退出码为 0。
4. 生成 HTML 中能看到运行态表入口：运行批次、同步状态、事件流水、当前任务、当前需求、当前方法、当前世界、当前动态。
5. 日志中不出现 `控制面板HTML生成失败`、`SQL 投影读取失败` 或 ADO 读取错误。
```

## 2. 实施结果

```text
1. `控制面板类.cpp` 已将运行态 SQL 表纳入控制面板读取数据：
   控制面板运行批次、SQL投影同步状态、控制面板事件流水、当前任务、当前需求、当前方法、当前世界、当前动态。
2. 旧全量 SQL 投影读取降级为校准 / 对照路径；运行态表读取成功时，旧投影读取失败只进入指标诊断，不阻断运行态控制面板。
3. 静态 HTML 菜单和区段刷新 JSON 已增加运行态页签：
   runtimeBatch、syncStatus、eventFlow、currentTasks、currentDemands、currentMethods、currentWorld、currentDynamics。
4. `私有_是SQL控制面板区段` 已同步加入这些页签 ID，避免 WebView2 分段刷新拒绝新增区段。
```
