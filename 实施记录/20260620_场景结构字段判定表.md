## 4. 当前结论

```text
1. 本切片只做 P2.1 判定表，不删除字段和结构体。
2. 场景节点主信息类字段总体属于场景归属引用和事实目录索引，不是任务 / 需求 / 结算权威业务字段。
3. 状态索引、动态索引、二次特征索引的权威事实分别在状态、动态和二次特征节点；场景字段只应作为事实目录缓存。
4. 关系索引 与 二次特征索引 存在同类型引用集合和双写路径，是下一切片 P2.2 的第一优先引用闭环问题。
5. 世界树场景坐标和轮廓查找结构当前是运行期 DTO，不直接持久化，也未发现文本字段承载机器逻辑；是否迁移归属留到世界树场景辅助函数归属审查。
6. 场景类后续需要补宿主存在、世界类型、状态 / 动态 / 二次特征索引快照与移除函数，避免系统逻辑继续直读 场景节点主信息类。
```
