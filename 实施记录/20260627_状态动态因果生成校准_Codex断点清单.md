### 1.1 状态生成入口清单

```text
状态类.cpp：
    状态类::创建状态(...)
        创建状态节点后追加到场景状态索引；
        调用 世界树.状态记录后刷新动态(场景, 节点, 刷新时间)。

    状态类::创建内部状态(...)
        经 创建状态(...) 统一入账；
        因此内部治理状态与输出场景中的内部状态也会走相邻动态刷新链。

世界树类.cpp：
    世界树类::创建状态(...)
    世界树类::创建内部状态(...)
        是状态服务包装入口。
```

当前判断：

```text
状态生成入口基本符合“状态先落主体 / 特征 / 值，再由状态后处理生成动态”的方向。
状态不是自由文本事件，动态也不是裸流程日志；动态主体来自结果状态宿主，动态特征来自结果状态特征。
```

### 1.2 状态 -> 动态入口清单

```text

        命中后调用 创建叶子动态(场景, 前状态, 新状态, now)。

    动态类::创建动态(场景, 初始状态, 结果状态, ...)
        写入 初始状态；
        写入 结果状态；
        写入 动态主体 = 结果状态主体；
        写入 动态特征 = 结果状态特征；
        写入 动态层级 = 0；
        写入 聚合方式 = 原子相邻。

    动态类::创建动态(场景, 主信息, 后处理选项)
        校验状态动态；
        去重相同状态动态；
        追加到场景动态索引；
        可触发 世界树.获取动态二次特征(*节点)。
```

当前判断：

```text
路径 A 已存在：
    状态 -> 相邻前状态 -> 状态迁移动态 -> 动态二次特征。

这条路径证明“某存在的某特征实际变了”，但不伪造来源动作。
若只有这条路径，不应进入任务筹办方法候选，只能形成状态变化因果 / 状态变化线索。
```

```text
    动作致变因果必须由动作来源 + 状态结果端点共同支撑。
```

### 3.3 相邻前态与首次状态处理


## 8. P4b 同源匹配口径修订

触发口径：

```text

    动作动态：动作执行期间记录动作过程。
```

```text

同源成立：
    E 一致；
    FT-X 一致；
    T0 <= Ta0；
    Ta1 <= T1。

允许采样误差 ε：
    T0 - ε <= Ta0；
    Ta1 <= T1 + ε。
```
