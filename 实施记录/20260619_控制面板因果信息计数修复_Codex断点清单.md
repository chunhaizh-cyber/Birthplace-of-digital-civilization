# 20260619 控制面板因果信息计数修复 Codex 断点清单

## 0. 恢复摘要

当前切片目标：修复控制面板 `因果信息` 页显示 `SQL 因果组合：16833；组成关系：67332` 的错误计数。

依据：

```text
规范/禁止性规范20260611.md
规范/规范目录.md
计划/计划索引.md
规范/因果信息用途与用法规范20260516.md
说明书/因果类说明.md
```

已复核证据：

```text
1. 控制面板当前 `因果信息` 页不是读世界树因果节点，而是从 `fishnest.runtime_event`
   中筛 `自我线程/初始因果模板入账` 日志，再按 `因比较 + 因方法 + 主果比较` 拼“因果组合”。
2. SQL 实测：
   `fishnest.v_current_world_tree_nodes` 总节点 12095，其中 `node_kind=N'因果'` 只有 5 个。
3. SQL 实测：
   这 5 个因果节点的世界树关系包括 `条件比较模板`、`果比较模板`、`主果比较模板`、`证据动态样本`，
   共 20 条。
4. 用户判断 `16833` 明显不对成立；该数字是日志事件组合数，不是世界树因果信息数量。
```

本次预期修改：

```text
1. `控制面板类.cpp`
   - `因果信息` 查询改为读取 `fishnest.v_current_world_tree_nodes WHERE node_kind=N'因果'`。
   - `因果信息关系` 查询改为读取这些因果节点在 `fishnest.v_current_world_tree_relations` 中的组成关系。
   - 页面标题从 `SQL 因果组合` 改为 `SQL 世界树因果节点`。
```

禁止宣称：

```text
不宣称 SQL 投影覆盖全部历史因果。
不宣称因果信息用途链全部闭环。
不宣称内部循环完成、自我苏醒完成或初步成熟完成。
```
