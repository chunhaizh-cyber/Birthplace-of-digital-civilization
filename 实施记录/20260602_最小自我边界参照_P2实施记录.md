# 最小自我边界参照 P2 实施记录

日期：2026-06-02

## 目标

优先实施 `计划/20260601_自我关键特征负向变化定义因果纠偏计划_v0.1.md` 的 P2：补齐“自我边界由哪个特征 / 存在 / 状态节点承载”的最小可表达参照。

## 本次实现

新增默认本能方法：

```text
自我_建立最小自我边界参照
```

该方法通过方法动作动态写入事实，优先将 `自我边界参照` 子存在挂到 `世界树.自我指针` 下；若运行时没有自我指针，才退到目标宿主。

新增或接入的承载字段：

```text
自我边界参照存在
自我边界参照状态
自我边界定义版本
自我相对视图坐标系状态
自我_场景绝对坐标明确状态
自我_场景绝对姿态明确状态
自我_近身安全缓冲半径
自我_接触边界半径
自我_边界完整性状态
```

默认值口径：

```text
自我边界参照状态 = 已建立
自我相对视图坐标系状态 = 已建立
自我_场景绝对坐标明确状态 = 条件不足
自我_场景绝对姿态明确状态 = 条件不足
自我_边界完整性状态 = 未评估
自我边界定义版本 = 1
自我_近身安全缓冲半径 = 1000
自我_接触边界半径 = 0
```

## 边界

本切片只建立自我边界参照承载，不把 D455 像素簇、ROI、权限边界或场景绝对坐标直接当自我边界。

本切片不写入：

```text
自我安全值
自我风险安全值
存在_自我相对安全特征明确状态 = 已明确
当前场景安全度明确状态
基础风险判断状态 = 已明确
```
