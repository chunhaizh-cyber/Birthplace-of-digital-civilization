# S6-N2a-P10 安全评估聚合写权剥离实施记录

日期：2026-06-04

## 1. 本轮目标

先剥离 `安全_评估当前场景安全性` 对风险安全层聚合结果的写权。

本轮不删除风险安全层特征词条；这些词条仍由自我线程聚合器写入。

## 2. 代码落点

文件：

```text
自我动作实现.外设模块.ixx
```

改动：

```text
1. 安全评估方法结果表不再声明风险安全层因素集合版本、因素数量、缺失数量、候选、投影、可聚合状态、已入账状态和风险因素计数字段。
2. 安全评估运行结果不再把场景影响候选直接等同为风险安全层候选。
3. 安全评估输出结果场景不再写风险安全层聚合字段。
4. 日志改为记录“风险安全层聚合由自我线程=1 / 外设方法不写风险安全层候选=1”。
```

保留：

```text
风险安全_场景影响部分候选；
风险安全_场景影响部分可结算状态；
风险安全_场景影响部分不可结算原因；
风险安全_场景影响部分已入账状态；
风险安全_场景影响部分变化方向。
```

这些是场景影响因素材料，不是风险安全层聚合结果。


## 4. 当前阻塞

自我线程仍在遗传模板初始化阶段固定生成 5 个风险安全层组成因：

```text
风险安全_场景影响部分已入账状态；
风险安全_运行影响部分证据搜索状态；
风险安全_资源影响部分证据搜索状态；
风险安全_权限影响部分证据搜索状态；
风险安全_未知影响部分证据搜索状态。
```

直接删除这组初始化会使安全根路径失去冷启动来源。

继续前需要补上：

```text
风险安全层组成因集合的遗传模板来源；
或从已入账遗传因果信息读取组成因集合的接口。
```
