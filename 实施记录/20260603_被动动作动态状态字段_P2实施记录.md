## 1. 本次目标

本切片只补最小动态结构能力：

```text
1. 统一方法动作动态入口可以携带初始状态 / 结果状态。
2. 任务状态提交动态写入旧任务状态 / 新任务状态。
3. 结算 D2 动态写入旧安全/服务值 / 新安全/服务值。
```

本切片不做：

```text
1. 不重排结算顺序。
2. 不把结算改回普通任务链。
3. 不处理同一任务满足多个需求的扫描。
4. 不直接接 D2 到按动态创建因果信息。
```

## 3. 修改内容

### 3.1 创建方法动作动态支持状态迁移

修改：

```text
动态类::创建方法动作动态 增加可选参数：
    初始状态
    结果状态
```

效果：

```text
原有调用点不传状态时保持原行为。
需要表达状态迁移的被动动作，可以显式把状态节点写入动态主信息。
```

### 3.2 任务状态提交动态补状态字段

修改：

```text
输出任务状态提交动作动态 不再丢弃 旧状态 / 新状态。
它会在任务虚拟存在上创建：
    任务状态旧状态节点；
    任务状态新状态节点；
并传给 创建方法动作动态。
```

效果：

```text
任务状态动作动态现在可以回解任务虚拟存在的任务状态迁移。
后续 P3 可以把 `任务虚拟存在.任务状态 = 已结算` 作为结算被动因证据。
```

### 3.3 结算 D2 动态补状态字段

修改：

```text
输出叶子任务价值结算动作动态 已经创建旧值 / 新值状态。
本次把这两个状态传给 创建方法动作动态。
```

效果：

```text
安全 / 服务结算 D2 动态现在可以回解：
    旧安全值 -> 新安全值；
    旧服务值 -> 新服务值。
```
