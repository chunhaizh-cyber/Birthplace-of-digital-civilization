## 现有实现

```text
正式特征 / 状态已存在：
    目标存在特征值域状态：
        未读取 / 值域内 / 冲突 / 证据不足
    已归属存在特征值域冲突状态：
        无冲突 / 有冲突 / 证据不足
    已归属存在特征值域冲突动态
    外设观察存在可复验状态：
        待复验 / 可复验 / 证据不足
    补观察缺口状态、补观察缺失原因、补观察需求建议

扫描变化上下文已有字段：
    目标特征值域状态
    值域冲突状态

计算观察存在变化结果：
    历史对应状态=已匹配 且 当前 / 历史均有效时：
        目标特征值域状态=值域内；
        已归属存在特征值域冲突状态=无冲突。
    历史对应状态不是已匹配时：
        当前 / 历史均有效则写：
            目标特征值域状态=冲突；
            已归属存在特征值域冲突状态=有冲突。
        当前 / 历史材料不完整则写证据不足。

自我_扫描已识别区域：
    会把目标特征值域状态和值域冲突状态写到运行存在、输出场景、目标宿主、当前存在和变化结果；
    当值域冲突状态=有冲突且存在实际变化时，会写 已归属存在特征值域冲突动态。
```

## 未闭合点

```text
1. 目标存在特征值域状态=值域内 目前是历史匹配成功后的默认结论，
   不是从“目标特征值域区间 / 特征类型稳定值域”独立读取后得到的结论。

2. 当前扫描摘要只读取几何 / 距离类基础值：
       中心坐标、AABB、尺寸、距离
   没有读取“目标特征类型”和对应值域区间。

3. 超值域变化当前没有扫描专用复验缺口输出；
   代码已有 外设观察存在可复验状态、补观察缺口、派生需求 helper，
   但 自我_扫描已识别区域 冲突分支没有调用。

4. P4c 后无变化不再提交变化事实；
   但“冲突 / 不确定”仍作为实际变化并可能写冲突动态，这一层需要进一步区分：
       可确认的值域外冲突
       需要复验 / 补观察的证据不足
```

## 下一步拆分

```text
P4e：扫描冲突分支复验缺口最小接入。
    在 自我_扫描已识别区域 中，当值域冲突状态=有冲突 或 目标特征值域状态=冲突 时：
        写 外设观察存在可复验状态=待复验；
        写 补观察缺口状态=1；
        写 补观察需求建议=重新取得观察特征帧 / 缩小 ROI 重新观察；
        写派生需求目标为 外设观察存在可复验状态 -> 可复验。

P4f：目标特征值域区间独立读取方案。
    另行确认“扫描当前特征”到底应绑定哪一个目标特征类型；
    再接入真实目标特征值域读取，不用几何匹配成功替代值域判断。
```
