# S6-N2a-P8 可观测单位存在对应事实提交入口实施记录

时间：2026-06-02

## 目标

实现两个正式提交入口：

```text
提交_当前观察范围可观测单位存在对应事实
提交_观察存在发现事实
```

边界：

```text
识别只入账当前观察范围可观测单位到存在的对应事实；
识别不产生被观察存在状态和动态；
稳定对应存在数量 >= 1 只写扫描可启动状态；
第一次扫描由 提交_观察存在发现事实 写发现动态；
提交_观察存在发现事实 不写变化动态；
两个入口都不写需求满足、安全值或服务值。
```

## 改动预测

```text
1. 构建 Debug x64 应通过。
2. 新本能方法 ID 6150 / 6151 应能完成默认方法登记、规格确认、内部执行注册和动作 wrapper 转发。
3. 当前观察范围有效可观测单位数量、已稳定对应存在可观测单位数量、未稳定对应存在可观测单位数量、多重对应冲突可观测单位数量、稳定对应存在数量 应按数值事实登记，不压成 0/1。
4. 当前观察范围可观测单位存在对应事实提交成功后，应写：
       当前观察范围可观测单位存在对应事实提交状态；
       当前观察范围有效可观测单位计数事实取得状态；
       当前观察范围可观测单位存在稳定对应事实取得状态；
       稳定对应存在数量明确状态；
       当前观察范围可观测单位存在对应闭合状态；
       当前场景特征值明确状态；
       扫描可启动状态。
5. 真实运行自然链若尚未触发新提交入口，只记录“入口已实现但自然链未观察到”，不把未触发误判为业务失败。
```

## 实施结果

```text
已新增本能方法：
    提交_当前观察范围可观测单位存在对应事实 = 6150
    提交_观察存在发现事实 = 6151

已接入：
    默认本能方法登记；
    内部本能函数执行闭环；
    规格确认 wrapper；
    外部动作执行 wrapper；
    任务筹办 / 自检练习目标排除。

提交_当前观察范围可观测单位存在对应事实：
    只消费已组织的外设识别结果场景和已提交确认观察存在事实；
    写当前观察范围有效可观测单位数量、稳定对应数量、未稳定数量、冲突数量、稳定对应存在数量；
    写可观测单位到存在映射表和对应闭合状态；
    稳定对应存在数量 >= 1 时写扫描可启动状态；
    不写需求满足、不写安全值、不写被观察存在状态动态。

提交_观察存在发现事实：
    只消费已组织的外设扫描结果场景和当前观察存在；
    写观察存在发现事实、观察存在发现状态、观察存在发现动态；
    第一次扫描只写发现动态；
    不写变化动态、不写需求满足、不写安全值。
```
