# 20260628 世界树 SQL 存储过程重构 Codex 断点清单

## 0. 恢复摘要

当前切片按用户最新口径重构世界树 SQL 投影存储过程：

```text
世界树是一棵大树；
根链上的各类子树仍属于这棵大树的一部分；
不再把根链子树复制成旧的“根树”派生存储；
显示摘要不入数据库底层表。
```

本切片只处理 SQL 投影 / 控制面板查询镜像，不改变世界树本体结构，不改变世界树事实写权。

## 3. 已完成修改

1. `世界树节点` 底层表收束为一棵大树的结构行：
   - 快照、行号、节点主键、父节点主键、深度、同层序号、直接子数量、路径文本。
2. `世界树节点关系` 只存主信息引用关系：
   - 宿主、目标、关系名、目标类别、序号；
   - 不再存 `目标文本`。
3. 删除旧 `世界树根树`、`世界树根树节点`、`世界树根树节点主信息`、`世界树根树关系` 的创建和写入逻辑；建表脚本只保留清理旧表 / 旧视图的删除语句。
4. 新增主信息大类分表：
   - 指代、抽象特征、特征、存在、场景、状态、动态、二次特征、因果、语言记录、其他。
5. 主信息分表只存底层字段：
   - `主信息类型值`、`名称主键`、`类型主键`；
   - 特征 / 状态值拆为值类型、I64、VecU 句柄、指针句柄列；
   - 场景、动态、因果等只存枚举值、计数、时间、句柄或数值字段。
6. `当前世界树节点`、`当前世界树关系` 视图保留旧查询列，但显示列只在视图中临时派生，不写入底层表。
7. 字段恢复比对改为验证：
   - 快照；
   - 一棵大树节点结构；
   - 主信息共性字段；
   - 节点引用关系。
