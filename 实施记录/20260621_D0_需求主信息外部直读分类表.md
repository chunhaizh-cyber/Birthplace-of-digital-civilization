## 2. 分类口径

| 类别 | 判定标准 | 处理 |
| --- | --- | --- |
| 机器逻辑必须回迁 | 用 `需求->主信息.*` 直接决定状态解析、候选、权重、满足、派发、重筹办或结算 | 改为调用 `需求类` 只读函数；缺函数先补 `需求类` |
| 显示 / 日志 / SQL 投影 | 只用于控制面板、摘要、日志输出、SQL 查询投影 | 后置；不得反向成为机器决策来源 |
| 可复用需求类函数 | 已有 `读取需求目标特征类型`、`生成任务初始化上下文`、`来源需求有安全方向` 等 | 优先复用，不重复造入口 |
| 缺需求类函数 | 状态引用、需求场景、权重读取等无统一只读边界 | 本计划 P0 补最小 helper |
| 跨类缺口 | 需求类自身解释状态 / 特征 / 二次特征 / 世界树主信息 | 登记到对应类纠偏计划，按“缺哪个类补哪个类第一优先”处理 |
