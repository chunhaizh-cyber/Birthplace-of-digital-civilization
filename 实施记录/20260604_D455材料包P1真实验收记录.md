# D455 材料包 P1 真实验收记录

日期：2026-06-04

## 1. 预测

```text
若真实 D455 条件具备：
    --d455-status 应能返回运行时 / 设备路径可用；
    --d455-capture-once 应能采到真实帧；
    D455 材料包证据卡应显示帧号、尺寸、d455:// 材料句柄、观察簇、质量和失败原因字段；
    不得构造假帧或伪造动作动态。
```

## 2. 条件检查

```text
结果：
    退出码=0；
    状态成功；
    相机当前未打开，但 D455 路径可用。

结果：
    退出码=0；
    单帧采集成功；
    尺寸=640x480；
    深度帧号=1；
    彩色帧号=9。
```

## 3. 业务触发检查

```text
命令：
    .\x64\Debug\鱼巢.exe --self-check-log
    默认运行 45 秒后输入 退出

结果：
    两个入口均未触发 D455 外设线程报告入队；
    运行日志只出现 外设观察等待项创建延后；
    原因是当前自然任务流没有提交实际 D455 等待项。
```

这不是 D455 硬件条件缺失，而是自然任务流当轮没有走到外设等待项提交。
