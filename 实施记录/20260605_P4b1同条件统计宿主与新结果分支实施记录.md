# P4b1 同条件统计宿主与新结果分支实施记录

## 执行目标

按计划索引继续执行 P4b，优先处理已经能从规范和代码中确定的口径：

```text
同一条件统计宿主；
新结果分支数量特征；
练习好用闸门的量化条件。
```

## 修改内容

### 1. 同条件统计宿主

`自我动作实现模块.ixx` 中新增：

```text
条件统计宿主_条件结果对归并
```

宿主选择为：

```text
条件节点 -> 条件节点信息.条件场景
```

原因：

```text
方法节点不是世界树基础信息节点，不能直接写特征；
条件场景是基础信息节点，且创建于目标方法虚拟存在之下，能够同时表达方法隔离和同一条件。
```

### 2. 条件结果对归并统计

归并时现在写入条件场景：

```text
样本次数
最近样本时间
结果符合次数
结果不符合次数
新结果分支数量
```

方法虚拟存在只继续保留：

```text
方法级样本次数
方法级最近样本时间
```

### 3. 练习好用闸门

练习读取目标方法首个可用条件结果对的条件场景统计，并将好用判断收束为：

```text
目标方法最近连续成功次数 >= 4
同条件样本次数 >= 4
同条件新结果分支数量 == 0
```

当同条件样本不足或出现新结果分支时，只记录结构化处置日志，不生成“新结果分支数量降到 0”的普通派生需求。

## 当前堵点

P4b 剩余问题转为方法状态被动模板接入：

```text
data/initial_causal_templates.tsv 的 6 列被动因果口径没有问题；
但当前应用入口 私有_应用安全因果风险树初始模板种子_线程侧 只服务安全风险树；
它只识别 target / scene / world；
并且固定创建 未明确 -> 已明确 的安全风险树比较；
不能表达 方法动作数量 > 0、方法条件结果对数量 > 0、同条件样本次数 >= 4 这类数量底账条件。
```

因此不能直接往 TSV 写方法状态模板行并宣称已接入。下一步若继续，需要先定义“数量底账已满足”的特征生成路径，再新增方法状态被动因果种子应用入口。
