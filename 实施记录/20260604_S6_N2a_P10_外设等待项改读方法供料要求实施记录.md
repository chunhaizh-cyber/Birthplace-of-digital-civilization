# S6-N2a-P10 外设等待项改读方法供料要求实施记录

日期：2026-06-04

## 1. 本轮目标

把外设观察等待项生成从“需求目标特征名 -> 识别 / 扫描 / 跟踪”迁到“当前方法供料要求 -> 识别 / 扫描 / 跟踪”。

本轮只处理任务管理界面线程中的等待项创建依据，不直接修改需求树、不直接写世界树事实、不新增模拟入口。

## 2. 代码落点

文件：

```text
任务模块.管理界面线程.impl.cpp
```

改动：

```text
1. 删除 私有_外设观察需求口径_按目标特征类型 和按需求目标特征名构造等待项的旧路径。
2. 新增 私有_外设观察需求口径_按方法供料要求：
       优先读取方法结果能力中的 外设识别结果场景状态 / 外设扫描结果场景状态 / 外设跟踪结果场景状态；
       仅在结果能力读不到时，用当前方法本能ID作为兼容诊断来源。
3. 新增 私有_按方法供料要求构造外设观察等待项：
       由当前方法供料口径生成 D455 识别 / 扫描 / 跟踪等待项；
       幂等键包含任务、需求、方法、结构化口径和观察模式。
4. 工作项入队阶段不再按需求目标特征名创建等待项，只记录“延后到当前方法供料要求”。
5. 工作结果归并后，如果当前方法需要供料且任务进入等待 / 推进失败 / 方法错误，则自动创建外设观察等待项并启动 D455 线程。
```

## 3. 边界

```text
不是把目标特征名表换成另一张目标特征名表；
不是由任务线程直接写需求树或世界树事实；
不是把外设报告材料包当成安全 / 服务结算证据；
不是在筹办前提前猜测识别 / 扫描 / 跟踪模式。
```

等待项的因是：

```text
当前方法已经出现，并且方法结果能力或兼容本能ID表明需要外设供料。
```

等待项的果是：

```text
外设观察等待项进入外设观察队列，供外设线程自动生成对应报告。
```
