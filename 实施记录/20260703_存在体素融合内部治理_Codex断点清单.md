## 3. 已有可复用入口

### 3.1 体素加工候选链

```text
视觉观察融合模块.ixx:
    结构_体素加工任务
    结构_体素加工候选结果包
    结构_体素子轮廓候选
    检查体素融合点
    生成子轮廓候选集合
    体素加工工作线程类::提交任务
    体素加工工作线程类::处理任务_
    读取体素加工候选结果包集合
```

事实：

```text
体素加工工作线程只把任务转换成候选结果包；
候选结果包保存父存在、输入观察证据ID、基准体素版本、融合点检查、父体素检查、子轮廓候选集合、子候选数量和处理状态；
`处理任务_` 明确注释为“正式入账留给提交入口”。
```

### 3.2 局部体素 / 子轮廓材料

```text
结构_体素子轮廓候选：
    候选ID
    局部子体素候选ID
    状态
    深度支撑率Q10000
    深度 / 空间支撑像素数量
    局部体素占据候选
    局部体素检查
```

事实：

```text

局部体素候选已经过正立方体包围盒检查。
```
