### P5-1 方法无条件结果对

```text
预测：
    任务筹办生成 方法条件结果对数量 > 0 的量化缺口；
    再筹办通过结果能力命中 自我_尝试学习；
    任务执行才调用 自我_尝试学习。

    任务筹办直接调用 自我_尝试学习。
```

### P5-2 方法有条件结果对但未稳定

```text
预测：
    任务筹办生成 方法最近连续成功次数 / 样本次数 / 新结果分支数量 等量化缺口；
    再筹办命中 自我_练习；
    任务执行才调用 自我_练习。

不应出现：
    用 方法状态=好用 直接替代稳定性底账。
```

### P5-3 方法无动作

```text
预测：
    任务筹办生成 方法动作数量 > 0 或 方法可执行入口数量 > 0；
    再筹办命中 自我_定向学习；
    候选动作不被写成真实动作。
```

### P5-4 方法状态更新

```text
预测：
    方法状态只在底账变化后由方法虚拟存在服务类同步；
    方法状态动作动态存在时为内部机制动作 / 被动动作语义；
    主动因果反推不以 提交方法状态变化 为因动作。
```

### P5-5 派生需求消息链

```text
预测：
    量化缺口在任务筹办回执 -> 工作线程派生消息 -> 自我线程入树之间不丢目标特征、主体、当前状态、目标状态和满足关系；
    缺量化状态时暴露缺口，不用粗状态兜底。
```
