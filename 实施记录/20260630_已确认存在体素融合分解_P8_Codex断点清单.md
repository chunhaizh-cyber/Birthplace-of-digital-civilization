## 8. P8b 首个独立问题

问题锚点：

```text
P8b 要求父基础颜色和子平均颜色作为项目结构特征落账，再由控制面板只读渲染。
当前代码中 P6 颜色统计位于 视觉观察融合模块.ixx 的 结构_体素加工候选结果包：父基础颜色统计、子轮廓候选集合[].颜色统计。
当前 P7/P8a 的提交入口 提交_确认内部世界子存在事实 只根据 结构_内部世界上下文 写局部体素模型、局部原点和提交状态，未消费体素加工候选结果包。
内部世界上下文的 来源空间候选编号 来自观察空间候选；体素加工子轮廓候选ID来自彩色连通分区输出顺序，二者当前没有明确同一性契约。
```

当前判断：

```text
不能用控制面板提示色、AABB 粗体素、颜色RGB结构状态或默认 CSS 色冒充父基础颜色/子平均颜色事实。
直接把读取到的第一个体素加工候选包颜色写到父/子存在，会绕过候选和内部世界子存在之间的身份匹配契约。
P8b 需要先补“体素加工候选包 -> 提交入口 -> 父/子颜色特征”的匹配契约，至少明确父存在、输入观察证据ID、基准体素版本、子候选ID或来源候选编号的对应关系。
```

下一步验证：

```text
回读 P6/P7 实施记录和当前函数，确认是否已有未命名匹配契约；若没有，P8b 应拆为契约补齐切片，不直接写颜色事实。
```

## 9. P8b 实施结果

实施内容：

```text
自我动作实现.外设模块.ixx：
  新增体素父基础颜色 / 子平均颜色相关特征入口；
  提交确认观察存在事实规格登记父基础颜色 RGBA、像素数量、事实状态、来源观察证据 ID、来源基准体素版本；
  提交确认观察存在三维体素特征成功后，按父存在、观察证据 ID、基准体素版本匹配体素加工候选结果包；
  候选父基础颜色统计有效时写入父基础颜色事实；缺候选包、统计无效、版本不匹配时只写结构化状态；
  提交内部世界子存在事实时，因当前缺少子轮廓候选 ID 与来源空间候选编号的同一性契约，只写“缺子候选映射”状态，不伪造子平均颜色。

  只读同步参数增加父 / 子颜色特征入口和颜色事实已写入状态值；
  场景体素存在项带出颜色 RGBA、颜色像素数量、颜色事实写入状态；
  只有颜色事实状态为已写入且 RGBA / 像素数均有效时，才标记为已读取父基础颜色事实或已读取子平均颜色事实。

控制面板类.ixx / 控制面板类.cpp：
```
