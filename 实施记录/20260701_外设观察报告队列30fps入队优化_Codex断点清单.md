# 20260701 外设观察报告队列30fps入队优化 Codex断点清单

## 0. 恢复摘要

当前切片：把优化目标从控制面板视频帧队列切换到四个自我侧外设方法消费的 `外设观察报告队列`，目标是正式观察报告写入达到 30 次/秒。

边界：

```text
1. 30fps 口径只针对 `外设观察报告队列` 中逐簇识别报告成功入队。
2. 扫描变化报告和跟踪报告仍必须由等待项 / 目标观察约束驱动，不强行绕过需求任务链每帧生成。
3. 外设线程只供料，不直接写世界树事实、需求树或价值结算。
4. 控制面板视频帧不能冒充四方法观察材料。
```

## 3. 当前实现

```text
1. `D455_相机实现::配置项` 增加 `启用彩色流`；默认完整路径仍启用彩色流，轻量路径可关闭彩色流。
2. 新增 `采集轻量观察帧` / `采集一帧轻量报告`，只采集真实 depth 帧、深度有效 mask、内参和帧元数据，不做对齐、滤波、点云全量生成或迁移分割。
3. 轻量报告用 depth-only 424x240@60 RealSense profile，给报告生成和队列提交留出 30fps 以上余量。
4. 轻量报告按真实深度网格生成空间候选，保留非空 `观察像素簇集合`、深度帧句柄、空间候选队列句柄、像素归属账本句柄、像素索引集合和质量字段；不是空报告刷帧。
5. `外设线程_D455深度相机` 在 `启用轻量观察报告=true` 时使用轻量报告路径，跳过迁移分割；完整路径和控制面板启动显式保持 `启用轻量观察报告=false`。
6. 逐簇识别报告和稳定子集报告继续入 `外设观察报告队列`；扫描变化报告、跟踪报告仍由等待项 / 目标约束驱动，不每帧强造。
7. 稳定子集入队日志改为节流输出；无扫描等待项时不回查上一帧 L1 稳定子集，减少发布编排开销。
8. 命令行入口 `--d455-report-queue-smoke` 的验收口径是 120 个逐簇识别报告，要求 `入队FPSx100 >= 3000`。
```

## 5. 质量边界

```text
1. 已达标的是 `外设观察报告队列` 中逐簇识别报告成功入队，非控制面板视频帧队列。
2. 轻量报告降低的是默认高频供料成本，不删除完整迁移分割、完整材料页和控制面板完整路径。
3. 当前轻量报告为 depth-only 424x240@60，适合高频 L0/L1 供料；需要精细彩色、完整点云或迁移分割材料时仍走完整路径。
4. 本轮未证明四个自我侧方法各自完整业务闭环达到 30fps；只证明它们共同消费的外设观察报告队列供料达到 30 次/秒以上。
```

不得宣称扫描变化报告和跟踪报告无等待项也达到 30fps。

不得宣称内部循环完成、自我苏醒完成或初步成熟完成。
