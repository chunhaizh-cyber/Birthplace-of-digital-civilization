# 20260701 外设观察报告队列30fps入队优化 Codex断点清单

## 0. 恢复摘要

当前切片：把优化目标从控制面板视频帧队列切换到四个自我侧外设方法消费的 `外设观察报告队列`，目标是正式观察报告写入达到 30 次/秒。

边界：

```text
1. 30fps 口径只针对 `外设观察报告队列` 中逐簇识别报告成功入队。
2. 扫描变化报告和跟踪报告仍必须由等待项 / 目标观察约束驱动，不强行绕过需求任务链每帧生成。
3. 外设线程只供料，不直接写世界树事实、需求树或价值结算。
4. 控制面板视频帧不能冒充四方法观察材料。
5. 关闭或削弱彩色流、对齐、深度滤波、填洞、空间候选、像素归属、观察像素簇、质量门或四方法消费边界得到的 30fps 结果无效；本切片只能通过并行、减少重复计算、减少拷贝 / 锁 / 调度开销优化。
```

## 3. 当前实现

```text
1. 旧的 `depth-only 424x240@60` / 关闭彩色流 / 关闭滤波链达标路径已作废，不作为有效验收证据。
2. `采集轻量观察帧` / `采集一帧轻量报告` 保留真实 D455 彩色流、深度到彩色对齐和视差 / 空间 / 时间 / 填洞滤波链；优化点不在关闭采集能力。
3. 高频报告构建继续保留原始深度毫米、深度有效性 Mask、空间坐标毫米 XYZ、非空 `观察像素簇集合`、深度帧句柄、彩色帧句柄、对齐帧句柄、空间候选队列句柄、像素归属账本句柄、像素索引集合和质量字段；不是空报告刷帧。
4. `提取轻量深度网格候选摘要` 从单线程全帧遍历改为分块并行统计，复用来源有效掩膜，预计算 X/Y 投影比例和网格归属，并在热循环内联等价有效像素判断，减少重复函数调用和尺寸检查。
5. 候选深度上限对齐相机默认观察范围 4000mm；普通候选门槛仍为 160 像素，只有整帧没有普通候选但存在真实有效深度时，才用 32 像素稀疏候选兜底，兜底候选按低覆盖率产生低质量分，不绕过后续质量门。
6. `外设线程_D455深度相机` 增加观察报告采集 / 发布流水线，在不绕过 `提交外设观察报告` 和队列质量门的前提下减少采集与入队编排互相阻塞；流水线不再以关闭控制面板视频帧为前置条件。
7. 控制面板视频帧保持启用；完整观察结果派生视频帧后按移动语义提交，减少同帧供报告队列和视频队列时的大数组复制开销。
8. 逐簇识别报告和稳定子集报告继续入 `外设观察报告队列`；扫描变化报告、跟踪报告仍由等待项 / 目标约束驱动，不每帧强造。
9. 命令行入口 `--d455-report-queue-smoke` 的验收口径是 120 个逐簇识别报告，要求 `入队FPSx100 >= 3000`，且能力关闭 / 削弱路径的结果无效；当前 smoke 显式记录 `启用控制面板视频帧=1`。
```

已知失败证据：

```text
第二轮 smoke：exit code 1，观察报告采集成功=119/120，观察报告入队=119，入队FPSx100=2973。
```

## 5. 质量边界

```text
1. 本切片验收对象是 `外设观察报告队列` 中逐簇识别报告成功入队，非控制面板视频帧队列。
2. 有效验证必须保留彩色流、对齐、深度滤波、填洞、空间候选、像素归属、观察像素簇、质量门和四方法消费边界；不能靠关闭能力换速率。
3. 本轮优化只证明四个自我侧外设方法共同消费的 `外设观察报告队列` 供料速率，不证明四个方法各自完整业务闭环达到 30fps。
```
