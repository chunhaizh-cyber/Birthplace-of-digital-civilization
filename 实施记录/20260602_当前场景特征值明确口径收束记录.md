## 用户修正

本轮按用户明确口径修订：

```text
当前场景特征值明确状态这一层只关注：
    当前帧有多少有效观察特征值；
    这些特征值是否都已经稳定对应存在；
    稳定对应出的存在数量。

识别不产生被观察存在状态和动态。
扫描和跟踪才产生状态和动态。
第一次扫描生成发现动态。
后续有上一帧 / 上一轮可比历史后，才生成变化动态。
```

## 定案

```text
当前场景特征值明确状态 =
当前帧全部有效观察特征值都已经稳定对应到存在。
```

它不是：

```text
安全意义明确；
风险状态明确；
自我边界影响明确；
扫描完成；
跟踪完成；
需求满足。
```

## 子链调整

旧口径中的 `确认型子需求` 被收束为 `对应事实型子需求`：

```text
当前帧有效特征值计数事实取得状态；
当前帧特征值存在稳定对应事实取得状态；
稳定对应存在数量明确状态；
当前帧特征值存在对应闭合状态；
扫描可启动状态。
```

扫描型子需求增加首次发现边界：

```text
当前帧稳定对应存在扫描状态；
首次发现动态生成状态；
观察存在发现事实提交状态；
已知存在当前状态取得状态；
已知存在变化动态生成状态；
观察存在特征值变化事实提交状态。
```

## 禁止回退

```text
不得把未知区域作为最终归属类型；
不得让识别产生被观察存在状态或动态；
不得把扫描可启动等同于全场景明确；
不得把第一次扫描写成变化动态；
不得把安全因果、自我边界、风险评估塞回当前场景特征值明确这一层。
```
