## 5. 指针落库修正

用户修正：

```text
数据库不能存储指针，需要将指针转换为数据库中数据的序号。
```

已处理：

```text
1. world_tree_node_relation 增加 owner_row_index / target_row_index。
2. world_tree_root_tree_relation 增加 owner_row_index / target_row_index。
3. 关系采集阶段只在内存里使用 基础信息节点指针 -> row_index 映射，SQL 落库只写序号。
4. 需求根节点 / 任务根节点 / 方法根节点不再写 ptr: 指针文本，改写对应节点自身主键文本；当前世界树关系目标序号为空，等待对应树投影按自身 row_index 查询。
5. 根链关系归属改为按 owner_row_index 关联，不再按可能重复的 node_key 关联。
```
