## 8. P5 对应关系与覆盖索引阻塞

问题锚点：

```text
计划 P5 要求：
    对每个已合法外设数据项，判断其对应哪个本轮应覆盖存在；
    建立本轮外设覆盖索引。
```

已复核证据：

```text
日志：
    日志/20260615_扫描完整实现_P5_对应关系阻塞证据.txt

关键事实：
    外设观察报告队列.ixx 中 结构_外设已知存在扫描结果 有 当前中心 / 当前空间范围，
    但构造扫描包时没有写入 已确认存在ID。

    构造外设扫描提交包_由观察报告 中：
        结果.当前中心 = 外设提交_簇中心(簇);
        结果.当前空间范围 = 外设提交_簇范围(簇);
        外设提交_追加缺口(结果.原因, 枚举_外设提交缺口码::缺已确认存在ID);
        包.已知存在结果.push_back(std::move(结果));

    自我动作实现.扫描.ixx 目前只能把 项.已确认存在ID 复制到 数据项.已确认存在ID；
    该值为 0 时会进入 缺已确认存在指针 / 数据项不可比较路径。

    任务约束链中的 目标存在ID 是世界树存在主键字符串，
    不是 结构_外设已知存在扫描结果.已确认存在ID 的 uint64_t。
```

当前判断：

```text
P5 不能安全继续实现。

原因不是编译问题，而是对应关系合同缺失：
    1. 已合法外设数据项缺少可回到世界树存在的存在指针或存在主键；
    2. 当前 uint64_t 已确认存在ID 没有可验证的世界树映射来源；
    3. 扫描数据项转换没有把 当前中心 / 当前空间范围 作为可比较字段保留下来；
    4. 即使保留外设空间材料，也缺少外设坐标系到当前内部场景坐标系的可用转换合同。

继续实现 P5 会变成用编号或外设局部材料猜测存在对应关系，
违反“空间位置是对应关键”和禁止伪造机器判断路径的边界。
```

保留状态：

```text
P0-P4 已完成并构建通过。
P5 暂停，等待先明确并实现外设数据项到世界树存在的合法对应合同：
    优先方案：
        已合法外设数据项直接携带世界树存在主键或存在指针；
    或者：
        已合法外设数据项保留当前中心 / 空间范围 / 轮廓 / 极值，
```
