# S6-N2a-P4 任务筹办结构化选择实施记录

日期：2026-06-02

## 1. 目标

```text
清理任务管理界面线程中按目标特征文本 / 需求类型文本判断识别、扫描、跟踪等待项的旧逻辑。

等待项生成必须只基于：
    来源需求的结构化目标特征类型；
    目标特征节点到外设观察口径枚举的显式映射；
    报告类型枚举和观察运行模式枚举。
```

## 2. 修改范围

```text
任务模块.管理界面线程.impl.cpp
```

主要变化：

```text
删除：
    私有_目标特征类型命中任一_任务管理；
    私有_需求目标语义命中任一_任务管理；
    私有_安全语素入口文本_任务管理；
    目标特征文本 / 需求类型文本 / 目标特征匹配文本参与等待项选择。

新增：
    枚举_外设观察需求口径_任务管理；
    私有_外设观察需求口径_按目标特征类型；
    目标特征节点 -> 汇总目标 / 识别 / 扫描 / 跟踪 / 未映射 的结构化口径映射。
```

## 3. 边界结论

```text
当前场景特征值汇总目标：
    不直接映射 D455 等待项；
    必须先拆成结构化材料型 / 确认型 / 扫描型 / 跟踪型子需求。

识别 / 扫描 / 跟踪等待项：
    只由结构化目标特征节点映射得到；
    未映射目标记录缺口；
    不读取目标特征词；
    不读取需求类型词；
    不把外设报告直接解释成需求满足、风险明确或安全值。

扫描仍要求已有确认场景或基准目标；
跟踪仍要求目标种子。
```
