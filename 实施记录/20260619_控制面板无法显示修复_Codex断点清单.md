# 20260619 控制面板无法显示修复 Codex 断点清单

## 0. 恢复摘要

当前切片目标：修复控制面板在自我环境初始化长时间未返回或 SQL Server 不可访问时无法显示的问题。

依据：

```text
规范/禁止性规范20260611.md
规范/规范目录.md
规范/线程生命周期状态上报与控制面板线程信息规范20260609.md
计划/计划索引.md
实施记录/20260616_控制面板读取SQL重构_Codex断点清单.md
```

已复核证据：

```text
1. 临时目录运行 `D:\鱼巢\x64\Debug\鱼巢.exe --panel-html` 超过 120 秒未返回。
2. 本次临时运行日志停在 `初始化自我环境()` 内部需求生长路径，未进入 HTML 保存。
3. 本次异常日志反复出现：
   `需求树SQL投影失败 | ADO打开连接失败 | SQL Server 不存在或拒绝访问。`
4. 20260616 控制面板读取 SQL 重构断点要求：
   `--panel-html` 不再为了生成控制面板而初始化自我环境或读取 live 控制面板快照。
```

本次修改：

```text
1. `鱼巢.cpp`
   - `--panel-html` 不再调用 `私有_确保自我环境已初始化(...)`。
   - `--panel` / `--panel-open` 不再以前置自我线程启动或自我环境初始化作为显示条件。
   - 默认控制台模式先预启动控制面板窗口，再进入自我线程初始化。
2. `控制面板类.cpp`
   - SQL 静态 HTML 保存复用 `生成SQL控制面板HTML()`。
   - SQL 读取失败时仍保存已有诊断 HTML 页面，避免没有可显示文件。
3. `数据库ADO模块.cpp`
   - SQL Server Windows 认证连接串追加 `Connect Timeout=3`。
   - 目的：SQL Server 不可达时尽快生成控制面板诊断页，避免 WebView2 / 静态 HTML 显示被连接等待拖住。
```

禁止宣称：

```text
不宣称 SQL Server 已恢复。
不宣称控制面板 SQL 读模型已有有效最新批次。
不宣称自我环境初始化性能问题已解决。
不宣称内部循环完成、自我苏醒完成或初步成熟完成。
```
