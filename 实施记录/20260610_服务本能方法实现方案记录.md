## 2. 已确认口径

### 2.1 宿主与字段

服务链不再单独新建“当前服务事件E”虚拟存在。

本次服务相关字段优先落在：

```text
任务虚拟存在T
方法运行虚拟存在R
成功服务治理视图G0
服务值结算动态D2
```

字段表达使用：

```text
存在E.特征类型F = 特征值V
```

不得使用：

```text
当前交互者明确状态 = 已明确
当前服务目标明确状态 = 已明确
服务对象当前状态明确状态 = 已明确
```

“明确”只能由字段已有合法具体值派生，不能作为底层权威目标值。

### 2.2 字段来源

任务字段来源分三类：

```text
1. 任务治理核心：
   任务ID、任务状态、来源需求、输入场景、输出场景、D0引用、D1引用、方法运行引用。

2. 来源需求：
   目标宿主、目标特征类型、目标值、目标比较关系、服务前目标锚点。

3. 方法虚拟存在：
   该实现方法声明的输入字段、输出字段、验证字段、归因字段、失败处理字段。
```

方法不是决定所有字段；方法只声明本方法运行所需字段。字段缺失时生成缺口，不造假值。

### 2.3 父子任务汇总

子任务虚拟存在承载子任务自己的具体特征值。

父任务虚拟存在只汇总父任务治理和组合判断需要的摘要、引用和判断结果：

```text
子任务完成状态
子任务目标达成结果
D0 / D1 引用
输出结果引用
证据引用
阻塞缺口
AND / OR 组合判断结果
```

父任务不得复制子任务全部字段。

## 5. 实现切片

### P0：服务模块骨架

目标：

```text
新增 自我动作实现.服务模块.ixx
加入工程文件
能被 自我动作实现模块.ixx import
不注册新本能方法
构建通过
```

验收：

```text
Debug x64 构建通过
无业务行为变化
```

### P1：任务字段绑定辅助函数

实现服务模块内部 helper：

```cpp
任务节点* 读取输入任务(...);
需求节点* 读取任务来源需求(...);
bool 绑定任务存在字段(任务节点* T, const char* 字段名, 存在节点类* 值);
bool 绑定任务特征类型字段(任务节点* T, const char* 字段名, const 语素入口节点类* 值);
bool 绑定任务I64字段(任务节点* T, const char* 字段名, I64 值);
bool 写入字段来源证据(...);
```

只允许写：

```text
任务T.交互者 = A
任务T.权限者 = B
任务T.服务对象 = C
任务T.目标宿主 = H
任务T.目标特征类型 = F
任务T.目标值 = V_target
任务T.输入场景 = S_in
任务T.权限边界 = P
```

禁止写：

```text
明确状态 = 已明确
```

### P2：字段补齐类本能方法

注册第一批可执行叶子方法：

```text
服务_绑定任务交互者
服务_绑定任务权限者
服务_绑定任务服务对象
服务_绑定任务权限边界
服务_绑定任务目标宿主
服务_绑定任务目标特征类型
服务_绑定任务目标值
服务_绑定任务输入场景
```

每个方法职责：

```text
从输入参数场景读取候选值
校验值为具体存在 / 合法特征类型 / 合法特征值
写入任务T虚拟存在对应字段
输出结果场景写入绑定结果和证据引用
```

### P3：方法声明特征装配

先实现为辅助函数，不注册为普通服务本能方法：

```cpp
bool 装配方法声明特征到任务(...);
结构_字段检查结果 检查服务方法输入字段(...);
bool 写入服务字段缺口回执(...);
存在节点类* 创建服务方法运行存在(...);
```

边界：

```text
方法选择仍归任务筹办
任务执行仍归任务生命周期
服务模块不实现“服务_选择服务实现方法”成本能方法
```

### P4：现实服务动作承接

注册或实现：

```text
服务_读取服务前状态
服务_写入方法运行输出场景
服务_读取服务后状态
服务_比较服务前后状态
```

D0 规则：

```text
D0 必须来自具体业务方法
服务模块可以读取和校验 D0
服务模块不得用“方法返回成功”伪造 D0
```

### P5：验证、归因与 G0

实现：

```text
服务_验证服务结果
服务_归因服务结果
服务_评估服务副作用
服务_计算完成度
服务_计算有效性
服务_计算证据强度
服务_判定成功服务硬门槛
服务_生成成功服务治理判断
```

输出落位：

```text
G0.硬门槛状态集
G0.完成度
G0.有效性
G0.证据强度
G0.成功服务层级
G0.候选状态
```

G0 是治理视图，不是 D0，也不能反向证明服务动作发生。

### P6：候选池与服务值结算

实现：

```text
服务_登记成功服务候选
服务_复核成功服务候选
服务_结算成功服务价值
```

结算方案：

```text
保留现有 自我_结算叶子任务价值 作为底层入口
新增 服务_结算成功服务价值 作为语义包装
只有 G0已确认 + D0存在 + D1存在 + 未重复结算 时调用
服务值使用饱和入账
```

禁止：

```text
S = S + q
D2反向证明成功服务
任务完成直接证明成功服务
输出存在直接证明成功服务
```

### P7：父子任务组合汇总

实现：

```text
服务_汇总AND子任务结果
服务_选择OR子任务路径
服务_汇总子任务证据引用
服务_判断组合输出一致性
```

AND 父任务：

```text
汇总每个必需子任务的满足结果和证据
全部必需子任务满足后，父任务组合目标才满足
```

OR 父任务：

```text
记录胜出路径
汇总胜出路径结果和证据
未选路径只保留状态、原因和历史引用
```
