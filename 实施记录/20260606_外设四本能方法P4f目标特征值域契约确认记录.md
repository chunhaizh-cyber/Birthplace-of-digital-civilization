目标：确认扫描目标特征值域区间应绑定的目标特征类型来源；若缺契约，记录具体阻塞。

## 修改前预测

```text
若扫描方法已经把 目标特征类型 声明为形参，并能从输入参数场景或目标宿主读取目标特征当前值、基准值和值域，
则 P4f 可以继续做最小代码接入。

若只有需求 / 筹办通用层具备 目标特征类型，而扫描方法本身未声明、未读取、未绑定该特征值域，
则本切片必须停在契约阻塞，不能把几何匹配成功伪装成目标特征值域判断。
```

## 已确认代码事实

```text
需求目标权威口径：
    规范/需求主信息类规范20260507.md 明确需求原子目标由
    目标宿主 + 目标特征类型 + 目标比较符 + 目标值 构成。

需求读取能力：
    需求类::读取需求目标特征类型 可从 目标特征类型缓存、目标状态或当前状态读取目标特征类型。

筹办通用绑定能力：
    任务模块.筹办.ixx::通用绑定候选方法输入参数_筹办 会向输入条件包写入 特征_目标特征类型。
    后续形参闭合循环也能在方法声明该形参时把 目标特征类型 指针补进输入参数场景。

扫描方法规格现状：
    确认自我扫描已识别区域规格 当前声明的形参是：
        输入条件包
        当前观察存在
        历史观察存在
        目标宿主
        当前方法运行存在
    未声明 特征_目标特征类型，也未声明目标特征当前值、基准值或目标值域输入。

扫描运行体现状：
    自我_扫描已识别区域 当前读取 当前观察存在、历史观察存在、目标宿主、归属状态、扫描可启动状态。
    读取观察存在摘要 只读取空间中心、AABB、尺寸和距离等几何 / 空间材料。
    计算观察存在变化结果 在历史对应状态已匹配时直接把 目标存在特征值域状态 写为 值域内；
    在历史对应冲突时写为 冲突或证据不足。
```

## 具体阻塞

```text
扫描“目标存在特征值域状态”缺少可安全落地的独立读取契约：

1. 目标特征类型从哪里进入 自我_扫描已识别区域 尚未成为方法规格形参。
2. 即使使用筹办通用层可提供的 特征_目标特征类型，也还缺少目标值域来源口径：
       是读取需求目标状态 / 目标执行后值，
       还是读取目标宿主上该特征当前值，
       还是读取已确认观察存在的当前特征值与历史基准值。
3. 当前扫描变化计算只比较空间摘要，不能代表任意目标特征类型的值域判断。
4. 若继续编码，会把历史几何匹配关系误写成“目标特征值域区间独立读取”，违反 P4f 边界。
```
