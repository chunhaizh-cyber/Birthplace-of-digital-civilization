# 20260606_外设四本能方法P4f扫描值域边界纠偏与轮廓变化接入记录

## 切片

```text
计划：计划/20260605_外设四本能方法需求树生成因果链修订计划_v0.1.md
切片：P4f 扫描值域边界纠偏与观察特征变化接入
目标：扫描只做已有存在的观察目标匹配和观测特征变化判断，不在自我方法层裁决特征值域。
```

## 用户确认口径

```text
扫描的前提是已经有了存在信息。
扫描通过空间位置匹配、轮廓匹配等确认当前观察的目标。
确认目标后再检查哪些特征发生变化。
没有变化则忽略变化动态；有变化才生成状态信息。
值域是特征类内部概念，自我不用管，特征类会自动匹配或根据规则分解。
```

## 修改前预测

```text
自我_扫描已识别区域 不再写 目标存在特征值域状态 / 已归属存在特征值域冲突状态。
确认自我扫描已识别区域规格 不再声明值域裁决结果能力。
观察存在匹配关系继续写空间匹配材料，并补入轮廓变化量参与匹配置信度。
观察存在变化结果继续写位置 / 范围 / 尺寸 / 距离变化，并补入轮廓变化量。
历史目标匹配失败时只触发待复验 / 补观察缺口，不写值域冲突动态。
```

## 已修改

```text
自我动作实现.外设模块.ixx：
    新增 特征_轮廓变化量。
    读取观察存在摘要 新增读取 轮廓吻合率、轮廓闭合度、轮廓数量。
    计算观察存在匹配关系 新增 轮廓变化量，并把它作为匹配置信度扣分因素之一。
    计算观察存在变化结果 新增 轮廓变化量；
        轮廓变化量参与 基准差异值；
        轮廓变化量超过阈值时写 变化状态=内部结构变化。
    确认自我扫描已识别区域规格 撤出目标存在特征值域状态和已归属存在特征值域冲突状态结果能力。
    自我_扫描已识别区域 不再写目标存在特征值域状态、不再写已归属存在特征值域冲突状态、不再写值域冲突动态。
    历史对应冲突或变化不确定时写待复验 / 补观察缺口。
```
