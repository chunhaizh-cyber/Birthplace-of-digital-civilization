# 20260621 P6 控制面板快照读取分类

## 1. 结论

```text
主控制面板正式展示读源已经收束为 SQL 读模型。
未发现主控制面板正式路径继续调用 `读取控制面板快照()`。
剩余 live 快照读取属于自我场景独立窗口、旧 live 页面函数、线程详情旧通道、命令行诊断和等待检查。
```

SQL 是控制面板查询投影，不是世界树、任务树、动作动态链的权威写源。

## 3. 已完成收口

```text
1. 主控制面板 HTML 生成走 `生成SQL控制面板HTML()`。
2. `--panel-html` 保存入口只保留 SQL 版 `保存控制面板HTML(const std::filesystem::path&)`。
3. 删除旧 live 主控制面板公开入口 `生成控制面板HTML(...)`。
4. 删除旧 live 保存重载 `保存控制面板HTML(const std::filesystem::path&, const 结构_控制面板快照&)`。
5. 删除无调用方的 `读取控制面板主窗口快照(...)`。
6. WebView2 主控制面板用途拒绝 `expand:` / `detail:` 旧 live 指针消息。
7. WebView2 主控制面板用途下 `refresh-page:*` 只允许 SQL 区段白名单。
```

## 4. 后续边界

```text
1. 自我场景独立窗口仍使用 live 快照，后续若继续收口，应按“自我场景显示入口”单独切片，不再按主控制面板读源处理。
2. 命令行日志 / 等待检查读取 live 快照，后续若继续收口，应按“日志诊断读取”或“运行检查读取”单独切片。
3. P6 当前控制面板读源纠偏闭合；不得再把主控制面板阻塞到新增 `世界树类` 显示快照契约。
```
