# 首次扫描发现事实口径纠偏记录

日期：2026-06-05

## 背景

用户指出：

```text
第一次扫描只能写发现存在或发现特征，而不是动态。
```

本次纠偏收束 `首次扫描 / 第一次扫描` 的业务结果口径：

```text
首次扫描：
    只能生成发现存在事实或发现特征事实；
    可以保留来源动作动态作为方法运行因果账本引用；
    不得把发现本身命名为发现动态；
    不得伪造成变化动态。

后续扫描：
    只有有上一外设帧 / 上一轮 / 历史可比观察材料集后，才允许生成变化动态。
```

## 代码口径

```text
旧：
    观察存在发现动态
    第一次扫描只写发现动态=1

新：
    观察存在发现来源动作动态
    第一次扫描只写发现存在或发现特征事实=1
```

说明：

```text
动作动态仍由方法运行产生，作为因果账本来源保留；
但业务特征不再把第一次扫描的发现结果命名为“发现动态”。
```
