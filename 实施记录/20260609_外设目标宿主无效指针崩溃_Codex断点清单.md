# 20260609 外设目标宿主无效指针崩溃 Codex 断点清单

## 触发问题

```text
用户提供 Visual Studio 调用栈：
vcruntime140d -> 基础信息类::取主信息<特征节点主信息类> -> 特征类::取特征主信息 -> 特征类::查找子特征_按类型 -> 自我动作实现.外设模块::读取基础节点I64 -> 提交当前观察范围可观测单位存在对应事实。

当前判断：
    崩溃点不是普通空指针，而是 `dynamic_cast` 触碰了不属于当前基础信息树的基础信息节点指针。
    栈上具体入口位于 `提交当前观察范围可观测单位存在对应事实` 的提交入口特征读取路径。
```

## 代码处理

```text
新增 `基础节点属于当前世界树`：
    用世界树基础信息全链指针比较确认候选基础节点是否仍属于当前世界树。
    不解引用候选指针，避免对野指针做 dynamic_cast 或读取主键。

增强 `基础节点日志文本`：
    节点为空显示 `空`。
    节点不属于当前世界树时显示 `无效基础节点指针:<地址>`，不再调用 `获取主键()`。

增强 `解析双目相机目标外设`：
    输入参数里的 `目标外设` 指针必须属于当前世界树，并且仍是存在节点。
    无效时写 `外设模块/无效基础节点引用` 错误日志，拒绝使用候选指针，回退到默认双目相机外设存在。

增强 `解析双目相机目标宿主`：
    输入参数里的 `目标宿主` 指针必须属于当前世界树。
    无效时写 `外设模块/无效基础节点引用` 错误日志，拒绝使用候选指针，回退到默认宿主。
```
