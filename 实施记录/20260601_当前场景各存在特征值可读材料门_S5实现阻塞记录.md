## 2. 保守口径

材料门不会把 D455 坐标直接升格为正式场景坐标：

```text
D455 的 ROI / 掩码 / 点集 / 深度切片 / 空间候选坐标只算观察材料；
中心空间坐标、AABB、深度质量、跨帧稳定性只能支持 部分可读；
只有存在_场景绝对坐标明确状态 或 存在_场景绝对空间范围明确状态 为真时，才允许材料门写完整 可读。
```

这与当前已定口径一致：

```text
场景用绝对坐标记世界，自我用相对视图看世界。
```

## 4. 遇到的问题

阻塞点：

```text
代码中仍缺少存在_场景绝对坐标 / 存在_场景绝对空间范围的一等写入链；
也缺少 D455相机坐标 -> 场景绝对坐标 的明确变换状态和合法生产者；
自我_场景绝对坐标 / 姿态 / 自我相对视图坐标系仍未形成可生产、可验证的承载。
```

影响：

```text
材料门可以说明每个已确认观察存在有哪些观察材料可读；
材料门可以把缺失、过期、冲突和证据不足写成掩码；
但在缺少场景绝对坐标生产链前，不能把 当前场景各存在特征值可读状态 写成完整 可读；
后续 P5 安全候选构造若需要边界、靠近、接触、遮挡、作用范围等空间判断，会继续被该缺口阻塞。
```

当前结论：

```text
S5/P4 的材料门定义与保守代码接线已完成；
继续进入 P5 前，需要先补最小场景绝对坐标承载和合法生产者。
```
