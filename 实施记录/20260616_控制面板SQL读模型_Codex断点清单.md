# 20260616 控制面板 SQL 读模型 Codex 断点清单

## 0. 恢复摘要

当前切片目标：将控制面板后续重构需要的读模型数据写入 SQL Server。

边界：

```text
1. SQL 是控制面板后续查询读源，不从 控制面板.html、WebView2 页面或已渲染快照反向抽取数据。
2. 当前只扩展 `tools/sql_projection/fishnest_sql_projection.py`，不改 C++ 控制面板运行主路径。
3. 数据来源限定为项目底层事实投影：特征定义/详细设计、运行日志、消息中间件线程生命周期缓存和消息文件。
4. SQL 投影不是世界树、任务树、动作动态链的权威写入入口。
```

已读依据：

```text
规范/禁止性规范20260611.md
规范/规范目录.md
计划/计划索引.md
线程生命周期消息模块.ixx
控制面板类.ixx
控制面板类.cpp
tools/sql_projection/fishnest_sql_projection.py
```

当前判断：

```text
控制面板线程状态页已存在底层来源：消息中间件/control_panel_thread_info_table.cache
和 thread_lifecycle_*.msg。后续 SQL 读模型应直接导入这些底层来源，而不是导入控制面板显示文本。
```

下一步：

```text
1. 扩展 SQL schema：控制面板字段目录、运行指标、线程信息、线程生命周期事件。
2. 从底层文件和运行日志生成导入 SQL。
3. 用 .\SQLEXPRESS 实际导入并查询行数。
```
