# S6-N2a-P7 D455路径标准子需求生长实施记录

时间：2026-06-02

## 目标

实现 `当前场景特征值明确状态` 的 D455 观察确认路径内部标准子需求生长。

本轮口径：

```text
当前场景特征值明确状态 =
    当前观察范围有效可观测单位全部稳定对应存在。

D455观察确认路径内部只生长：
    材料型；
    对应事实型；
    缺口解释。

扫描 / 跟踪不作为该明确状态的完成子需求；
稳定对应存在事实出现后，后续由并行动动态取得需求触发扫描 / 跟踪。
```

## 已实施

```text
1. 新增 外设_D455_当前场景特征值需求展开规则.h。
   D455 专用标准子需求定义放在外设 D455 规则文件中，
   不进入 需求类，也不进入自我线程内的硬编码表。

2. 自我线程 OR 路径展开不再因 OR组满足状态 已存在而直接跳过。
   现流程为：
       查找或创建 OR组满足状态；
       查找或创建 D455 / 缓存 / 交互者说明 三个 方法路径完成状态；
       对 D455观察确认路径 继续确保材料型 / 对应事实型 / 缺口解释子需求。

3. 新链材料目标使用 当前观察材料集取得状态。
   当前观察特征帧取得状态 仅保留兼容旧入口，不作为 D455 标准链的新目标。

4. 任务管理外设等待项映射补充：
       当前观察材料集取得状态；
       当前观察范围有效可观测单位计数事实取得状态；
       当前观察范围可观测单位存在稳定对应事实取得状态；
       稳定对应存在数量明确状态；
       当前观察范围可观测单位存在对应闭合状态；
       当前观察范围可观测单位存在对应缺口可解释状态。

5. 汇总目标拒绝日志改为：
       需要先拆成结构化材料型 / 对应事实型 / 缺口解释子需求；
       扫描跟踪由稳定对应存在事实并行触发。
```
