# 第一批被动动作迁入口径 P3-02 实施记录

日期：2026-06-04

## 1. 本轮目标

按 `计划/20260604_主动能力与被动触发遗传因果落实计划_v0.1.md` 的 P3-02，对第一批被动动作做代码对账：

```text
提交任务状态变化
回写需求满足
叶子任务价值结算后处理
安全 / 服务值账务变化
需求链权值重算
父任务重筹办触发
横向任务结算候选触发
```

判断标准：

```text
有被动因 -> 果自动出现；
中间不能有需要自我主动知道如何使用的阻塞点；
能闭合的项迁入 被动触发遗传因果读取 / 增强公共口；
不能闭合的项记录为被动果缺失、幂等链缺口或等待真实样本复验；
被动动作不得进入普通候选方法集。
```

## 2. 已接入项

### 2.1 回写需求满足

代码位置：

```text
自我线程模块.impl.cpp
    私有_增强回写需求满足被动遗传因果_线程侧
    私有_处理任务满足反馈_线程侧
```

接入口径：

```text
被动因：
    任务完成后的需求满足判定成立

自动果：
    回写需求满足D1需求满足动作动态出现

因比较：
    任务虚拟存在.需求满足判定被动因出现状态: 0 -> 1

果比较：
    任务虚拟存在.回写需求满足D1被动果出现状态: 0 -> 1

证据动态：
    来源动作动态
    D1需求满足动作动态
```

说明：

```text
回写需求满足仍由自我线程在任务满足反馈后自动调用；
它不是普通任务筹办候选；
只有 D1 已真实返回后才增强遗传因果信息；
没有伪造动作动态或模拟任务完成。
```

### 3.3 需求链权值重算

当前代码事实：

```text
需求类.h
    需求类::刷新直接子需求权重_已加锁
    需求类::计算子需求权重

规范/需求树生长机制规范20260512.md
    OR关系子需求继承父权重；
    AND关系子需求平分父权重；
    OR组 / AND组按同一规则处理直接子需求；
    需求列表汇总权重只用于排序、主任务选择和任务优先级比较。
```

当前结论：

```text
核心算法已符合新口径：
    OR关系：每个活动子需求继承父需求安全 / 服务权重；
    AND关系：活动子需求平分父需求安全 / 服务权重；
    非活动子需求权重归零。

部分生成入口仍先写 1/0 作为临时方向值；
但 新增 / 更新 / 满足需求 后会通过 执行更新指令 -> 刷新子需求权重 覆盖为新口径权重。

本轮不把它作为代码阻塞；
后续可清理临时写 1/0 的注释和变量名，避免误读为最终权重算法。
```

### 3.4 横向任务结算候选触发

当前代码事实：

```text
自我线程模块.impl.cpp
    私有_按成功结果满足来源需求并唤醒父任务_任务管理新链
        先调用 私有_处理任务满足反馈_线程侧 结算自身；
        自身结算快照已生成后，再调用 私有_处理横向任务满足反馈_线程侧。

    私有_处理横向任务满足反馈_线程侧
        计算 满足差 = 目标值 - 实际值；
        满足差 >= 0 时跳过；
        满足差 < 0 时取外溢量 = abs(满足差)；
        横向候选结果值 = 横向候选当前值 + 外溢量；
        候选按任务权重评分降序处理；
        结算仍复用任务价值反馈既有算法。
```

当前结论：

```text
横向结算触发链符合“先结算自己，再横向”的口径；
也符合“缺口未变化则不结算”的口径；
尚未迁入独立的被动触发遗传因果模板。
```

### 4.3 已接入最小被动因果模板

```text
规则：
    遗传因果.父任务重筹办.子目标满足解除等待

因比较：
    子任务虚拟存在.对应需求满足状态: 0 -> 1

承接：
    父任务虚拟存在.等待来源子需求 = 子任务对应需求；
    父任务状态属于等待类状态。

果比较：
    父任务虚拟存在.任务状态: 等待中 / 挂起 / 无法执行 -> 待重筹办

自动果描述：
    父任务虚拟存在.任务状态进入待重筹办；
    父任务阶段回到筹办；
    等待缺口唤醒状态为 1。

证据动态：
    子任务状态动作动态；
    子需求满足 D1 动作动态；
    父任务状态动作动态。
```

边界：

```text
子需求未满足、只表现为任务终结时，本轮不套用该“子目标满足解除等待”模板；
会记录 父任务重筹办被动遗传因果跳过。

父需求整体已经满足时，父任务仍通过 待重筹办 + 筹办阶段 进入收束判断；
日志中区分 下一步含义=进入父任务收束判断，不把它解释成继续找新方法。
```
