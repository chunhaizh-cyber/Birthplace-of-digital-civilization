## 当前切片

服务本能方法实现计划 P8c：G0 自然链路接入。

## 目标

```text
在自我线程任务价值反馈自然链路中生成 G0 成功服务治理候选。
```

最小接入点：

```text
私有_处理任务价值反馈_线程侧
    -> 已收集正式结算证据
    -> 已计算服务证据摘要
    -> 已提交任务已结算状态并取得 D1 任务状态动作动态
    -> 调用服务模块 G0 组装 helper
    -> 登记成功服务候选记录
    -> 继续旧任务价值结算链
```

## 禁止修改范围

```text

```

## 实现策略

```text
1. 自我线程显式 import 自我动作实现.服务模块。
2. 在任务价值反馈链中，当计划服务增量 > 0 时生成 G0 候选。
3. G0 输入使用：
   - 任务
   - 来源需求
   - D0 服务业务动作动态
   - D1 任务已结算状态动作动态
   - actual 状态
   - 服务对象状态变化证据摘要
   - 非重复去重键已检查结果
4. 安全通过门槛第一版保持待确认，不直接确认成功服务。
5. 生成待确认 / 可接受候选时登记成功服务候选记录。
6. 本切片只新增候选，不改变旧服务值入账行为。
```

## 预测

构建通过后，真实运行路径若出现计划服务增量：

```text
任务价值反馈服务结算证据已提交结算方法
成功服务G0候选生成
```

其中 G0 候选应记录：

```text
G0 治理视图
候选状态
成功服务层级
候选记录
D0 / D1 引用
服务证据摘要字段
```

不会出现：

```text
新增普通服务本能方法
服务值改由 G0 饱和入账
G0 直接证明成功服务
D2 反向证明成功服务
```
