```text

3. SQL 运行态只读查询能看到运行批次、事件流水、同步状态和当前态显示表。
4. HTML 中显示最近运行态 SQL 事件和当前态表入口。
5. 使用 `CL=/D鱼巢_开关_启用SQL控制面板同步写入=0` 临时 Rebuild 后，运行路径不执行 SQL 写命令，日志出现预处理开关关闭跳过控制面板运行态 SQL 初始化。
6. 宏关闭运行路径业务进程退出码为 0；验证后普通 Debug Rebuild 恢复默认宏开启构建。
```

## 3. 堵点

```text
堵点：真实 SQL Server 不可用时的控制面板诊断显示未做侵入式验证。

原因：
    当前代码连接串固定为 .\SQLEXPRESS / 鱼巢投影库。
    若要制造真实 SQL 不可用，需要停用 / 改连本机 SQL Server，或新增故障注入路径。
    停用本机 SQL Server 会影响用户本地环境；新增故障注入路径会改变当前计划范围。
    项目规则禁止用伪造样本、伪造入口或假 SQL 结果冒充真实验证。

已排除：
    不用日志文本冒充控制面板诊断显示。
    不停用 SQL Server 服务制造不可用环境。
    不新增临时连接串开关作为当前 S7 的临时测试入口。

当前判断：
    常规运行态 SQL 读写显示路径已验证。
    预处理宏关闭路径已验证，SQL 写命令在进入 ADO 前被阻断，业务自检路径仍退出码 0。
    真实 SQL Server 不可用诊断显示需在用户授权停服 / 独立 SQL 隔离环境 / 正式故障注入计划具备后恢复。
```
