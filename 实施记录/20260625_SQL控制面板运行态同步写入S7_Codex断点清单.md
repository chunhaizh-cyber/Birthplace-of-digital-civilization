## 1. 真实验证预测

```text
1. 默认宏开启构建通过。
2. 默认宏开启下 `.\x64\Debug\鱼巢.exe --panel-html` 退出码为 0。
3. SQL 运行态只读查询能看到运行批次、事件流水、同步状态和当前态显示表。
4. HTML 中显示最近运行态 SQL 事件和当前态表入口。
5. 使用 `CL=/D鱼巢_开关_启用SQL控制面板同步写入=0` 临时 Rebuild 后，运行路径不执行 SQL 写命令，日志出现预处理开关关闭跳过控制面板运行态 SQL 初始化。
6. 宏关闭运行路径业务进程退出码为 0；验证后普通 Debug Rebuild 恢复默认宏开启构建。
```

## 3. S7b 真实 SQL Server 不可用验证

```text
服务暂停：
    用户手工暂停本机 MSSQL$SQLEXPRESS 服务。
    Get-Service -Name 'MSSQL$SQLEXPRESS' 显示 Status=Paused，StartType=Automatic。

SQL 不可用业务路径：
    .\x64\Debug\鱼巢.exe --self-check-log --self-check-log-wait-ms=5000
    退出码 0。
    日志 `日志/鱼巢_run_20260626.低值g` 出现：
        控制面板运行态SQL初始化失败
        ADO打开连接失败 | HRESULT=0x80004005
        SQL Server 服务已经暂停
        影响=仅控制面板SQL显示镜像不可用，业务结构不回滚

SQL 不可用控制面板路径：
    单独重定向复跑 .\x64\Debug\鱼巢.exe --panel-html
    退出码 0。
    输出：控制面板 HTML 已生成: D:\鱼巢\控制面板.html | 来源=ADO-SQL。
    控制面板.html 更新时间=2026-06-26 08:56:00。
    HTML 包含：
        SQL 投影读取失败
        ADO打开连接失败
        SQL Server 服务已经暂停

    Get-Service -Name 'MSSQL$SQLEXPRESS' 显示 Status=Running，StartType=Automatic。
    恢复后 .\x64\Debug\鱼巢.exe --panel-html 退出码 0。

    控制面板.html 更新时间=2026-06-26 08:58:40。
    HTML 不含 `SQL 投影读取失败`，包含运行态 SQL、运行批次和 ADO / SQL Server 数据来源。

排除项：
    未伪造 SQL 结果。
    未新增临时连接串开关。
    未把日志文本当作控制面板诊断页证据；控制面板.html 已实际写出诊断页。

当前判断：
    常规运行态 SQL 读写显示路径已验证。
    预处理宏关闭路径已验证，SQL 写命令在进入 ADO 前被阻断，业务自检路径仍退出码 0。
    真实 SQL Server 不可用时，业务继续、SQL 同步失败只影响显示镜像、控制面板可生成诊断页。
    SQL Server 恢复后，控制面板可恢复为运行态 ADO-SQL 页面。
```
