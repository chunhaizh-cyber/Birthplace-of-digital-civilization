# 20260702_D455稳定深度聚簇优化_Codex断点清单

## 0. 恢复摘要

当前切片：D455 普通高频观察报告路径清理与优化。

本轮结论：

- 不删除 `D455_提取迁移分割空间候选` / `D455_写回迁移分割空间候选`：它们仍用于完整材料、单帧证据卡和精细 smoke，按规范只能作为 L0/L1 诊断、回查、局部细分或低频材料。
- 普通报告路径新增 `提取轻量深度网格候选摘要_v2`、`从轻量观察帧生成结果_v2`，由 `从轻量观察原始帧生成报告` 切到 `_v2`。
- `_v2` 不再复制慢的精细分割；默认复用原多线程轻量深度网格候选，只有输入帧真实携带 raw / filtered / filled 额外深度口径时才补三口径诊断，避免高频队列降速。
- `_v2` 普通轻量帧不再无条件复制整帧；只有真实需要切到 filtered / raw 深度口径时才创建分割帧副本。
- 报告生成增加稳定深度网格版本标记分支；当前高频轻量帧未携带额外三口径时仍保持旧轻量网格报告口径，避免用空结构冒充稳定深度结构。

禁止宣称：

- 不宣称精细分割已进入普通高频路径。
- 不宣称单帧簇已经是稳定世界存在。
- 不宣称 D455 稳定深度聚簇最终闭环已完成。
- 不宣称识别、扫描、跟踪或自我苏醒完成。

下一步：

- 若要继续优化跨帧稳定簇，应在 `外设线程_D455深度相机.ixx` 的跨帧匹配 / 稳定发布门上做版本化小切片，不再把精细分割塞入普通路径。
- 若要高频路径也保留 raw / filtered / filled 全量深度，应先改成零拷贝或压缩材料页承载；直接逐帧复制三套 640x480 深度会把普通队列降到约 8-15fps。

## 3. 实施内容

1. 新增 `提取轻量深度网格候选摘要_v2`。
   - 默认复用旧多线程轻量网格候选，保留原有 30fps 级普通路径。
   - 当输入帧携带额外深度口径时，补充 raw / filtered / filled 三口径诊断和稳定性摘要。
2. 新增 `从轻量观察帧生成结果_v2`。
   - 普通报告构建入口改由 `_v2` 生成调用结果。
3. 更新 `D455_从调用结果生成逐簇识别报告` 的报告生成方法版本分支。
   - 有真实深度来源 / 稳定性 / 邻域一致性结构时标记为 `20260702-D455轻量稳定深度网格`。
   - 否则仍保留旧 `20260701-D455轻量深度网格` 口径。
4. 收掉 `_v2` 普通路径冗余整帧复制。
   - 无额外深度口径时直接用输入帧调用旧多线程轻量网格提取。
   - 有 filtered / raw 深度口径时才创建副本并切换提取用深度数组。

## 4. 试错记录

曾尝试在高频轻量采集里逐帧复制 raw / filtered / filled 三套深度，并让 `_v2` 做全帧串行深度桶聚合。

实测结果：

- 第一次重版：普通报告队列 `入队FPSx100=834`，不合格。
- 收窄候选聚合后仍为 `入队FPSx100=875`，不合格。
- 保留多套深度复制但复用多线程候选后为 `入队FPSx100=1545`，仍不合格。

最终处理：

- 撤回高频轻量采集多口径全量复制。
- 对 `_v2` 增加额外口径门控。
- 保留普通高频路径吞吐。
