## 1. 已完成复核

规范结论：

```text
需求当前满足判定是运行期实时视图。
每次判断必须读取当前状态 / 当前值，与目标状态 / 目标值和满足关系比较。
需求有效截止只表示本轮活动承接截止 / 不参与当前活动集。
任务完成只是结算输入之一，不能直接等同于需求满足。
```

代码锚点：

```text
任务模块.筹办.ixx
    统计直接子需求聚合_筹办：当前 `需求已截止 || 需求已满足` 计为子已满足。
    返回直接子需求聚合筹办结果：当前由未满足子数为 0 推出目标结果符合。

自我线程模块.impl.cpp
    私有_回查父需求目标_任务管理新链：当前 `已满足或截止子数 == 直接子总数` 设置父目标已满足。
    私有_收束已完成叶需求_线程侧：当前按完成 / 已结算任务直接调用来源需求收束入口。
```

可复用正确路径：

```text
任务模块.筹办.ixx::筹办_判定需求满足状态
自我线程模块.impl.cpp::私有_需求状态已满足_任务管理新链
```

```text

5. `rg` 不再命中机器逻辑中的 `已满足或截止子数` 和 `需求已截止 || 需求已满足`。
6. Debug x64 构建通过。
```
